\paragraph{Code and data.}
We publish the code that reads, processes and evaluates the two corpora used here, and the aggregated results, as a
release of the study repository with a DOI on acceptance. We do not write or publish code that reads other released
keystroke logs directly; in particular, no code reads the competition data. This lets others repeat and extend the
evaluation on the same corpora without distributing a tool aimed at a particular release (see the ethical
considerations). The data are not redistributed: KLiCKe, ENJA15 and the KeyTAR model are obtained from their sources
under their licences, and the repository records the versions and SHA-256 of the files we used. Results per writer are
not published.
