# A registered methodological review of measurement in studies of "AI fatigue"

Materials for a methodological review (meta-research) of how studies of AI-related fatigue attribute fatigue to AI,
measure it and report it. The protocol is registered with the Generalized Systematic Review Registration form.

- `manuscript/outline.md`: the structure of the manuscript, the claims and their evidence, and the table shells,
  fixed before coding.

The code table, codebook, coding form and synthesis scripts will be added at registration and publication.
