\section{Conclusion}
\label{sec:conclusion}

In the CS1 holdout (139 students), the discrimination AUC of the 30-second change of the estimator's two signals, in
the matched comparison, fell within the band $[0.45, 0.55]$ set in advance (Section~\ref{sec:limitations} qualifies
the error rate). These signals gave no basis for a seconds-scale trigger before stalls in character production. An
estimator of the same type intended as a trigger can be checked against a band set in advance on held-out writers, and
the code of the procedure is released for that purpose.
