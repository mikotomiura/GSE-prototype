\section{Conclusion}
\label{sec:conclusion}

In the CS1 holdout (139 students), the discrimination AUC of the 30-second change at $u$ of the estimator's two signals,
in the matched comparison, fell within the band $[0.45, 0.55]$ set in advance (Section~\ref{sec:limitations} qualifies
the error rate). On this input, the change of these signals over the 30~s up to the last character input gave no basis
for a trigger before stalls in character production; the estimator responded only to injected changes far larger than
those observed, and simple keystroke quantities ranked the same pairs higher. An estimator of the same type intended as
a trigger can be checked against a band set in advance on held-out writers, and the code of the procedure is released
for that purpose.
