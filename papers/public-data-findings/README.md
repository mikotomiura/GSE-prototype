# Keystroke run-up to stalls: a preregistered equivalence test

This directory holds the manuscript of a study that tests, on a preregistered holdout of a public introductory
programming keystroke dataset, whether the 30-second change in two signals of a keystroke state estimator distinguishes
the run-up to a stall in character production from the run-up to a matched short pause that did not become one.

- `manuscript/`: the LaTeX sources for the Journal of Educational Data Mining (`BUILD.md` says how to build them).

The preregistration, the deviation, the start records and the results are public on the Open Science Framework
(<https://osf.io/mrkxt>, <https://osf.io/fqgcp>, <https://osf.io/ajg2x>, <https://osf.io/uj6cy>). The public data are not
redistributed here. Where the code of the evaluation procedure will be released is to be decided before submission.
