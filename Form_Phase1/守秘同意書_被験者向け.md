# GSE ユーザー検証 守秘同意書（被験者向け）

三浦 尊統（以下「研究者」）が開発する **GSE（Generative Struggle Engine、以下「本ソフトウェア」）** の
ユーザー検証にご参加いただくにあたり、本ソフトウェアが**未公開**であることをふまえ、
以下の守秘事項に同意していただきます。

本同意は、あなた（参加者）の**データやプライバシーを制限するものではありません**。
データの取り扱い・記録内容・撤回の自由は、別途の「参加同意・スクリーニング（F1）」の説明のとおりです。
本書は、あなたが検証中に知り得た**研究者側の未公開情報を口外しない**ことだけをお願いするものです。

## 1. 守秘の対象（あなたが第三者に話さない情報）

検証への参加を通じて知り得た、本ソフトウェアに関する次のような未公開情報：

- 画面・UI・操作感、介入（通知 / Wall / タイマー / 散歩のうながし等）の具体的な挙動や文言
- 認知状態の推定の仕組み・判定ロジック・パラメータに関する説明
- 未公開の機能・仕様・設計、開発中の不具合や制限事項
- 研究者から「これは未公開なので口外しないでほしい」と口頭・書面で示された情報

## 2. お願いすること

- 上記の情報を、SNS・ブログ・口頭・スクリーンショット等で**第三者に共有・公開しないでください**。
- 検証で配布されたアプリ・ファイルを、第三者に再配布しないでください。
- これらの義務は、**検証終了後も継続**します（公知になるまで）。

## 3. 対象外（守秘の対象に含まれないもの）

- すでに公開されている情報、またはあなたの責任によらず公開された情報
- あなたが本検証より前から正当に知っていた情報
- 本ソフトウェアの情報によらず、あなたが独自に得た情報
- 法令や公的機関の正当な要求により開示が必要な情報

## 4. あなたのデータについて（確認）

- あなたの操作ログ・アンケート回答の扱いは F1 同意のとおりで、本書はそれを変更しません。
- あなたはいつでも理由を告げずに参加を撤回でき、撤回によって本守秘の対象（研究者の未公開情報）
  以外で不利益を受けることはありません。
