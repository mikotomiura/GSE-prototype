## 問い

round 4 の指摘（R1・R3・Codex）: 他人で選ぶ目的（他の書き手の「本人 − 連鎖」の中央値）は予測の良さを選ばず、候補に置いた最頻値（多くの書き手で選ばれた当てはめより良い）をほとんど選ばない。Take-home（15-session のパネルで、選ばれた本人の当てはめは最頻値を上回らない）は、この目的に依るか。

## D2 目的を替えた選び

- 目的「平均」: 候補ごとに、w を除く書き手 v の値の平均（中央値ではなく）。値は sel と同じ（2 段（他人）は 本人(構造, τ) − r1、τ 他人は 本人(τ) − 同じ構造の共通）。v ごとに r1 と共通は候補に依らないので、平均の目的の順は、他の書き手の評価の単位の 1 記号あたりの対数尤度の平均の順と同じ（各書き手を同じ重みで数える）。
- 候補と同点の並べは sel と同じ（∞ → 最頻値 → 10^6 → … → 0・同じ τ の中では自由な母数の少ない構造が先・同点は先の候補）。
- −∞ の値は平均に入れる（他の書き手に 1 人でも −∞ があればその候補の平均は −∞）。−∞ の候補は、ほかの候補がすべて −∞ でない限り選ばれない。NaN は出さない（+∞ は値に出ない）。
- 主の行: 最頻値を候補に入れた並べ（sel と同じ候補）。副の行: 最頻値を候補から外した並べ（mode と同じ候補）で、目的だけを平均に替えたもの。
- 中央値の目的の値（sel の値）を同じ表に並べる（「中央値」の列）。

## D4 休止の秒の割合

- パネルの書き手ごとに、評価の単位の記号のうち、押下の印が 0 の記号（直近 30 秒の窓に押下が無い秒）の割合。パネルごとに、全員を合わせた割合と、書き手ごとの割合の中央値・四分位・最小・最大・人数。
- パネルの書き手は sel の `ml.panel_members` の k のどれかに入る書き手（パネルの和）。
- 押下のある記号だけの主の値（sel の summary の `pressed/…`）は既にあるので、ここでは数えない（外枠では S6 に置く）。

## D5 読みの形（結果より前に決める・閾値を置かない）

見る所: 2 段（他人）の主の行（平均の目的・最頻値を候補に入れる）・CoAuthor P15・k = 1〜15。k ごとの形とパネルの形は sel の `k_form`・`readings` をそのまま当てる（M・S・N・∞・なし。分母は ∞ の k を除いた k）。

- 形 N: 「選ぶ目的を他の書き手の予測の良さ（平均）に替えても、選ばれた本人の当てはめは最頻値を上回らない」。Take-home の 15-session の文は目的に依らないと書く。
- 形 M: 「予測の良さで選ぶと、手順は多くの書き手に最頻値そのものを選ぶ」。Take-home を「最頻値が選ばれる（本人の記録を使わない平滑した共通が、本人の当てはめより良いと他人の予測が示す）」に書き換える候補にする。
- 形 S: 「予測の良さで選ぶと本人の寄与（値）が残る」。Take-home は目的に依ると書き、中央値の目的と平均の目的の両方を並べる。
- どれにも当たらない: 値を並べ、形を書かない。
- P30 と C5 は同じ形で読み、値を並べる。副の行（最頻値を候補から外す）は値だけ。
- 外枠への持ち込み（形に依らず）: 選びの目的の感度として 4.3 か 4.4 に 1 文と S9 の表。どの形でも書き換えの採否は研究者に問う。
- 「最頻値 − 共通」と休止の秒の割合は値だけ（読みの形を置かない）。外枠では 4.4 と Table 1。

## V1 門（実データの前・合成だけ・Mac と HP Z2 の両方で通す）

| 門 | 通る条件 |
|---|---|
| P-HASH | D1 の SHA-256 がすべて一致（読み込みの時点で止める） |
| P-MEAN | 中央値と平均で選びが違うように作った合成の値で、平均の目的が手で数えた候補を選ぶ |
| P-NOW | 合成で、w 自身の値をでたらめに書き換えても w の選びが変わらない（乱数 200 回） |
| P-NEGINF | 他の書き手の 1 人に −∞ を持つ候補が選ばれず、NaN が出ない。すべての候補が −∞ の作った例では先の候補が選ばれる |
| P-SAMEMED | 合成の値で、この試験の選びを中央値に戻すと sel の `_select` と同じ選び |

| 変異 | 赤になるべき門 |
|---|---|
| o1: 平均でなく中央値で選ぶ | P-MEAN |
| o2: 選びに w 自身の値を入れる | P-NOW |
| o3: −∞ を平均から捨てる | P-NEGINF |

- 本計算の P-REPRO・P-SAMESEL・P-NEVAL は本計算の中で当てる（外れれば止める）。

## V2 来歴と時間

- provenance.json: git の HEAD・実験のディレクトリの未コミットの変更・読み込むコードの SHA-256・pickle の SHA-256・照らしの結果・Python と numpy の版・機械。
- run.sh は 1 コマンドで selftest → 変異 → 照らし → 集計 → 休止の数え → report を回す。場所は HP Z2（実データ）。selftest と変異は Mac でも回す。
- 時間: 当てはめを回さないので、データの読み込みを含めて数分〜十数分の見込み。1 時間を超えたら止めて報告する。
- 書き出すファイルは改行を LF に固定する（`open(..., "w", newline="\n")`・計算 3 の CRLF の件）。
