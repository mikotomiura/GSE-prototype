## 2. ★ 設計に効く発見 3 つ（判定そのものより重要）

### 発見 1: 検出器は **within-person** でなければならない

今回のロバスト z は**全セッションを母集団**に取ったため、**被験者間の差が支配した**
（並べ替え検定が有意になったのはまさにそれ）。しかし out-of-scope 検出が問いたいのは
**「この人の、このセッションが、その人自身の普段と違うか」**である。

→ **母集団基準ではなく個人基準で定義し直す必要がある。**
これは [V30]（被験者横断の universal marker は存在しない）と整合し、
`§4.4 Phase A`（EWMA ＋ robust quantile による個人基準）に**そのまま乗る**——
新しい機構を作る必要はなく、既に設計にある個人基準の**用途が 1 つ増える**だけである。

⚠️ **本実験は within-person 版を事前登録していないので実施していない。** 次ラウンドの第一候補。

### 発見 2: ★ 長ポーズは「計画」と「離席」に**分解しないと使えない**

事前登録では M4 を `IKI > 10s` の割合と定義したが、これは
**計画ポーズと離席（away）を混ぜている**。分解した探索的結果（下記 §4）では像が変わった。

→ `§5.2` の Tier 1「**沈黙長の分布**」は、p50/p90/max だけでなく
**帯域別の率（例: 2–10s / 10–120s / >120s）**を持つべきである。
分位点だけでは「計画ポーズが多い人」と「離席が多い人」が同じ値になりうる。

### 発見 3: 宣言された `task_kind` は**教師として使えない**

`session_meta.task_kind` は**全 40 セッションが `argumentative`**（`condition` も全て `blind_calibration`）。
分散ゼロなので識別情報を持たない。

→ 対処案 ②（セッション開始時のタスク宣言）は、**単独では無力**であることが実データで裏づけられた。
較正プロトコルが値を固定してしまうため、宣言値は「実際に何をしたか」と独立に決まる。
**② は ③ と組み合わせて初めて意味を持つ。**

## 4. ★ 探索的分析（**事前登録していない**・確証に使わない）

事前登録の時点で「M4 は計画ポーズと離席を混ぜている」という交絡を認識していたため、
**帯域を分けて再計算した**。これは事前登録外なので**探索的結果としてのみ報告する**。

| PID | 計画ポーズ相当 (10–120s) | 離席相当 (>120s) |
|---|---|---|
| P010 | 0.0110 | 0.0010 |
| **P011** | ★ **0.0012** | 0.0000 |
| P012 | 0.0103 | 0.0010 |
| P013 | **0.0101** | 0.0036 |
| P014 | 0.0098 | 0.0025 |

### 像が変わった点

- **P013 の計画ポーズ率は他被験者と同等**（0.0101 vs P010 0.0110 / P012 0.0103 / P014 0.0098）。
  生の長ポーズ率で外れて見えたのは **離席（>120s）が最多（0.0036）だったため**であり、
  **ポーズ構造そのものは正常**だった。
- **P011 だけが残る**。計画ポーズ率が他の **約 1/8**、離席は 0。
  5 セッション（各 21–31 分・5,200–8,400 打鍵・166–278 keys/min）で、
  **1 セッションは 10 秒超の間隔が 1 回も無い**（21 分・5,756 打鍵）。
- ★ **交絡の効き方が非対称**である点が重要: 離席の混入は長ポーズ率を**押し上げる**方向にしか働かない。
  したがって **P013 の「思考が多い」ように見えた像は交絡で説明できるが、
  P011 の「ポーズが無い」像は交絡では説明できない**。

## 5. ⚠️ 解釈の制限（事前登録 §解釈の制限 をそのまま適用する）

1. ★ **外れ値であること ≠ 対象外作業をしていたこと。** 本実験が示せたのは
   **「行動署名で区別できる」までである。** 何をしていたかは content-free では原理的に分からない。
2. **P011 の署名は「論述＝計画ポーズを伴う」という設計上の想定と整合しない**が、
   それは「対象外作業だった」の証明ではない。**極めて流暢な書き手**でも同じ署名になりうる。
   結論するには**本人への確認か、外形的な記録**が要る。
3. **本実験の結果で `docs/` の確証トラックを書き換えていない**（事前登録の宣言どおり）。
4. **多重性**: 6 指標 × 38 セッション = 228 セル、|z|>3.0 の偶然期待は 0.62 件。
   実測 13 件はこれを大きく超えるが、**閾値は事前固定であり後から緩めていない**。

### ★ 別途の吟味を要する点（本実験では扱わない）

`§1.2` の「弱いが一貫した信号」のうち、**`f3`→Q2 が P011 で p=.003（唯一の名目有意）** という記述は、
**P011 のセッションに依存している**。P011 の署名が設計上の想定と整合しない以上、
この根拠は**別途の吟味を要する**。

⚠️ ただし **本実験は `§1.2` を書き換えない**（事前登録の制限 5）。
書き換えるとしたら、P011 の実態確認を経てからである。
**伝聞と同じ扱い**——確認されていない情報で確証トラックを動かさない。

## 6. 次ラウンドの候補（優先順）

1. ★ **within-person 版の検出器**（発見 1）。個人基準からの逸脱として定義し直す。
   `§4.4 Phase A` の個人基準にそのまま乗るので実装コストは低い。
2. ★ **P011 の実態確認**（本人・研究者の記録）。当たれば ③ の検出器の答え合わせになり、
   外れれば「流暢な書き手を誤検出する」という**偽陽性の実例**が得られる。**どちらでも価値がある。**
3. **帯域別の沈黙率**（発見 2）を `§5.2` Tier 1 の定義に反映する。
4. 伝聞（P013）の確認。★ **本実験の範囲では P013 のポーズ構造は正常**であり、
   打鍵レートの低さと離席の多さで説明がつく。
