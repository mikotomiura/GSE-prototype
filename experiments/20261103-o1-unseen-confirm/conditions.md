## U2 H4a 日の揺れ（対象は C0）

- 日の数 D（U1 で残った日）が 5 未満なら「決まらない（日数不足）」とし、量だけ出す（判断 2）。
- θ の温まりを除く（判断 7）: 日 d の温まりの終わり w_d = その日の θ の標本（C0 は押下の間隔・`gap_pool`）が 100 個そろう時刻。T_d = w_d 以後の観測時間、n_d = 原点（t0）が w_d 以後の観測区間（端を含む）にある C0 の件数。標本が 100 個にならない日は T_d = 0 で H4a に入れない。λ̂ = Σn_d / ΣT_d。C0 は温まりの中では構造上立たないので、温まりを含めると日ごとの温まりの割合の違いが見かけの過分散になる。14 日と同じ式（温まりを含めた観測時間と件数）の値も記述として並べる。
- X² = Σ_d (n_d − λ̂T_d)² / (λ̂T_d)、φ = X² / (D − 1)。p = P(χ²_{D−1} ≥ X²)（片側）。
- SD の比 = `unit_sd` の `sd_between_units` ÷ `sd_expected_poisson_mean`（停滞の分解・c1c2c6 と同じ式）。
- φ の 95% 上限 = X² / χ²_{D−1} の 2.5% 点（両側 95% の上の端）。
- 判定（主・判断 3）。判定は丸める前の値で行う:
  - 支持: p < 0.05 かつ SD の比 ≥ 1.5。
  - 反証: φ の 95% 上限 < 2.25（SD の比で 1.5 未満にあたる）。
  - どちらでもない: 決まらない。
  - 支持と反証が同時に立ったら止める（日数が数十日までなら起きない。2.25·χ²_{D−1} の 2.5% 点が χ²_{D−1} の 95% 点を下回るため）。
- 副（判定に使わない・判断 3）: 各日の観測時間を頭から 1 時間ずつに切る（観測区間をまたいで観測時間を積む・最後の 1 時間に満たない残りは捨てる）。θ の温まりを除いた観測区間を使い、ブロックの断片はすべて半開 [x, y) で数える（境界の原点を 2 度数えない・観測区間の終わりちょうどの原点は数えない）。ブロックごとの C0 の件数（t0 で数える）から、日を群にした一元配置の F（群の間の平均平方 ÷ 群の中の平均平方）を出す。ブロックを日の間で並べ替え（各日のブロック数は固定）、2,000 回、SEED は `SEED`。p_perm = (1 + #{F_perm ≥ F_obs}) / 2,001。群の中の平均平方が 0 のとき、F は群の間の平方和が正なら ∞、0 なら定義しない（観測の F が定義されなければ副は出さない。並べ替えの回で定義されなければ数えない）。ブロックが 2 個未満の日は副に入れない。
- 読み: 主が支持で副の p_perm ≥ 0.05 なら「日の揺れの一部は、日の中の 1 時間を超える固まりで出る」と書く。主が支持で副も p_perm < 0.05 なら「日の間の差が日の中の 1 時間ごとの差を超える」と書く。副の並べ替えは 1 時間より短い固まりをブロックの中に残すので、日の中の固まりを全部は除かない。
- C1・C2 にも同じ量（X²・φ・p・SD の比・φ の上限・副）を出し、記述として並べる（判定しない）。温まりは C1 では活動の出来事の間隔、C2 では C0 と同じ押下の間隔で取る。

## U3 H5 作業の時期（対象は C0 の t0）

- 日の数 D（U1 で残った日のうち、θ の標本が 100 個そろった日）が 5 未満なら「決まらない（日数不足）」。
- まとまり: 停滞の分解と同じ「押下で区切った作業のまとまり」（押下の間が 30 分以上空いたら次のまとまり・`types_core.blocks_from_press`）。まとまりの範囲は開始からそのまとまりの最後の押下まで（判断 7）。まとまりを終わらせる 30 分以上の途切れと、その途切れで立つ C0（最後の押下の後に t0 がある停滞）は入れない。まとまりの観測時間 = 範囲と観測区間の交わりの長さ。
- 使うまとまり: 観測時間が 60 分以上のもの（判断 4）。60 分以上のまとまりが 10 未満なら「決まらない（まとまり不足）」（Claude が置いた下限・判断 5）。
- 温まりを除く: まとまりの開始から 10 分の範囲（`types_core.EARLY_MS`・壁時計）と、その日の θ の標本（C0 と同じ押下の間隔の標本・`gap_pool`）が 100 個そろう時刻より前を除く。標本が 100 個にならない日は H5 に入れない。
- 残りの観測時間 R_b を、観測時間で前半と後半に分ける（前半の観測時間 = R_b / 2 になる時刻 m_b で切る）。t0 が残りの観測の中（各断片の半開 [x, y)）にあり m_b より前なら前半、m_b 以上なら後半。残りの外の t0 は数えない。
- RR = Σ_b 後半の件数 ÷ Σ_b 前半の件数（前半と後半の観測時間は各まとまりで等しいので、率の比と同じ）。どちらかの和が 0 なら両方に 0.5 を足す（ブートストラップの各回も同じ）。
- 区間: まとまりを単位にした復元抽出（全日のまとまりをプール）2,000 回、SEED は `SEED`。log RR の標準偏差 SE を取り、log RR_obs ± 1.96·SE を戻した値を 95% 区間とする（判断 4）。
- 判定（判断 4）:
  - 前半と後半の件数の合計が 40 未満なら「決まらない（件数不足）」（判断 7）。
  - 支持: 95% 区間の下限 > 1。上限 < 1.25 でも支持とし、「差は 1.25 倍未満」と添える（判断 7）。
  - 反証: 支持でなく、95% 区間の上限 < 1.25。
  - どちらでもない: 決まらない。
  - 判定の順: 日数 → まとまりの数 → 件数 → 支持 → 反証。判定は丸める前の値で行う。
- 記述（判定に使わない）: 同じ残りの観測時間を 3 等分した各部分の C0 の 1 時間あたりの率。前半・後半の件数と観測時間。除いた温まりの観測時間。C1・C2 にも同じ RR と区間を出す（判定しない）。

## U5 陽性対照と変異（実データの前に走らせる・止める）
