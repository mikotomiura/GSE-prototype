## 問い

論文 3 の外枠の attack-me round 2（R2 N2・Codex）に答える。外枠の手順（構造と τ を他人で選ぶ・τ = ∞ を候補に入れる）の下で、実データの残りは小さかった（CoAuthor の 15-session パネルで本人 − 共通 +4.1e-4〜+7.2e-4、CS1 は共通そのもの）。

- (a) 用量: 既知の大きさの個人差を埋めると、手順は正の本人 − 共通を返すか。埋めた大きさに応じて上がるか。拾える最小の大きさ（感度の下限）はどこか。
- (b) 陰性対照: 埋めた差が 0 のとき、どれだけの正の残りが出るか（事前分布の最頻値と共通の違いだけで出る残り）。
- (c) 構造: 真の構造が候補の外（候補の上端 K = 3 より状態の多い AR(1)-HMM）のとき、差 0 の残りは大きくなるか。埋めた差を拾えるか。
- (d) 分布: 書き手の一部だけが大きく違うとき、中央値で選ぶ手順はそれを拾うか。

## 読まないこと

- 合成の結果を実データの書き手の個人差の大きさの推定として読まない。言えるのは「この真の生成・この形の記録の量で、この手順が拾える大きさ」だけである。真の生成は 1 つの作り（AR(1)-HMM・記号の遷移の行の混ぜ）で、実データの生成を表すとは主張しない。
- 結果を段 1 の候補の採否や ADR-047 の主張の根拠にしない（ADR-047 D2・D6）。使うのは論文 3 の外枠の S15・4.3・限界の文だけ。
- EM の状態に名前を付けない（ADR-046 D1）。閾値の検定を置かない。数字は記述。

## D1 真の生成

### 共通の真の母数 m0（真の構造ごとに 1 つ・乱数 [SEED + 2, K]）
- 族: AR(1)-HMM（`hmm2.py` の kind = "ar"）。用量と分布の筋は K = 3、構造の筋は K = 5。
- π: 一様。A: 対角 0.97、残りの 0.03 を他の状態に等分。H の行: Dirichlet(1)。
- C の行: C0[k, j, :] = ρ_k · e_j + (1 − ρ_k) · q_{k, j}、q_{k, j} ~ Dirichlet(1)（26 記号）。ρ は K = 3 で (0.6, 0.8, 0.9)、K = 5 で (0.5, 0.65, 0.8, 0.9, 0.95)。e_j は前の記号 j に 1 を置いた単位の行（記号が続きやすい列にする）。
- 実データの母数・npz・書き手ごとの値は使わない。

### 書き手ごとの真の母数 m_w（個人差の埋め方）
- C だけを変える（記号の遷移の個人差）: C_w[k, j, :] = (1 − λ_w) · C0[k, j, :] + λ_w · D_w[k, j, :]。π・A・H は m0 と同じ。
- D_w[k, j, :] ~ Dirichlet(2 · C0[k, j, :])。期待値が C0 の行なので、書き手の C の平均は C0 になる（m0 が書き手の集団の中心）。D_w は書き手ごとに一度引き、段（λ）を変えても同じものを使う。
- λ_w: 用量と構造の筋は全員同じ λ（段の値）。分布の筋は、書き手の通し番号（パネル・共通だけの書き手を通して 0 から）を 4 で割った余りが 0 の書き手だけ λ（g = 3e-2 の値）、ほかは 0。

### 大きさの物差し（g）
- 書き手ごとの真の利得 g_w = 本人の評価の系列での「m_w の 1 記号あたりの対数尤度 − m0 の 1 記号あたりの対数尤度」（`ml.Eval.ll` と同じ量・nats/記号）。外枠の量と同じ単位。
- 段の目標 g* ∈ {0, 1e-3, 3e-3, 1e-2, 3e-2}（用量）・{0, 1e-2}（構造）・3e-2（分布の埋めた書き手）。
- λ の較正（真の構造ごと・乱数 [SEED + 3, K]）: 較正の書き手 40 人（D_w をそれぞれ引く）に 20,000 記号の系列を 1 本ずつ作り、g_cal(λ) = 書き手の g_w の中央値。λ ∈ [0, 1] の二分法（40 回・各回の系列の乱数は同じ種）で、g_cal が g* の ±10% に入る λ を採る。入らなければ止める（逸脱として書く）。λ の値と g_cal は出力に書く。g* = 0 は λ = 0。
- 各複製の実際の g_w（評価の系列で測った値）の中央値と四分位も出す。

## D7 読みの形（結果より前に決める）

### 用量（形 × 主のセルごと）
- 陰性対照の上の端 U = 用量の g* = 0 の種ごとの主の量の中央値の最大。
- 拾える（段・セル）: その段のすべての種で、主の量の中央値が U を超え、かつ良い側の割合が 0.8 以上。
- 感度の下限（セル）: 拾える段のうち最小で、それより大きい段もすべて拾えるもの。無ければ「3e-2 でも拾えない」。
- 上がる: 主の量の中央値の種の平均が、段の順（0 → 3e-2）に減らない。
- 回収の比は値だけを書き、判定に使わない。

### 構造（CoAuthor の主のセル）
- (c1) 外れた構造での差 0 の残り: K = 5・g* = 0 の 3 種の主の量の中央値を、K = 3 の陰性対照の U と、実データの残り（+4.1e-4〜+7.2e-4）と並べる。3 種すべてで中央値が K = 3 の U を超えるなら「真の構造が候補の外だと、個人差が 0 でも、候補の中のときより大きい正の残りが出る」と書く。超えないなら「外れた構造は、この作りでは残りを大きくしない」と書く。
- (c2) K = 5 の g* = 1e-2 の拾える: U を K = 5・g* = 0 の 3 種の中央値の最大に置き換えて、用量と同じ規則。

### 分布（CoAuthor の主のセル）
- (d1) パネル全体の主の量で、用量と同じ「拾える」の規則（U は K = 3 の用量の陰性対照）。
- (d2) 埋めた書き手だけの主の量の中央値が U を超えるか。選ばれた τ が ∞ と 10^6 の外（格子の中）に動いた書き手の数。
- 読み: (d1) が拾えず (d2) が正なら「少数の書き手の大きな個人差は、パネル全体の中央値では見えない」と書く（手順は中央値で選ぶので）。

### 外枠への持ち込みの場合分け
- CoAuthor の主のセルの感度の下限が 3e-3 以下: 4.3 に「記録の量を CoAuthor の 15-session パネルに合わせた合成では、手順は埋めた（値）以上の遷移の個人差を正の差として返した。実データの残り（約 1e-3 以下）は、この作りでそれより大きい個人差が無いことと合う」の趣旨。
- 下限が 1e-2 以上・または拾えない: 4.3 と限界に「手順は（値）未満の個人差を拾えない。実データの小さな残りは、それより小さい個人差が無いことを示さない」の趣旨。
- U が実データの残りと同じ桁（1e-4 以上）: 「個人差を埋めない合成でも同じ桁の正の残りが出た」を、残りを本人の上積みとして読まない根拠に加える。U が 1e-4 未満: その根拠には使わず、値だけを書く。
- CS1: CS1 の主のセルの下限を「CS1 で共通そのものが選ばれたことは、（値）以上の個人差が無いことと合う」の形で書く（下限があるときだけ）。
- 構造と分布の結論は補足 S15 に書き、本文は 1 文までにする。

## V1 陽性対照と変異（合成だけ・本計算の前に通す）

| 対照 | 通る条件 |
|---|---|
| P-HASH | 読み込む 4 つのコードの SHA-256 が D3 の値 |
| P-PLANT0 | λ = 0 で、すべての書き手の C_w が C0 と完全に一致し、g_w がちょうど 0 |
| P-MEAN | D_w の行の書き手 2,000 人の平均が C0 の行と最大の絶対差 0.01 未満 |
| P-DIFF | λ > 0 で、2 人の書き手の C_w が違う（D_w が書き手ごとに引かれている） |
| P-CAL | 較正の λ で g_cal が g* の ±10%（小さい較正: 書き手 10 人 × 5,000 記号・g* = 1e-2） |
| P-GROUP | 分布の筋で λ_w > 0 の書き手が、通し番号を 4 で割った余りが 0 の書き手と一致 |
| P-SPLIT | 合成の形で、評価の単位が学習の単位・w を除く共通のどちらにも入らない（`DT.split` と `pool_units` の exclude） |
| P-RECOVER | 小さい合成（パネル 8 人 × 20 セッション × 400 記号・共通だけの書き手 0・g* = 0.1・k = 15）で、主の量の中央値が正、かつ良い側の割合が 0.75 以上 |
| P-NULLSAME | g* = 0 の合成で、2 人の書き手の系列の生成の母数が同一（m_w = m0） |
| P-JOINTW | 2 段（他人）の選びに、w の値をでたらめに書き換えて渡しても w の選びが変わらない（作った例 1 つと乱数 200 回） |

| 変異 | 赤になるべき対照 |
|---|---|
| v1: D_w を全員で 1 つにする | P-DIFF |
| v2: g_w を m_w でなく w を除く共通の当てはめで測る | P-PLANT0 |
| v3: 2 段（他人）の選びに w 自身を入れる（tau-extend の m12） | P-JOINTW |
| v4: 分布の筋の印を 1 つずらす | P-GROUP |
| v5: 評価の単位を学習に 1 つ混ぜる（tau-extend の m6） | P-SPLIT |

- 変異は check_mutations.py で、名指しの対照が赤、それ以外の対照の結果を出す。
