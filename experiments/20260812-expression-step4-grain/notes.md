### 3.2 ★★★ 実測が本物の欠陥を 1 件見つけた —— **層 2 が完全に無音だった**

> ★ **静的検査 58 件が全部緑のまま通り、捕まえたのは陽性対照だけだった。**

- **症状**: `層 2 単体 RMS = 0.000e+0`。**層 2 は 1 サンプルも音を出していなかった。**
- **原因**: `grain-processor.js` の `parameterDescriptors` に **既定 0 の `gain` AudioParam** があり、
  player 側は**外部の `GainNode` だけ**を設定していた。★ **ゲインの制御点が 2 つあり、片方が 0 のままだった。**
- ★★ **どうやって気づいたか**: **陽性対照 [3]（層 2 のゲインを 0.01 Hz で変調して検出できるかを見る）が
  `-61.8 dB` を返し、「検出できない = 計器を疑う」と出た。**
  ⚠️ **他のすべての検査は緑だった**——4 Hz 判定も側帯波も、**無音なら当然通る。**
  ★ **「危険な成分が無い」ことは「何も鳴っていない」でも満たされる。**
- **直し方**: ★ **Worklet からゲインの AudioParam を削除**し、**制御点を外部 `GainNode` 1 つに絞った。**
- ★ **同じ型を捕まえる検査を 3 つ足した**（`verify-before-claiming` ルール 6）:
  1. 動的 `[0]`: ★ **層 0 単体と層 2 単体の RMS を対照つきで測る**（片方だけでは無音と測定死を区別できない）
  2. 静的: **Worklet が `gain` AudioParam を持たない**（二重制御を作らせない）
  3. 静的: **player が `renderRms()` の定義と呼び出しの両方を持つ**
- ⚠️ **修正後の値**（同じ測り方）: 層 0 単体 **2.407e-1** / 層 2 単体 **1.716e-1** / 比 **0.713**。

### 3.3 ★ 検査自体の欠陥を 3 件、実測で見つけて直した

> ★ **どれも「緑だった」ものが実は測れていなかった／逆に自分の説明文に反応していた。**

| # | 何が起きたか | 直し方 |
|---|---|---|
| **1** | ★ **検査が自分のコメントに反応した** —— `Math.random` を禁じる検査が、`grain-processor.js` の**注記「Math.random() を使わない」に反応して赤くなった** | ★ **コメントを剥がしてから見る**。⚠️ これは silent pass の裏返し（false alarm）である |
| **2** | 分解能の検査が **浮動小数の丸めで落ちた**（`4.0 - 3.995 = 0.004999…` vs `2/400 = 0.005`） | ★ **bin 数で比べ**、相対誤差だけ許す。★ **基準は緩めていない**（Hann の主ローブ 2/T のまま） |
| **3** | ★★ **`renderRms` の存在検査が部分一致で緩かった** —— `renderRmsGone` に改名しても緑のままだった（**meta 検査が捕まえた**） | ★ **定義 `function renderRms(` と呼び出し `renderRms({` の両方**を要求する。⚠️ **Step 3 の音量スライダ silent pass と同じ緩さ** |

⚠️ **meta 検査の変異ケース自体も 2 件間違っていた**（先に別の検査が発火して、狙った検査を試せていなかった）。
★ **`first_failure()` が「名前 :: 理由」を返す形になっていたから気づけた**（S0-D14 の教訓が効いた）。

### 3.6 ★ 倍音傾斜（B / C 案の前提）の機構確認

|---|---|---|

⚠️★★ **そして「機構が分かれている」と「耳が分離できる」は別問題である**（S3-D13 の B 案の代償そのもの）。

## 5. ⚠️ 試していないこと（★ 「たぶん大丈夫」で埋めない）

1. ★★★ **停止ボタン・音量スライダが「実際に効く」ことは未検証**（**2 Step 連続**）。
   本セッションでも Chrome ウィンドウが **`visibilityState="hidden"` / `outerWidth=0`** で、
   **実クリックが届かなかった**（実測）。
   ⚠️ **合成クリックでは検証にならない**（autoplay policy で `AudioContext` が `suspended` のままになり、
   「押しても鳴らない」が仕様どおりの挙動として出てしまう）。
   → ★ **DOM 実在・停止がランプ経由であることは静的に確認済み。「押したら本当に止まる」だけが未確認。**
2. **10 分の連続再生は未実施。** 検算は 400 s のオフラインレンダであって実時間ではない。
   → ★ **メモリ・ノード数が増えないことは未確認。** player の
     「発振器 N + LFO M + 傾斜 K（★ 増えないこと）」表示で見られるようにしてある。
3. ★ **実データ（P010 等）を本 Step でまだ通していない**（`run.sh data` 未実行）。
   → **系統 A / B の実データ駆動・B3 は未実行。**
4. **実時間は 48 kHz、検算は 8 kHz。** ★ **粒の帯域が両方の Nyquist を下回ることは静的に検査している**が、
   **48 kHz の実出力の変調スペクトルは測っていない。**
5. ★★ **B / C 案の実レート（0.005 / 0.0005 Hz）での測定は原理的にできていない**（§3.6）。
   **0.25 Hz での機構確認だけである。**
6. ★ **SEED の再現性（同じ seed で同じ音になること）を 2 回走らせて突き合わせていない。**
7. **`file://` では動かないことを実測していない**（★ 動かないはずだが、確かめていない）。
8. **macOS では未確認**（Windows 11 / Chrome 151 のみ）。
9. ⚠️★ **粒の中心周波数 440 Hz / 帯域 ±600 cents / 粒長 40 ms は設計上の選択であって文献の値ではない。**
   ★ **耳で見直す対象である。**
