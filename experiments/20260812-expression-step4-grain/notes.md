### 3.2 ★★★ 実測が本物の欠陥を 1 件見つけた —— **層 2 が完全に無音だった**

> ★ **静的検査 58 件が全部緑のまま通り、捕まえたのは陽性対照だけだった。**

- **症状**: `層 2 単体 RMS = 0.000e+0`。**層 2 は 1 サンプルも音を出していなかった。**
- **原因**: `grain-processor.js` の `parameterDescriptors` に **既定 0 の `gain` AudioParam** があり、
  player 側は**外部の `GainNode` だけ**を設定していた。★ **ゲインの制御点が 2 つあり、片方が 0 のままだった。**
- ★★ **どうやって気づいたか**: **陽性対照 [3]（層 2 のゲインを 0.01 Hz で変調して検出できるかを見る）が
  `-61.8 dB` を返し、「検出できない = 計器を疑う」と出た。**
  ⚠️ **他のすべての検査は緑だった**——4 Hz 判定も側帯波も、**無音なら当然通る。**
  ★ **「危険な成分が無い」ことは「何も鳴っていない」でも満たされる。**
- **直し方**: ★ **Worklet からゲインの AudioParam を削除**し、**制御点を外部 `GainNode` 1 つに絞った。**
- ★ **同じ型を捕まえる検査を 3 つ足した**（`verify-before-claiming` ルール 6）:
  1. 動的 `[0]`: ★ **層 0 単体と層 2 単体の RMS を対照つきで測る**（片方だけでは無音と測定死を区別できない）
  2. 静的: **Worklet が `gain` AudioParam を持たない**（二重制御を作らせない）
  3. 静的: **player が `renderRms()` の定義と呼び出しの両方を持つ**
- ⚠️ **修正後の値**（同じ測り方）: 層 0 単体 **2.407e-1** / 層 2 単体 **1.716e-1** / 比 **0.713**。

### 3.3 ★ 検査自体の欠陥を 3 件、実測で見つけて直した

> ★ **どれも「緑だった」ものが実は測れていなかった／逆に自分の説明文に反応していた。**

### 3.11 ★★★ 層 2 の作り直し（2026-08-12・S4-D12）— 実装と、切替が no-op でないことの実測

#### なぜ作り直したか（★ 研究者の実聴による）

1. ★ **「粒子でのプラスの音が激しすぎる」**
2. ★ **見本モード（非盲検）で「変化自体が聞こえなかった」** → ★ **B7 は判定不能**（S4-D11）

★★ **(2) の機構的な原因は、本実験の config 自身が書いていた** ——
`density_norm_exp: 0.5` はエネルギー保存なので **「密度を上げても音量はほぼ変わらない」**。
★ さらに粒長 40 ms では重なりが **100/s で 4 枚・400/s で 16 枚**。
⚠️ **レベル手がかりは設計で消してあり、質感手がかりは範囲の両端とも融合済み** ——
**両方塞がっていた。**

#### 何を作ったか（★ 3 軸は独立。既定は現行のまま＝対照を残す）

| 軸 | 候補 | 何を変えるか |
|---|---|---|
| **音色** | `t_current` / `t_low_long` / `t_wide_soft` / `t_high_air` | 粒長・中心周波数・帯域 |
| **密度の写し方** | `c_texture`(0.5) / `c_mixed`(0.25) / `c_level`(0.0) | `density_norm_exp` |
| **密度の幅** | `s_current`(100–400) / `s_wide`(100–1200) | 粒子率の上限（★ **下限 100 は動かさない**） |

⚠️★★★ **切替は processor 側で一次遅れ（6.0 s ＝ 0.027 Hz）**。
★ **段差で切り替えると、それ自体がオンセット**であり、spec §2 の禁止事項を UI 操作で作りに行くことになる
（引き継ぎ §5-5 が Step 3 で踏んだ形として名指ししている）。
★ 6.0 s は禁止帯（0.5–20 Hz / 15–70 Hz）から **1 桁以上下**。

#### ★★ 切替が no-op でないことの実測（Windows 11 / Chrome / 実クリック）

⚠️ **この検証を省けない理由**: 本 Step は既に
**「層 2 が完全に無音のまま静的検査 56 件が全部緑」**を一度出している（§3.2）。
★ **DOM が変わったことは、音が変わったことの証拠にならない。**

**(a) 音色の morph** —— `t_current` → `t_low_long` を実クリックし、
processor が返す**「いま効いている値」**（目標値ではない）を追跡:

| 0 s | 98.9 ms | 237.4 Hz | 0.0838 |

★ 40 ms / 440 Hz から漸近して到達。★★ **rms は 0.083–0.099 で安定＝レベルの段差が無い**

**(b) 密度手がかりが実際に開くか** —— `c_level`（`density_norm_exp` → 実効 **0.0**）で

（層 0 は密度に応答しない）。⚠️ 現行 `c_texture` では設計上ここが **0 dB** だった。
