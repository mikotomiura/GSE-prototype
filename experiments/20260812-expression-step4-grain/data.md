## ★★ 2026-08-13 追記 — 実際に受け取ったデータは **5 名 63 セッション**だった

⚠️ 上表は「平文 3 本」を前提に書かれていたが、研究者から渡された Phase1 のディレクトリは
**P010 / P011 / P012 / P013 / P014 の 5 名・合計 63 セッション**である。

★ **上表で hash 固定した 3 本は、この中に実在し、sha256 が完全に一致した**（2026-08-13 実測）。
→ ★ **本 Step の実測は引き続きこの 3 本の上にある**（記録との対応が切れていない）。

⚠️★★★ **この発見が `run.sh` の欠陥を露出させた**（S4-D13）——
`cmd_data` の `tag="${b%%_*}"` は最初の `_` までしか取らないため、
**同一参加者の 17 セッションがすべて `P010` になり互いを上書きしていた。**
★ **黙って「別の回の P010」を聴くことになる**ので、tag に hash を含めて一意にし、
**選択もファイル名ではなく sha256 で行う**形に直した
（⚠️ セッション名は擬似 ID ＋ 打鍵開始日時を含むので repo に書けない）。

★ **既定は `pinned`**（data.md が固定した 3 本だけ）。全 63 本を回すなら
`run.sh data <dir> all`。⚠️ **その場合は hash 固定の外に出るので notes に必ず書く。**
