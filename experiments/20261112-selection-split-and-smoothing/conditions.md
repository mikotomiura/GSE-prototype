前の試験は `experiments/20261106-tau-mode-candidate/`（以下 mode。run_id 20261106T205818-149・HP Z2）。本文の主の表（Table 2）は mode の summary の「最頻値を候補に入れない」値で、2 段（他人）と τ 他人の選びは tau-extend の `select_joint`・`select_other` のとおり。この試験は mode の本計算が repo の外に残した書き手ごとの値（pickle）を読み、A は当てはめを回さず、B は共通（w を除く）だけを当て直す。本人の当てはめは回さない。

## 問い

- A（R2・R3 M1・M6）: 選びは w を除く他の書き手の中央値で行うが、報告する中央値の残りの書き手は選びに使われている。固定の行では選びの量と報告の量が同じで、共通そのもの（差 0）が候補にあるので残りは 0 で下から切られる。選びと報告を別の書き手に分けると、残り（CoAuthor の 15-session パネルの 2 段で +4.1e-4〜+7.2e-4）はどれだけ動くか。
- B1（R1 M2）: 残りは最頻値 − 共通（ar3 で +7.4e-4）と同じ大きさで、共通の基の擬似度数が最適でない分ではないか。共通の基の擬似度数を他人で選び、その共通を比べの相手と τ = ∞ の候補に置くと、残りはどう変わるか。
- B2（R1 M3）: 本人の 1 次マルコフ連鎖（r1）の +0.5 は固定。これを他人で選ぶと、中心の所見（弱い構造 hmm3 は本人の連鎖に負ける・選ばれた当てはめは連鎖に勝つ）と残りは変わるか。

## 読まないこと

- mode と tau-extend の「読まないこと」をそのまま守る（EM の状態に名前を付けない・閾値の検定を置かない・セッションと課題は日ではない・CS1 を日本語や GSE の参加者へ広げない・ラベルを使わない）。
- 結果を段 1 の候補の採否や ADR-047 の主張の根拠にしない。使うのは論文 3 の本文の要旨・序論・4.3〜4.5・考察・結論・限界の文だけ。
- 書き手ごとの値・pickle・npz を人が開かない。repo に置くのは集計値だけ。外部の LLM に書き手ごとの値を送らない。
- 二分の値（半分のパネルの中央値）を、全員のパネルの中央値の推定として読まない。A で読むのは、同じ半分の上での「同じ半分で選んだ値」と「別の半分で選んだ値」の違い（選びの楽観）と、別の半分で選んだ値の符号と大きさだけ。
- B1 は共通の基の平滑だけを他人で選ぶ。本人の当てはめの事前分布（基の擬似度数 + τ S̄）は mode のまま当て直さない。B1 の結果を「本人の当てはめも含めて平滑を選び直した結果」とは読まない。

## D3 A: 書き手の二分

- パネルの書き手 n 人を、乱数 [SEED + 20, データの番号（CoAuthor 0・CS1 1）, パネルの番号（P15 0・P30 1・C5 0）] の並べ替えで、前の ⌊n/2⌋ 人（半分 X）と残りの ⌈n/2⌉ 人（半分 Y）に分ける。1,000 通り。分け方は同じパネルの k の間で共有する。
- 各分け方で 2 つの向き（X で選んで Y で報告・Y で選んで X で報告）。合わせて 2,000 組（選ぶ半分 S・報告する半分 R）。
- 各組で:
  - 正直な値 h: S の全員の中央値でいちばん良い候補 c_S を選び（S の中で w を除かない。R の書き手は選びに入らない）、R の書き手の差（行の報告の量）の中央値を c_S で出す。
  - 同じ半分の値 i: R の全員の中央値で候補 c_R を選び、R の書き手の差の中央値を c_R で出す（選びと報告が同じ書き手。楽観がそのまま乗る）。
  - 楽観 o = i − h（組ごと）。
- 候補・同点の規則・選びの量は D2 の行のとおり（2 段は 本人 − r1、τ 他人は 本人 − 共通）。報告の量は 2 段では 本人 − 共通（主）と 本人 − r1、τ 他人では 本人 − 共通。
- セル（パネル × k × 行）ごとに出すもの: h・i・o の 2,000 組の中央値・平均・2.5% と 97.5% の分位、h > 0 の組の割合、c_S の (構造, τ) の領域の数（∞・10^6・格子の中・0）、今の値 L（mode の summary の同じ行の 本人 − 共通 の中央値・w を除く選び）。
- 半分の人数は P15 で 8 と 9、P30 で 4 と 5、C5 で 11 と 12。P30 は値だけを出し、読みに使わない（半分が 4〜5 人）。人数の伏せ（N_MIN = 6）は当てない（書き手ごとの値は出さず、組の要約だけを出す）。

## D6 読みの形（結果より前に決める・閾値の検定を置かない）

見る所はどれも CoAuthor P15 の k = 1〜15（7 つの k）。形はセルごとに決め、7 つのうち半分を超える k（4 つ以上）の形をパネルの形とする。どれも半分を超えなければ「混ざる」と書き、k ごとに値を並べる。

### A（主: 2 段の 本人 − 共通。副: τ 他人の ar3）
- k の形: L = 今の値、Hm = 正直な値 h の 2,000 組の中央値。
  - 「残る」: Hm > 0 かつ Hm ≥ L / 2。
  - 「縮む」: 0 < Hm < L / 2。
  - 「消える」: Hm ≤ 0。
- 本文への持ち込み:
  - 残る: 残りの文を「選びと報告を別の書き手に分けても（書き手の二分・2,000 組）、残りは Hm（k の範囲）で、同じ書き手で選んだ値との差（楽観）は o の中央値（範囲）」に替え、要旨の「残り」の数は変えない。
  - 縮む: 残りの数を「選びと報告を分けると Hm（範囲）」に替え、今の値の半分以上は選びの楽観に当たると書く。要旨の数を替える。
  - 消える: 「選びと報告を分けると残りは 0 以下で、今の残りは選びの楽観と分けられない」と書き、要旨と結論の残りの文を「選びと報告を分けると残らない」に替える。
- 副（ar3 の τ 他人）は同じ形で読み、主と違えば両方を並べる。C5 は 2 段で全員に τ = ∞ が選ばれたので値だけを書く（h が作りの上で 0 の組の割合も書く）。

### B1（主: 2 段の 本人 − 共通(α*)）

  - 「1 倍」: 2 段で選ばれた構造について α* = 1 の書き手が半分を超える。
  - 「消える」: R1 ≤ 0。
  - 「縮む」: 0 < R1 < R0 / 2。
  - 「残る」: R1 ≥ R0 / 2。

  - 1 倍: 限界の「基の平滑は他人で選んでいない」を「CoAuthor では他人で選んでもいまの強さ（1 倍）が選ばれた」に替える。最頻値 − 共通の解釈（平滑の差）はそのまま「診断」として残す。

| 門 | 通る条件 |
|---|---|
| P-HASH | D1 の SHA-256 がすべて一致（読み込みの時点で止める） |
| P-HALF | 分け方ごとに、X と Y が交わらず、和がパネル全体、人数が ⌊n/2⌋ と ⌈n/2⌉。同じ乱数で同じ分け方 |

| P-SCALE | α = 1 の事前分布が `hmm2.base_prior` と全キーで一致し、α 倍は全キーの全セルが α 倍 |
