## 問い

論文 3 は、本人ごとの差を予測の点数（本人の表 − 共有の表）で探した。CoAuthor k = 5 の検出率（論文 3 の規則・10 種）は、第 1 の帰無（sens の生成）で 1e-3 0.0・3e-3 0.2・1e-2 0.9・3e-2 1.0、第 2 の帰無（nfs の生成）で 1e-3〜1e-2 0・3e-2 0.2 だった（補足 S10）。

同じ記録の分け方（A = 学習の k 単位、B = 評価の H 単位）と同じ記録の量で、1 状態の遷移表のパラメータの空間で「本人の A が、他の書き手の A より本人の B に近いか」を数える目は、植えた差をどこまで拾えるか。

## 読まないこと

- 結果は、この真の生成（AR(1)-HMM・記号の遷移の行の混ぜ・sens D1。第 2 の帰無は nfs の母数）と、CoAuthor の 15-session パネルと CS1 の five-assignment パネルに合わせた記録の量での値である。目一般の検出の限界とは書かない。
- 合成の検出力を、実データの書き手の個人差の大きさの推定として読まない。
- 差は記号の遷移の行（C）だけに植えてある。状態の持続（A）や最初の記号（H）の差を拾えるかは測っていない。状態を周辺化した 1 状態の遷移表にも C の差は写るので、この生成は 1 状態の表で数える目に有利な方向と見込む（どれだけ写るかは D9 の g1 で測る）。論文 3 との並べはそれを含めて読む。
- 異質性の形は、全員に同じ λ（用量）か、0 か 3e-2 か（分布）の 2 つだけ。書き手ごとに連続に散らした形は試さない。
- 用量・分布・構造の筋の書き手は、全単位が同じ母数から作られ、単位の間の本人の中の揺れが無い。その検出力は揺れが 0 のときの値である。揺れ・漂い・量の筋（D4）は、それぞれ根拠なしの 1 つの作りでの値で（揺れは半分を引き直す・漂いの ρ は全員に共通の 0.5 と 0.9・量の尺度は 0.5〜2 倍）、実データの揺れ・漂い・量の差の大きさには合わせていない。
- 目は「本人の A が本人の B に近い」ことを数える。隣り合う A と B では、安定した差と、時間が近いと似ること（漂い）を区別しない。分けるのは間を空けたセル（D1）で、漂いの筋で間のセルの「安定した差としての偽陽性」を測り、事前の基準（D6）を超えたセルは分けないセルとして読む。間を空けられないセル（CoAuthor k = 15・CS1 k = 5）は「安定と漂いを分けない」セルとしてだけ読む。
- T は集団の量で、「平均で本人の A が本人の B に近い」ことだけを言う。T が正でも、誰に本人の表を使うかは決めない。
- 書き手ごとの AUC_v は、他の書き手に差があると本人に差がなくても 0.5 より上がる（17 人中 5 人に植えたとき、植えていない人でも、植えた 5 人が完全に遠ければ約 0.66 まで上がりうる）。AUC_v は本人の差の印ではない。書き手の水準の量は、本人だけで決まる予測の得（D6）で見る。
- 第 2 の帰無は、論文 3 の HMM の平滑の効き方を再現するために作られ、その強さは実データの約 2.4 倍に行き過ぎた（nfs notes の所見 1・4）。この目は HMM の平滑を使わないので、第 2 の帰無は「実データの共有の形から作った 1 つの生成」として使い、実データの再現とは読まない。
- 結果は m = 26 に条件づく。CoAuthor k = 1 では 1 行あたりの遷移がおよそ 25 で、縮めは約半分になる。CS1 ではほぼ効かない。形の間の比べは m に依る。
- 1 状態の表は真の生成（3 状態・5 状態）とは違う構造である。目は構造を当てない。状態に名前を付けない。
- 選んだ案を、選びの規則で選んだ以上に「より拾う目」とは書かない。
- 門（D5・D6）を通っても、実データの入れ替えの帰無が正しいことの証拠にはしない。門が言うのは「この生成のこの差なしで、偽陽性の膨らみを検出しなかった」ことまでである。1 つの門が膨らみを落とす確率は、D5 の門（68/1000）で真の率 7% が約 0.57・8% が約 0.91・10% がほぼ 1、D6 の門（73/1000）で 7% が約 0.33・8% が約 0.77・10% が約 0.998 である。門は要因を 1 つずつ入れた差なしと、量・長さの不均一・ρ = 0 を重ねた差なしでの値で、他の重ね方は確かめていない。
- 間を空けたセルが基準（D6）を通っても、分けられたと言えるのは、この作りの漂い（ρ ≤ 0.9・単位ごとのずれを用量の 3e-2 に揃えた大きさ・1 単位を 1 歩とする均一な間隔）のもとでだけである。より遅い漂い（振幅を揃えた作りでは λ_ρ ≤ 1 なので ρ は約 0.93 までしか作れない）、より大きな漂い、実データのような不均一な時間の間隔とは分けていない。基準は膨らみを見逃しうる（D6 の「間を空けたセルの基準」の検出力）。漂いの振幅を揃えたのは確率の空間の偏差で、対数の空間の差は ρ ごとに違いうる（D9 の単位ごとのずれの大きさ〔KL〕を添えて読む）。
- 評価はパネルの中の閉じた集合で、他人はパネルの 16〜22 人だけである。登録外の他人（パネル外の書き手）は評価に使っていない。
- 第 2 の帰無は生成の母数を公開しないので、第三者はその値を再現できない（確かめられるのはハッシュだけ）。
- 結果を段 1 の候補の採否や ADR-047 の主張の根拠にしない。

## D2 目の候補（3 案・判断 3）

近さ s(w → v) は、書き手 v の B に対する書き手 w の A の近さで、大きいほど近い。

| 案 | s(w → v) |
|---|---|
| E1 交差尤度 | v の B のすべての遷移の組の、p_w^A での対数尤度の和 ÷ 組の数 |
| E2 ずれの相関 | δ_w^A = log p_w^A − log S と δ_v^B = log p_v^B − log S の、重み u[j, c] = π_j · S[j, c] の重み付きピアソン相関 |
| E3 行ごとの JS | − Σ_j π_j · JS(p_w^A[j, ·], p_v^B[j, ·])（JS は自然対数） |

- 3 案の理由: E1 は尤度の形（B を生の列のまま評価する）、E2 は共有からのずれの向きだけを見る形、E3 は行ごとの分布の距離の形で、近さの取り方の違う 3 つを並べた。距離の学習・分類器は、学習の自由度が増え合成への合わせ込みになるので比べない。学習の要らない距離のうち打鍵の時間の特徴を使うもの（キーの組の時間の距離など）は、この研究の対象が時間の特徴を持たない 26 記号の遷移の表なので採らず、表の上の距離は E3 を代表とする。遷移行列の均一性の検定（書き手 × 遷移の数の尤度比・カイ二乗）は、単位の間のずれ（過分散）で帰無が保たれない見込みなので採らない。異質性の大きさを推定する系統（分散成分・階層の縮め・縮めの濃度の推定）は、論文 3 の予測の点数と同じ「有無」の問いに揃えて検出力を比べるのが目的なので採らない（縮めの強さの推定は、目で差の場所が見えた後の段）。比べから外した系統があることは位置づけの限界である。
- AUC_v = #{w ≠ v : s(w → v) < s(v → v)} / (P − 1)。同点（差の絶対値 1e-12 以下）は 0.5 と数える。同点の判定を先に行う。P はパネルの人数（CoAuthor 17・CS1 23）。
- パネルの量 T = AUC_v の、パネルの書き手の平均（判断 10）。計算と比べは整数で行う: W = Σ_v (2 · #{勝ち} + #{同点})（T = W / (2 P (P − 1))）。浮動小数の加算の順で T の同点が崩れないようにする。
- 未定義の値: E2 で δ の重み付き分散が 0 のとき s = 0 とする。s が有限でない値は E1・E3 では作りの上で出ない（p > 0）。出たら例外として扱い、D8 のとおり本計算全体を止める。

## D3 帰無と複製の判定

- 帰無: パネルの B の名札を無作為に並べ替える（置換 σ）。T_σ = (1/P) Σ_v AUC_v^σ、AUC_v^σ = #{w ≠ σ(v) : s(w → v) < s(σ(v) → v)} / (P − 1)。s の行列は並べ替えの前に 1 回だけ作る（S を全員で 1 つにしたので、名札の入れ替えで作りは変わらない）。
- 置換の数は 2,000。σ はそれぞれ一様な置換を独立に引く（同じ σ が 2 回引かれることも、恒等の置換が引かれることもある。その分 p は保守的になる）。同じ複製・同じセルでは 3 案に同じ σ の列を使う。p = (1 + #{W_σ ≥ W}) / 2,001（整数の比べ）。
- p ≤ 0.05 で、その複製は「拾えた」。
- 乱数（入れ替え）: [SEED, 帰無の番号, 筋の番号, 形の番号, k, g, 種]。帰無の番号は第 1 = 1・第 2 = 2。筋の番号は用量 0・分布 1・構造 2・揺れ 3・漂い 4・量 5・重ね 6。形の番号は CoAuthor 0・CS1 1。g は間（空けないセルは 0）。同じ種の段どうし・ρ どうしは、生成の D と入れ替えの σ を共有する（共通乱数・意図した作り）。
- 段の番号（D9 の乱数）: 差なし 0・1e-3 1・3e-3 2・1e-2 3・3e-2 4・λ = 1 5。漂いの筋は ρ = 0 が 0・0.5 が 1・0.9 が 2。
- T_σ は 1 つの関数で計算し、本計算の引きの経路と P-HAND の全列挙の経路が同じ関数を呼ぶ。

- 量: 本人の表の予測の得 G_v = v の B での 1 記号あたりの対数尤度の、p_v^A − S（本人の A と B と共有の表だけで決まる。E1 の近さとも E1 の門とも独立）。

## D8 回す順・時間・失敗・止め・再開

- 回す順: V1 と変異 → コミット → 選びの組 → D5 → 選んだ案と D5 の量をコミット → 報告の組 → D6。
- 時間: 選びの組と報告の組のそれぞれの前に、各帰無・各形の最初の 10 複製で時間を測り、全体を見積もる。1 台で 24 時間を超える見積もりなら、回さずに止めて研究者に問う。変えてよいのは計算の割り振り（機械の台数・並列）だけで、複製の数・置換の数・筋・セルは変えない（閾値の根拠が崩れるため）。並列にするときは種の単位で分け、各複製の乱数の鍵は変えない。それで収まらなければ D8 の「定義を変えた版」として扱う。
- 失敗: 複製の中で例外が出たら、その時点で本計算全体を止める（黙って落とさない）。検出力と偽陽性の分母は、計画したすべての複製。

- 赤の扱い（判断 28）: 決定的な検査（P-HASH・P-XMACH・P-HAND の手計算と全列挙の部分）の赤は実装の誤りとして直してよい。確率的な検査（P-HAND の引きの経路の照合・P-NULL・P-UNIF・P-STAT・P-POS・選んだ案のセルの門）の赤は「原因未確定」として、コード・生成・入れ替えを調べる。実装の誤りが見つかれば直す。見つからなければ新しい種で回し直さず、「この目はこの版では使えなかった」と notes と報告に書く。
- 再開: 直してよいのは実装の誤りだけで、D1〜D6 の定義は変えない。直した版は新しい code_hash で V1 と変異をはじめから通してコミットし、止めた組を同じ種で最初から回し直す。報告の組を見た後に見つけた誤りが D5 で使うコードに触れるときは、選びの組も回し直す。選ばれる案が変わったら、報告の組はすでに見ているので、その版は探索として扱う（変わらなければそのまま進む）。止めた種・例外・赤の記録と直した理由を notes とコミットに残す。
- 定義を変えた版: 新しい版の条件として凍結し直し、種 10000 以上で始める。その版は探索として扱い、結果は確認の主張に使わない。失敗した版もすべて報告する。今の報告の組は使わない。

## D9 1 状態の表に出る植えた差の大きさ（記述だけ・判断 2）

- 較正と同じ形の書き手 40 人（種 7000〜7039・乱数 [SEED + 91, 帰無の番号, 筋の番号, 段の番号, 種]）で、m_w と m0 から長さ 20,000 の系列を作り、それぞれの 1 状態の表（D1 の数え方・0.5 を足す）を当てる。m_w から作った別の 20,000 記号で、2 つの表の 1 記号あたりの対数尤度の差を測り、その中央値を g1 とする。植えた g（AR-HMM での差）と並べる。
- 用量の筋（第 1 と第 2 の帰無の両方・第 2 は HP Z2）・構造の筋（K = 5）・揺れの筋・漂いの筋（ρ = 0・0.5・0.9。当てる側と評価の側は揺れの筋と同じく単位を並べた系列で、E は定常から）で測る。m_w は `writer_model(m0, draw_D, λ)`（揺れ・漂いでは単位ごとの母数）で作り、λ は D4 の値。
- 揺れの筋: 当てる側も評価の側も、長さ 650 の単位を 31 個並べた系列（最後の単位は 500 記号で、合わせて 20,000）にし、単位ごとに D_{w,u} を新しく引く（D_w は書き手ごとに 1 つ）。当てる側と評価の側の単位は独立に引く。系列は単位の境目で切り、境目をまたぐ組は数えない。漂いの筋も同じ形で、当てる側と評価の側は別々に空回しから始める。こうして測る g1 は「有限の記録で当てた 1 状態の表が、同じ書き手の別の記録に写す差」で、母数の変動の総量ではない。漂いの筋は安定した差が 0 なので、g1 はどの ρ でもほぼ 0（推定の誤差で負に寄る）になる見込みで、ρ の比べには使わない。
- 単位ごとのずれの大きさ（判断 35・漂い・揺れ・用量の筋）: 種 7000〜7039 の書き手の、記録の 20 単位それぞれの真の母数と m0 から長さ 20,000 の系列を作って 1 状態の表を当て（0.5 を足す）、π で重みを付けた行ごとの KL（単位の表 ∥ m0 の表）を求め、書き手 × 単位の中央値を出す。ρ ごとと、用量の各段で並べる。
