## 逸脱（結果を見た後・/cross-review の指摘で直して回し直した）

- 逸脱 1: 負の対照を、1 回の並べ替えを日の復元抽出した区間（C5）から、並べ替え 20 回の ΔAUC の分布（同じ折り・点推定）に変えた。1 回の並べ替えでは帰無の分布にならないため。T と B で種を分けた（seed + 7・seed + 11）。C8 の採否の規則の「並べ替えの ΔB の区間が 0 を含む」は、この 20 回の 2.5〜97.5% 点の範囲が 0 を含むと読む。
- 逸脱 2: ファイル名の時刻の正規表現に、同じ秒の衝突を避ける接尾辞（`_2` など）を許した。今の記録では当たる本は無かった（止まらずに通った）。
- 逸脱 3: 日の復元抽出の成功が 200 回のうち 150 回に届かなければ区間を出さない下限を足し、公開版に対照の数・失敗の回数・区間の状態を足した（C7 は対照の数を公開すると書いていた）。今回の失敗は 0 回。
- 逸脱 4: 平文との対応を、観測 0 やフォーカスの行の無い本も含めてすべての本で照らし、T6 の「直前の観測区間」をすべての本の観測区間から取るようにした。観測区間の重なりを数えて公開した（3 人とも 0）。
- 時刻の基準（C2）の確かめ: 記録の始まり（起動・日ごとの切り替えとも）では、ファイル名の時刻（`chrono_like_filename`・UTC）と `meta` の `session_start`（匿名化の相対の基点・`anonymize.rs`）が、どちらもその時点の現在時刻から作られる（`logger.rs` の Rotate の処理・`lib.rs` の `o1_rotate`）。相対の時刻の 0 はファイル名の時刻とみなせる。
- 分割の単位の注: 折りと復元抽出の単位は 20261116 の R5 と同じく名前の日付（`date`）で、T7 の日（現地 4 時の境）とは別の単位である。R5 との互換のためにそのままにした。
- 自己検査を足した: T6 の本またぎ・T7 の複数区間の和と 4 時の境・240 分の上限・接尾辞・区間の重なり・B の窓の端・ちょうど 50 ms・W1 − W0 と欠けの差。
