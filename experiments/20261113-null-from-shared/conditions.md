## 問い

本文 4.4 は、実データの 15-session パネルが事前の検出の規則（陰性対照 5 種の中央値の最大 U を超え、かつ 80% 以上が本人の側）を満たす（k = 5 で +5.53e-4・1.00、k = 15 で +4.14e-4・0.94。D の U は 1.38e-5・8.44e-5）のに、合成の帰無が実データの共通の平滑の効き方を再現しない（実データでは最頻値が共通に勝ち〔b = 最頻値 − 共通が ar3 で +7.4e-4〕、sens の合成ではいつも負ける〔−1.3e-5〜−3.7e-4〕）ので「検出」と読まない。

- 実データの共通そのものを真の生成にし、平滑の効き方（b > 0）を再現する帰無の下で、同じ規則の U・誤警報率・検出率・L80 を出す。
- その帰無の下で、実データの残りは規則を満たすか。

## 読まないこと

- 合成の結果を実データの書き手の個人差の大きさの推定として読まない。言えるのは「この真の生成（実データの全員の共通 ar3 を 1 つの倍率で当てた母数・記号の遷移の行の混ぜ）と、この形の記録の量で、この手順と規則がどう振る舞うか」だけ。
- 実データが規則を満たしても、残りの大きさ（+4e-4〜+6e-4）を本人の差の大きさとは書かない。回収の比（D で 3〜40%）が小さいので、植えた差と返った量を同じ物差しで並べない（判断 11・22 と同じ）。
- 帰無の書き手は全員が同じ m0 から作る。書き手の異質さ（記号の使い方の違い）は植える差だけで、帰無には入れない。帰無に異質さを入れた作りは試さない。
- この計算は round 2 の結果を見た後に足した（post hoc）。本文にそう書く。
- EM の状態に名前を付けない。閾値の検定を置かない。結果を段 1 の候補の採否や ADR-047 の主張の根拠にしない。CoAuthor のセッションは日ではない。

- Mac の selftest は偽の m0（sens の `make_m0(3, SEED)` を疎にしたもの）で回す。本物の m0 での合成は HP Z2 だけ。

## D2 門（本計算の前・α を 1 つ選ぶ）

- 各 α の m0（K = 3）から、差 0 の合成（sens の `build`・形 CoAuthor・筋 dose・λ = 0）を門の種 100・101・102 で作る。全員の共通は ar3 だけを当てる（`run_synth.fit_full`・乱数 [SEED + 11, 複製の番号, 3]・複製の番号は 200 + 3 × α の位置 + 種の位置）。w を除く共通（ar3）をパネル 17 人それぞれに当てる（`run_synth.fit_excl`）。
- 書き手 w ごとに、評価の単位（`DT.split(n, 1, H)` の test）で b_w = 最頻値の評価 − 共通の評価（1 記号あたり・全記号）。最頻値は `HM.mode_of("ar", S̄_w)`（S̄_w は w を除く共通の期待度数）、評価は `decomp.mode_eval`（確率 0 の後は −∞）。最頻値が −∞ の書き手は b_w = −∞ として中央値に入れる。
- 種ごとの b の中央値 b_s（17 人）と、α の b̄ = 3 種の b_s の中央値。
- 選び: 3 種とも b_s > 0 の α のうち、|log(b̄ / 7.4e-4)| が最小のもの（7.4e-4 は mode の notes 89 行の実データの CoAuthor P15・ar3・主の b）。同じ値なら大きい α。どの α も 3 種とも正にならなければ、本計算に入らずに止めて研究者に聞く（本文は今のまま）。
- 出すもの（`results/gate.json`）: α ごとに 3 種の b_s・b̄・−∞ の人数・b_w > 0 の割合・通ったか・選ばれた α。帰無の主の量（本人 − 共通）は門では計算しない。

## D4 規則（D と同じ・結果より前に決める）

- k = 5・15 ごとに、D の `ten.rule` をそのまま当てる: U' = 陰性対照の種 0〜4 の中央値の最大。検出 = 中央値 > U' かつ良い側の割合 ≥ 0.8。FA' = 陰性対照の種 5〜14 の検出の割合。DR' = 段の種 0〜9 の検出の割合。L80' = DR' ≥ 0.8 の段のうち、それより大きい段もすべて 0.8 以上の最小の段。
- 実データへの当て: 実データの残り（mode の summary.json の `datasets.coauthor.em.P15.<k>.two_stage.other.two_stage_other["all/self_minus_pool_same"]` の `median` と `better_share`。k = 5 で 5.531e-4・1.00、k = 15 で 4.136e-4・0.941）に同じ検出の式を当てる。
- 規則が使える k: FA' ≤ 0.2（10 種中 2 以下）。
- 並べるだけ（判定に使わない）: 陰性対照 15 種の中央値の最小・中央値・最大、実データの残りを超えた陰性対照の数、回収の比、D の同じ番号の複製との主の量の差の中央値。

## D5 読みの形と本文への持ち込み（結果より前に決める）

- G0（門で止まる）: 本文は今のまま。研究者に聞く。
- R1（k = 5 と 15 の両方で規則が使え、両方で実データが検出）: 要旨・序論・結論の「示しも否定もしない（neither shows nor rules out）」を、「平滑の効き方を再現する共通だけの帰無の下でも、事前に決めた規則は検出を返した。残りは小さな本人の差と合う（大きさは推定しない）」の趣旨に替える。その帰無の L80' を添える。生成が 1 つの作りであること・post hoc であることを添える。4.4 の「帰無が再現しないので読まない」を、新しい帰無の結果に替え、D の帰無の結果は「平滑を再現しない帰無」として並べる。限界の「平滑の効き方を再現しない帰無で較正した」を、「再現する帰無は 1 つの作りで、書き手の異質さを帰無に入れていない」に替える。
- R2（両方で規則が使え、両方で実データが検出されない）: 「平滑の効き方を再現する共通だけの帰無が、実データの残りを超える（または同じ桁の）残りを出す。残りは本人の差を示さない」に替える。「否定もしない」の側は、新しい帰無の L80' で書く（L80' 未満の本人の差は確実には検出されない）。
- R3（片方の k だけ検出・または規則が使えない k がある）: k ごとに値を書き、「検出」とは言わない。要旨の「示しも否定もしない」は残し、理由を「平滑を再現する帰無の下でも k によって規則の答えが分かれる」（または「誤警報が多い」）に替える。
- どの場合も、要旨の感度の文（L80）は新しい帰無の L80' を主にし、D の値は本文 3.5・4.4 と補足 S15 に残す。推奨 (3)「平滑の効き方を再現する帰無で」は残す。
- 結果を見た後に気づいたことは、この形の外として notes に分けて書く。
