## C0 罰の表し方と格子

- モデル: p̂ = σ(b + z·β)。z は特徴を学習の側（CV では各折の学習の側）の平均と SD で標準化したもの（SD が 0 なら 1）。目的は対数尤度 − λ/2‖β‖²。切片 b は罰しない。寄せる先は 0（判断 1）。
- λ = 1/τ²。τ は標準化した係数の事前の SD に当たる。格子（強い罰 → 弱い罰の順）: τ ∈ {0（切片だけ ＝ B0-self）, 0.125, 0.25, 0.5, 1, 2, 4, ∞（罰なし・λ = 0）}。
- 当てはめは `experiments/20261104-coauthor-ml-improve/scripts/logit.py` の `fit_logistic` を写したもの（Newton 法・許容 1e-8・最大 100 回・特徴 0 の擬似観測 y = 1 と y = 0 を重み 0.5 ずつ足す）。擬似観測は 1 類だけの学習でも切片を有限にするため。罰なしで分離した当てはめは収束しないことがあり、その数を記録し、予測はそのまま使う（対数損失は p を [1e-6, 1 − 1e-6] に切って数える）。

## C1 生成器（1 人・1 反復）

- 日 d = 0, 1, 2, … の件数 m_d は {1, 2, 3} から一様。日の揺れ u_d ~ N(0, σ_d²)。
- 主の特徴: 件ごとに z_true ~ N(0, Σ)（Σ は対角 1・非対角 0.3）、特徴 x = z_true。
- p = σ(a + x·β_d + u_d)。信号あり β = (0.8, −0.5, 0.3, 0, 0)、信号なし β = 0。主は β_d = β（動かない）。
- 学習の側: 日の順に並べた件の先頭 n 件（最後の日は途中で切る）。学習の日数 D は n 件目のある日の番号 + 1。
- 評価の側: 日 D, D + 1, … の新しい日（新しい u_d・同じ規則の件数）から 5000 件。
- 切片 a: 切片のセル（陽性の率 r・σ_d・信号の有無・特徴の形の 4 つ組・n によらない・`sim.acells()` の並びの番号）ごとに、乱数 [SEED, 99, 切片のセルの番号] で 2 × 10^5 件を引き（u_d を含む・β_d は β）、陽性の率の期待値 mean(p) が r になる a を 2 分法（許容 1e-6）で求めて凍結する。
- 乱数: 反復ごとに `np.random.SeedSequence([SEED, セルの番号, 反復の番号])`。決め方の間で同じデータを共有する。

### 主の格子（72 セル・各 400 反復）

n ∈ {10, 20, 30, 50, 80, 120} × r ∈ {0.10, 0.25, 0.40} × σ_d ∈ {0, 0.5} × 信号 ∈ {あり, なし}。

### 感度（各 400 反復・主の規則の入力にしない）

いずれも信号あり・r = 0.25・σ_d = 0.5・n は主と同じ 6 つ。
- s1 係数が動く: β_d = β · max(0.5, 1 − 0.5 · d / 60)。評価の側の件はすべて β_D（学習の最後の次の日の値）で作る（u_d は日ごとに新しく引く）。切片 a は β_d = β で求めた主の値を使う。
- s2 特徴の形: z_true は主と同じで、x_1 = z_1、x_2 = z_2、x_3 = exp(0.8 z_3)、x_4 = exp(0.8 z_4)、x_5 = 1[z_5 > 1]。真のモデルの線形の部分は、x_3〜x_5 を母集団の平均と SD（対数正規と二値の理論値）で標準化した量に β を掛ける。学習のモデルは x を学習の側で標準化する（真の標準化とはずれる）。

### 整合性の陽性対照（cons・100 反復）

信号あり・r = 0.25・σ_d = 0・n = 2000。

## C2 決め方

- (i) 固定: 格子の各 τ で学習の側の全件に当てはめる。
- (ii-a) 前向きの CV（主の CV）: 学習の日を `np.array_split(range(D), B)` で日の順の B = min(5, D) 個の連続するブロックに分ける。k = 1, …, B − 1 で、ブロック 0…k − 1 の件で学び（標準化もその件で）、ブロック k の件で検証する。F[k, τ] ＝ 検証の対数損失の和。選ぶ τ は Σ_k F[k, τ] が最小のもの。差が 1e-9 以内の同点は強い罰の側（格子の前の方）。D < 2 なら CV は立たず、τ = 0（切片だけ）に落とし、数を記録する。
- (ii-b) 1-SE: (ii-a) の選び τ* に対し、d_k(τ) = F[k, τ] − F[k, τ*]。mean_k d_k(τ) ≤ sd_k(d_k(τ)) / √(B − 1)（sd は ddof = 1）を満たす τ のうち最も強い罰を選ぶ（τ* 自身は満たす）。B − 1 < 2 なら (ii-a) と同じ。1-SE は CV の選びの雑音に対する既知の手当てとして並べる（出典は notes で citation-ssot により登録する）。
- (ii-c) ブロックの抜き 1 つ（時間順でない CV・記述だけ）: 同じ B 個のブロックで、各ブロックを検証にし残りで学ぶ。選びは (ii-a) と同じ規則。案の規則には入れず、時間順にした意味を s1 で見るためだけに出す。
- (iii) 組み合わせ: 学習の側の量 q が下限 L 未満なら固定の τ_f、以上なら CV（(ii-a) か (ii-b) のうち C4 で選んだ方）。q は 2 通り: 総件数 n、少ない方の類の件数 min(陽性, 陰性)。追加の当てはめは無く、反復ごとに (i) と (ii) の結果から作る。

## C3 評価の量（評価の側の 5000 件）

- 対数損失の平均（主）・Brier・C（AUC・同点は平均の順位）・較正の切片（傾きを 1 に固定し logit(p̂) をオフセットにした切片だけの当てはめ・calibration-in-the-large。最尤の条件が切片に単調なので 2 分法で解く。判断 8: 初めの版の Newton 法は予測が率から離れると発散した）・較正の傾き（y を logit(p̂) と切片で当てはめた傾き。Newton 法が収束しなければ nan にし数を記録する）。p̂ の logit の SD が 1e-8 未満なら傾きと C は「立たない」。神託（真の p）の対数損失も数える。
- 後悔: 反復ごとに、決め方の対数損失 − 格子の固定の τ の中の最小の対数損失（後知恵の最良）。害: 決め方の対数損失 − τ = 0（B0-self）の対数損失。
- 選ばれた τ の分布（格子の値ごとの割合）・後知恵の最良の τ の分布。
- 診断: 学習の側が 1 類だけの反復・収束しなかった当てはめ（τ と、全件・前向きの折・ブロックの抜き 1 つの折・較正の傾きの当てはめで分けて）・CV が立たなかった反復の数。

## C4 案の値を出す規則（結果を見る前に凍結）

主の格子の 72 セルだけを使う。セルごとの量は 400 反復の平均。

1. **τ_f**: n ∈ {10, 20, 30} の 36 セルで、固定の τ ごとに平均の後悔の最大（36 セルの上の最大）を求め、それが最小の τ。同点（差 1e-6 以内）は強い罰。
2. **CV の版**: (ii-a) と (ii-b) のうち、72 セルの上の平均の後悔の最大が小さい方。同点は (ii-b)。
3. **下限 L**: q と候補 L の組ごとに組み合わせ (iii) の反復ごとの対数損失を作り、セルごとの平均の後悔から「そのセルでの τ_f の固定と CV の版のうち良い方の平均の後悔」を引いた**超過**を求める。72 セルの上の超過の最大が最小の L を採る。同点は大きい L（固定に寄る側）。候補: q = n なら L ∈ {0, 10, 20, 30, 50, 80, 120, ∞}、q = min(陽性, 陰性) なら L ∈ {0, 1, 2, 3, 5, 8, 10, 15, 20, 30, ∞}。L = 0 は常に CV、L = ∞ は常に固定。
4. 併記: 案の τ_f・CV の版・L のもとでのセルごとの較正の傾きの分布（中央値と四分位）・害の平均と区間・選ばれた τ の分布。信号なしのセルの較正の傾きは立たない反復が多いので、立った数を併記する。
5. 最悪のセルが陽性 1 件前後のセル（n = 10・r = 0.10）に引きずられる場合に備え、そのセルを除いた版も同じ規則で出す（主は除かない版）。
