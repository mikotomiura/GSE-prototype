# G1 収集開始 — 人手確認の記録票

> ★ 作成: 2026-09-20。`.steering/20260920-g1-collection-readiness-gate/` 判断 3。

## ⚠️ この票は何のためにあるか

事前登録の収集開始の前提条件 1〜7 のうち、**3 つの部分は機械検査に載らない**。
いずれも **外部サービスの状態**（配布済みフォーム・Drive・CI の両 OS ジョブ）で、
手元のリポジトリを読んでも分からないからである。

⚠️★★★ **ゲートがこの票について見ているのは「人が確かめたと書いたこと」だけである。**
★ Drive 上の実物も、配布済みフォームの中身も、CI の実際の run も、**ゲートは見ていない。**
→ **埋めた人が中身に責任を持つ。**（★ 埋めれば緑になるが、それは「確認したと申告した」の意味しかない）

⚠️ **前提条件そのものが未達のまま、この票だけを埋めてはならない。**
