## 規則による推奨

M（M1・M2・M4）と O が成り立ち、V は成り立たない。§J の規則では「単独にする」。

## 言えること

- 同じ公開データで、停滞の窓・θ・条件 A・区間の切り方を妥当な範囲で振ると、データの間の率の順位は 9 割の通りで変わり、2 つのデータの比は向きごと入れ替わる。
- 同じ人の中で停滞の数が数え上げ（ポアソン）を超えるかの結論は、区間の切り方と θ しだいで逆になる。
- 率がほぼ同じ 2 つの定義が、ほとんど別の時刻を停滞と呼ぶことがある。率の一致は、ラベルの一致の代わりにならない。
- 推定の水準の差（CS1 と KLiCKe の `p_stuck`）は、押下の無い長い時間を除いても大半が残る。
- 停滞の長さの揺れは、大半が同じ書き手の中の停滞ごとの揺れで、書き手・課題・日・まとまりの違いは小さい（CS1 では 9 割前後が停滞ごと。3 つのデータ・9 通りのすべてで同じ向き）。

## 言えないこと

- どの定義が正しいか（本人の申告が無い）。停滞の始まりは詰まりの判定ではない（ADR-030 の 9b）。
- 件数の揺れが書き手・課題・日・まとまりのどこにあるか（K5 で回復しなかった）。
- データの間の違いの原因（作業の種類・記録の仕方・単位の長さが同時に違う）。
- M1 の 89% は、振った範囲（`conditions.md` の C3）に対する割合で、定義の母集団からの標本ではない。

## ずれ（条件からの）

1. 件数のモデルの露出を offset ではなく固定効果の傾きにした。statsmodels の `PoissonBayesMixedGLM` に offset が無い。傾きは上のとおり 1 に近い（CoAuthor を除く）。
2. 件数のモデルの最適化を、既定の BFGS から L-BFGS-B にした。既定は乱効果の数の 2 乗の行列を持ち、合成の 499 行で 259 秒かかり、実データ（CS1 2019 で 2,967 行・乱効果 5,000 個余り）では終わらない。合成で両者の推定は小数 2 桁まで一致した（L-BFGS-B は 1.6 秒）。
3. CS1 のまとまりの露出（D4）は、[最初の押下, 最後の押下] で切った長さではなく、まとまりの開始で単位の時間を区切った区間と観測区間の重なりにした（まとまりの間の時間を次のまとまりに入れる）。停滞は t0 でまとまりに割り当てるので、まとまりの間に立った停滞が露出 0 の区間に落ちないようにした。
4. K5 は推定の前ではなく同じ実行の中で回した。判定（§J）が K5 で回復した水準だけを使うので、結果は変わらない。
5. K1 の θ 0.995 の変種は、下限 100 個では 269 単位で一致せず、作業場の作り方（下限 200 個）に合わせて一致を確かめた。
6. M4 の一致は、B0 の t0 がその通りの停滞の [s, 再開] に入る割合とその逆の小さい方。再開は同じ観測区間の中の最初の文字の押下に限り、再開しなかった停滞はその観測区間の終わりまでを区間にした（`candidates.py` の `Day.resume` と同じ。1 回目の計算は区間をまたいで次の文字を取っており、B0 で CS1 2021 の 6%・CS1 2019 の 3% の長さが観測していない時間を含んでいた。直して全部を回し直した。件数・率・φ・M1〜M4 の値は変わらず、長さの分解だけが動いた。CS1 2019 の書き手の分け前は 0.19 から 0.11 になり、その後ずれ 13 で 0.03 になった）。
7. C2 の (b) で、件数が 0 の書き手の単位は外し、p はそれ以外の書き手の数にした。書き手の率が 0 だと期待が 0 になり、Pearson の項が定まらない。B0 で件数 0 の書き手は CS1 2019 の 1.3%・ほかは 0% 前後。
8. 観測 10 分以上の書き手という条件を、D の表の KLiCKe の行だけでなく全部のデータにかけた。K1 の照合も外した後の単位で数えた。
9. 件数のモデルの分散成分の事前の SD を、statsmodels の既定の 1 ではなく 2 にした（`vcp_p=2.0`・弱い事前）。条件に書いていなかった。K5 も同じ設定で回すので回復の判定とは整合する。分散成分は事後の対数 SD の変分平均を指数にした値で、事後平均そのものではない。V は判定に使っていないので、推奨は動かない。
10. O の「CS1 のまとまりか課題、CoAuthor のセッションのうち 2 つ以上」を、5 つのセル（CS1 2019 と 2021 のまとまり・課題、CoAuthor のセッション）のうち 2 つ以上と数えた。同じ年版のまとまりと課題は同じ書き手・同じ停滞を数えるので独立ではない。より厳しい読み（CS1 のまとまり・CS1 の課題・CoAuthor のセッションの 3 つ組のうち 2 つ、または年版ごとに 1 つ）でも、CS1 2021 のまとまりと課題、CS1 2019 の課題が基準を超えるので、O は成り立つ。
11. M4 で一致の割合が定義できない通り（どちらかの停滞が 0 件）を一致 0 として数えた。そのような通りは B0 と率が ±20% 以内にならないので、M4 の 2 つ目の条件で外れる。
12. 2 系統レビューの後に、M3 の比が 0 のとき欠測になる判定を直し、収束の記録・selftest の対照 8 つ・変異 8 つ（K3 は 20 個すべて赤）を足した。検出器の本体は変えていないので、run_configs は回し直さず、c3b・analyze・来歴だけを回し直した（来歴の `git_head` はその版）。CoAuthor の取り置きの照合（D3）は元の ID が作業場に無いのでセッションの数だけで確かめている。
13. 長さのモデル（MixedLM・REML）を、既定の最適化だけでなく Powell と Nelder–Mead でも当て、収束した中で REML の対数尤度が最大の解を採った。既定の最適化は 27 回のうち 14 回で未収束で、B0 の CS1 2019 では尤度が Powell・Nelder–Mead の解より 241 低かった。両者は同じ解に揃った（分け前の差は 0.01 以内）。推定量は REML のままで、条件の範囲の中の実装の選択とする。直す前の値（書き手の分け前 0.11・0.36 など）は局所の解で、使わない。2 系統レビューで収束の記録を足して見つかった。
14. 件数のモデル（変分ベイズ）は、同じ入力・同じ seed でも回すたびに値が変わり、分け前が最大 0.93 動いた（並列の行列計算の丸めの順が揃わないためと見る・確かめていない）。K5 の回復の結果も合わせ、件数の分解は判定にも記述にも使わない。長さのモデル・φ・C3 の値は回し直しで一致した。

## 二重の公表について

B0 の値（率・φ の一部）は論文 1 の付録の定義と同じ定義なので、論文 1 に出た数と重なりうる。論文 2 では B0 を基準点としてだけ使い、主張は振ったときの動き（M）と同じ人の中の過分散（O）に置く。
