## 問い

論文 3 の本文（commit b1fa91de の main.tex・Discussion の第 1 段落）は "The weak comparison is likely not specific to keystrokes: features computed over overlapping windows make consecutive inputs dependent, and a shared model whose structure misses that dependence makes a per-person fit look good. この試験は、窓の歩みを 1・5・10・15・30 秒と変え、同じ記号の数で歩みだけが違う比べを作って、次を問う。

- (a) 記号の数をそろえたとき、歩みが短い側（重なりが強く、予測の先が短い側）で得が大きいか。
- (b) そのとき、共有 hmm3 が共有の 1 次の連鎖に負ける量（共有の構造の足りなさ）と、共有 hmm3 の擬似残差の自己相関も、歩みが短い側で大きいか。

- (d) 本人 hmm3 が本人の連鎖に負けるか勝つかは、どの歩みで入れ替わるか（論文 3 の勧め (1) がどの記号化で効くか）。

## 言い方の限り（どの結果でも守る）

- 歩みを変えると、窓の重なり（(30 − 歩み) / 30）と、続く記号の間の秒（予測の先の長さ）が同時に変わる。この試験は 2 つを分けない（窓の長さを変えて歩みを固定する列は作らない・判断 4）。どの型でも、本文と補足は「歩み（窓の重なりと予測の先の長さ。この試験は分けない）」と書き、「重なりが効いた」「重なりが従属を生む」と書かない。打鍵そのものが 1 秒先では続き 30 秒先では続かないことでも同じ形は出うる。
- 型の名と文は「仕組みと合う形」「仕組みと合わない形」と書き、「仕組みを測った」「仕組みが確かめられた」と書かない。

## D1 データ（変える所）

## D5 読みの形（結果を見る前に決めた・閾値と検定は置かない）

値は全記号の中央値。1/2・1/4・「3 つ以上」は言い方の区切りで、検定ではない。

### 量ごとの「列 C と列 A の比べ」の語（主）

各セル（k = 5・15）で、歩み s ∈ {5, 10, 15, 30} ごとに Δ(s) = Q_C(s) − Q_A(s)、m(s) = max(|Q_C(s)|, |Q_A(s)|) とする。判定は次の順に当て、最初に当たった語を採る。

1. 4 つの s のどれかで値が欠ける → 「欠けがある」。
2. m(s) = 0 がある s では、その s を「差なし」として数える。
3. 「歩みの短い側で大きい」: 3 つ以上の s で Δ(s) > 0、かつ Δ(30) ≥ m(30) / 2。
4. 「歩みの短い側で小さい」: 3 つ以上の s で Δ(s) < 0、かつ −Δ(30) ≥ m(30) / 2。
5. 「歩みで変わらない」: 3 つ以上の s で |Δ(s)| < m(s) / 4（「差なし」を含む）。
6. どれでもない → 「形が定まらない」。

2 セルで同じ語ならその語、違えば「割れる」とする。ρ_h は共有モデルも評価の単位も k に依らないので、セルを分けず語は 1 つとする。

### 量ごとの「歩みに沿うか」の語（記述・列 A と列 C それぞれ）

m = max(|Q(1)|, |Q(30)|)（列 C の Q(1) は列 A の s = 1 と同じ）。判定の順は、欠け → m = 0 なら「沿わない」→「増える」（Q(1) − Q(30) ≥ m / 2 かつ隣の 4 組のうち 3 つ以上で Q(短い歩み) ≥ Q(長い歩み)）→「減る」（鏡）→「沿わない」（|Q(1) − Q(30)| < m / 4）→「形が定まらない」。図と表に添えるだけで、型に使わない。

### 作りの確かめ（型の前に当てる）

列 A の M（Miller–Madow）が、上の「歩みに沿うか」の語で「増える」（歩みが短いほど大きい）でなければ、歩みは続く記号の従属を意図どおりに変えなかったと書き、型を付けず値を並べる。この確かめはほぼ必ず通る作りの確かめで、モデルが運べない従属の確かめではない（その役は ρ_h）。

### 型（主の量の語の組で決める・決定表）

G の語で枠を決め、D_s・ρ_h の語で型を決める。R_ar3 の語は型の文に添える。

| G の語 | D_s と ρ_h の語 | 型 | 名 |
|---|---|---|---|
| 歩みの短い側で大きい | D_s が「歩みの短い側で大きい」かつ ρ_h が「歩みの短い側で大きい」 | 1 | 記号の数をそろえても、歩みの短い側で得と共有の構造の足りなさがともに大きい（仕組みと合う形） |
| 歩みの短い側で大きい | 上でない（どちらかが他の語・割れる・欠け） | 2 | 得は歩みに沿うが、共有の構造の足りなさとは並ばない |
| 歩みで変わらない | どれでも | 3 | 記号の数をそろえると歩みの差は消える（縮みは記号の数と合う） |
| 歩みの短い側で小さい | どれでも | 4 | 記号の数をそろえると、歩みの短い側で得が小さい（仕組みと合わない形） |
| 形が定まらない・割れる・欠けがある | どれでも | なし | 形が定まらない |

R_ar3 の添えの文（どの型でも）:

- 「歩みで変わらない」→「構造を固定した強い比べの残りは、記号の数をそろえると歩みで変わらなかった」。
- 「歩みの短い側で大きい」→「強い比べの残りも歩みの短い側で大きかった」。
- 「歩みの短い側で小さい」→「強い比べの残りは歩みの短い側で小さかった」。
- 「形が定まらない」「割れる」「欠けがある」→ その語と値を並べる。

副の採点（頭を除く）で G・D_s・R_ar3 の語が全記号と違えば、その量に「割れる（系列の頭）」と添え、型は全記号で決めたまま書く。
