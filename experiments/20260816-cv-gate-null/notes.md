# EP-Q8 の帰無比較 — 「非打鍵ノイズが CV の半分」は打ち切りの算術効果と分けられるか

## 0. この実験の位置づけ

| 項目 | 内容 |
|---|---|
| 問い | ⚠️★★★ **EP-Q8**（`.steering/_handoff/next-session-prompt-survey-synthesis-and-design.md` §5） |
| 検証する仮説 | ⚠️ **`research-positioning.md §5` の H-X1/X2/Y のいずれも検定しない。**★ **方法論実験**である —— `media-expression-spec.md §8` の検出力設計が乗る **anchor（CV）の妥当性**を点検する |
| PreReg | ★ 直接は縛られない。⚠️ ただし **ゲート値 `keydown ≥ 100` は G1 事前登録 §2.9 で凍結済み**であり、本実験が事後に選んだ値ではない |
| 借用手法の出典 | ★ **無し**。左側打ち切り最尤法は標準的な統計手法であり、特定文献に依拠しない（★ `citation-ssot` に新規登録しない） |
| HMM_VERSION | `0.3.0`（★ 本実験は HMM 出力を使わない。`key` レコードの打鍵数のみ） |
| 上流 | `experiments/20260815-expression-power/`（★ 窓抽出 `window_counts` を**再利用**した。切り方を再発明すると比較が成立しない） |

## 1. 何が問題だったか

`20260815-expression-power/notes.md §4-1` は次の観測から
**「非打鍵ノイズが CV のおよそ半分を占めていた」**と解釈していた:

| ゲート | 残る窓 | 参加者内 CV 中央値 |
|---|---|---|
| なし | 617 | **1.0526** |
| `keydown ≥ 1` | 494 | 0.7576 |
| **`keydown ≥ 100`** | 382 | **0.5019** |
| `keydown ≥ 200` | 311 | 0.3952 |

⚠️★★★ **しかし正の分布の下側を切れば、中身が何であれ CV は算術的に下がる。**
★ スイープは閾値に対して単調であり、**純粋な打ち切り効果と区別されていなかった**。

## 2. 何をしたか

**H0**: 「打鍵している窓」は 1 つの同質な過程（対数正規）から来ており、
**ゼロ打鍵の窓だけが別の点質量**（離席・非打鍵作業）である。

★ **ゲート上の窓だけ**（`keydown ≥ 100`・左側打ち切り）から対数正規を MLE で当て、
**外挿**して観測と突き合わせた（★ 打ち切りを無視して素で当てると σ が過小になり
**H0 に有利な方向へ偏る**ので、打ち切り尤度で補正した。★ 自己検査 1c がこれを固定している）。

## 3. 結果

### 3-1 ★ 観測は上流実験と完全一致（★ 窓の切り方が同一であることの確認）

★ 1.0526 / 0.7576 / 0.5019 / 0.3952 —— **4 値すべて一致**。617 窓・5 名・ゼロ打鍵窓 123・`≥100` 窓 382。

### 3-2 ★★★ 分解（★ model-free・観測値だけで決まる）

| 内訳 | 値 |
|---|---|
| 低下の総量（全窓 → `≥100`） | **0.5507** |
| ★ **ゼロ打鍵窓の除去**が説明する分 | **53.6%** |
| ⚠️★★★ **打鍵している窓の本体を切ったことによる分** | **46.4%** |

⚠️ **share は CV の差の比であって分散分解ではない**（★ 記述的な内訳として読む）。

### 3-3 ★★★ 打ち切りの算術効果は実在する（★ 5 名全員で単調）

★ **ゼロ打鍵窓を全部除いた後でも**、閾値を上げると CV は下がり続ける:

| 参加者 | `≥1` | `≥100` | `≥200` |
|---|---|---|---|
| A | 0.6446 | 0.5019 | **0.3952** |
| B | 0.4091 | 0.4091 | **0.3887** |
| C | 0.7576 | 0.5353 | **0.4356** |
| D | 1.2811 | 0.7446 | **0.5977** |
| E | 0.8013 | 0.4537 | **0.2986** |

→ ★★★ **5 名全員で `≥100` → `≥200` がさらに下がる。**★ これは「非打鍵ノイズ」では説明できない
（★ すでに 100 打以上打っている窓しか残っていない）。⚠️ **EP-Q8 の懸念は妥当だった。**

### 3-3b ★ レビュア提案の帰無（EP-D15 (b)）も実施した — ★ ただし判定には使えない

★ `.steering/20260815-expression-power-calculation/decisions.md` EP-D15 の提案 (b)
**「打鍵率と無関係な閾値でランダムに 38% 落とす帰無比較」**を実施した:

| | CV 中央値 |
|---|---|
| 観測（全窓） | 1.0526 |
| ★ **ランダムに同数を落とした帰無** | **1.0378** |
| 観測（`≥100`） | 0.5019 |

→ ★ **標本サイズの減少では CV は動かない**（1.0526 → 1.0378）＝ **代替説明が 1 つ消えた。**
⚠️★★★ **しかしこの帰無は EP-Q8 の問いに答えない** —— ★ 無作為間引きは CV を期待値として保存するので、
**「低い窓が別集団か」と「同質な分布の下側を切っただけか」を区別できない**。
→ ★ **その区別のために 3-4 の打ち切り外挿を主判定に置いた**（★ 提案 (b) とは別の帰無である）。

### 3-4 ★ H0 は棄却される（★ ただし別の意味で）

| 予測対象 | 観測（中央値） | H0 予測 | 差 |
|---|---|---|---|
| 全窓 CV | 1.0526 | 0.8916 | ★ **観測 > 予測 +0.161** |
| `≥1` CV | 0.7576 | 0.5967 | ★ **観測 > 予測 +0.161** |
| `≥200` CV（★ モデル検証用） | 0.3952 | 0.5004 | ⚠️ **予測 > 観測 +0.105** |

- ★ **観測 > 予測**（5 名中 4 名）＝ ★★★ **ゼロではないが極端に低い窓にも余分な質量がある。**
  → ★ **「非打鍵」的なものはゼロ窓だけではない**（★ 自己検査 3 の検出閾値 0.05 を大きく超える差）。
- ⚠️★★★ **同時にモデルの当てはめは良くない** —— `≥200` の CV を **5 名中 4 名で過大予測**
  （例 E: 予測 0.495 対 観測 0.299）＝ 単一対数正規は上側の裾が実データより重い。
  → ★ **定量的な外挿は指標にとどめ、判定は 3-2 / 3-3 の model-free な結果に置く。**

## 4. ★★★ 結論（EP-Q8 への回答）

1. ⚠️★★★ **「非打鍵ノイズが CV のおよそ半分を占めていた」は過大であり、書き換えが要る。**
   ★ 正しくは **「低下分（0.5507）の約 54% がゼロ打鍵窓の除去で説明され、残り約 46% は
   打鍵している窓の本体を切ったことによる算術効果である」**。
   ⚠️ **CV そのものの半分が非打鍵ノイズだった、とは言えない。**
2. ★ **一方で「低打鍵側に別の集団がある」こと自体は支持される**（3-4・観測 > 予測）。
   ★ **ゼロ窓だけでなく、低いが非ゼロの窓にも余分な質量がある。**
3. ⚠️★★★ **したがって `0.502` は「統制下 CV の推定」ではなく、閾値の選択に依存する量である。**
   ★ ゲートが 100 だから 0.502 であって、200 なら 0.395。
   → ★ **`20260815-expression-power/notes.md §4-3` の「あと 1.6 倍」は
   *ゲート値 100 を選んだときの* 距離であることを明記する必要がある。**
4. ★ **統制下 CV は依然として G1 が出す**（★ 上流の結論は変わらない）。
   ⚠️ **本実験は「0.502 を統制下の代理として使うな」と言うだけで、G1 の必要性を減らさない。**

## 5. ⚠️ 限界（★ 隠さない）

1. ⚠️ **H0 の族を対数正規に固定した。**★ 別の重い裾の族（ガンマ・ワイブル）なら当てはめが変わりうる。
   ★ **ただし 3-2 / 3-3 は model-free** なので、主結論はこの選択に依存しない。
2. ⚠️ **参加者 5 名・窓 617。**★ 中央値は 5 点の中央値である。
3. ⚠️ **5 分窓の切り方は上流実験の実装をそのまま使った**（★ 最後の欠けた窓は捨てる）。
   ★ 窓長を変えた感度分析はしていない。
4. ⚠️ **「ゼロ打鍵窓＝離席/非打鍵作業」は解釈であって観測ではない。**
   ★ content-free なので、その窓で何が起きていたかは分からない（★ `_index` 2026-08-15 の
   「沈黙の中身を content-free に同定した研究はゼロ」がそのまま当たる）。
