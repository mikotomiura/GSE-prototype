## (a) 合成の日の模擬

### A1 生成（1 回の模擬 = 1 人・D 日）

- 日 d = 1..D の日の揺れ u_d は定常な AR(1): u_1 ~ N(0, σ_d²)、u_d = ρ·u_{d−1} + √(1−ρ²)·ε_d、ε_d ~ N(0, σ_d²)。
- 日 d の無作為の枠の回答の件数 n_d ~ Poisson(λ)。
- 回答 i の z_i ~ N(0, 1)。モデルの線形予測 η_i = a + s·z_i、モデルの出力 p̂_i = σ(η_i)。真の確率 p_i = σ(η_i + u_d)、ラベル y_i ~ Bernoulli(p_i)。
- a と s は、母集団（A3 の大きな標本）で、陽性の割合が π、p̂ の y に対する AUC が狙いの値になるように二分法で決める（許容 ±0.002）。
- p̂ は学習の後に凍結したモデルとみなし、模擬の中で学習しない（学習の推定のばらつきは含まない）。

### A2 評価

- 前の ceil(0.6·D) 日を学習の側（模擬では使わない）、残りを評価の側にする（MhD 判断 8 の前向き分割・割合は第 1 版と同じ仮置き）。
- 評価の側で、較正の切片（logit(p̂) をオフセットにした切片だけのロジスティック回帰の切片）と、較正の傾き（y を logit(p̂) に回帰した傾き）を Newton 法（許容 1e-8・最大 100 回）で求める。

### A3 推定の対象（被覆の基準）

- 同じパラメータで日を 50,000 日作り（日の揺れも同じ過程）、全体で求めた較正の切片と傾きを「母集団の値」とする。日の揺れがあるとき、周辺の傾きは 1 より小さく、切片は 0 からずれうる。被覆はこの値に対して数える。

### A4 区間

- 評価の側の日を、巡回するブロック（[V369]）で再標本化する。日を円に並べ、長さ L のブロックの始まりを一様に引き、評価の日数に達するまで並べて切る。各回答の重みは、その日が選ばれた回数。
- L の主の規則: L = max(2, round(m^(1/3)))（m は評価の日数）。次数は [V367] の分散の推定の次数で、定数は決めていない仮置き。
- 反復は B = 500、区間は 2.5・97.5 パーセンタイル。再標本の中でラベルが 1 クラスだけのものは捨て、捨てた回数を数える。Newton 法が収束しなかった回数・|傾き| > 50 になった回数（分離の目印）を数える。収束しなかった再標本は区間の計算から除く。区間を作れた再標本が 100 未満なら、その模擬の区間は「作れない」とし、被覆では含まないと数える。
- 被覆は R 回の模擬で、区間が A3 の値を含む割合。

### A5 格子

- 主の格子: D ∈ {20, 35, 50, 75, 100} × AUC ∈ {0.60, 0.70, 0.80} × π ∈ {0.15, 0.30, 0.50}。λ = 6・σ_d = 0.5・ρ = 0.3。R = 200。
- 感度（D = 50・AUC = 0.70・π = 0.30 のまわりで 1 つずつ変える）: σ_d ∈ {0, 1.0}・ρ ∈ {0, 0.6}・λ ∈ {3, 10}・L ∈ {1, 2 × 主の規則}・回答 1 件ずつの再標本化（日を無視する）。R = 200。
- 出すもの（格子の点ごと）: 評価の日数・回答の件数と陽性の件数の中央値・傾きと切片の区間の幅の中央値と四分位・被覆・母集団の値・捨てた再標本・収束しなかった回数・分離の目印の回数。
- 乱数: 格子の点ごとに SEED と点の番号から作る（`numpy.random.SeedSequence([SEED, 点の番号])`）。

### A6 陽性対照（`--selftest`・計算の前に通す）

- P1 重み付きの Newton 法: 整数の重みで解いた係数が、行を重みの回数だけ並べて解いた係数と 1e-6 で一致すること。既知の係数で作った 20,000 件で係数を ±0.05 で戻すこと。
- P2 母集団の値の解き方: 解いた a・s で作った母集団の陽性の割合と AUC が、狙いから ±0.005 に入ること（σ_d = 0.5・π = 0.30・AUC = 0.70）。
- P3 日の揺れが無いとき（σ_d = 0・D = 100・AUC = 0.70・π = 0.30・R = 400）、傾きと切片の被覆がどちらも [0.92, 0.98] に入ること。外れたら配管に誤りがあるとみて止める。
- P4 日の揺れが大きいとき（σ_d = 1.0・ρ = 0.6・D = 50・AUC = 0.70・π = 0.30・R = 300）、回答 1 件ずつの再標本化の切片の被覆が、日のブロックの切片の被覆より 0.03 以上低いこと。成り立たなければ、生成が日の依存を作っていないか、ブロックが依存を拾っていないとみて止める。
- 変異（計算の前に 1 回ずつ走らせ、P3 が赤になることを確かめる）: (m1) 傾きの計算で y と p̂ を取り違える（p̂ を logit(y) に回帰する）、(m2) 切片の計算でオフセットを外す。
- 陽性対照と変異の出力は `results/selftest_daysim.json` に書き出す。
