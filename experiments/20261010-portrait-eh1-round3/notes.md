### 記述だけ（design §3.6）

- 材料の情報量（`material_info.json`・上乗せの点推定）: L300 は p_stuck +0.164 / +0.120・F の水準 +0.173 / +0.189（hgb / lr）。L60 は +0.170 / +0.180・+0.173 / +0.243。L1800 は +0.162 / +0.063・+0.213 / +0.178。画面から取れた上乗せ（L300 の 8 組で +0.009 以下）は、材料の上乗せよりずっと小さい。ただしこの差だけでは、写す段で情報が落ちたのか、今回の特徴と攻撃者が画面から読めないだけなのかは区別できない。
- 下見（P 40）と本番（P 240）の PC-cal（λ = 0.10）: L300 +0.057 → +0.054、L60 +0.032 → +0.028、L1800 +0.007 → +0.023。L1800 の PC1 の下限は −0.027 → +0.048。

## 逸脱・気づいたこと

- 逸脱は design §8 のとおり（`select_lambda` の解釈・`gse-replay` のビルド・下見とスモークと本番の値）。基準・ラベル・攻撃者・λ は、下見の後に変えていない。
- L60 は、下見の値から見込んだとおり PC-cal の下限が 0.03 に届かなかった（+0.024）。L1800 は PC1 が 0.10 に届かなかった（+0.048）。どちらも design §3.3 の「結果の前の宣言」に当たり、λ・条件・ラベルは変えない。
- `PCcal0` の L1800 の下限が 0 をわずかに上回った（+0.001）。λ = 0 の色は雑音だけなので、時刻の経路（`clock60` の更新の有無が窓によって違うこと）か、偶然の揺れかは分からない。点推定は +0.004（上限 +0.007）で、基準より十分小さく、判定には使わない。
