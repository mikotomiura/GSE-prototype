### (2) 何を計算するか

- データ: CoAuthor の 15-session パネル（17 人）と CS1 の five-assignment パネル（23 人）。論文 3 の補足 S2 で取り置いた 30% の書き手は読まず、S と π にも入れない（取り置きの一覧は論文 3 の作りのものを使い、その SHA-256 を出力に書く）。単位は補足 S2 と同じ `data.load_*`・`ml.pool_units` で作る。A と B の単位の番号は v1 の D1 の式（`eye.py` の `a_idx`・`b_idx`、合成と同じ関数）で作る。S と π は、取り置き以外の全書き手（パネル外は、課題や回の数が少ない書き手も含む）の `ml.pool_units(writers, H)` の単位から作る（`ml.non_eval` のとおり、単位が H + 1 以上ある書き手だけ後ろの H 単位を落とす）。揃え（v2 の D1 の追加）も合成と同じ作りで行う。書き手は除外しない。
- 読み込みの始めに、`data.MUT`・`ml.MUT`・`eye.MUT` が空であることを確かめ、空でなければ止める。
- 書き手の番号 v: パネルの書き手を公開のデータの書き手の ID の順（`data.py` の `sorted(by_w)`）に並べた番号。並べた ID の列の SHA-256 を出力に書く。`load_*` の seed・probe_unit は記号の系列に効かない。
- セル: D6 の門をかけた 9 つ（CoAuthor k = 1・5・15 の間なし、k = 5 の g = 5・10、CS1 k = 1・5 の間なし、k = 1 の g = 1・4）。
- 量: セルごとに、E1 の T（整数の W）、2,000 置換の p（D3 の式）と、置換の引きの揺れの目安 SE = √(p(1 − p)/2,000)。記述の量（rank-1・EER 2 つ・書き手ごとの AUC_v・G_v）。
- 頻度だけの基準線（記述・判定しない）: 同じセル・同じ揃えた数・同じ σ で、遷移の行を潰した近さ s0(w → v) を作る。q_w^A[c] = (Σ_j N_w^A[j, c] + m · u[c]) / (Σ_{j,c} N_w^A[j, c] + m)、u[c] = (Σ_j M[j, c] + 0.5 · 26) / (Σ_{j,c} M[j, c] + 0.5 · 26²)（S と同じく 1 セルあたり 0.5 を足した数の列の和・m = 26）、s0(w → v) = v の B のすべての遷移の行き先 c の log q_w^A[c] の和 ÷ 組の数。AUC_v・T・p は E1 と同じ作り。値が有限でないときは、そのセルの基準線だけを「算出できなかった」とし、E1 の計算と判定は止めない。
- 乱数: 揃えは [SEED + 93, 0, 7, 形, k, g, r, 側, v]、入れ替えは [SEED, 0, 7, 形, k, g, 0]（帰無の番号 0 と筋の番号 7 は実データの印。合成の鍵と重ならない）。σ の列はすべての r で共有する。r = 0 を主の 1 回とする。
- 揃えの揺れ（記述）: r = 1〜20 でも揃えだけを引き直して同じ計算をし、p と T の範囲と、p ≤ 0.05 になった回数 m/20 を並べる。判定は r = 0 だけで行い、r = 1〜20 を見て変えない。
- 計算の前に出す量: 各セルのパネルの人数、揃えた後の A と B の総数（n_A・n_B）と、パネルの書き手ごとの総数の中央に対する比、パネル外の人数と単位の数、パネルの書き手ごとの単位の数の分布。
- 止め: 例外が出たら止め、コードを直して同じ鍵ですべてのセルを回し直す。止めた時点で出ていた量と直した差分を notes に書く。揃えた後の総数が 0 になる側が出たセルは「計算できなかった」と書き、ほかのセルの計算・判定・文は変えない。定義を変えるなら v1 D8 の「定義を変えた版」として新しく凍結する。

- 規則: 実データのセルの n_A か n_B が、この範囲の最小を下回ったら「合成の量の範囲の外（下）」、最大を上回ったら「合成の量の範囲の外（上）」とする。範囲の外のセルでは、書き手の水準は数を出すだけにして「c の較正の量の範囲の外」と書き、T と p は (3) のとおり読んで「門で確かめた量の範囲の外」と添える（入れ替えの p の大きさは交換可能性で決まるが、門はこの範囲の量でしか確かめていない）。範囲の内のセルでは下の報告をする。範囲の内であることは量についての必要条件で、c の較正が実データに移ることを保証しない。

### CS1 の読みの範囲

### 読まないこと（この追記で足す）

- 「本人の A が本人の B に近い」の「本人」は、書き手の中で一定の条件（機器・キーボード・環境）、作業のしかた（止まっている秒の割合と続き方。CS1 では止まりの割合が書き手ごとに 0.082〜0.900・補足 S6）、A と B の課題や話題の組み合わせを含む。人に固有の打鍵の差とは読まない。頻度だけの基準線は止まりの割合のような周辺の頻度の差を映すが、止まりの続き方と、それ以外の書き手の中で一定の条件は分けない。
- 実データのパネル外の構成（CS1 は 31 人のうち 25 人・パネル 23 人、CoAuthor のパネルは 20 単位以上で単位の数が書き手ごとに違う）は、合成（パネル外 CoAuthor 26 人 × 5 単位・CS1 8 人 × 3 単位、パネルは全員同じ単位の数）と違い、S と π の組成が違う。判定は変えず、計算の前に出す量（(2)）で並べる。
- 実データの p は 1 回の揃えの引き（r = 0）に条件づく。r = 1〜20 の範囲と回数は記述で、判定を変えない。
- 実データで拾ったことを論文 3 の結論の否定として、拾わなかったことを論文 3 の裏付けとして書かない。
