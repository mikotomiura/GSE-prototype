### (3) パネルの判定と、間を空けたセルの読み

- 判定の単位はセルごと。p ≤ 0.05 のセルは「この記録で、E1 は、本人の A が他の書き手の A より本人の B に近いことを、名札の入れ替えの帰無に対して p = x で示した」と書く。p > 0.05 は「拾わなかった」。セルをまとめた 1 文（「本人ごとの差がある」）は書かない。9 つのセルは同じ書き手・重なる単位を使うので独立でなく、補正はしない（すべての p を表に並べ、9 セルで少なくとも 1 つが偶然に p ≤ 0.05 になりうることを脚注に書く）。
- 主のセルは CoAuthor k = 5 の間なし（D5 の選びのセル・論文 3 の主のセル）。本文で 1〜2 文で触れるのはこのセルの結果だけとする（v2 の「論文 3 への入れ方」）。
- 間を空けたセル: E1 の 4 つの間のセルはすべて D6 の基準を超えた（判断 50）。よって実データでも、CoAuthor k = 5・g = 5・10 と CS1 k = 1・g = 1・4 は、CoAuthor k = 15・CS1 k = 5 と同じく「安定と漂いを分けない」セルとしてだけ読む。どの間のセルも、安定した差と漂いを分ける根拠にしない。
- g の並び（記述）: 実データの g = 0・5・10（CS1 は 0・1・4）の p と T を、合成の次の 3 つの並びと同じ表に並べる。(i) 用量の筋（安定した差・g によらない）、(ii) 漂いの筋 ρ = 0.5（合成の E1 で g = 0 が 0.61・g = 5 が 0.064・g = 10 が 0.040 と、間を空けると落ちる）、(iii) 漂いの筋 ρ = 0.9（どの g でも 1.0）。読みの文は次の 3 つだけを使う。
  - g = 0 で拾い、間を空けると拾わない: 「合成の ρ = 0.5 の漂いの並びと同じ向き。小さい安定した差でも同じ並びになりうる（合成の用量の 3e-3 は g = 0 でも 0.46）」。
  - どの g でも拾う: 「安定した差の並びとも、ρ = 0.9 の漂いの並びとも同じ向き。この版では分けない」。
  - どの g でも拾わない: 「どの並びとも食い違わない。合成の検出力（表）の範囲で、拾えない大きさの差か差が無い」。
  - 上のどれにも当たらない並び（g = 0 で拾わず間を空けると拾う）は、そのまま書き、読みを付けない。
