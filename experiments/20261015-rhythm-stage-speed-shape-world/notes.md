# notes — 背景のステージの机上の検査・揺れの形を分けた world（倍率だけ・漂いだけ）

設計: `.steering/20261015-rhythm-stage-speed-shape-world/design.md`（固定 `74754d26`・逸脱の表 §8）。判断: 同 `decisions.md` 判断 1〜14。

## 接続

- 問い（design §0）: 揺れの world `h(c)` の L300 の赤（とくに `r_absdiff`・`r_sd` が運ぶ上乗せ）は、速さの揺れの 2 つの成分（セッションごとの倍率 `u`・秒ごとの漂い `d`）のどちらから来るのか。
- world: 倍率だけ `f(c)`（`z = c·δ·u`）と漂いだけ `d(c)`（`z = c·δ·d(k)`）。段は `f100`・`f200`・`d100`・`d200`。成分の乱数の引きは `h(c)` と対（同じ `SEED` 20261020）。区間と打鍵は対にならない。
- 段・world・規則は、揺れの world と原因の切り分けの結果を見た後に決めた（探索的・判断 2・3）。world の式・段・PCr の形・読みの表は、どの段の下見 0 よりも前に固定した。
- 開示（判断 9・design §3.0）: 固定の前の 1 回目の試作が本番の seed のままで、本番の下見 0 の列の最初の 40 セッションの L300 の AUC(A_speed) を見た（f100 が天井になりそうなことを含む）。段・world・天井の規則は、それより前の grill で決めてあり、見た後に変えていない。ほかに固定の前に計算した本番の値は無い（試作の 2 回目以降は seed 7770000）。

### 項目 1 の判定の数（L300 / L60 / L1800）

`rd` = `red_detected`、`ru` = `red_unconfirmed`、`g` = green、`u` = `undecidable`（`red_detected_stop_path` はどの段でも 0）。

| 段 | L300 | L60 | L1800 | world の状態 |
|---|---|---|---|---|
| t050（`g(0.5)`・中間の world） | 判定不能（`ceiling`） | 同 | 同 | 走っていない |
| c100（`h(1)`） | rd 8・ru 2・g 14 | rd 6・g 6・u 12 | g 24 | 赤あり |
| f100 | 走っていない | 走っていない | 走っていない | 走っていない |
| d100 | rd 7・g 9・u 8 | u 24 | g 18・u 6 | 赤あり |
| c200（`h(2)`） | rd 4・ru 5・g 15 | rd 1・g 1・u 22 | g 21・u 3 | 赤あり |
| f200 | ru 4・g 4・u 16 | rd 9・ru 6・g 1・u 8 | u 24 | 決まらない |
| d200 | rd 6・ru 3・g 15 | rd 4・g 4・u 16 | g 24 | 赤あり |

- `undecidable` の理由はすべて `weak_stall_pc`（PC-stall がその候補で働かない）。d100 の L300 は smooth-ground・rank の 8 本、f200 の L300 は smooth の 6 本・rank の 6 本・jitter-hold/ground の 4 本。f200 の L60 は 8 本、L1800 は 24 本とも。下見 1 で「帯に入る λ なし → 格子の上端 0.3」で選んだ候補は、d100 が L300 8 本・L1800 6 本、f200 が L300 8 本・L1800 24 本、d200 は 0 本（design §8）。
- L300 の赤（`rd`）の候補:
  - d100: raw の `-sub` 3 本・smooth-hold-sub・jitter の `-sub` 3 本。
  - d200: raw の `-sub` 3 本・jitter の `-sub` 3 本（`ru` は smooth-hold-sub・rank-decay-sub・rank-ground-sub）。
  - f200: `red_detected` は 0 本（`ru` は raw-hold-sec と raw の `-sub` 3 本・16 本は判定不能）。
  - 参考（揺れの world）: c100 は raw・jitter の `-sub` 6 本・smooth-hold-sub・rank-decay-sub、c200 は raw の `-sub` 3 本・jitter-ground-sub。
  - 候補ごとには読まない（列は world の間で対にならない・design §3.3 への追加 (i)）。24 本すべての判定の並びは `compare.json` の `verdicts_L300`。

### (i) 成分の読み（固定した表のとおり）

| c | `h(c)` | `f(c)` | `d(c)` | 読み |
|---|---|---|---|---|
| 1 | 赤あり | 走っていない（f100 は天井） | 赤あり | `not_run` |
| 2 | 赤あり | 決まらない | 赤あり | `unsettled` |

- **どちらの c でも、固定した表の読みは作られなかった。** 表の読みを作るには `f(c)` と `d(c)` がともに「赤あり」か「赤なし」である必要があり、`f(c)` は c = 1 で天井、c = 2 で 24 本のうち 16 本が判定不能だった。したがって、この試行は「`h(c)` の赤は `u` と `d` のどちらから来るのか」に答えていない。
- 言えるのは状態の記述までである。この試行では、`d(1)`・`d(2)` のどちらでも L300 に赤が出た。`f(2)` の L300 は `red_detected` が 0 本、`red_unconfirmed` が 4 本、判定不能が 16 本、緑が 4 本で、状態は「決まらない」だった。これを「倍率では赤が出ない」とは読まない（判定できなかった候補が 3 分の 2 ある）。

### (j) 切り分けの読み（L300・`lr|R2` などは「残る / 消える / 決まらない / 読めない」の数）

|---|---|---|---|---|---|---|
| c100 | 8 / 14 / 2 / 0 | 0 / 19 / 5 / 0 | 8 / 14 / 2 / 0 | 0 / 24 / 0 / 0 | 読めない 24 | 読めない 24 |
| d100 | 7 / 9 / 0 / 8 | 0 / 15 / 1 / 8 | 6 / 9 / 1 / 8 | 0 / 8 / 0 / 16 | 読めない 24 | 読めない 24 |
| c200 | 4 / 15 / 5 / 0 | 0 / 19 / 5 / 0 | 2 / 17 / 5 / 0 | 0 / 24 / 0 / 0 | 3 / 17 / 1 / 3 | 0 / 21 / 0 / 3 |
| f200 | 0 / 4 / 4 / 16 | 0 / 7 / 2 / 15 | 0 / 3 / 3 / 18 | 0 / 3 / 0 / 21 | 読めない 24 | 読めない 24 |
| d200 | 6 / 15 / 3 / 0 | 0 / 23 / 1 / 0 | 6 / 17 / 1 / 0 | 0 / 24 / 0 / 0 | 6 / 18 / 0 / 0 | 0 / 24 / 0 / 0 |

- c100・c200 は原因の切り分けの読み（このタスクでは回していない・写しただけ）。`Rall` はどの段でも「残る」0。
- `d(c)` では、落とさない（`none`）で上乗せが「残る」候補があり、`R2` を落とすと読めるモデル（d100 は `lr`・`lrbin`、d200 は 3 つとも）で「残る」が 0 になった。この点は原因の切り分けの `h(c)` と同じで、見込み（(k)「`d(c)` で赤が出れば、`R2` を落とすと消える」）どおり。
- `A2`（`a` の側）を落としたときの「残る」は、`d(c)` ではほぼ変わらなかった（`lr` d100 7 → 6・d200 6 → 6、`lrbin` d100 4 → 3、hgb d200 6 → 5）。`h(2)` では `lr` で 4 → 2 と減り、原因の切り分けの notes は c200 の `lr` で「`r` の 2 量が特に効くとは読まない」としている。この面では `h(2)` と同じとは言わない（下げ幅は `d(c)` について計算していない）。
- `f(2)` は「読めない」が多く、型を言えない。

- `over` と `unreadable` と `not_calibrated` はどこにも無い（土台の漏れは 0.03 に届かず、λ はすべて較正できた）。
- **`d(c)` の読み（design §3.3 への追加 (j) の読み方）**: `lr`・`lrbin` の `PCrl`（水準）は、`R2` を落としても 24 本すべてで `works` のままだった。この攻撃者は、`R2` を落とした後も、この大きさの `r` の水準の型の手がかりを拾えた。`R2` で「消える」になった候補（`lr` で d100 15 本・d200 23 本）について、上乗せが消えたことを「`R2` を落とすと `r` の側が何も見えなくなる」ことでは説明できない。赤だった raw-decay-sub は d100・d200 とも `lr|R2` で「決まらない」で、この読みに入らない。
- `PCrv`（揺れ）も、`R2` を落として大半が `works` のままだった（`lr` で d100 23 本・d200 22 本）。この大きさの点ごとに独立な揺れの手がかりは、`R2` を落としても残りの量で拾えた。それでも「消える」になった候補では、候補の手がかりは PCr-var の揺れとは違う形で `R2` の 2 量に偏っていたか、PCr-var より小さかった（どちらかは分けない）。`fails` になった候補（d200 の `lr` で smooth-ground の 2 本など）について、候補の手がかりが `R2` だけにあったとは読まない。
- `d(c)` の `lr`・`lrbin` で `PCrv` が `R2` で `fails` になったのは、smooth-ground の 2 本だけだった（d100 の `lrbin`・d200 の `lr`・d200 の `lrbin`、計 6 件）。`unclear` は読まない。`PCrl` は `smooth` でも `R2` で `works` のまま。
- 見込みとの違い: `smooth` の候補の PCr-var は働かないと見込んだ（design §1.3）が、`d(c)` の `none` では `smooth` の 6 本も `lr`・`lrbin` で `works` だった。smooth-ground の `fails` は、この形・この大きさの PCr-var の対照について、`R2` を落とすと上乗せが 0.03 未満になったと言えるだけである。
- hgb は d100・f200 で本番の L300 が天井で、PCr は `fails` だが、余地が無かった可能性があるので読まない（design §3.3 への追加 (j)）。

## 読み（記述・判定の語は前の判定を写すだけ）

- 主な問い（`u` か `d` か）には、この試行は答えていない。`f(c)` が c = 1 で天井、c = 2 で判定不能が多く、固定した表の読みはどちらの c でも作られなかった。
- 漂いだけの world `d(c)` では、c = 1・2 のどちらでも L300 に赤が出て、`R2` を落とすと「残る」が 0 になる点も `h(c)` と同じだった（`A2` の面は c200 で違う）。`r` の側の対照は、`R2` を落とした後も水準の手がかりを拾えた。この試行では、漂いだけでも L300 に赤が出て、それは `R2` を落とすと「残る」が 0 になった、とまで言える。倍率が赤を生むかどうかは、この試行からは何も言えない。
- 見込み (k) の「`f(c)` は赤が出にくい」は、確かめられていない（判定できなかった）。
- `f(2)` で判定できなかったのは、16 本で停滞の陽性対照 PC-stall が働かなかったため（理由 `weak_stall_pc`・観測）。下見 1 では 8 本の λ が「帯に入る λ なし → 格子の上端 0.3」だった（観測）。なぜ働かなかったかは、この試行では分けていない。考えられるのは、`A_speed` が強く上乗せの余地が小さいこと（L300 の hgb は 0.979 で天井として外したが、判定に残る lr も 0.874 と `d(2)` の 0.790 より高い）、λ の格子の上端、PC-stall の形、のどれか（推論）。倍率の world を読むには、`A_speed` を弱める作り（c を上げる・別の要約）か、PC-stall の格子を延ばす（PCr で行ったように）ことが要る見込み（推論・採るかは研究者が決める）。
- 人の打鍵の速さの揺れについては何も言わない。world の差を確かめたとも言わない（1 つの seed・列は world の間で対にならない・検出の力が world ごとに違う）。

## 逸脱・気づいたこと

- design の固定の後の変更は無い。§8 は値の追記だけ。
- design §8 の書き違いを 3 つ直した（`/cross-review` 1 巡目と照合で見つけた）。d200 の本番の行の L300 の green は 14 本でなく 15 本、d100 の下見 1 の行の L1800 で格子の上端を採った候補は 8 本でなく 6 本。また `d100` の本番の行に、L300 の赤を「raw・smooth・jitter の `-sub`（smooth-decay-sub は green）」と書いたが、smooth-ground-sub は `undecidable` で、正しくは「raw の `-sub` 3 本・smooth-hold-sub・jitter の `-sub` 3 本」。§8 の行を直した。
- PC-stall の λ が格子の上端に張り付く問題は、confound world でも同じ規則で起きていた（変えていない）。PCr の格子だけを延ばした（判断 10）ので、`f(2)` では `r` の側の対照は働き、停滞の対照は働かない、という非対称が出た。
