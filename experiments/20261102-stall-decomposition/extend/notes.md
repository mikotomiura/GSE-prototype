## 読み

1. どちらのデータでも、手の様子の 4 類は最も密な信号でほぼ埋まった。DUX はクリックが停滞の手前の 100% にあり、型はすべて操作になった（無作為な窓でも 97.7% が操作の類）。SWELL-KW は遷移が 76.3%、クリックが 93.3% の停滞の手前にあり、沈黙だけは 0.5%（2 件）。遷移を最下位に置くと 96.4% が操作になるので、SWELL-KW の遷移の型は、クリックがほぼ常にある中で優先順が選んだ割り当てでもある。
2. SWELL-KW では、停滞の手前は短い休止の手前より遷移が多く（+10.8 点・区間は 0 をまたがない）、削除 2 回以上が少なかった（−11.0 点・同じく）。今の順では、操作と沈黙の差は区間が 0 をまたぐ（削除を操作より上に置くと、操作の差は +3.2・+0.1〜+6.9 で 0 をまたがない）。削除の差は優先順を変えても向きを保った（−11.0 → −13.7）。DUX は類がすべて操作で、比べから情報が出なかった。
3. 180 秒を超える停滞は、DUX で 0%、SWELL-KW で 1〜2% だった。沈黙の型がほとんど無いので、上の段で 3 つのデータに見えた「前が沈黙だけ → 長い」は、ここでは確かめられない。X2 の同じ集合では、遷移と操作の型の長さの中央値はほぼ同じ（20.6 秒と 20.5 秒）。
4. SWELL-KW の停滞の率は、序盤（10 分未満）よりその後の方が高い（7.5 と 13.8 件/時）。差の一部は θ の温まりで序盤に停滞の始まりが立ちにくいことから来る。また、遷移の割合はセッションの後ろほど高い（3 等分で 60.5% → 84.4%）。条件の間の違いは、率で 11.6〜13.1 件/時、遷移の割合で 69.9〜81.3%。
5. DUX は 1 session が短く、22 session で停滞が 24 件、5 件以上の session は 1 本だった。区間は広く、型の記述にはほとんど使えない。`TAB` の扱いを変えると停滞の数は 24 → 25 とわずかに変わり、型の割合は変わらなかった。

## 逸脱

1. 条件の E3 は DUX の `repeat` について「E0 では 0 件」と書いたが、E0 の数え方が値の大文字（`True`）を小文字（`true`）と比べていた誤りで、実際は 32 本で 3,377 件の押下が自動の繰り返しだった。規則（繰り返しを押下に数えない）は条件のまま、大文字と小文字を区別せずに比べた。
2. SWELL-KW の 1 ファイルの末尾に、途中で切れた出来事が 1 つあり（`TimeStamp` が無い）、条件に無い扱いとして捨てて数えた（`no_timestamp`）。条件のコミットの後に変換器に足した。原因を探すとき、76 本すべて（取っておいた 8 名の 24 本を含む）の出来事を数え、`TimeStamp` の無い出来事の数と型だけを見た（全 434,686 件のうち 1 件・取っておかない人のファイル）。取っておいたファイルの停滞・休止・型の値は見ていない。振り分けより先を処理しないという E2 の文からは外れる。
4. レビューの後に、変換器を条件の文に合わせて直した: SWELL-KW の `special key` の 1 文字の値を other に（条件は 1 文字を `key combination` の最後の部分だけで扱う）、`Ctrl`・`Alt` を含まない修飾と `Backspace` の組を other に、DUX の同じ ms の押下と離しを対にする順（最初の直しは「離し → 同じキーの再押下」を誤って対にしたので、Codex の指摘で、すでに開いている押下を閉じる離しを先に置く順に改めた）・DUX の入力が 2 本でなければ止める。回し直して、変換の件数と型・長さ・X2〜X4 の値は変わらなかった（該当する出来事が無かった）。変わったのは、条件で出さないとした SWELL-KW の「沈黙の中の移動の割合」を null にしたことだけ。
5. 外した 2 ファイルの切り替えとクリックの数が、最初の版の build の合計（と 1 時間あたりの回数）に入っていた（レビューの HIGH）。合計を使った単位だけに改め、1 時間あたりの回数を直した（256 → 249 回・940 → 915 回）。型などの値には効かない。
3. 条件の X1 に「4 つの信号の共起の表」と「旗ごとの有無の割合」を出すと書いた。共起の表は `P1_cooccurrence`、旗ごとの割合は X4 の `flag_share_overlapping` にある。

## 言える範囲

- どちらも統制課題で、ふつうのデスクワークではない（ADR-032 D5）。DUX は否定的な感情の仕掛けを入れたフォームのアプリ、SWELL-KW は割り込みと時間の圧力を入れた模擬の知識労働。
- DUX の離しは同じキーの名前で対にするので、`ANONYMIZED` のように複数のキーが同じ名前になる押下が重なると、離しが別の押下に付きうる。停滞の始まりは押下の時刻で決まり、離しの時刻は型に使わない。
- 「時刻が秒より粗い」の判定は、全押下がちょうどの秒のファイルだけを外す。一部だけ粗いファイルは通る（該当は 0 本・押下の 99.9% に 1 秒未満の桁がある）。
- SWELL-KW の遷移は `Window Activated` で、O1 の `focus_transition` と同じ計器ではない。1 時間あたり約 249 回あり、ダイアログや通知の窓の活性化も含みうる（中身は読んでいない）。
- 停滞の始まりは詰まりの判定ではない（ADR-030 の 9b）。型は止まりの手前と最中の手の様子の記述。
- 取っておいた書き手は開けていない。検定をしていない。
