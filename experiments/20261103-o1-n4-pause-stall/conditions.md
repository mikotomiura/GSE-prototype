## N2 単位と除外

- 単位 = ファイル 1 本（前の解析と同じ。O1 は 1 日におおむね 1 本だが、起動し直した日は複数本になる）。補助として、名前の `<日付>` が同じファイルをまとめた単位（日付の単位）でも N4 の SD を出す。
- フォーカスの行が 0 のファイル: C0 と押下の間隔（N3 の流れ P）には入れ、C1・C2 と活動の出来事の間隔（流れ A）には入れない。c1c2c6 はフォーカスの行が 0 のファイルを全部外したが、本実験は人によってはその規則で全部が外れうるため、フォーカスを使わない量には残す。人ごとに外した数を出す。
- 観測区間の合計が 0 のファイルは全部の量から外し、数を出す。
- N4 の日の揺れの SD: 観測時間が 4 時間以上の単位だけを使う（見ていない期間の確かめ U1 と同じ下限）。4 時間未満の単位も件数・率の合計と N3 の分布には入れる。使える単位が 5 未満の人は SD を「単位不足」とし、値を出さない。

## N3 休止の長さの分布（人ごと）

- 流れ P: すべての押下（category を問わない）。流れ A: c1c2c6 の活動の出来事（押下・`pointer_bin` の行・`focus_transition` の行。同じ時刻は 1 点）。
- 休止 = 同じ観測区間に入る、流れの隣り合う 2 点の間隔（c1c2c6 の `gap_pool`・C0 と C1 の θ の標本と同じ）。0 ms の間隔は対数を取れないので外し、数を出す。
- モデルに依らない量（主）: 休止の長さの分位（50・75・90・95・99・99.9%・nearest rank）と、2 秒超・30 秒超・180 秒超・30 分超の休止の割合。加えて、休止の長さの和のうち、それぞれの長さを超える休止が占める割合（時間で重みを付けた割合）。
- 混合モデル（従・記述）: x = log10(休止の ms) に、成分数 K = 1〜5 の正規分布の混合を当てる。x を幅 0.02 の階級に分け（端は x の最小の切り下げ・最大の切り上げ）、階級の中央と度数で重みを付けた EM で当てる。初期値は、決まった 1 組（平均 = x の (k − 0.5)/K 分位・SD = x の SD ÷ K・割合は等分）と、SEED の乱数による 9 組（平均を x の度数分布から重複なしに K 個引く・SD と割合は同じ）。SD の下限は 0.02。対数尤度の増分が 1e-9 × 休止の数を下回るか、2,000 回で止める。K ごとに対数尤度が最大の初期値を残す。BIC = −2 × 対数尤度 + (3K − 1) × ln(休止の数)。BIC が最小の K を出し、K = 5 が選ばれたら「上限に当たった」と書く。K = 1〜5 のすべての当てはめ（成分の平均を秒に戻した値・SD〔桁〕・割合を平均の昇順で）を出す。
  - 混合の成分は「休止の種類」の証拠ではない（分布の形の要約）。成分の数・位置は K と階級の幅で動く。読みは主の量で行う。
- 人の間の幅: 上のモデルに依らない量（すべての分位と割合）と BIC の K について、4 人の値を並べ、最小と最大と、最大 ÷ 最小を出す。混合の成分は人ごとの値だけを出す。
- 読みの注: 流れ A は `pointer_bin`（1 秒のビン）を含むので、間隔が 1 秒・2 秒にそろいやすい。そのため流れ A の分位が 1.0 秒に集まり、混合の成分がその点に割かれて K が上限に当たりうる。

## N4 停滞の率と日の揺れ（人ごと）

- C0・C1・C2 は c1c2c6 の K2〜K4 のまま（`candidates.py` の `Day`・`day_rows`）。C6 は計算に含まれるが、14 日でほぼ立たなかったので読まない（値は出る）。
- 人の間の値が、フォーカスの本がある人で欠けたら止める（無くて当然の欠け〔フォーカスの本が無い・単位不足・標本が 0〕だけを欠けとし、キーの誤りは止める）。
- c1c2c6 の `summarize` が出す `day_unit_sd` は 4 時間の下限をかけていないので、名前を `day_unit_sd_no_4h_floor_not_N2` に替えて出す（N2 の SD と取り違えないため）。
- 人ごとに c1c2c6 の `summarize` を回し、O1（件数・1 時間あたり・単位の率の中央値と四分位・`unit_sd`）、O2（θ の発火した時点の中央値と四分位）、O3（長さの段の割合・再開したものの長さの中央値と四分位）、O4（C0 のうち C2 の割合ほか）を出す。C0 だけの量（フォーカスの行が 0 のファイルを含む）は別に出す。
- 日の揺れ: 単位（4 時間以上）の率の SD と、数え上げだけの SD の見込み（`unit_sd` の `sd_expected_poisson_mean`）と、その比。ファイルの単位と日付の単位の両方。
- 人の間の幅: 1 時間あたりの率（C0・C1・C2）、SD の比、θ の中央値、C0 のうち C2 の割合、長い（180 秒超）か打ち切りの割合の、4 人の値と最大 ÷ 最小。加えて、人の間の率の SD と、人の中の単位の率の SD の平均を並べる（事前登録 §3 の見積もりで人の間と人の中を分けて入れるための材料）。
- 版の違い: 人ごとに `app_version` の種類の数と、版ごとの単位の数を repo の外の表に出す。repo には「人ごとの版の種類の数」だけを書く。

## N6 陽性対照（実データの前に走らせる・止める）

1. c1c2c6 の `--selftest` を通す（検出器が変わっていないこと）。
2. 混合: 既知の 2 成分（平均 log10 = 2.3 と 4.0・SD 0.2 と 0.4・割合 0.8 と 0.2・10 万点・SEED）から作った標本で、BIC が K = 2 を選び、推定の平均が 0.05 以内・割合が 0.02 以内で戻る。1 成分（平均 2.5・SD 0.3）の標本では K = 1 を選ぶ。
3. モデルに依らない量: 手で作った間隔の列（例: 1, 2, 3, 100 秒）で、分位・割合・時間で重みを付けた割合が手計算と一致する。0 ms の間隔が外され、数が数えられる。
4. 単位の除外: フォーカスの行が 0 の合成のファイルが C0 と流れ P には入り、C1・C2・流れ A に入らない。観測が 4 時間未満の単位が SD から外れ、件数には入る。
5. 記号と漏れ: 同じ SEED で同じ対応になる。漏れの走査が P-ID・日付の形・版の文字列をそれぞれ見つける。
6. 合成の 4 人分の作業フォルダで `run()` を最後まで通す: 流れ A の数がフォーカスのある本の間隔の数になる・日付の単位が同じ日付の本を足す・人の間の主な値が欠けない・repo に入れる版が丸められ、漏れが無い。
7. 選ぶ規則: 一時フォルダで、本人の `083029` は入り `083030` は外れる・他人の `083030` は入る・`_dup-`・P-ID の食い違い・直下のファイルを形の合わないものに数える。
- 変異: BIC の罰・階級の重み・0 ms の除外・フォーカス 0 の振り分け（C1 側と流れ A）・4 時間と 5 単位の下限・観測 0 の除外・P-ID と日付の形の走査・between のキー名・日付の単位の合算・取り置きを全員にかける・公開用の丸めを外す、を壊した写しで対照が赤になる。変異していない写しが通ることを先に求め、読み込みの失敗による赤は数えない。BIC の罰の係数の小さな違い（3K と 3K − 1）は対照で見分けられない（限界）。

## N7 言える範囲（先に置く）

- 検定をしない。n = 4 なので、人の間の幅は「この 4 人ではこれだけ違った」の記述にとどまり、母集団の幅の推定ではない。
- 結果は形成的な内部の記述（ADR-014）で、主張に使わない。
