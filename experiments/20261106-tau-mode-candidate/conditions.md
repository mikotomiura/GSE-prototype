## −∞ の扱い（判断 4・9）

- 最頻値の評価で、ある記号の予測の確率が 0 になった書き手は、全記号の量を −∞ とする（有限の τ を ∞ に送った極限も −∞）。押下のある記号の量も −∞ とする（約束・確率 0 の後は最頻値だけからは濾波が定まらないため）。
- その書き手の差は、本人 − 最頻値 = +∞、最頻値 − 共通 = −∞。除かず、そのまま中央値・四分位（`inverted_cdf`）・良い側の割合に入れる。
- 区間: 復元抽出の中央値がすべて有限なら前の試験の式（linear）のまま。∞ を含むときは `inverted_cdf` で出し、印（`ci_method`）を付ける。
- 各セルに +∞・−∞ の人数を出す。構造ごとに、最頻値が −∞ になった書き手の人数と、和 0 の行（一様を置いた行）に評価で当たった書き手の人数を出す。
- NaN は出さない（出たらコードの誤りとして止める）。summary の JSON では ±∞ を文字列 "+inf" / "-inf" で書く。
- 値を見た後に床を入れる・書き手を除くなどの変更はしない。

## 読みの形（判断 5・結果を見る前に決めた）

閾値は置かず、a と b の中央値の絶対値の大小と符号で読む。見る所は上の表。
