## 結果 1 —— 大きい τ の差を a と b に分ける（結果の後）

見る表: `tables.md` の「最頻値で分ける」（主）と「副: 最頻値が有限の書き手だけで分ける」。全記号を主に、押下のある記号は向きが同じかだけを見る。構造 ar1〜ar3・hmm3 × 主のパネル × k、τ ∈ {10^5, 3×10^5, 10^6}。

読みの形（判断 5・10・結果を見る前に決めた）:

- 形 1（最頻値の側）: 10^6 で |a| < |b| かつ b の符号が c と同じ →「前の試験の大きい τ での差は、主に最頻値と共通の母数の違いから来る」

- 形 3（混ざる）: どちらでもない → 値を並べ、分けられないと書く
- 形 4（τ に沿う形）: a が 10^5 → 3×10^5 → 10^6 で 0 へ近づくかを書く（極限の対照・合成の P-LIMIT と同じ形か）
