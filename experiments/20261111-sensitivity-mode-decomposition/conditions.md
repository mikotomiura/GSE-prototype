## 問い

論文 3 の外枠は、実データ（CoAuthor の 15-session パネル）の 2 段（他人）の残り（本人 − 共通 +4.1e-4〜+7.2e-4）を「本人の上積みとしては読まない」とし、その根拠の 1 つに mode の分解（形 1: b = 最頻値 − 共通 が c と同じ符号で |a| より大きい）を挙げる。attack-me round 3（T1）は、sens で埋めた 1e-3〜3e-3 の個人差がこの桁の残りしか返さないことと、この「読まない」が食い違うと指摘した。

- 埋めた差が 0 の合成（陰性対照）で、分解は形 1 を返すか。
- 既知の大きさの個人差を埋めた合成（陽性）で、分解は形 2（a > 0 が主）を返すか。どの大きさから返すか。
- つまり、実データで形 1 が出たことは、どの大きさ以上の個人差が無いことと合うと言えるか。

## 読まないこと

- sens と mode の「読まないこと」をそのまま守る（合成の結果を実データの書き手の個人差の大きさの推定として読まない・EM の状態に名前を付けない・閾値の検定を置かない・CoAuthor のセッションは日ではない）。
- 結果を段 1 の候補の採否や ADR-047 の主張の根拠にしない。使うのは論文 3 の外枠の Take-home・C1・4.3・限界・S9・S15 の文だけ。
- a と b の中央値を足して c の中央値とは読まない。
- 言えるのは「この真の生成（記号の遷移の行の混ぜ・AR(1)-HMM）と、この形の記録の量で、分解がどう出るか」だけ。

## D2 計算（新しい乱数を引かない）

パネルの書き手 w・構造 s ごとに、評価の単位（`DT.split(n, 1, H)` の test）で次を測る。

- `pool`: w を除く共通の母数の評価（`ml.Eval.ll`）。sens の JSON の `pool[s]` とビットまで一致することを門とする（P-REPRO。外れれば止める）。

## D3 量（書き手ごとの差・中央値どうしの差ではない）

行は 2 つ。

- 主: 2 段（他人）の行。選びは sens の `analysis.cell` と同じ（`ml.select_joint`・`ml.joint_cands`・値は 本人 − r1）。選ばれた (s, τ) で、a = 本人(s, τ) − mode(s)、b = mode(s) − pool(s)、c = 本人(s, τ) − pool(s)。τ = ∞ が選ばれた書き手は 本人 = pool なので a = −b、c = 0。
- 副: 構造 ar1・ar2・ar3 の τ = 10^6 の行（mode の結果 1 と同じ行）。a・b・c を同じ式で。

各セル（複製 × k × 行）で、a・b・c の中央値・四分位（`inverted_cdf`）・良い側の割合（> 0）・+∞ と −∞ の人数。最頻値が −∞ の書き手は a = +∞・b = −∞（mode の判断 4・9 のとおり）。除かずに主の集計に入れる。加えて、最頻値が有限の書き手だけの集計（以下「有限」）と人数。

- 主の 2 段の行では、選ばれた τ の人数と、τ = ∞ の人数も出す。
- sens の主の量（2 段の c の中央値）と、ここで作り直した c の中央値が一致することを門とする（P-SAME。sens の summary.json の `cells[].main.median` と比べる）。

## D4 形（mode の形 1〜3・5 をそのまま当てる・結果より前に決める）

セルごとに、主の集計の中央値で:

- 形 1（最頻値の側）: |a| < |b| かつ b の符号が c と同じ。
- 形 2（本人の側）: |a| > |b|、a > 0、a の良い側の割合が 0.5 を超える。
- 形 3: どちらでもない。
- 形 5: a か b の中央値が ±∞ のセルは主で形を読まず、「有限」の集計で読む（有限の書き手が 4 人未満なら「読まない」）。どちらで読んだかを書く。
- 2 段の行で τ = ∞ の書き手が半分を超えるセルは「読まない（a = −b）」とする（mode の結果 2 の CS1 と同じ扱い）。
- c の中央値が 0 のときの「b の符号が c と同じ」は満たさないとする（形 1 にしない）。

## D5 読みの形（結果より前に決める）

主の行（2 段）・用量の筋（真の K = 3）・k = 5 と 15 ごとに:

- N1（陰性対照が形 1）: g* = 0 の 5 種すべてが形 1。
- 段 g が「形 2」: その段の 2 種すべてが形 2。段 g が「形 1」: 2 種すべてが形 1。
- 見分ける下限 D（k ごと）: 形 2 の段のうち最小で、それより大きい回した段もすべて形 2 のもの。無ければ「無し」。

Take-home の「読まない」への持ち込み（k = 15 を主に、k = 5 を添える）:

- 残す: k = 15 と k = 5 の両方で N1 が成り立ち、D = 1e-3。→「合成では、分解は埋めた 1e-3 以上の遷移の個人差を形 2 として返し、差 0 では形 1 を返した。実データの形 1 は、この作りでの 1e-3 以上の個人差と合わない」の趣旨を S9・S15 に足し、本文の「読まない」を残す。
- 弱める: k = 15 で N1 が成り立ち D がある（D > 1e-3、または k = 5 で N1 か D = 1e-3 が成り立たない）。→「形 1 は差 0 の合成と同じ形だが、D 未満の埋めた差でも（形 1 か形 3 が）出た。分解は D 未満の個人差が無いことを示さない」と限り、Take-home の「読まない」を「手順が返した量で、本人の上積みと分けて読めない」へ弱める。
- やめる: k = 15 で N1 が成り立たない、または k = 15 で D が無い。→ 分解を「読まない」の根拠に使わない。Take-home は「手順が返した量（at most about 1e-3）」だけを書き、上積みかどうかはこの分解では読めないと書く。

並べるだけ（判定に使わない）:

- 副の行（τ = 10^6）の形の数。構造の筋（真の K = 5）と分布の筋（17 人中 5 人だけに 3e-2）の形。分布の筋は埋めた書き手と埋めていない書き手を分けた a の中央値も。
- 合成の b の中央値と、実データの b（ar3 で +7.4e-4・mode の結果 1）。桁の比べは値だけで、読みに使わない。
- 最頻値が −∞ の書き手の人数（複製 × 構造）。

## V1 門（本計算の前・合成だけ）

| 門 | 通る条件 |
|---|---|
| P-HASH | D2 のハッシュがすべて一致（読み込みの時点で止める） |
| P-ZERO | 確率 0 のセルの無い母数で、mode の評価（`pred_logprob_zero` の平均）が `ml.Eval.ll` と 1e-12 以内で一致 |
| P-MODEW | 小さい合成（sens の selftest と同じ作りの P-RECOVER の形・g* = 0.1・k = 15）で、`mode` が w を除く共通の S̄ の最頻値の評価と一致し、全員の共通の S̄ の最頻値の評価とも、w を除く共通の母数の評価とも一致しない（書き手 8 人のうち少なくとも 1 人で違う） |
| P-NEGINF | 共通に無い記号の組を 1 人の評価にだけ入れた合成で、その書き手の mode が −∞（NaN でない）、a = +∞・b = −∞、主の集計の ±∞ の人数が手で数えた値と一致し、NaN が無い |
| P-AB | 有限の書き手ごとに a + b = c が 1e-12 以内 |
| P-PICK | 2 段の選びに、対象の書き手 w の値をでたらめに書き換えて渡しても w の選びが変わらない（sens の P-JOINTW と同じ・乱数 200 回） |

| 変異 | 赤になるべき門 |
|---|---|
| u1: 最頻値を全員の共通の S̄ から作る | P-MODEW |
| u2: 最頻値に w を除く共通の母数をそのまま使う | P-MODEW |
| u3: −∞ の書き手を集計の前に捨てる | P-NEGINF |
| u4: 確率 0 の扱いの無い評価（`pred_logprob`）を使う | P-NEGINF |
| u5: 書き手ごとの差でなく中央値どうしの差で a を作る | P-AB |

- 本計算の P-REPRO と P-SAME は、複製ごとに本計算の中で当てる（外れれば止める）。最初の複製（00）で外れたら、そこで止めて研究者に聞く。
