## 事前宣言する指標（8 個・これ以外を後から足さない）

前ラウンドの 6 指標を引き継ぎ、**発見 2（長ポーズは「計画」と「離席」に分解しないと使えない）**を
反映して M4 を帯域別に分解した 2 指標を追加する。`press == true` の `key` レコードのみを使う。

| # | 指標 | 定義 | 位置づけ |
|---|---|---|---|
| **M5** ★ | `bs_rate` | (backspace + delete) / press 総数 | ★★ **主指標**。低い＝**推敲の不在** |
| M1 | `keys_per_min` | 打鍵数 / セッション実測分 | 副次（RQ-F の連動確認に使う） |
| M6 | `enter_rate` | enter / press 総数 | 副次（RQ-F の連動確認に使う） |
| M2 | `iki_p50` | IKI の中央値 | 副次 |
| M3 | `iki_p90` | IKI の 90 パーセンタイル | 副次 |
| M4 | `long_pause_rate_10s` | IKI > 10,000ms の割合 | 副次（前ラウンドとの接続のため残す） |

- ⚠️ **IKI はセッション内の全打鍵から計算し、セッション境界を跨がない。**
- ⚠️ `press < 200` のセッションは前ラウンドと**同一基準で除外**する（除外数を報告）。

## 事前宣言する検出器（この定義を結果を見た後で変えない）

### D-1: 個人基準（leave-one-out ロバスト z）

被験者 p・指標 m・セッション s について:

```text
baseline(p, m, s) = { 被験者 p の有効セッションのうち s を除く全て }   ← ★ leave-one-out
med  = median( baseline )
scale = 1.4826 * MAD( baseline )
z_within(p, m, s) = ( value(s, m) - med ) / scale
```

- ★ **LOO は必須である**。対象セッション自身をベースラインに入れると、
  「その人の普段」が対象セッションに引きずられ、逸脱が構造的に過小評価される。
- **`scale == 0` の場合は z を計算しない**（`unscorable`）。フラグにも非フラグにも数えず、件数を報告する。
- **有効セッション数 < 5 の被験者はスコアしない**（LOO ベースラインが 3 点以下になるため）。
  該当被験者は報告のみ。

### D-2: フラグ規則（主・片側）

```text
out_of_scope_flag(s) := z_within(p, bs_rate, s) < -3.0
```

- ★ **片側**である。仮説は「**推敲の不在**が対象外作業の署名」であり、
  `bs_rate` が**高い**方向（過剰な打ち直し）は本仮説の対象ではない。
- 閾値 **−3.0** は前ラウンド（母集団基準 |z|>3.0）と**同じ値を意図的に流用**する。
  本実験で新たに調整しない。
- 副次 7 指標には両側 |z_within| > 3.0 を適用し、**記述としてのみ**報告する。

## 事前宣言する解析

### T-1（★ 主検定・**P013 を除外**・非循環）

**帰無仮説**: 被験者ラベルは `bs_rate` の**群構造**について情報を持たない
（＝セッションの `bs_rate` 値は被験者間で交換可能）。

**統計量**: 被験者内の「最大ギャップ」の平均。

```text
被験者 p の bs_rate を昇順に並べ v_1 ≤ … ≤ v_n
gap_p = max_i ( v_{i+1} - v_i )
G_p   = gap_p / scale_cohort            scale_cohort = 1.4826 * MAD( 全対象セッションの bs_rate )
S     = mean_p ( G_p )
```

- `scale_cohort` は**値の多重集合から決まる**ため並べ替えで不変であり、統計量は並べ替え間で比較可能。
- **並べ替えは被験者ラベルのみをシャッフルし、各被験者のセッション数を保存する**
  （最大ギャップは n に依存するため、n を保存しないと検定が壊れる）。
- 並べ替え **10,000 回**・seed は `SEED` に固定・**片側**（S が大きいほど「群に割れている」）・α = 0.05。
- **対象**: P010 / P011 / P012 / P014 の有効セッションのみ。**P013 は値の池からも除く。**

### T-2（サニティのみ・**循環しているので証拠に数えない**）

T-1 と同一手続きを **P013 を含めて**実行する。P013 が統計量を押し上げるはずだが、
それは**既知の事実の再確認にすぎない**。`significant` であっても RQ-D の答えにしない。

### 予測 P-1（操作化のサニティチェック）

D-1/D-2 を P013 に適用したとき、前ラウンド §4.5 の**群 X 側のセッションがフラグされる**。

> ⚠️ **成功しても新しい情報ではない**（同じデータから導いた規則である）。
> **失敗した場合は操作化が誤っている**ことを意味するので、その場合のみ情報を持つ。

### 予測 P-2（★ 本命・**P013 以外**への一般化）

凍結規則を P010 / P011 / P012 / P014 に適用したときのフラグ件数。
**これらの被験者のセッション単位 `bs_rate` は凍結時点で未見である。**

### 予測 P-3（RQ-F・機序の連動・**P013 以外**で評価）

`bs_rate`-low でフラグされたセッションは、同一セッションで
**`z_within(keys_per_min) > 0` かつ `z_within(enter_rate) < 0`** を示す
（速く打ち・改行せず・修正しない＝産出のみの署名）。

- 一致数 / フラグ数を報告する。
- ⚠️ **P013 での一致は循環である**（§4.5 で既にこの共変動を見ている）ため、サニティ扱いとする。

## 事前宣言する判定

| 結果 | 判定 | 次の行動 |
|---|---|---|
| **T-1 有意 かつ P-2 のフラグ ≥ 1** | ★ **within-person 検出器は P013 以外でも構造を捉える** | 対処案 ③ を **within-person 定義**で `§4.4 Phase A` に接続する設計へ進む。フラグ率を偽陽性負荷の初期見積りに使う |
| **T-1 有意でない かつ P-2 のフラグ = 0** | ★ **本コホートでは P013 以外に検出可能な逸脱は無い** | ③ の**機構は否定されない**が、**本データでは検証できない**。検証は Phase2 の**構造化較正**（対処案 ①）に持ち越す。**これも結論である** |
| **T-1 有意でない が P-2 のフラグ ≥ 1** | **単発の逸脱はあるが群構造は無い** | 検出器は「2 群への分離」ではなく「**単発の外れセッション**」を狙う設計にする（Phase A の robust quantile で足りる） |
| **P-2 のフラグが有効セッションの 20% 以上** | ⚠️ **閾値の偽陽性負荷が高すぎる** | 小 n の LOO ロバスト z では |z|>3 は運用に耐えない。Phase A 側の分位点基準で再定義する |

- ★ 上の 4 分岐は**排他ではない**（1 行目と 4 行目は同時に起こりうる）。その場合は**両方を報告する**。

## ★ 解釈の制限（事前に宣言する・最重要）

前ラウンドの 5 項目を**そのまま引き継ぎ**、本実験固有の 3 項目を足す。

1. **外れ値であること ≠ 対象外作業をしていたこと。** 示せるのは
   **「その人自身の普段と行動署名で区別できるか」まで**である。何をしていたかは content-free では原理的に分からない。
2. **特定の被験者が外れても、伝聞の裏づけにはならない。** 原因は他にいくらでもある
   （課題の難度・時間帯・端末・疲労・入力方式）。
3. **特定の被験者が外れなくても、伝聞の否定にはならない。** 検出力不足の可能性が残る。
4. **多重性**: 主指標は `bs_rate` の**片側 1 本**に限定した。副次 7 指標は記述であり判定に使わない。
5. **本実験の結果で `docs/` の確証トラック（GATE3 の原因診断・`§1.2` の信号の根拠）を書き換えない。**
6. ★ **導出集合 = 検定集合の問題**: `bs_rate` は P013 から選ばれた特徴である。
   **P013 を含む数値はすべて循環しており、証拠として引用しない。**
7. ★ **小 n**: LOO ベースラインは 4〜11 点しかない。MAD ベースのロバスト z において
   **|z|>3 は 0.27% の事象ではない**。したがって本実験は
   **「偶然期待件数」を二項近似で報告しない**（誤導するため）。判定は T-1 の並べ替え検定だけが担う。
8. ★ **本実験は検出力・偽陽性率を測っていない。** 外的な正解ラベルが 1 件（`P011-s01` の自己申告）しか
   存在しないため、ROC も PR も計算できない。**「検出器が動く」以上の主張をしない。**
