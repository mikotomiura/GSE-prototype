## 読みの形（条件 D5 をそのまま写す・結果の前に決めた）

「1/2」「1/10」は読みの言い方を決める区切りで、検定ではない。値は全記号の中央値。

- 部分 1（主のセルごと・hmm3 の 3 列）: 列 q ごとに、そのまま（o）と並べ替え（p）の対で、ΔD = D_o − D_p、G_o・G_p を見る。
  - 「消える」: 3 列とも ΔD > 0、G_o > 0、G_p < G_o / 2。
  - 「沿わない」: 3 列のどれかで ΔD > 0 かつ G_p ≥ G_o。
  - どちらでもない: 「割れる」。
- 部分 2（主のセルごと・そのままの列の hmm3 の 3 列）:
  - 「他の人でも勝つ」: 3 列とも S0 > 0 かつ S0 > G0 / 10。
  - 「本人に固有」: 3 列とも S0 ≤ 0 または S0 ≤ G0 / 10。
  - どちらでもない: 「割れる」。
- 形（主のセル 3 つのすべてで同じ形のときだけ、その形と書く。割れれば形 C）:
  - 形 A（仮説と合う）: 部分 1「消える」かつ部分 2「他の人でも勝つ」。
  - 形 A'（足りなさは効くが、人ごとの違いもある）: 部分 1「消える」かつ部分 2「本人に固有」。
  - 形 B（対抗の説明と合う）: 部分 1「沿わない」。
  - 形 C: どれでもない → 値を並べ、分けられないと書く。
- hmm6・hmm10・ar1〜ar3 の部分 1・部分 2 の値も同じ表に並べる（形の判定には hmm3 だけを使う。前の試験で上積みが大きかったのが hmm3 だから）。
- 並べ替えは、系列の中のゆっくりした頻度の変化も消す。D_p は 0 にならず、「1 次の依存とゆっくりした変化の両方が消えた」と読む。
- 部分 2 が「他の人でも勝つ」でも、原因として「共通の EM が悪い局所解にある」が残る。全員の共通の 10 開始点の 1 位と 2 位の差（診断）を並べて書く。
