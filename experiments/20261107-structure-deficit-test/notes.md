## 言えること・言えないこと

言えること（この 2 つのデータ・この 3 つの量子化の列・この 6 つの構造で）:
- 条件 D5 の読みの形を当てると、CoAuthor の主のセル 3 つはすべて形 B（対抗の説明と合う）、CS1 C5 k = 5 は形 C だった。
- 形 B は 10 記号の列の「沿わない」から来た。26 記号と 50 記号の列では、並べ替えで D がほぼ 0 になり、hmm3 の上積みは 1/2 未満（G_p / G_o = 0.30〜0.47）に縮んだ。ただし 0 にはならず、+0.06〜+0.10 が残った。
- 部分 2 は、すべての主のセル・列で「本人に固有」だった。他の人の τ = 0 の当てはめを w に当てると、どの書き手でも共通に負けた（S0 は −0.08〜−0.41）。
- 前の試験の notes の「hmm3 で本人の上積みが大きく、ar で小さいので、前回の読みの仮説と同じ向きである」は、この試験で次のように狭まる。仮説の後半「人ごとの違いではなく」は、部分 2 で支持されなかった（本人に固有）。仮説の前半「足りなさが原因」は、事前に決めた形では「沿わない」（形 B）で、26 記号と 50 記号の列に限れば上積みの半分以上が並べ替えで消えた。前の試験の notes は書き換えない。

言えないこと:
- 仮説が否定された・確かめられた、とは書かない。形の語は事前に決めた読みの言い方で、検定ではない。
- 部分 2 の S0 は、v の記録だけで τ = 0 で当てた解で作った（判断 11）。少ない記録で縮めない当てはめは他の人に移すと崩れやすいので、S0 が負であることには「本人の当てはめが本人の記録に合いすぎていた」という説明も残る。S0 と G0r は同じ土台だが、G（τ 他人）とは土台が違う。
- 並べ替えは 1 次の依存とゆっくりした頻度の変化の両方を消す。G_p が残った分がどちらによるかは、この試験では分けられない。
- ar1〜ar3 で並べ替えた後に G_p が大きくなったことは、形の判定に使っていない。読みを足さない。
- 結果を段 1 の候補の採否や ADR-047 の根拠にしない。EM の状態に名前を付けない。CS1 を日本語・IME・GSE の参加者へ広げない。
