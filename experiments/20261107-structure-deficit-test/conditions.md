## 問い

ml-improve の notes の読みの仮説「B で本人の EM が共通に勝っていたのは、3 状態の HMM が前の記号への強い依存を運べず、その不足を本人の当てはめが一部埋めていたため（人ごとの違いではなく、構造の足りなさを人ごとに補っていた）」を、2 つの部分に割って確かめる。

- 部分 1（足りなさが原因）: 同じ構造・同じ量子化の列のまま、前の記号への依存を消すと（系列の中で記号の順を並べ替える）、本人の上積みも消えるか。母数の数は変わらないので、「母数が多い構造ほど本人の記録では推せず、上積みが小さく見えるだけ」という対抗の説明と見分けられる。
- 部分 2（人ごとの違いではない）: 他の人の本人の当てはめを w に当てても、共通に勝つか。

## D4 量（新しい・書き手 w ごと・1 記号あたりの対数尤度の差）

- G(s) = 本人_w(s, τ 他人) − 共通_w(s)。共通は w を除く共通（同じ構造・同じ組）。
- G0(s) = 本人_w(s, τ = 0) − 共通_w(s)。
- D(s) = r1_w − 共通_w(s)（足りなさ）。r1 は w の学習の記号の 1 次のマルコフ（同じ組・同じ k）。選びの段を持たない。
- S0(s)（他人の当てはめ）= 他人_{v→w}(s, τ = 0) − 共通_w(s) の、v についての中央値。v は w と同じパネル・同じ k の他の書き手。他人_{v→w} は、v の τ = 0 の本人の当てはめ（v の学習の記号だけ・共通へ寄せない）の母数で w の評価の単位を予測した値。新しい当てはめはしない。
  - τ = 0 に限る理由（判断 9）: τ > 0 の v の当てはめは v を除く共通へ寄せられ、その共通には w の学習の記号が入る。S に w の記録が漏れないよう、共通へ寄せない τ = 0 だけを使う。比べる相手も G0 にする。
- 共通 − r1（tau-extend と同じ）も出す。
- どれも書き手ごとの差で、中央値どうしの差ではない。集計は tau-extend の D5 と同じ（中央値・四分位・良い側の割合・区間・人数・伏せ）。
- 記述（判定に使わない）: 各セル・各組で、6 構造の D の中央値と G の中央値の Kendall の順位の相関。

## D5 読みの形（判断 8・結果を見る前に決めた・閾値と検定は置かない）

「1/2」「1/10」は読みの言い方を決める区切りで、検定ではない。値は全記号の中央値。

- 部分 1（主のセルごと・hmm3 の 3 列）: 列 q ごとに、そのまま（o）と並べ替え（p）の対で、ΔD = D_o − D_p、G_o・G_p を見る。
  - 「消える」: 3 列とも ΔD > 0、G_o > 0、G_p < G_o / 2。
  - 「沿わない」: 3 列のどれかで ΔD > 0 かつ G_p ≥ G_o。
  - どちらでもない: 「割れる」。
- 部分 2（主のセルごと・そのままの列の hmm3 の 3 列）:
  - 「他の人でも勝つ」: 3 列とも S0 > 0 かつ S0 > G0 / 10。
  - 「本人に固有」: 3 列とも S0 ≤ 0 または S0 ≤ G0 / 10。
  - どちらでもない: 「割れる」。
- 形（主のセル 3 つのすべてで同じ形のときだけ、その形と書く。割れれば形 C）:
  - 形 A（仮説と合う）: 部分 1「消える」かつ部分 2「他の人でも勝つ」。
  - 形 A'（足りなさは効くが、人ごとの違いもある）: 部分 1「消える」かつ部分 2「本人に固有」。
  - 形 B（対抗の説明と合う）: 部分 1「沿わない」。
  - 形 C: どれでもない → 値を並べ、分けられないと書く。
- hmm6・hmm10・ar1〜ar3 の部分 1・部分 2 の値も同じ表に並べる（形の判定には hmm3 だけを使う。前の試験で上積みが大きかったのが hmm3 だから）。
- 並べ替えは、系列の中のゆっくりした頻度の変化も消す。D_p は 0 にならず、「1 次の依存とゆっくりした変化の両方が消えた」と読む。
- 部分 2 が「他の人でも勝つ」でも、原因として「共通の EM が悪い局所解にある」が残る。全員の共通の 10 開始点の 1 位と 2 位の差（診断）を並べて書く。
