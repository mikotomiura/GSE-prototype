読みの形:
- 本人 − 共通（同じ構造）が τ を上げるにつれ 0 へ近づき、どの有限の τ でも正にならないなら「格子の端のせいではなく、本人に固有の構造が、この量子化の列・この構造の族では小さい」と書く。

読み:
- 但し書き（結果を見た後に気づいた・レビューで範囲を広げた・末尾に書く）: 有限の τ の事後の最頻値は normalize(S + 基の擬似度数 + τ · S̄) である（`hmm2.py` `make_prior`・`ml.py` の S̄ は w を除く共通の期待度数を記号の数で割ったもの）。そのため τ が大きいほど、本人の母数は normalize(S̄)（基の擬似度数を抜いた共通）へ近づく。これは τ = ∞ に置いた w を除く共通の母数そのものとは違う点である。合成の P-TAU（`selftest.json`）では、A・C の最大の差は次のとおりだった。τ = 10^5 で共通まで 0.0068、最頻値まで 0.0068。τ = 3 × 10^5 で共通まで 0.0057、最頻値まで 0.0023。τ = 10^6 で共通まで 0.0060、最頻値まで 0.0007。共通と最頻値の差は 0.0064 である。つまり、このずれは 10^6 だけでなく、10^5 以上の有限の τ に入る。CoAuthor の ar では、学習の記号が少なく本人の重みがほぼ 0 の k = 1（624 記号）でも、10^6 で +2.0e-4 〜 +5.4e-4 が出る。Δ も 300,000 で負、10^6 で正、∞ で 0 と単調でない。したがって、大きい τ での +1e-3 前後までの「本人 − 共通」は、本人の記録の寄与と、最頻値と共通の母数の違いとを、この計算では分けられない。CS1 では同じ差が負で、ずれは逆向きに効いている可能性がある。この但し書きは両方の向きに掛ける。
- CS1 の ar2・ar3: 本人 − 共通は τ を上げるにつれ 0 へ近づき、どの有限の τ でも正にならない（k = 1〜5 のすべて。10^6 でも −2.4e-4 〜 −1.8e-5）。読みの形では「格子の端のせいではなく、本人に固有の構造が、この量子化の列・この構造の族では小さい」に当たる。ただし大きい τ での負の差は但し書きのずれと同じ桁で、「小さい」までしか言えない（0 とは言えない）。CS1 の ar1 は k = 5 だけ有限の τ で正になる。τ 他人の行で +3.4e-4 だが、良い側の割合は 0.52・四分位は [−0.002, 0.002] で、約半数は負である。
- CoAuthor の ar1: 学習の記号が多い所で、格子の中の τ で同じ構造の共通より良くなる。大きさ（τ 他人の行の中央値）と学習の記号の中央値は次のとおり。P15 は k = 8 で +3.8e-4（5,125 記号）、k = 12 で +8.8e-4（7,850）、k = 15 で +0.002（9,673）。P30 は k = 20 で +0.003（12,786）、k = 30 で +0.005（19,427）。τ 固定の行でいちばん大きいのは P30 の k = 30・τ = 10^4 で +0.006。但し書きのずれの幅（+1e-3 前後）を明らかに超え、「本人に固有の上積みがある」と書けるのは P30 の k = 20・30（+0.003・+0.005）である。P15 の k = 15（+0.002）は境目。ほかのセルは、本人の寄与とは分けられない。
