## 結果 1 —— 問い (a): 上の端への張り付きは解けたか

|---|---|---|---|---|

読みの形（結果を見る前に決めた）:
- 人数の表をそのまま書く。「多くが」「ほとんど」と書くときは人数を添える。
- ∞ を選んだ人が多い構造・パネルは「他人の基準では、本人の当てはめは w を除く共通そのものに届かない。前回の 10,000 への張り付きは、格子の上の端の狭さではなく、共通への寄せきりがいちばん良いことを示していた」と読む。
- 格子の中（100〜300,000）を選んだ人が多い構造・パネルは「前回の張り付きは格子の狭さで、本人と共通の間に良い点がある」と読む。その τ の値は、この構造・この量子化の列での値としてだけ書く。
- 上の有限の端（10^6）を選んだ人が多い構造・パネルは「まだ張り付いている」と書き、τ = 10^6 と τ = ∞ の Δ の差（τ 固定 9 行の表）を並べる。差が小数 3 桁で 0 なら「10^6 と ∞ は実質同じ点」と書く。

読みの形:

## 結果 3 —— 問い (c): 2 段の組み方で、本人の上積みは k とともにどう変わるか

見る表: 「2 段の行」（2 段（他人）・2 段（構造は他人・τ は本人 CV））と、学習・評価の記号の数の表。

| データ・パネル | k | 学習の記号（中央値） | 2 段（他人）: 本人 − r1 / 本人 − 同じ構造の共通 | 選ばれた構造 | 選ばれた τ | 2 段（構造は他人・τ は本人 CV） |
|---|---|---|---|---|---|---|
| （結果の後） | | | | | | |

読みの形:
- 本人の上積みは、2 段の行の「本人 − 同じ構造の共通」で読む（相手は書き手ごとに選ばれた構造の w を除く共通・`ml.py` の `em_rows`。τ = ∞ が選ばれた人では 0）。k が増えると上積みが増えるか、0 のままかを、k の列に沿ってそのまま書く。
- 「記録が多い人だけ本人へ動かす」の形は、2 段（構造は他人・τ は本人 CV）の行で、k ≥ 3 の選ばれた τ のうち ∞ でない人数として書く。その人たちの上積みが 2 段（他人）より良いかを、Δ の中央値と良い側の割合で書く。
- 前回の読みの仮説（B で本人が勝っていたのは構造の足りなさの補い）への材料として、hmm3 を固定した行（τ 他人）と 2 段の行を並べる。hmm3 で本人の上積みが大きく、ar で小さいなら「仮説と同じ向き」とだけ書き、仮説が確かめられたとは書かない（構造の族は 2 つだけ・量子化の列は 1 つだけ）。
- 選ばれた構造の人数は、本人の値を選びに入れない（P-JOINT）ので、構造の良し悪しを他人の基準で決めた結果として読む。
