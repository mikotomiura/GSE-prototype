5. ⚠️★★ **ADHD への言及は設計目標にしない**（S3-D16）—— n=1 の主観であり、

### 3.4 ★ 変調スペクトル（Chrome 151 / OfflineAudioContext 400 s @ 8 kHz / Hann 窓）

**24 通り（基音 4 × 減衰則 3 × ゆらぎ 2）すべてで PASS。最悪でも −192.6 dB**（判定 −60 dB）。

代表値（基音 55 Hz / 1/n² ×8）:

| 測定 | ゆらぎ 無 | ゆらぎ 有 | 逆検査（4 Hz 注入） |
|---|---|---|---|
| 包絡 4.0 Hz | −inf dB | −204.2 dB | ★ **−13.0 dB → FAIL** |
| 包絡 0.005 Hz（陽性対照） | — | ★ **−24.1 dB** | — |
| 包絡 0.0031 Hz（陽性対照） | — | ★ **−23.4 dB** | — |
| 実音声 f0±4 Hz（側帯波） | −197.2 dB | −200.5 dB | ★ **−19.0 dB → FAIL** |

★★ **陽性対照が効いているので「−inf は測定が死んでいるからではない」と言える** ——
ゆらぎを入れると **0.005 / 0.0031 Hz にちゃんと出る**（−24 dB 台）のに、
**同じ測定が 4 Hz では −204 dB を返す。** 測っている計器は生きている。

### 3.5 ⚠️★★★ 検算そのものの欠陥を 2 件、実測で見つけて直した

> ★ **どちらも「緑だった」ものが実は測れていなかった。逆検査が無ければ気づけなかった。**

1. **実音声の検査が変調を原理的に検出できていなかった。**
   当初 **実音声の 4 Hz の線**を見ていたが、**55 Hz の搬送波を 4 Hz で振幅変調しても
   エネルギーが乗るのは 4 Hz ではなく側帯波 51 / 59 Hz** である。
   → 逆検査で 4 Hz を注入しても **−90 dB で PASS したまま**だった（実測）。
   **★ 側帯波 f0±f を見る形に直したところ、同じ注入で −19.0 dB → FAIL になった。**
2. ★★ **候補を切り替えると「鳴らし直し」が走っていた**（倍音の本数が変わる場合とゆらぎの有無）。
   フェードアウト→フェードインは **オンセットそのもの**であり、
   ★ **`spec` §2 が禁じているものを、自分の UI 操作で作りに行っていた。**
   → **常に最大構成（倍音 8 本・LFO 全レート）で組み、使わないものはゲイン 0** にする形へ変更。
     どの軸も**連続ランプだけで移れる**ようになった。
   ★ 実測で副作用が無いことを確認: 未使用側がゲイン 0 のとき包絡 4 Hz は **−inf dB のまま**
     （`low_only` = 倍音 3 本でも、`drift=none` = LFO 深さ 0 でも変わらない）。
3. **参考線 20 Hz が `+31.7 dB` というありえない値を出していた。**
   包絡を 400 分の 1 に間引いていた（包絡レート 20 Hz）ため、
   **20 Hz はブロック平均の零点にあたり、sinc 補正がほぼ 0 で割っていた**。70 Hz は Nyquist 超で測れていない。
   → **間引きを 40 分の 1（包絡レート 200 Hz）に変更**し、
   **補正が信用できない周波数には数字を出さず「測定不能」と書く**ようにした。
   ⚠️ ★ **「参考値だから害が無い」ではない。読んだ人はその数字を測定結果として受け取る。**

### 3.6 ブラウザ実地（`browser-verification`）

| 確認項目 | 結果 |
|---|---|
| 設定が読める / 既定が spec 準拠（drift=none・gap=carry） | ★ **実測で確認** |
| 外部リソース読み込み | ★ **0 件**（`script[src]` / `link[href]` / `img` / `iframe` すべて空） |
| 停止ボタン・音量スライダの **DOM 実在** | ★ **実測で確認** |
| ★ **停止・音量が実際に効くこと（実クリック）** | ⚠️ **未検証**（§5 参照） |
| 自己検算 / 逆検査 | ★ **実測で確認**（3.4 / 3.5） |

★ **実地確認が実装欠陥を 1 件見つけた** —— `play()` が **`await ctx.resume()` を無期限に待って

2. **10 分の連続再生は未実施。** 検算は 400 s のオフラインレンダであって、実時間 10 分ではない。
   → ★ **メモリが増え続けないこと・位相が飛ばないことは未確認。**
