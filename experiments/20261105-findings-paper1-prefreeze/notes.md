## 計算 1: 幅の換算（F3）

閾値 = 書き手ごとの対照の候補（2〜30 秒の休止）の 90 分位。休止が 2 秒に達した時点で u の信号が閾値を超えたら発火。

| データ・信号 | 仮の AUC | 停滞の当たり（全員の比） | 対照の超過（全員の比） | 発火 / 時（書き手の中央値・四分位） | 発火のうち停滞の休止 |
|---|---|---|---|---|---|
| KLiCKe `d_p_stuck` | 0.55 | 0.156 | 0.093 | 20.3（14.6〜25.4） | 0.136 |
| | 0.50 | 0.149 | 0.093 | 20.1 | 0.133 |
| KLiCKe `d_ewma_x` | 0.55 | 0.140 | 0.093 | 19.2（14.4〜24.3） | 0.114 |
| | 0.50 | 0.116 | 0.093 | 18.9 | 0.103 |
| CS1 出来事なし `d_p_stuck` | 0.55 | 0.086 | 0.099 | 10.0（7.9〜12.6） | 0.052 |
| | 0.50 | 0.086 | 0.099 | 10.0 | 0.052 |
| CS1 出来事なし `d_ewma_x` | 0.55 | 0.122 | 0.099 | 10.0（7.9〜12.6） | 0.062 |
| | 0.50 | 0.091 | 0.099 | 9.9 | 0.051 |

- 参考: 等分散の正規分布で AUC 0.55 なら、誤発火 10% の閾値での当たりは 0.135。
- 読み: AUC を 0.55 まで上げても、閾値の契機の発火の 86〜95% は停滞にならない休止の上に落ち、AUC 0.50 との差は発火のうち停滞の割合で 0〜1.1 ポイントにとどまる。KLiCKe の実の信号（0.515・0.521）はこの間にある。
- AUC 0.50 でも当たりが超過を上回る（KLiCKe）のは、AUC が対を合わせた比べ（揃えた対照）で、閾値は揃えない候補の全部から作るため。当たり − 超過の差を AUC の大きさの換算に読まない。
- `d_p_stuck` は値が 0 のごく近くに集まる。KLiCKe では停滞の値に 0.00002 を足すと AUC が 0.515 から 0.55 になる（換算の仮の信号は、その集まり方を保ったまま作っている）。
