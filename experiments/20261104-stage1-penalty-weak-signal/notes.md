## 3 何が起きたか

### 3.1 見込みと逆だった

研究者に読みの規則を問うときに、私は「信号が弱いと罰の縮みが相対的に効き、傾きは 1 より大きくなる」と書いた。結果は逆で、信号が弱いほど傾きは 1 より小さくなった（予測の幅が広すぎる）。解釈（表が直接示すことではない）: 弱い信号では、推定した係数のうち真の信号の分が減り、雑音の分は件数で決まるので減らない。罰が同じなら、予測の広がりに占める雑音の割合が増え、傾きが下がる。この誤りは規則を選ぶ問いの説明に入っていた（規則そのものの数値の範囲は変わらない）。

### 3.2 傾きが 1 に最も近い τ の格子点は、倍率と同じ刻みで動いた（記述・結果を見た後に足した）

n ≥ 50 の 18 セルで、傾きの中央値が 1 に最も近い固定の τ（|log| で比べる）は、倍率 1 で 18 セルとも τ = 0.5、0.5 倍で 18 セルとも τ = 0.25、0.25 倍で 18 セルとも τ = 0.125 だった。τ の格子も倍率も 2 倍刻みなので、分かるのは格子の 1 目の中までで、比例を示したわけではない。解釈としては、τ は係数の大きさの事前の幅なので、信号が半分になるとちょうど良い τ も小さくなる、と読める。

固定の τ のうち、3 倍率 × n ≥ 50 の 54 セルで傾きの中央値が 1 から最も外れない（|log| の最大が最も小さい）のは τ = 0.25（0.228〜1.957・|log| の最大 1.478）で、τ = 0.125（0.579〜5.772・1.753）、τ = 0.5（0.098〜0.977・2.322）が続く。この順位は、選んだ 3 つの倍率の範囲に依る。

### 3.3 対数損失の後悔（記述）

信号ありの 36 セルの後悔の平均の最大:

| 案 | 1 倍 | 0.5 倍 | 0.25 倍 |
|---|---|---|---|
| 案 A（τ = 0.25） | 0.0116 | 0.0086 | 0.0086 |
| 案 B（τ = 0.5） | 0.0297 | 0.0437 | 0.0497 |
| 案 C′ | 0.0116 | 0.0086 | 0.0086 |
| 前向きの CV | 0.3784 | 0.2972 | 0.3448 |
| 1-SE | 0.2984 | 0.1824 | 0.2360 |

最大は n = 10 のセルで出る。固定の τ ごとの最大（tables.md の記述の節）では、倍率ごとに最も小さいのは 1 倍で τ = 0.25（0.0116）、0.5 倍で τ = 0.125（0.0052）、0.25 倍で τ = 0.125（0.0027・切片だけの 0.0028 とほぼ同じ）。3 倍率を通した最大で最も小さいのは τ = 0.25（0.0116）で、τ = 0.125（0.0298）・τ = 0.5（0.0497）・切片だけ（0.0603）が続く。n ≥ 50 に限ると、1 倍では B が最も小さく（0.0015〜0.0052）、0.25 倍では 1-SE（0.0014〜0.0087）と A（0.0021〜0.0075）が B（0.0090〜0.0280）より小さい。

### 3.4 CV は信号の強さに合わせて動くが、切片だけを多く選ぶ（記述）

n ≥ 50 で 1-SE が切片だけ（τ = 0）を選んだ反復の割合は、1 倍 0.559・0.5 倍 0.818・0.25 倍 0.890（前向きの CV は 0.151・0.417・0.544）。切片だけのモデルは予測が一定なので傾きが無く、表の CV の傾きの中央値はそれを抜いた残りの反復の値である。信号が弱いほど切片だけを選ぶのは、信号を見分けられないときの振る舞いとして筋が通る。

## 4 S1-E8 と S1-E3 への含み（研究者が決める）

- 固定の τ の較正の傾きは、較正の良し悪しと同時に「真の信号の強さが τ の想定と合っているか」を測っている。どの固定の τ も、3 つの強さすべてで傾きを [0.8, 1.25] に入れられない（3.2）。
- 案 B を保つ場合: 信号が C ≈ 0.7 なら傾きは 1 に近い。C ≈ 0.62 以下では傾きが 0.1〜0.6 に下がり、S1-E3 の傾きの判定で落ちる（予測が広すぎるモデルを昇格させない側に倒れる）。
- τ = 0.25（案 A・前の C4 の規則の答え）に戻す場合: 3 つの強さを通した最大で見ると、傾きの外れも対数損失の後悔も固定の τ の中で最も小さい（強さごとに見ると、0.5 倍・0.25 倍の後悔は τ = 0.125 の方が小さい）。代わりに C ≈ 0.7 では傾きが 1.4〜2.0（予測が狭すぎる）になる。
- どちらでも、S1-E3 の傾きの許容は、罰の縮みと信号の強さの両方で 1 から動くことを前提に決める必要がある（前の notes §6 の 2 つ目の問い）。
