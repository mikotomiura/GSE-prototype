## ★ 実測の経過

### 2026-09-03/04 — macOS `with-gse` を開始

| 項目 | 値 |
|---|---|
| 開始 | 2026-09-04 01:20 JST（epoch 1788452403） |
| 条件 | ★ **AC 接続**・GSE は既に **4 時間 15 分**稼働していた状態から計測開始 |

⚠️★ **すでに 4 時間動いていた状態から測り始めている。** ★ 起動直後の山（孤児回収の走査を含む）は
**入っていない**。⚠️ 「起動コスト」ではなく「**定常状態のコスト**」を測っていると読むこと。

### ⚠️★★★ 計測中に観測された既存の欠陥 —— **フックの starvation**

★ 同じセッション中に `gse-app.log` へ出た:

```
ERROR keyboard hook may be dead: the system saw input but the hook was not called
      (keystrokes may NOT be recorded) starved_ms=30088
INFO  keyboard hook is delivering events again
```

⚠️ これは memory `macos-tap-idle-away-probe-bug` の **macOS CGEventTap 失効**である。
★ **本実験の欠陥ではない**が、⚠️ **数週間回す O1 で実際に起きることの実測**なので記録する。
→ ★ 回復はしている（`delivering events again`）。⚠️ **失効中の打鍵は記録されていない。**
