# 入力データの固定 — experiments/20260903-o1-runtime-cost

`reproducibility-discipline` ルール 3。

⚠️★★★ **本実験は gse-dataset の NDJSON を入力に取らない。**
★ 測るのは「**動いているアプリそのもの**」であり、入力は**研究者本人の実作業**である。

→ ★ したがって固定すべきは NDJSON の hash ではなく **測定条件**である:

| 固定するもの | どこに書くか |
|---|---|
| 測定の開始 / 終了時刻 | `results/<run>/meta.json`（★ `run.sh` が自動で書く） |
| 測定中に何をしていたか（★ 作業の種類・粗く） | `notes.md`（⚠️ **アプリ名や文書名は書かない** —— `data-privacy` ルール 7） |
| 生成された NDJSON の**バイト数のみ** | `results/<run>/ndjson-size.tsv`（⚠️★★★ **中身は 1 行も読まない・コピーしない**） |

## ⚠️★★★ プライバシー（★ ここを外さない）

- ⚠️ **NDJSON そのものを `results/` に置かない**（★ `.gitignore` されていても置かない）
- ⚠️ **ウィンドウタイトル / アプリ名 / プロセス一覧を記録しない**（★ `data-privacy` ルール 7 の擬似識別子）
- ★ 記録してよいのは **GSE 自身のプロセスの数値**（CPU% / RSS / スレッド数）と
  **バッテリー残量の百分率**、**ファイルのバイト数**だけである
