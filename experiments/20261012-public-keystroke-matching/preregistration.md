## 問い

1. 公開の打鍵の記録の加工（公開の現場の加工と候補の加工）は、記録から本文を照合する攻撃に対して、どこまで効くか。正答率を、偶然の水準 1/N と、記録の全長だけを使う攻撃者 A0 の正答率と並べて示す（判断 18）。
2. 効き目は、残す列（位置・語数・区切り・時刻）と攻撃者でどう変わるか。
3. 加工の後に、作文研究の標準の指標はどこまで計算でき、加工の前の値とどこまで一致するか（判断 11・19）。
4. 日本語 IME の翻訳の記録（ENJA15）でも、同じ型の照合が偶然の水準と A0 を上回るか（判断 5・12）。

「加工が効く」とは書かず、「この攻撃者に対して、この N で、正答率が 1/N の何倍か・A0 からどれだけ上か」と書く。

## 脅威モデル（判断 23）

- **場面**: 打鍵の記録を公開する者（研究者・教育データの提供者・コンペの主催者）が、本文を隠す目的で記録に加工を掛けて公開する（[V265] の `q` のマスクが実例）。一方、本文そのものは別の経路で存在する: 同じ作文が別の公開物で本文ごと出ている、教員・採点者・プラットフォームが本文を持つ、作文が授業や投稿で公開されている。
- **攻撃者の知識**: 加工した記録 1 本と、正解を含む候補の本文 N 本（同じ課題の作文）。加工の手順を知る（Kerckhoffs・判断 16）。同じ型の公開データ（加工の前の記録と本文の組）を学習に使える（本実験では評価用と別の書き手）。本人の過去の文章・言語モデルでの本文の生成・複数の公開物の結び付けは使わない。Wagner & Eckhoff の分類では、受動・外部・静的・事前の知識あり（候補の集合と学習用のデータ）。
- **目的と害**: (a) 隠された本文の中身を知る（加工の目的が破られる）。(b) 記録とそこに付いた列（時刻・推敲の過程・得点・他の列）を、本文とその書き手に結び付ける（本文の書き手が分かる場面では、記録の過程が書き手に結び付く）。本実験が測るのは (a)(b) の前提となる「記録 ↔ 本文」の結び付きで、書き手の身元の特定は行わない。
- **N と場面**: N = 10（候補が絞れている: 小さな授業・提出の一覧）、100（学年・講座）、1,000（同じ課題の大きなコーパス）。
- **閉じた世界**: 正解が必ず候補に入る。開いた世界は診断で見る（正解を候補から抜いたときの最小費用の分布との分けやすさ）。

## 揃え（A1・A1'・A2・A3 に共通）

- 1 つの組は「記録の p 区間 ↔ 本文の q 区間」で、(p, q) は (1,1)・(2,1)・(1,2)・(3,1)・(1,3) の 5 通り（`align.py` の `ORDER` と同じ・判断 23）。費用は |記録の和 − 本文の和| ＋ λ ×（p − 1 ＋ q − 1）、λ = 8（調整しない）。
- 同じ費用の経路は `ORDER` の先の組を選び、終点が選べるときは本文の位置の小さい方。
- 終点: 窓の照合は記録の最後まで使い、本文は途中で終わってよい。全文の照合は記録と本文の両方を最後まで使う（終点を (記録の区間の数, 本文の区間の数) に固定・判断 23）。
- 道が無い候補の費用は ∞（選ばれない）。全候補が ∞ なら全候補の同点（1/N）。道が無かった数を形 × 攻撃者ごとに報告する。

| 抽選の回数 | 1 つの記録に N = 10・100 は 20 回、N = 1,000 は 5 回 |
| 範囲 | 全文と、窓（連続した k 区間・k = 5・10・20・50） |
| 窓の正解 | R0 の記録を再生して、各押下が最終稿のどの文字として残ったか（真の対応）を作る。記録の窓の先頭の区間で残った文字が最も多く属する本文の語から k 区間を正解の窓とする。真の対応は R0 で一度だけ作り、どの形・どの攻撃者でも同じ正解を使う（判断 23）。先頭の区間の文字が 1 つも残っていない窓と、本文の終わりを越える窓は使わない |
| 窓のおとり | おとりの本文の中で有効な長さ k の窓から一様に 1 つ |
| 窓の始まり | 記録 1 本につき、有効な始まりから一様に 5 つ |
| 同点 | 正解を含む m 個の同点は 1/m |
| 足りないとき | 課題の有効な書き手が N 人未満なら、その課題のその N のセルは出さず、数を報告する。長さ k の有効な窓が無い記録は、その k のセルから除き、数を報告する |
| 区間（信頼区間） | 書き手を単位にした百分位のブートストラップ 2,000 回・95%。すべてのセルで同じ抽出。課題で層別して抽出する |
| 乱数 | `seed = int.from_bytes(sha256(f"{SEED}:{use}:{prompt}:{writer}:{N}:{k}:{draw}".encode()).digest()[:8], "big")` を `numpy.random.default_rng` に渡す。使わない欄は空文字。`use` は `split`・`eval_sample`・`decoys`・`window_start`・`r5_sub`・`r6_perm`・`r7_drop`・`bootstrap`・`enja_decoys` |

## 報告する量

- **主な量**: 各形 × 攻撃者 × N × 範囲の正答率と区間、1/N に対する倍率、A0 からの上乗せ（正答率の差と区間）。
- **最も強い攻撃者**: 各形で、適応する攻撃者（A0〜A3・A1'・A2-b のうちその形で使えるもの）の最大。区間はブートストラップの各回の中で最大を取り直して作り、各回で選ばれた攻撃者の割合も報告する。A4 は別の行に出す。
- **列の対比**（判断 18・監査の指摘）: 最も強い攻撃者の正答率の差と区間を、R2 − R3（位置と語数）・R3 − R3-u（区切り）・R3 − R3-t(w)（時刻）・R1 − R3（マスクと縮約）で出す。
- **副次**: 正解の順位（top-5 の正答率・逆順位の平均）、書き手ごとの正答率の分布（10・50・90 パーセンタイル）、λ = 4・16 の A2（N = 1,000・全文）、開いた世界の診断（最も強い攻撃者の、正解を含む候補の最小費用と正解を抜いた候補の最小費用の分けやすさの AUC・N = 1,000・全文）、組み立て直しの一致・不一致で分けた正答率、道が無かった数。

## 診断

- 陰性対照: 記録を同じ課題の別の書き手の記録に入れ替えて同じ照合をする（正解の本文はそのまま）。1/N に近いことを期待する。
- 窓の正解の偏り: 正解の窓の位置での A2 の揃えの費用と、記録の全体の揃えの費用の分布を並べる（正解の窓が揃えの都合のよい位置に偏っていないかを見る）。

## ENJA15 の節（判断 5・12）

- 形: R0j（加工なし）・R3j（種類: ローマ字の英字・変換と確定のキー・`[Back]`・句読点の確定・Enter・移動・その他）・R3j-t(w)（keydown の時刻を丸める・w = 10・100・1,000 ms）・R4(w)。keyup が無いので保持時間は使わない。
- 攻撃者: A0 と A2。A1・A1'・A3・A4 は行わない（英語のモデルと最終稿の組み立て直しのため）。
- おとり: 同じ原文の他の訳者の訳文の全部（N は 10 と全員）。訳者が 10 人未満の原文は N = 10 のセルを出さず、数を報告する。同じ訳文は同点として 1/m。訳者の識別は問わない。
- 問い 4 に答える量: 全文・N = 全員での A2 の正答率と、1/N・A0 との比較（原文ごとと、原文の平均）。
- IME の経路の検査（取得の後・本計算の前）: 未確定の文字列の更新・変換の取り消し・確定を含む記録で、R3j の後のどの列（`IMEtext`・`Value` など）にも文字列が残らないことを確かめる。残れば形を直し、逸脱に書く。

## 記録の扱い

## 倫理の考察（論文の節の材料）

- 研究者は研究機関に所属せず、審査を受けられる委員会が無い（判断 7）。外部の委員会に出していないことと、その理由を書く。
- KLiCKe の論文と Tian の博士論文 [V274] には、倫理審査の承認と公開への同意の記載が無い（同意は目的と手順を示したとだけ書かれている）。著者に問い合わせた（判断 4）。返事の内容を書く。
- Menlo Report の原則に照らす: 人の尊重（参加者が同意した目的は作文研究で、本研究は公開の記録の保護の評価である。新しい収集をせず、個人を識別せず、人口統計を取得せず、集計だけを出す）・善行（結果は公開する者が加工を選ぶ材料になり、参加者を含む書き手の保護に資する。害は記録 ↔ 本文の結び付きの手順の公開）・正義・法と公益の尊重（データの利用条件 [V273] に従い、出典を示す）。
- Kaggle の記録と KLiCKe を突き合わせない（判断 3）。

## Open science（論文の節の材料）

- 公開する: 事前登録（Zenodo）・加工と攻撃者と集計のコード・集計の結果。
- 公開しない: データ（各公開元から取る）・個々の書き手の結果。
- 攻撃のコードの公開の範囲は論文の段で研究者が決める。候補: (1) すべて公開、(2) 加工と評価のコードは公開し、公開の記録（例: [V265]）に直接当てるための読み込みの部分は公開しない、(3) 申し出に応じて共有。

## 結論に使わないこと

- 安全の証明・照合の危険の上限とは書かない（ここで試した攻撃者・閉じた世界に限る）。
- 合格・不合格の判定はしない。
- 書き手の属性による違いは言わない（人口統計を取得しない）。
- 本文の照合の結果を、書き手の身元の特定の結果として書かない。
- ENJA15 の結果を、日本語の自由作文や日本語 IME の記録の一般に広げない。KLiCKe との差を言語や IME のせいにしない（課題・入力の方式・言語が同時に違う）。
- 照合という攻撃そのものを新しいと書かない（[V266] [V267] [V268] [V269]）。新しいのは公開の記録の加工の評価である。
