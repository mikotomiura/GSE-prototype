# 倫理審査の経路と投稿先の規程（費用ゼロ・所属に委員会が無い場合）

人を対象とする研究を、研究者の制約の下でどう審査してもらい、どの誌に出せるかを、経路ごとと誌ごとに表にしたもの。照合の論文（PoPETs 候補・ADR-039 D1 の 2026-10-12 の注）、BRM の IME 論文の 2 本目（ADR-039）、AI 疲労の核 2（`.steering/20261015-ai-fatigue-core2-discriminant/`）で共通に使う。

- 作成 2026-10-15。規程は改訂されうるので、投稿や申請の前に読み直す。取得日と取得の方法は `docs/references.md` の各行にある。
- 法的な判断はしていない。指針や法令に当たるかの記述は Claude の読み。
- 研究者の条件（2026-10-15 の確認・ADR-039 D1 の注）: 審査にも謝礼にも掲載料にも費用を出せない。ZEN大学の所属はあるが、人を対象とする研究の審査委員会があるかは未確認（問い合わせ B は送っていない）。
- この表は経路と規程の事実をまとめるだけで、どの経路を使うかは研究者が決める。

日本の指針について（Claude の読み・法的判断ではない）: 「人を対象とする生命科学・医学系研究に関する倫理指針」の対象は、健康や傷病の理解・予防・診断・治療に資する知識などを目的とする研究である [V270]。匿名の心理の質問紙（疲労・燃え尽き・性格の自己評価）は、目的しだいで指針の対象外になりうる。ただし、指針の対象外であることは、誌の求める承認があることを意味しない（ADR-039 の注と同じ）。

## 3. 読み取れること（Claude の見立て）

- 新しく集める研究に、費用ゼロで、委員会の承認なしに出せると規程から言える誌は見つからなかった。説明で足りうると書く誌は *Behaviour & Information Technology*（承認が要らない環境なら説明・委員会が無いなら編集者に相談）と *Computers in Human Behavior Reports*（国の法令で要らないなら説明・ただし APC あり）。*Meta-Psychology* は記載が無い。どれも、編集者が受け入れるかは問い合わせるまで分からない。
- 費用ゼロで新しく集めるなら、現実の道は R1（ZEN大学の委員会）か R2（所属機関の長の承認）か R7（共同研究者）。どれも問い合わせ B か共同研究者しだいで、今は確かめられていない。
- 委員会も費用も要らないのは R9（公開データの二次利用）だけ。
- 所属で投稿するか独立の研究者として投稿するかで変わるのは、R1・R2 が使えるかと、T&F の「独立の研究者」向けの勧め [P497] が当てはまるか。誌の表 2 の要件そのものは、所属の有無で変わる書き方をしていない（読んだ範囲）。

## 4. 未確認のこと

- ZEN大学の委員会の有無と、所属機関の長による承認が得られるか（問い合わせ B）。
- R2 の「所属機関の長による承認」を国際誌が受けるか（表 2 のどの誌の規程にも記載が無い）。
- *Meta-Psychology* と *Behaviour & Information Technology* の編集者が、委員会の無い著者の調査研究を受けるか（問い合わせが要る。文面は研究者が経路を決めてから下書きする）。
- *Royal Society Open Science* の裁量の免除の申請の条件、*European Journal of Psychological Assessment* の費用と倫理の規程、*PLOS ONE* の APC。
- 心理学・HCI の学会が会員を審査する制度（今回の調査では見つからなかった）。
