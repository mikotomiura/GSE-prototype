## 0. 今回の中心

新規性の候補を先に並べるのではなく、まず作品として次を成立させたい。

1. GSE 内部にある密な作業時系列を、数値や状態名ではなく造形素材として扱う。
2. ユーザーをアバターとして描かず、その人が作業してきた変化様式を一つの肖像へ昇格させる。
3. 作品は普段は周縁に留まり、必要時には通知を付加するのでなく、作品自身の形式が開く。
4. その開口はスマホ内の次の課題へ導かず、画面外の身体へ向く。
5. 身体行為を測定・採点・報酬化せず、システムが知る権利を手放したまま再開を待つ。
6. 作品鑑賞そのものを常時の第二課題にせず、開口の後は媒体自身が再び注意の外へ退く。

一文で表すと、次のようになる。

> **GSE は人間の内面を表示する装置ではない。計測された実践の微細な差異を、解読可能な
> 指標ではなく生成する肖像へ変換し、その肖像が必要なときだけ自身の縁を開いて、
> 計測されない身体領域へ作者＝鑑賞者を送り返すメディアアートである。**

```text
密な作業時系列
  -> 機械による限定的な仮説
  -> 非可逆な造形変換
  -> 実践生成肖像
  -> 作品内部の開口
  -> [計測しない身体領域]
  -> 新しい実践としてのみ再接続
```

角括弧内は欠測を埋める対象ではない。作品を成立させる積極的な外部である。

## 1. 理論を構成する三つの語と、4 つ目の語の候補

### 1.1 実践生成肖像 / Practice-Generated Portrait

作品が描くのは顔、性格、能力、真の認知状態ではない。**その人と作業との関係が時間の中で
変化してきた仕方**である。

ここで「肖像」と呼ぶためには、単に本人のデータを使うだけでは足りない。少なくとも次が要る。

- **指標性**: その形態が本人の実際の作業行為から因果的に生じている。⚠️★ **借りもの** —— `indexicality` は autographic visualization の中心概念である [P424]。
- **非代替性**: 最終状態が同じでも、異なる時間経路なら異なる形態になる。★ **差分の候補** —— ⚠️ データ肖像の系譜はこれを主張しておらず [P418]、[P424] にも `trajectory` は 0 件（★ 2026-09-21 のメインの全文実測）。⚠️ ただし「**今回の範囲で見つからなかった**」までである。
- **過程性**: 人格プロフィールでなく、現在のセッションで生成中の関係を描く。★ **差分の候補（＝向きの違い）** —— ⚠️ personal / lived informatics は**長期蓄積が前提**で（*"Long-term reflection is valuable"* [P421]・*"ego-centric"* [P423]）、**先行が無いのではなく逆を向いている**。
- **解釈の余地**: システムの推定を本人の真実として閉じない。⚠️★ **借りもの** —— [P424] が *"not stable artifacts whose correct interpretation is just a matter of visual literacy"* と既に述べている。⚠️★★★ **かつデータ肖像の系譜はむしろ正確性を志向する**（*"more accurately determine the significance of a relationship"* [P420]・満足が**確認**と結びつく [P419]）→ ★ **この要件を「系譜の延長」として書かない**。
- **造形的自律性**: データを受けない基層や美的変奏もあり、作品が計器の皮膚に留まらない。★ 近い記述は [P418]（★ 主観性と正確性を区別する節。⚠️ **節名はサーヴェイ担当の報告に拠り、メインは節見出しの実在を照合していない**）。⚠️ 「データを受けない基層」そのものの明言は無い。

> ⚠️★★★ **2026-09-21 追記（S4・研究者判断で本文に当てた）**: **この 5 要件の *結合* が新しい、とは書けない。**
> ★ **指標性**と**解釈の余地**は [P424]（autographic visualization）に既出であり、⚠️ 同論文は **「computer keyboard の摩耗」を直接の例に挙げている**（★ ただし `accidental` の側で、`portrait` の語は **0 件**）。
> → ★ 残る差分の候補は **(i) 非代替性の明示要件化 × (ii) 肖像（人格表象）の文脈 × (iii) セッション局所**の 3 点に**縮小する**。
> ⚠️ **それも「今回の範囲で見つからなかった」まで**である —— ★ **Offenhuber, D. *Autographic Design*（MIT Press, 2024）は書籍全体が未読**である。
> ★ **2026-09-21 追記（S5）**: **序章 30 頁は照合した** —— ⚠️ `portrait` / `path depend` / `indexical` いずれも **0 件**で、関心は逐語 *"the **origin of a data set**"* であった [P430]。
> ⚠️★★★ **ただし帰趨を決める pp.33 / 62 / 80 / 186–187（biometric・Bertillon・"displays of self"）が未読**であり、**そこが肖像・経路依存に踏み込んでいれば、この 3 点も消える**。→ ★ **(ii) は「判定不能」のままであり、「差分が残った」と格上げしない。**
> ★ 根拠: `docs/literature/20260921-data-portrait-and-lived-informatics.md` カード 6。

ユーザーは同時に五つの位置を占める。

| 位置 | 意味 |
|---|---|
| 素材の起点 | 作業行為が形態変化の因果になる |
| 暗黙の共同作者 | 作品を作ろうとせずに、作品の履歴を変える |
| 肖像の主題 | 人格でなく「作業との関わり方」が描かれる |
| 鑑賞者 | 後から自分の実践を異なる距離で見る |
| 呼びかけの相手 | 開口を受け取るが、従う義務は持たない |

「暗黙の共同作者」は、ユーザーが美しい形を作ろうとして作業を最適化することを意味しない。
そうなった時点で GSE は作業支援から自己量化ゲームへ変質する。

### 1.2 内在的開口 / Immanent Aperture

介入を作品の外から通知、警告、文章、バッジとして貼り付けない。同じ作品の構図、境界、
運動規則が一時的に変わり、画面外への方向が生まれることを **内在的開口** と呼ぶ。

```text
通知:       作品 + 「立ってください」
内在的開口: 作品の境界そのものが、外へ続く形へ変わる
```

開口は命令を運ばない。継続、休止、離席、無視のいずれも本人に残す。`invitation` はこの
開口を許可する契約であり、表現層自身が Need や Opportunity を判断するものではない。

### 1.3 計測終端 / Measurement Termination

身体回帰を作品へ接続する方法は、歩数、距離、速度、位置、スマホ操作から「身体へ戻った」と
認定することではない。**作品が身体の手前で計測を終えること自体を、形式へ組み込む。**

- 開口の後に、歩行や回復を証明しない。
- 無入力を歩行、休息、熟考のいずれかに決めない。
- 復帰後の変化を、開口に従った成果として返さない。
- 「歩くと作品が育つ」「戻ると完成する」という報酬ループを作らない。
- チャネルが失効した場合も、最後の肖像を真実として凍結せず自律的な基層へ縮退する。

したがってこの作品は、因果的には循環していても、認識的・規範的には閉じていない。

> **身体は、システムがうまく表現できる対象としてではなく、システムが表現する権利を
> 手放す地点として現れる。**

### 1.4 手跡 / Handmark（4 つ目の語の候補）

> 2026-10-16 追記。格は EH0 の **候補** である（研究者の判断・`.steering/20261015-tangibility-design/decisions.md` 判断 28、置き場所と書く範囲は `.steering/20261016-handmark-theory-term/decisions.md` 判断 1）。§1.1〜§1.3 の三語と同格の語にはまだしていない。§0・§11・§12 の「三語／三点」は書き換えていない。新しい概念であるとは主張しない（下の「限界」）。

**手跡（しゅせき）** は、肖像の中で本人に手応えを返す層と、その層が満たすべき性質を指す。手応えを返す層の案は、一打ずつ返す（案 A）・時間をおいて出会う再生（案 C）・打ち方の手触りを写す（案 D）の 3 つで、設計の議論は `.steering/20261015-tangibility-design/` にある。

> **本人には自分の手のものと分かり、本人にも他人にも状態としては読めない。この二つを
> 同時に満たすことを肖像の性質として要件にし、その両方を測って確かめる。**

#### 二つの条件

| 条件 | 意味 | 満たさないときの姿 |
|---|---|---|
| 自己認識 | 本人が、自分の打鍵から生じた形を、他人の打鍵から生じた形と見分けられる | 誰の作業でも同じに見える装飾。§1.1 の指標性と非代替性が、本人の経験の上では成り立っていない |
| 状態として読めない | 本人も他人も、形から作業の状態（停滞・速さなど）を当てられない | 凡例を隠した状態計（§2.2 の「悪い写像」）。ADR-025（層 A に数値を添えない・本人に自分の量を返さない）の趣旨に、形を通して反する |

自己認識は「分かる」と答えることではなく、自分の形と他人の形を並べたときの見分けで測る。他人の形を自分のものと言う取り違えも数える（2 肢の強制選択や d′ の形）。取り違えの例は打鍵以外にある [P506]。

状態として読めないことは、`docs/glossary.md`「予期しない・評価を含まない驚き」の注記にある未検証の設計目標（形に状態の情報が残らないこと・EH1 で検査する）と同じものを指す。手跡はこれに自己認識を対にする。個人の再識別（形から誰の打鍵かを当てられること）を漏れに含めるかは未決である。相対のタイミングに個人らしさが残るなら、自己認識の手がかりと再識別の材料は同じものになりうる [P510] [P269]。

#### §1.1 の緊張と §2.2 との関係

§1.1 は本人を「暗黙の共同作者」とし、形を良くしようと作業を最適化した時点で自己量化ゲームへ変質すると警告する。手応えを返すことは作者の側を強めるので、この警告に近づく。手跡は、強めながらゲームにしないための条件に名前を与える。形が状態として読めなければ、形を良くするために目指す状態が形の上に現れない。それでも自分の手のものとは分かる、という組み合わせを狙う。これは設計上の仮説であり、二つの条件を満たせば最適化が起きない、という主張ではない（§9 の「報酬化していないか」で別に確かめる）。

§2.2 は「見た人が単一の値を逆算できない一方、異なる作業経路は異なる構図として感じられる。その中間を狙う」と書くが、中間にいるかを測る方法を持たない。手跡の二つの条件は、この中間の両端を本人の側から測る形にしたものである。

#### 測り方（検査法）

- 同じ刺激について、二つの役の成績を対にし、片方を保ちつつ片方を落とせるかを見る。この型には近い先例がある。携帯の可視化に囮を重ね、持ち主の読み取りを保ったまま覗き見の読み取りを偶然水準より下げた研究である [P508]。ただし [P508] は 2 つの役を別の群に割り当てており、刺激は乱数で作ったグラフで、測ったのは「読めるか」である。手跡では、刺激は本人の打鍵から作った形で、本人の役（自己認識）はそのデータの持ち主にしか務まらず、観察者の役（状態の推定）は本人と別の人が務める。本人が自分の形から状態を読めるかも測る。
- 写像の条件を 2 つ置く。全体の速さを残す写像と、割り引いて相対のタイミングを写す写像である（`.steering/20261015-tangibility-design/decisions.md` 判断 25 (1)）。速さの手がかりを減らしても自分と分かるかは、演奏では奏者の間のテンポの差を除いても評定が有意に変わらず [P492]（抄録のみ・12 人の帰無）、表情の動きでは長さを一様に伸ばす（相対のタイミングは保たれる）と偶然を有意に上回らず、真の動きより有意に低かった [P503]（倒立の刺激・12 人）。[P503] の操作は本人と他人の速さの差を除く操作（案 D の割り引き）とは違い、普段の速さから外れた不自然さで認識が崩れた可能性も残る。どちらも正規化した相対のタイミングの直接の検査ではなく、打鍵では 0 件である。割り引いた写像で自己認識が落ちて漏れも減るなら、手応えと漏れのあいだに交換条件があることになり、それ自体が検査の結果になる。
- 「偶然を上回らない」は、その検査で検出されなかったことであり、漏れが無い・自己認識が無いことの証明ではない（S-TN が [P492] [P503] に付けた「12 人の帰無は同等の証拠ではない」と同じ規則）。そこで、測る前に二つの値を決めて固定する。状態の漏れについて「読めない」とみなす優位の上限（同等性の幅）と、自己認識について「分かる」とみなす最小の水準である。判定は推定値ではなく信頼区間で行い、3 つに分ける。
  - 状態として読めない: 漏れの優位の信頼区間の上限が幅の内側にあれば満たす。下限が幅の外側にあれば満たさない。幅をまたげば判定不能。
  - 自己認識: 信頼区間の下限が最小の水準を超えれば満たす。上限が水準に届かなければ満たさない。水準をまたげば判定不能。
  - 検出力が足りず区間が広い結果は、判定不能に入る。
  - 本節が定めるのはこの原則だけである。幅・水準・信頼の水準の値と、下の統制の設計は、人の段の検査の事前登録で決める（研究者の判断・`.steering/20261016-handmark-theory-term/decisions.md` 判断 4）。
- 人の段の自己認識の検査では、自分の形と他人の形のあいだで、書いた内容・課題・機材・セッション・状態の分布の違いと、直前に見た形の記憶が手がかりにならないよう統制が要る。統制の設計は人の段の検査の事前登録で決める（未決）。
- 状態の漏れの机上の検査（機械の識別）と、人の段の自己認識の検査は別の段で行う。前者は G-GEAR のタスク（同 判断 17・21）にあり、本節はその中身を変えない。

#### 「予期しない・評価を含まない驚き」との関係

手跡は、`docs/glossary.md` の「予期しない・評価を含まない驚き」とは別の語として置く（`.steering/20261016-handmark-theory-term/decisions.md` 判断 1）。二つは両立しうる。自分の手のものと分かっても、いつ・どう返るかは予期できない、という組み合わせである。ただし驚きは慣れると予期された帰結になる（同語の注記）ので、肖像の性質としての要件には含めない。案 A・C・D のどこで予期を外すかは、まだ設計されていない。

#### 反証の条件

> 判断 28 の 2 つの崩れ方（打鍵で自己認識が成り立たない／成り立たせると状態が漏れる）を、上の判定の規則で書き直したもの。条件 3 は Claude が足し、範囲の限定と判定の規則は `/cross-review` を受けて Claude が足した。いずれも研究者が確かめた（`.steering/20261016-handmark-theory-term/decisions.md` 判断 2〜4）。

次のいずれかが、検査した写像・対象者・条件の範囲で成り立てば、手跡はその範囲で打鍵の肖像の要件として支持されない。範囲の外への一般化はしない。

1. 検査したどの写像でも、自己認識が「満たさない」と判定される。
2. 自己認識が「満たす」と判定された写像では、どれも状態の漏れが「満たさない」と判定される（自己認識を成り立たせると状態が漏れる）。
3. 自己認識が「満たす」と判定されるのは全体の速さを残した写像だけで、そのどれでも、形から状態が読めると判定される（全体の速さが形を通して状態を漏らす）。

どの写像でも判定不能が残るなら、支持も反証もされていない。3 が成り立てば 2 も成り立つ。3 は 2 を速さの経路に絞って書いたもので、判断 28 の 2 つの崩れ方に判断 25 (1) の 2 条件を当てたものである。速さそのものが状態を予測できることと、形から状態が読めることは別であり、3 が問うのは後者である。

#### 限界

- 打鍵での実証は 0 件である。自己認識と状態の漏れを同じ研究で両方測ったものは、S-TN の範囲で見つかっていない（`docs/literature/20261016-tangibility-self-recognition-and-leak.md` 台帳 #1）。網は粗く、HCI の個別の会議と被引用のたどりは未着手なので、検査法を新しいとは書かない。
- 打鍵は、抽象の表示で自己認識が弱い単純で反復的な動作の側に近い可能性がある [P504] [P505]（外挿）。反証の条件 1 が成り立つ（その範囲で支持されない）可能性は小さくない。
- 指標性と解釈の余地は [P424] に既出で（§1.1 の 2026-09-21 追記）、Offenhuber の書籍 [P430] の pp.33 / 62 / 80 / 186–187 は未読である。そこが本人の痕跡の見分けに踏み込んでいれば、手跡の位置づけはさらに縮む。
- 手応えを返すこと（タンジブルさ）は設計の動機であり、貢献として主張しない（`.steering/20261015-tangibility-design/decisions.md` 判断 20）。打鍵を周辺の動く層にする着想・過程の再生・行為の痕跡を指標とする理論に先例がある（同 判断 20 の理由）。
- 予期の外し方（上）と、案 A・C・D のどれが二つの条件を満たしうるかは未設計・未検査である。

#### 名前の注記

- 日本語の「手跡」は、一般には書いた文字の筆跡を指す。筆跡には本人を識別する含みがあり、判断 28 が「指紋」を候補から外した理由（本人の識別を連想させる）と同じ向きに読まれうる。本書では読みを「しゅせき」とし、上の定義の意味に限って使う。
- 英語の Handmark は既存の用法と重なる（2026-10-16 に WebSearch で軽く調べただけで、出典は採番していない）。モバイル向けソフトウェアの会社 Handmark, Inc.（2000 年設立・2013 年に事業終了と Wikipedia は記す）と、HANDMARK の米国商標の出願がある（現在の権利の状態は未確認）。HCI では、手と指を記憶の手がかりにするマルチタッチのメニュー HandMark menus（Uddin & Gutwin, 2016・検索の抜粋と学位論文の書誌の頁だけを見た・原典は未確認）がある。美術では、手の痕跡を残す行為を hand-marking と呼ぶ用法がある。どれも肖像や自己認識の概念ではないので、候補の段階では注記付きで名前を保つ（研究者の判断・判断 4）。論文などで英語名を使う前には衝突を確かめ直す。

## 2. 「ユーザー自身」へ昇格する条件

GSE の出力をそのまま色や図形にすると、それは装飾された状態計になる。肖像へ昇格させる
ためには、次の変換が必要である。

### 2.1 状態でなく経路を描く

`p_stuck = 0.7` や `level = stuck` は、その時点の切断面にすぎない。本人らしさが生じるのは、
そこへ至るまでの加速、修正、まとまり、間、再開、揺り戻しの配列である。

```text
同じ stuck
  A: 長い連続生成 -> 少数の修正 -> 急な停止
  B: 短い生成と修正を反復 -> 間が増える -> 停止

=> 意味状態は同じでも、肖像の形態は異なるべき
```

### 2.2 一対一写像でなく交差写像にする

「F3 が高いほど赤い」のような写像は、凡例を隠した計器である。各信号が複数の造形作用へ
寄与し、一つの造形作用も複数信号の関係から生じるようにする。

```text
悪い写像: F3 -> 赤さ

交差写像:
  F1 + F4        -> 連結の速度と距離
  F3 + F6        -> 書き換え痕の深さと残留
  F4 + F5        -> 群の結合と空隙
  X/Y の関係     -> 全体の張力と伝播方向
  時間経路       -> 以上の痕跡が残る順序
```

見た人が単一の値を逆算できない一方、異なる作業経路は異なる構図として感じられる。その
中間を狙う。

### 2.3 推定を真実へ格上げしない

打鍵は行為の痕跡だが、X/Y や HMM 状態はモデルを通した仮説である。したがって GSE の肖像は、
「本人の内面の指標」ではなく、より限定して次のように定義する。

> **機械が本文を読まずに立てた、本人と現在の作業との関係についての仮説を、本人が再解釈
> できる形にした暫定的な肖像。**

この意味で GSE の形は、物質現象が直接残した痕跡を扱う autographic visualization そのもの
ではない。行動痕跡、推論、造形文法が重なる **推論媒介的な指標** である。

### 2.4 作品にデータ以外の自由を残す

すべての画素がデータを担うと、作品は高密度な計器になる。現行の autonomous ground は、
次の意味で重要である。

- 接続や観測がなくても作品が存在する。
- 変化しないことを空白や死として描かない。
- データを担わない揺らぎが、美的経験と状態符号を分離する。
- OS や媒体が変わっても、作品の存在様式を保てる。

## 3. GSE 内部データから作れる造形

### 3.1 現在実装されている主要素材

| 内部要素 | 実際の意味 | 肖像として担えるもの | 直接表示した場合の危険 | 交差的な造形案 |
|---|---|---|---|---|
| F1 | 直近 30 秒の Flight Time 中央値 | 作業の微視的な拍、呼吸に似た間隔 | 速度・能力の評価 | F4 と混ぜ、生成運動の位相と局所間隔へ |
| F3 | BS/Del を含む修正率 | 書き直し、戻り、再構成の傾向 | ミス率、能力不足 | F6 と混ぜ、既存形態の折返し、重層、消去痕へ |
| F4 | 200 ms 未満の連続入力バーストの平均長 | 勢いではなく連続性のまとまり | 生産性、集中力の順位 | F1/F5 と混ぜ、線群の結合距離や連なりへ |
| F5 | 2 秒以上の無入力間隔の回数 | 実践内部の間、呼吸、切れ目 | 怠慢、離席の断定 | 空白にせず、密度の偏りや静止領域へ |
| F6 | 削除直後に 2 秒以上停止した割合 | 書換え後に残る保留 | 不安、詰まりの診断 | F3 と混ぜ、遅れて閉じる亀裂や残留層へ |
| raw X/Y | 現窓から合成した Friction / Engagement | 現在の局所的な張力関係 | 二軸の自己採点 | 軸を見せず、曲率・結合・伝播の関係へ |
| EWMA X/Y | 平滑化された X/Y | 瞬間値に還元されない持続と推移 | 固定的な「自分の状態」 | 軌跡線を出さず、構図の慣性や戻りに使う |
| `p_flow/p_inc/p_stuck` | HMM の参考確率 | 造形文法を切り替える粗い位相 | 認知状態の診断 | 数値・色階段にせず、複数の構成規則の重みへ |
| `idle_ms` | 最終入力からの経過 | 入力がない時間の存在 | 在席監視、タイマー | 数量を出さず、一定以上で生成を保留し基層へ寄せる |

F1/F3/F4/F5/F6、raw/EWMA X/Y、HMM 確率は実装・記録されている。ただし、これらをスマホへ
連続送信する表現チャネルは現行実装ではない。上表はまずローカルなリプレイ／Layer B 試作で
造形可能性を確かめるための候補であり、現行の層 A 契約を暗黙に拡張しない。

### 3.2 記録にはあるが、第一の肖像材料にしないもの

| 要素 | 状態 | 扱い |
|---|---|---|
| `keys/bs_keys` | Tier 0 の記録のみ。30 秒窓であり累積値ではない | 行を跨いで合算しない。活動量や努力量として返さない。F3 の造形を安定させる補助以上にしない |
| paste | 回数と外部 paste 文字数のみ記録可能 | AI 依存や自力性を道徳化しやすいため、本人の肖像材料でなく研究アウトカム側に留める |
| focus transition | 時刻だけを記録 | 文脈不明のため「注意散漫」と描かない。将来、遷移リズムとして使う場合も別検証が要る |
| pointer bin | 1 秒単位の量子化された活動 | O1 の補助信号。座標やアプリ文脈がなく意味が弱いため、現段階の主造形には入れない |
| IME 状態 | 入力観測の文脈 | 言語・入力方式を個人特性として描く危険がある。作品素材でなく推論の条件として扱う |
| intervention response | Nudge に対する固定カテゴリ応答 | 従順さの肖像にしない。介入評価へ限定する |

### 3.3 設計にあるが未実装のもの

| 要素 | 現在の状態 | 理論上の役割 |
|---|---|---|
| `level` | `stable/friction_rising/stuck` の設計契約。表現送出コードは未実装 | 層 A で意味構造を保つ最小の商。肖像全体そのものではない |
| `invitation` | `none/present` の独立フィールドとして設計。未実装 | 内在的開口を許可する二値。理由・強度・残り時間を運ばない |
| `evidence_quality` / `uncertainty` | `WorkStateEstimate` とともに将来設計。実行コードには未実装 | 証拠不足時に肖像を断定させず、基層へ退くための条件。実装前は入力として扱わない |
| expression event | 配送意味論と失効は設計済み、実コードは未実装 | スマホへ意味構造だけを渡す境界。履歴再送はしない |
| Physical Anchor | 現行の運搬路・完了判定はなく、実装されていない | 計測された達成でなく、画面外へ向く選択肢という概念上の出口 |

### 3.4 本人を表すための最小データ単位

個々の F 値ではなく、短い時間区間の **変化関係** を最小単位にする。

```text
Temporal primitive = {
  pace,           // 拍の速さではなく変化方向
  continuity,     // まとまりが続く / 切れる
  revision,       // 書換えが形を残す度合い
  suspension,     // 間がどこへ配置されるか
  tension,        // X/Y から得る局所関係
  persistence,    // その関係がどの程度残ったか
  observability   // 将来: 証拠が足りるか
}
```

この中間単位はまだ仕様ではない。重要なのは、元の値、能力評価、時系列を逆算できる表示に
しない一方で、異なる経路の差を消し切らないことである。

## 4. 第一の具体作品案: 「書き直される境界」

現行の `ground / lattice / sparsity / aperture` を捨てず、状態記号から肖像生成へ拡張する。

### 4.1 通常時

- スマホ面には、データがなくても成立する静かな ground が常にある。
- ground の上に格子または線維状の関係場がある。
- 作業の拍とバーストは、点を増やすのでなく、既存要素どうしの結び方を変える。
- 修正は失敗として赤くならず、既存の線を折り返し、重ね、異なる経路へ書き直す。
- ポーズは穴や死ではなく、周囲の配置が呼吸できる間として残る。
- 同じ最終 `level` でも、そこへ至った履歴により重層、余白、結合の仕方が異なる。

ユーザーは画面内の物体ではない。**この場が書き直されてきた様式がユーザーの肖像になる。**

### 4.2 摩擦が増えたとき

- 派手さ、赤、警告、嵐を増やさない。
- 結合の一部が格子から外れ、互いの距離が少し不均一になる。
- `stuck` は破壊や罰でなく、作用できる関係が疎になった構図として現れる。
- autonomous ground は失われない。本人の存在や価値が空になる表現を避ける。

### 4.3 invitation が生じたとき

- 別の通知を載せず、作品の一辺または輪が一度だけ開く。
- 内側の要素がスマホ中央へ集まるのでなく、画面外へ続く方向を持つ。
- 開口は点滅、文章、ボタン、カウントダウン、報酬を伴わない。
- スマホは「次に操作する対象」でなく、作業画面と身体空間の間に置かれた閾になる。

### 4.4 開口の後

- システムは歩いたか、立ったか、休んだかを知らない。
- 作品は身体行為へ追従せず、ground の自律運動だけを続ける。
- 無入力の長さに比例した成長、色、空白を作らない。
- 復帰した場合も「成功」として閉口せず、新しい作業の作用が別の方向から加わるだけにする。
- その間は「身体回帰の記録」ではなく、作品が所有しなかった時間として扱う。

### 4.5 セッションの終わり

長期プロフィールを作らず、そのセッションの肖像は消えるか、一枚へ凝縮して閉じる。保存する
場合も、本人向けの累計、比較、連続日数へ接続しない。保存の是非は別途判断する。

### 4.6 周縁的でありながら介入できる媒体形式

この構想の難所は、「作品として豊かであること」と「普段は作品へ集中させないこと」を同時に
満たす点にある。常時見たくなるほど美しく、変化が多く、収集したくなる作品は、それ自体が
新しい注意捕捉装置になる。GSE にとっては作品への滞在時間が増えることを成功にしてはならない。

仮にこの媒体形式を **周縁開口型表現 / Peripheral-Aperture Expression** と呼ぶ。

```text
背景存在
  -> 普段は注視を要求しない

一回変形
  -> invitation 時だけ、同じ作品の構図が局所的に変わる

弱い残留
  -> 点滅や反復をせず、見れば開いていると分かる程度に留まる

自己退却
  -> 追加操作、続きを見る画面、達成演出を作らず、再び ground へ退く
```

この形式では、適切な介入を「必ず即時に気づかせること」と定義しない。スマホを自然に見る、
PC 上で注意が少し緩むなどの **次の自然な曝露機会に、開口が受け取れること** と定義する。

次の三条件は同時には最大化できない。

1. 普段はほとんど気づかれない。
2. 必要時には必ず気づかれる。
3. 注意を強制的に奪わない。

周縁開口型表現は 2 の保証を手放し、1 と 3 を守る。即時かつ確実な到達が必要な場面は、
表現層だけで解こうとせず Nudge などの介入として別に扱う。表現を強くして通知相当にすると、
表現と介入の境界を隠すことになる。

### 4.7 注意を奪わない具体的な作品変化

| 案 | 通常時 | invitation 時 | 開口後 | 避けたい読み |
|---|---|---|---|---|
| 書き直される境界 | 作業履歴によって線群が静かに重なる | 一辺の結合だけがほどけ、線が画面外へ続く | 外へ向いた構図を弱く残し、反復運動しない | 壊れた、修理が必要 |
| ひらく余白 | ground 内に密度差があるが、中心を作らない | 周縁の一部に奥行きのある余白が生じる | 余白は拡大せず、そこに留まる | 空白は無価値、作業していない |
| 向こう側へ流れる格子 | 格子がほぼ静止し、局所的な揺らぎだけを持つ | 格子の位相が一方向だけ画面外と連続する | 流れは一度で止まり、方向だけが残る | 急げ、移動しろ |
| 手放す輪郭 | 輪郭が場を囲むが閉鎖感を強めない | 輪郭の一箇所が開き、内外の区別が弱まる | 開口が閉じる際も成功演出を出さない | 完了、解除、クリア |

共通条件は次のとおりである。

- 通常時の連続アニメーションを主役にしない。
- 変化は全画面でなく局所的・一回的にする。
- 色、点滅、振動、音、文章を注意捕捉の階段として足さない。
- タップしないと消えない構造にしない。
- 「続きを見る」「作品を完成させる」動機を作らない。
- 作品を見逃しても、未達、失敗、損失が生じない。
- 開口の意味は画面内の情報量増加でなく、画面外への方向として作る。

この意味で作品の成功は、長く鑑賞されたことではない。**必要なときに短く関係を変え、
それ以上の注意を自分から返したこと**にある。

### 4.8 密なデータを「形態を動かす力」へ変換する

GSE が持つ密度を、そのままスマホへ送ってグラフや色へ一対一対応させると、作品ではなく
状態ダッシュボードになる。必要なのは、数値を視覚属性へ置換する処理ではなく、短い履歴から
**時間的な性質を抽出し、それを形態変化の原因へ翻訳する中間層**である。

```text
FeatSnapshot の短期履歴
  F1 / F3 / F4 / F5 / F6
  raw X/Y・EWMA X/Y・HMM 事後確率
        ↓ 30〜120 秒の窓で関係を読む
Temporal Primitives
  pace        伝播の速さ
  continuity  流れの連続性
  revision    書換えの深さ
  suspension  留保・間の分布
  cohesion    局所的な結びつき
  tension     形がほどけようとする力
        ↓ 範囲を制限し、不可逆に圧縮する
Morphology State
  velocity / curvature / link_distance / void_ratio /
  persistence / boundary_openness
        ↓ 端末内で連続時間へ補間する
Generative Renderer
  線、格子、粒子、残像、開口
```

各 primitive は単独特徴量の別名にしない。例えば次のような**交差写像**にする。

| 造形上の力 | 主に参照する関係 | 作品上の現れ |
|---|---|---|
| 伝播 | F1 と F4 の組、短期傾向 | 変化が近傍へ伝わる速さ。作業速度のメーターにはしない |
| 書換え | F3 と F6、Friction の傾き | 線が消えるのでなく、以前の線を薄く残して別経路を取る |
| 留保 | F5 とバースト間隔の分布 | 空白の大きさではなく、空白がどこへ散るかを変える |
| 結合 | F4、F5、Engagement の関係 | 格子の局所結合と孤立領域の比率を変える |
| 張力 | EWMA X/Y とその一次差分 | 曲率、慣性、境界へ向かう偏りを変える |
| 開口 | invitation のみ | 一辺の境界条件を変え、線や粒子が画面外へ抜けられるようにする |

F1 などの値を色相や大きさへ直接対応させない理由は二つある。第一に、単独値の意味を本人の
性質として誤読させやすい。第二に、同じ最終状態へ至った異なる時間経路が同じ絵になり、
「実践の肖像」ではなく三状態表示へ縮退するためである。

また、現在の `FeatSnapshot` は無入力時にも合成観測を含みうる。したがって沈黙をそのまま
「本人が休んだ」「身体へ戻った」と描かない。合成観測は推定器を継続するための内部値として
来歴を保持し、身体行為の痕跡には変換しない。

### 4.9 推奨する流動エンジン

第一候補は、**ばね格子 + curl-noise の流れ場 + パリンプセスト状の残像**を組み合わせる方式
である。実際の流体方程式を全面的に解く必要はない。

- ばね格子は `lattice / coherence / sparsity / aperture` という現行文法を保てる。
- curl-noise は発散しにくい滑らかな局所流を安価に作れる。
- 残像テクスチャは修正、逡巡、過去の経路を「消去されない書換え」として残せる。
- invitation 時だけ一辺の境界条件を開放し、一度だけ外向きの流れを作った後に沈静化できる。

反応拡散 shader は有機的な静止像に強く、GPU 粒子場は滑らかな運動に強い。Navier--Stokes
型の本格的流体計算も可能だが、数値発散、端末差、電池、意味制御の難しさが増える。GSE の
作品では「物理的に正しい液体」より、**時間経路を保ったまま意味的に制御できる流動**の方が
重要なので、最初から完全流体を採る利点は小さい。

### 4.10 「ぬるぬる」と「注意を奪わない」は両立できる

ここでは **フレームの滑らかさ**と**運動の強さ**を分ける。60 fps で描いても、速度、振幅、
コントラスト、全画面移動を小さくすれば、知覚上は滑らかだが低エネルギーな背景にできる。
逆に 5 fps でも点滅や大きな状態ジャンプがあれば注意を奪う。

推定周期と描画周期も分離する。

```text
GSE の推定・意味更新: 1 Hz または状態変化時だけ
端末へ渡すもの:     新しい目標形態または意味イベント
端末内の描画:         60 fps（可視時のみ）
```

端末内では、各形態変数を臨界減衰に近いばねで目標へ寄せる。

```text
velocity += (stiffness * (target - value) - damping * velocity) * dt
value    += velocity * dt
```

`dt` は固定刻み（例: 1/60 秒）で積分し、描画フレームが落ちた場合は accumulator で追いつく。
入力値、速度、反復回数を clamp し、同じ session seed なら同じ意味的構図へ至るようにする。
これによりネットワークから 60 件/秒を送らなくても、端末側では連続的に動く。

注意を捕捉しないための運動規則は次のように置く。

- 通常時は低速・小振幅・低い空間周波数とし、中心を作らない。
- 状態更新は形を瞬間移動させず、数秒から数十秒で馴染ませる。
- invitation は常時激しくするのでなく、局所的な一回の位相変化にする。
- 変化後は周期的な催促をせず、開いた構図を弱く保持する。
- 非表示時は計算を止め、次の曝露時に現在形へ再構成する。
- 作品の美しさを維持するが、収集、完成、希少形、連続記録へ結びつけない。

したがって、ぬるぬるしたメディアアートへの昇華は無理ではない。むしろ GSE では、
**滑らかさを報酬刺激ではなく、離散的な推定が人間へ断定として突き刺さらないための緩衝材**
として位置づけられる。

### 4.11 計算上・研究上の主な問題

| 問題 | 失敗すると何が起きるか | 対応 |
|---|---|---|
| 1 Hz と 60 Hz の不一致 | 状態変更のたびに絵が跳ぶ | 目標値だけ更新し、端末内ばね・補間で連続化する |
| 履歴の無限増大 | GPU/メモリ消費、長期プロフィール化 | 有限の場・有限の残像へ圧縮し、セッション終了時に消す |
| 数値発散 | 粒子や格子が端末外へ飛ぶ | 固定 timestep、clamp、反復上限、安定な積分法を使う |
| 端末差 | 同じデータでも別作品に見える | pixel parity でなく、結合・疎密・開口の semantic parity を試験する |
| 状態境界の往復 | invitation のような変化が連打される | hysteresis と one-shot impulse を分け、再通知しない |
| 通信断・再接続 | 古い形へ巻き戻る | `epoch/seq` と現在スナップショットを使い、履歴を再送しない |
| 個人識別 | 抽象画から長期的な本人像が固定される | セッション seed、不可逆圧縮、安定した人物 ID の不使用 |
| 推定不確実性 | 精密な絵が精密な真実に見える | 現状は粗い文法に限定し、将来 `evidence_quality` 導入時に再設計する |
| 熱・電池 | 背景作品が作業や端末利用を妨げる | 可視時だけ描画、適応 fps、低解像度場、静止 fallback |
| 馴化・注意捕捉 | 頻繁に作品を確認する第二の作業になる | 常態は低エネルギー、開口は一回、視聴時間を成功指標にしない |

### 4.12 現行チャネルとの境界

現行の表現チャネル案は `(level, invitation)` が変化したときだけ送信し、連続値も 1 Hz
ストリームも載せない。この契約だけで作る場合、端末側の作品は滑らかにはできるが、入力は
三状態と開口だけなので、厳密には **「密な実践データの肖像」ではなく「状態の流動表現」**で
ある。この差を曖昧にしてはならない。

候補は次の三段階に分ける。

1. **層 A**: 現行契約を守り、`level / invitation` と端末内で生成する local session seed だけから周縁的な流動を作る。
2. **層 B または PC リプレイ**: `FeatSnapshot` の短期履歴から完全な Practice Portrait を生成する。
3. **将来の拡張**: PC 側で不可逆に圧縮した `MorphologyState` だけを低頻度で送る。生特徴量は送らない。

3 を採るなら、現行の「これ以外を載せない」という契約を変更するため、wire protocol の実装に
紛れ込ませず、表現上の必要性、再識別可能性、保持期間、失効を含む別 ADR と privacy review が
必要になる。まず 2 で密な肖像が本当に成立するかを合成系列とローカル再生で確認し、その後に
スマホへ縮約するのが安全である。

### 4.13 スマホ OS 上で可能な範囲

#### Android

ライブ壁紙なら描画用 `SurfaceHolder` が与えられ、可視／非表示の通知も受けられるため、
**表示中の連続描画**は実現できる。Android の公式 API も、壁紙は可視時だけ CPU を使うことを
強く求めている（[WallpaperService.Engine](https://developer.android.com/reference/android/service/wallpaper/WallpaperService.Engine)）。
したがって Android は低エネルギーな 60 fps 表現の第一実験面に向く。

ただしロック画面への適用、AOD 中の可視性、実際の更新頻度は OEM と端末設定の差が残る。
`FLAG_LOCK` は存在するが、任意端末で同じ挙動になることを意味しない。AOD で
`onVisibilityChanged` がどうなるかは現行文書どおり実機試験を要する。

#### iOS

iPhone のロック画面 Widget は、任意の描画ループを常時所有できない。Widget extension は
画面上にあっても常時実行されず、更新はシステムの timeline と budget に従う
（[Keeping a widget up to date](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date)）。
データ更新時の animation も最大 2 秒である
（[Animating data updates in widgets and Live Activities](https://developer.apple.com/documentation/widgetkit/animating-data-updates-in-widgets-and-live-activities)）。
さらに iPhone のロック画面 Widget は `vibrant` 表示になり、システムが脱色して周囲へ適応させる
（[WidgetKit strategy](https://developer.apple.com/documentation/widgetkit/developing-a-widgetkit-strategy)）。

Live Activity も任意の常時 60 fps 面ではなく、通常は最大 8 時間、その後を含めロック画面上の
保持は最大 12 時間という時間制限がある
（[Displaying live data with Live Activities](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities)）。
よって、通常の iOS と App Store 配布を前提に、ロック画面全体を自前の連続作品へ置換することは
できない。アプリを前景表示すれば可能だが、常に作品へ集中させないという目的と衝突する。

### 4.14 自前システムで越えられるもの／越えられないもの

| 自前化する範囲 | 解決できること | 解決できないこと・代償 |
|---|---|---|
| 独自描画エンジン | 流動、補間、形態文法、端末内生成 | iOS のロック画面実行権限は増えない |
| Android ライブ壁紙／launcher | Android の home 面をかなり所有できる | secure lock screen と全 OEM の AOD は所有できない |
| AOSP fork／専用 Android 端末 | OS 面を含む完全な作品制御 | 一般ユーザーのスマホではなく、専用作品端末になる |
| 外付け ambient display | OS 非対称を避け、常時・周縁・滑らかさを制御できる | ハードウェア制作、携帯性、配布の問題が増える |
| Web/PWA | 配布と試作が容易 | ロック画面所有と安定した背景連続描画はできない |

したがって「自前システム」は描画問題を解けるが、他社 OS の権限モデルそのものは解けない。
同一の連続作品を iOS と Android のロック画面へ出すことが絶対条件なら、スマホ OS は主媒体に
適さず、専用 Android、AOSP、外付け表示体のいずれかへ研究媒体を移す必要がある。

一方、作品の意味を同じにしつつ時間表現だけを OS に合わせるなら成立する。

- Android: 可視時に連続する **continuous fluidity**。
- iOS: 自然に見るたび次の位相が現れ、短い更新 animation で接続する **episodic fluidity**。
- 層 B／展示: 密な履歴を使う完全な 60 fps Practice Portrait。

これを **意味的不変性と時間的非対称 / semantic invariance, temporal asymmetry** と呼べる。
iOS を劣化版として隠すのではなく、「作品は鑑賞中ずっと動く必要があるのか、それとも生活の
遭遇間で連続していればよいのか」という媒体理論上の問いへ変えられる。スマホを主媒体として
維持するなら、この非対称性を欠陥ではなく作品形式の条件として扱う案が最も強い。

## 5. 何が既存で、何が貢献候補か

### 5.1 それ自体では新規性にしないもの

- データから絵を生成すること
- 顔以外のデータで人物を肖像化すること
- スマホの壁紙／ロック画面をアンビエント表示に使うこと
- ユーザー状態に応じて媒体を変化させること
- 抽象表現によって内省を促すこと
- 身体信号をメディア作品へ変換すること
- 周縁から必要時に注意を中心へ移すこと
- 閉ループでメディアを適応させること

### 5.2 GSE で厳密化できる貢献候補

#### A. 肖像論としての貢献

累積データから「その人らしさ」を固定する data portrait ではなく、**現在の実践関係だけを
描き、セッションとともに消える過程的肖像**を定義する。

#### B. 造形方法としての貢献

本文非保存の行動時系列を、単一値へ対応させず、経路差を保ったまま逆算不能な形態へ変換する
**交差的・非可逆な造形文法**を定義する。

#### C. 介入形式としての貢献

通知を作品へ添えるのでなく、同一作品の位相変化が選択肢を開く **内在的開口** を定義する。
ここでは表現と介入は別モジュールのままだが、経験上は断絶した二画面にならない。

#### D. 身体論・倫理としての貢献

身体回帰を測定精度の改善で閉じず、センサのない身体を作品の積極的外部とする **計測終端** を
定義する。データ欠損を埋めるのでなく、システムの認識権限が終わる形式として扱う。

#### E. bioadaptive media への貢献

推定状態を望ましい状態へ制御する閉ループだけでなく、**ユーザーが作品へ影響し、作品も
ユーザーへ働きかけるが、正しい意味と行為をシステムが完結させない開いた循環**を示す。

### 5.3 新規性候補の最小命題

現時点で「世界初」とは書かない。調査と実作を経た後も、主張候補は次の接続に限定する。

> **日常の知的作業が暗黙に共同制作するセッション固有の生成肖像が、普段は周縁に留まり、
> 必要時には同じ作品の内部から画面外への開口を作る。その先の身体を測定・達成判定・
> 報酬化せず、作品が自らの計測権限を終える。**

これは「要素の組合せが見つからなかった」だけでは研究貢献にならない。次を形式化し、比較し、
反証できるところまで進めて初めて理論候補になる。

- 実践生成肖像の必要条件
- 交差写像がデータ可視化と異なる条件
- 内在的開口が通知と異なる条件
- 計測終端が単なるセンサ不足と異なる条件
- 媒体を変えても保存すべき意味構造
- 作品として成立しなかったと判定する失敗条件
- 本人の自己認識と状態の漏れを同じ刺激で対にして測る検査（§1.4 手跡の測り方。新規性ではなく形式化の対象として置く。近い先例 [P508] があり、新しさの候補とは書かない）

> 2026-10-16 注記: 手跡（§1.4）は §5.2 の貢献候補に加えない。手応えを返すことは設計の動機で、貢献として主張しない（`.steering/20261015-tangibility-design/decisions.md` 判断 20）。

|---|---|---|

| [MoodLight](https://pmc.ncbi.nlm.nih.gov/articles/PMC6173949/) | バイオセンサ情報のアンビエント表現が、説明と意図しない介入の両方になりうることを示す | GSE は作品の介入性を副作用にせず、開口として明示的に設計する |
| [Pulse Room](https://www.lozano-hemmer.com/artworks/pulse_room.php) | 参加者の心拍を空間的・時間的な作品へ昇格させる | 身体信号を明示的に測る焦点的・公共的作品。GSE は日常の周縁と未計測身体を扱う |
| [Physiological Computing](https://physiologicalcomputing.org/wp-content/uploads/2017/09/fairclough_phycomp_v4.pdf) | 動的なユーザーモデルを閉ループ制御へ入れると、システムが所定の agenda を持つことを指摘する | GSE は正解状態への制御を閉じず、最後の意味・身体行為を本人に残すことを作品条件にする |
| [SYNAPSE](https://www.milabujic.com/publicationsdata/synapse-a-sociotechnical-taxonomy-of-bioadaptive-media) | bioadaptive media を System Objective / Feedback Logic / User Agency から社会技術的に分析する | 計測終端型の作品を、この分類上の一つの設計立場として記述・比較できる可能性がある |

新規性の証明ではない。今後は検索式、対象データベース、採否基準を固定した scoping review が要る。

## 7. アート理論としての形

### 7.1 三者の作者性

作品は次の三者のどれか一つに還元されない。

| 作者性 | 作品へ与えるもの |
|---|---|
| 人間の実践 | 拍、修正、継続、間という因果的な揺らぎ |
| 推論・造形系 | 不完全な仮説、選択、圧縮、交差写像 |
| 媒体 | 画面サイズ、点灯機会、単色化、周縁性、外部との境界 |

ユーザーだけが作者なのでも、アルゴリズムだけが作者なのでもない。作品は三者の交渉として
生じる。その交渉の非対称性、特に推論系が持つ権威を隠さないことが必要である。

### 7.2 内容・形式・媒体

| 層 | GSE における定義 |
|---|---|
| 内容 | 本人と現在の作業との関係が、生成・修正・間・再開を通じて変化した時間構造 |
| 形式 | ground、結合、疎性、書換え痕、持続、開口からなる生成的な構図 |
| 媒体 | 身体とともに移動しながら、普段は背景に留まるスマートフォン面 |
| 外部 | 画面を離れた身体、環境、他者、紙、沈黙など、GSE が所有しない領域 |

媒体としてのスマホは単なる小型ディスプレイではない。作業 PC から離れうる一方、別の
注意捕捉装置にもなる両義的な物体である。この両義性を隠さず、「開いた後は見続けるものが
ない」という時間構成にする。

### 7.3 作品単位

作品単位はスマホ画面上の画像ではなく、次の全体である。

```text
作業 <-> 痕跡 -> 推論仮説 -> 生成肖像 -> 内在的開口
                                          |
                                計測終端   v
                                      身体・環境
                                          |
                                          v
                                   次の作業として再接続
```

つまり、レンダリングだけを切り出して「作品」と呼ばない。計測が始まり、形になり、境界を
開き、知ることを止めるまでが作品である。

## 8. 横展開できる貢献

横展開するのはキーボード特徴量や `stable/friction_rising/stuck` の三値ではなく、次の構成規則である。

```text
domain-local な行為痕跡
  -> 時間的 primitive
  -> 交差的・非可逆な造形
  -> 媒体内の周縁的肖像
  -> 必要時の内在的開口
  -> センシングしない外部
```

### 8.1 展開候補

| 領域 | 行為痕跡の例 | 開かれる外部 | 注意点 |
|---|---|---|---|
| Writing | 打鍵、修正、間、バースト | 紙、歩行、対話、何もしない時間 | 現在の第一実証。意味妥当性は未確証 |
| Coding | 編集、ビルド、テスト、往復 | 設計を描く、机を離れる、他者に相談する | イベント意味が Writing と異なり、単純転移できない |
| 音楽練習 | 反復、間、テンポの揺れ | 楽器から手を離す、聴く、身体で拍を取る | 芸術行為そのものを採点しないことが重要 |
| 手仕事・制作 | 道具操作、工程の反復 | 素材へ触れる、距離を取って見る | 新たなセンシングの妥当性・プライバシーが要る |
| 学習 | 解答、書換え、停止 | 身体を動かす、別媒体で考える、他者に聞く | 速さや正解を能力肖像へしない |
| ケア／リハビリ | 日常行為のリズム | 本人の身体感覚、休息、支援者との対話 | 医療判断に見える表現は不可。別の倫理・検証が必須 |

### 8.2 理論的な横展開

1. **Human-data interaction**: 自分の量を返す以外に、データとの関係を作品化する方法。
2. **Generative portraiture**: 顔や蓄積プロフィールでなく、短期の実践関係を描く肖像。
3. **Ambient media**: 背景から注意中心へ移るだけでなく、媒体外へ注意を手放す構造。
4. **Adaptive interfaces**: 正解状態へ適応するのでなく、介入後に制御を閉じない設計。
5. **Critical data art**: 何を測るかだけでなく、どこで測定を終えるかを形式にする方法。

ただし横展開可能性は、Writing で成立した後に別ドメインで同じ primitive と作品条件が
保たれるかを比較して初めて主張できる。

## 9. 評価と反証

分類精度だけではアート理論を検証できない。少なくとも次を分ける。

| 問い | 成立側の兆候 | 失敗側の兆候 |
|---|---|---|
| 肖像として成立したか | 「数値」より、自分の作業の時間や癖との関係を語る | 状態ウィジェット、壁紙、診断表示としか読まれない |
| 本人性があるか | 同じ状態でもセッション間の違いを感じる | 色違いの三状態表示にしか見えない |
| 権威を閉じていないか | 表現を仮説として受け取り、異なる解釈や否定ができる | 作品が自分の真の内面を知っていると感じる |
| 周縁に留まるか | 通常時は作業の注意を要求しない | 作品を頻繁に確認し、第二の作業になる |
| 開口になったか | 通知文なしでも画面外の選択肢を感じる | 警告、命令、装飾的変化としてのみ読まれる |
| 計測終端が伝わるか | 画面外で追跡されていない安心と余地がある | 行動を見られている、採点されると感じる |
| 報酬化していないか | 作品を良くするために行動を変えない | きれいな形、完成、連続記録を目的にする |
| 外部が保たれたか | 離席、継続、無視のいずれも可能 | 特定行動を「正解」と感じ、罪悪感が生じる |
| 自分の手のものと分かるか（手跡・§1.4） | 自分の形と他人の形を並べ、自分の形を選べる割合の信頼区間の下限が、前もって決めた最小の水準を超える | 区間の上限が水準に届かない。または他人の形を自分のものと言う取り違えが多い。水準をまたげば判定不能 |
| 状態として読めないか（手跡・§1.4） | 本人も観察者も、形から停滞や速さを当てる優位の信頼区間の上限が、前もって決めた同等性の幅の内側にある | 区間の下限が幅の外側にある。自己認識が成り立つ写像のどれでもそうなら、手跡の反証の条件 2。幅をまたげば判定不能（偶然を上回らないだけでは合格にしない） |

形成的試視では「何を表していますか」と正解を当てさせるだけでなく、次を尋ねる。

- この形を自分のものだと感じる根拠は何か。
- 自分について何を断定されたと感じたか／感じなかったか。
- 変化を見て画面内と画面外のどちらへ注意が向いたか。
- 見逃したとき、失敗または未達だと感じたか。
- 形を良くするために作業を変えたくなったか。
- 何をシステムに知られていると想像したか。
- 自分の形だと分かったとき、その形から自分の調子（詰まっている・速い）が読めると感じたか。

## 10. 現時点で主張しないこと

- 「このメディアアート形式は世界初である」
- 「ユーザー本人の内面を表現できる」
- 「抽象表現ならプライバシーが守られる」
- 「作品を見ると身体へ戻る」
- 「身体へ戻ると回復する」
- 「GSE は身体行為を計測・完了判定できる」
- 「表現チャネルや Physical Anchor は実装済みである」
- 「Writing で考えた造形文法が他領域へそのまま移植できる」
- 「読めなさそのものがアートとして優れている」
- 「手跡（§1.4）は新しい概念である」「打鍵の肖像で手跡が成り立つ」（打鍵での実証は 0 件）

## 11. 次に進める順序

1. このメモの三語「実践生成肖像／内在的開口／計測終端」が、既存概念の言い換えに留まるかを scoping review する。
2. 一つの実セッションを使わず、合成系列で「最終状態は同じ・経路だけ異なる」作品対を作る。
3. `ground/lattice/sparsity/aperture` を用いた「書き直される境界」の静止画または短い動画を作る。
4. 状態表示版と実践肖像版を並べ、本人性、診断感、注意捕捉、画面外への方向を形成的に比較する。
5. 交差写像の再現性と非可逆性を定義し、どこまでを研究用リプレイ、層 B、層 A に置くか分ける。
6. 作品が成立しなかった条件も含めて記録し、その後に限って理論・方法・実作の貢献を分離して書く。

## 12. 暫定判断

GSE の研究価値を上げうるのは、状態推定の精度に「アート」を加えることではない。

1. **作業の内容を読まず、その時間構造から実践の肖像を作ること。**
2. **介入を通知でなく作品の開口として経験させること。**
3. **その開口の先で、システムが身体を知ろうとすることを止めること。**

この三点を、造形、相互作用、倫理の別々の工夫ではなく、一つの作品構造として成立させる。
そこまで到達すれば、GSE は「認知状態を当てるアプリ」から、**計測が人間を閉じ込めず、
自らの限界を形式として示すメディア**へ位置づけ直せる可能性がある。

> 2026-10-16 注記: 4 つ目の語の候補「手跡」（§1.4）は、上の三点に加えていない。候補から語へ上げるかは、§1.4 の二つの条件を測った後に研究者が決める。
