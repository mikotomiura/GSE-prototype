# ADR-045: 主の対象を行動上の停滞に置き、詰まりは停滞の中身の 1 つとして記述する

## Context

1. ADR-043 は、停滞（ADR-030 の C0）が詰まりなのかを詰まりの自己申告（C4）で確かめる形で段 1 を組んだ（Context 1）。H1（混合）は「停滞の中で詰まりと申告される割合が上限 p* を下回る」を判定として置く（`docs/preregistration-stage1.md` S1-C1）。詰まりが主の的になっている。
2. 行動だけでは、詰まりと熟考・外部資料・会話・離席が同じ形をとりうる。公開データに、作業の途中に時刻つきで取った状態の申告と打鍵を同じ作業で持つものは見つかっていない（ADR-043 Context 2）。詰まりを主にすると、見えない状態を当てることが研究の成否を決める。
3. 研究者は、詰まりではなく PC 上の行動としての停滞・デスク疲労に近いものを相手にする案を出した。身体回帰の招待は、詰まりより「長く止まっている」に自然に結び付く。停滞は時計で決まる事実で、当てる必要が無い。
4. 疲労も見えない状態で、確かめるには疲労の申告という別のラベルが要る。プローブは 1 回 3 問が上限で、4 問目を足すなら別 ADR（ADR-031 D8・根拠は項目数に負担の証拠がある [V121]）。段 1 は Q1 摩擦・Q2 前進・6 択で 3 問が埋まっている。用語の上でも、休憩・身体回帰の文脈で「消耗・回復」の語は禁止されている（`docs/glossary.md` 禁止用語・限定資源モデルの語彙）。
5. ADR-041 D3 は、同じ信号を招待の契機とアウトカムの両側に置かないと決めている。

## Decision

### D1. 主の対象を行動上の停滞にする（判断 1）

- 主の単位は行動上の停滞で、定義は ADR-042 D3 のまま（凍結までは C0 を仮に使い、C1・C2 は感度。定義の選択は C4 で H1・H2 を確かめた後に事前登録で決める）。
- 詰まり・熟考・外部資料・会話・離席などは、停滞の中身として 6 択（ADR-031）と Q1・Q2 で記述する。詰まりを特別扱いしない。
- 停滞の始まりで詰まりを検出したとは書かない（ADR-030 の 9b のまま）。

### D2. H1 は合否ではなく、停滞の中身の内訳の記述として読む（判断 1）

- H1 は「停滞の中で詰まりと申告される割合」を、上限 p* との比べの判定ではなく、6 択の各類の割合として区間つきで報告する記述にする。事前登録 S1-C1 の種別を「判定」から「記述」へ改める（割合の単位・区間の作り方は S1-C1 のまま事前登録で決める）。
- H2（空回り）・H3（先回りの弱さ）を判定のまま残すか記述に改めるかは、事前登録の改訂で決める（本 ADR では決めない）。
- 内訳は無作為の時刻の申告から作るので、割合の単位（時間の割合か停滞の件数の割合か・S1-C1 で未定）の選び方によって、長い停滞ほど当たりやすい偏りと、離席中に未回答が増えて離席が少なく見える偏りが効く。扱いは事前登録で決める。

### D3. 段 1 の収集は変えない

- 問い（Q1・Q2・6 択の 3 問）・申告の幅（直前の 30 秒）・無作為の枠を主にすること・問いへの同意を参加の条件にすること（ADR-043 D5〜D7）は変えない。段 1 の同意文書の問いの部分は、本 ADR で変わらない。
- 確証の核 L0（X 摩擦・Y 前進の 2 軸と Q1・Q2 との個人内の順序の一致）は変えない。

### D4. デスク疲労に近いものは、既存の記録から作る副の記述の量だけで扱う（判断 2）

- 連続作業の長さ・打鍵のリズムの崩れなどを、既存の記録から作る副の記述の量にする。問いは足さない。
- これらの量を「疲労」と呼ばず、中身で呼ぶ（例: 連続作業の長さ）。疲労そのものについては主張しない。AI 疲労の研究（AF-*）の量と混ぜない。
- 量の定義は段 1 の事前登録で決める。

### D5. 段 2 の契機を探す的を、詰まりの手前から停滞へ読み替える（判断 1 の帰結）

- 判断 1 から導いた帰結で、研究者の選択として個別に採ったものではない。ADR-041 D2 の最後の項の「詰まりらしい型が見えれば」を、「招待の的にする停滞の型が見えれば」と読む。
- 契機の中身と手順は ADR-041 D2・D3 のまま変えない。停滞の長さは事後にしか決まらないので契機の中身にしない（ADR-041 D2）。契機に使えるのは、停滞の始まりまでの手の様子・作業の中の位置など、契機の時点で見える量だけである。主要アウトカムは ADR-041 D4 の手順で決める。

### D6. 招待の望ましさの扱いは保留する（判断 3）

- 段 1 は招待を出さないので、段 2 の設計を始めるときに決める。保留した論点（ADR-033 D3・D5 の制約、招待の面に受諾の記録経路が無いこと）は判断 3 にある。

## Alternatives

| 案 | 採らなかった理由 |
|---|---|
| 詰まりを主のまま（ADR-043 のまま） | 研究の成否が、行動からは見分けにくい状態の当て方に懸かる。詰まりの申告が少ないと件数がたまるまで長い |
| 疲労を主にする | 疲労の申告という別のラベルが要り、3 問の上限（ADR-031 D8）に当たる |
| 1 日の終わりに短い疲労の問いを 1 つ足す | 同意文書と実装が増え、1 日 1 件で少人数では件数が少ない |
| ADR を起こさず steering だけにする | ADR-043 Context 1 と事前登録 S1-C1 の「判定」が ADR の上では生きて見える |

## Consequences

### 良くなること

- 主の単位が時計で決まり、見えない状態を当てることに研究の成否が懸からない。
- 段 1 の収集と同意文書の問いの部分を変えずに済む。
- 身体回帰の招待と的が素直に結び付く。

### 代償

- 「詰まる前に差し出す」という言い方が弱まる。名前（Generative Struggle Engine）と research-positioning §1 の言い方の見直しが要る（別タスク）。
- H1 を記述にすると、段 1 で反証できる主張が減る。確かめられる主張は L0 と、判定のまま残す H のぶんになる。
- 停滞は時計で決まる事実だが、その長さは事後にしか決まらず、契機には使えない（ADR-041 D2）。招待を「長く止まっている」に結び付けるとき、契機の時点で見える量だけで近似することになる。
- 疲労については何も言えない。

### 決めずに残すもの

- H2・H3 を判定のまま残すか（D2）。
- 停滞の定義の選択の規則（S1-E7・ADR-042 D3）は「H1・H2 のどの結果でどれを選ぶか」で書く前提だった。H1 が記述になったので、選択の規則を何で書くかを事前登録の改訂で決める。
- ADR-042 D5 の「詰まりの申告の件数の下限」は、criterion 直結の段のラベルを詰まりのままにする限り残る。ラベルの対応づけ（下の項目）と併せて決める。
- 副の量の定義（D4）。
- 招待の望ましさの扱い（D6）。
- MhD の criterion 直結の段のラベルを、詰まりから停滞の中身のどれへ対応づけるか（MhD の再考・別タスク A）。
