## Context

1. ADR-047 D1 は GSE の主張を「本文を保存しない観測で、停滞の中身をどこまで見分けられ、どこで系は判断を保留すべきか」に置いた。見せ場（詰まる前に助ける）が弱くなった。
2. 手跡（打鍵だけで動く背景の層と下の縁の帯）の要件は、「本人には自分の手のものと分かる」と「本人にも他人にも状態として読めない」の同時成立である（tangibility 判断 28）。背景は打鍵だけで動き、推定を契機にしない（handmark-expression 判断 2・3）。育たず溜まらない（tangibility 判断 9）。
3. 研究者は、慣性のある背景の試視で「速く打ったから速く動いた」「自分の作業が一緒にいる感じ」を面白いとした（handmark-why-interesting 判断 2）。1 人・設計者本人・伏せていない試視である。同期の自己報告は期待で膨らみうる（S-CO・判断 11・12）。
4. ADR-043 D4 は手跡の効果を前期（なし）と後期（日ごとに無作為）で見ると決め、動機づけと同期・共生の問い方を保留 1 に残した。
5. GSE の O1 のモードには「セッション終了」のボタンが無く（`src/components/Dashboard.tsx:725`・終了はトレイの「GSE を終了」）、記録は一時停止（`src-tauri/src/recording.rs` の `set_paused`）だけを持つ。

## Decision

### D1. 手跡を、ADR-047 の「保留」の裏側の柱として位置づける

- 系は、状態を判断できない所では判断しない（ADR-047 D1）。その所でも、本人の手の痕跡（手跡）だけは返す。これを保留への設計の答えとして、位置づけの中に置く。
- 手跡は段 1 の後期に残す（ADR-043 D4 のまま）。
- 動機づけと共生（同期・共存の感覚）は副の探索の量にし、効果を主張しない。

### D2. 手跡が返すのは行為の性質だけで、系の判断は返さない

- 行為の性質（速さ・リズム・止まり）は、本人が手跡から感じ取れてよい。
- 系の判断（`p_stuck`・`level`・停滞の中身の推定）は、手跡から読めないようにする。確かめ方は「速さを差し引いた後で、系の判断を当てられないこと」。自己認識と機械の再識別を同じ刺激で対に測る。やり方は手跡を main に入れるタスクで決める。
- ADR-025 D1 の規則（本人が読む面に、本人の状態を量として読める表示を置かない）に、手跡も従う。手跡は数値・順位・達成度・累計を出さず、育たず溜まらない。行為の動きを連続の写像で見せることは、量として読める表示に当たらないとする。ADR-025 の Accepted の射程（層 A・D2）は広げない。手跡についての同じ規則は、本 ADR で決める。

### D3. 動機づけと共生は、日の終わりにアプリから尋ね、翌朝に拾う

- 自主的な記入にしない。アプリから 1 日 1 回、2〜3 項目（10 秒ほど）を尋ねる。
- 今日の作業への動機づけは、前期から尋ねて基準にする。手跡との同期・共存の感覚は、後期の手跡ありの日だけ尋ねる。
- 主の契機は「夕方の時間帯に打鍵が一定時間途切れたとき」。トレイの終了と一時停止は補助の契機にする（Context 5）。時間帯と途切れの長さは事前登録で決める。
- 当日に答えが無ければ、翌朝の最初の起動で 1 回だけ「昨日の作業について」と尋ね、「遅れた回答」の印を付けて当日の回答と分けて解析する。
- 抜けた日は欠測のまま残し、回答率を手跡あり・なしの日ごとに報告する。回答率が条件で大きく偏ったときに読み方を弱める基準は、事前登録に書く。
- 無作為の時刻の問い（C4）は変えない。

## 上書き・読み替えの範囲

- ADR-043 保留 1（動機づけと同期・共生の問い方）は、D3 で問う時点と回数を決めた。尺度の文はまだ決めていない（下の「決めずに残すもの」）。
- ADR-043 D4（手跡の前期と後期）は変えない。
- ADR-025 は変えない（D2 は射程を広げず、手跡について同じ規則を本 ADR で置く）。
- ADR-047 は変えない。D1 は ADR-047 D1 の主張に、手跡の役を足すだけである。

## Alternatives

- 位置づけ: 段 1 に残すが主張に入れない／別のトラック（EH の系譜）に分ける。前者は手跡の役が宙に浮き、後者は見せ場を失う。
- 境: 速さも読めないようにする（同期の感覚が消えうる）／伏せた比べの後で決める。
- 問い方: 当日にアプリから尋ねるだけ（抜けが増えうる）／C4 の問いに足す（負担と作業への干渉が増える）／後期の終わりに 1 回だけ（あり・なしの日を比べられない）／自主的な記入（忘れ方が条件で違うと比べが偏る）。

## Consequences

- 位置づけが「判断しない系」と「行為を返す面」の 2 本になり、見せられる形（メディア表現）が主張とつながる。
- 動機づけと共生は副の量なので、効果が見えなくても主張は崩れない。逆に、見えても主張にしない。
- 手跡が速さを返すことで、本人は自分の打ち方を見て変えうる（反応性・ADR-043 Context 6）。後期の割付の総効果に、この反応性も含めて読む。
- 日の終わりの問いが、停滞や手跡ありの日の印象で答えやすさを変えうる。回答率の層別でそれを見る。

## 決めずに残すもの

1. 動機づけ・同期・共存の尺度の文（先行研究を調べてから・文献のラウンド）。
2. 同期の感覚が「速さが読めているだけ」ではないと区別する対照（handmark-why-interesting 判断 14・15）。段 1 の事前登録の改訂で決める。
3. 段 2 で手跡を出し続けるかと、持ち越しの扱い。段 2 の事前登録の前に決める。
4. 層 A（スマホ）の未決（ADR-017 PS-Q1・Q3・Q5・PM-Q7・Q8・ADR-021 E-6〜E-9・W-1）と ADR-035 の Accepted 化。層 A を実装するときに決める。
5. 手跡を main に入れる時期と、tangibility 枝の ADR-040（手跡の入力を記録しない・Proposed）の番号の振り直し（main の ADR-040 と衝突）。
