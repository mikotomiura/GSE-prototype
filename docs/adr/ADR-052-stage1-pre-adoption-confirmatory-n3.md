## Context

1. ADR-043 D3 は、採択前に研究者本人で段 1 を回して探索とし、確認を採択後の参加者のうち本人を除く 2〜4 名で行うと決めた。設計の地図は、参加者への配布（R9）の前提に倫理審査（R8・担当 PM の大学）を置いている（`docs/architecture/gse-design-map.md:61-62`）。
2. 本人の段 1 は 2026-11-08 に macOS の前期で始まった（ADR-051 Context 6）。
3. 研究者は 2026-11-14 に、本人の段 1 を約 1 週間（手跡の後期まで）回し、問題がなければ採択を待たずに本人以外の 3 名を回すと決めた。基準は「研究として強い方」で、「採択後などとなれば遅い」とした。採択前は審査を受ける道が無い（ADR-039 D1 の 2026-10-11 の注）。
4. O1 は、ADR-014 判断 3 で「倫理審査は不要」と研究者が判断し、4 根拠（本文を取らない・外部へ送らない・止めて消せる・一般公募しない）が全部そろうことを条件にした。この判断は委員会による免除ではない。
5. ADR-039 D3 は、ADR-014 判断 3 を O1 の形成的な収集についての判断として残し、記録の公開と 2 本目の論文（日本語 IME の打鍵の記録を出す論文）には使わないとした。理由は、BRM が委員会の判断を求めること（[V237]・ADR-039 事実 1）と、公開が根拠 2 の崩れる条件に触れることである。
6. 段 1 は O1 の収集の器の上に載る層で、提出・自動起動・導入 ID・区間の削除は O1 の分岐を共有し、変わるのは問いを出すことだけである（`src-tauri/src/s1.rs:1-6`）。
7. 手跡は今 macOS だけにある（ADR-051 D1）。状態は OS に依らない純関数で（ADR-051 D5・`src-tauri/src/analysis/handmark/state.rs`）、漏れは記録から描き直して確かめる（ADR-051 D3）。
8. 研究者は、n=3 の結果の当面の使い道は未踏 IT の応募の材料で、学会や論文誌への投稿は今は深く考えなくてよいと述べた（判断 12）。

## Decision

### D1. 採択前の 3 名を事前登録つきの確認とし、採択後の審査済みの群を同じ事前登録の再現にする（判断 1・3）

- 確認は、本人を除く 3 名で、採択を待たずに行う。事前登録（`docs/preregistration-stage1.md`）は、3 名の記録の C4 を開く前に凍結する（同 §0 の 5 のまま）。
- 採択後に担当 PM の大学の審査を通して集める群は、3 名の前に凍結した事前登録をそのまま使う直接の再現にする。審査の条件で同意の文や収集の細部が変わるときは、凍結の後の宣言で差分だけを記し、解析の規則は変えない。
- 本人の段 1 はどちらの群にも数えず、探索のまま扱う（ADR-043 D3 のまま）。
- 計器（ADR-043 D9）は 3 名の開始の時点で固定し、採択後の群でも変えない。
- 3 名の結果を見た後に定義の不備が見つかっても、採択後の群の事前登録は直さない。直すなら、別の事前登録として探索に戻す。

### D2. 3 名を審査なしで回す根拠は、ADR-014 判断 3 の 4 根拠を段 1 に当て直したものにする（判断 1）

ADR-014 判断 3 は O1 の形成的な収集についての判断だった（ADR-039 D3）。本 ADR はその 4 根拠を、確認を目的とする段 1 の 3 名に当て直す。崩れる条件は ADR-014 判断 3 のまま使う。目的が形成的から確認へ広がることは、4 つの崩れる条件の字のどれにも当たらない。ただし根拠 4 の欄は「形成的サブコホート（判断 1）であり、研究者が直接説明できる範囲」と書いており、本 ADR は前半（形成的）を確認へ改め、後半（直接説明できる範囲）だけを保つ。判断の責任は研究者にあり、所属機関の規程に照らした適法性は主張しない（ADR-014 判断 3 と同じ）。

| # | 根拠 | 段 1 で増えるもの | 当て直しの結果 |
|---|---|---|---|
| 1 | 本文を取らない | 問いの回答（時刻と 6 択のどれか・`src-tauri/src/logger.rs:1211-1214`）、日の終わりの問い（1..5 の 1 項目か答えない・`src/components/DayQuestionCard.tsx:25`）、手跡の日ごとの行（ADR-051 D4） | 条件つきで保たれる。6 択の「外部資料」「会話」は役割カテゴリと意味の上で等しく、ADR-031 は「触れないのではなく、4 条件付きで新たに許可した」と書く（ADR-031 D3 と同 ADR の「却下した主張」3）。根拠 1 は、自己申告に限ることを含む ADR-031 D3 の 4 条件を段 1 が守る限りで保たれる。自由記述・アプリ名・URL・理由は持たない。手跡の入力は記録しない（ADR-050 D2） |
| 2 | ローカル保存のみ（外部提供は同意の範囲だけ） | 研究者への提出（O1 の経路を共有・`s1.rs:3-6`）、個人ごとの集計値と図の公表 | 条件つきで保たれる。公表は D6 の同意の範囲に限り、記録そのものは公開しない。3 名は研究者が直接知る人で、作業の様式・OS・手跡の有無の組み合わせで人が分かりうるので、公表の前に ADR-039 D6 の集計値の点検（少人数のセル・1 人ずつの値・外れ値・公表物どうしの差・[V254]）を当てる（D6） |
| 3 | 止めて消せる | 手跡を切る操作（ADR-051 D2） | 保たれる。一時停止と区間の削除は O1 の分岐を共有する（`s1.rs:4`）。段 1 で足す行種（手跡の日ごとの行など）は、区間の削除の鍵 `"t"` を持ち削除で消えることをテストで縛る（`"ts"` だと消えない・`src-tauri/src/logger.rs:1205-1210`・ADR-031 D6）。日ごとの行（ADR-051 D4）は、その日の表示の量や切った・戻した時刻のような観測から作る量を持つので、時刻キーだけでは足りない。削除の区間がその日に重なったときに、その行を落とすか重なりを除いて書き直すことをテストで縛る（方法は手跡の PR で決める）。どちらも 3 名の配布の前に確かめる |
| 4 | 一般公募をしない | 本人以外の 3 名 | 保たれる。研究者が直接説明できる人に限る。公募に広げた時点で崩れ、再判断する |

- 4 根拠が覆わないもの: 4 根拠は、記録の中身・保管・削除・募集の範囲についての根拠で、画面に出すものと答える負担を扱わない。O1 は画面に何も出さない収集だった（O1 同意 §3 注 C・ADR-043 D8）。段 1 は、無作為の枠の問い・日の終わりの問い・手跡の日ごとの表示を出す。これらを審査なしで行うことは 4 根拠の当て直しでは支えられず、研究者の判断として別に置く。その判断の支えは、問いの数と負担の上限（ADR-031 D8・[V121]）、答えの理由を問わないこと（[V117]）、問いに答えなくてよいこと・手跡を切れること・いつでもやめられること（ADR-043 D7・ADR-051 D2）、医療・心理の介入をしないことである。
- ADR-014 の「確証には使わない」は O1 の記録についての決定で、段 1 は事前登録と同意を分けた別の収集である（ADR-043）。O1 の記録を 3 名の確認に使わない。

### D3. ADR-039 D1・D3 は段 1 に当てない。使い道を限ることで D3 の理由を受ける（判断 1・12）

- ADR-039 D1（承認の後に新しく集める）と D3（ADR-014 判断 3 を使わない）の対象は、記録の公開と 2 本目の論文である。段 1 の 3 名はどちらでもない。ADR-039 D1 の 2026-10-12 の注の「GSE で新しく集めるときは承認を受けてから」は、D1 の対象（2 本目の論文）の言い換えとして読む。
- 3 名の結果の当面の使い道は、未踏 IT の応募の材料とする。
- 審査を開始前に求める投稿先（BRM は開始前の承認を求め、事後の承認では査読に回せないことがあると書く・[V237]）には、3 名の結果を使わない。論文で審査を要するときは、採択後の再現の群を使う。投稿先ごとの規程は、論文を書くときに確かめる。

### D4. 本人の段 1 は macOS で進め、4 つの関門を満たしたら 3 名へ進む（判断 4・5・10）

- 本人の段 1 は、今の macOS のまま前期から後期まで進める。Windows 版の手跡を待たない。
- 3 名へ進む関門は次の 4 つで、数値の閾値は置かない。どれかが欠ければ、直して本人の段 1 を延ばす。
  1. 配線: 無作為の枠で問いが出て、回答の行が欠けなく記録される。
  2. 手跡の後期: 割付の表と入口の門のとおりに出た（macOS で確かめる）。
  3. 負担: 本人が他人に頼めると判断した。
  4. 事前登録の値が本人の記録で埋まった（`docs/preregistration-stage1.md` §2）。
- 本人の段 1 の計器は、手跡の PR が足されるにつれて変わる（読み替えの表の ADR-043 D9 の行）。関門 1・2 は、3 名に配る版のビルドで本人の記録でも確かめ直す（判断 15）。
- 回答率や詰まりの申告の率が低いことは、止める理由にしない。事前登録の値（最低の件数・期間・問いの頻度）で受ける。
- 本人の記録からの集計は、Claude が集計のスクリプトを書き、研究者か Claude が回す。Claude が見るのは件数・率・分布の要約だけで、行の中身と個々の申告は出力しない。集計も Codex に送らない。

### D5. 3 名は両 OS で募り、Windows 版の手跡が通るまで始めない（判断 6・7）

- 3 名は、作業の様式の対照（ADR-047 D5）で選び、OS では絞らない。
- 3 名の開始は、Windows 版の手跡が通るまで待つ。macOS に限って始める退路は置かない。
- Windows 版が「通った」とするのは、次の 3 つを実機で確かめたときである。手跡の状態と写像は macOS と共通に保つ。
  1. ADR-050 の条件 (a)（Windows の位置とクリックの読み）。
  2. 背景と帯が割付の表のとおりに出る。
  3. 段 1 の通し 1 本: Windows の実機で、無作為の枠の問いと日の終わりの問い（手跡ありの日の項目を含む）が出る・回答が記録される・起動し直しても日付が変わっても割付が保たれる・提出が届く（判断 13・15・手跡の確かめと同じ機会に行う）。
- 漏れの判定（ADR-051 D3）は記録から描き直すので OS に依らない。本人が Windows で段 1 を回すことは求めない。Windows の参加者の記録でも、確認の段の中で D3 の判定を回す。

### D6. 3 名の同意に入れるもの（判断 8）

- 参加・問い（問いへの同意は参加の条件・ADR-043 D7）・手跡の後期（どけた回数を記録するなら、その項目を含む・ADR-051 D2）。
- 匿名の個人ごとの集計値と図の公表。公表の前に ADR-039 D6 の集計値の点検を当て、公表する属性（作業の様式・OS など）と時刻の粒度を、人が分からない範囲に限る。
- 記録そのものの公開（ADR-039 D4 の第 3 層）は求めない。
- 同意の型は O1 のもの（ADR-014 D7）を使い回す。中身は別のタスクで書く。

### D7. ADR-031・ADR-032 は、3 名の同意文書の承認で Accepted にする（判断 9）

- ADR-043 D8 の「段 1 の同意文書の承認」は、3 名の同意文書を研究者が承認することと読む。採択後の群の審査版は、同意の文の差分だけを記す。
- 審査が問いか計器の中身の変更を条件にしたときは、ADR-031 か ADR-032 の改訂として扱う。

## Alternatives

| 論点 | 却下した案 | 理由 |
|---|---|---|
| 審査なしの根拠 | 採択前でも審査を探す／3 名も探索に留める | 前者は開始が審査待ちで遅れ、無料の道が見つかっていない。後者は確認が採択後に戻り、研究者の「採択後では遅い」に反する |
| 採択後の群 | 3 名の後に事前登録を改訂する／今は決めない | 改訂すると採択後の群は概念の再現に弱まり、結果を見た後の改訂が入る |
| 進む条件 | 回答率などの下限を置く／研究者の判断だけ | 本人 1 名・約 7 日では閾値の根拠が無い。判断だけでは何を確かめたかが残らない |
| 集計の手 | 研究者だけが回す／Claude が行を読む | 行の中身が会話に入ると定義づくりに混ざりうる |
| OS | macOS に限る／Windows の人は前期だけ（Claude の推奨は macOS に限る案） | 研究者が両 OS をそろえる方を選んだ |
| 退路 | 条件で macOS に切り替える／募集の結果で決める（Claude の推奨は条件で切り替える案） | 研究者が退路を置かない方を選んだ |
| Windows 版の範囲 | 本人が Windows でも段 1 を回す | 漏れの判定は記録で決まり OS に依らない |
| 公表の同意 | 集計値だけ／記録の公開まで | 集計値だけでは一人ずつの結果を出せない。記録の公開は照合の危険がある（ADR-039 D6）ので審査なしの群では求めない |
| Accepted の時点 | 採択後の審査版の承認まで待つ | 3 名が計器を固定して始める最初の群で、採択後の群は同じ計器の再現になる |

## Consequences

### 良くなること

- 確認を採択前に事前登録つきで行え、採択後の群を直接の再現として重ねられる。主張の上限（個人ごとの結果と事例をまたいだ再現・ADR-043 Context 5 が引く small-n 判断 2・6）に合う。推論は個人の中に限る（ADR-042 D1）。
- 本人の探索と事前登録の値の決定は、Windows 版の手跡と並行して進められる。

### 代償

- 3 名の開始が Windows 版の手跡の実装と実機での確認に掛かる。Windows の実機は G-GEAR が 11 月中ふさがっており、職場の HP Z2 が代わりになる。採択の前に始められないこともありうる。
- 3 名の結果は、審査を開始前に求める投稿先に使えない。
- 3 名で見つかった定義の不備を、採択後の群で直せない。
- 審査なしの判断は研究者の判断で、委員会による免除ではない。

## 決めずに残すもの

- 事前登録の値のすべて（本人の探索の後・`docs/preregistration-stage1.md`）。3 名のうち途中でやめた人の補充と、S1-G1 の「確認の記録を開ける手順」も事前登録で決める。
- 3 名の同意文書と配布物（段 1 の収集の型・タグ・ADR-032 の計器を入れるか）。
- Windows 版の手跡の形と実装の分け方。
- 3 名の結果を論文に使うか・どの投稿先か。
