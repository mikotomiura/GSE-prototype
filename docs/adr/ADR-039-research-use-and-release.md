## Context

研究者は 2026-10-07 に方針を示した: G1 / O1 で集めた**人の打鍵の記録を論文として公開したい**。個人が分からないよう加工し、
ログだけでなく集計値も出しうる。投稿先は **BRM（1 本目の IME 論文と同じ）を想定**する。所属大学は倫理審査を扱っていない可能性がある。
O1 は **2026-10-08 に v0.1.40 で始まる**。

一次資料で確かめた事実:

| # | 事実 | 一次 |
|---|---|---|
| 1 | BRM は「研究が審査委員会に**承認された（または免除された）**」と書くことを求め、免除なら理由も書く。⚠️ **研究開始前に承認が無ければ、遡及承認は通常得られず、査読に回せない場合がある**（編集者の裁量） | [V237] |
| 2 | BRM は**参加への同意とは別に、データの公表への同意**を投稿前に取ることを求める | [V237] |
| 3 | BRM は type 4 のデータ方針で、生データを含む資料が非商用の研究者に自由に入手できることを投稿の前提にする | [V237] |
| 4 | ADR-014 判断 3 の「倫理審査は不要」は**研究者自身の判断**であり、委員会による免除ではない。本文も「所属機関の規程に照らした適法性を主張しない」と書く | ADR-014 判断 3 |
| 5 | ZEN大学の公開資料（研究不正の防止規程ほか）に、人を対象とする研究の審査委員会・手続きは**見つからなかった**。⚠️ 学則と一部の規程は読んでいないので「無い」とは断定しない | 下位エージェントの調査（`.steering/…/decisions.md` 判断 3） |
| 6 | G1 の同意文書は「打鍵の**生ログは公開しません**」「公表するのは集計した数値だけ」と約束している | `experiments/20260801-controlled-friction-task/consent.md:122-125` |
| 7 | O1 の同意文書（フォームの正本）に**公表・公開の記述は 0 件**。「研究利用」は中身を説明していない | `Form_O1/GSE_O1_Form_Builder.gs` の `o1ConsentFormDescription_` |
| 8 | O1 の保管の約束は「研究者が復号したものは解析が終わってから 30 日以内に削除」。**公開する加工記録はこの規定の外にある**（約束に無い） | 同上・`O1_RETENTION_PLAINTEXT` |
| 9 | 打鍵の押下・解放の時刻だけでも本文の情報が漏れうる（temporal side channel） | [V194] |
| 10 | G1 の同意フォームは「どの文字を打ったか（**本文の復元はできません**）」と書いている | `Form_G1/GSE_G1_Form_Builder.gs:244` |

⚠️ 事実 1 が要点である。O1 は承認も免除も無いまま明日始まる。→ **O1 のデータを 2 本目の BRM 論文に使えるかは、編集者の裁量に左右される**。

## Decision

### D1. ★ 2 本目の論文のデータは、審査委員会の承認（または免除）を受けてから**新しく集める**（研究者判断 2026-10-07）

- 承認を受けた研究計画・同意文書（公開への同意を含む・D4）の版で、収集を**始める**。
- O1（2026-10-08 開始）は予定どおり始め、ADR-014 の**形成的な収集**のまま扱う。
- 2 本目の論文に使う収集は、O1 の延長ではなく**別の研究**として計画する（事前登録・同意・プールを分ける。ADR-034 の分け方に倣う）。

### D2. ★ 条件つきで O1 のデータも採る（研究者判断 2026-10-07）

**次の 3 つが全部そろったときだけ**、O1 のデータを 2 本目の論文に使う。1 つでも欠けたら使わない。

| # | 条件 | 確かめ方 |
|---|---|---|
| a | BRM の編集者が、収集開始後に受けた審査でも**査読に回せる**と書面で答える | 問い合わせ文 A（`inquiry-drafts.md`） |
| b | 審査委員会が「既に集めた O1 の記録の解析と公表」を**審査し、承認か免除をする** | 問い合わせ文 B / C |
| c | **ログの公開**は、O1 の参加者に改めて尋ね、**同意を得た人の記録だけ**にする（集計値の公表は D4 の範囲で別に扱う） | 同意文 v2 の第 2・3 層 |

⚠️ 条件がそろっても、論文には**開始後に審査を受けた経緯をそのまま書く**（BRM は免除の理由を書くことを求める [V237]）。

### D3. ADR-014 判断 3 は**公開と 2 本目の論文には使わない**

- 判断 3 の 4 根拠（content-free / ローカル保存 / 停止・削除可 / 一般公募なし）は、O1 の形成的な収集についての判断として**そのまま残す**。
- ⚠️ ただし公開は根拠 2 の「崩れる条件」（研究用の外部提供を同意なしに行う）に正面から触れ、かつ BRM は**委員会**の判断を求める（事実 1・4）。→ 公開と 2 本目の論文については、**研究者の自己判断で「不要」としない**。
- 経路の候補（★ どれが使えるかは問い合わせで確かめる・⚠️ 私はどれも可否を確かめていない）:
  1. **ZEN大学**: 委員会があれば審査、無ければ「審査を扱わない／対象外」の**書面**と、日本心理学会の方針 [V241] にならい**所属機関の長による承認**で代えられるかを尋ねる。
  2. **所属機関の外の有料の委員会**: 例として 1 件 20 万円（税別）・最長 5 週間の委員会がある [V242]（所属の無い個人・学生を受けるかは未確認）。
  3. 学会の委員会: 会員外を受ける非医学系の委員会は**見つからなかった**（未踏査を含む）。
- ⚠️ 「人を対象とする生命科学・医学系研究に関する倫理指針」の対象は健康・傷病・医療・ゲノムの知識を得る研究であり、本研究がそれに当たるかは研究目的による（下位エージェントの報告。私は指針の逐語を確かめていない）。**指針の対象外でも、BRM の要件（事実 1）は別に残る。**

### D4. 同意は**段階式**にする（同意文 v2・O1 と 2 本目で揃える）

| 層 | 同意の対象 | 断ったとき |
|---|---|---|
| 1 | 参加と記録（現行の同意項目） | 参加しない |
| 2 | **集計値の論文での公表**（個人が特定できない数値・分析スクリプト） | ⚠️ 集計からも外す |
| 3 | **加工した記録の公開**（項目・加工・公開の形式・撤回の限界・再識別のおそれを具体的に書く） | 記録は公開しない（参加は続けられる） |

- 第 3 層は**任意**とし、断っても参加に影響しない。**答えが無い場合は公開しない**（opt-in）。
- 同意の**版**を記録する（どの版で何に同意したか。削除台帳と同じ作法）。
- ⚠️ 第 3 層に書くべきことは `consent-v2-draft.md` にまとめた（再識別・本文の部分的な復元・健康状態の推定のおそれ・撤回の限界・保管規定との関係）。

### D5. 公開の形式 — 【決 5】（推奨: **申請制**）

| 案 | 中身 | ⚠️ 代償 |
|---|---|---|
| A（推奨） | **申請制**（研究目的・再識別を試みない・再配布しないことへの同意を条件に渡す）。BRM には「プライバシーのため条件つき」と Open Practices Statement に書く | BRM の type 4 の「自由に入手できる」の例外に頼る（⚠️ 例外の逐語は自分で確かめていない [V237]）。申請に応じる手間 |
| B | 誰でも取れる形（リポジトリで公開・ライセンスつき） | 公開後は撤回できず、再識別の試みを止められない |
| C | 集計値と分析スクリプトだけを公開し、記録は公開しない | BRM の type 4 は raw data の入手を前提にする（事実 3）ので、記録を出さない理由を Open Practices Statement に書く必要がある。代わりに第 3 層の同意は要らない |

ライセンスは【決 5-b】（A なら利用規約、B なら CC BY-NC などを候補にする）。

### D6. 公開前の関門 — 加工した記録に**自分で攻撃を試し、通らないことを確かめてから**出す

- 対象: 公開候補の加工済みの記録（第 3 層に同意した人の分だけ）。
- 試すこと: (i) **本文の復元**（IME 論文の評価一式と同じ形で、打鍵の種別と時刻からの復元の度合いを測る）、(ii) **個人の再識別**（同じ人の別のセッションどうしを結び付けられるか）。
- 合格の基準（数値）は**データを見る前に決めて記録する**【決 6】。⚠️ 私は数値を出さない。
- 加工の候補と、文献が示す効き目（★ 加工だけで安全とみなさない根拠）:
  - 時刻の丸めは、攻撃側の前処理で効き目を失いうる [V240]（provisional）。
  - ランダムな遅延は識別率を下げるが限定的（25 ms で約 20%）[V239]（provisional）。
  - → ★ **加工の効き目は文献から決めず、上の (i)(ii) で実測する。**
- 必ず落とすもの: **`o1_install_id`**（ADR-038 D2 が「長期の相関子」と認めている）・絶対時刻（日付・時刻は相対化する）・`app_version` 以外の環境の記述。

### D7. 個人情報保護法は**例外に頼らず、同意で受ける**

- 個人情報保護法は本人の同意の無い第三者提供を原則禁じ、学術研究の例外（第 27 条第 1 項第 5 号ほか）は提供者が「学術研究機関等」（大学…又は**それらに属する者**）であることを要件にする [V238]。
- ⚠️ 研究者がこれに当たるか、仮名 ID 付きの打鍵ログが「個人情報」に当たるかは、条文からは決まらない（法的判断をしていない）。
- → ★ **例外の適用を前提にせず、第 3 層の同意（D4）で受ける。** 例外の解釈が問われる設計にしない。

### D8. 既存のデータの扱い（研究者判断 2026-10-07）

| データ | 扱い |
|---|---|
| **G1（収集済み）** | ★ **集計値と分析スクリプトだけ**を公表しうる（同意の範囲内・事実 6）。**記録は公開しない**。再同意は求めない |
| **O1（2026-10-08〜）** | 形成的な収集。記録の公開は D2 の 3 条件がそろったときだけ。集計値の公表は、2026-10-07 の改訂で足す一文（`o1-consent-today-proposal.md`）が反映されればその範囲で |
| **Phase1（P006〜P014）** | 本 ADR の対象外（扱いを変えない） |

## 判断 1（研究者判断 2026-10-07）— 今日の O1 の同意改訂に、公開の可能性を残す一文を入れる

逐語「将来、加工した記録を研究成果として公開する可能性があります。その場合は、あらためてお尋ねし、同意をいただけた記録だけを公開します。」
置き場所と同意項目の案は `.steering/20261007-research-use-and-release/o1-consent-today-proposal.md`。⚠️ 一文は**再同意の代わりにならない**。

## Consequences

- 2 本目の論文は、**審査の経路が決まり、新しい収集が終わるまで書けない**。1 本目（IME・合成入力のみ）の予定は変わらない。
- O1 は予定どおり始まる。O1 のデータを 2 本目に使う可能性は、D2 の 3 条件に左右される。
- ⚠️ **事実 10**: G1 の同意フォームの「本文の復元はできません」は、[V194] と IME 論文の本文復元の分析に照らすと**言い過ぎになりうる**。G1 の記録は公開しない（D8）ので公開の危険は増えないが、**研究者の手元でも復元が部分的にできうる**ことを参加者は知らされていない。→ 【決 9】G1 の参加者に知らせるか（推奨: IME 論文の復元の結果が出た時点で、結果に基づいて判断する）。同意文 v2 ではこの言い方を使わない。
- ⚠️ **事実 8**: 公開する加工記録は、保管の約束（30 日・2 年・5 年）の外に恒久的に残る。同意文 v2 の第 3 層で**別の扱いとして明記**する。
- 審査に費用（例: 20 万円）と期間（最長 5 週間）がかかりうる [V242]。

## 却下した案

- **ADR-014 判断 3 のまま公開する**: BRM は委員会の判断を求める（事実 1）。研究者の自己判断では倫理声明が書けない。
- **O1 の開始を延ばして審査を先に通す**: 研究者が採らなかった（2026-10-07）。O1 の形成的な問いは公開と独立に進められる。
- **G1 の参加者に再同意を求めて記録を公開する**: 研究者が採らなかった（2026-10-07）。G1 は「生ログは公開しない」と約束済み。

## 見直しの条件

- IME 論文の本文復元の結果が出たとき（D6 の関門の設計・【決 9】）。
