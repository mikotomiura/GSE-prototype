- **決定者**: 研究者 ＋ Claude Code
- **関連**: ADR-031（6 択とプローブ・本 ADR が対象と M9 を読み替える）/ ADR-032（計器の変更の裁定・本 ADR が対象と D8 を読み替える）/ ADR-040（本体の介入は招待）/ ADR-041（招待の契機は停滞の分解の後・同じ信号を契機とアウトカムの両側に置かない）/ ADR-042（MhD の単位）/ ADR-014（O1・R3）/ ADR-034（G1 と O1 の並行）

## Context

1. 停滞（ADR-030 の C0）が詰まりなのかを確かめる仮説 H1〜H3（synthesis §5）は、どれも詰まりの自己申告（C4）が無いと確かめられない。MhD の criterion 直結の段（ADR-019 D1 の M2・単位は ADR-042）も、C4 をラベルにする。
2. C4 は O1 で取らないと決めた（`.steering/20261103-gse-stall-candidates-c1c2c6/decisions.md` 判断 9）。O1 はまもなく終わる。申請なしで取れる公開データに、作業の途中に時刻つきで取った状態の申告と打鍵を同じ人の同じ作業で持つものは見つかっていない（`docs/literature/20261102-public-data-beyond-keystrokes.md` の claim 6）。
3. ADR-031（Proposed）は 6 択とプローブを O1 本体で出すと決め（D1）、Accepted の条件を O1 の同意文書の改訂の承認にしている。ADR-032（Proposed）も同意文書 §3 の表に 1 行を要求する。ADR-031 M9 は 6 択の配布を ADR-032 と同じリリースに束ね、その理由を「同意の再開封を 1 回にする（2 回に割ると被験者に 2 回説明することになる）」としている（ADR-031 M9 の追補・ADR-032 D8）。
4. 研究の位置づけの計画（`docs/research-positioning.md` §1・`docs/wbs-verification-halfyear.md` B1〜B4 の 2026-10-31 改訂）は、1 段目で招待を {推定器（`friction_rising`）/ 頻度を合わせた無作為 / なし} に割り付ける。ADR-041 D1 は `friction_rising` を今の推定の出力の上がりで埋めないと決め、中身は停滞の分解の後に決める（D2）。推定器の腕の中身が空のまま比べると、効果が見えないときに理由が契機か招待かを分けられない。
5. 読み手は HCI の設計者・研究者で、採択後に見込む人数は研究者本人を含め 3〜5 名、主張の上限は個人ごとの効果と事例をまたいだ再現である（small-n 判断 2・6、next-study-design 判断 1）。倫理審査は採択後に担当 PM の所属大学で出してもらう道を探る（small-n 判断 1）。
6. 研究者は、試作中の手跡（打鍵で動く背景の層と下の縁の帯）の効果（作業への動機づけ・手跡との同期と共生の感覚）を次の検証に加えることを提案した（next-study-design 判断 5）。手跡は打鍵だけで動き、推定器の出力を契機にしない。ただし自分の打鍵が画面に見えると打ち方・止まり方が変わりうる。デジタルのその場の計測も反応性を持ちうる（[P163] のプール効果 ds = 0.27–0.30）。

## Decision

### D1. 次の検証を段で分け、段 1 では招待を出さずに C4 を取る（判断 2）

- 段 1: 招待を出さずに C4 を取り、H1〜H3 と L0 を確かめ、招待の契機（`friction_rising` の中身）と主要アウトカム（ADR-041 D4）を決める材料にする。
- 段 2: 契機と主要アウトカムが決まった後に、招待の 3 腕（推定器 / 頻度を合わせた無作為 / なし）。WBS の B1（統制課題の 3 腕）は段 2 に後ろ倒しになる。
- 招待が見える環境の申告は `post_intervention` として分ける既存の規約（glossary「ラベルプール」）があり、段 1 の申告は招待に汚されない。

### D2. 段 1 の収集は自然作業の長い記録を主にする（判断 3）

- O1 型の長い自然作業の記録で C4 を取る。H1・H2 の割合はふつうのデスクワークの頻度でしか意味が無く、L0 も自然作業の長い記録を時間順に分けて判定する。ADR-031 D2 は統制課題を「自然な頻度を推定する場ではなく、似た観測系列を見分けられるかを反証する場」としている。
- 短い統制課題を「問いの理解と時刻の対応の確かめ」に限って併用する案は候補として残す（頻度の推定には使わない・判断 11 の 6）。
- O1 の計器・配布・同意の型を使い回す。段 1 を `--mode o1` のまま回すか、別の収集の型を立てるかは決めていない（下の「決めずに残すもの」）。

### D3. 研究者本人で段 1 を先に回し、探索として扱う（判断 4・13）

- 採択前に本人で段 1 を回し、問いの配線・回答率・詰まりの申告の率・申告と停滞の段の対応を確かめる。件数の見積もりと事前登録の材料に使い、探索として記録する。
- 確認は採択後の参加者のうち研究者本人を除く人（3〜5 名から本人を引いた 2〜4 名）で行う。本人は H1〜H3 と C1・C2 の定義を知った上で申告するので、確認の事例に数えない。
- 探索に使った記録（本人の段 1・O1 の見た 14 日）と確認に使う記録を分け、確認の記録を開ける条件を事前登録に書く。

### D4. 手跡の効果は、前期（手跡なし）と後期（日ごとに無作為）に分けて見る（判断 5・6・12・13）

- 前期: 手跡なしで C4 を取り、H1〜H3 の主にする。
- 後期: 初日は手跡を必ず表示し（割付の外）、2 日目以降を日ごとに手跡あり・なしへ無作為に割り付ける。主の解析は後期の中の日ごとの比べで、読み方は「手跡を知った後の、その日の表示の上乗せ」とする。主の量は割付の総効果で、問いの密度で調整した解析は副にする（密度は手跡の後の変数になりうる・判断 11 の 5）。
- 前期の長さ（手跡を始める日）を人ごとに無作為にずらす。導入の前後の変化は、導入の時点をずらした多重ベースラインとして読む副の解析にする（開始時点の無作為化の検定は [V300]・単一事例の設計の基準は [V299]・処遇の順の無作為化の検出力は [V335]）。2〜4 名ではずらせる段が少なく、[V299] の「3 回の実証」に届くかは人数と各人の情報量しだいである（届くとは書かない）。
- 後期の C4 は H1〜H3 に混ぜない。手跡ありの日の申告を `post_intervention` のように分けたラベルプールにするかは事前登録で決める。割付の上の開始日・初めて表示した日・累積の表示の量を分けて記録する。
- 動機づけと同期・共生の感覚の問い方・尺度（保留 1）は本 ADR では決めない。

### D5. C4 はアプリ内のプローブで出し、無作為の枠を主・層化を補いにする（判断 7）

- 本体のプローブで出す（ADR-031 D1 の「本体で出す」を段 1 に当てる）。H1〜H3 は無作為の枠の申告で読む。
- 低操作の区間の終わり・復帰の層化（ADR-031 D2）は件数の補いとして `stratum` で分けて記録し、分けて読む。層化した申告を主の件数に混ぜない（ADR-042 D1 と同じ）。
- 無作為の枠の頻度を先に確保し、層化に頻度の上限を使わせない。抑制・未回答・回答の遅れを別に記録する（判断 11 の 3）。

### D6. 申告が指す時間の幅を問いの文で示し、既定は今の 30 秒にする（判断 8・13）

- 幅を問いの文に入れ、解析もその幅で停滞の段（停滞の外 / [s, t0) / t0 の後 / C1 の段）に対応させる。
- 既定は今のプローブの「直前の30秒」（`src/components/ProbeCard.tsx:181`・解析の窓 t−31s〜t−1s は `src-tauri/src/analysis/probe_scheduler.rs:44-48`）で、6 択も同じ幅に揃える。30 秒から変えるなら、ラベルの窓の実装・ウォームアップ・既存の較正評価との互換も変わる。
- 幅が段の境界をまたぐときの類（混在・時点不明）と、回答の操作を停滞の判定から除く規則は事前登録で決める。

### D7. 問いへの同意を段 1 の参加の条件にする（判断 10）

- 段 1 は問いを含む検証として募り、問いに同意しない人は参加しない。個々の問いには答えなくてよく、途中でやめる・削除を求める道は残す。

### D8. ADR-031・ADR-032 の対象を O1 から段 1 に移し、Accepted の条件を段 1 の同意文書の承認に読み替える（判断 9）

- ADR-031 の「O1 本体のプローブ」「O1 で取る」は「段 1 の本体のプローブ」「段 1 で取る」と読む。O1 では C4 を取らない。
- ADR-031 と ADR-032 の Accepted の条件（同意文書の改訂の研究者の承認）は、段 1 の同意文書の承認と読む。段 1 の参加者は新しく募るので、O1 の同意文書の改訂（ADR-031 M2）は要らなくなる。O1 同意 §3 注 C（「この記録では画面に何も出しません」）は O1 のまま守られる。
- ADR-031 の D2〜D8（層化・規約・行種・第三者・区間削除・解析の代償・負担の上限 [V121]・理由を問わない [V117]）の中身は変えず、段 1 に当てる。D5 の提出猶予の実体（`o1.rs` の 48 時間）は、段 1 が O1 の提出の仕組みを使うときにそのまま当たる。

### D9. ADR-031 M9 の束ねを段 1 では解く（本タスク判断 3）

- 段 1 の配布は ADR-032 の Accepted を待たない。
- 段 1 の計器は始める時点で固定する。ADR-032 の計器（`undo`/`redo` の別行種・`key` 行の修飾キーの 1 ビット）を入れるかは、段 1 の同意文書を書くときに決める。段 1 の途中で計器を変えない。
- 理由: M9 の理由は O1 の参加者に同意を 2 回開け直させないことで、段 1 の参加者は最初の 1 回の同意で始まるので当てはまらない。

### D10. 値と解析の規則は事前登録で決める

- 段 1 の事前登録は `docs/preregistration-stage1.md` に置く。C4 を開く前に凍結する（synthesis 判断 9）。今は草案で、値は本人の段 1 の探索の後に決める。
- 事前登録に書く項目は next-study-design の「事前登録に書く項目」1〜17 と ADR-042 Migration 6 で、対応は事前登録の草案の §4 にある。
- 判断 11 から事前登録へ渡したもののうち、次の 3 つはここに名指しで残す。各人の最低の条件（申告の件数・割付の日数・区間の精度）と最長の期間に届かない人は「判定不能」とする（S1-G2）。H1・H2 の割合の単位（時間の割合か停滞の件数の割合か）を決める（S1-C1・S1-C2）。問いの無い短い区間を無作為に挟む案は、その区間の C4 が取れないので今は採らず、候補として残す（判断 11 の 5）。

## Alternatives

| 案 | 採らなかった理由 |
|---|---|
| C4 と無作為の招待（無作為の時刻 / なし）を同時に取る | 招待が見える日の申告が介入に汚され、H1〜H3 の母集団が割れる |
| WBS のまま 1 段目に 3 腕を置く | 推定器の腕の中身が空（ADR-041 D1）で、効果が見えないときに契機と招待を分けられない |
| 統制課題を主にする | H1・H2 の割合が自然な頻度の量にならない。ADR-031 D2 の統制課題の役割とも合わない |
| 本人を確認の 1 事例に数える | 定義を知った上での申告が確認に入る |
| 手跡を最初から日ごと無作為に | 基準（H1〜H3）が手跡を見た後の記録で汚れる |
| 手跡は段 2 へ（招待 × 手跡） | 条件が増え、各人の情報量が足りない見込み |
| C4 をアプリの外（フォーム）で取る | 層化の引き金は本体しか観測しない（ADR-031 D1）。申告の時刻を打鍵の記録と同じ時計で持てない |
| ADR を起こさず steering だけにする | ADR-031 の「O1 で取る」が ADR の上では生きて見える |
| M9 の束ねを残す | 束ねの理由が段 1 では当てはまらず、段 1 の始まりが ADR-032 の承認に縛られる |

## Consequences

### 良くなること

- 段 1 の申告が招待に汚されず、H1〜H3 と停滞の定義の選択（ADR-042 D3）に使える。
- ADR-031・ADR-032 の Accepted の道が、終わる O1 から段 1 の同意文書に移り、O1 同意 §3 注 C を破る改訂が要らなくなる。
- 手跡の効果を、基準を汚さずに個人の中で見る形が決まる。

### 代償

- 介入の結果が出るのが遅れる。WBS の B1 は段 2 に後ろ倒しになる。
- 自然作業の主で詰まりの申告が少ないと、件数がたまるまで長くかかる（ADR-042 D5 の 2 条件に届くまで）。
- 手跡の後期で 1 人の期間が伸びる。後期には慣れと持ち越しが残り、導入の前後の比べは時期の変化との区別が弱い。
- プローブの発火の配線と `activity_label` の行種の実装（ADR-031 M5）が段 1 の前に要る。
- 層化の引き金は打鍵由来で、推定器の出力からは切り離されるが打鍵の観測から独立ではない（ADR-031 D2 の限界）。

### 決めずに残すもの

- 段 1 を `--mode o1` のまま回すか別の収集の型を立てるか・配布のタグ・同意文書（`next-session-esm-consent-next-study.md` §2 の 2〜6 と手跡の後期の同意項目）。
- ADR-032 の計器を段 1 に入れるか（D9）。
- 動機づけと同期・共生の感覚の問い方と尺度（保留 1）。前期から測るか。
- 事前登録の値のすべて（`docs/preregistration-stage1.md`）。
- 短い統制課題を併用するか（D2）。
