## コメントの論点の要約

- 評価された点: AI への依存が深まる時代に人の試行錯誤を守るという切り口、先行の理論を束ねた設計思想の一貫性、両 OS のプロトタイプを反復して公開してきた実装力。
- 議論の中心: 打鍵のリズムだけで 3 状態を実用精度で判別できるか。
- 指摘: 妥当性の検証が n=1 に近い。テキスト内容や文脈の情報を併用すべきではないか。手紙を書くときの逡巡とナレッジワーカー一般の停滞を同じモデルで捉えられるか。
- 求められたこと: ML としての技術的な裏付けと、介入（散歩の促進）が受け入れられるかのユーザ検証を両輪で進める。仮説検証を重ねて推定の核を磨いてから再挑戦する。
- 筋が通っているとされた点: 段階的な縮退の設計、日本語 IME に対応したデータセットの公開計画。
- 一般的な注意: 二次審査に進むには、PM の誰か 1 人の関心を強く引く尖りが要る。

## 論点ごとの対応（2026-11-15・核と尖りの行は ADR-054 の後に直した）

| 論点 | 今の対応 | 状態 | 根拠 |
|---|---|---|---|
| 打鍵のリズムだけで 3 状態を実用精度で判別できるか | 公開データ 3 種で、停滞・道具の要求の手前 30 秒の推定の上がりを確かめた（AUC 0.49〜0.52・0.53〜0.58 程度の小さい効果は否定できない）。検証した先行予測では手前の信号は見えなかった。同じ時点の状態の識別そのものは、ラベルが無く確かめていない。3 状態の名前を主張から外し、推定は契機を作らない役に下げた。問いを「観測でどこまで見分けられ、どこで判断を保留すべきか」に移した | 先行予測については否定側の結果。識別そのものは未確定（段 1 の C4 から）。転換の説明が要る | ADR-044・046・047、`experiments/20261031-*`〜`20261104-*` |
| 妥当性の検証が n=1 に近い | 1 人を長く深く見る設計（N-of-1・日を単位・個人ごとの区間推定）に組み替えた。本人の探索の後、本人を除く 3 名を事前登録つきの確認として回し、採択後の群を再現にする | 設計は済み。実施は未着手で、今も実質 n=1 | ADR-042・047 D5・052 |
| テキスト内容や文脈の情報を併用すべきではないか | 本文は取らない方針を保つ。代わりに IME の変換状態・フォーカスの遷移・ポインタを本文なしで観測する。IME の観測は合成入力で精度を評価した論文にした | 理由つきで部分的に採用 | ADR-014・016・036、`papers/ime-observation/` |
| 手紙の逡巡とナレッジワーカーの停滞を同じモデルで捉えられるか | `task_kind` で推定の頭を分けた。作文・AI 支援の作文・プログラミングの公開データで停滞の形を比べ、停滞の定義を変えたときに何が動くかを調べた。段 1 の 3 名は作業の様式の対照で選ぶ | 対応した。人のデータでの比べは段 1 から | ADR-006・047 D5、`experiments/20261102-public-data-landscape/` |
| ML としての技術的な裏付け | 段で学ぶ地図（固定 baseline → criterion 直結 → タスク適応 → 時系列）と昇格ゲート（人の中の時間順の holdout での較正）を決めた。1 人ごとに学ぶ効きを公開データで検証中 | 方法は固めた。本体はまだ HMM 0.5.0 で、ラベルは 0 件 | ADR-019・042・046 |
| 介入（散歩の促進）が受け入れられるかのユーザ検証 | 散歩の促進と身体活動の計測は行わない方針に変えた。招待は採点しない。段 2 で、適格な時点ごとに招待を出す・出さないを無作為に決め、1 人ごとに効果を見る | 未実施。いちばん遅れている | ADR-017 D10・018・047 D4 |
| 段階的な縮退の設計（下位のモデルを残し、昇格の条件を満たしたときだけ上へ進む） | 固定 baseline（HMM 0.5.0）を残し、段ごとの昇格ゲート（人の中の時間順の holdout での較正）を通ったときだけ上の段へ進む。見分けられない所では判断を保留する。推定が通らなくても、計測・記述・方法の知見が成果として残る | 引き継いだ（段の地図と保留の形で） | ADR-019 D3・044・046 D3・047 |
| 日本語 IME に対応したデータセットの公開 | 人の打鍵の記録は倫理審査の承認の後に集め直す。合成入力の評価一式を先に公開した | 公開は未達。審査待ち | ADR-039 |
| 仮説検証を重ねて推定の核を磨く | 推定を事前登録の帯で公開データ 3 つに当て、手で決めた推定器の上がりが停滞の契機の根拠にならないと確かめた（論文 1）。同時に、停滞の定義で結論が動くこと（論文 2）と、本文なしの観測でも句が特定されうること（IME の照合）が分かった。そこで核を、推定器の性能から「本文を保存しない観測から停滞についてどこまで言えるかを、予測・定義・漏れの 3 つの検査で確かめる」へ移した。推定器の改良の課題に、測る対象の妥当性の課題を先に足した、と説明する | 説明の骨子と根拠は済んだ（2026-11-15）。予測の検査に定義の検査をまだ当てていない | ADR-047・054、`docs/research-positioning.md` §1.4 |
| 尖り | 評価された点（AI 時代の切り口など）に合わせず、実測が強い資産から組んだ。一言は「本文を保存しない打鍵の観測から、作業の停滞についてどこまで言えるかを、予測・定義・漏れの 3 つの検査で確かめる」。結果として、読める所・読めない所・漏れる所・定義しだいの所の 4 面の地図を描く。AI は位置づけに置かない | 一言は決めた（2026-11-15）。3 つの検査の手順そのものの先行は探していない。新規性は組み合わせの水準のまま。未踏向けの言い方は派生の素材で | ADR-054、`docs/research-positioning.md` §1・§8 |
