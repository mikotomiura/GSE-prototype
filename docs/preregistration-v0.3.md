## 0. このスモークで主張すること / しないこと

本スモーク (n=3〜5) は **効果量推定・重大破綻検出**に限定する。母集団妥当性・被験者間一般化・「認知状態を捉えた」確証は**主張しない** (v0.3 §11)。

| ✅ 主張してよい | ❌ 主張してはいけない |
|---|---|
| ラベリング UI・回答負担・欠測構造の実態 | 母集団妥当性 |
| 個人内で観測された X↔主観の方向と効果量 | 被験者間一般化 |
| 重大な破綻の有無 (測定法 Kill / モデル Kill) | 「認知状態を捉えた」という確証 |
| 尺度理解の成否・二軸性の検証可否 | Recall の点推定 |

この段階のラベルは **Ground Truth とは呼ばず criterion label (主観参照ラベル)** と表記する (D-13)。

## 1. 凍結する事前登録項目 (PreReg-1〜8)

### PreReg-1 尺度理解ゲート
- **合格条件**: 8 ビネット中 **6 問以上**が想定象限、かつ被験者の **80% 以上**が通過。
- **不合格時**: 教示文を作り直して**再施行**する (本番データを取らない)。

### PreReg-2 測定法ゲート (回答)
- **要件**: ランダムプローブ回答率 **≥80%** / 回答時間中央値 **≤10秒** / 有効プローブ **≥20件/人**。
- **測定法 Kill**: 全体回答率 **<80%**、または **2人以上で <70%** → 測定法未成立。**モデル評価 (フェーズ2) に進まない**。

### PreReg-3 測定法ゲート (波形 cue 再現性) ※比較条件・初回スモークでは延期可
- **要件**: 波形 cue 回答がリアルタイム回答と **±1 以内 ≥70%** かつ `dont_remember` **≤25%**。
- **不成立時**: 波形 cue データを妥当性証拠に使わない。
- ※ 初回スモークは最小核スコープ (D-14) のため `context_beacon`／波形 cue ラベルは次段へ延期。本項は比較条件を実装した段で発効する。

### PreReg-4 モデルゲート (順序 C-index)
- 判定指標: 被験者内の**方向付き順序 C-index** (`|r|≥0.30` は逆相関でも通る穴があるため**廃止**)。
- **Go 候補**: 各人の C-index 中央値 **≥0.65**、十分なデータがある全員で **>0.55**。
- **Kill 候補**: 中央値 **≤0.55**、または **2人以上で ≤0.50**。
- **それ以外**: `INCONCLUSIVE` (無理に成果と言わない)。

### PreReg-5 評価設計 (前向き固定 holdout)
- 各人の**最初の2セッションで β 較正 → 凍結**、残り 8 セッションで前向き評価。
- 評価期間中の閾値・パラメータ調整は**禁止**。
- **最低要件**: 評価セッション **≥6回**、ランダムプローブ **≥16件/人**。
- LOSO / LOUO は探索扱いに降格 (時間リークを含むため)。

### PreReg-6 Recall
- 独立した陽性エピソードが **30件未満**なら Recall の点推定を**出さない** (定性所見のみ)。
- 分母は**一様ランダムプローブのみ**。顕著区間・自己ホットキーは Precision・事例探索専用 (分母に混ぜない)。

### PreReg-7 欠測 (MNAR)
- 全プローブの**提示・回答・無回答理由 (skip/dont_remember)・回答所要時間**を保存。
- 未回答を「**全て高摩擦**」「**全て低摩擦**」と置いた**上下限を併報** (極端値感度分析)。
- 無回答率 **>20% で注意**、**>30% で主分析不成立**。
- **被験者は除外しない** (高欠測者を落とすと「難しい状態の人」だけ消え MNAR を強化するため)。
- `dont_remember` を中間値 3 で代用しない。

### PreReg-8 二軸性
- 自然データで**非対角象限 (特に③インキュベーション) の出現が <10%** なら「**二軸性は検証不能**」と報告。
- 単軸とも二軸とも結論しない。
- ※「Q1–Q2 が高相関なら単軸へ縮約」は**採らない** (状態分布の対角偏りでも高相関は起きる交絡のため)。

## 2. 判定フロー

```
尺度理解テスト ──(PreReg-1 合格)──▶ 較正スモーク本番
                  └─ 不合格 ──▶ 教示文再設計・再施行 (本番データなし)

較正スモーク ──▶ 測定法ゲート (PreReg-2 / -3)
                  ├─ Kill ──▶ ラベル方式を再設計 (フェーズ2 に進まない)
                  └─ 通過 ──▶ モデルゲート (PreReg-4, 評価は PreReg-5)
                               ├─ Go         ──▶ 核検証フェーズへ
                               ├─ Kill       ──▶ モデル/特徴を差し戻し
                               └─ INCONCLUSIVE ──▶ データ拡充・設計見直し
```

Recall (PreReg-6) と MNAR (PreReg-7) と二軸性 (PreReg-8) は各ゲートの**報告要件**として併走する。
