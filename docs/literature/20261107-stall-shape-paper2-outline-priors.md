### カード 1: 行動のデータの前処理の multiverse は BRM で既出 **[検証済・抄録]** [V472] [V474]

1. **どんなもの？** Godwin ら（[V472]）は、読みの眼球運動の実験で、fixation の清掃の設定 14 通り・試行の除外・外れ値の除去・混合モデル 3 種を掛け合わせた 1,890 通りで、語の頻度の効果を推定した。Calignano ら（[V474]）は、乳児の瞳孔のデータで前処理と模型の構造を振った。
2. **先行研究と比べてどこがすごい？** [V472] の抄録の逐語: *"The frequency effect was found to be extremely robust and present in almost all cases, but the magnitude varied substantially, with 36% of the size of the effect being due to specific choices made during data cleaning and analysis."*
3. **技術や手法の肝はどこ？** 分析者が実際に取りうる「妥当で擁護できる」選択の範囲を列挙し、全組み合わせで同じ効果を推定する。
4. **どうやって有効だと検証した？** 1,890 通りのうち未収束 12（サブエージェントが本文から写した・未照合）。
5. **議論はあるか？** [V472] は fixation と saccade への分割のアルゴリズムを振らず既定に固定した（本文の逐語 *"here we did not vary the different underlying parsing algorithm settings"*・サブエージェントが Chrome で読んだ・メインは未照合）。論文 2 が振るのはまさに出来事の切り方に当たる部分で、評価の軸も効果の大きさではなくデータの間の比べ・過分散・時刻。
6. **次に読むべき論文は？** Eskenazi 2023（doi:10.3758/s13428-023-02137-x・清掃の強さを 3 段にした比べ・未照合）。

### カード 2: 検出器の間でラベルの時刻の一致を数える型は眼球運動で既出 **[検証済・抄録]** [V473]

1. **どんなもの？** Nir と Deouell（[V473]）は、閾値型の眼球運動の検出器 7 種を、人手で注釈した公開データ 2 つに当て、出来事の分類の違いを比べた。
2. **先行研究と比べてどこがすごい？** 抄録の逐語: *"Performance was assessed using metrics such as Cohen’s kappa, relative timing offset and deviation, and a sensitivity index (d′) for fixation and saccade onsets and offsets."*
3. **技術や手法の肝はどこ？** onset と offset を分けて、時刻のずれと一致を数える。
4. **どうやって有効だと検証した？** 人手の注釈を基準にした比べ（本文未読）。
5. **議論はあるか？** 人手の注釈という基準がある分野で、検出器どうしを比べる。論文 2 は基準（本人の申告）が無く、同じ検出器の定義を振って基準の定義との一致を数える。時刻の一致を「率の一致の代わりにならない」ことの根拠に使う形は、探した範囲（浅い）では見つからない。
6. **次に読むべき論文は？** Andersson ら 2017（doi:10.3758/s13428-016-0738-9・10 種の検出器の評価・抄録を照合できていない）。
