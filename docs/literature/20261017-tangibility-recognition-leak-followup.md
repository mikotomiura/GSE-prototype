## gate 判定（要点先出し・下位問いごとの温度）

- **SQ-1**: 自己認識と状態の漏れを同じ研究で両方測った研究 = **判定不能（0 件・2 ラウンド目）**。網を広げて見えたのは文献の分かれ方で、共有された生体信号について「観察者の読み取り」と「持ち主の懸念（質的）」を測る系列（[P509] [P511] [P512] [P513]）はあるが、持ち主の自己認識を測る系列とは交わらない。→ 検査法の新しさの候補は、この網の範囲では残る。会議の論文集の直接の走査は未着手で、「初めて」と書く根拠にはまだならない。
- **SQ-2**: 打鍵のリズムの自己認識 = **判定不能（0 件・3 ラウンド目）**。近い例は向きが割れる。打鍵の時間を音に写すと人がユーザーを照合できる = **確定（全文・聞き手 3 人・検定なし）**（#6）。ピアノの時間のずれは機械には識別できても人には聞き分けられない = **確定**（#7）。自分の運動の音を明示的に当てるのは難しいことがある（#8）一方、自分の心音は偶然を上回る（#9）。打鍵で自分のものと分かるか = **PLAUSIBLE BUT UNPROVEN**（どちらの向きも傍証）。
- **SQ-3**: 正規化の前と後の統制比較 = **判定不能（0 件・2 ラウンド目）**。[P510] の R と A の差は全行で同じ向き（#11）だが、統制比較ではない。
- **SQ-4**: 速さを除いた特徴での状態の推定 = **判定不能（0 件）**。打鍵からのストレスの推定は、人の間で共通の特徴を探すと一貫せず、全体として帰無の研究で、実験室だけで残った弱い信号が全体の速さに当たる特徴だった（#13・オンラインでは再現せず。相対の特徴が漏れない証拠にはならない）が、同じ人の前と後を比べると個人ごとに分類できる（#14・#15）= **確定（抄録・小標本）**。割り引いた写像で漏れが減るか = **PLAUSIBLE BUT UNPROVEN**（向きを決める証拠が無い）。

6. **次**: 会議の論文集（DIS・TEI・ISEA・ICAD・NIME・VISAP）の直接の走査。[P508] の被引用 1 件（題名が取れず未確認）。

### カード2: 時間の型の個人らしさは、機械には識別できても人の耳には届かないことがある **[2-1]** [P515] [P517] [P516] [P514]

1. **どんなもの**: ピアノの音階の時間のずれの聞き分け（[P515]）・打鍵を旋律に写した認証（[P517]）・自分の指鳴らしの音（[P516]）と心音（[P514]）の自己認識。
2. **すごい点**: [P515] は同じ時間のずれを、機械（距離が最小の分類器）と人の聞き手の両方に識別させ、ずれを拡大した条件で人の側の閾値を探った。
3. **肝**: [P515] の逐語 "none of the sensitivities significantly exceeded zero [all t (9) < 0.7, p > 0.25], indicating that participants were not able to distinguish pairs of recordings from the same pianist from pairs from different pianists" と "the irregularities became audible only when they were slightly increased"。不均一さの閾値は "10.22 ms (SD 2.51)"。[P517] の逐語 "these auditory signals are distinguishable between users by both standard classifiers (SVM, Random Forests and Naive Bayes) and humans alike"。
4. **検証**: [P515] は奏者 8 人・聞き手 10 人。実際のずれで d′ = −0.11、拡大で d′ = 0.70。[P517] は 30 人の曲を聞き手 3 人が照合し、正答 0.81〜0.83（表 I）。[P516] は 12 人中 4 人。[P514] は抄録で「偶然を上回る」。
5. **議論**: [P515] と [P517] は向きが割れて見えるが、写し方が違う。[P515] は 10 ms 前後の生のずれをそのまま聞かせ、[P517] は打鍵の時間の絶対値を、そのまま音の長さに、対数をとって音高に写した（式 (2)(3)）。ms の値を周波数とみなすので、速く打つ人ほど低い音になり、全体の速さの違いは音の高さと長さの両方に現れる。[P515] の 10 ms のずれは人に届かず、[P517] の写し方なら届いた理由の候補の 1 つはこの差だが、どの手がかりが識別に効いたかは検査されていない（外挿）。案 D にとっては、全体の速さを割り引くと、全体の速さに由来する音の差は除かれる。それが人の照合にどれだけ寄与していたかは、割り引く前と後を比べて確かめるしかない。GSE にとって大事なのは、[P515] の形が「最悪の組み合わせ」になりうる点である。機械は個人を識別できる（再識別の漏れは残る）のに、本人には自分の型が届かない（手応えは無い）。どちらも他人どうしの区別で、自己認識ではない。[P516] と [P514] は、自分の運動や身体の音を明示的に当てる力が弱い・確信が伴わないことを示し、検査に自信の評定だけを使えない理由になる。
6. **次**: [P517] の写し方で、全体の速さを割り引いた曲を人が聞き分けられるか（文献には無い・自前に測れる）。

### カード3: 打鍵からの状態の推定は、人の間では一貫しないが、同じ人の前と後なら成り立つ **[2-1]** [P222] [P518] [P161]

1. **どんなもの**: ストレスを誘発した実験室とオンラインの 2 実験（[P222]）・ストレスの前と後の固定の句の打鍵（[P518]）・睡眠慣性で誘発した疲労（[P161]）。
2. **すごい点**: [P222] は 924 人のオンラインまで含めて再現を試み、分析法も 2 つ使った（既登録の行の記録では、有意だった唯一の特徴は平均の打鍵の遅れで、効果は小さい）。[P518] は心血管・血行動態・自己申告で誘発を確かめた。
3. **肝**: [P222] の逐語 "revealed a few isolated links between stress and keyboard typing, but the results were inconsistent across both studies and the analysis methods"。[P518] の逐語 "Machine learning algorithms accurately classified stressed typing for each individual based on their typing rhythms; however, no universal keystroke markers of stress were identified" と "the markers used for classification differed between individuals"。[P161] の逐語 "the fatigue detection model performs better for some participants than others because of the intrauser variations when typing"。
4. **検証**: [P222] は 53 人・924 人。実験室の平均の打鍵の遅れは d = 0.18、オンラインは g = 0.024（既登録の行の記録）。[P518] は 116 人（抄録のみ・数値なし）。[P161] は 14 人で AUC 72.2〜80%。
5. **議論**: 状態の漏れは、誰が読むかの設定で大きさが変わりうる。人の間で共通の読み方（汎用の分類器）では弱く出る（[P222] は全体として帰無で、実験室だけで残った弱い信号が全体の速さに当たる特徴だった。相対の特徴が漏れない証拠にはならない）が、同じ人の前と後を知る読み手（個人ごとの分類器）には読める（[P518] [P161]）。GSE の表現を毎日見るのは本人と、本人をよく知る人なので、後者の設定に近い。ただし 3 本とも速さを除いた条件を持たず、全体の速さを割り引いた写像で漏れが減るかは、この 3 本からは決まらない（#12 は 0 件）。
6. **次**: [P518] の本文（特徴が全体の速さか相対のリズムか）・[P222] の本文（11 の特徴の内訳・オープンデータの所在）・Kołakowska 2017（特徴ごとの有用性・否決 R-9）。

## → GSE への含意（設計の議論の材料・判断ではない）

1. **検査法の新しさは、網を広げても残った**（#1・2 ラウンド目の 0 件）。文献は「観察者の読み取りと持ち主の懸念」の系列（カード 1）と「自己認識」の系列（S-TN のカード 2・3）に分かれていて、交わる研究が見つからない。両方を同じ刺激で測ることを GSE の検査法の特徴として書く筋は強まったが、会議の論文集の直接の走査がまだで、「初めて」とは書けない。
2. **人の段の検査では、本人の自己認識と、機械による個人の再識別を必ず対にする**（カード 2・外挿）。[P515] の形（機械は分かる・人には分からない）が打鍵でも起きるなら、手応えは無く漏れだけが残る。判断 25 (2) で個人の再識別を G-GEAR 側の候補として渡したが、人の段でも、本人の自己認識が偶然に落ちた条件で機械の再識別がどれだけ残るかを並べて見る必要がある。
3. **ずれの拡大は設計の手がかりになりうるが、漏れも増やしうる**（#7）。[P515] では拡大して初めて聞き分けられた。案 D の写像で相対のタイミングの差を誇張すれば自分らしさが届きやすくなるかもしれないが、同じ操作は再識別も容易にする。誇張の度合いを人の段の条件に入れる候補になる（外挿）。
4. **漏れの検査は、個人ごとの読み手を想定して行う**（カード 3）。人の間で共通の分類器で漏れが小さく出ても、同じ人の前と後を知る分類器では読めることがある（#13 と #14・#15）。G-GEAR の机上の検査がどちらの設定かは、そちらのタスクで研究者が決める（判断 21 でこのタスクは触れない）。
5. **自己認識の検査に自信の評定だけを使わない**（#8・#9）。自分の身体の音は偶然を上回って選べても確信が伴わず、自分の運動の音は明示的に当てにくいことがある。強制選択の正答（d′）を主にし、自信の評定は添えるだけにする（S-TN の含意 5 と同じ向き）。
