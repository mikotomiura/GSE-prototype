### カード 1: 固定の pause 閾値は恣意的 —— ただし「個人化すべき」と「作文なら固定でよい」の両論がある **[検証済 3-0]** [V161] [V162] [V163]

1. **どんなもの?** 書字過程研究の pause 閾値をめぐる一次 3 本。
2. **先行研究と比べてどこがすごい?** [V161] は混合モデルで閾値を置かずに非流暢を推定する。[V163] は ex-Gaussian で個人閾値（358–810 ms）を出す。
3. **技術や手法の肝は?** 逐語 *"pauses and pause-related measures are defined using threshold values which are, in principle, arbitrary"*（[V161] p.359）・*"A pause threshold would need to be participant-specific"*（[V161] p.362）・*"the same could be argued for any threshold a researcher might care to choose between perhaps 250 ms and 10 s"*（[V162] p.243）。
4. **どうやって有効だと検証した?** ⚠️ **反対側**: [V163] 自身は逐語 *"composition studies, where it is safe to establish a (somewhat arbitrary) cut-off value for pauses, the spontaneous nature of chats calls for more detailed statistical analyses of individual IKIs"*（p.66）。
5. **議論はあるか?** ★ GSE は **`W`（条件 A の窓）を固定の事前宣言値**にし、**`θ_person`（持続）だけを個人の IKI 分位点**にしている（ADR-030 D4）。→ ★ 両論の間にある設計で、⚠️ **`W` は [V162] の批判がそのまま当たる**（★ ablation で値を振る）。⚠️ `q ≥ p99` は文献上のどの pause 定義よりはるかに極端（★ サブエージェントの推論: Baaijen の極端ポーズ群でも語間ポーズの約 9% [V160]）→ ★ **`t0` が「pause の検出」でなく「標本の原点」である（ADR-030 D2）ことと整合する**。
6. **次に読むべき論文は?** Roeser et al. (2025, JEP:G, 10.1037/xge0001759・未登録)・Hall et al. (2022)・Chenu et al. (2014)。

### カード 2: 「再開した」の基準 —— 実験室は最初の 1 操作、フィールドは持続 **[検証済 3-0]** [P35] [V144] [V165] [V166]

1. **どんなもの?** 中断・再開研究の操作的定義。
2. **先行研究と比べてどこがすごい?** 同じ「再開」に 2 系統の作法がある。
3. **技術や手法の肝は?**
   - フィールド: 逐語 *"we considered users to resume a suspended task if they had spent more than 15 seconds on the suspended application, which is more time than required for rapid application switches"*（[P35] p.679）
   - 実験室: 最初の操作までを再開ラグとし（[V144]）、⚠️ 偶発的操作を除外 —— 逐語 *"100 ms, which were assumed to be due to incidental mouse clicks timed coincidentally with the VCR task onset"*（[V165] p.304）
   - ⚠️ 反証側: IDE ログの edit lag は「戻ってから最初の編集まで」＝ **1 操作で再開とみなす**（[V166] p.82）
4. **どうやって有効だと検証した?** [P35] は 27 名・2,267 時間のフィールドログ。[V165] はラボ 3 実験。
5. **議論はあるか?** ★ **研究者判断 #6（E1 連結）はフィールド側の作法（持続を要求する）と同じ向き**である —— 停滞中の 1 打鍵は「再開の試み」であって「再開の成立」ではない。⚠️ ただし **GSE の E1 が要求する「持続」は ADR-029 D2 の `recovery`（`progress_proxy`）であり秒数ではない**。★ [P35] の 15 秒は**アプリ滞在**であって産出ではないので、値は移らない（★ 形だけを借りる）。
6. **次に読むべき論文は?** 「再開後すぐの再停止」を類型化した研究（★ **0 件**）。

### カード 3: burst の長さは速度に交絡する —— `stable_generation_ms`（ミリ秒）の危険 **[検証済 2-1]** [V164] [V152] [V153]

1. **どんなもの?** pause で区切った産出の塊（burst / execution period）の長さの研究。
2. **先行研究と比べてどこがすごい?** [V164] は打鍵速度で群を割り、burst の長さを比べた。
3. **技術や手法の肝は?** 逐語 *"while slow typists can sustain execution for 7.7 s, fast typists do it for a longer time, 11.6 s"*・*"During their execution periods, slow typists produce half the words produced by the fast typists."*（[V164] p.61）。★ ETS の burst は *"uninterrupted typing that does not include pauses longer than two-thirds of a second"*（[V153] p.15）。
4. **どうやって有効だと検証した?** ★ burst 長は**語数で測ると課題間で比較的安定、時間で測ると不安定**（[V152] Table 5・⚠️ サブエージェント報告・特徴は burst 長の SD）。
5. **議論はあるか?** ⚠️ **GSE の `stable_generation_ms` はミリ秒で測る** → 速度と交絡する。★ **提案（未決）**: 同じ区間 `[r_1, s'_1)` の**純産出の打鍵数**を併記する（★ issue 006 AC1 のフィールド追加 ＝ 研究者判断）。⚠️ [V164] は N=21。
6. **次に読むべき論文は?** 日本語 IME の作文での burst（★ **0 件**）。

### カード 4: 連結（束ね）の根拠と危険 —— bout 解析は連結を直接支えない **[検証済 2-1 / 3-0]** [V168] [V169] [V167]

1. **どんなもの?** 行動生態学の bout 解析と、Web ログのセッション分割。
2. **先行研究と比べてどこがすごい?** 間隙の分布を混合で分け、bout 内と bout 間の境界（bout criterion）を推定する。
3. **技術や手法の肝は?** ★ 短い異種行動（飲水）を **bout 内の第 3 母集団**として吸収するモデル（[V168] abstract）。⚠️ 個体によっては基準が立たない（[V169] abstract）。
4. **どうやって有効だと検証した?** ⚠️ [V168] / [V169] は **abstract のみ**（provisional）。
5. **議論はあるか?** ⚠️★★★ **bout criterion は間隙の内外を分けるだけ**であり、停滞中の 1 打鍵の前後がどちらも基準超なら**その 1 打鍵は「1 イベントの bout」として分割される**（★ サブエージェントの推論）→ ★ **E1 連結の根拠は bout 解析ではなく「再開の成立に持続を要求する」作法（カード 2）の側にある**。⚠️ **連結の危険**: 逐語 *"too long for other cases where it will erroneously concatenate sessions that should actually remain separated"*（[V167] p.3）→ ★ **E1 は過剰結合の側へ誤りうる**。→ ★ **対策（提案・未決）**: `T1d` に**エピソード内の再開の試みの回数**を持たせれば、**連結で吸収した回数が見える**（⚠️ issue 006 AC1 のフィールド追加 ＝ 研究者判断）。E2（分割）を感度分析として併報する余地を残す。
6. **次に読むべき論文は?** Sibly, Nott & Fletcher (1990)・Langton, Collett & Sibly (1995)（原典・未取得）。
