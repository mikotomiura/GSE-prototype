## 動機

議題 1b の新規性の候補は、Claude の見立てとして「アンビエント表示・自己追跡の表示・データアートなどの表現の先行は、伝わるか・役に立つか・注意を奪わないかを問う。表現の見た目から元の記録の内容や系の推論がどこまで推せるかを実測で縛り、それを表現の設計の制約にするものは手薄ではないか」と書かれていた。回 1（手跡の見た目から判断が漏れないかを予測器 A と B で比べる）の後のメタな整理の前に、この見立てを文献で確かめる。結果の向きは先に決めず、既にあると分かることも整理の材料とする。近い既存のラウンドは、データ肖像（`20260921-data-portrait-and-lived-informatics.md`。やり残しに「HCI の abstract / ambient representation の評価研究は未着手」）、S-NW（手跡の自然世界の案）、S-3C（3 つの検査の先行）。

- 問い 1: 可視化・アンビエント表示・生成的な表現について、表示から元のデータや推論を推す攻撃・漏れを実測した研究はあるか。
- 問い 2: 系の判断を返さず、行為の痕跡だけを返す表現の先行と、その評価の仕方。
- 問い 3: 概念や定義の不確かさを 1 つの答えに潰さずに表現する先行。
- 問い 4: 観測の限界を UI や表現の設計の仕様として使う枠組み。

結論: 見立ての一般の形（表示から推せることを測り、その結果で表示の粒度を縛る）は新しくない。25 年前の常時映像のぼかしの研究 [P555] [P556] と、2026 年の地図への攻撃と粒度の道具 [P559] が同じ流れを持つ。議題 1b で「表現が運ぶ推論を実測で縛ることが新しい」とは書けない。

残る差の候補は次の 3 点で、どれも「この範囲で見つからなかった」水準（新しいとは書かない）。

1. 漏れの対象を、元の記録や本人だけでなく系の判断（推定値）に置くこと。表示から読めてはいけないものが、データではなく系がまだ確かめていない推定である点。説明からの漏れ [P569] は機械が訓練のデータを推すもので、人が表現から推定値を読むものではない。
2. 判断を返さない表現の系統（問い 2）に、その「返さなさ」を測る検査を足すこと。少なくとも [P573] は読み取りでの評価をはっきり退けており（系統全体がそうかは照合できた範囲で未確定）、差は手薄さというより評価の向きにある。ただし、読みが系の内部の値と違うこと（意味の解釈の不一致）は、漏れていないことの証拠にならない。読みが一貫して逆なら、反転すれば内部の値を復元できる。議題 1b の監査が見るべきは解釈の一致ではなく、表現から内部の値をどこまで予測できるか（基準の予測と比べた予測可能性）で、[P573] の観察とは別の量である。
3. 系の判断を縛る検査と、表現を縛る検査を同じ観測・同じ道具で行うこと（S-3C の 3 つの検査と表現の監査をつなぐ）。

留意: [P556] は、粒度を落とせば守れるという前提が場面のリスクで崩れることを示した。表現の監査の結果は、どの場面で成り立つかを限って書く必要がある。
