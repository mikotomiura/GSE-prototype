# 文献カード: タスク種別と執筆の停滞（struggle）の質

トピック: task-type-writing-struggle / 日付: 2026-06-29
動機: GSE Dashboard の課題種別 enum（`argumentative` / `correspondence` / `creative` / `vibe_coding`）は
現状 ad-hoc・記録専用で理論的裏付けが無い（research-positioning §8 で明文化）。本カードは
「**停滞（Stuck）の質はタスク種別で異なる**」という仮説の理論的接地と、Phase1 を論述（argumentative）に
絞る判断の根拠を与える。出典は references.md の P 名前空間 [P16]-[P18]。

---

## カード1: Flower & Hayes (1981) — A Cognitive Process Theory of Writing [P16]

1. **どんなもの?**: 執筆を「planning（計画）／translating（言語化）／reviewing（推敲）」という再帰的な
   認知プロセスの集合としてモデル化した古典。書き手は作業記憶上でこれらを切替・入れ子で実行する。
2. **先行研究と比べてどこがすごい?**: 「段階（prewrite→write→rewrite）」の線形段階論を退け、プロセスが
   **問題解決として再帰的に起こる**ことを protocol analysis で示した。停滞を「工程の遅れ」でなく
   「どのサブプロセスで認知資源が詰まったか」として位置づけられる。
3. **技術・手法の肝**: think-aloud protocol を過程モデルに写像。planning↔translating の同時要求が
   作業記憶を圧迫する点（overload）を構造として記述。
4. **どう有効と検証?**: 熟達/未熟達書き手の発話プロトコル比較。質的だが反証可能なモデルとして
   以後の実証（Kellogg [P18] 等）の土台になった。
5. **議論はあるか?**: モデルは記述的で定量予測に乏しい。後年 Hayes (1996/2012) が motivation/working
   memory を組み込み改訂。GSE の打鍵プロキシは「どのサブプロセスの停滞か」までは分解できない（粒度限界）。
6. **次に読むべき**: Hayes (2012) 改訂モデル / Kellogg の作業記憶系 [P18]。
- **やり残し**: 停滞は工程単位で質が異なる（planning 停滞 vs translating 停滞）。GSE は打鍵動態でこの
  サブプロセス分解までは届かず、タスク種別が「どの停滞が支配的か」の代理になりうる。
- **§4 差分との関係**: GSE の L1 Stuck は「停滞の存在」を測るが「停滞の質（工程）」は未分解 →
  タスク種別固定でこの交絡を統制するのが Phase1 の正攻法。

## カード2: Scardamalia & Bereiter (1987) — Knowledge Telling / Knowledge Transforming [P17]

1. **どんなもの?**: 執筆の2つの対照的モデル。**knowledge-telling**＝想起した内容をそのまま書き出す線形・
   低負荷過程（物語・近況・定型通信文）。**knowledge-transforming**＝内容問題空間と修辞問題空間を往復し
   主張を再構成する高負荷過程（論述・説得・expository）。
2. **先行研究と比べてどこがすごい?**: 「書く」を単一過程とせず、**課題（ジャンル/目的）が要求する処理の
   深さで停滞構造が質的に変わる**ことを定式化。熟達差も同モデルで説明。
3. **技術・手法の肝**: 2つの問題空間（content/rhetorical）の相互作用の有無で telling/transforming を分ける。
   transforming は反省的な「行き詰まり→再構成」を内在的に伴う＝**生産的苦闘が起きやすい課題タイプ**。
4. **どう有効と検証?**: 作文プロトコル・思考発話・年齢/熟達比較（児童 vs 院生）による収束的証拠。
5. **議論はあるか?**: 二分法は理念型で連続体（Galbraith の knowledge-constituting 等の異論）。
   ジャンル名と処理タイプは1対1でない（同じ「論述」でも telling 的に書ける）。
6. **次に読むべき**: Galbraith dual-process writing / Kellogg [P18]。
- **やり残し**: 「論述＝transforming＝深い停滞」「通信文/近況＝telling＝浅い停滞」という**タスク種別→停滞の質**の
  対応は理論上明確だが、GSE の4分類が実際にこの軸を切れているかは未検証（creative/vibe_coding は曖昧）。
- **§4 差分との関係**: GSE の課題種別 enum はこの telling/transforming 軸で**再定義/検証すべき**。
  Phase1 で transforming 代表＝論述に絞れば停滞信号が最も濃く、measurement/model の成立を最短で確かめられる。

## カード3: Kellogg (1988) — Attentional Overload and Writing Performance [P18]

1. **どんなもの?**: 執筆中のサブプロセス（planning/translating/reviewing）が**作業記憶を競合的に消費**し、
   過負荷が成果を下げることを実験的に示した。outline/rough-draft 方略が負荷を分散し成績を改善。
2. **先行研究と比べてどこがすごい?**: Flower&Hayes [P16] の記述モデルを**作業記憶負荷の実験パラダイム**へ
   接続。停滞を「認知資源の枯渇」という測定可能な負荷現象として扱える。
3. **技術・手法の肝**: 方略（outline 有無）で online の同時処理負荷を操作し、成果・流暢性への影響を測る。
4. **どう有効と検証?**: 統制実験（方略条件比較）。後続の dual-task 研究（Kellogg 2004 等）が WM 負荷を裏付け。
5. **議論はあるか?**: 課題要求と方略の相互作用が大きく、個人差・熟達差も。負荷の絶対量はタスク・書き手依存。
6. **次に読むべき**: Kellogg (2004) dual-task / 作業記憶と執筆のレビュー。
- **やり残し**: 停滞＝WM 過負荷なら、**負荷の大きいタスク（論述/transforming）ほど停滞が頻発・濃厚**に出る
  はずで、打鍵プロキシ（ポーズ・バックスペース）の停滞信号も濃くなる仮説が立つ（GSE で検証可能）。
- **§4 差分との関係**: GSE の打鍵5特徴量は WM 過負荷の行動的痕跡を拾う代理。タスク要求が大きい論述で
  C-index が最も立ちやすい＝Phase1 の対象として合理的。

## まとめ（GSE への含意）

- **理論的結論**: 「停滞の質はタスク種別で異なる」は [P16][P17][P18] が支持する。特に
  **knowledge-transforming（論述/expository）は内在的に行き詰まり→再構成を伴い、作業記憶過負荷で
  停滞が濃く出る**一方、knowledge-telling（物語/通信文）は浅い。GSE の4分類 enum はこの
  telling↔transforming 軸で再定義・検証すべき（現状 ad-hoc）。
- **Phase1 への含意**: 論述（argumentative＝transforming 代表）に絞ると、(i) 停滞信号が最も濃く C-index が
  立ちやすい、(ii) writing β ベースラインと整合、(iii) タスク交絡を統制、(iv) ラベルを1タスクに集中で
  検出力最大。タスク間の停滞差の本分析は N と検出力の都合で Phase2 へ（research-positioning §8/§9 に明文化）。
- **やり残し（全体）**: GSE の4分類が telling/transforming 軸を妥当に切るかの**経験的検証**、および
  タスク別 C-index/状態分布の**層別分析パイプライン**（現状 task_kind は記録のみ・dead_code）。
