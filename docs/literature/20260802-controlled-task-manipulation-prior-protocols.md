## カード 1: **G1 の課題操作は「自前」ではない — integrated vs independent の系譜に属する** **[検証済 3-0]** [P43][P44]

1. **どんなもの?** 資料を読んで統合させる課題（integrated / reading-into-writing / source-based）と、
   資料なしで書かせる課題（independent）を対比し、打鍵ログで書字過程を比べる系譜。
   TOEFL iBT の 2 種のライティング課題がその代表。
2. **先行研究と比べてどこがすごい?** 「課題の認知的要求を実験者が操作し、打鍵で測る」という
   **G1 がやろうとしていることそのもの**を、language testing が既に標準的な計測課題として持っている。
3. **技術・手法の肝?** 同一被験者に両課題を **counterbalanced** で課し、fluency / pausing / revision を比較する。
   [P44] は eye-tracking と刺激再生インタビューを併用して過程を三角測量している。
4. **どう検証した?** [P43] N=2（探索的）／[P44] **N=60**・independent 2 本 × integrated 2 本。
5. **議論はあるか?** ★ カード 2（結論が割れている）。
6. **次に読むべき?** [P44] 本文（どの指標が動き、どれが動かなかったかの内訳）。

> ★ **GSE への含意**: 事前登録 §1.1 に「**自前の設計と主張しない**」と明記した。
> G1 の差分は**操作の新規性ではなく、判定単位（個人内のブロック分類）と観測制約（content-free）**にある。

## カード 2: ★★ **同系統の操作が打鍵挙動に差を作るかは、先行研究内で一貫していない** **[検証済 3-0]** [P43][P44]

1. **どんなもの?** 同じ「integrated vs independent」の対比で、結論が逆を向いている 2 本。
2. **すごい点?** 標本サイズが 30 倍違い、**大きい方が「差は小さい」側**に立っている。
   出版バイアスの向きを考えると、これは軽く扱えない。
3. **肝?**
   - **[P43]**（N=2）: integrated の方が demanding。**ポーズ長・修正数が増え、産出速度が落ちる**。
   - ★ **[P44]**（N=60・counterbalanced）: **source use を除けば、writing behaviours と cognitive processes は
     概ね similar**。integrated の方が dynamic / varied ではある。
4. **どう検証した?** [P44] は 60 名 × 4 課題、眼球運動と刺激再生を併用。
5. **議論はあるか?** L2 writer（第二言語）である点、TOEFL という高負荷の試験文脈である点が
   GSE の自然作業とは違う。**そのまま外挿はできない。**
6. **次に読むべき?** 両者の指標定義の突合（「差が無い」が指標の粗さ由来でないか）。

> ### ★★ GSE への含意（**事前登録を 2 か所で厳しくした**）
> **(a) 帰無が現実的である。** G1 の **12 倍の標本**で同系統の操作が広い行動差を作らないと報告されている。
> → 事前登録 `§3.7` に「**`positive control ✓` かつ `FS-A ✗ / FS-B ✗` は失敗ではなく主要な成果**」と
> **価値を先に宣言**した。結果を見てから「想定内だった」と言わないためである。
> **(b) `✗/✗` の解釈が単独では成立しない。** → カード 3。

## カード 3: ★★ **`FS-A ✗ / FS-B ✗` は 3 つの原因を区別できない — positive control を新設した** **[検証済 3-0]** [P44][P37][P36][P38]

1. **どんなもの?** G1 の判定表で最も重大なセル（「打鍵由来イベントでは作業状態を分離できない」→
   **軸そのものを疑う・パイプラインを作らない**）が、単独では次を区別できないという指摘。
   **(i) 打鍵では原理的に測れない**（意図した結論）／**(ii) 操作が弱すぎた**（★ [P44] がまさにそう報告）／
   **(iii) 計器・特徴量抽出が壊れていた**。
2. **すごい点?** 操作チェック（主観の強制比較）は (ii) を**部分的にしか守らない**——
   [P44] の含意は「**主観的に難しくても行動が似ている**ことはありうる」だからである。
3. **肝?** ★ **既知の大きな差を同じ計器で流す**。写経 vs 自然な執筆は打鍵ログのみで
   **RF 99%** で判別でき（[P37]）、revisions は課題間で動き（[P36]）、
   **copy task は writing research の標準計測器**である（[P38]）。
   → **同一セッション・同一パイプライン・同一特徴量**で copy vs 執筆を流し、
   分離できなければ **G1 を無効**とする。
4. **どう検証した?** 本カードは設計上の推論であり、実験による検証ではない。
   根拠は [P37][P36][P38] の「判別可能性が独立に確立している」という事実。
5. **議論はあるか?** ★ **copy ブロックは位置固定（先頭・末尾）なので位置効果と交絡する。**
   したがって **floor チェックにのみ使い、効果量を主張しない**と事前登録に明記した。
   ★ また copy vs 執筆は HI/LO より**はるかに大きな差**なので、**通っても HI/LO の分離力は保証しない**。
6. **次に読むべき?** —（設計判断のため文献追加は不要）

> `task-adaptation-and-scope-gating.md §4.1` が必要としていた
