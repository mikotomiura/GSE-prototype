## 動機

- 研究者は、肖像の「タンジブル」を「自分の手が作った手応え」の意味で設計すると決め（判断 1）、達成感は狙わない（判断 8）。深掘りする案は D 手触りの写像・C 出会いの再生・A 一打ずつ（判断 9）、面は画面端の小面と背景のステージ（判断 10）。
- 作者性の手応えは一般に応答の速さに支えられるので、壁紙の規則（打鍵の最中に更新しない・肖6）と緊張する。論点 1・2（経路と速さ）を決める前に、文献で確かめる（判断 5・11）。
- 既存の調査との分担: 指標性と data portrait は S4（`20260921-data-portrait-and-lived-informatics.md`）、背景のステージの代償と新規性は S-RM と S-RN（`20261012-rhythm-stage-novelty.md`）、周辺表示の代償は `20260907-pc-invitation-surface-and-peripheral-cost.md`。本ラウンドはそこに無い問いを探した。

下位問い（判断 11）:
- **SQ-A** 一打ずつ: 主体感は応答の遅れでどう変わるか。打鍵ごとの応答は成績と注意に何をするか
- **SQ-D** 手触りの写像: 即時の応答なしに、自分の運動の痕跡を自分のものと分かるか
- **SQ-C** 出会いの再生: 自分の作業の過程を事後に再生すると、作者性・再開・振り返りに何が起きるか
- **SQ-S** 面: 小さな動く面と全面の動く背景の、作業中の代償と慣れ
- **SQ-X** 反証: 即時の応答が自己監視・評価の不安・ゲーム化を呼ぶか。作者性が消えるときの喪失を呼ぶか

## gate 判定（要点先出し・下位問いごとの温度）

- **SQ-A**: 評定の主体感は遅れが 200 ms を超えると下がる = **確定**（#2・最大 1 秒）。結果の拘束は 250 ms（慣習の区切り）を超える遅れで弱まる = **確定**（#1・拘束は主体感そのものではない）。遅れた結果に事後の推論の経路が残る = **PLAUSIBLE BUT UNPROVEN**（#3 は考察・数秒〜数分は 0 件）。打鍵ごとの応答の代償 = **判定不能**。
- **SQ-D**: 運動の痕跡は時間をおいても自分のものと見分けられうる = **確定**（#8）。ただし見分けられない動きもある（#9）。手がかりは時間の構造 = **PLAUSIBLE BUT UNPROVEN**（#10 は要約のみで否決）。打鍵のリズムでの自己認識・写した形での認識 = **判定不能**。
- **SQ-C**: 自分の過程の再生は気づきを生む = **確定（面接）**。見せることが自意識を生む例がある = **確定（日記研究の 2 人・質的）**。再生が作者性や再開に効くか = **判定不能**。
- **SQ-S**: 動き続ける表示は止まりと動きを繰り返す表示より妨げる = **確定**（課題で割れる・S-RN）。慣れ（#21）は要約のみで否決。小面と全面の比較 = **判定不能**。
- **SQ-X**: 注意が自己に向くフィードバックは成績を下げうる = **確定（課題の成績）**。抽象の表現での評価の不安・消える作品の喪失 = **判定不能**。

## カード

### カード1: 評定の主体感は 200 ms を超えると下がる。遅れた形に残りうるのは事後の推論（未検証） **[2-1 / 3-0]** [P485] [P486]

1. **どんなもの**: 時間的拘束 75 研究のメタ分析（[P485]）と、遅れ 0〜1000 ms の 7 水準の実験（[P486]）。
2. **すごい点**: [P485] は予測の経路と事後の推論の経路を、行為の拘束と結果の拘束に分けて比べた。
3. **肝**: 結果の拘束は遅れと因果の物語で動き、行為の拘束は運動の指令の副産物に近い（[P485] の考察）。
4. **検証**: 遅れの調整効果 F(1,237) = 7.41, p = .007（[P485]）。評定は 200 ms を超えると下がり、拘束は強まる（[P486]・η²p = 0.87 と 0.29）。
5. **議論**: 拘束と評定は逆に動く（[P486]）。拘束は機械の原因でも起きる（[P487]・抄録）。250 ms は慣習の区切り（[P485]）で、[P486] の評定の低下も予測と事後の推論の経路を分けていない。分単位の遅れは測られていない。
6. **次**: Haggard ら 2002・Moore ら 2009・Humphreys & Buehner 2009 の本文（否決リスト）。

### カード2: 自分の運動は時間をおいても見分けられうる。手がかりが時間の構造かは要約しか無い **[3-0 / 2-1 / 否決]** [P489] [P490] [P491]–[P493]

1. **どんなもの**: 全身運動（[P489]）・踊り（[P490]）・描画（[P491]）・ピアノ（[P492]）・手拍子（[P493]）の自己認識。
2. **すごい点**: [P489] は平均 84 日後でも偶然水準を超えた。即時の応答なしの見分けである。
3. **肝**: 手がかりは時間の構造。[P492] はテンポ・音量・強弱を除いても評定が変わらなかった（要約）。[P493] は全体のテンポが重要とする（要約）。
4. **検証**: 18 種で 0.43〜0.86（[P489]）。自作の踊りは 38.6% で偶然水準に届かない（[P490]）。
5. **議論**: [P491]–[P493] は道具の要約か検索の要約のみで、#10 は否決した。どれも運動をそのまま見せ・聞かせたもので、別の形に写した表現ではない。
6. **次**: [P491] [P492] の本文、Sevdalis & Keller 2009、Kadambi & Lu 2019。

### カード3: 過程の再生は気づきを生むが、見せることは自意識も生む **[2-1]** [P494] [P495]

1. **どんなもの**: 書き手が自分の執筆の再生を見た面接（[P494]）と、執筆の痕跡を見せる UI の日記研究（[P495]）。
2. **すごい点**: 自分の再生を本人に見せた数少ない研究。
3. **肝**: 再生は「自分の脳の動きが見える」気づきになる（[P494] の W12）。推定と判断を添えると「観察者」を感じる人が出た（[P495]）。
4. **検証**: 13 人中 7 人が癖に気づいた（[P494]）。日記研究の 11 人中 2 人が自意識、1 人が書く速度を落とした（[P495]・W1 と W5）。
5. **議論**: どちらも質的。[P495] は推定と LLM の判断つきで、GSE の「推定を材料にしない・評価を載せない」と条件が違う。著者は本人が見え方を制御できることを緩和に挙げる。
6. **次**: Leijten & Van Waes 2013（Inputlog の再生）・Lindgren の再生による振り返りの研究。

### カード4: 再開の手がかりは直前の操作と結びつくものが効き、手がかりが変わると妨げる **[3-0 / 2-1]** [P496] [P497] [P498]

1. **どんなもの**: 中断の後の手がかりの実験 3 件。
2. **すごい点**: [P496] は直前の操作を指す矢印だけで誤りを大きく下げた。
3. **肝**: 手がかりはどれも課題の画面の中で、課題の目標や位置と結びつく。[P497] は中断の後に視覚の手がかりが変わると妨げになるとする。
4. **検証**: 誤り 47.22% → 4.76%（[P496]）。位置の手がかりは読みの再開を助けた（[P498]・抄録）。
5. **議論**: 目標と無関係な背景の変化（肖像・再生）が再開を助けるか・妨げるかは、どれも測っていない（[P471] と同じ空白）。[P497] は「戻ったとき画面が変わっている」ことの代償を示唆するが、手がかりは課題の画面そのものなので外挿。
6. **次**: [P497] の結果の節・Altmann & Trafton の goal-activation model。

### カード5: 動き続けるより、止まりと動きを繰り返す方が妨げが小さい **[2-1 / 否決]** [P267] [P499] [P502]

1. **どんなもの**: 周辺の動きの代償（[P267]）、注意の捕捉の慣れ（[P499]）、周辺表示の邪魔の順（[P502]）。
2. **すごい点**: [P267] は動きの型（連続か離散か）を比べた。
3. **肝**: 動きは周辺で注意を捕まえやすい（[P267] の考察）。慣れても刺激を除くと捕捉は戻る（[P499]・抜粋）。
4. **検証**: [P267] は S-RN #8。[P499] [P502] は要約・抜粋のみで、#21・#24 は否決した。
5. **議論**: 小面と全面、入力に随伴する動きと無関係な動きを比べた研究は 0 件。[P500]（操作している物に対応する妨害物は捕捉される・抜粋）は、打鍵に連動する表示が「自分に対応する物」として捕まりやすい、という推論の材料にとどまる。
6. **次**: Bartram ら 2001・Turatto の 2018・2019 の本文。

### カード6: 自己へ向くフィードバックは成績を下げうる **[3-0 / 否決]** [P235] [P501] [P100]

1. **どんなもの**: フィードバックの介入のメタ分析（[P235]）、IKEA 効果（[P501]）、UbiFit（[P100]）。
2. **すごい点**: [P235] は効果が注意の位置（課題か自己か）で変わるとした。

4. **検証**: [P235] は d = .41・3 分の 1 超が負。[P501] は道具の要約のみで、#25 は否決した。
5. **議論**: 抽象の表現が評価の不安を生むか・消える作品の喪失は 0 件。[P501] は「壊した・未完成なら愛着が消えた」で、消えることの喪失を支える材料ではない（物理物の評価額）。
6. **次**: Norton ら 2012 の本文・消える投稿の研究（Cavalcanti ら 2017・未読）。
