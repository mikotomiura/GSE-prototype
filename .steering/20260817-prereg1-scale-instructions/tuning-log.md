# tuning-log — 教示文・ビネットの実測改善 (`empirical-prompt-tuning`)

> **手法**: 教示文と 8 場面**だけ**をプロンプトに貼り、正解 (想定象限) を渡さずに
> subagent に回答させ、想定象限との一致数を採点した。repo 参照は明示的に禁止し、
> **全 22 回の実行すべてで `tool_uses = 0`** を確認している (`VignetteTest.tsx` に
> 正解が書いてあるため、読まれたら測定にならない)。
> **tier**: Lite → 3 シナリオで開始し、hold-out 2 本を追加した実質 Full 相当。

---

## シナリオ (diversity rubric: median / edge-low / edge-high / adversarial ×2)

| id | 象限 | ペルソナ | 合格条件 |
|---|---|---|---|
| **S-A** | median | 教示を読んで誠実に答える大学院生 | 一致 **≥6/8** |
| **S-B** | edge-low | 端の値を避け、迷うと 3 を選びたがる (中心化傾向) | 一致 **≥6/8** |
| **S-C** | adversarial | ⚠️ 場面文を読まず早く終わらせたい (straight-lining) | 一致 **<6/8** ← **空振り検査** |
| **S-D** | edge-high | 「進捗＝書いた分量」と考える癖が強い (hold-out) | 一致 **≥6/8** |
| **S-E** | adversarial | 学術用語を一切知らずアンケートに不慣れ (hold-out) | 一致 **≥6/8** |

## §1 各ラウンドで何が分かったか

### v1 → v2: 尺度の定義に穴があった (S-A / S-B が独立に同じ 5 点を指摘)

1. Q2 の「仕上がり」の範囲が未定義 → **S-B が場面 4 で 3 を付けて唯一の失点**
2. Q1 の 5「強く引っかかって動けない」が「引っかかりの強さ」と「手が止まっている」を束ねていた
3. 「引っかかり」に意欲低下を含むかが未定義
4. **2 と 4 にラベルが無く**、S-B は最も多く使った値の意味が決まっていなかった
5. 「4 通りすべてが起こる」と「どちらか一方に寄る」が**矛盾して読める**

→ すべて v2 で修正。S-B が 7/8 → 8/8 に改善。

### §2 ⚠️ v2 → v3: 追加した 2 行が**妥当性を壊していた**ので撤回した

v2 で足した次の 2 つが、**測ってみると逆効果**だった。

| 追加した文言 | 実測された害 |
|---|---|
| 「8 問中 6 問がそろわなかった場合は、こちらの説明を書き直してもう一度お願いします」 | ⚠️★ **S-A が出題構成を推測して答えを配分し始めた**。逐語:「**8 問全体の構成を先に見た**…4 通りが 2 問ずつ配置されているはずだと考え、**1 と 5、2 と 6、3 と 7、4 と 8 が対になるように値をそろえました**」／「自分の感じ方より、**出題者の想定を推測するようになった**」。S-B も「少し身構えました（**これも端を避けた一因かもしれません**）」<br>⚠️ S-C には**逆効果**: 「そろわなくても…単に説明が書き直されるだけだと読めたので、**余計に気楽になりました**」 |
| 「（両方が高い場面も、両方が低い場面もあります）」 | S-B 逐語:「8 場面の中に 4 通りが均等に入っているのだろうと推測しました。**答えを配分で調整すべきか一瞬考えました**」 |

→ **両方削除**。v3 の S-A は「**分布を整えるための調整はしていません**」と明示的に報告し、
戦略的回答が消えたことを確認した。

**教訓**: 合否条件を被験者に開示すると、理解度ではなく**出題構成の推測能力**を測ってしまう
(`synthesis.md` §2 **L5「計測・提示それ自体が行動を変える」**の実例)。

### v3 → v4: 場面 6 に「難しさの目印」が無かった

S-B が場面 6 の Q1 を 3 のままにした。逐語:
「場面 8 には『難しいところに当たったわけではなく』という**否定の目印**があるのに、
場面 6 には**肯定側の目印（難しい／迷った／うまくいかない）が無い**」

→ 「何を書くか決まらないまま」→「**どう論を運べばよいのか決められないまま**」に変更。
v4 以降、全ペルソナが場面 6 を正答。

### v4 → v5: 場面 2 が Q2 の手がかりを「量」でしか与えていなかった

S-B 逐語:「場面 2 が本文の進み具合について与えている情報は『文字数は始めたときと変わらない』
＝**量だけ**でした。…**量を使うなと言われた上で量しか与えられていない**ので、
『近づかなかった』に振る根拠が自分には作れませんでした」

→ 「文字数は始めたときと変わらない」→「**書き直すたびに、最初に書いた言い回しへ戻ってきてしまう**」
に変更（量ではなく「堂々巡り」で Q2 低を示す）。v5 で S-B が場面 2 を正答。

### §3 v5 → v6: Q2 が「何が数えられないか」しか言っていなかった (S-B / S-D が独立に同診断)

v5 で S-B・S-D が**そろって場面 7** を落とした。診断が一致していた。

- **S-B**: 「足りなかったのは、**質の改善が「完成への接近」に数えられる、という言い切り**です。
  教示文は『量ではない』という**否定形までしか言っておらず**、『では何が数えられるのか』を
  肯定形で示してくれていれば、迷わず振れたと思います」
- **S-D**: 「場面 3 は動かせて場面 7 は動かせなかったのは、**減った量が明示されているかどうか**の差」

→ Q2 に肯定形の規則を追加:
**「中身がよくなったのなら、書いた量が増えていなくても、減っていても、近づいたと数えてください。」**

v6 で S-B・S-D とも 8/8。S-D 逐語:「後半の『**減っていても、近づいたと数えてください**』は、
私の癖を名指しで否定していると読めました」。S-B は「**3 のままにした場面: なし**」。

## §4 空振り検査 (S-C) の中身 — 器が straight-lining を実際に落とせるか

| ver | S-C の回答 | 一致 |
|---|---|---|
| v1 | (3,3)×7 ＋ (3,2) | 0/8 |
| v2 | (3,3)×7 ＋ (3,4) | 0/8 |
| v3 | (3,3)×7 ＋ (3,4) | 0/8 |
| v4 | **(4,4)×8**（全問同一の非中点） | 2/8 |
| v6 | (3,3)×7 ＋ (4,3) | 0/8 |

⚠️ v4 で「全問 (4,4)」という**中点以外の straight-lining** が出たのは重要な観測で、
`inferQuadrant` の「3 は不一致」だけに頼っていては 2/8 まで通ってしまうことを示す。
**6/8 に届かない本当の理由は、4 象限を 2 問ずつ均等配置していること**である
（どの定数 (q1,q2) を置いても一致は最大 2 問）。
→ この性質を `calibration_eval.rs` の
`vignette_straight_lining_cannot_reach_pass_threshold` で 25 通り全数検査し、
`scripts/check_vignettes.py` の C3 で配置崩れを防いでいる。

S-C の質的所見も一貫していた:

- 「**あなたを評価するものではありません**」は毎回**手抜きの許可**として読まれた
  （v1「それでいっそう気が抜けました」/ v4「適当でも困る人はいないと解釈した」）
- 「迷ったら近いほうへ振れ」は**読解を前提にするので読まない参加者には作用しない**

→ ⚠️ **教示文で straight-lining を防ぐことはできない**。防げるのは**ゲートで落とすこと**だけ。
被験者を離脱させない対策はプローブ負荷の側にあり (`notes.md` §6.2)、本タスクの範囲外。

## §5 ⚠️ 収束判定 — skill の基準は満たしていない (正直に記録する)

`empirical-prompt-tuning` の停止条件は「**連続 2 回で新規不明瞭点 0 件**」だが、**達していない**。
v6 でも次の残余が報告されている:

| # | 残る不明瞭点 | 指摘したペルソナ | 実害 |
|---|---|---|---|
| R1 | **Q2 の「本文」に見出し・構成メモが入るか** (場面 4 / 場面 6) | S-A / S-B / S-D / S-E (**全ラウンドで最多**) | v3 以降**失点ゼロ**。ただし場面 4 の Q2 が 1 と 2 に割れる |
| R2 | **Q1 の 4 と 5 の境目に目安が無い** | S-A / S-B / S-D / S-E | ⚠️ **実害なし**（採点は ≥4 を high とするため 4/5 の別は結果を変えない） |
| R3 | **「3」が選択肢にあるのに「近いほうへ振れ」と言われる矛盾** | S-A / S-B / S-E | 3 の使用を抑える効果はあるが、被験者は不安を報告 |
| R4 | 場面ごとの時間の長さ (10/15/30 分) を強度に使ってよいか不明 | 全ペルソナ | 実害なし（全員が「使わない」と判断） |

**R1 を潰さなかった理由**: 「見出し・参考文献の書式は本文に数えません」と書くと、
場面 4（参考文献の書式）と場面 6（見出しだけ）の**答えを教示文が名指ししてしまう**
（decisions D-7 に反する）。**曖昧さを残す方が、器としての識別力は高い**と判断した。
一度この一文を書いて即座に撤回している。

**R2 を潰さなかった理由**: 採点規則 (`q1 >= 4` を high) の下では 4 と 5 の区別が結果に
影響しない。教示を増やすと読解負荷が上がる (L5) 割に、測定は 1 ビットも変わらない。

**停止の判断**: 質的な残余は消えていないが、**判定 (合格/不合格) は 27 回の実行で一度も
外していない**。skill の「リソース打ち切り（80 点で出す判断）」に該当すると判断して停止した。

## §6 ⚠️ この実測が保証しないこと (過大主張の自制)

1. ⚠️★★★ **LLM の実行者は人間被験者の代理ではない。**
   ここで測ったのは「**教示文と場面文だけで想定象限が一意に決まるか**」であって、
   人間の中心化傾向・straight-lining の**発生率**ではない。
   ペルソナは指示によって演じられたものであり、実際の被験者分布を反映しない。
2. ⚠️ **通過率 80%（被験者間）は一切検証していない。** 測ったのは per-被験者の 6/8 だけ。
3. ⚠️ **反応性 (L5) の残余は消えていない。** 「8 つの場面は…はっきりするように書いてあります」は
   本番プローブへ「端に寄せる」癖を持ち越させうる。完了画面の打ち消し文で緩和しているが、
   **その打ち消しが効くかは測っていない**（人間でしか測れない）。
   → 施行後に Q1/Q2 の分布を施行前と比較する項目を follow-up に残す。
4. ⚠️ **v6 の教示文で S-C を再測定したのは 1 回のみ。** v5 では S-C を回していない。
