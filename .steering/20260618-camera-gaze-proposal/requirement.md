# Camera Gaze Probe Proposal

Date: 2026-06-18

## 背景

GSE の現行 Need / Opportunity 層に対して、カメラ由来の視線・顔向き・画面注視らしさを入力として追加できるかを検討する。
ユーザーの直感としては、キーストロークだけでは判別しづらい「考えている」「読んでいる」「離席している」「詰まっている」の識別精度が上がる可能性がある。

一方で、カメラ利用には計算負荷、低スペック端末での格差、カメラ品質・照明・眼鏡・姿勢による不安定性、プライバシー、カメラ作動表示による緊張感がある。

## ゴール

- `.idea/` 配下に、カメラ視線を GSE の Need / Opportunity に追加する案を Markdown で保存する。
- HCI・視線推定・プライバシー研究を根拠として明記する。
- 現行 GSE のロジック・アーキテクチャとの整合性を保つ設計として落とし込む。
- 採用可否を曖昧にせず、研究プローブとしての採用範囲と本番機能としての制限を明確にする。

## スコープ

今回の作業は設計メモの追加のみ。
Rust / TypeScript 実装、NDJSON schema 変更、依存 crate 追加、カメラ API 実装は行わない。

## 受け入れ条件

- `.idea/camera-gaze-need-opportunity-proposal.md` が作成されている。
- 参考文献として Web / 論文ソースが明示されている。
- カメラ LED / OS センサー表示を隠す案への判断が明記されている。
- Need / Opportunity のどちらにどう入れるか、既存 HMM / intervention / logger / frontend 境界との整合性が説明されている。
- 低負荷化、スペックディバイド、プライバシー、評価指標が具体化されている。
