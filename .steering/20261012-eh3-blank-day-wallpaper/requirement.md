# 空の日に替えていない壁紙を書き直さない

## 背景

`.steering/20261012-eh3-windows-device-rest/` 判断 2（見つかったこと 2）: 空の日の割り当てで、`wallpaper.rs` の `Show::Original` → `restore(false)` が、この層がまだ壁紙を替えていなくても、控えた元の画像をもう一度壁紙に設定し、位置（合わせ方）も控えた値で設定していた。見た目は同じだが、替えていない壁紙に触れ、本人が起動の後に替えた位置を控えた値で上書きする経路になる。研究者は直すと決めた（同 判断 3 #2）。

## ゴール

すでに元の壁紙を出しているモニタには書かず、どのモニタも書かないなら位置も書かない。肖像が残るモニタは今までどおり書き戻す。

## スコープ

### 含むもの
- `src-tauri/src/wallpaper.rs` の `restore` とテスト

### 含まないもの
- 実機での確認（次の Windows の実機の残りで、空の日に `TranscodedWallpaper` が更新されないことを見る）
