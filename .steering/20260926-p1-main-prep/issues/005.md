## Goal

⚠️★★★ **fold をまたぐ集約・同点の崩し方・最終の 1 つの選び方は実装しない**（`decisions.md` 判断 18・研究者裁定。v1.2 で宣言してから別タスク）。

## Background

- 事前宣言 §2.2（★ 全文を読むこと）: 設計 = grouped nested CV ／ group = 参加者 ／ outer = **leave-one-participant-out** ／
  inner = **grouped k-fold（`k = min(5, 参加者数 − 1)`）** ／ seed = **20260921**（★ 凍結 JSON の `search_protocol.seed` から**読む**。コードに書き写さない） ／ 選択の budget = 全格子 27 通り ／ 感度 OFAT 4 は**選択に入れない・報告のみ**。
  ★ 本 issue での `参加者数` は**全参加者数 N**（outer の訓練側は N−1 人なので、inner の k は常に訓練側の人数以下になる）。
- 事前宣言 §2.3 の 3 metric（順位）:
  - 主: **一人あたり episode 数の下限** —— 表には「その集合での参加者ごとの episode 数の最小値」と、それが `L = pg1.min_episodes_per_participant` 以上かの真偽を載せる
  - 副: **転帰 base rate が退化しないこと** —— 表には転帰カテゴリごとの件数と、カテゴリ数（1 なら退化）を載せる
  - 第 3: **参加者間の episode 数の変動係数** —— 表には `pstdev / mean`（参加者 1 人・平均 0 のときは `null`。⚠️ 0 で埋めない）を載せる
- ⚠️ **予測成績を metric にしない**（§2.3・ADR-008 D4 の会計規則）。
- `decisions.md` 判断 11: 転帰は**外から渡す**（`--labels` の CSV）。無ければ拒否。⚠️ `restart` などから転帰を作らない。
- `decisions.md` 判断 19: `L` は凍結 JSON の新版 `pg1.min_episodes_per_participant`。無ければ **exit 6**。
- `decisions.md` 判断 12: 極ごとに独立。`pole_applicable=false` の単位は episode 数に入れず、表に件数で載せる。
- 感度の一式（`ofat__…`）も同じ表に載せてよいが、**`role` 列で `selection` / `sensitivity_only` を区別**する（選択に入れないことを表の上で見えるようにする）。
- 読み込みは `scripts/p1_features_io.py`（issue 002）の `discover` / `load_envelope` / `project_pg1`、規則 (d) は `scripts/p1_run_grid.py` の `is_valid_search_run` と `grid_manifest.json` の `excluded_rule_d` を使う。
