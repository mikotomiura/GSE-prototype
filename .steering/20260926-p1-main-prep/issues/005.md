## Background

  - 主: **一人あたり episode 数の下限** —— 表には「その集合での参加者ごとの episode 数の最小値」と、それが `L = pg1.min_episodes_per_participant` 以上かの真偽を載せる

  - 第 3: **参加者間の episode 数の変動係数** —— 表には `pstdev / mean`（参加者 1 人・平均 0 のときは `null`。⚠️ 0 で埋めない）を載せる
- ⚠️ **予測成績を metric にしない**（§2.3・ADR-008 D4 の会計規則）。
- `decisions.md` 判断 11: 転帰は**外から渡す**（`--labels` の CSV）。無ければ拒否。⚠️ `restart` などから転帰を作らない。
- `decisions.md` 判断 19: `L` は凍結 JSON の新版 `pg1.min_episodes_per_participant`。無ければ **exit 6**。
- `decisions.md` 判断 12: 極ごとに独立。`pole_applicable=false` の単位は episode 数に入れず、表に件数で載せる。
- 感度の一式（`ofat__…`）も同じ表に載せてよいが、**`role` 列で `selection` / `sensitivity_only` を区別**する（選択に入れないことを表の上で見えるようにする）。
