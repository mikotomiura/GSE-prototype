## Background

- 事前宣言 `docs/preregistration-p1-episode.md` v1.1 冒頭 (3)（★ 実装前に**全文**を読むこと）:
  - 軸は 2 本: **ポインタ軸 = `baseline`（極 A）と `pointer_b`（極 B）**／**修飾キー軸 = `baseline`（極 M−）と `modifier_m_plus`（極 M+）**。
    ⚠️ 軸をまたいで 3 実行の min / max を取らない。
  - ★ 上下界は**極の順序を前提にせず**、独立に求めた 2 極の値の min / max で取る（「極 A が上・極 B が下」と書かない）。
  - ⚠️ ポインタ軸: `pointer_b` が `pole_applicable=false` なら極 B を min / max に**入れない**。その単位のポインタ軸は**算出不可**と報告し、**幅 0 と報告しない**。
  - ⚠️ 修飾キー軸: `modifier_m_plus` が `not_applicable` なら `not_applicable` と報告し、**極 M+ を計算したと書かない**。幅への寄与はゼロ。
- G2 はまだ計算できない（recovery 推定器・介入判断が未実装）ので、**量に依らない**結合器として作る（`decisions.md` 判断 3）。
- 出力の形は `decisions.md` 判断 20 で決めた:
  - `ok`: `min` / `max` / `width = max − min`
  - ポインタ軸の `not_computable`: `min = max = width = null`
  - 修飾キー軸の `not_applicable`: `width = 0`、`min = max = baseline の値`、**極 M+ の値のキーを出さない**
