## Background

- 事前宣言 v1.1 冒頭 (1): `ime_overlap` は **retrospective**（`t` は変換の終端なので `t0` より後の行に依りうる）→ **`t0` の時点で使える特徴量としては使わない**。
- ADR-030 補訂 1 項目 7: `restart`（`T1d`）は**転帰側の retrospective な量**で、同じエピソードの予測にも、オンラインの推論・介入の入力にも使わない。
- `decisions.md` 判断 10: 結合するのは episode 表と `sessions.csv` だけ（metrics・probe・survey とは結合しない）。
- 既存の流儀: `scripts/build_analysis_db.py`（使い捨ての DB・duckdb が無ければ exit 5・PII を入れない・FULL OUTER で「無い」と「0」を区別する）。★ 実装前に全体を読むこと。
- `sessions.csv` の列は `participant_id,session_id,os,phase`（`scripts/gen_sessions_manifest.py` の契約）。★ 本 issue では **`session_id` = レイアウトの `<session>` ディレクトリ名**として結合する。
- 読み込みは issue 002 の `scripts/p1_features_io.py`（`discover` / `load_envelope`）を使う。⚠️ `project_pg1` は PG-1 専用なので**使わない・変えない**。

### 判断（issue の文言が決めていなかったところ・メインの確認を求める）
1. **非適用の極（`pole_applicable=false`）の onset は `episodes_*` に載せない。** 封筒の行は baseline と恒等（`replay.rs` の doc）なので、載せると baseline の episode が極の名前を変えて二重に入る（002 の `episodes` の数え方と同じ）。`sessions` にだけ理由つきで載せ、`n_onsets` は「`episodes_t0` に載せた本数」＝非適用なら **NULL**（適用可で 0 本の `0` と区別）。AC1 の「`is_onset==true` の行数の合計（極ごと）」は**適用可の極の合計**と読んだ。
2. **許可したブロックの中に退行キー（`ime_overlap` / `restart` / `restop_ms`）が現れたら exit 3**（黙って落とさず・載せず）。AC2b の「再帰的にたどっても無い」を、素直な入力だけでなく**どんな入力でも**保つため。名前一致だけの検査なので、別名で入ったものは防げない。
3. **onset 行の型を検査する**（`t0_ms` / `s_ms` は 0 以上の int64 の整数・`theta_*` は整数か null・`ime_overlap` は真偽か null・onset 行に許可ブロックと `restart` が要る）。DuckDB の BIGINT への暗黙の丸めを避けるため。同じ極の中で `t0_ms` が重複すれば exit 3（キーが一意でなくなる）。
4. **既存の `--out` は上書きしない**（`build_analysis_db.py` は消して作り直すが、002 の判定に揃え、誤指定のファイルを消さない側に倒した）。
5. `manifest` 表を足した（ビューの結合先として必要）。値は文字列のまま・前後の空白は除く・空の `os` / `phase` は NULL。BOM 付き・CRLF の CSV を読める。

### ⚠️ 未裁定（残課題）
- **`episodes_t0.dispersion` に「`t0` の時点で使えない量」が入っている可能性。** issue の指示どおり `dispersion` を載せたが、`dispersion.rs` の doc によれば `surprise` は**セッション全体の IKI baseline** に対する逸脱（`Dispersion::surprise`）、`pause_*` は穴による切断が retrospective。規則 (e)・補訂 1 項目 7 が名指しするのは `ime_overlap` / `restart` だけなので**動かしていない**が、このスキーマの分離は `surprise` を `t0` の側から外していない。→ 使う側（004 以降）の前に、`surprise`（と穴による切断）を `episodes_retrospective` 側へ移すかの裁定が要る。モジュール docstring にも同じ注記を残した。
- `sessions` は事前宣言の版・sha・`config_source`・`overrides_json` を行ごとに持つが、**セッション間で版が混ざっていても拒否しない**（002 の凍結既定の検査に相当するものは 003 の Scope に無い）。
- 時刻（`t0_ms` / `s_ms`）は絶対 epoch ms で個人を同定しうる。DB は repo の外・共有しない前提（docstring に注記）。
