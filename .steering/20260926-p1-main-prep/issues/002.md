# Issue 002: 3 極の出力を読み、PG-1 に渡す「参加者ごとの episode 数の分布」だけを出す
verify_level: recheck

## Goal

`run-features-all-poles.sh` の出力を参加者レイアウトに並べたものを読み、**宣言ゲート PG-1 に渡す唯一の集計**
（参加者 × 極ごとの episode 数の分布）を出す CLI `scripts/p1_pg1_distribution.py` を作る。
⚠️★★★ **転帰・予測成績・`restart`・`ime_overlap`・`T1a`（`dispersion`）・θ・時刻を読まないことを構造で保証し、テストで固定する。**

- 事前宣言 §2.3「宣言ゲート PG-1」: **いつ** = WP1 の yield が出た直後・探索を 1 度も回す前／**何を見てよいか** = ★ 参加者ごとの episode 数の分布**だけ**（⚠️ 転帰も予測成績も見ない）。

  トップは `{provenance, config, rows}`。`config` に `pole` / `pole_applicable` / `pole_not_applicable_reason` / `prereg_id` / `prereg_version` /
