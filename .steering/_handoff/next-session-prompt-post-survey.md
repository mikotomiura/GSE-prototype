## §4 ★★★ 本題 —— 層 0 の「揺らぎ」を測る（★ 音を変える前に）

### ★ なぜ「測る」が先か

サーヴェイは **層 0 を連続ノイズ側へ寄せる**方向を支持した（★ 一次で「silence と有意差なし」が最も強く言えるのは
**continuous noise**。legato music の予測 ISE はその **5〜7 倍**）。
⚠️ **しかし `player/step4.html` にはノイズ生成が 1 つも無く**（`noise` の出現 **0 件**・`createBufferSource` なし）、
層 0 は **正弦波の足し算のみ**である。→ ★ **寄せる＝新規実装＝音が変わる＝ Step 3 で耳が通した形が変わる。**

★★ **一方 S3-D14 で研究者は層 0 を「ブラウンノイズなどを主にしたもの」と聴いている。**
→ ★ **既に連続ノイズ帯に体制化されている可能性が高い。★ ならば書き換えは不要である。**

> ★★★ **だから最初の一手は「測る」であって「変える」ではない。**

### ⚠️★★★ ただし —— **vacil はそのままでは計算できない**（★ ここを誤魔化さない）

式 1 は `F ≈ ΔL / [(f_mod/4Hz) + (4Hz/f_mod)]` [vacil] だが、
⚠️ **`ΔL` は物理的な変調深度ではなく "temporal masking depth"（知覚された変調深度）**であると原文が明記している
（★ Fastl & Zwicker の量）。★ **正しく出すにはラウドネスモデル（Bark 帯域の specific loudness の時間変化）が要る。**

★ `player/step4.html` の既存の検算は **`renderOffline()` → `steadyPart()` → `decimate()` → `hannAmplitude()`** で
**物理的な変調を dB で測っている**（★ 2740–2792 行あたり）。→ ⚠️ **これは vacil ではない。**

★ **やってよいこと / 書いてはいけないこと**:

| やる | 書き方 |
|---|---|
| ★ 既存の包絡解析で **f_mod ごとの物理的な変調深度**を出す | ★ **「変調深度」と書く。**⚠️ **「fluctuation strength」「vacil」と書かない** |
| ★ 式 1 の分母（4 Hz で最大の重み）を**掛けて相対比較**する | ★ 「**vacil に比例する量の相対比較**」と書く。⚠️ 絶対値を [P65] の表と直接比べない |
| ⚠️ ラウドネスモデルを実装して真の vacil を出す | ★ **やるなら別タスク**（★ ISO 532-1 相当が要る）。⚠️ 「近似した」で済ませない |

### ★ 最初の 3 手（★ この順）

1. ★ **現行の層 0（`plan_a`・`inv_n2`・55 Hz）の変調深度を f_mod ごとに出す**
   （★ 既存の `[1] 包絡` の枠組みをそのまま使う。★ 0.001–0.02 Hz の状態帯と 0.5–20 Hz の禁止帯の両方）。
2. ★ **層 0 ＋ 層 2（粒子 100→400/s）でも同じものを出す**（★ 粒子率の変化が変調として乗るか）。
3. ★ **`inv_n`（ブラウンノイズらしさが強い候補）と比べる** —— ★ **どちらが連続ノイズ側に近いかを数値で言う。**
   ⚠️ **その数値で「安全」と結論しない**（★ r²=.55・§2-5）。★ **耳の判断（B1）は依然として要る。**
