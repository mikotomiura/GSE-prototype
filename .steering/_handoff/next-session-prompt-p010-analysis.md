
## §4 【A】復号と転記検証

```bash
mkdir -p /tmp/p010            # ★ repo 内に置かない
UNPACK=~/Desktop/G1_確認用_v0126/gse-next.app/Contents/MacOS/gse-unpack
for f in ~/Downloads/G1_P010/P010_block0*.age ~/Downloads/G1_P010/P010_block10*.age; do
  case "$f" in *_dup-*) continue ;; esac      # ★ dup は除く (同一なので)

done
cd experiments/20260801-controlled-friction-task
python3 validate_blocks.py --dataset /tmp/p010
```

### ⚠️★ `validate_blocks.py` が **検出できない**型 (スクリプト自身が明記・報告に必ず書く)

1. **ファイルの取り違え** — `file` が実在し重複も無いが**別ブロックの録音**である場合。
   NDJSON 名にブロック番号は入らないので原理的に区別できない
2. **`produced_chars` の隣接ブロック間の入れ替わり** — どちらも妥当な範囲なら無警告で通る

→ ★ **この 2 つを「検査した」と書いてはならない。**

★ このスクリプトは**判定に関与しない**（除外しない・しきい値を持たない・
条件ラベルを画面に出さない = 盲検を壊さない）。

## §6 ⚠️★ 踏んだ罠 (★ 繰り返さない)

1. ★ **`cargo test --workspace` は `packaging.rs` のテストを 1 件も走らせない**
   (`feature = "package"` の裏)。→ `--features package` を付ける。
   ⚠️ 付けずに「全緑」と報告しかけた
2. ★ **`gse-replay` の `OK:` は stderr に出る。** `2>/dev/null` で自分の測定結果を捨てて
   「回帰失敗」と誤読した
3. ★ **Windows の版文字列は UTF-16LE。** macOS の `strings` に `-el` が無く、
   ASCII 検索だと `0.1.26` が **0 件**に見える → Python のバイト列検索を使う
4. ★★ **端末から直接起動したアプリは、端末 (VS Code) の TCC 権限を継承する。**
   `input_monitoring=true` と出ても当てにならない。⚠️ **`open` 経由で測る**
5. ★★ **`#[cfg]` なしのテストは相手側の OS でも走る。** macOS 前提のテストが Windows CI で
   赤になった。⚠️ **`cfg` で閉じるだけでは半分**で、閉じると相手側の規則が未検証で残る
   → **両 OS に対のテストを置く** (`docs/development-guidelines.md` §3)
6. ★ **`git push` / `gh pr merge` / `gh pr create` の一部はエージェントから実行できない。**
   → ユーザーに `! git push` の形で打ってもらう
