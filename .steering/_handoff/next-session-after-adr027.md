## ⚠️★★★ 前セッションから引き継ぐ「運用の教訓」

1. ⚠️★★★ **昇格済みの用語は、後続の裁定で意味が絞られたときに *黙って* stale になる。**
   ★ 実際: 2026-09-08 の午前に `.idea` §1 から `glossary.md` へ昇格した「招待の解除」の定義
   （逐語「表現が **基層** へ縮退すること」）が、★ **同じ日の午後に ADR-027 D5（解除では層 0 へ落ちない）と正面から矛盾した。**
   ⚠️ **`基層` は `expression-channel.md` §3.5.3 で「視覚側の層 0」と定義されている**ので、字句上も矛盾していた。
   → ★★★ **`/cross-review` 第 1 巡が「重大」として拾った。**⚠️ **自分の diff だけを見ても出ない型である**
   （★ 矛盾は「前セッションの成果」と「本セッションの裁定」の *あいだ* にあった）。
   → ★ **用語を昇格したら、その用語に触れる裁定を出すたびに定義を読み直す。**
2. ⚠️★★★ **`/cross-review` は巡ごとに *別の層* を突く。**
   ★ 今回: **1 巡目 = 自文書・他文書の矛盾**（★ 上記 1）／**2 巡目 = 自分が足した規則の *境界条件***
   （★ 「同じ評価契機」の所有者は誰か・「受け入れない」の *あと* どうするか・`epoch` 回転と heartbeat の混同）。
   ⚠️ **2 巡目の 4 件はすべて「第 1 巡で私が足した規則」に付随する穴だった** —— ★ **規則を足すと、その境界が新しい穴になる。**
   → ★ **打ち切りは「指摘が尽きたから」ではなく「残る論点が別の未決（`W-1`）へ収束したから」で判断する。**
3. ⚠️★★★ **`git add -A <dir>` を使わない。**
   ★ 実際: `git add -A docs/` で **未踏スライドの無関係な作業 17 ファイル**（`.pptx` / `figures/*.png` / `_template/`）を
   ADR-027 のコミットへ巻き込んだ。★ `git reset --soft HEAD~1` ＋ `git restore --staged` で戻したが、
   ⚠️ **`git show --stat | head` で確認したせいで一覧が切れており、最初は 4 ファイルだと誤認した。**
   → ★★★ **ステージは常に *明示パス* で行う。**★ **確認は `git show --numstat --format="" <sha>` を `head` せずに読む。**
4. ⚠️★★★ **レビューの指摘は「一次で検算してから」受け入れる。**
   ★ 今回は **HIGH 4 件 ＋ Codex 重大 1 件がすべて検算に耐えた**（⚠️ **stale read 由来の誤指摘は 0 件**）。
   ★ ただし **1 件は半分だけ妥当だった**（★ Codex #4: `A21` の `ADR-017 D2` 引用は
   「フィールド追加の禁止」としては**正しい**。⚠️ 誤帰属だったのは *別の* 逐語）。
   → ★ **「指摘が当たっている」と「指摘の理由が当たっている」を分けて検算する。**
5. ⚠️★★★ **自分が足した「実測」の行番号は、自分の編集で腐る。**
   ★ 今回、ADR に `expression-channel.md:95` / `:818` と書いた直後に自分の編集で行がずれた。
   → ★ **自分が編集する文書は行番号でなく *節番号 / 観点 ID* で参照する**（★ 他文書なら行番号でよい）。
