## §3 ★★★ 本 Step の主題 — 未解決の衝突（S3-D13）

```text
spec §1.1 は状態の波を 0.001–0.02 Hz に置くと定めている
      ↓
層 0 の自律変異も同じ帯域に置くと（現候補は 0.005 / 0.0031 Hz ＝ まさに帯域内）
      ↓
★ 聴き手が「基層が勝手に揺れただけ」と「自分の状態が変わった」を区別できない
      ↓
★★ 表現層における偽陽性
```

★ **Step 3 では層 1–3 が無かったので実害が無く、B1 の結果は有効である。**
**問題になるのは層 2 を足す本 Step である。**

**解き方の 3 案（★ 推測で選ばない。聴いて決める）**:

| 案 | 内容 | 代償 |
|---|---|---|
| **A: 周波数で分ける** | 層 0 の自律変異を状態帯より 1 桁以上遅く（≤ 0.0005 Hz ＝ 周期 33 分以上） | ⚠️ **1 セッション内でほぼ変化しない**——研究者が求めた「時々で変異していく面白さ」が体験されない |
| **B: 次元で分ける** | 層 0 は音色・減衰だけ、状態は密度・帯域・空間 | ⚠️ **耳が次元で分離できる保証が無い**（未検証の想定） |
| **C: 両方** | 遅くしたうえで次元も分ける | 最も安全だが体験される変化が最も乏しい |

→ ★ **3 案を切り替えて聴ける形にして、研究者に選んでもらう。**

## §5 ⚠️★ 落とし穴（Step 0–3 で実際に踏んだもの・同じ形を繰り返さない）

1. ⚠️★★★ **silent pass はこのタスク系列で 4 回出た**（S0-D14 の 3 件 ＋ Step 3 の音量スライダ検査）。
   → ★ **検査を書いたら「壊した状態で赤くなること」を必ず実測する。**
   ★ **Step 3 の `layer0_selftest.py --selftest`（meta 検査 25 件）がその型なので流用する。**
2. ⚠️★★★ **測る場所を間違えると検査は空回りする**（Step 3 で実測）——
   **55 Hz の搬送波を 4 Hz で振幅変調しても、エネルギーは 4 Hz ではなく側帯波 51/59 Hz に出る。**
   4 Hz の線を見ていた検査は **−90 dB で PASS したまま**だった。→ ★ **側帯波で測る。**
3. ⚠️★★ **窓なし DFT は比較の符号を逆にする**（S0-D8）。変調スペクトルは **必ず Hann 窓**。
   **一様に刻んだ帯域 RMS も誤る。線の位置で比べる。**
   ★ **間引きの零点・Nyquist 超の周波数には数字を出さない**（Step 3 で `+31.7 dB` という嘘の値が出た）。
4. ⚠️★★ **4 Hz 付近が最悪**（fluctuation strength のピーク・**ISE を 70 例中 63 例予測した予測子**）。
   15–70 Hz も避ける。**状態の波は 0.001–0.02 Hz**。
   ★ 書き方は「緩慢だから安全」ではなく **「禁止帯から離れているから安全」**。
5. ⚠️★★ **候補の切替で「鳴らし直し」を作らない**（Step 3 で踏んだ）——
   フェードアウト→フェードインは**オンセットそのもの**で、spec §2 の禁止事項を UI 操作で作りに行くことになる。
   ★ **常に最大構成で組み、使わないものはゲイン 0 にしてランプで移る。**
6. ⚠️★ **`await ctx.resume()` を素で待たない**（自動再生ブロック下で**無言で固まる**）。
   ★ **`alert()` を使わない**（モーダルはページを止め、ブラウザ自動検証も固める）。
7. ⚠️ **合成クリックでは AudioContext が起動しない**（Chrome の autoplay policy）。
   ★ **実クリックが要る。** ⚠️ **ウィンドウが最小化／タブが背面だと、実クリックもスクショも届かない**
   （`visibilityState="hidden"` / `outerWidth=0` を先に確認する。**着弾プローブで区別する**）。
8. ⚠️★★ **Windows コンソールは cp932** —— `—`(U+2014) / `⚠`(U+26A0) で **Python が落ちる**。
   ★ `PYTHONIOENCODING=utf-8` ＋ `stream.reconfigure(errors="backslashreplace")`。
   **PowerShell スクリプトに日本語を入れない。**
9. ⚠️ **`file://` から設定ファイルを `fetch` できない**。★ ローカル HTTP で配る（`run.sh serve`）。
10. ⚠️ **GSE 本体（Rust / TS）を変更しない。OSC / WebSocket を実装しない**（D5・外部送信境界を増やさない）。
11. ⚠️ **凍結対象に触れない**: `docs/preregistration-v0.3.md` / `engine.rs` / `probe_scheduler.rs` /
