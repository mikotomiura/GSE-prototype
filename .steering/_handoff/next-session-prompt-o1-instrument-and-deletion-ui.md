## §4 ⚠️ 落とし穴（★ 実測で分かっているもの）

1. ⚠️★★★ **`SetWinEventHook` の範囲は単一の連続区間しか取れない** —— ★ 0x0003 を既存 IME 範囲に
   混ぜようとしない。**3 本目を張る**（`hook_windows.rs:295` が仕様として明記）
2. ⚠️★★★ **フックコールバック内は Atomic ＋ `try_send` のみ**（`hook-constraints`）。★ ログを書かない
3. ⚠️★★ **`is_typing_key` を素朴に広げると `HMM_VERSION` bump になる** —— ★ チャネルは 1 本で、
   `FeatureExtractor::process_event` が**受け取った全イベントを特徴量に使う**（`features.rs:89`）
4. ⚠️★ **`Cargo.toml` は repo 直下に無い**（`src-tauri/` にある）。`cd src-tauri` するか `--manifest-path`
5. ⚠️★ **`| tail` にパイプすると `$?` が tail のものになる** → リダイレクトしてから `echo $?`
6. ⚠️★ **Windows コンソールは cp932** → Python は `PYTHONUTF8=1`
7. ⚠️★★ **`.rs` への Write は guard が `println!` を文字列一致で弾く**（★ **コメント内でも弾かれる**）
8. ⚠️★ **macOS では `hook_windows.rs` が 1 行もコンパイルされない**。★ `#[cfg]` の無いテストは
   **相手側の OS でも走る** → **両 OS に対のテスト**
9. ⚠️★★ **「空いている」は `docs/` だけを見て言わない** —— ★ 採番も既決も `.steering/` に潜む
