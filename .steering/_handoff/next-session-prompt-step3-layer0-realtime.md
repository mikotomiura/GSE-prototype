## §3 ★ 手を動かす順序

### Step 3a — 層 0 を WAV で書き出して聴く（★ 依存追加なしでできる）

⚠️★★ **ここは numpy を必要としない。** 層 0 の仕様は「**正弦波の足し算**」だからである:

```text
55–110 Hz 帯の持続音 ＋ 整数次倍音のみ（2f, 3f, 4f…）
非調和成分ゼロ / sharpness 低 / ★ 状態に応答させない
```

→ **Python 標準の `wave` モジュール**で 16bit PCM を書ける（`math.sin` と `struct` で足りる）。

**全層に共通する禁止事項**（[P64] から直接・`spec` §2）:

- ✗ **オンセット**（アタックのある音を鳴らさない。全て持続音の重ね合わせ）
- ✗ **拍・リズム**（周期的な無音・周期的な強弱を作らない）
- ✗ **音高のステップ**（動かすなら連続グライド）
- ✗ **実物音の引用**（水・鳥・機械音）

★ **確かめること**: **「ずっと鳴っていて気にならないか」**。
★ **同時に [P71] のオフスイッチ要件も試す**（止められること・音量を変えられること）。

### Step 3b — リアルタイムの形を音として通す

★ **Step 2 が作ったのは「1Hz の目標値 → レンダレートで連続追従」という形**である。
これを**音のパラメータに実際に当てて**、音として破綻しないかを見る。

```bash
# 既に動くパイプライン（Step 0-2 の成果物）
cd src-tauri && cargo run --bin gse-replay -- <ndjson> > snap.json
python .steering/20260811-expression-prototype-step0/scripts/snapshot_to_csv.py snap.json out.csv

```

⚠️ **層 0 は状態に応答させない**ので、Step 3b で動かしてよいのは
**「基層が鳴り続けている上で、平滑化された値が“聴こえない程度に”何かに乗る」**ところまで。
**状態→音の本格的なマッピングは Step 4 以降**（層 2 粒子）。
