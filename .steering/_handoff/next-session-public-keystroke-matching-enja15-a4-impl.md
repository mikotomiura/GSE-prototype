  1. **語の長さの並びの一意性（unicity）**: 配布の本文だけで（記録は使わない）、連続する k 語の長さの並びが、同じ課題の候補 N 本の中で一意になる割合を k と N ごとの曲線にする。前の試作 `experiments/20261009-length-sequence-uniqueness/`（青空文庫）を KLiCKe に広げる形。
  2. **差分プライバシー（DP）の形との比較**: R3 を起点に、区間の押下の数と押下の間隔に雑音を加えた形 R-DP(ε) を足し、同じ攻撃者と同じ 10 の有用性の指標で並べる。

- **順番の制約（信頼の根拠）**: 2 つの手順（k・N・ε・雑音の形・プライバシーの単位）は、**本計算の照合の結果を 1 つも見る前に** `notes.md` に書いてコミットする（コミット時刻が証拠）。→ 本計算（`run_main.py` の実データの段）を回す前に必ず閉じる。
- 根拠のサーヴェイ: `docs/literature/20261013-length-unicity-and-dp-release.md`（[V287]〜[V298]）。どちらの問いも直接の先行研究は見つからなかった（判定不能 0 件・新しさの主張にできる見込み）。カードの末尾に「探索的な分析の手順の案」がある。設計への含意の要点:
  - unicity は 1 つの数でなく k と N の曲線で示し、試した N の外へ延ばさない [V290]。「再識別」と呼ばず「候補 N 本の中の一意さ」と呼ぶ [V291]。窓の位置は無作為・書き手を単位にした区間。
  - DP は「何を 1 単位として守るか」を必ず書く。区間ごと・間隔ごとの雑音は事象ごとの保証で、書き手ごとの保証ではない [V292]。DP でも識別は残りうる [V293]。
  - 雑音は評価だけの模擬なので事前登録の種の導き方（numpy）でよい [V295]。整数（区間の長さ・ms の間隔）には両側の幾何分布（離散の Laplace）を使い、浮動小数の Laplace は使わない [V296]。論文に「本当の公開の実装ではない」と書く。
- 種: 事前登録の `seed_uses` に探索的な分析の用途は無い。新しい用途の名（例 `exploratory_dp`・`exploratory_unicity`）を足すかは手順と一緒に決めて notes に書く（`config.json` は凍結の値なので、足すなら逸脱の扱いを確かめる）。
