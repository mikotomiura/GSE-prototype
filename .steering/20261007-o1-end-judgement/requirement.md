# O1 の終了判定を運営シートに実装する

## 背景
研究者判断（2026-10-07）: O1 の終わりは非公開の運営スプレッドシートが機械的に判定し、終わった人から研究者が個別に連絡して O1-S を手で送る。
基準（同日・研究者が選んだ）:
- 起算点 = **最初に記録した日**（届いたファイル名のセッション開始の日付の最小）
- 期間 = **暦日 21 日**（起算日を 1 日目として 21 日目が過ぎたら終了）。事前登録草案【決 3-a・3-b】と同じ
- 届いた日の数は**条件にしない**（数を出すだけ）。⚠️ 台帳はファイル名しか見られないので「有効日」は判定できない
- 新しく終了になった人は**研究者宛ての通知に含める**（参加者には送らない）

## ゴール
受領台帳（`Form_O1/GSE_O1_Ledger.gs`・6 時間ごと）に「O1 終了判定」タブを足し、P-ID ごとに 判定（記録待ち / 期間中 / 終了（連絡待ち）/ 終了（連絡済み）/ 完了）・起算日・21 日目・今日は何日目・届いた日の数・最後の記録の日・片づけの案内 を出す。研究者が書く欄（終了連絡日・O1-S 送付日・片づけ確認日・メモ）は P-ID ごとに保つ。

## スコープ外
- 参加者への連絡（研究者が手で送る）・アプリ側の変更・期間の延長の仕組み

## 受け入れ条件
- [ ] 判定は純関数でテストし、境界（20・21・22 日目）を固定する
- [ ] 研究者の記入欄が作り直しで消えない・削除された P-ID の行は残らない
- [ ] 新しく終了になった人だけを 1 回通知する（続いても再送しない・走査打ち切りの回は保留）
- [ ] 途絶の判定・通知を壊さない（既存のテストが緑）・変異テストで新しいガードが赤になる
- [ ] 氏名・メールを書かない
