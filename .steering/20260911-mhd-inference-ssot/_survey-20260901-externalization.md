## §2.2 効果主張の 4 層区分 / §6.1 評価の 4 層

**効果主張の 4 層**: 1. 行動特徴から状態信号を生成できるか / 2. 本人が読み取れるか /
3. 本人が選び直せるか / 4. 機会保存に関係する行動変化があるか

**評価の 4 層**:

| 層 | 測る内容（原文） | 例（原文） |
|---|---|---|
| **表現の可読性** | 表現の変化を本人が区別できるか | 状態対応の説明、再認テスト |
| **自己状態の俯瞰** | 表現が本人の判断材料になるか | 状態の振り返り、選択理由 |
| Physical Anchor の受容 | 離席の選択肢が受け入れられるか | opt-in、dismiss、拒否理由 |
| 下流の機会保存 | 復帰後の作業がどう変わるか | `paste_after_stuck_rate`、`self_recovery_without_paste`、`manual_contribution_ratio` |

★ 安全性（HIR、ストレス、品質、継続意欲、autonomy loss）は「効果」と**別軸**で見ると明記。

**判定**: 後半 2 層（PA 受容 / 機会保存）は**既決の言い換え**（`research-positioning.md §1/§8`・ADR-018 D5）。
⚠️ **前半 2 層（可読性 / 自己俯瞰）は新規** —— ADR-021 D10 の E-7 は「層 0 vs `stable`」限定であり、
**4 値全体の可読性・自己俯瞰という一般的評価設計は `.idea` にしかない**。

**§6.2 形成的試作の順序**（★ 具体的手順として他箇所に見当たらず新規）:
1. 静止画/短い動画で 4 イベント比較 → 2. **診断名なしで説明できるか** →
3. 継続/休止/離席のどれを選びたくなるか → 4. **「歩かねばならない」と感じないか** →
5. PA 提示時の受容/拒否/負担

## §5.1 Physical Anchor の非命令的経路

```
状態表現を見る → 自分の作業状態に気づく → 続ける/休む/離れるを選ぶ
  → 離れる選択をした場合だけ Physical Anchor を利用
  → 戻る時刻・距離・歩数は本人が決める
```
★ **ADR-018 D1〜D3 と完全に整合**（`.idea` は ADR-018 を参照文書に明記しており後追いの説明文）。
→ 新規性は薄いが、**経路図として明文化した点に価値**（設計意図の可読性）。
