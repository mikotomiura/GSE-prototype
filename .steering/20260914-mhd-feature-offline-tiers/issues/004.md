# Issue 004: `T1c`（削除と挿入の遷移の形 — delete run / del→ins 遷移 / burst 内の後続の削除の走り / D-I 交替 / category bigram の重複率）
verify_level: parse

## Goal

特徴行に `revision` を足し、**削除の走り・削除から挿入への遷移・burst 内の 2 本目以降の削除の走り・削除と挿入の交替回数・キー種別 bigram の重複率**を載せる。
⚠️ 「修正（revision）の位相」とは呼ばない —— ★ **「削除と挿入の遷移の形」**という観測の名前で扱う（下記 Background 冒頭）。

## Background

### ★★★ 算出式と名前（2026-09-19 確定・研究者判断 —— ★ 細部 U1〜U4 も 2026-09-20 に裁定済み・下の節）

★ 出典: `.steering/20260918-theory-critical-review/decisions.md` **判断 2 #5 / #6**（研究者の回答）・
`definitions-restop-t1d-t1c.md` §6.2 / §6.2b（算出式）・`docs/literature/20260919-content-free-revision-measures.md`（S7 サーヴェイ）。
★ このタスク側の記録は `decisions.md` **判断 26**。

⚠️★★★ **旧フィールド名（`rewrite_count` / `redelete_count` / `loop_depth_max` / `local_recurrence`）を使わない。**
★ 理由（S7）: rewrite・repetitive（再削除）・depth・recurrence は、文献上**位置・入れ子・RQA を前提に定義された構成概念**である（[V155] [V154] [V158] [V159]）。
GSE は本文もカーソル位置も持たないので、同じ名前を付けると別の概念を測っていると誤読される。

| ★ フィールド | 旧名 | 算出式（★ 新しい定数ゼロ） |
|---|---|---|
| `delete_run_max` | （そのまま） | 連続する削除系 press の走りの最大長 |
| `delete_runs` | （そのまま） | 連続する削除系 press の走りの本数 |
| `del_to_ins_transitions` | `rewrite_count` | 削除の走りの**直後の press** が挿入系である回数 |
| `delete_runs_after_first_in_burst` | `redelete_count` | burst の中で **2 本目以降**に現れる削除の走りの本数 |
| `di_alternations_max` | `loop_depth_max` | burst を `{D, I}`（削除の走り / 挿入の走り）の run-length 列に圧縮したときの**遷移回数**の最大 |
| `category_bigram_repeat_rate` | `local_recurrence` | burst 内の `KeyCategory` bigram の重複率 |

- **挿入系 / 削除系**: ★ ADR-030 D3 の写像（`mod.rs` の `key_net_delta` が +1 / −1 / 0 を返す —— `metrics::is_text_producing` / `metrics::is_backspace`）。⚠️ 新しい分類を作らない。
- **burst**: ★ 既存の pause SSOT で切る（`extract_pause_resumptions` ／ `features::PAUSE_THRESHOLD_MS`）。⚠️ 独自の閾値を作らない。
- ⚠️★★★ **主張の格**: 誤打訂正と内容修正は、文字があっても自然課題ではほぼ分けられない（[V156]）。GSE の削除系の量は大半が表層の訂正を数えている（[V155]: 表層 92%）。→ **「修正の位相」と呼ばない。**
- ⚠️ **評価の制約**: 削除系の量は課題を変えると最も一貫しない（[V152]）。文書長で正規化すると得点との関係が消える（[V153]）。→ ★ **`T0`（打鍵数・純産出）と中央値 IKI で統制した増分でしか評価しない**（ADR-030 D10 の block ablation）。
- ⚠️ **妥当性の証拠は 0 件**（キー種別と時刻だけで作った修正特徴を、人手注釈と照合した研究が無い）。

### ★★★ 実装フェーズの設計裁定（2026-09-20 に**全件裁定済み**）

★ 研究者の指示（2026-09-19）: E1 連結の具体設計は、実装フェーズの設計議論で行う。
★ 以下の 4 点も同じく実装の設計に属するので、**実装フェーズで決める**とされていた（theory-critical-review `decisions.md` 判断 3）。
→ ★ **2026-09-20 に 4 点とも裁定した**（`.steering/20260920-issues-004-006/decisions.md` **判断 1**）。
⚠️ **worker は推測で 1 つ選ばない** —— ★ 下の Stop Conditions に該当する（★ 裁定が覆るときはここへ戻る）。

| # | 論点 | ★ 裁定（2026-09-20・判断 1） | 採らなかった案 |
|---|---|---|---|
| U1 | 削除の走りを**切る press**（挿入でも削除でもない press = `navigation`・修飾キー等の扱い） | ★ **裁定: 削除系以外の press はすべて切る**（全 press 列での連続。navigation を挟むと 2 本になり、§6.2 が位置の代理に挙げた navigation の情報を潰さない） | 挿入系だけが切る（navigation・修飾キーは無視する） |
| U2 | `category_bigram_repeat_rate` の**式**（例: bigram 列 AA, AA, AB） | ★ **裁定: `1 − 種類数 ÷ 総数`**（= 1/3。既に出た bigram を繰り返した出現の割合。bigram が 0 個の burst は `null`） | 2 回以上現れる種類に属する出現の割合（= 2/3。⚠️ 1 回目の出現まで重複に数える） |
| U3 | 走り・burst を単位とする値を載せる **tick** | ★ **裁定: 閉じが確定した時点の tick**（走り = 次の削除系以外の press または burst の閉じ ／ burst = 最後の press + `PAUSE_THRESHOLD_MS`）。causal になり、onset の予測に使う ablation へ未来の情報が漏れない | 最後の press の tick（retrospective 扱い）／ 次の burst の最初の press の tick（末尾の burst は計上しない） |
| U4 | 走りの**最小の長さ** | ★ **裁定: 1 から**（最大連続の自然な読み。★ 2 以上にすると新しい定数 2 を作ることになる） | 2 から（★ AC5 の fixture はどちらでも通るように選んである） |

- ★ 共通の規則（既存原則の適用）: **件数は 0**、閉じる単位が無い tick の**最大値・率は `null`**（⚠️ 0 で埋めない）。
- ⚠️ `Alphabetic` が大半を占めるため、U2 はどちらの式でも **burst の長さと強く相関する**（→ 上記「評価の制約」）。

#### ★ U1 ＋ U3 から従う細目（★ 判断 1 で明文化した。⚠️ 実装者はここを推測で埋めない）

1. **走りは burst をまたがない**（U3 が閉じる契機に「burst の閉じ」を挙げているため）。
   → ★ これで `delete_runs_after_first_in_burst` の「属する burst」が一意に決まる。
2. **件数は「数える単位が閉じた tick」に載せる**: `delete_runs` / `delete_runs_after_first_in_burst` は走りが閉じた tick、
   `del_to_ins_transitions` は**遷移を確定させた挿入系 press の tick**。
3. **burst 単位の値（`di_alternations_max` / `category_bigram_repeat_rate`）は burst が閉じた tick**。
   ★ burst の閉じは互いに `PAUSE_THRESHOLD_MS` 以上離れるので 1 tick に高々 1 つ。
4. ⚠️ **閉じがグリッド外に落ちた単位は黙って捨てる**（★ `stall_onset::column_from_onsets` と同じ規約）。
   ★ 実測: `instrument_rich` の**末尾 burst の閉じはグリッドの外**なので、その burst 単位の値は出ない（★ 欠陥ではない）。
5. `di_alternations_max` は、burst が閉じていれば **D/I の press が 1 つも無い burst でも `0`**。
