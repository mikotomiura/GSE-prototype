### ★★★ 規範となる定義（★ 判断 18 で裁定済み。⚠️ ここを勝手に変えない）

```text
観測区間:   feat 行の t を昇順・重複除去し、隣接差が hole_gap_ms 以下の極大な連続を 1 区間 [a, b] とする。
            ⚠️ feat 行が 1 本も無いファイルには観測区間が無い → onset は 1 つも立たない（全行 is_onset=false）。
            ⚠️ 最初の feat 行より前・最後の feat 行より後は観測区間の外である。

評価時刻:   条件 A を評価するのは、ある観測区間 [a, b] について  a + W <= t <= b  を満たす t だけ。
            集合 = { key の t } ∪ { key の t + W } ∪ { a + W（区間ごと） } をこの範囲に制限したもの。

連続を切る: 条件 A の直前状態（立ち上がり判定の prev）は、各観測区間の評価開始時点で false に戻す。

θ の標本:   昇順 press 列の隣接対 (k_i, k_{i+1}) のうち、k_{i+1} <= s かつ
            k_i と k_{i+1} が同じ観測区間 [a, b] に入る（a <= k_i かつ k_{i+1} <= b）もの。
            標本 0 件、または warmup_count が Some(n) で標本数 < n なら θ = None（onset を立てない）。

確定:       t0 = s + θ。t0 が s と同じ観測区間の右端 b 以下で、かつ (s, t0] の全評価時刻で
            条件 A が真のときだけ onset を確定する。不応期は現行どおり（立ち上がり 1 回につき 1 度だけ）。
```

★ 上の定義は **ADR の構造だけを使い、原因を 1 つも区別しない**（削除・一時停止・計器欠損・セッション境界を同じ 1 規則で受ける）。
