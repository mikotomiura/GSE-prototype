## Execution Result

**実装**: `src-tauri/src/analysis/feat_offline/dispersion.rs` (新規) と
`src-tauri/src/analysis/feat_offline/mod.rs` (配線) のみ (Allowed Files どおり)。

- `Dispersion` (`T1a`): `pause_p50_ms` / `pause_p90_ms` / `pause_max_ms` / `iki_cv` / `surprise` の
  5 フィールド。すべて tick 内の要素が 0 個なら `null` (0 埋めしない)。
- 分位点は nearest-rank 法 (`rank = ceil(q * n)`, 1-indexed, `[1, n]` にクランプ)。単調性
  (`p50 <= p90 <= max`) は rank が q に対して非減少であることから構造的に保証される。
- `iki_cv` は tick 内 IKI (全間隔、pause 閾値未満も含む) の変動係数 (std / mean)。
  要素 2 個未満、または mean が 0 (同時刻打鍵のみ) なら `null`。
- `surprise` はセッション全体の IKI baseline (`SessionIkiBaseline`、`mean`/`std` を
  セッション全体の IKI から一度だけ計算) からの z 相当の逸脱。baseline は
  `mod.rs::build_feature_rows` が tick ループの外で 1 回だけ作り、各 tick の
  `compute_dispersion` に引数として渡す (AC5: 関数シグネチャがセッション全体の統計を取る)。
  セッション全体で IKI が 2 個未満、または分散 0 なら baseline 自体が `None` になり、
  全 tick で `surprise` は `null`。
- pause の判定・長さは `super::extract_pause_resumptions` (issue 001 の共有ヘルパ) にそのまま
  委ね、`dispersion::pause_durations` は対になる直前 press との差分で `gap_ms` を添えるだけ
  (`boundary::pause_boundary_pairs` と対称の手法)。独自の pause 判定・新しい数値定数は追加していない。
- 帯域分割 ([P121] が否定した short/medium/long のような閾値切り) は実装していない。
