特徴行に `dispersion` を足し、**pause 長の分布統計**（p50 / p90 / max）と **IKI の CV**、

## Background

⚠️★★★ 一次は `ADR-030 D10` の Tier 表:
「`T1a` | 分布・個人相対（p50 / p90 / max・CV・個人基準からの逸脱）| **中**（平均より分散・最大値・
混合成分が過程差を持つ）。⚠️ **ただし帯域で切る案は否定された** [P121]」。

→ ★★★ **「pause を帯域（短い/中/長い）に切って意味を割り当てる」実装をしない。**

弁別は「長さ」ではなく「直前イベント」にあると結論している（★ それが `T1b` = issue 002 の担当）。
★ ここで作るのは **分布の要約値そのもの**であって、帯域の解釈ではない。

### ⚠️★★★ baseline は「セッション内」である（★ 研究者採択 2026-09-14）

D4 は **`t0` 検出器の閾値**の話であって、`T1a` の baseline の話ではない。
⚠️ 混同して「個人 baseline を実装した」と書かないこと。
