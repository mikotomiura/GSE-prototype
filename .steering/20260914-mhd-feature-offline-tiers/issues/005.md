## Background

⚠️★★★ **一次は `docs/adr/ADR-030-stall-onset-and-decision-episode.md` の D1〜D6 である。
★ この issue ファイルの要約を一次資料にしない。必ず ADR 本文を読むこと。**

★ ADR が凍結した構造（逐語）:

```text
条件 A（産出）:  因果窓 W（★ 右端 = 評価時刻・⚠️ look-ahead ゼロ）の中で
                 net = Σ(挿入系 press=true) − Σ(削除系 press=true)
                 が  net < net_diff_min  である
                 ★ net_diff_min は既存 OutcomeConfig の値（既定 1）をそのまま使う

条件 B（持続）:  条件 A が false → true へ 立ち上がった 時刻を s として、
                 s から θ_person 経過した

t0            :  ★ s + θ_person（= 条件 B が満たされる瞬間）
```

- **D2**: ⚠️★★★ **`t0` は「検出時点」であって「停滞が始まった時点」ではない。**
- **D3**: ⚠️★★★ **新しい定数を作らない。** 産出の計算に使うのは `key` 行の `(t, category, press)` だけ。
- **D4**: `θ_person = quantile_q(隣接 key 行の t 差分の分布 | user, task_kind)`。
  ⚠️★★★ **床も天井も置かない。** ★ `W` / `q` / `B` の**値は P1 前に事前宣言**するものなので、
  ⚠️ **本 issue で値を決めない** —— ★ 設定として外から与える形にし、既定は既存パラメータから引く。
- **D5**: `phase` は自然セッション（O1）では **`unspecified` に collapse** する。
- **D6**: ⚠️ `task_kind` の**未宣言を 5 値目にしない**。★ 鍵を作らず個人の全体基準へ back-off する。

### ⚠️★★★ ADR-030 はまだ **Proposed** である

★ 研究者判断 2026-09-14 で「**`t0` 検出器の issue を 1 本足す**」と決めた（→ `decisions.md`）。
⚠️ ただし **D2〜D6 の文言が Accepted 化の過程で変わる可能性が残る**。

   確定させること。
3. **修飾キー押下中の文字キー除外**（D3 逐語）: `net_production`（issue 001 の共有ヘルパ、
   AC8 で使用必須）は press イベントの `{t, vk}` のみを受け取り、修飾キーの押下区間を

   受けている扱いに倣い、**基本の写像のみ**を実装した（残差は次 issue 以降の検討事項）。
4. **`feat` 列の穴 (ADR-030 D8 (b-2))**: Goal が明示する D2-D6 の範囲外。Scope Out の
