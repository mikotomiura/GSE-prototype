# Issue 002: `T1b`（境界 — 直前/直後の `KeyCategory`・Space/Enter/文末句読点・IME 局面）
verify_level: parse

## Goal

特徴行に `boundary` を足し、**pause の直前/直後に何を押したか**と
**Space / Enter / 文末句読点**、および **IME の局面**（既存 `ime_shadow` の範囲で）を載せる。

## Background

⚠️★★★ **`T1b` は ADR-030 D10 が「投資順序で最有力」と名指しした枠である。**

- D10 逐語「⚠️★★★ **`T1` の内側では `T1b`（境界）を `T1a`（分布）より先に置く。**
  ★ 根拠: [P121] が **4 帯域を事前宣言した検定で「全帯域が成績と負相関」**を示し、
  ⚠️ **弁別は「長さ」ではなく「直前イベント」にある**と結論した」。
- D11 で `T1b` は **計器変更が不要**と実測済み ——
  `KeyCategory` は **14 種**で **`sentence_punctuation` が分離済み**
  （`anonymize.rs:93-110`・回帰テスト `category_count_is_stable` が 14 を固定）／
  `ime_shadow{dwell_ms, nav, abandon}` が在る。

### ⚠️★★★ 2026-09-15 追記: `ime_shadow` は **replay 側がまだ読んでいない**

★ `decisions.md` **判断 12** で実測した事実（⚠️ 推測ではない）:

- `bin/replay.rs:159` の `ReplayEvent::ImeShadow` は **`serde_json::Value` の読み飛ばし専用**
  （doc 逐語「replay では読み飛ばす」）。★ `build_feature_rows(keys, paste_ts, max_ticks)` に
  IME は **1 バイトも入っていない**。
- ⚠️★★★ **既存 fixture には `ime_shadow` 行が 1 本も無い**（★ 全 `.ndjson` を grep して 0 件）。

→ ★★★ 本 issue は **`bin/replay.rs` の `--features` 経路に IME の読み出しを足すところまでを含む**。
★ そのため **`## Allowed Files` に `bin/replay.rs` を足した**（★ 制約は下記）。
★ 非退化検査用の fixture **`tests/fixtures/instrument_rich.ndjson`** は
**裁定セッションが用意済み**である（⚠️ 自分で fixture を作らない・既存 fixture を書き換えない）。

⚠️ これは「計器変更」ではない —— ★ `logger.rs:478` は `ime_shadow` を**実際に書いている**。
欠けているのは**オフライン読み出し側**であり、それは本タスクが作っているものそのものである。

### ⚠️★★★ IME は「今ある行」だけを使う

★ `.idea/survey §6.3` の優先候補（composition 内部の delete / commit latency など **9 項目**）は
**`ADR-032 D5` が「追加の是非を今決めない。`capability matrix` が先」**と裁定している。
→ ⚠️ **本 issue で IME の新しい観測項目を作らない。** ★ 使うのは `ime_shadow` の現行フィールドだけ。

⚠️ かつ **起票 6**（2026-09-12 実測）——「★ **放棄が 1 件偽陽性で立ち、確定 1 回が 2 行に分裂する**」。
★ ライブ変換は **macOS の既定 ON** なので、`ime_shadow` の**行数は「変換回数」の代理にならない**。
→ ★ **`abandon` を「迷い」と読む解釈をコードにもコメントにも書かない**（★ 数えるだけにする）。
