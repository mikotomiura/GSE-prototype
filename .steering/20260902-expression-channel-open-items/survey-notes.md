## C. 抽象表現の個人化 — 未決 #3（★ 完了・9 件）

### ★★★ 中心的な発見: **境界線は「固定 vs 自由」ではなく「意味構造 vs 表層」に引く**

★ Schloss+2019 / Consolvo+2008 / Stasko+2004 の 3 本が独立に同じ線を示した。

| 分類 | 何を | 一次（★ 効果量つき） |
|---|---|---|
| **系が固定** | **写像の極性**（どちら向きが「強い」か） | ⚠️★★★ **凡例が毎試行目の前にあっても、事前予測に反する写像は有意に遅い** —— `F(1,29)=32.50, p<.001, η²p=.528`（Exp1 N=30 / Exp2 N=36）。逐語 *"it is easiest for people to interpret colormaps that are designed such that the dark-is-more and opaque-is-more bias result in **congruent inferred mappings**."* |
| | **形状クラス** | ★ 同じ情報でも形で一瞥コストが **6.3 倍** —— 91% 正答に要する提示時間 bar **245 ms** / donut **159 ms** / **radial 1548 ms**（N=18 × 2 研究）。⚠️ ただし radial の遅さは**親近性（M=2.28）と交絡**しており著者は分離していない |
| | **数値・順位・達成度を出さないこと** | ⚠️★★★ **「オプションにする」は逃げ道にならない** —— 任意提示条件でも享受が低下 `F(1,97)=8.73, p=.004`（N=100）。逐語 *"**merely making measurement available** reduced how much the activities were enjoyed."* ★ かつ **N=104 の 88% が計測を希望し、「楽しくなる」と誤予測**（`t(103)=6.06, p<.001`）→ ★ **ユーザー要望を根拠に数値を開いてはならない** |
| | **未達を罰として描かないこと** | ★ 具体的処方の逐語 *"the garden has **no wilting flowers, weeds, or stormy sky**. Instead, inactivity results in a **sparse (or empty) garden** with a blue sky and green grass."* → ★ **GSE の `stuck` は「悪い状態」ではなく「疎な状態」として描く** |
| | **構造が別の意味を暗示しないこと** | ★ 実地で**放射状の花を「時計」と誤読**した事例（N=7・2 週間）。⚠️ 訂正は *"slightly disappointed"* を生む＝**後から意味を教え直すのはコストがある** |
| **本人が選ぶ（★ N 択）** | モチーフ / 配色テーマ / 表示位置 / 表示の有無 | ★ 3 か月の実地（N=28）で **28 名中 25 名が glanceable display を望み、「必ずしも garden でなくてよい」**。著者逐語 *"such a system should **offer the individual a choice of metaphors**"* |
| **初期に開かない** | **意味の定義そのもの（user-defined mapping）** | ⚠️★★★ **初回に編集させると 25.5% 遅くなる**（410.71 vs 327.23 s・N=27）。★ かつ **27 名中 5 名（18.5%）が編集しない / 仕組みを理解しない**。⚠️ **いったん編集を済ませれば固定既定と同等**（22 名で 300.72 vs 301.76 s）＝ **コストは恒久的でなく初期に集中する** |
| | **連続量の読み取り** | ★ 抽象写像の想起は 8 秒の一瞥で可能だったが、**困難が出たのは連続量を位置で読む箇所だけ**（slider / 高さ）。→ ★ **GSE は 4 値の swap 型に留め、位置・長さの連続写像を避ける** |

### ⚠️★★★ 文献間の対立を隠さない（★ 2 件）

1. **「直感的でなければならない」は実地で否定されている** —— アンビエント表示のヒューリスティクスは
   *"Consistent and intuitive mapping"* を専門家関連度 **4.7/5** で最上位に置くが、
   ⚠️ 2 か月の実展開（N=4）は逐語 *"**Many of the representations chosen by the participants were not intuitive.**"*
   と報告し、著者自身が heuristic と *"potentially conflicts"* と明記している。
   → ★ **「固定＝直感的、自由＝読めない」という単純図式は成り立たない**（⚠️ ただし N=4・自己申告）。
2. ⚠️ **「初期は固定、後から開放」は選択率が下がりうる** —— 非編集の理由の逐語
   *"I have **familiarized myself** with the location of items so did not want to change them."*

### ⚠️ この angle で埋まらなかったこと（★ 5 件）

1. ★ **抽象カテゴリ状態（GSE の 4 値型）に限定した customization の統制実験は発見できず。**
   得られた統制実験はすべて**連続量の chart か GUI メニュー**であり、実験対象と設計対象にギャップが残る。
2. ★ **アンビエント表現の「学習時間」の定量値は 1 つも取れていない**（★ 何分 / 何日で覚えるか・忘却曲線）。
   ⚠️ `contingency knowledge` という語での実証も発見できず。→ **既存の未決 E-1 は文献では埋まらない。**
3. ★ **choose-from-N と自由編集を同一課題で直接比較した実証は発見できず。**
   → ⚠️ **GSE が N 択を採る根拠は「自由編集の初期コスト」の裏返しであって、N 択自体の優位ではない。**
4. ★ **personalization そのものの効果量を報告した実験は発見できず。**
5. ★ **「カスタマイズが valence を持ち込む」の統制実験は発見できず**（★ 証拠は
   **ユーザー自身が happy/sad の魚を選んだ**という逸話 1 件のみ）。
