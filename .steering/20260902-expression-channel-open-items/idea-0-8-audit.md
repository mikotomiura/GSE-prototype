## B. ★★★ 新規に発見した衝突・空白（★ 引き継ぎメモに書かれていないもの）

### B1. ⚠️★★★ `level` の 4 値契約に「**わからない**」が無い

**実測**:

| 出所 | 逐語・実測値 |
|---|---|
| **ADR-017 D2** 契約表 | `level` = `stable` / `friction_rising` / `stuck` / `intervention_active`（★ **4 値のみ**）。他に `seq` / `emitted_at` / `epoch` |
| **ADR-010 D1** | 「走っている head が `scope_fit` を計算し、`WorkStateEstimate` の `evidence_quality` を単調に減衰させ `uncertainty` を上げる」「`evidence_quality` 低下 → `none`/`defer`」 |
| **コード** `src-tauri/src/analysis/heads/mod.rs:20` 逐語 | 「`WorkStateEstimate` (`uncertainty` / `evidence_quality` **必須**) は Decision Engine 境界」 |
| **`.idea` §2.1** | 表現対象に「**状態推定の不確実性や観測品質**」を挙げている |

→ ⚠️★★★ **推論層は `uncertainty` / `evidence_quality` を *必須フィールド* として持っているのに、
表現境界の契約はそれを 1 ビットも運ばない。**

★ **帰結**: MhD が「推定できていない」とき、表現面は **`stable` を表示し続ける**か、
**最後の `level` のまま固まる**しかない。⚠️ **どちらも「静かである」と読める。**

⚠️ これは **ADR-017 D4 制約 4「チャネルが無い間のフレームを捏造しない」と同型の問題**である
（★ あちらは *運搬路* の不在、こちらは *推定* の不在）。
★ かつ **[P183] Reflective Design 原則 4** 逐語
*"avoid making the technology, rather than the user, the final authority on what the user is doing"* に照らすと、
**「わからない」を「安定している」と表示するのは、系が本人より上位の権威として振る舞う**ことになる。

→ ★ **`decisions.md` 判断 3 / 判断 9 で裁く。**

### B2. ⚠️★★★ `.idea` §4.2 が「**音の有無**」を本人の調整項目に置いている（ADR-017 D5 と衝突）

**実測**:
- `.idea` §4.2「調整できるもの: 色、形、動き、密度、**音の有無**、表示場所」
- **ADR-017 D5** 逐語: 「**音声の自動開始を Phase1 の範囲外とする（実装も評価もしない）**」
  ★ 範囲は「常在の層 0 と 介入候補の視覚的な優先化の **2 段まで**」

→ ⚠️ **実装しないと決めたものを設定項目に置くことはできない。**
★ さらに **PS-Q3（層 0（音）を第 1 版から外すか）は ADR-017 の未決**であり、
**`.idea` は未決を「本人が調整できる」と書くことで飛び越えている。**

### B3. ⚠️★★★ `.idea` §4.2 が「**表示場所**」を調整項目に置くと、ADR-017 D6 の 2 層設計が壊れる

**実測**: ADR-017 D6 ——「**層 A（強制曝露・≤4 秒）と 層 B（任意閲覧・数十秒）を別に設計する。
同じ表現を層 A と層 B に流用しない**」。根拠は [P153]（N=134・1 か月の実端末ログ）。

→ ★ **層 A が成立するのはロック画面（アンロック動作に埋め込まれた強制曝露）だけ**である。
⚠️ **「表示場所」を本人が自由に動かせると、層 A が消える構成が作れてしまい、
「同じ表現を流用しない」という制約が検査できなくなる。**
→ ★ **未決 #1（第一媒体）と 未決 #3（個人化の範囲）は独立ではない。** `decisions.md` 判断 1 / 判断 3 で連結して裁く。

### B4. ⚠️★★ スマホ側の「**層 0**」の実体が未定義

**実測**:
- **ADR-017 D4 制約 3**: 「表現側はチャネル不在でも成立する —— 途切れたら **層 0（状態に応答しない基層）へ縮退**する」
- ⚠️ しかし `docs/glossary.md` L105 の **層 0 の定義は音である** —— 逐語
  「**55–110 Hz 帯の持続音 ＋ 整数次倍音のみ**」。★ 層 1（うねり）/ 層 2（粒子）/ 層 3（空間）も**すべて音**。

→ ⚠️ **スマホの視覚表現には「層 0」の実体が無い。**
★ 縮退先が定義されていないので、**ADR-017 D4 制約 3 は現状 *実行不能* である。**
★ ただし **S3-D12 が層 0 の役目を「状態に応答しないこと」と定義し直している**ので（逐語:
「『不動である』ことは役目ではない。**状態と無関係な自律変異は許される**」）、
**視覚側にも同じ性質の基層を定義すれば概念は移植できる。**

### B5. ⚠️★★★ `.idea` §5.2 の上位 2 項目は **GSE が持てない情報**を要求する

**実測**（`.claude/skills/data-privacy/SKILL.md`）:
- L61 逐語: `pub window_title: String,    // 作業内容の推定に使える: 禁止`
- L197: **フォーカス遷移**は「★ **遷移が起きた時刻のみ**」。
  ⚠️ 禁止側に「HWND / PID / アプリ識別子 / ウィンドウタイトル / **ウィンドウ通し番号**（★ 擬似識別子）」

| `.idea` §5.2 の項目 | 判定 |
|---|---|
| 「離席前の**作業状態を保持**する」 | ⚠️ **GSE の機能にできない**。何のアプリの何を保持するかを知る必要があり、content-free 制約に抵触する |
| 「戻ったときに**次の作業位置が分かる**」 | ⚠️ **同上**。★ ただし *OS とアプリが既に提供している*（アプリは開いたまま）。→ ★ **GSE は何もしないことで満たす** |
| 「離席中に未完了感を強める**カウントダウンを表示しない**」 | ✅ **既決**。ADR-018 D2 逐語「**タイマー・カウントダウン・残り時間表示を実装しない**」 |
| 「戻ったことを**「成功」と採点しない**」 | ✅ **既決**。ADR-018 D3「`completed` / `achieved` / `達成` に相当する語を置かない」 |
| 「表現を見たあとに**継続する選択も同等に許容**する」 | ✅ **既決**。ADR-018 D1（招待であって課題ではない） |

→ ★ **§5.2 は「GSE が実装する 5 項目」ではなく、「GSE が *やらない* ことで満たす 3 項目 ＋ 実装できない 2 項目」である。**
⚠️ **この読み替えをしないと、content-free 制約を破る実装要求として次段に渡ってしまう。**

### B6. ★ `.idea` §1 の「借用元」は、前セッションの一次確認で**両方とも崩れている**

**実測**: `survey-verification.md` 重大な誤り #2 / #3 ——
`.idea` §9.2 が「潜在状態 → 個人化表現の先行例」として挙げた **A 群 2 件**
（EmoWear / Significant Otter）は、**一次資料ではどちらも成立しない**
（前者は content 解析依存かつ送り手が手で選ぶ、後者は実測の生理信号であって潜在状態ではない）。

→ ★ **§1 の「共有ページの構造を借りる」という枠組み自体は使えるが、
「先行例がある」という含意は一次で否定されている。**
⚠️ **`docs/research-positioning.md` §4（差分の所在）に、この 2 件を先行例として書き足してはならない。**
★ なお §1 自身が「文献上の根拠として使う場合は、各一次論文を別途確認する」と留保しており、
**メモの書き手は正しく留保していた**（★ 誤りは §9 の追記側で起きた）。

### B7. ⚠️ §3.1 の境界記述が **契約の 3 フィールドを落としている**

`.idea` §3.1 は「PC側から受け取るのは `stable` / `friction_rising` / `stuck` / `intervention_active`
のような抽象イベント**だけ**」と書くが、**ADR-017 D2 の契約は `seq` / `emitted_at` / `epoch` を含む**。
★ これらは**再接続の意味論**（欠落 / 巻き戻り / リプレイ / 再起動の区別）に必須であり、
D2 が `/cross-review` 指摘を受けて**明示的に足したもの**である。
→ ★ **軽微だが、実装時に「level だけ送ればよい」と読まれると再接続の意味論が消える。**
