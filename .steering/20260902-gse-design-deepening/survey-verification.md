# 横断サーヴェイ（§14 の ML 主張 4 件の裏付け）

| 主張 | 判定 | 要点 |
|---|---|---|
| **abstention を正式な推論出力に** | ⚠️ **概念は裏付けあり／GSE の実装形は裏付けなし** | Chow (1970) 以来の正統（Cortes+2016 / Angelopoulos&Bates 2023 / Dvijotham+2023 Nature Med）。⚠️ **3 本とも「ラベル付き正解」「棄権コストの明示」「交換可能性」のいずれかを前提**にする。★ **「観測数が閾値未満だから `insufficient_evidence`」という手書き規則を正当化する文献は発見できず** |
| **calibration / Brier / holdout を併記** | ⚠️ **部分的**（★ 4 件中最弱） | TRIPOD+AI (2024)・Van Calster+ (2019)・Steyerberg+ (2010) は強固。★ Saeb+ (2017) は **subject-wise の楽観バイアスの実証**だが、⚠️ **同じ号に Little+ の反論**が「subject-wise は万能でない・use-case 依存」と明示。⚠️★★★ **「個人内で当たるが別セッションで崩れる」に直接対応する一次文献は発見できず**。★★★ かつ **TRIPOD も Van Calster も「帰結が観測される」ことを前提**にしており、**GSE の認知状態には gold standard が無いので calibration をそもそも計算できない** |
| **競合リスク／離散時間ハザード** | ⚠️ **部分的** | Fine&Gray (1999) / Austin+ (2016) / Loh+ (2025 JMIR AI) / Singer&Willett (1993) / Suresh+ (2022) は個別に強い。⚠️ **離散時間 × 競合リスクを同時に扱う方法論原典は確保できず**。⚠️★ **Loh の実証的優位は年単位の long-horizon に集中し、4 疾患中 2 つで二値分類が同等以上** —— **GSE の時間尺度（分〜時間）は優位が確認されなかった側に近い** |
| **JITAI の因果評価は MRT** | ★ **裏付けあり**（4 件中最強） | Klasnja+ (2015 原典) / Nahum-Shani+ (2018 枠組み) / Qian+ (2022 WCLS) / Boruvka+ (2018 推定量) / Klasnja+ (2019 実証)。⚠️★★★ **実証の効果量が小さく減衰する**: HeartSteps MRT (N=44・6 週) で **30 分歩数 +14% (p = .06)**、初期 +66% が**時間とともに減衰**、**antisedentary suggestion は検出可能な効果なし**。⚠️ **MRT は「提示すべきと判断した時点であえて提示しない」ことを要求** —— GSE の cooldown / daily cap と衝突する |

★ **副産物（重要）**: 検証者から **帰結ラベル `self_recovery` の「recovery」が 2026-09-01 に捨てた語彙圏に接触する**という指摘。
