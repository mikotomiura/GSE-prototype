# 提案書再設計案（v2）

## 方針

提案書の主語を「何を削ったか」から「何を作り、どの判断で動かすか」へ移す。中心の因果連鎖は、行動イベント → 作業状態の推定 → 介入機会の判定 → 抽象的なメディア表現 → 本人が選ぶ身体的回帰、とする。

## 技術構成

- 現行のWriting HMMを再現可能な基準モデルとする。
- 学習候補はMultiROCKET+Hydraで時系列を特徴化し、正則化ロジスティックヘッドで二値リスクを出す構成を第一候補とする。
- 自力前進・外部化・離席など競合する結果は、離散時間の競合リスク尤度で別扱いにする。シグモイドは二値補助ヘッドやハザード出力に使い、相互排他的な結果を無理に独立二値化しない。
- 学習はPythonでオフライン、推論はRustで行う。採用時はsubject/session holdout、較正、Brier、介入安全性、golden replayを通す。

## 表現構成

推定値を画面へ直接表示せず、`stable` / `friction_rising` / `stuck` の抽象イベントへ変換する。PCでは作業を遮らない小さな視覚変化、任意閲覧面では状態の遷移を短時間で読み取れる形を試す。表現チャネルは推論や介入判断を行わず、状態を写すだけにする。

`friction_rising` や `stuck` を罰や警告として扱わず、外部の答えへ直行する前に一拍置くための環境変化として提示する。その後、必要な場合だけ「画面から離れる」という招待を提示し、Physical Anchorは開始・継続・完了を測らない。

## 検証

表現の弁別性、提示の侵襲性、招待の受容、機会保存の行動指標を分けて検証する。Physical Anchor単独の効果や歩行による成績改善は主張しない。
