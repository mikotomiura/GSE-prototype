# 重要な設計判断

## 判断 1: 終端を `([[:space:]]|$)` に留め、`([^a-z0-9]|$)` へは広げない

- **判断日時**: 2026-09-08
- **背景**: ★ `.ndjson` の判定は `([^a-z0-9_]|$)` で書かれており、**それに揃える案**があった。
  ★ 実際そちらの方が「拡張子の切れ目」を素直に表す。
- **選択肢**:
  - **A**: `([^a-z0-9]|$)` に揃える → ⚠️ **`.pptx.md` も止まる**
  - **B**: ★ `([[:space:]]|$)` に留める（★ 引用符の正規化と対で直す）
- **採用**: **B**
- **理由**: ⚠️★★★ **A は現行仕様を勝手に拡大する。**
  ★ `docs/external-skills.md` が送信禁止としているのは **拡張子 `.pdf` / `.docx` / `.xlsx` / `.pptx`** であり、
  `.pptx.md`（Markdown 版）は**含まれていない**。
  → ★ **本タスクは「実装が仕様どおり動いていない」を直すものであって、仕様を変えるものではない。**
  ★ 仕様を変えるなら**それ自体を研究者が決める**べきである（→ 判断 2）。

## 判断 2: `.pptx.md` / `.docx.md` の扱いは **研究者に委ねる**（★ 本タスクでは触らない）

- **判断日時**: 2026-09-08
- **⚠️ 実測で具体化した論点**:
  ★ 修正後に実物の diff を通したところ、
  **`.pptx`（バイナリ）は rc=2 で除去された**が、
  ⚠️★★★ **`[提案プロジェクト補足資料]GSE設計スライド.pptx.md` の追加行 257 行は出力に残った。**
  ★ **中身は pptx の本文そのもの**（`md2pptx.py` の入力）である。
- **⚠️ つまり**: ★ `/cross-review` を**パス限定せずに**回すと、
  **未踏提出物の設計スライド本文が Codex へ渡る。**
- **選択肢**:
  - **A**: `.pptx.md` / `.docx.md` をフィルタの禁止パターンに足す
    → ⚠️ **副作用**: 未踏提出物に触る diff が**毎回 rc=2** になる。
       ★ 既存コメント（`secrets-filter.sh:64-73`）が警告する
       **「人がフィルタを迂回する動機を作る」**型に近づく。
  - **B**: 足さない。★ 運用（**パス限定で `/cross-review` を回す**）で守る
    → ⚠️ **人間の規律に依存する**（★ fail-closed ではない）。
  - **C**: `docs/external-skills.md` 側の定義を先に改訂し、それに実装を合わせる
- **採用**: ★★★ **A（フィルタに `.pptx.md` / `.docx.md` を足す）** —— ★ **2026-09-08・研究者が選択。**
- **理由**（★ 研究者判断 ＋ 実測）:
  ★ **拡張子が `.md` なのは `md2pptx.py` の変換の都合にすぎず、守るべき中身は資料の本文そのものである。**
  ⚠️ 実測が具体的だった —— **`.pptx` バイナリを止めても、Markdown 版から本文 257 行が外へ出ていた。**
  → ★ **fail-closed を優先する。**
- **⚠️ 引き受けた代償**: ★ **未踏提出物に触る diff は毎回 `rc=2` になる。**
  → ★ そのときは **`--ack-filtered`**（★ 人が `[REDACTED]` の中身を確かめてから通す）で運用する。
  ⚠️★★★ **フィルタを弱めて回避しない**（★ `secrets-filter.sh:64-73` の設計哲学）。
- **★ 実装**: `PROPRIETARY_EXTS_REGEX='\.(pdf|docx|xlsx|pptx)(\.md)?([[:space:]]|$)'`
- **★ 実測（修正後）**: 実物の diff が **rc=2 / SKIPPED hunk 2 件 / 残った追加行 0 行**
  （★ 出力は SKIPPED 通知 2 行のみ）。⚠️ 陰性対照（実験 diff 2130 行）は **1 バイトも変わらず rc=0**。
