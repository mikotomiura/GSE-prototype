# 重要な設計判断

判断 1〜6 は 2026-11-06 の grill で研究者が選んだ（新しい計算の値を見る前）。

## 判断 1: 足し方は A（最頻値を τ の候補にする）

- **背景**: 前の試験の τ = ∞ は w を除く共通の母数（基の擬似度数 π = 1・A = 1・B/H/C = 0.5 を含む）で、有限の τ の極限 normalize(S̄) とは違う点だった。
- **選択肢**: A 最頻値を候補に足す（当てはめず normalize(S̄) を本人の母数として評価する）/ B 基の擬似度数を抜いて共通を作り直し ∞ と極限を揃える / C 両方
- **採用**: A
- **理由**: 共通と τ = ∞ がそのまま残るので、P-REPRO と前の試験の表の大半を照らせる。B は共通そのものが変わり、前の試験の「本人 − 共通」とつながらない。
- **影響範囲**: conditions D3 の行。S̄ は `fit_pool_excl` が既に作っている。

## 判断 2: 最頻値は τ 固定の行だけに入れ、選ぶ行の候補は変えない

- **背景**: 選ぶ行に入れると、選ばれる τ の人数と値が前の試験から変わる。
- **選択肢**: 固定の行だけ / 選ぶ行にも入れる
- **採用**: 固定の行だけ
- **理由**: 問い（大きい τ の差を分ける）は固定の行と新しい相手で答えられる。選ぶ行は前と一致させ、P-REPRO の範囲を選ぶ行にも広げられる。−∞ の書き手が選びの中央値に混ざらない。
- **影響範囲**: P-REPRO の範囲（前の試験の summary のすべてのセル・区間を除く）。

## 判断 3: 相手に「本人(τ) − 同じ構造の最頻値」をすべての行に足す

- **採用**: すべての行（τ 固定・τ 他人・τ 本人 CV・2 段・K 本人 CV）・全記号と押下のある記号
- **理由**: 本人の記録の寄与だけを見る量になる。前の試験の 2 段の上積み（約 1e-3）も同じ形で分けられる。当てはめは増えない。
- **却下案**: τ 固定の行だけ（2 段の上積みを分けられない）/ 足さない（中央値は引き算できない）

## 判断 4: 最頻値の評価が −∞ の書き手は、そのまま入れて人数を出す

- **背景**: 最頻値には基の擬似度数が無いので、他の書き手の記録に一度も出ない記号の組や頭の記号は確率 0 になる。w の評価の単位にそれがあると −∞（有限の τ を ∞ に送った極限も −∞）。
- **選択肢**: そのまま入れて人数を出す / 除いて人数を出す / 小さな床を入れる
- **採用**: そのまま入れて人数を出す
- **理由**: 中央値・四分位・良い側の割合は順位の量で ±∞ でも定まり、極限の意味を曲げない。床は極限でも共通でもない第 3 の点になる。
- **影響範囲**: summary の JSON では ±∞ を文字列で書く。各セルに −∞ の人数を並べる。

## 判断 5: 読みの形（結果を見る前に決めた）

a = 本人(τ) − 最頻値、b = 最頻値 − 共通（書き手ごとに 本人 − 共通 = a + b。中央値は足し算にならないので並べて書く）。閾値は置かず、a と b の中央値の絶対値の大小と符号で読む。見る所は ar1〜ar3・hmm3 × 主のパネル × k、τ ∈ {10^5, 3×10^5, 10^6}、2 段（他人）の行。

- 形 1（最頻値の側）: 10^6 で |a| < |b| かつ b の符号が「本人 − 共通」と同じ →「前の試験の大きい τ での差は、主に最頻値と共通の母数の違いから来る」
- 形 2（本人の側）: 10^6 で |a| > |b|、a > 0、良い側の割合が半分を超える →「本人の記録の寄与が主」
- 形 3（混ざる）: どちらでもない → 値を並べ、分けられないと書く
- 形 4（τ に沿う形）: a が 10^5 → 10^6 で 0 へ近づくかを書く（極限の対照）
- 形 5（−∞）: 最頻値が −∞ の人がいるセルは人数を書き、中央値に ±∞ を含むと断る

特に答える: CoAuthor の ar の「10^6 が ∞ を上回る」と CS1 の負の差は、形 1〜3 のどれか。

## 判断 6: 論文 3 には限界の節の書き換えとして効かせ、共通の母数は保存する

- **論文 3**: 主の表（τ 他人・2 段）は前の試験の値のまま（この試験でも変わらない）。a・b の表は補足資料に置き、本文は限界の節の一文を形 1〜3 に合わせて書き換える（形 1・2 なら読める範囲を広げ、形 3 なら但し書きを残す）。
- **共通の母数の保存**: する。全員の共通・w を除く共通・S̄ を repo の外（書き手ごとの値と同じ所・人が開いて読まない）に npz で書き、SHA-256 を provenance に記す。今回は読み戻さない（書き出しだけなので結果は変わらない・P-REPRO で照らす）。次の試験で使うときは、その試験の条件で照らし方を決める。

## 判断 7: 設計は /reimagine の v2 を採る

- **背景**: v1（初回案）と、v1 を読まない Opus のエージェントが作った v2 を比べた（`design-comparison.md`）。
- **採用**: v2（研究者が選んだ）
- **理由**: v1 には本計算で NaN を生む道が 2 つ残っていた。±∞ を含む区間の分位点（linear）と、和 0 の行の normalize（0/0）。どちらも Mac の numpy 2.5.2 で確かめた。v2 は最頻値を `res["mode"]` に分けて前の試験の鍵を保ち、P-SAME で前のコードとの一致を Mac でも見る。

## 判断 8: 和 0 の行は一様（1/26）

- **背景**: AR の C の行 [k, j, :] は、前の記号 j が他の書き手に一度も出ないと S̄ がすべて 0 になる。この行は事前分布が τ で縛らず、有限の τ の極限でも本人の度数＋基の擬似度数のまま（最頻値からは決まらない）。
- **選択肢**: 一様 / 0 にして −∞ / その書き手を定まらないとする
- **採用**: 一様（normalize(基の擬似度数) = 1/26）
- **理由**: 本人の記録を入れない点という最頻値の意味を保ち、事前分布が何も言わない行に仮の −∞ を作らない。和が正の行の 0 のセルは極限でも −∞ なので判断 4 のまま。
- **影響範囲**: `mode_of`。和 0 の行に当たった書き手の人数を出す。

## 判断 9: 押下のある記号の量は、全記号が −∞ なら −∞

- **背景**: 確率 0 の記号の後は、最頻値だけからは状態の濾波が定まらない。
- **選択肢**: 全記号が −∞ なら両方 / 0 の時刻から後に押下があれば −∞（v2）/ 定まらないとする
- **採用**: 全記号が −∞ なら両方
- **理由**: 主の量は全記号、押下の量は副。単純で一貫した約束を条件に書き、人数を並べる。v2 の案も 0 の後の押下の扱いは約束で、極限に合うわけではない。
