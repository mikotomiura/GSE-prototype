# 設計（初回案）

## 実装アプローチ

前の試験のディレクトリ `experiments/20261104-timeseries-tau-extend/` を新しいディレクトリ `experiments/20261106-tau-mode-candidate/` に写し、`ml.py` に最頻値の固定行と相手を足す。前の試験のディレクトリは変えない。SEED は前と同じ 2026110401（P-REPRO のため）。

### 最頻値の作り方
- `fit_pool_excl` が返す S̄（w を除く共通の最後の母数での E 段の期待度数 / 記号の総数）から `mode = hmm2.normalize(kind, S̄)`。π・A・B（hmm3）／π・A・H・C（ar）のすべて。当てはめない。k にも折り目にも依らない（w ごと・構造ごとに 1 つ）。
- 評価は評価の単位だけ（選ぶ行に入れないので折り目の量は要らない・判断 2）。

### −∞ の扱い（判断 4）
- 確率 0 のセルに当たると前向きの正規化が 0 で割られ、以後が NaN になる。`Eval.ll_mode` を足し、マスクの中に c = 0 または非有限が 1 つでもあれば、その書き手の最頻値の量を全記号・押下のある記号ともに −∞ とする（押下のある記号だけの極限は厳密には −∞ に限らないが、0 の後の濾波が定まらないので両方 −∞ とし、条件に書く）。
- 差: 本人 − 最頻値 = +∞、最頻値 − 共通 = −∞。同じ差の列に +∞ と −∞ が混ざらない（NaN にならない）。
- 集計: `q`・`delta_stats`・`boot_median` は ±∞ をそのまま扱う（`inverted_cdf`・中央値の平均は同符号の ∞ と有限だけ）。NaN が入ったら止める（assert）。
- summary の JSON では ±∞ を文字列 "inf" / "-inf" で書く（`allow_nan=False` で書けることを確かめる）。各構造のセルに `mode_neg_inf`（全記号・押下のある記号の人数）を出す。

### ml.py の変更
- `MODE = "mode"`。`TAU_KEYS`（選ぶ行の候補・9 値）は変えない。固定の行は `TAU_KEYS + [MODE]` の 10 行（`tau_mode`）。
- `em_writer`: 構造ごとに `res["mode"][name] = ev.ll_mode(mode_m)`、各 k の `rk["self"][name][MODE]` に同じ値を置く（`em_rows` を一般のまま使うため）。乱数は引かない（前と同じ流れ）。
- `em_rows` の相手に `mode`（`OPPS` の末尾に足す・区間の乱数の順は変わるが区間は照らさない）。
- `em_values`・`joint_values`・選びは `TAU_KEYS` のまま（判断 2）。
- 共通の母数の保存（判断 6）: `GSE_ML_RAW` があるとき `<RAW>.pools.<データ>.npz` に、全員の共通（構造ごと）と w を除く共通・S̄（書き手の通し番号 × 構造）を書く。repo の中を指したら止める（既にある検査）。provenance に SHA-256。
- 書き手ごとの値の出力先は `~/gse-public-data/landscape/tau_mode_candidate_writer_values.<データ>.json`（前の試験のファイルを上書きしない）。

### P-REPRO（`repro_check.py`）
- 範囲を前の試験の `summary.json` のすべてのセルに広げる（判断 2）: すべてのパネル × k × 構造 × 行（τ 固定 9・τ 他人・τ 本人 CV・2 段の 2 行・K 本人 CV の 2 族）× 相手 4 × 全記号・押下 の中央値・四分位・良い側の割合・人数、選ばれた τ・構造の人数と位置、共通 − r1、n_train・n_eval、診断の数。区間（ci）は照らさない（相手が 1 つ増え区間の乱数の順が変わる）。時間（seconds）も照らさない。
- 前の試験の値は repo の `experiments/20261104-timeseries-tau-extend/results/summary.json`（HP Z2・同じ版）。

## 合成の対照（selftest）と変異

前の試験の 17 対照は引き継ぐ（P-TAU・P-INF などはそのまま）。足す対照:

| 対照 | 通る条件 | 名指しの変異 |
|---|---|---|
| P-MODE-LIM | 合成（零のセルが無い大きさ）で、本人の当てはめ τ = 10^7 の母数と最頻値の A・C の最大の差が 1e-3 未満、評価の尤度の差が τ ∈ {10^5, 10^6, 10^7} で増えず 10^7 で 1e-4 未満 | m16: 最頻値に基の擬似度数を足す（normalize(S̄ + 基)） |
| P-MODE-NOSELF | w の学習の単位を入れ替えても最頻値の評価が完全に同じ。最頻値が normalize(S̄) と一致 | m17: 最頻値に w の学習の単位の期待度数を混ぜる |
| P-MODE-NEGINF | 評価の単位に共通に無い記号の組を入れた合成で、最頻値が −∞（両方の量）・本人 − 最頻値 が +∞・summary が `allow_nan=False` で書け、"inf" の文字列と `mode_neg_inf` の人数が合う。NaN が無い | m18: 0 の確率を 1e-300 に床上げする |
| P-OPP-MODE | 相手「最頻値」の書き手ごとの値が、本人と最頻値の評価の尤度の差と 1e-12 で一致（中央値どうしの差ではない） | m19: 中央値どうしの差を配る |
| P-SEL-SAME | 選ぶ行（τ 他人・τ 本人 CV・2 段の 2 行・K 本人 CV）の選びが、最頻値の有無で変わらない | m20: 最頻値を選びの候補に入れる（∞ の次） |
| P-SAVE | 保存した npz から読んだ母数が、書き手の計算に渡した母数と完全に同じ。保存の有無で summary が同じ | m21: 保存の前に S̄ を正規化する |
