Subject: Question about sharing derived per-pause values from the CS1 keystroke data

Dear Dr. Edwards,

Thank you again for allowing me to use the 2019 and 2021 keystroke files of your CS1 dataset (doi:10.7910/DVN/6BPCXN and
doi:10.7910/DVN/BVOF7S). I am preparing a manuscript for the Journal of Educational Data Mining that cites Edwards, Hart
and Shrestha (2023), as you asked.

When I requested the files, I said I would not redistribute them and would publish only aggregate values. Before
submitting, I would like to ask whether you would allow one further, limited release, so that readers can check the
main test without the raw files:

- for each pause analysed (about 4,500 stalls and their matched control pauses), the values of two derived signals at
  the start of the pause and 30 seconds earlier, the pair identifiers used in the statistic, and the anonymised
  SubjectID and AssignmentID of the dataset;
- the list of the 146 writers I set aside as the holdout, as anonymised SubjectIDs of the dataset, so that readers can
  see which writers the confirmatory test used;
- no keystrokes, no inserted or deleted text, no timestamps, and no assignment content.

If you prefer that I keep to aggregate values only, I will do so, and readers who obtain the files from you will be able
to rebuild these values with the released code.

With best regards,
Mikoto Miura
Independent Researcher (ORCID 0009-0000-4196-0508)
