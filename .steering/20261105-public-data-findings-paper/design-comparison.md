# 主張と新規性の比べ（/reimagine・2026-11-05）

対象は design.md ではなく `paper-write/outline-v1.md`（初回案・メイン）と `paper-write/outline-v2.md`（初回案を見ていない Opus のサブエージェントが作った）。

## v1 の要旨
反証の論文。C1 揃えた対照では上がりが見えない／C2 揃えない比べの AUC の多くは局面で説明される（未計算）／C3 同等性の検定と事前登録で「当たらない」を言える形にする。停滞の形と契機の制約は付随の 1 段落。

## v2 の要旨
評価の設計の方法の論文で、反証はその実演。C1 反証（同等性は C1 の強さの条件に入れる）／C2 手前の変化と局面を分ける比べ方（既にある水準と上がりの開きを根拠に足す）／C3 道具の要求は代理になりにくい（既知の確認）／C4 契機の制約を独立の短い節に。計算 1 の 2 つの分岐を事前登録に書く。

## 主な違い

| 観点 | v1 | v2 |
|---|---|---|
| 枠組み | 反証が芯 | 方法が芯・反証は実演 |
| 持ち帰り 1 文 | 上がりは消える → 揃えて評価すべき | それに加えて「水準ではデータで逆向きに離れる（0.42・0.58〜0.60）」 |
| 同等性の検定 | 独立の貢献 C3 | C1 の強さの条件（独立の貢献にしない） |
| 道具の要求の代理 | 主張しないことの側 | 既知の確認の貢献 C3 |
| 契機の制約 | 付随の 1 段落 | 独立の節（450 語） |
| 計算 1 の結果への備え | 「上がらなければ書き換える」 | 2 つの分岐とそれぞれの教訓を事前登録に書く |
| 危うさ | C2 が未計算のまま貢献に立つ | 水準の 0.42 と 0.58 は出来事・対照の作りが違う比べの値で、並べると同じ設計の結果に見える。4 つの貢献は paper-write の上限いっぱい |

## 推奨
ハイブリッド。v2 の枠組み（方法の論文・2 分岐の事前登録）と、同等性を C1 に入れる扱い、契機の制約の節を採る。v2 の持ち帰り 1 文の「水準では逆向き」は、CoAuthor の 0.42（1 回目・休止だけで揃えた要求）と KLiCKe の 0.58〜0.60（区切りで揃えた停滞）が違う設計の値なので、計算 1 で同じ設計で出すまで持ち帰り 1 文から外し、C2 の根拠の「手がかり」にとどめる。道具の要求の代理（v2 の C3）は探索の記述なので貢献にせず、考察の 1 段落に下げる。貢献は 3 個（反証・方法・契機の制約）。
