# 招待の契機と配線（ADR-040 D4・Migration 2・タスク B）

## 背景

- ADR-040 D1 でNudge を本体の既定で出さなくした（タスク A・`.steering/20261031-nudge-default-off/`）。このままだと通常のモードで本体の介入が何も出ない。
- ADR-040 D4: 招待の契機は `friction_rising`（値は事前登録の前に決める・判断 13）。統制の 1 段目は {推定器 / 無作為 / なし}（判断 14）。
- 2026-11-01 の決定（`.steering/20261101-gse-pre-stall-signal/decisions.md` 判断 4）: 契機は上がりに限らず差し替えられる形にする。中身は T2・T3 の後の合流で決める（`.steering/_handoff/next-session-gse-three-parallel-tracks.md` §4）。

## ゴール

1. 契機を差し替えられる形にする（推定器・friction_rising・頻度を合わせた無作為・なし）。既定は今の挙動（`p_stuck ≥ 0.60` が 30 秒）。
2. 通常のモードの第 2 週で招待を出す。第 1 週・O1・G1 では出さない。EH3 は今のまま。
3. 条件（契機の種類と値・推定器の版）を session_meta と別の行に記録する。
4. 新しい契機を `gse-replay` で記録から再現できるようにする。

## 研究者の決定（AskUserQuestion）

- 2026-10-31: 通常のモードでは出す・O1 では出さない・EH3 は今のまま。出し方は `Settings::default`（出す・終日・1 日 2 回）で本人が変えられる。第 1 週の盲検較正では出さない。契機の既定は今の挙動のまま。
- 2026-11-01: 第 2 週だけ出す（画面の表示名を「第2週 (招待)」に改める）。契機は研究者の設定ファイル（`~/.gse/`）で選ぶ。無作為の頻度は値を注入する（既定値を置かない・指定が無ければ無作為の条件は選べない）。

## 受け入れ条件

- 既存の招待のテスト（`analysis/invitation.rs`・`eh3.rs`）が書き換えなしで緑。EH3 の挙動が変わらない。
- 契機の種類ごとの単体テスト（立つ・立たない・離席候補で立たない・無作為の seed で再現する）。
- 設定ファイル: 無い → 推定器の既定。未知の欄・欠けた値（無作為の頻度・上がりの値）→ 招待を出さない（読めなければ出さない・fail-closed）。
- 第 1 週・O1 では招待の状態機械が出さない（テスト）。
- `gse-replay` のスナップショット回帰が byte-equal（HMM は触らない・`HMM_VERSION` を上げない）。
- 新しい行は `emit_schema` と `schema/current.json` と `capabilities.rs` の宣言に揃う。
- `cargo test --workspace`・clippy・`tsc` が緑。
