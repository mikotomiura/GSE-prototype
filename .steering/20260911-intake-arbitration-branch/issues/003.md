## Background

- ⚠️★★★ **ブランチを `git checkout` / `git switch` で切り替えない。**
- `docs/references.md` は **append-only** の中央書誌 SSOT。既存番号の振り直しは禁止。
  main 側の現在の最大番号は **`[P275]` / `[V124]`** であり、ブランチ側が
  `[P276]`〜`[P356]` / `[V125]`〜`[V145]` を追加する形なので、**番号は連続して衝突しない**。
  ⚠️ ただし main 側がこの間に新しい文献を追加していないかを**取り込み前に必ず確認**する。
- ⚠️★★★ **`check_citations.py` は違反を 1 回で全件出さない。**
  「違反なし」になるまで **是正 → 再実行を繰り返す**こと。1 回緑になっただけで完了としない。
- append-only ルール: 撤回時は行を残し **tombstone** にする（番号は再利用しない）。
  同一文献の二重登録は key 列（DOI / arXiv ID / 正規化 URL）で検出する。
  両書誌に既出の文献は「重複」列で相互リンクし、片方を tombstone 化しない。
