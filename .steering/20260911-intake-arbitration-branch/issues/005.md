# Issue 005: 提出文書の図版・スライドの取り込み（docs/mitou_submission/）
verify_level: parse

## Goal

未マージブランチ `feat/resumption-outcome-arbitration` から `docs/mitou_submission/` 配下の
図版（png / svg）・pptx・その MD 版を main へ取り込む。

## Background

- ⚠️★★★ **ブランチを `git checkout` / `git switch` で切り替えない。**
- この系統は**バイナリを含む**（png / svg / pptx）。差分レビューが効かないので、
  取り込み後に**実際に開いて目視確認**する必要がある。
- ⚠★★★ **`scripts/check_doc_lexicon.py` の検査対象そのもの。** スクリプト冒頭が
  検査対象として次を列挙している:
  ```
  docs/mitou_submission/mitou_docs/[提案プロジェクト詳細資料]GSE_proposal.docx.md
  docs/mitou_submission/mitou_docs/[提案プロジェクト補足資料]GSE技術設計書.docx.md
  docs/mitou_submission/mitou_docs/[提案プロジェクト補足資料]GSE検証レポート.docx.md
  docs/mitou_submission/mitou_docs/[提案プロジェクト補足資料]GSE参考文献.docx.md
  docs/mitou_submission/mitou_pptx/[提案プロジェクト補足資料]GSE設計スライド.pptx.md
  ```
  ⚠️ スクリプトのコメントが警告している通り、**分割で増えたファイルを対象に入れないと
  禁止用語が素通りする**。取り込みでファイルが増えた場合は `MITOU` リストへの追加要否を確認する。
- 禁止用語の代表例（`docs/glossary.md` より）: 段階呼称 `Lv1〜Lv4`（ADR-018 D7 が廃止）、
  `M1〜M4`（ADR-021 D11 が撤回）、`不便益 HCI である`、`歩数達成 / 距離達成 / 完了 / クリア`、
  `集中度 / 集中状態`、`winapi`。

### Out

docs/mitou_submission/**

## Acceptance Criteria

| # | AC | 対応 test / コマンド |
|---|---|---|
| 1 | 禁止用語違反なし | `PYTHONUTF8=1 python scripts/check_doc_lexicon.py` が exit 0 |
| 2 | 新規ファイルが検査対象に入っている | 取り込みで `mitou_docs/` または `mitou_pptx/` に MD が増えた場合、`scripts/check_doc_lexicon.py` の `MITOU` リストに追加されている |
| 3 | 図版が壊れていない | 取り込んだ png / svg をすべて開いて表示できる（目視。`svg` は XML として parse できる） |
| 4 | MD と pptx の対応が取れている | `mitou_pptx/*.pptx` と `mitou_pptx/*.pptx.md` が対で存在する |
