# 設計（初回案 v1）

## 実装アプローチ

1 人の合成の記録を日の順に作り、前の日の n 件で罰つきロジスティックを学び、後の日の大きな集合で評価する。罰の強さ λ は格子の各値で当てはめ（固定）、学習の側の中の前向きの CV で選び（CV）、その 2 つから組み合わせを作る。同じ反復のデータを決め方の間で共有し、差を対にして数える。

### 1 生成器（1 人・1 反復）

- 日 d = 1, 2, … ごとに件数 m_d を {1, 2, 3} から一様に引く。日の揺れ u_d ~ N(0, σ_d²)。
- 特徴 x ∈ R^5 は件ごとに N(0, Σ)（Σ は対角 1・非対角 0.3。表の特徴どうしの相関の仮置き）。
- 陽性の確率 p = σ(a + x·β + u_d)。信号あり β = (0.8, −0.5, 0.3, 0, 0)（標準化の尺度・真の AUC が 0.7 前後になる大きさ。値は条件で凍結）。信号なし β = 0。
- 切片 a は、生成器から大きく引いた集合（2×10^5 件・σ_d を含む）の陽性の率が目標（0.10・0.25・0.40）になるように 2 分法で決め、セルごとに 1 回だけ求めて凍結する。
- 学習の側は、日の順に並べた件の先頭 n 件（最後の日は途中で切る）。評価の側は、学習の側の最後の日の次の日から始まる新しい日（新しい u_d）の 5000 件。

### 2 当てはめ

- 特徴は学習の側（CV では各折の学習の側）の平均と SD で標準化する（SD が 0 なら 1）。
- 目的は対数尤度 − λ/2‖β‖²（切片は罰しない）。`logit.py` の `fit_logistic`（Newton 法・許容 1e-8・最大 100 回・擬似観測 y=1 と y=0 を重み 0.5 ずつ）を写して使う。擬似観測は 1 類だけの学習でも切片を有限にするため（改善の試験と同じ）。
- λ の格子: 0.1・0.3・1・3・10・30・100・∞。∞ は切片だけ（B0-self・本人の基準率）。

### 3 決め方

- (i) 固定: 格子の各値。
- (ii) CV: 学習の側の日を、日の順に K + 1 = 5 個の連続するブロックに分ける（日数を 5 でほぼ等分）。k = 1…4 で、ブロック 1…k で学びブロック k+1 で検証し、検証の対数損失の和が最小の λ を選ぶ。同点は大きい λ。日が 5 日未満ならブロックの数を日数まで減らし、2 日未満なら CV が立たないとして ∞ に落とす（数を記録する）。
- (iii) 組み合わせ: 学習の側の量が下限未満なら固定の λ_f、以上なら CV。下限は 2 通りで数える: 総件数 n、および少ない方の類の件数 min(陽性, 陰性)（S1-E4 の下限が件数で決まるので）。(iii) は (i) と (ii) の結果から作り、追加の当てはめは無い。下限と λ_f の組は格子のすべてを出し、案の文はそこから選ぶ。

### 4 評価の量（評価の側の 5000 件）

- 対数損失（主）・Brier・C（AUC）・較正の傾きと切片（評価の側で y を logit(p̂) に回帰した傾きと切片・S1-E3 の主）。
- 比べ: B0-self（λ = ∞）との差・後知恵の最良の λ（その反復の評価の対数損失が最小の格子の値）との差（後悔）・真の p（神託）との差。
- 選ばれる λ の分布（格子の値ごとの割合）。
- 診断: 1 類だけの学習の反復の数・収束しなかった当てはめの数・CV が立たなかった反復の数。

### 5 対照と変異（conditions で門の値を凍結）

- 陽性の対照: 信号あり・n = 120・陽性の率 0.25・σ_d = 0 で、CV の評価の対数損失の平均が B0-self より小さく（差の 95% 区間が 0 をまたがない）、選ばれる λ の中央値が有限、C の平均が 0.6 を超える。
- 陰性の対照: 信号なし・n = 120 で、C の平均が 0.5 ± 0.01、CV の評価の対数損失の平均が B0-self 以上（罰が弱いと悪くなる側）、選ばれる λ のうち 30 以上が半分を超える。
- 当てはめの検査: λ = 10^10 の当てはめが切片だけと一致・最適での勾配が 0 に近い・標準化が学習の側だけの値と一致・CV の各折で検証の日が学習の日より後。
- 変異: m1 標準化を学習と評価を合わせて行う／m2 CV の日のブロックを並べ替える（時間順でない）／m3 切片も罰する／m4 CV を C で選ぶ／m5 同点を小さい λ で切る／m6 評価を学習の側で行う。各変異が少なくとも 1 つの検査で失敗することを確かめる。
