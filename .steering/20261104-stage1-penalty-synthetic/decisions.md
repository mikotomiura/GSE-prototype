# 重要な設計判断

## 判断 1: 罰の寄せる先を 0 にする（ridge）

- **判断日時**: 2026-11-04（grill・研究者）
- **背景**: 改善の試験の λ = ∞ は他の書き手の共通の係数へ寄せる形で、ADR-046 D3（段 1 では人をまたがない）のもとでは段 1 に持ち込めない。
- **選択肢**:
  - A: 0（切片は罰しない・特徴は本人の学習の側で標準化）
  - B: 固定 baseline（HMM 0.5.0）から作る係数（logit(p_stuck) を offset に置くなど）
  - C: 公開データ（CoAuthor・CS1）で学んだ係数
- **採用**: A
- **理由**: λ → ∞ の極限が本人の基準率だけのモデル（B0-self）になり、比べの床が格子の端に入る。人をまたがず、移しの前提も要らない。B は寄せる先を作る規則を新しく決める必要があり（S1-E8 は p_stuck の代わりに ewma_x を入れる）、C は ADR-046 D3 と近く、領域の移しの前提が要る。
- **トレードオフ**: 公開データや固定 baseline の知識を事前として使わない。
- **影響範囲**: 生成器・当てはめ・S1-E8 に渡す案の文。
- **見直しタイミング**: 段 2 で人をまたぐ段に入るとき（ADR-046 D3 の個人適応の行）。

## 判断 2: 決め方は 3 つとも比べる

- **判断日時**: 2026-11-04（grill・研究者）
- **背景**: 本人の CV はラベルが少ないと雑音で決まる（改善の試験・判断 10）。
- **選択肢**: A: 固定・時間順の CV・組み合わせ（下限未満は固定）の 3 つ／B: 固定だけ／C: 固定と CV の 2 つ
- **採用**: A。CV の選びの量は対数損失。
- **理由**: 組み合わせの下限と固定の値を合成から出すのがこのタスクの主な産物。段 1 の判定の主は較正（S1-E3）なので、選びの量は C より対数損失が近い。
- **トレードオフ**: 比べる組が増え、notes の表が大きくなる。
- **影響範囲**: conditions・集計・案の文。
- **見直しタイミング**: 合成の結果で CV がどのラベル数でも固定に勝たないとき（組み合わせの意味がなくなる）。

## 判断 3: 格子と評価の集合

- **判断日時**: 2026-11-04（grill・研究者）
- **採用**: 学習の側のラベルの数 10・20・30・50・80・120（1 日 1〜3 件を乱数で引き日の順に並べる）× 陽性の率 0.10・0.25・0.40 × σ_d 0・0.5 × 信号あり／なし（β = 0）の 72 セル・各 400 回。評価は学習の後の日に同じ生成器から大きく引いた集合（約 5000 件）。
- **却下案**: 陽性の率を 0.05 まで広げる／評価を段 1 と同じ規模の時間順の holdout にする。
- **理由**: 陽性の類は探索の後に選ぶので幅で置く。評価を大きな別の集合にして holdout の大きさの揺れを手法の性質から切り離す（S1-E2 の割合は未定なのでここでは決めない）。
- **影響範囲**: conditions・計算の量。

## 判断 5: G6（整合性の陽性対照）の門を計算の前に直した

- **判断日時**: 2026-11-04（計算の前・Claude）
- **背景**: 初めの門「選んだ τ が後知恵の最良と同じか隣が 80% 以上」が selftest（100 反復）で 0.51 になった。後悔の平均は 0.0003 で門の 0.002 を大きく下回る。2000 件では τ ≥ 0.25 の対数損失の平均の差が 1e-4 以下で平らで、後知恵の最良がその中で雑音で決まる（τ = 0.125 は 0.002、切片だけは 0.059 悪い。CV は τ ≤ 0.125 を 1 度も選ばなかった）。
- **採用**: 門を「後悔の平均 < 0.002・選んだ τ ≥ 0.25 が 95% 以上」にし、「同じか隣」は記述に残す。途中で τ ≥ 0.5 の版を書き、0.76 で落ちたので τ ≥ 0.25 に下げた（τ = 0.25 の罰は 2000 件では弱い）。
- **トレードオフ**: 門を見て置き直したので、G6 は事前の門ではなく「CV が強すぎる罰を選ばない」の確認として読む。主の結果の規則（C4）は触っていない。
- **影響範囲**: conditions C5 の G6・selftest.py の g6。

## 判断 8: 完了時のレビュー（/cross-review 1 巡目）の指摘を直し、計算をやり直す

- **判断日時**: 2026-11-04（本計算の後）
