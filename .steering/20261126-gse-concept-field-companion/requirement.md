# gse-concept-field-companion

## 背景

研究者は、GSE の全体の設計とコンセプトにまだ納得できる形が無いと感じている（2026-11-26）。

- 全体の設計が従来の GUI の形で硬く、望む形や結果にならない気がする。
- 人の感覚・直感・生活の中で培った知識を、入力の形・介入・メディア表現が活かせていない。
- 研究の命題は特異なまま、裏の設計は厳密で具体的な工学として複雑に、表はユーザーや一般の人が感覚で分かり、理解できてワクワクするものにしたい。

同日の議論で、違和感の場所は入力の形・メディア表現・介入と関わり方で、推論の形は挙がらなかった。活かしたい感覚は道具・物の感覚と時間の感覚。在り方は場と相棒（相棒はインタフェースそのもので、一つの場・概念のような存在）。経緯は `decisions.md`。

## ゴール

1. 議論で決まったことを `decisions.md` に記録する。
2. 今ある部品（ADR・モード・コード・文書・未決）を、初案を渡さないサブエージェントに棚卸しさせ、一次資料で裏取りする。
3. 部品ごとに「残す／凍結する／削る」の候補を付け、研究者が 1 件ずつ決める。
4. 残ったものを、場＝相棒・二つの時計・経年変化の形で一枚にまとめ直す（/reimagine を当てる）。

## スコープ

### 含むもの
- 議論の記録・部品の棚卸し・削る候補の一覧と研究者の判断・まとめ直しの案

### 含まないもの
- コードの変更
- 段 1 の配布と事前登録への変更（段 1 の n=3 は今の形で進める）
- 既存 ADR の本文の書き換え
- 実際の削除（別のタスクで行う）

## 受け入れ条件

- [ ] `decisions.md` に今日の判断が記録されている
- [ ] 棚卸しの一覧が `inventory.md` にあり、主な事実に一次資料の場所（ファイル:行）が付いている
- [ ] 部品ごとに研究者の判断（残す／凍結／削る）が記録されている
- [ ] まとめ直しの案が初案と /reimagine の案の比べを経て、研究者が採用を決めている
