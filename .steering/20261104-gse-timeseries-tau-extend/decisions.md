## 判断 1: 確かめる範囲は 3 段のうち (1)(2) を行で組む

- **背景**: 引き継ぎ §1(d) の 3 段「(1) 共通のデータで構造を選ぶ → (2) 共通へ強く寄せた小さな上積み・記録が多い人だけ本人へ → (3) ラベルが少ない間は罰を固定」のどこまでを今回の計算で確かめるか。
- **選択肢**: A (1)(2) を行で組む / B (a)(b) だけ（格子を広げるだけ） / C (1)〜(3) すべて（ロジスティックの罰の固定も持ち込む）
- **採用**: A
- **理由**: 2 段の行（構造と τ を他人で選ぶ・τ = ∞ を候補に入れる）は、新しい当てはめを τ の分しか要さない。(3) はロジスティックの話で、引き継ぎ 1 の結果に任せる。
- **トレードオフ**: ロジスティックは今回回さない（前回の D4 は計算しない）。
- **影響範囲**: conditions D3 の行・相手、V2 の対照の範囲（ロジスティックの対照と変異を外す）。

## 判断 2: τ の格子は {0, 100, 10^3, 10^4, 3×10^4, 10^5, 3×10^5, 10^6, ∞}

- **背景**: CS1 の k = 5 では学習の記号が約 8 万で、τ = 10^4 は本人の約 0.13 倍にすぎない。張り付きが解けるかを見るには、本人の記号を十分に超える所まで要る。
- **選択肢**: A 10^6 まで＋∞ / B 3×10^5 まで＋∞（引き継ぎの例） / C 本人の記号の数に対する比（τ = c · n_w）
- **採用**: A
- **理由**: CS1 の k = 5 でも本人の約 12 倍まで届く。前回の 4 値を含むので照らし合わせられる。
- **トレードオフ**: 比（C）にすればデータや k をまたいで同じ尺度で読めるが、前回の定義から変わる。今回は τ を絶対の擬似度数のまま置き、読みの材料として学習の記号の数の中央値を k ごとに出す。
- **影響範囲**: D3 の τ、P-PRIOR 以外の対照の範囲。
- **見直しタイミング**: 10^6 でも張り付くなら、比の定義や更に上の格子を別の試験で見る。

## 判断 3: 構造は ar1・ar2・ar3・hmm3

- **背景**: hmm は r1 に大きく負けたので外す案（引き継ぎ）があった。ただし B の仮説（本人の勝ちは構造の足りなさの補い）を確かめるには、弱い構造を並べる必要がある。
- **選択肢**: A ar1〜ar3＋hmm3 / B ar1〜ar3 だけ / C 前回と同じ 6 構造
- **採用**: A
- **理由**: hmm3 を弱い構造の対として残し、同じ計算の中で、本人の上積みが k とともにどう変わるかを並べる。hmm6・hmm10 は時間がかかり、この問いには要らない。
- **トレードオフ**: ふつうの HMM の族で K を選ぶ行は無くなる（hmm の族は hmm3 だけ）。
- **影響範囲**: D3 の構造・K 本人 CV の族、乱数の流れ（conditions D3 の注）。

## 判断 4: 「共通 − r1」の書き手ごとの行と、2 段の行を足す

- **選択肢**: A 足す / B 足さない（2 段の行だけ）
- **採用**: A
- **理由**: 書き手ごとの評価の尤度は既に出ており、新しい当てはめを要さない。2 段の行は (構造, τ) の組を、w を除く書き手の「本人 − r1」の中央値でまとめて選ぶ。
- **影響範囲**: D3 の相手と行、V2 の P-JOINT・P-INF。

## 判断 6: P-TAU の単調さは事前分布の最頻値との距離で見る（条件の後の変更・実データを見る前）

- **背景**: 合成の selftest（Mac・2026-11-04）で P-TAU が赤。本人の母数と w を除く共通の母数の A・C の最大の絶対差（書き手の中央値）は τ = 10^3 → 10^6 で 0.132・0.045・0.017・0.0068・0.0057・0.0060 と、最後に少し上がった。τ → ∞ の本人の当てはめの行き先は事前分布の最頻値 normalize(S̄) で、共通の母数そのものではない（共通は基の擬似度数 0.5 を含む）。両者の差（床）は 0.0064。最頻値との距離は 0.137・0.049・0.021・0.0068・0.0023・0.0007 と単調に下がった。m15（τ を 10^4 で頭打ち）では、どちらの距離も τ ≥ 10^4 で 0.045〜0.049 に止まる。
- **選択肢**: A 両方を課す / B 最頻値だけに替える / C 共通のまま単調さを外す
- **採用**: A（研究者が選んだ）
- **理由**: 単調さは正しい行き先で見て、「共通に届く」という元の意図も残す。
- **新しい定義**: P-TAU は、最頻値との距離が τ ∈ {10^3, …, 10^6} で増えない、かつ 10^6 で 0.02 未満、かつ共通との距離が 10^6 で 0.02 未満。合成は通り、m15 は赤（Mac で確かめた）。
- **影響範囲**: conditions V2 の P-TAU（末尾の「条件の後の変更」に足した）。実データの計算・行・集計は変わらない。
