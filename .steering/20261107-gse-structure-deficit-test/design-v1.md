grill の判断 1〜7（`decisions.md`）を前提にする。前の試験 `experiments/20261106-tau-mode-candidate/`（以下「前の試験」）のコードを写して変える。書いていない所は前の試験（とその元の `20261104-timeseries-tau-extend/conditions.md`）のとおり。

## 1. 入力と量子化の列（新）

- 入力は前の試験と同じ中間（職場の PC の `C:/Users/SDS02/gse-public-data`・manifest の SHA-256 で照らす）。feat 行 `[t, p_flow, p_inc, p_stuck, ewma_x, ewma_y, obs, alpha]`。
- 列 q ∈ {3, 5, 7}（記号の数 q² + 1）: 行ごとに obs = 25 なら q²（backspace 連打の記号）、そうでなければ `xb = min(max(floor(ewma_x · q), 0), q − 1)`、`yb` も同じ、記号 = xb · q + yb。engine.rs の `(x * 5.0).floor().min(4.0) as usize`（負は 0 に飽和）と同じ式。
- 門 P-Q（職場の PC・実データ）: q = 5 で作り直した記号が、全データの全 feat 行で obs と完全に一致する（obs = 25 の行は 25 のまま）。1 行でも外れれば止める（境界の丸めを含め、直さずに研究者に聞く）。出すのは行の数と外れた行の数だけ。中間は `gse-replay` の snapshot（serde の f64）から作られており、NDJSON の小数 4 桁の丸めは通っていない見込み（`build_cs1_obs.py:75`）。
- 系列の切り方・評価の単位・押下のある記号の印（pflag）は前の試験と同じ（列に依らない）。

## 2. 並べ替えた列（新・対照）

- 各系列（EM の 1 系列 = 1 まとまりの feat 行）の中で、行の順を一様に並べ替える。記号と pflag は行といっしょに動かす。学習と評価の両方に当てる。
- 並べ替えは行の番号に当て、その後で列 q の記号を作る。同じ系列の並べ替えは 3 列で同じ。
- 乱数は `default_rng([SEED + 41, データの番号, 書き手の番号, 単位の番号, 系列の番号])`（EM の乱数とは別の流れ。EM の乱数の流れは、そのままの列と同じ位置から始まる）。
- 並べ替えで保たれるもの: 系列ごとの記号の頻度・系列の長さ・評価の単位。消えるもの: 系列の中の記号の順（前の記号への依存）。

## 3. 構造・τ・行

- 構造: hmm3・hmm6・hmm10・ar1・ar2・ar3（前の試験の PREV_STRUCTS の 6 つすべてを当てはめる）。放出の表の幅は列の記号の数（10・26・50）。
- τ: 前の試験と同じ 9 値（0 … 10^6・∞）。最頻値の行と相手（mode）は作らない。
- 行: τ 固定の 9 行と τ 他人（主）。τ 本人 CV・2 段・K 本人 CV は作らない（折り目を作らない）。
- k: CoAuthor P15 は {1, 5, 15}、P30 は {30}、CS1 C5 は {1, 5}。副のパネルは作らない。
- 乱数の流れ: 作らない k・折り目の乱数は、前の試験と同じ位置で引いて捨てる（`discard_draws` の形）。これで 26 記号・そのままの列の本人の当てはめが前の試験と一致する（P-REPRO）。

## 4. 量（書き手ごと・中央値）

- 相手: r1・同じ構造の共通（pool_same）。
- G(s) = 本人(s, τ 他人) − 共通(s)。
- D(s) = 共通(s*) − 共通(s)。s* は、w と同じパネル・同じ k の他の書き手 v の「共通_v(s) − r1_v」の中央値がいちばん大きい構造（w の値を選びに入れない・同点は自由な母数の少ない構造）。s* の人数を出す。
- 共通 − r1（足りなさの絶対の目安）も書き手ごとに出す。
- 全記号（主）と窓に押下のある記号（副）。

## 5. 読みの形（判断 5 を詰める）

各（データ・パネル・k・列・順）のセルで、6 構造を D の中央値の大きい順に並べる。

- 形 A（仮説と合う）: CoAuthor の主のセル（P15 の k = 5・15、P30 の k = 30）のすべてで、
  (A1) そのままの列の 3 列とも、D の中央値がいちばん大きい構造が G の中央値もいちばん大きく、hmm の 3 構造の G の中央値の順が D の中央値の順と同じ。
  (A2) 並べ替えた列で、hmm3 の G の中央値が、そのままの列の hmm3 の G の中央値の 1/10 以下になる（1 桁以上縮む）。
- 形 B（対抗の説明と合う）: (A2) の代わりに、並べ替えた列の hmm3 の G の中央値が、そのままの列の 1/10 より大きい（同じ桁で残る）。
- 形 C: A でも B でもない（A1 が崩れ A2 が成り立つ、など）→ 値を並べ、分けられないと書く。
- CS1 は前の試験で hmm3 の G がもともと小さい（0〜+0.028）ので、同じ形を当てるが、形の判定は「力が弱い」と断って別に書く。
- Kendall の順位の相関（6 構造の D と G）は値として出すが、閾値は置かない。
- 「1/10」は読みの言い方を決めるための区切りで、検定ではない。

## 7. 門（V1）・陽性対照（V2）

- P-D1・manifest: 前の試験と同じ。
- P-Q: 上の 1。合成でも、境界の値（0.2・0.4 …）と負の値・1 以上の値で engine の式と一致することを照らす。
- P-REPRO: 26 記号・そのままの列の hmm3・ar1〜ar3 の、作る k・τ 固定の行・τ 他人の行を前の試験の summary（tau-extend）と照らす（相対 1e-9）。hmm6・hmm10 は τ ∈ {0, 100, 1000, 10000} を coauthor-ml-improve と照らせるかを先に確かめる（SEED と乱数の位置が同じなら）。
- 陽性対照（足す）:
  - P-SHUF: 合成で、並べ替えた列の系列ごとの記号の頻度が元と一致し、順が変わり、3 列で同じ並べ替えが使われる。名指しの変異: 系列をまたいで並べ替える／列ごとに別の並べ替え。
  - P-DEFICIT: 前の記号への依存の強い合成（AR(1) で作る）で、そのままの列の D(hmm3) > 0 が大きく、並べ替えた列で D(hmm3) が 0 近くに縮む。変異: 並べ替えを学習だけに当てる。
  - P-COMP（仮説の陽性対照）: 書き手ごとに AR(1) の遷移が少し違い、共通の構造が hmm3 の合成で、そのままの列の G(hmm3) が並べ替えた列の G(hmm3) より 1 桁以上大きい。変異はなし（形の判定の陽性対照）。
  - P-NULL（対抗の説明の陽性対照）: 書き手ごとに記号の頻度だけが違い、順の依存の無い合成で、そのままと並べ替えの G(hmm3) が同じ桁。
  - P-DSEL: D の s* の選びに w の値を入れない（変異: w を入れる）。
  - P-QW: 列ごとに放出の表の幅が記号の数に合う（変異: 26 に固定）。
- 前の試験の対照と変異は、当てはまるものを引き継ぐ（mode に関わる P-MODE・P-LIMIT・P-AB・P-NEGINF・P-FINITE と m16〜m27 の一部は外す）。
