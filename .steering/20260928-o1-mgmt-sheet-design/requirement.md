# o1-mgmt-sheet-design — O1 管理シートを見て分かる形にする

## 背景
O1 の管理シート（`O1_MGMT_SHEET_ID`）の 4 タブ（O1 登録ログ・O1 却下ログ・O1 受領台帳・O1 途絶）は
「1 行目 バナー / 2 行目 見出し / 3 行目以降 データ」の素の表で、書式が 1 つも無い（`Form_O1/*.gs` に
`setBackground` 等の呼び出しが 0 件）。研究者が「誰に連絡すべきか」を一目で読めない。
研究者依頼（2026-09-28）: 管理シートのデザインを、視覚的にも理解しやすい形に修正する。

## ゴール
- 「O1 途絶」を**状況ボード型**にする（研究者の選択 2026-09-28）: 表題帯（更新・走査の状態）→ 件数サマリ → 判定の凡例 →
  注意書き → 見出し（固定）→ 要対応順に並べた P-ID 行。判定セルを色分けする。
- 他の 3 タブにも見出し帯・固定行・列幅・結果の色（ok/partial/blocked・対象外・削除済・dup）を付ける（研究者の選択: 4 タブすべて）。
- Phase1 管理シートの配色（`Form_Phase1/GSE_Phase1_Form_Builder.gs` `UI_*`）に揃える。

## スコープ
### 含むもの
- `Form_O1/GSE_O1_Ledger.gs`（受領台帳・途絶の書式と途絶の配置）/ `Form_O1/GSE_O1_Form_Builder.gs`（登録ログ・却下ログの書式）
- 両テストの偽スプレッドシートを書式呼び出しに対応させ、見た目の契約（配置・色・並び）をテストする
### 含まないもの
- 判定ロジック（途絶/欠番/未受領の日数・条件）・通知・追記される**値**の変更（書式だけ）
- タブ名の変更（削除台帳 A-14 と既存シートが名前で参照している）
- 参加者ロスター（Phase1 の表・O1 の管理シートではない）
- 実シートへの反映（研究者が台帳を再配備・ビルダーで `buildO1MgmtSheet()` を 1 回実行）

## 受け入れ条件
- [ ] `node Form_O1/o1_ledger_test.cjs` / `node Form_O1/o1_form_builder_test.cjs` 緑（配置・色・並びのケースを含む）
- [ ] 変異検査（台帳・ビルダー）穴 0
- [ ] 既存行の**値**に触れない（追記のみの 3 タブは書式だけ）ことをテストで固定
- [ ] 画面の見た目を研究者が実シートで確認（UI は目で見るまで完了ではない: memory `ui-changes-need-eyes`）

## 運用メモ
- /reimagine 適用: No
- 理由: 形は研究者がプレビューで選択済み（状況ボード型・4 タブ）。判定ロジックは変えない。
