## 設計案比較（/reimagine 1 回目・2026-11-07）

v1 = メイン（`design-v1.md`）。v2 = v1 を読ませない別のエージェント（Opus）が requirement・decisions・一次のコードから作った案（`design-v2.md`）。

### v1 の要旨
- 駆動役 `s1_driver.rs` が Tauri と IO も持ち、専用スレッドで 1 秒ごとに調停器を回す。`superseded` の行だけ `lib.rs` の関数を呼ぶ。
- 押下・遷移は channel で受け、壁時計の今で判定する。一時停止は前の tick との差で見る。電源は段 1 の駆動役が自分で `power::start`（EH3 と排他であることに頼る）。
- カードは backend が 1 つ持ち、画面は状態を描く。overlay は画面外 1×1 に置いてから `show()`。
- 終了の補助はトレイだけ。他の終了経路で日の問いが開いていたときの行の扱いは「待ちの中に別の終了が来たら書く」までで、平常の × や「GSE を終了」で開いていたカードは書かない。

### v2 の要旨
- `s1_driver.rs` は純粋（Tauri・logger・OS を持たない）で `Action` を `Effect` に変えるだけ。行の組み立てと副作用は全部 `lib.rs`（送出元の検査と O1 の配布の門が `lib.rs` を見たまま効く）。
- 調停器に渡す時刻を 2 秒遅らせる（`S1_TICK_LAG_MS`）。押下が届き切ってから判定し、3 本目の `gse-replay --probes` と結果を合わせる。
- 一時停止は止める側のコマンドが `set_paused` の前に画面を伏せて `on_pause` を呼び、再開は `recording.rs` の世代 `PAUSE_EPOCH` で取りこぼさない。電源は受け口を 1 本にまとめる（`power::start` を `lib.rs` に 1 回）。復帰の予備に 30 秒の空き。
- `shutdown` の冒頭（どの終了経路でも）で `s1_finish_before_end`: 開いている日の問いを `closed_by = quit` で書いてから `End`。一時停止と終了で開いていたプローブのカードは行を書かずに下ろす。
- 枠の作り直しで `Arbiter::into_day_question` を足す。段 1 の overlay に `set_content_protected(true)`（画面共有に映さない）。画面は `S1CardHost.tsx` を新しく置き、マウント・受信・`focus`/`visibilitychange` で取り直す。

### 主要な差異
| 観点 | v1 | v2 |
|---|---|---|
| アプローチ | 駆動役が副作用まで持つ | 純粋な駆動役（`Effect`）＋ `lib.rs` が副作用。単体で検査しやすい |
| 時刻 | 壁時計の今 | 2 秒遅らせた時刻（生きた走行と再生の一致） |
| 一時停止 | tick の差（1 秒以内の止めて再開を見落とす） | 止める側が直接呼ぶ＋世代の数 |
| 電源 | 段 1 が自分で登録（排他に頼る） | 受け口を 1 本にまとめる |
| 終了 | トレイの補助だけ。× などで開いていた日の問いは行が無い | どの経路でも `End` の前に日の問いの行を書く |
| 取り消し | 行なしで下ろす（判断 2 の「以後の行は 0」） | プローブ = `dismissed`、日の問い = `dismiss` を書いてから印を消す（本人の未回答と混ざる） |
| overlay | 画面外 1×1 に置いてから `show()`（Windows の一瞬のクリック奪取を防ぐ） | NSPanel 化の後に `show()` だけ。`set_content_protected` を足す |
| 変更規模 | やや小さい | `recording.rs`・`probe_arbiter.rs` の小さな追加と `S1CardHost.tsx` で少し大きい |
| テスト戦略 | 純粋な部分は限られる | 純粋な駆動役の検査が厚い・本文の検査に `power::start` が 1 回 |
| リスク | 再生との割れ・1 秒以内の一時停止の見落とし・× で日の問いの行が消える | 2 秒の遅れが足りるかは未実測・一時停止の境目 ±2 秒は再生と合わない |

### 推奨案
ハイブリッド（v2 を土台に、v1 から 2 点）— 理由: v2 は再生との一致・一時停止の取りこぼし・どの終了経路でも日の問いの行を残す点で、v1 が外していた穴を塞いでいる。v1 から残すのは、(1) 取り消しは行なしで下ろす（判断 2 の「以後の行は 0」に合い、本人の `dismissed` と混ざらない。v2 自身が一時停止と終了で採った理由と同じ）、(2) overlay は画面外 1×1 に置いてから `show()`（v2 も「読んでいない」に挙げた Windows のクリック奪取への備え）。
