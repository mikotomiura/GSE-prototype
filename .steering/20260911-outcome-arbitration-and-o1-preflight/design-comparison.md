# 設計案比較 — issue 007（転帰定義の一本化 / ADR-029）

> `/reimagine` 1 回目。⚠️ v1 = `design-v1.md` / v2 = `design.md`。

## v1 の要旨

★ 争点を **ADR-009 対 ADR-024 の 2 者**と見て、**役割で分離**する
（出口 = ADR-024 の `receipt_free_resumption` / 入口 = ADR-009 の軸）。
★ 「上書き」とも「対称的並存」とも書かず、**一方向の禁止**（入口の量を出口に流用しない）を置く。
⚠️ 根拠は ADR-009 / ADR-024 の 2 本と ADR-023 D7 の自己言及論だけ。

## v2 の要旨

★ まず **「O1 の主解析とは何か」を一次資料で確かめ直した**。
⚠️ 結果、**issue 007 の前提が 4 点覆った**（関係は ADR-025 に既出 / O1 の問いは ADR-014 D1 が既に指定 /
並立は 4 つ / ADR-024 が O1 の観測設計文書に未反映）。
★ 裁定は **「転帰を減らす」のではなく「*役割割当* を確定する」** —— ⚠️ `receipt_free_resumption` は
**何も予測しない記述統計**なので「O1 の主解析が *予測する* 転帰」には据えられない。
★★★ そのうえで **中身を 2 つ入れる**: ① `left_observation` を計器不在 / フォーカス / セッション終了の
**3 層に割る**（新観測ゼロ・上下界の対象が縮む）② **ADR-024 D4 の競合イベントにも上下界を課す**
（新観測ゼロ・`outcomes` の読み替えだけ）。

## ⚠️★★★ v1 の致命的な欠陥（★ 再生成して初めて見えた）

1. ⚠️★★★ **v1 は「O1 の主解析の出口は ADR-024」と書く** —— ★ しかし **ADR-014 D1（Accepted）が
   O1 の答える問いを `left_observation` の内訳、判定量を G2 の上下界の幅と既に指定している。**
   → ★ v1 の ADR は **ADR-014 を黙って上書きする**ことになり、⚠️ 「ADR 本文を書き換えない」規約の
   趣旨（= 改訂は明示的に行う）を**形式だけ守って実質を破る**。
2. ⚠️★★★ **v1 は ADR-025:10-11 を知らないまま「どの文書にも書かれていない」を前提にした。**
   → ★ そのまま書くと **ADR-029 自身が事実誤認を含む**。
3. ⚠️ **v1 の裁定は中身が無い。** 役割分離は ADR-025 が 1 行で既に言っており、
   ★ handoff §3 が警告した「**ここを外すと ADR が空になる**」にそのまま当たる。

## 推奨案

★★★ **v2 を採用する。**

理由:

1. ★ **v1 の結論（役割で分ける）は方向としては v2 と同じ**だが、⚠️ **v1 は役割の割り当て先を
   逆にしていた**（O1 の主解析に ADR-024 を据えた）。★ 一次資料（ADR-014 D1）が v2 を支持する。
2. ★ **v2 だけが ADR に中身を入れる。** ⚠️ 裁定の価値は「どちらを採るか」より
   **「採った側の空欄を埋めること」**にあり、それは `left_observation` の 3 層化と
   ADR-024 への上下界義務の 2 件である。
3. ★ **v2 の 2 つの決定はどちらも新観測ゼロ・コード変更ゼロ**であり、
   ⚠️ issue 007 の Stop Condition（「第三の統合案が新しい観測を要求するなら即エスカレート」）に**触れない**。
   → ★ **O1 配布前に決め切れる。**
4. ⚠️ v2 は「決めない」ものも明示する（**ESM 監査 criterion** / 上下界の実装 / 2 設計文書の反映）。
   ★ これは issue 007 の Out と Stop Conditions に忠実である。

⚠️ **v1 を捨てるのではなく、`Alternatives` に「役割分離だけで留める案」として残す**
（★ AC 3 が却下案の保存を要求している）。
