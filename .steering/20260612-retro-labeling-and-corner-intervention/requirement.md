# requirement.md — 事後ラベリングシステム v0.2 の厳密レビュー＋具体設計、および角型(コーナー)段階介入 UI

## 背景

- 検証フェーズ移行前の成果物として `GSE_事後ラベリングシステム設計書_v0.2.md.docx`(以下 v0.2)が提出された。
- v0.2 は PM 指摘(n=1 問題・認知状態推定の妥当性)に応答する Ground Truth 収集基盤の設計案(スモークテスト前)。
- 並行して、介入 UI の改善要望が出された:
  - 段階的介入(Lv1→Lv2…)は維持する。
  - 「霧」などの大胆な全画面グラフィック介入はやめる。
  - 右下から「ひょこっと」通知で段階的に知らせる。
  - 介入してよいと判断した段階で、右下から QR コードを「ひょこっと」出し、散歩へ誘導する。
  - 演出・デザインは JS/CSS でモダンに。

## ゴール

1. **厳密なジャッジ・レビュー**: v0.2 を敵対的にレビューし、隠れた前提・統計的妥当性・反証可能性・運用破綻点を High/Med/Low で優先度付けして指摘する(codex を独立レビュアーとして併用)。
2. **具体設計**: レビューを反映した実装可能な設計(NDJSON スキーマ拡張・UI フロー・解析パイプライン・事前登録項目・kill 基準)を提示する。
3. **コーナー段階介入 UI 設計**: 全画面 Wall を「右下コーナーで段階的にひょこっと出る companion」へ再設計し、散歩誘導 QR まで一貫させる。介入却下フィードバック(§4)と同一コンポーネントに統合する。

## 受け入れ条件

- [ ] v0.2 の最重要欠陥 上位5件以上を、根拠と推奨修正付きで提示している。
- [ ] 循環論法リスク(主観ラベルとモデル特徴が同一打鍵由来)に対する具体的な統制案がある。
- [ ] 反証不能(フェイルセーフ論法)に対し、事前登録された kill / Go-NoGo 基準を定義している。
- [ ] コーナー UI のエスカレーション・ラダーが、不便益(forcing function)の喪失トレードオフを明示した上で設計されている。
- [ ] スキーマ拡張案が既存 `schema_dto.rs` / CI drift 検知と整合している。
- [ ] プライバシー境界(本文・ウィンドウタイトル・選択文字列 非保存)を侵していない。
