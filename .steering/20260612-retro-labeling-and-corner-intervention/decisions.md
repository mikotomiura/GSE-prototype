# decisions.md

## D-1 v0.2 を破棄せず「較正先行」へ立て付け直す
- **判断**: v0.2 を捨てず、Part B の追加・置換で検証可能化する。ただし**確証的 GT 収集を名乗らず**、スモークは「UI 操作可能性確認＋測定法較正研究」に降格。
- **根拠**: 自分(Opus)と codex の独立レビューが、波形の 4 役兼任(測定対象/cue/判断材料/機能ラベル)による測定法の非独立性に収束。確証主張は審査で容易に折れる。較正で測定法を成立させてから核検証に進む順序が頑健。

## D-2 主観ラベルの confound-free 化を最優先
- **判断**: 較正ブリッジ(リアルタイム申告)+ 時刻のみ cue 条件を主分析へ昇格。波形 cue は補助。
- **根拠**: X と Q1 が同一打鍵由来である循環論法は、波形を見ずに付けたラベルでしか切れない。v0.2 は較正を最小化していたが因果が逆。

## D-3 反証可能性の回復(事前登録 kill 基準)
- **判断**: PreReg-1..5 を `docs/` に凍結。各「どちらでも成果」に閾値を付し、大域 kill(confound-free |r|<0.3)を置く。
- **根拠**: 「どちらに転んでも成果」は反証不能設計。失敗条件の事前明示が検証の前提。

## D-4 統計は順序混合モデル、CV は被験者内 LOSO 主
- **判断**: z 化 Pearson → 順序ロジット混合モデル。LOUO は探索に降格、LOSO(被験者内)を主に。
- **根拠**: 1–5 は順序尺度・反復測定で非独立。個人化モデルを横断汎化で測る LOUO は評価対象の取り違え。n=3–5 は効果量推定フェーズ。

## D-5 介入 UI は「ハード全画面 Wall 廃止 → ソフトコーナー companion」
- **判断**: 全画面ブロック(霧)を廃し、右下アンカーの段階 companion(peek→expand→walk-QR)+ ソフトビネット + 打鍵警告へ。クリック遮断はしない。
- **根拠**: ユーザー要望(大胆グラフィック廃止・右下ひょこっと・QR 散歩導線)。不便益の forcing function は「能動的に QR をスキャンして散歩する」コミットへ移す。Monk/却下で裁定権をユーザーに残す GSE 哲学と整合。
- **確定(2026-06-12 ユーザー承認)**: Lv2 は**ソフトのみ**。ハード全画面ブロックは残さない。強制力は「能動的に QR をスキャンして散歩する」コミット + 画面端ビネット + 打鍵警告に限定。クリック遮断なし。Monk/却下(✕/⏸)で恒久 off・裁定権をユーザーに保持。walk-hard モードは実装しない。

## D-6 却下 UI と研究データの統合
- **判断**: コーナーカードの却下 2 択(✕ 詰まってない / ⏸ 今はもがきたい)を、v0.2 §4 の `InterventionDismiss` ログ源と同一コンポーネントにする。
- **根拠**: UI と GT 収集を二重実装しない。「⏸」押下数は GSE 思想の実証データ(独立指標)。

## D-7 スキーマは既存 DTO ミラー方式に同期追加
- **判断**: `LogEntry` 本体と `schema_dto.rs` の DTO を同期して新バリアント追加 → emit_schema → current.json → CI drift 緑。不変条件は producer 側で強制。
- **根拠**: 既存の schema drift 検知運用(`schema_dto.rs` 冒頭注記)を踏襲。プライバシー境界(本文・タイトル・選択文字列 非保存)を全新規ログで維持。
