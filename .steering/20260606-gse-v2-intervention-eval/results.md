## 結論: v2 は Phase 1 の有害誤 Stuck パターンを抑制できているか

**部分的に Yes。重度の害（Wall 誤発火）は完全抑制、軽度の害（Nudge 誤発火）は低減するが残存。**

1. **重度介入の完全抑制（最重要）**: 全 13 セッション 3925 decision で **Wall は 1 度も発火しなかった**。
   Phase 1 で観測された「タイポ多い Flow を誤 Stuck 介入し実際の stuck を誘発した」害の経路は
   Lv2 Wall。これがゼロ＝最も破壊的な誤介入は構造的に起きていない。need×opportunity×累積30秒の
   多重ゲートが効いている。

2. **PROTECT を 99.4% 正しく守る**: PROTECT (Flow/Inc) の 3456 decision のうち 3434 が HOLD。
   絶対量では誤発火率 0.6%／PROTECT-moment と低い。

3. **ただし条件付き HIR は高い (0.647)**: v2 が「ACT する」と決めた 34 回のうち 22 回が PROTECT 区間
   （= 有害な nudge）。opportunity ゲートは nudge レベルの false positive を**低減するが消し切れていない**。
   害は (a) 全て gentle な nudge、(b) 65 分で 34 回と低頻度、(c) 特定セッションに集中
   （`033257` 9件、`043006` 4件、`143258`/`045123` 各3件）。

4. **defer は概ね正答 (DC=0.933, 14/15)**: 見送った defer 区間の大半が W 内に自己回復＝
   「介入を控えた判断」が事後的に支持された。STALL recall 0.073 と合わせ、defer-first の
   保守的設計が意図どおり動いている（真の stall は多く見逃すが、害より見送りを優先）。

### 解釈の限界（screening であり verdict ではない）
- **GT は point label の forward-fill**（D2）。HIR の 22 FP の一部は、30–60 秒前の自己申告が
  「Flow」のまま延伸された区間で発火したもので、実際にはユーザーが stall 側へドリフトしていた
  可能性がある → **HIR=0.647 は真の害の上限寄り**の推定。
- ACT 分母が 34 と小さく、HIR の数値は数件の増減に敏感。**Wall=0 と DC=0.933 は GT 仮定に依らず頑健**だが、
  HIR の絶対値はラベル仮定・1Hz cadence・W 暫定値に依存する近似。
- フィードバック効果（誤 nudge が後続打鍵を変える相互作用・受容性）はオフラインでは測れない
  → live 収集に委ねる（issue.md ⑤）。
