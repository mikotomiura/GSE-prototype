### D0-1. `--sandbox read-only` で Codex は repo を **1 バイトも読めなかった**

引き継ぎ §0.5 は **「資料は貼らない。Codex は `--sandbox read-only` で repo を自分で読む」** を
前提にブリーフを組んでいた。⚠️ **この前提は 2026-08-16 に初めて実行されて成立しないことが判明した。**

  > `.steering/_handoff/codex-survey-audit-input.md` は参照できていません。
- → ★★★ **pass1 / pass2 の出力は「pass 指示文だけを読んだ一般論」であり、監査として無効。**
- ★ 関連: `~/.codex/config.toml` に `[windows] sandbox = "elevated"` がある（★ 因果は未確認）。

⚠️★★★ **教訓（引き継ぎに書かれていなかったもの）**: 過去に `codex-consult` / `codex-review` が
動いていたのは、いずれも **入力を stdin で渡す形**だったからで、
**「Codex が repo を自分で読める」は一度も検証されていなかった。**
→ ★ `verify-before-claiming` を **ツールの能力の記述**にも当てる。

## D2. ⚠️★★★ 未決 — `[V45]` と `[V51]` が同一 arXiv key で **V 名前空間内に二重登録**

★ **引き継ぎが把握していた重複は `[P130]` / `[P127]` の 2 件だけで、これは未把握だった。**

| ID | 内容 | 状態 |
|---|---|---|
| `[V45]` | Perry et al. — Do Users Write More Insecure Code with AI Assistants?（本体の主張） | active・重複列 `—` |
| `[V51]` | 同論文の **観察的二次分析**（engagement × 脆弱性） | active・重複列 `=V45` |

★ **key はどちらも `arXiv:2211.03622`** ＝ citation-ssot ルール 4「DOI / arXiv ID / 正規化 URL を key にして
二重登録を防ぐ」に抵触する。

⚠️ **ただし `[P130]` とは性質が違う**:
- `[P130]` は **気付かずに二重登録した事故**（→ tombstone が正しい是正）
- `[V51]` は **重複列に `=V45` と自己申告してあり、同一論文の *別の主張* を別 ID にした意図的な運用**

★ **選択肢**（⚠️ **研究者判断・本セッションでは直していない**）:

| 案 | 中身 | 代価 |
|---|---|---|
| **(a)** | `[V51]` を tombstone にし `[V45]` へ統合 | ⚠️ カード本文の引用の書き換えが要る。★ **2 つは別の主張**なので、統合すると「行動→安全の弱連関」の出所が消える |
| **(b)** | ルール 4 に **「同一文献の別主張は別 ID を許す（重複列で相互リンク必須）」という例外を明文化** | ★ 現状追認。⚠️ 重複防止キーの意味が弱まる |
| **(c)** | 現状維持＋検査の既知例外リストに入れる | ⚠️ 検査が形骸化しうる |

★ **私の見立て（未承認）= (b)**。理由: `[V45]`/`[V51]` は**実際に別の主張を運んでおり**、
統合すると 2026-07-24 ラウンドの結論（「テレメトリは accept を予測するが害リンクなし」と
「行動→安全は弱連関」）のどちらかが出典を失う。★ ルールの目的は**同じ主張の二重計上を防ぐこと**であって、
1 論文 1 ID を守ること自体ではない。

### C-1（HIGH）「『答えを写す』境界が設計変数に落ちていない」→ ★ **採用（ただし新しい穴ではない）**

- ⚠️ **既知**: `research-positioning.md §4` に逐語で
  **「現行の Lv1 Nudge / Lv2 Wall はこの区別を持たない」**と既に書かれている（★ Codex が読んだ資料内）。
  → ★ **「誰も問うていない下位問い」ではない。★ 優先度の裏書きとして扱う。**
- ★ **Codex が足したのは操作化案**（`direct solution 受領` / `hint 利用` / `検索・調査` を別カテゴリにする）。
  ★ これは `20260816-ai-escape-moment-and-friction.md` が
  **「『答え/ヒント』の境界を正解の無い論述執筆でどう操作化するかは文献に無い＝自分で決める部分」**
  と名指しした空白に、初めて具体案が入ったもの。
- ★★★ **一次確認で分かった追加の材料（★ Codex は知らない）**:
  `personalization-and-online-learning.md §5.2` の Tier 0 表に
  **`external_paste_chars` / count が「採用」で載っており、paste の文字数は既に記録されている**。
  → ★ **「長い貼付＝答え / 短い貼付＝断片」の粗い代理は、新規収集ゼロで作れる。**
  ⚠️ **未検証の仮説**である（[P125] の `direct solutions` 層と対応づく保証はない）。
  → ★ **Step 2 の主題 A の具体案として持ち込む。**

### C-2（HIGH）「空白を設計判断で埋めた後の失敗様式が未整理」→ ⚠️ **部分採用（誤検知を含む）**

    ＝ 引き継ぎ §8-1 の既知の失敗様式が**予告どおり発現した**。
- ★ **絞ると残る指摘は本物**（★ ここが採用部分）——
  **§4(b) の「文献では埋まらない空白」10 件のうち、反証ゲートに紐づいているのは G1 が触れる 1–2 件だけ**:

  と同型である。★ **新しい原則を持ち込まずに書ける。**
  → ★ **Step 2 に持ち込む。**
