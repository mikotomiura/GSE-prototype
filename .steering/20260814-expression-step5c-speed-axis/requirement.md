# expression-step5c-speed-axis — 提示手順の最後の漏れを塞ぎ、速度軸 4 点を同じ手順で測る

## 背景

★ Step 5b（2026-08-13）で盲検の提示手順の交絡 6 件を塞ぎ、研究者の耳で

| 条件 | 結果 |
|---|---|
| 層 0 = 0.5（+2.16 dB）× 遷移 0 秒 | 8/8（ヒット 4/4・誤警報 0/4） |
| 層 0 = 1.0（+1.05 dB）× 遷移 0 秒 | 8/8（ヒット 4/4・誤警報 0/4） |
| 層 0 = 1.0（+1.05 dB）× 遷移 5 秒 | 8/8（ヒット 4/4・誤警報 0/4） |

を得た。⚠️★★★ **これにより S4-D14 の前提（「+1.04 dB は聞き分けられない」）が旧手順の産物**
だったことが分かり、★ **層 0 を下げる理由が消えた**（閾値探索は不要）。

⚠️★★★ **しかし `/cross-review` の Codex が、まだ塞がっていない漏れ（AB-D10）を見つけた**
——★ **準備区間の跳びの回数の偶奇が、入場状態（＝直前トライアルの真値）を一意に決める。**
★ 感度ゼロで漏れだけを使った期待点は **4.80 / 8** なので **8/8 は漏れだけでは説明できない**が、
⚠️ **点数が上振れしている可能性は分離できない。**

★ 併せて **速度軸（量か速度か）はまだ「速い側」しか測っていない**
——★ 状態帯（0.001–0.02 Hz）に入るのは **60 秒**であり、⚠️ **そこを測るまで製品条件について何も言えない。**

## ゴール
