（`.steering/20260929-ai-fatigue-db-readable-and-gaps/`・PR #261 / #263 で main にマージ済み）。

研究者の方針（2026-09-29・逐語は `../20260929-ai-fatigue-db-readable-and-gaps/ideas.md` 冒頭・判断 11）:

「そのサーヴェイやかくまとめができた段階で判定者用ファイルを仕上げ, そのうえで, 相手先に送る要の判定評価後のスプレッドシートを作成する」。

## ゴール

サーヴェイ issue の A 群 5 本を、調べる価値の見込みの順に行い、1 本ごとに次の 3 種類のファイルを残す（引き継ぎ §3）:

| ファイル | 中身 | 誰が読むか |
|---|---|---|
| `survey-S-xx.md` | **事実だけ**（検索記録・書誌・抄録の要点・尺度の構成など論文に書いてあること）。評価の語を書かない。GSE に触れない | ★ 判定者が判定前に読むのはこれだけ |
| `survey-S-xx-ai-judgments.md` | **AI の判定案と評価**（含める／除外・除外理由・中心-A/B の見立て・COSMIN の評価・研究の質の懸念） | ⚠️ 判定者は自分の判定が終わるまで読まない（冒頭に明記） |
| `survey-S-xx-gse.md` | **GSE にとっての含意**（アイディア issue の材料） | GSE の計画を担う人 |

| 順 | issue | 出すもの（引き継ぎ §2） |
|---|---|---|
| 1 | S-12 日本語の文献 | 検索記録（データベース・検索語・日付・件数）＋書誌だけの候補一覧 |
| 2 | S-02 検索漏れ候補の抄録判定（11 件）＋ N-06 | 11 件の抄録の要点（書誌つき）。Sci Rep 2026 と Acta Psychologica 2026 の標本の重なり。N-06 のデータセット 2 件の生成方法 |
| 3 | S-08 AI 疲労の尺度の一覧 ＋ N-07 | 尺度の一覧（項目数・下位尺度・AI への向け方・報告された信頼性・妥当性の検証・翻訳版） |
| 4 | S-04 疲れが減る側の証拠 | 研究の表（対象・デザイン・測定・著者が報告した向き） |
| 5 | S-05 自動化を見張る疲労 | 能動的／受動的疲労の区別・主な実証・測定法の表 |

## スコープ

### 含むもの
- 学術 API（J-STAGE・CiNii Research・国立国会図書館サーチ・Europe PMC・Crossref・DataCite・Semantic Scholar・OpenAlex）での検索と件数の記録
- 公開されている抄録・本文（オープンアクセス）の読み取り（抽出は Sonnet のサブエージェント・判定はメイン）
- DB への追加・修正の**提案の表**（DB の xlsx は変えない）
- 本文の入手に研究者のアクセスが要るものの**[研究者] 依頼の一覧**（N-01 を含む）

### 含まないもの
- ⚠️ DB（xlsx）の行の追加・変更
- ⚠️ 判定者用ファイル・相手先に送るスプレッドシートの作成（引き継ぎ §4 の順番。サーヴェイの後）
- ⚠️ S-04・S-05 を DB の範囲に入れるかの決定（N-05 で決める。本タスクは材料集めに徹する＝判断 12 の逸脱の記録どおり）
- ⚠️ B 群（S-01・S-06・S-07・S-09・S-10・S-11）・C 群（S-03）
- ⚠️ 外部に出る操作（著者への照会・GitHub の issue・フォーム）。学術 API に研究者のメールアドレスを送らない
- ⚠️ 論文の本文・PDF・尺度の全項目文・抄録の全文のコミット（repo の外に置く。逐語の引用は 1 引用 40 語以内）
- ⚠️ GSE の `docs/references.md` への登録・文献カード（GSE の文書で引くと決めたときだけ）
- ⚠️ `/literature-review` の実行（Step 6〜8 が references.md・research-positioning へ書き込むため）

- [ ] すべての検索に、情報源・検索式（そのまま再実行できる形）・実行日・件数・どこまで目で見たか（全件／上位 N 件）が記録されている
- [ ] 件数を PRISMA の件数として扱っていない（目安であることを明記）
- [ ] 書誌（DOI・題名・著者・年・収録先）は一次（Crossref・DataCite・出版社・J-STAGE 等）で確かめたものだけを書き、確かめられないものは「未確認」と書く

- [ ] 本文・PDF・抄録の全文・尺度の項目文がコミットに入っていない
- [ ] DB への追加・修正は提案の表にまとまっている（xlsx は不変）
