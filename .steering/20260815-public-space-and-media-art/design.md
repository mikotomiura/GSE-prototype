## アプローチ

⚠️★★★ **研究者が出した 4 つ目の問い（over-fitting）は、A / B / C の上流にある。**

```text
「もっとシンプルな解き方があるのでは（over fitting）」
      ↓
★ これが「YES」なら、A（公共の場に物理オブジェクトを持ち出す）と
  B（音）の問い自体が縮む
      ↓
★★★ したがって 2 波構成にする —— RQ-0 を先に回し、結果を返してから A/B/C
```

★ **研究者の合意で確定した設計**（★ `decisions.md` 冒頭に記録）:

| 項目 | 値 |
|---|---|
| 範囲 | ★ **A + C 主・B は 1 angle 追加**（★ B は「音自体の問い」に戻る余地も残す） |
| 用途 | ★ **A = 設計根拠の補強 / C = gate / B = 設計判断の材料** |
| 名前空間 | ★ 現象・理論は **`P`**（[P108]–）／ 測り方・方法論は **`V`**（[V81]–） |
| 予算 | ★ **angle 8**（★ RQ-0 追加で 6 → 8）・ソース 25–30・一次全文 5–7 本 |
| 順序 | ★★★ **RQ-0 を第 1 波・A/B/C を第 2 波**（★ 間で研究者に結果を返す） |

## 検証戦略（★ 敵対的 3 票パネル）

★ **票は視点を変える**（★ `/literature-review` Step 4）:

| レンズ | 何を見るか |
|---|---|
| 1 | **内的妥当性**（設計・統制・交絡） |
| 2 | **外的妥当性・外挿**（★ GSE の課題・母集団・目的関数と一致するか） |
| 3 | **効果量の頑健性**（★ 補正後の値・出版バイアス・等価性検定の有無） |

⚠️★★★ **対称性の厳守**: ★ GSE に有利な主張も不利な主張も同じフィルタにかける。
★ **本ラウンドでは、案に有利な T-1（「文献はシンプルにせよと言っている」）を 0-3 で落とした。**
