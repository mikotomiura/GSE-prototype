# Issue 002: 青空文庫の本文から句を切り出し、ひらがなの読みを付ける前処理（辞書は注入可能にし、テストは辞書なしで回す）
verify_level: parse
runs_on: any

## Goal

青空文庫のテキスト（ローカルのファイル）から、シナリオが要求する長さの**句**を切り出し、**ひらがなの読み**を付けて
`corpus/1`（`kit/formats/FORMATS.md`）で書き出す `build_corpus.py` を作る。
★ 読みの付与は SudachiPy（判断 19）だが、**トークナイザは差し替え可能**にし、selftest は辞書なしで回す。

## Background

- 判断 19: 読みは `sudachipy` ＋ `sudachidict_core`（どちらも Apache-2.0）を**前処理だけ**に使う。1 回走らせて句 ＋ 読みを確定し、SHA-256 を `experiment/data.md` に記録する。以降の実行は辞書に依存しない。
- design.md §1.5: 「青空文庫（著作権切れ）の文から、シナリオが要求する長さの句を seed 固定で抽出する」。
- ⚠️ **E1 の正解は変換事象**なので、読みが原文と違っても打鍵列として妥当なかなであれば足りる。**E2 の正解は「打った読み」**（原文ではない）。
- 青空文庫のテキストは Shift_JIS（cp932）で、注記の記法がある: ルビ `《…》`、ルビの始まり `｜`、注記 `［＃…］`、作品末尾の底本情報。
- ⚠️ ループの worker は**ネットワークにも pip にも触れない**。辞書の導入と本番の実行はマイルストーン **M0**（`_issue-plan.md`）でメインが行う。

## Scope

### In
- `papers/ime-observation/kit/corpus/build_corpus.py`（新規）
  - `build_corpus.py --src <dir> --out <file> --seed <int> [--tokenizer sudachi|table:<json>] [--min-reading N] [--max-reading M] [--per-work K]`
  - 処理: cp932 で読む → 底本情報・注記・ルビ記法を除く（★ ルビは**原文の漢字を残して読みを捨てる**。読みはトークナイザが付ける）→ 文に分ける（`。` `！` `？`）→ 句に分ける（読みの長さが `min`〜`max` に入る単位。既定 6〜30 字）→ 読みを付ける → **読みがひらがなだけ**（`^[ぁ-ゖー]+$`）の句だけ残す（数字・英字・記号を含む句は捨てる）→ seed で作品ごとに `K` 句まで抽出。
  - `phrase_id` は `<work_id>-<文番号>-<句番号>` のように**入力から決定的に**決める。`work_id` はファイル名から。
  - ヘッダに `tokenizer`（名前と版）と `dict`（辞書の名前と版）を書く。版は `importlib.metadata.version` から取る。`table:` のときは `"table"` と JSON の SHA-256。
  - `--validate <file>`: `corpus/1` の検査（ヘッダ・必須キー・読みの正規表現・`reading_len == len(reading)`・`phrase_id` の重複なし）。違反で exit 1。
  - `--selftest`（目印 `# kit: selftest`）: **辞書を使わない**。表トークナイザ（テストの中で作る小さな対応表）で、次を確かめる:
    - ルビ `｜青空《あおぞら》` と `漢字《かんじ》`・注記 `［＃「…」に傍点］`・底本情報が除かれる
    - 読みにカタカナ・数字・英字が残る句は捨てられる
    - 同じ入力・同じ seed で**バイト一致**、seed を変えると抽出が変わる（陰性対照）
    - `--validate` が正しい出力を通し、壊した出力（読みに漢字・重複 ID）を拒否する
- `papers/ime-observation/kit/corpus/README.md`（新規）: 使い方、M0 の手順（venv を作る → `pip install sudachipy sudachidict_core` → 版を記録 → 本番の実行 → SHA-256 を `experiment/data.md` へ）、⚠️ 読みの誤りの扱い（E1 は影響なし・E2 は打った読みを正解とする）。

### Out

- `requirements.txt`（★ 版は M0 でメインが確定して置く）。
- 青空文庫からのダウンロード、作品の選定（M0）。
- 現代文コーパス（issue 027・任意）。
- 実データ `kit/corpus/data/phrases.jsonl` の生成（M0）。
