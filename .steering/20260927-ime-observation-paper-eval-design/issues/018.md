## Goal

照合器（issue 017）が作った対から、L1 の残りの指標を出す `l1.py` を作る。
`dwell_ms` の誤差（中央絶対誤差 ＋ Bland–Altman・ブロック単位のクラスタ・ブートストラップ）、`abandon` の混同行列と κ、

- design.md §1.3 の表（`dwell_ms` の誤差 = 中央絶対誤差 ＋ Bland–Altman・ブートストラップ（seed 固定）／`abandon` = 正解は確定なしで marked text が消えた・混同行列 ＋ κ・Wilson／`nav` = 完全一致率 ＋ 差の分布・正解は**正解側のセッション区間の中で実行器が送った矢印の数**（issue 010 の `nav_true`）／20 秒打ち切り = 20 秒超のセッションで行が出ないことの確認・件数／oracle ↔ 正解の不一致 = 件数と型・Wilson・**評価からは除外しない**）。
- design.md §1.3〔v2〕: 連続量の区間は**ブロック単位のクラスタ・ブートストラップ**（同じブロックの試行は IME の状態を共有するので独立でない）。★ 推定で書く（検定しない）。
- ⚠️ `ime_compose.rs:68-69` の逐語: 時計が巻き戻ると `dwell_ms == 0` の行が出る → 「解析側は `dwell_ms == 0` を実測値として扱わないこと」。→ ★ `dwell_ms == 0` の対は誤差の計算から外し、**件数を別に出す**。
- 入力: issue 017 の `match()` の結果（`pairs` など）と `sessions.json`（issue 010）の `oracle_agreement`。統計は `stats.py`（issue 016）。
