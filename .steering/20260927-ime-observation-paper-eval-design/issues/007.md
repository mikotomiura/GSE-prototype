# Issue 007: 参照入力欄 macOS —— NSTextInputClient への呼び出しを content-free な `gt/1` で記録する
verify_level: recheck
runs_on: macos

## Goal

`NSTextInputClient` を実装した最小の Cocoa アプリ（Swift 1 ファイル）を作り、IME からの呼び出しを
**種別・長さ・範囲・時刻だけ**の `gt/1`（`kit/formats/FORMATS.md`）で記録する。★ 正解の源（判断 2）。
⚠️★★★ **確定文字列・未確定文字列を一切記録しない**（design.md §1.1〔v2〕）。

## Background

- design.md §1.1（参照入力欄 macOS）: `setMarkedText` の長さと `selectedRange`・`insertText`・`unmarkText`・`firstRect` を時刻つきで記録する。
- ⚠️ 2026-09-28 の一次確認（decisions.md 判断 10）: `unmarkText()` は逐語 "The text view should accept the marked text as if it had been inserted normally." ＝ **確定側**。★ **呼び出し順は Apple の文書に書かれていない** → 較正パイロット（M1）で確かめる。→ 本 issue は**解釈しない**（呼ばれたものを呼ばれた順に書くだけ）。
- ⚠️ プロトコルに候補窓の表示を知らせるメソッドは無い（`firstRect` は位置決め）。
- 判断 22: Swift 1 ファイル・`swiftc`・パッケージ依存なし。
- 時計: 壁時計 `t_wall_ms`（`Date().timeIntervalSince1970 * 1000` を整数に）と単調時計 `t_mono_ns`（`clock_gettime_nsec_np(CLOCK_UPTIME_RAW)`）の**両方**（design.md §1.1 の時計の節）。

## Scope

### In
- `papers/ime-observation/kit/refinput-macos/RefInput.swift`（新規）
  - `NSView` のサブクラスで `NSTextInputClient` を実装する。IME が動くのに必要な問い合わせ（`hasMarkedText` / `markedRange` / `selectedRange` / `attributedSubstring(forProposedRange:actualRange:)` / `validAttributesForMarkedText` / `characterIndex(for:)`）には**メモリ上の文字列**で正しく答える（★ 本文はメモリには持つが**ログには出さない**）。
  - 記録するもの（`gt/1` の `mac_nstic`）: `set_marked`（`len` = UTF-16 長・`sel_loc` / `sel_len`・`rep_loc` / `rep_len`（`NSNotFound` なら省く））／`insert_text`（`len`・`rep_*`）／`unmark`／`first_rect`／`do_command`（セレクタ名を `FORMATS.md` の列挙に写す。列挙外は `other`）／`key_down`（`event.keyCode`）／`focus_in` / `focus_out`（窓の key 状態の通知）。
  - ⚠️★★★ **記録関数の型で content-free を保証する**: 記録関数は `ev`（列挙型）と**整数・真偽値の引数だけ**を受け取り、`String` を受け取る形を**作らない**（`cmd` も列挙型から `rawValue` を出す）。
  - `--out <path>`: 1 行目にヘッダ（`"src":"mac_nstic"`・`app_version`・`"os":"macos"`）。1 行ごとに flush する。
  - 窓: 1 つの窓にこのビューだけ。起動時に前面に出て first responder になる。
  - `--selftest`: 窓を出さずにビューを作り、プロトコルのメソッドを**直接**呼ぶ（例: `setMarkedText("にほんご", …)` → `insertText("日本語", …)` → `setMarkedText("", …)` → `doCommand(by: #selector(cancelOperation(_:)))`）。出力を読み戻して、(a) `len` が UTF-16 長と一致、(b) ⚠️ **渡した文字列（「にほんご」「日本語」）が出力のどこにも無い**、(c) 列挙外のセレクタが `other` になる、を確かめて exit 0 / 1。
- `papers/ime-observation/kit/refinput-macos/build.sh`（新規）: `swiftc -O RefInput.swift -o .build/refinput-macos`（`.build/` は ignore 済み）。bash 3.2 で動くこと。
- `papers/ime-observation/kit/refinput-macos/README.md`（新規）: ビルド・起動・selftest、記録する呼び出しの一覧、⚠️「解釈しない（正解の定義は M1 で決める）」、⚠️ 本文はメモリにだけ持つこと。
