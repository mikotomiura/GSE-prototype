# Issue 008: 参照入力欄 Windows (a) IMM 互換 —— 自窓の WM_IME_* / IMN_* を content-free な `gt/1` で記録する
verify_level: recheck
runs_on: windows

## Goal

自分の窓で IME のメッセージ（`WM_IME_STARTCOMPOSITION` / `WM_IME_COMPOSITION` / `WM_IME_ENDCOMPOSITION` / `WM_IME_NOTIFY`）を受け、
**種別・フラグ・長さ・時刻だけ**を `gt/1`（`src: "win_imm"`）で記録する Rust の小さなアプリを作る。
⚠️★★★ **確定文字列・未確定文字列を一切取得しない**（長さは `ImmGetCompositionStringW` にバッファ `NULL`・長さ 0 を渡して**バイト数だけ**を得る）。

## Background

- design.md §1.1（Windows (a) IMM 互換）。⚠️ MS の一次文書（*IME and TSF Accessibility in Windows XP*）は「非 TSF アプリにも互換層で効く」とだけ書き、**どのメッセージが届くかは書いていない**（判断 10）→ 本 issue は**解釈しない**（届いたものを届いた順に書く）。M5 のパイロットで確かめる。
- 判断 2: **自分のプロセス内の観測**なので `docs/agent-shared.md` 制約 7 に触れない（★ グローバルフック・DLL 注入は使わない）。
- 判断 22: Rust・`windows = "0.58"`（src-tauri と同じ版）。★ 純粋な部分（メッセージ → 記録行）は **OS に依存しない `core.rs`** に置き、`cargo test` が Mac でも走る形にする（`windows` は `[target.'cfg(windows)'.dependencies]`）。
- 時計: `t_wall_ms`（`SystemTime`）と `t_mono_ns`（`QueryPerformanceCounter` を ns に換算、または `std::time::Instant` を起動時基準で）。
- `WM_KEYDOWN` の `vk` は、IME が処理中なら `VK_PROCESSKEY`（`0xE5`）になる。★ **そのまま記録する**（パイロットで意味を確かめる）。

## Scope

### In
- `papers/ime-observation/kit/refinput-windows/Cargo.toml`（新規）: パッケージ `refinput-windows`、lib（`src/core.rs`）と bin `refinput_imm`。依存は **`windows = "0.58"`（cfg(windows) のみ）だけ**。★ 必要な feature: `Win32_Foundation` / `Win32_UI_WindowsAndMessaging` / `Win32_UI_Input_Ime` / `Win32_UI_Input_KeyboardAndMouse` / `Win32_Graphics_Gdi` / `Win32_System_LibraryLoader` / `Win32_System_Performance`。⚠️ JSON は**手書き**（整数と列挙だけなので serde は要らない）。
- `papers/ime-observation/kit/refinput-windows/Cargo.lock`（新規・生成物）。
- `papers/ime-observation/kit/refinput-windows/src/core.rs`（新規・OS 非依存）
  - `enum Ev`（`StartComp` / `Comp { flags, comp_len, result_len }` / `EndComp` / `Notify { imn }` / `KeyDown { vk }` / `FocusIn` / `FocusOut` ＋ issue 009 用に `TsfStart` / `TsfUpdate { len }` / `TsfEnd { result_len: Option<u32> }` / `UiBegin { kind }` / `UiUpdate { kind }` / `UiEnd { kind }`）と、`fn line(ev, t_wall_ms, t_mono_ns) -> String`（`gt/1` の 1 行）と `fn header(src, app_version) -> String`。
  - ⚠️★★★ `Ev` のどのバリアントも `String` / `&str` / `char` を**持たない**。
  - `#[cfg(test)]`: 各バリアントの出力が期待する JSON と一致、ヘッダの形、⚠️ UTF-16 のバイト数 → コード単位数の換算（`bytes / 2`）。
- `papers/ime-observation/kit/refinput-windows/src/bin/refinput_imm.rs`（新規・Windows のみ）
  - 窓を 1 つ作り、`WM_IME_*` を記録したうえで **`DefWindowProcW` に渡す**（IME の既定の表示を壊さない）。`WM_IME_COMPOSITION` では `lParam` のフラグを記録し、`GCS_COMPSTR` / `GCS_RESULTSTR` の**長さだけ**を `ImmGetCompositionStringW(himc, flag, None, 0)` で得る。`WM_IME_NOTIFY` は `wParam`（IMN_*）を記録する。`WM_SETFOCUS` / `WM_KILLFOCUS` / `WM_KEYDOWN` も記録。⚠️ `WM_IME_CHAR` / `WM_CHAR` は**記録しない**（文字を運ぶため）。
  - `--out <path>` / `--selftest`（窓を作らず、`core.rs` を通して代表的なメッセージ列を出力し、読み戻して検査して exit 0/1）。
  - ⚠️ `unsafe` は Win32 呼び出しに限り、小さなラッパーに閉じる（`rust-standards` Skill）。`println!` / `eprintln!` を使わない（エラーは戻り値で返し、終了コードで知らせる）。
- `papers/ime-observation/kit/refinput-windows/README.md`（新規）: ビルド・起動・selftest、記録するメッセージの一覧、⚠️「解釈しない」、⚠️ 文字列を取得しないこと（`NULL`・長さ 0 の呼び出しだけ）。
