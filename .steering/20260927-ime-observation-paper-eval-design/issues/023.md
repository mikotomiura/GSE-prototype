- 判断 12 / design.md §3: 公開する観測部だけを単体の常駐プロセスとして両 OS で測り直す。⚠️ `_summary.txt` の CPU 平均 0.98% は**無効**（旧計器 `top -l 2` の過小報告）。★ 直した計器（macOS = `ps -o cputime` の増分 / 実時間）を流用する。⚠️ 短い窓でレート系を代表させない（`notes.md:906-907`）。⚠️ **バッテリーは外す**。

- 一次（2026-09-28 に確認）: `experiments/20260903-o1-runtime-cost/scripts/sample-macos.sh:41` は `pgrep -x 'gse-next'`、`sample-windows.sh:8` は `Get-Process -Name "gse-next"` で、**プロセス名が決め打ち**。
- ⚠️ 境界（`papers/README.md`）: `papers/` は GSE の `experiments/` を**実行時に参照しない**。→ ★ 計器は `kit/e3/` に**写し**、元のパスと SHA-256・**変えた行**（プロセス名を環境変数 `E3_PROC` から取る 1〜2 行）を README に表で書く。
- 作業中の打鍵は段取り（issue 006 `run_cell.py`）で流す。★ 本 issue は**コマンドの組み立てと集計**だけを持つ。
