# Issue 012: 単体ロガーの macOS ドライバ —— CGEventTap（listen-only）→ IME の開閉の追跡 → `ime_compose::drive` → `key` / `ime_shadow` 行
verify_level: parse
runs_on: macos

## Goal

issue 011 の差し込み口 `driver_macos.rs` に、macOS のドライバを実装する。打鍵を **listen-only の CGEventTap** で受け、
GSE と**同じ判断**で VK に写し、IME の開閉（`IME_OPEN`）を追い、`ime_compose::drive` に渡す。あわせて `key` 行の材料
（`(t, vk, press)`）を核へ送る。★ これで macOS の単体ロガーが `obs/1` を出せるようになる。

## Background

- 判断 17 / 22。⚠️ `hook_macos.rs`（1529 行）は `logger::LogEntry` や GSE の他の部分に絡むので、**ドライバは新規に書く**。ただし次は GSE から**抜粋の逐語コピー**にする（manifest `manifest.macos.json`）:
  - `hook_macos.rs` の **`is_observed_key`（`:248`）と `macos_vk_to_vk`（`:279`）の 2 関数**（doc comment ごと・関数ごと）。⚠️ `macos_vk_to_vk` と `handle_event`（`:480`）の間には別の関数があるので、「〜 `handle_event` の直前」では取らない。
  - `ime_macos.rs` の**純粋関数**（例: `select_ime_source`・`:106`）。⚠️ `ime_macos.rs` は `crate::logger::LogEntry` / `crossbeam_channel` に依存するので**ファイルごとは不可**。
- ★ 抜粋の書き方（issue 011 の `check_manifest.py` の規則）: コピー側は `// @excerpt-begin <id>` と `// @excerpt-end <id>` の**間**に逐語で置く（前置きの `use` は目印の外）。GSE 側は開始アンカー（行全体の一致・ファイルの中で 1 回だけ）〜終了アンカーの前。★ 関数の抜粋には **`symbol`（関数名）** を必ず入れる。★ manifest は `check_manifest.py --update --manifest manifest.macos.json --entries <spec.json>` で**自分の manifest だけ**を書く（`manifest.json` を書き換えない）。
- ★ IME の開閉の決め方は GSE と同じにする: 押下時の遷移は `ime_mode.rs`（011 が逐語コピー済み）の関数、入力ソースのポーリングは `ime_macos.rs` の `spawn_ime_open_polling_thread`（`:53`）と同じ判断（TIS で日本語の入力ソースか・`IME_STATE_DIRTY` / `JIS_KEYBOARD_SEEN` の扱い）。⚠️ ポーリングの FFI は新規に書く（`hook-constraints` mac-2: `dispatch_sync_f` をメインスレッドから呼ばない / mac-5: `AXIsProcessTrustedWithOptions` はメインスレッド）。
- ★ 修飾キー: `Command` / `Control` を伴う打鍵は `Chord::Modified`（`hook_macos.rs:590-607`）。
- ★ `key` 行に出すキーの範囲は GSE と同じ（`is_observed_key`）。⚠️ **auto-repeat は出さない**（GSE の macOS は repeat を捨てる）。
- ⚠️ `hook-constraints` mac-1: タップのコールバックの中は **Atomic 操作と channel の送信だけ**（ログ・確保・ブロック禁止）。mac-3: タップが無効化されたら作り直す。mac-4: 権限は Input Monitoring → Accessibility の順に確かめる。
- ⚠️ ドライバの Atomic（`IME_OPEN` / `IME_STATE_DIRTY` / `JIS_KEYBOARD_SEEN` 等で 011 のシムに無いもの）は **`driver_macos` の中に**置く（★ シム `src/input/hook.rs` は 011 の Allowed Files。触らない）。
- ⚠️ `main.rs` を触らない。サブモジュールは `src/driver_macos/` に置く（`driver_macos.rs` から `mod keymap;` などで宣言する）。
