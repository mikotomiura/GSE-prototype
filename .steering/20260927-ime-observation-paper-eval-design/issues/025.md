## Goal

実アプリ（macOS = テキストエディット、Windows = メモ帳）で「中」の速さ・n = 30 / シナリオを流した run と、参照入力欄の run を比べる `transfer.py` を作る。
★ 実アプリでは正解が取れないので、**oracle で数えられる量だけ**（変換の数・放棄の数）と、`dwell_ms` の**分布**を比べる（design.md §1.6）。

## Background

- design.md §1.6〔v2・任意〕。⚠️ Windows の観測部は IME の候補窓のイベントに依るので、ホストで挙動が変わりうる。

- 入力: 参照入力欄の run（`obs` / `oracle` / `plan`）と実アプリの run（`obs` / `oracle` / `plan`・`gt` なし）。統計は `stats.py`、L1 の部品は `l1.py`。
- 比べ方（★ 本 issue で固定する・使うなら M3 で凍結）: シナリオごとに「oracle の意図で変換があるはずの試行のうち `ime_shadow` 行が出た割合」と「放棄の意図の試行のうち `abandon` が真の割合」の差（Wilson の差の区間は Newcombe の方法 10）、`dwell_ms` の分布の 2 標本 Kolmogorov–Smirnov の統計量（★ 検定の p 値は出さず、統計量と分位点の差を出す）。
