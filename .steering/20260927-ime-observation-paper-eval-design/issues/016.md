## Background

- design.md §1.3: 検出の適合率・再現率は **Wilson 95% CI**、連続量は**ブロック単位のクラスタ・ブートストラップ**（seed 固定）、`dwell_ms` は **Bland–Altman**、`abandon` は **κ**。§1.3a: L2 は **Bland–Altman ＋ ICC(2,1)（絶対一致）**。★ 推定で書く（検定しない）。
- 既知の値:
  - **ICC**: Shrout & Fleiss (1979) の例（6 対象 × 4 評定者）—— 行 = 対象: `9 2 5 8` / `6 1 3 2` / `8 4 6 8` / `7 1 2 6` / `10 5 6 9` / `6 2 4 7`。★ 論文の表は小数 2 桁（ICC(1,1) = .17 / **ICC(2,1) = .29** / ICC(3,1) = .71）。平均平方から計算した値は **0.1657 / 0.2898 / 0.7148**（2026-09-28 にメインが計算して確認）→ ★ 4 桁で比べる。
  - **Wilson**: `x = 0, n = 10` の上限 = z² / (n + z²) = **0.2775**（z = 1.95996）。`x = n = 10` の下限 = n / (n + z²) = **0.7225**。
  - **κ**: 2×2 の表 `[[20, 5], [10, 15]]` → 一致率 0.70・偶然の一致 0.50 → **κ = 0.40**。
  - **Bland–Altman**: 差 `[1, 2, 3, 4, 5]` → 偏り 3.0、SD = 1.5811、一致限界 = 3.0 ± 1.96 × 1.5811。
- ⚠️ 出典の `[Pn]` 採番（`docs/references.md`）は本 issue の範囲外（★ メインが M3 で行う・citation-ssot）。コードのコメントには著者・年・題だけを書く。
- 判断 22: Python 標準ライブラリだけ（`math` / `random` / `statistics`）。

## Scope

### In
- `papers/ime-observation/kit/analysis/stats.py`（新規）: 次の純粋関数。
  - `wilson(x, n, conf=0.95) -> (lo, hi)`（`n = 0` は `(None, None)`）
  - `cluster_bootstrap(clusters, stat, B, seed, conf=0.95) -> (lo, hi)`（`clusters` = クラスタごとの値の配列。**クラスタを単位に**復元抽出する。パーセンタイル法）
  - `bland_altman(a, b) -> {"bias", "sd", "loa_lo", "loa_hi", "n"}`
  - `cohen_kappa(table) -> float`（k × k）
  - `icc(matrix, kind="2,1") -> float`（`"1,1"` / `"2,1"` / `"3,1"`。二元配置の分散分析の平均平方から）
  - `median_abs_error(a, b) -> float`
  - 乱数は `random.Random(seed)` だけを使い、**グローバルな乱数状態に触らない**。
- `--selftest`（目印 `# kit: selftest`）: 上の既知の値（小数 2〜4 桁で一致）に加えて、
  - `cluster_bootstrap` が同じ seed で**完全に同じ区間**、seed を変えると変わる
  - ⚠️ `cluster_bootstrap` がクラスタを壊さない: 各クラスタが定数（例: クラスタ内の値がすべて同じ）なら、要素単位の抽出より区間が**広い**（★ クラスタ内相関を無視していないことの陽性対照）
  - `wilson` の区間が常に `[0, 1]` に収まり、`x / n` を含む
