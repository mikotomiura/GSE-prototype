# Issue 014: 単体ロガーの Windows ドライバ (2) —— DWM cloak の WinEvent → CloakFold → `ime_shadow`、IME の開閉のポーリング
verify_level: parse
runs_on: windows

## Goal

Windows ドライバの**後半**を実装する。Windows 11 の新しい候補窓は表示・非表示ではなく **DWM の cloak / uncloak** で出入りするので、
GSE と同じく cloak の WinEvent（`WINEVENT_OUTOFCONTEXT`）を受け、`ime_cloak.rs`（011 が逐語コピー済み）の `CloakFold` で畳み込んで
変換セッションの Atomic に書く。あわせて、旧来の経路（013）との**調停**（`legacy_path_is_driving`）と、IME の開閉のポーリングを入れる。

## Background

- 一次（2026-09-28 に確認）: `hook_windows.rs` の `cloak_event_callback`（`:283`）と登録（`:423-430`・`WINEVENT_OUTOFCONTEXT`）、`ime_windows.rs` の `spawn_cloak_resolver_thread`（`:392`）・`class_name_of`（`:322`）・`dwm_is_cloaked`（`:341`）・`resolved_cloak_state`（`:366`）・`is_ime_candidate_class_name`（`:218`）・`is_stale_winevent_active`（`:202`）・`apply_fold_action`（`:502`）・`spawn_ime_open_polling_thread`（`:251`）、`hook.rs` の `is_ime_active`（`:41`）・`legacy_path_is_driving`（`:166`）。
- ★ 抜粋の逐語コピー（`manifest.windows.json` に**追記**）: `ime_windows.rs` と `hook.rs` のうち**純粋関数**（例: `is_ime_candidate_class_name` / `resolved_cloak_state` / `is_stale_winevent_active` / `legacy_path_is_driving`）。⚠️ `ime_windows.rs` は `crate::logger::LogEntry` / `crossbeam_channel` / GSE の Atomic に絡むので**ファイルごとは不可**。Win32 呼び出しとスレッドは新規に書く。
- ★ 2026-09-28 追記（判断 35）: 核に `crate::analysis::key_gate`（GSE の `key_gate.rs` のファイルごとの逐語コピー）がある。013 の `is_observed_key` の抜粋はそれを呼ぶ。

- `lib.rs:3552-3664` の Stale 経路（`MONITOR_SAFETY_VALVE_MS`）は **Windows 限定**。★ 核（011 の `main.rs`）が既に持っているか確かめ、無ければ Stop（`main.rs` は 011 の Allowed Files）。
- `hook-constraints` Win-1 / 共通-1〜3。`architecture-rules` ルール 5（DLL 注入なし・`WINEVENT_OUTOFCONTEXT` だけ）。
