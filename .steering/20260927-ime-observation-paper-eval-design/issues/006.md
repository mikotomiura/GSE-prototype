## Scope

### In
- `papers/ime-observation/kit/run/run_cell.py`（新規）
  - `run_cell.py --cell <cell.json> --plan <plan> --run-dir <dir> [--i-understand-this-sends-keys]`
  - セルの設定（★ キー名はこのとおり）: `os` / `ime`（名前と版の文字列）/ `ime_settings`（辞書）/ `refinput_cmd`（配列・`{out}` を gt の出力先に置換）/ `logger_cmd`（配列・`{out}` を obs の出力先に置換）/ `reset_cmd`（配列・空ならリセットしない）/ `focus_cmd`（配列）/ `ready_wait_ms` / `backend`（`dryrun` / `macos` / `windows`）/ `clock_sync_disabled`（真偽・研究者が確かめて書く）/ `auto_update_disabled`（同）。
  - 手順: run ディレクトリを作る（既にあれば止める）→ ロガーを起こす → 参照入力欄を起こす → `ready_wait_ms` 待つ → ブロックごとに（`reset_ime` が真なら `reset_cmd` を実行して `Emitter.write_reset` で記録）→ `focus_cmd` → `Emitter.run_block` → 全ブロック後に参照入力欄とロガーを**穏当に止める**（終了を依頼 → 待つ → だめなら kill し、その旨を manifest に書く）。
  - 子プロセスが途中で死んだら、その時点で止めて manifest に `aborted` と理由を書く（★ 除外規則「ホストのクラッシュ」の材料）。
  - `run.json`（manifest）: セルの設定、git の commit（`git rev-parse HEAD`・取れなければ `null`）、開始・終了の時刻（壁時計と単調時計）、各出力（`plan.jsonl` の写し / `oracle.jsonl` / `gt.jsonl` / `obs.jsonl`）の SHA-256 と行数、子プロセスの終了コード、`aborted`。

  - `--selftest`（目印 `# kit: selftest`）: `dryrun` と**スタブの子プロセス**（`python3 -c` でヘッダ 1 行を書いて待つだけの参照入力欄・ロガー）で 1 セルを回し、次を確かめる:

    - `reset_cmd` の終了コードが oracle の `reset` 行に入る（★ `false` 相当のコマンドで非 0 を記録できる）
    - ⚠️ 子プロセスが途中で死ぬスタブで `aborted` になる（陰性対照）
    - ⚠️ 既存の run ディレクトリを上書きしない
