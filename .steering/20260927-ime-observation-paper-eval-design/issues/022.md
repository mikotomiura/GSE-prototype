# Issue 022: E2 開集合の復元 —— 文字 n-gram の言語モデルと制約つき復号・文字誤り率・事前分布のベースライン
verify_level: parse
runs_on: any

## Goal

公開される形のログから**打った読み（ひらがな）**を推定する開集合の攻撃（A1・K0 / K1）を作る。
攻撃者は `alphabetic` の連続長（＝ローマ字の長さ）と `space` / `enter` などの区切りから、**ローマ字の長さが合うかな列**を
文字 n-gram の言語モデルで復号する。★ 指標は文字誤り率（CER）、ベースラインは**ログを見ない**言語モデルの事前分布だけ。
「ログを見ることでどれだけ良くなるか」を出す。

## Background

- design.md §2 A1: 日本語の言語モデルを持つ攻撃者が、カテゴリ列と時刻から本文を推定する。指標 = 文字誤り率。ベースライン = 言語モデルの事前分布だけ（ログを見ない）。⚠️ 攻撃の強さの上限は主張しない。
- ★ 知識の段（本 issue で固定する・M3 で凍結）: **K0** = ジャンルの知識なし → 文字 1-gram（学習コーパスの文字頻度だけ）、**K1** = ジャンルの知識あり → 同じコーパスの**重ならない分割**で学習した文字 n-gram（既定 n = 3・平滑化は Witten–Bell か加算）。★ 評価に使う句は学習に入れない。
- 判断 19: E2 の正解は**打った読み**（原文ではない）。
- ★ ローマ字の長さの表は生成器の `romaji.py`（issue 003）を import して使う（★ 再実装しない —— 攻撃者のモデルが刺激と同じ写しを使う）。
- ⚠️ 縮退順（判断 14）の**最後**（遅れたら最後に落とす）。→ ★ 本 issue は E1 の経路より優先度が低いが、任意ではない。

  - `evaluate(trials, lm_k0, lm_k1, ...)`: CER は試行ごと・平均・区間は `stats.cluster_bootstrap`（クラスタ = 計画のブロック）。`K0` / `K1` / `baseline` / `gain`（対の差 = baseline − 攻撃）に加えて、**陰性対照 `shuffled`**（各試行に「読みの違う別の試行」の復号結果を当てて自分の正解と比べる。ログが情報を持たない水準の gain）を出す。
  - `split_phrases`: 学習と評価を seed 付きシャッフルで分け、評価の句と**読みが同じ**学習の句も除く（重複の除去を数える）。
