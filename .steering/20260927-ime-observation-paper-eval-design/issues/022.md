# Issue 022: E2 開集合の復元 —— 文字 n-gram の言語モデルと制約つき復号・文字誤り率・事前分布のベースライン
verify_level: parse
runs_on: any

## Goal

公開される形のログから**打った読み（ひらがな）**を推定する開集合の攻撃（A1・K0 / K1）を作る。
攻撃者は `alphabetic` の連続長（＝ローマ字の長さ）と `space` / `enter` などの区切りから、**ローマ字の長さが合うかな列**を
文字 n-gram の言語モデルで復号する。★ 指標は文字誤り率（CER）、ベースラインは**ログを見ない**言語モデルの事前分布だけ。
「ログを見ることでどれだけ良くなるか」を出す。

## Background

- design.md §2 A1: 日本語の言語モデルを持つ攻撃者が、カテゴリ列と時刻から本文を推定する。指標 = 文字誤り率。ベースライン = 言語モデルの事前分布だけ（ログを見ない）。⚠️ 攻撃の強さの上限は主張しない。
- ★ 知識の段（本 issue で固定する・M3 で凍結）: **K0** = ジャンルの知識なし → 文字 1-gram（学習コーパスの文字頻度だけ）、**K1** = ジャンルの知識あり → 同じコーパスの**重ならない分割**で学習した文字 n-gram（既定 n = 3・平滑化は Witten–Bell か加算）。★ 評価に使う句は学習に入れない。
- 判断 19: E2 の正解は**打った読み**（原文ではない）。
- ★ ローマ字の長さの表は生成器の `romaji.py`（issue 003）を import して使う（★ 再実装しない —— 攻撃者のモデルが刺激と同じ写しを使う）。
- ⚠️ 縮退順（判断 14）の**最後**（遅れたら最後に落とす）。→ ★ 本 issue は E1 の経路より優先度が低いが、任意ではない。

## Scope

### In
- `papers/ime-observation/kit/e2/charlm.py`（新規）: `CharLM(n, smoothing).fit(texts)`・`logp(context, ch)`・`sample_prior(length, seed)`。
- `papers/ime-observation/kit/e2/open_set.py`（新規）
  - `decode(observed_segments, lm, beam, romaji_len) -> reading`: 観測の区切りごとの `alphabetic` の数に**ローマ字の長さが一致する**かな列をビーム探索で探し、言語モデルの対数尤度の最大を返す。
  - `baseline(lengths, lm, seed) -> reading`: ログを見ず、読みの長さだけ（★ 攻撃者に長さを与えるかどうかは README に明記・既定は「区切りの数だけ与える」）で事前分布から作る。
  - `evaluate(trials, lm_k0, lm_k1, ...) -> {"K0": {"cer", "cer_ci"}, "K1": {...}, "baseline": {...}, "gain": {...}}`（CER は試行ごと・CI は `stats.cluster_bootstrap` でブロック単位）。
  - CLI: `--obs <obs>... --plan <plan>... --corpus <corpus> --split-seed <int> --out <json>`。
  - `--selftest`（目印 `# kit: selftest`）: 小さな人工コーパス（語彙の少ない反復的な文）で、
    - 復号の CER が事前分布のベースラインより**低い**（ログが情報を持つ）
    - ⚠️ 陰性対照: 観測の区切りと長さを**ランダムに入れ替える**とベースラインとの差が消える
    - 評価の句が学習に入っていない（分割の検査）
    - 同じ seed で**バイト一致**
- ⚠️ 既存のファイル（`closed_set.py` / `simulate_obs.py` / `README.md`・issue 021）は触らない。説明は `open_set.py` の docstring に書く。
