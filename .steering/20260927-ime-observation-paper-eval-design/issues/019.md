# Issue 019: L2 測度の一致 —— テキスト単位の集計量・Bland–Altman・ICC(2,1)・混合比で偏りが動くか
verify_level: parse
runs_on: any

## Goal

書字研究者が実際に計算する**集計量**が、正解と観測で一致するかを出す `l2.py` を作る（design.md §1.3a・★ 主評価の一つ）。
試行を「テキスト」に束ね、テキストごとの **平均変換時間 / 変換の数 / 放棄率 / 変換中の時間割合** を正解・観測の両方から計算し、
**Bland–Altman ＋ ICC(2,1)** で一致を示す。★ 速さ・シナリオの混合比を変えた 2〜3 の「合成テキスト母集団」で、集計量の偏りが混合比で動くかを見る。

- design.md §1.3a〔v2〕。⚠️ L1 で一致していても、誤りが特定の条件に偏れば**集計量は系統的にずれる**（design.md §0）。
- design.md §1.5〔v2〕: 合成入力には「自然な混合比」が無い → 主推定値はシナリオ別。まとめるときは重み（既定 = 均等）を明示。
- ★ **テキストの定義**（本 issue で固定する・M3 で凍結）: 計画の**同じブロックの中で、計画の順に** `text_size_trials` 件（設定・既定 8）ずつ束ねた試行の集まり。端数は捨てて件数を出す。★ issue 003 が**ブロックを速さで揃える**（`plan/1` のブロック行の `speed`）ので、テキストは 1 つの速さに属する → 混合比の層は**速さ**（`slow` / `mid` / `fast`）である。⚠️ テキストの中の試行の `speed` が揃っていなければエラーにする（揃っていない計画を黙って扱わない）。
- 集計量の定義:
  - 平均変換時間 = テキスト内のセッションの `dwell`（正解 = `end − start`、観測 = `dwell_ms`）の平均
  - 変換の数 = テキスト内のセッション数
  - 放棄率 = 取消（正解 = `outcome == "cancel"`、観測 = `abandon`）の割合
  - 変換中の時間割合 = `dwell` の合計 / テキストの時間（最初の `trial_begin` 〜 最後の `trial_end`・oracle から）
- 入力: `match.py` の結果（issue 017・`pairs` = `{"gt", "obs", "iou"}` の配列ほか）・`sessions.json`（issue 010）・`plan` / `oracle`。★ 差の符号は「観測 − 正解」（issue 018 と同じ）。統計は `stats.py`（issue 016）の `bland_altman` / `icc` / `cluster_bootstrap`。
- 判断 22: 標準ライブラリだけ。

    - 端数の試行を捨て、件数を出す
    - 同じ seed で**バイト一致**
