# O1 の 4 人で、人ごとの休止の分布と停滞の率の違いを記述する（改めた C）

## 背景

- 事前登録 `docs/preregistration-stage1.md` §3 の件数の見積もりは、日の揺れを研究者本人の O1 の 14 日の率の SD だけで入れている（`experiments/20261103-stall-candidates-c1c2c6/notes.md` §1）。人の間の違いの手がかりが無い。
- S1-E7（停滞の定義の選択）と S1-B4（C0・C1・C2 の作り方・長さの閾値は本人の分布から）の材料も、本人 1 人の記録にしか無い。
- O1 には研究者本人のほかに 3 人の記録が届いている（受け取りフォルダ `/Users/johnd/Downloads/GSE_Observation-1_.age-receiving/` の P006・P009・P011・P013。P009 が本人）。
- 引き継ぎ `.steering/_handoff/next-session-gse-mhd-rethink-abc.md` の C を、研究者が 2026-11-03 に「O1 の n=3 の記述」へ改め、B より先に置いた。受け取りフォルダには 4 人分あったので、4 人で行う（判断 1）。

## ゴール

O1 の 4 人それぞれについて、次を記述した notes と集計の JSON を残す。

1. 休止の長さの分布: 同じ観測区間の隣り合う押下の間隔（C0 の θ の標本と同じ流れ）と、活動の出来事の間隔（C1 の θ の標本と同じ流れ）の、対数の混合モデルの成分（位置・広がり・割合）。
2. 停滞の率と日の揺れ: C0・C1・C2（c1c2c6 の定義そのまま）の 1 時間あたりの件数、日の率の SD と数え上げだけの SD の見込みの比、θ の中央値、長さの段の割合。
3. 人の間の違いの幅を、事前登録 §3 の見積もりと S1-E7 に入れられる形で並べる（どの値を使うかは事前登録の改訂で決める）。

## 守ること

- 形成的な内部の記述（ADR-014）で、主張に使わない。
- 研究者本人の 11-01 08:30 以降の記録は開かない（名前の `<日付>_<時刻>` が `20261101_083030` 以上の本）。他の 3 人には取り置きを設けない（判断 3）。
- repo に入れるのは記号（人 A〜D）を付けた集計値だけ。記号と P-ID の対応・本人がどれかは repo の外に置く。時刻・日付・ファイル名を出さない（判断 2 と 5）。
- 削除の求めは無い（`docs/o1-deletion-ledger.md` §6 が 0 件・2026-11-03 に確かめた）。計算の直前にもう一度確かめる。
- 復号した平文と中間は repo の外（`~/gse-o1-derived/20261103-o1-n4-pause-stall/`）。削除台帳 A-4 の置き場として扱う。
- 記録・中間・結果の本文を外部の LLM（Codex を含む）に送らない。Codex に送るのは条件の文とコードだけ。
- 「作業上の認知状態」と書く。停滞を詰まりと書かない。疲労と呼ばない。
