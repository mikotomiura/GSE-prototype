## 1. 何をする研究か

この研究は、ふだんのパソコン作業のあいだ、キーボードやマウスの「操作のしかた」を記録し、作業中にときどき画面に出る短い問いへのお答えと合わせて、作業の進み方と手が止まる時間を調べるものです。

文章の中身・画面の内容は記録しません。記録するのは「いつ・どの種類の操作をしたか」と、問いへのお答えです。

G1（課題の実験）や O1（ふだんの作業の長期記録）とは別の研究です。

この研究は、大学などの倫理審査委員会の審査を受けていません。研究者が、記録の中身（文章の中身や画面の内容を取らない）・保管・削除のしかた・お願いする相手の範囲を限り、問いの数に上限を置き、問いに答えなくてよく、画面の表示を切れて、いつでも止めたりやめたりできるようにしたうえで、進めてよいと判断しました。

## 2. お願いすること

- ふだんどおりに作業していただくだけです。特別な課題はありません。
- 期間は前半と後半をあわせて数週間で、長くても 8 週間です。始める日と終わる日は、研究者からお知らせします。
- 記録用のアプリを起動しておいていただきます。参加の確認を済ませると、パソコンにログインしたときに自動で起動するよう設定されます（設定でいつでも切れます。切り方は配布フォルダの説明書にあります）。いつでも止められます（§4）。
- 作業中、ときどき画面のすみに短い問いが出ます（注 D）。1 日の終わりにも 1 つ問いが出ます（注 E）。アプリの画面で「問いに同意する」を押すまで、問いは出ません。
- 後半の期間には、日によって画面に表示が出ます（注 F）。
- いま何の作業をしているかを、画面の表示から 5 つの選択肢で選んでいただきます（論述 / 通信文 / デザイン・映像・制作作業 / vibe coding / その他・細切れの作業）。メールを読む・調べものなど、どれとも決めづらいときは「その他・細切れの作業」を選んでください（メールを書くのは「通信文」です）。選ばなくてもかまいません。何を選んでも、記録する内容は変わりません。
- 謝礼はありません。

問いへのご同意は、この研究に参加していただく条件です。問いに同意いただけない場合は、参加をお断りいただくことになります。個々の問いには答えなくてかまいません（注 D）。

## 3. 記録するもの / 記録しないもの

| 記録する | 記録しない |
|---|---|
| キーを押した時刻（ミリ秒） | どの文字を打ったか（本文） |
| キーの種類（注 A） | 画面の内容・スクリーンショット |
| 日本語入力の変換にかかった時間 | アプリの名前・ウィンドウのタイトル・URL・ファイル名・プロジェクト名 |
| 貼り付けの回数と文字数（中身は取得しません） | 音声・映像 |
| 画面の切り替えが起きた時刻（どのアプリへ切り替えたかは記録しません） | どのアプリへ切り替えたか |
| マウスの「動いた量・ホイールの回数」（Windows ではさらに「押した回数」）を 1 秒ごとに数えた値（注 B） | マウスの位置・軌跡・画面の解像度・モニタの配置 |
| キーボードの配列の種類（開始時に 1 回だけ） | 端末を特定できる情報（機体番号・ホスト名など） |
| この端末の導入ごとに作った乱数の識別子（16 桁・開始時に 1 回だけ）。端末や個人を特定する情報ではありません。複数の端末で使うときに、記録を端末ごとに分けるためだけに使います | 識別子を作るのに、機体番号・ホスト名などは使いません |
| アプリの版、記録がうまくいっていたかの状態 | 位置情報・端末の中の他のファイル |
| （macOS のみ）パスワード入力中だった区間の印（中身は取得しません） | クリップボードの中身 |
| 上の記録から計算した「作業の状態」の推定値（注 C） | その推定値をもとにした助言・通知（この研究では出しません） |
| 短い問いへのお答え・答えなかったこと・答えるまでにかかった時間（注 D） | お答えの理由・自由に書いた文・お相手のお名前（入力欄をつくりません） |
| 1 日の終わりの問いへのお答え・答えなかったこと（注 E） | 同上 |
| 後半の表示について、日ごとの記録（注 F） | 表示の見た目そのもの（画面の写し） |

### 注 A —「キーの種類」に何が入るか

文字キー / 数字 / 記号 / 句読点 / 空白 / 改行 / Tab / バックスペース / Delete、これに加えて修飾キー（Shift・Ctrl・Alt など）/ ファンクションキー（F1〜F12）/ Esc / 矢印キー（Windows のパソコンではさらにテンキー）の種類だけを記録します。

お使いの OS によって、記録されるキーの種類がすこし違います。テンキーは Windows でのみ記録されます。また Mac のノート型では、PageUp / PageDown / Home / End は矢印キーと同じ扱いで届くため、矢印キーとして記録されます。

たとえば文字キーは 26 種類がすべて同じ「文字キー」として記録されるので、打った言葉を復元することはできません。ただし、時刻と操作の並びから、作業していたか・手が止まっていたかといったようすは推し量れます。なお、貼り付けの操作をしたことは、§3 の表のとおり別に記録されます。

なぜ修飾キーなども記録するのか: 図面・動画編集などの作業は文字をほとんど打たないため、文字キーだけを見ていると「何もしていない」ように見えてしまいます。「作業していた」と「席を外していた」を取り違えないために、操作の種類だけを数えます。

### 注 B —「マウス」について

1 秒ごとに「どれくらい動いたか」を大まかな数にまとめたものだけを記録します。「押した回数（クリック）」は Windows でのみ記録されます（Mac では記録されません）。マウスがどこにあったか（位置・軌跡）は記録しません。位置を記録しないので、画面のどこを触っていたかは分かりません。

### 注 C —「作業の状態の推定値」とは

このアプリは、上の表に書いた記録だけから「いま作業がどれくらい滑らかに進んでいるか」を 1 秒ごとに推定し、その数値も保存します。新しく何かを記録するわけではありません。

この推定値をもとに、助言や通知が出ることはありません。短い問い（注 D）が出るかどうかも、この推定値とは関係なく、「しばらく操作が止まっていた・操作が戻ってきた」という時計と操作の事実と、ランダムな抽選で決まります。

推定は研究のための目安であり、あなたの能力や成果を評価するものではありません。

### 注 D —「短い問い」について

作業中、ときどき画面のすみに小さなカードが出ます。作業を強制的に止めたり、作業中の窓を覆い隠したりはしませんが、手前に出るので、注意がそれることはあります。

カードは「直前の30秒について教えてください」と尋ね、3 つの問いがあります。

1. どれだけ詰まっていた感覚ですか（1〜5 の目盛り）
2. どれだけ前に進んでいる感覚ですか（1〜5 の目盛り）
3. 直前の30秒、何をしていましたか（次の 6 つから 1 つ）

| 選択肢 | どんなときか |
|---|---|
| 熟考 | 手は止まっていたが考えていた |
| 詰まり | 先に進めずにいた |
| 外部資料 | 本・書類・画面などを読んでいた |
| 会話 | 会話・通話・打ち合わせをしていた |
| 離席 | その場を離れていた |
| 回答不能 | 思い出せない・当てはまらない |

どれくらい出るか（アプリが守る上限です）:

- 記録を動かしている 1 時間あたり、多くても 9 回です（ランダムな時刻に出るものが多くても 6 回、操作が止まったあとに出るものが多くても 3 回）。
- 20 分のあいだでは、多くても 3 回です。
- 間隔はふつう 6 分以上ですが、2 種類の問いが近づいたときは、2 分ほどの間隔で続けて出ることがあります。
- 1 日じゅう動かしていれば、その日は数十回になります。

いつ出るか: 主にランダムな時刻に出ます。そのほかに、しばらく操作が止まっていたあとや、ほかの画面から戻ってきたあとの最初の操作で出ることがあります。どの時刻に出すかはアプリが決め、すべての参加者で同じ決め方にしています。そのため、出る回数を人ごとに変えることはしません。多いと感じたときは、答えずに閉じていただくか、一時停止していただくか（§4）、参加をやめていただけます（§4-2）。

お約束:

- 答えなくてかまいません。閉じていただいても、参加にもそのほかのことにも影響しません。
- 理由はお聞きしません。自由に書いていただく欄もつくりません（お相手のお名前・アプリの名前・ファイル名などが残らないようにするためです）。
- 記録に残るのは、問いを出した時刻、目盛りの値、6 つのうちどれを選んだか、答えなかったこと（「思い出せない」「閉じる」のどちらで閉じたかを含む）、答えるまでにかかった時間です。問いを出す候補になったのに出さなかった時刻とその理由（間隔が近すぎたなど）も残ります。

正直に書いておきたいこと:

1. 「会話」をお選びになると、「その時刻に会話していた」ことが記録に残ります。お相手が誰かは残りません。それでも気になるときは、§4 の 3 番（この時間帯を消して）をお使いください。お答えもいっしょに消えます。ご同席の方が気にされる場合も、あなたからお申し出いただければ同じように消せます。
2. 問いが出ること自体が、ふだんの作業を少し変えてしまう可能性があります。私たちはそれを隠さずに、どれくらい変わるのかも含めて調べます。

§5 のとおり、記録は 48 時間おいて自動的に送られます。送られたあとは、あなたの端末の操作だけでは消えません。気になるお答えは、送られる前（その日と、その次の 2 日ほど）に消していただけます。

### 注 E —「1 日の終わりの問い」について

夕方から夜（17 時〜23 時）のあいだに、その日の作業について 1 つ尋ねるカードが出ます。出るのは、そのあいだに操作が 20 分ほど止まったとき、アプリを終了するとき、一時停止から戻ったときのどれかで、その日については 1 回です。

- 問いは「今日の作業にどのくらい熱意を持てましたか」で、1〜5 の目盛りで答えます。
- その日に答えがなかったとき（問いが出なかったとき、閉じたときを含む）は、翌日の最初に「昨日の作業」について 1 回だけ尋ねます。1 つの日について尋ねるのは 2 回までです。そのため、前の日の分と当日の分の 2 枚が出る日があります。
- 答えなくてかまいません（「今日は答えない」で閉じられます）。理由はお聞きしません。
- 記録に残るのは、尋ねた日、出たきっかけ（夕方の途切れ・終了・一時停止からの再開・翌日）、目盛りの値か答えなかったこと、カードを出した時刻と閉じた時刻、答えるまでにかかった時間です。

### 注 F —「後半の画面の表示」について

後半の期間には、日によって、画面の背景と画面の下の縁に、線の表示が出ます。表示は、あなたのキーボードとマウスの操作に合わせて動きます。

- 後半の初日は、必ず表示が出ます。2 日目からは、前もって作った無作為の表で、表示が出る日と出ない日が決まります。どの日が出る日かは、前もってはお知らせしません。
- 表示はマウスの位置とクリックにも合わせて動きますが、マウスの位置やクリックの場所は記録しません（記録するのは §3 の表のとおりです）。
- 表示が邪魔なときは、画面上部（Windows では画面右下）のアプリのアイコンのメニューから「やめる」を選ぶと、その日のあいだは表示が出なくなります。「描く」を選ぶと戻ります。翌日は表のとおりに戻ります。カーソル・クリックに合わせた動きも、同じメニューから個別に切れます。
- 表示を見るために、ほかのアプリの窓をいったんどけることができます（もう一度操作すると戻ります）。
- 表示は作業の妨げにならないように作っていますが、気になるときは上のとおり切っていただいてかまいません。切っても不利益はありません。

この表示について記録するもの（日ごとに 1 行と、その日の途中の 5 分ごとの写し）:

- その日が表示の出る日だったか（無作為の表での割り当て）
- その日に表示が出ていた時間と、画面の下の縁の表示が見えていた時間（画面のロック中・スリープ中・ほかの窓に隠れていたときなど、見えなかった時間を除いたもの）
- 「やめる」「描く」を選んだ時刻と、カーソル・クリックの動きを切った・戻した時刻
- 表示を始めた時刻、ほかの窓をどけた回数
- 表示の描き方を決める乱数の値と、無作為の表の照合用の値

表示の見た目そのもの（画面の写し）は記録しません。打ったキーの内容も、この表示の記録には入りません。

## 4. あなたがいつでもできること（3 点）

| # | できること | どうやって |
|---|---|---|
| 1 | 記録中だと分かる | 記録している間はずっと画面に印が出ます（印が出ていないときは記録していません） |
| 2 | すぐ止める | ワンクリックで一時停止できます。理由を聞きません。一時停止中は問いが出ません |
| 3 | あとから「この時間帯を消して」と言える | 時間帯を指定して削除できます（例:「昨日の 14:00〜15:00」）。理由を説明する必要はありません |

3 番で消える範囲:

- その時間帯の操作の記録、問いへのお答え（1 日の終わりの問いを含む）、後半の表示について記録した時刻と量が消えます。
- 残るのは、その日が表示の出る日だったかどうか（無作為の表での割り当て）、記録のファイルごとの始まりの印と設定（始まった時刻を含む）、問いの出し方の設定です。研究の計算の土台になるためで、あなたがその時間に何をしていたかは含みません。
- 直前の時間帯を消すときは、一時停止せずに、記録したまま消してください。一時停止中は、いちばん新しい記録だけは消せません（再開すると消せます）。

3 番は「送る前」と「送ったあと」で手順が変わります。記録は 1 日ごとにひとまとまりにして、そこから 48 時間おいてから研究者へ送られます（§5）。

| いつ | どうなるか |
|---|---|
| 送られる前（その日と、その次の 2 日ほど） | あなたの端末の上で消えます。研究者に届きません |
| 送られたあと | 研究者に「消してください」とお伝えください。研究者側で削除し、削除したことを記録に残します（あなたの端末の操作だけでは消えません） |

どちらの場合も、理由を説明する必要はありません。

## 4-2. 参加をやめる

- 参加はいつでもやめられます。やめても不利益はありません。
- アプリの画面で「問いへの同意を取り消す」を押すと、問いは出なくなり、参加をやめたことになります。そのあとはアプリを終了し、自動で起動する設定を切って、研究者にお知らせください（切り方は配布フォルダの説明書にあります）。
- 取り消しても、アプリを終了して自動で起動する設定を切るまでは、操作の記録は続き、研究者へ送られます（後半の期間なら画面の表示も出ます）。研究者は、取り消した時刻より後の記録を削除し、研究に使いません。
- やめるときに、それまでの記録を研究に使ってよいか、すべて削除するかを選べます。削除を選んだときは、§4 の手順で、送られる前の分も送られたあとの分も削除します。
- すべて削除を選んだときも、同意のフォームへのご回答（同意したことの記録）と、削除したことの記録は残ります。公表した後の数値は取り除けません（§5-2）。

## 5. 記録の保管

- 記録はまず、あなたの端末の中だけに保存します。クラウド同期フォルダ（OneDrive 等）には置きません。
- そのうえで、1 日ごとにひとまとまりにした記録を、48 時間おいてから暗号化して自動的に研究者へ送ります。
  - なぜ自動なのか: 手作業でまとめて送っていただく形だと手順が多く、続けていただくのが難しいためです。
  - なぜ 48 時間おくのか: 送る前なら、あなたが「この時間帯を消して」と言えば端末の上で消えるからです（§4 の 3 番）。
  - 送るのは §3 に書いた記録だけです。本文・画面の内容・アプリ名は入っていません。
  - 送信を止めたいときは、いつでもお申し出ください。止めるまでのあいだに送られた分は、お申し出があれば削除します。
- 記録は P0xx のような記号で管理し、氏名・連絡先とは別に保管します。
- 保管の上限:
  - 暗号化した記録 … 受け取った日から 2 年
  - 研究者が復号したもの … 解析が終わってから 30 日以内
  - 個人が特定できない集計値 … 論文発表から 5 年
  - 上限に達したものは、お申し出が無くてもこちらで削除します。

## 5-2. 結果の公表について

- 記録と、記録から計算した値は、この研究（今回の確認と、のちに同じ手順で別の参加者に行う確認との比べ）にだけ使います。ほかの研究には使いません。
- 研究の結果は、論文や研究の応募書類などで公表します。公表するのは、記録から計算した数値と図、その計算のプログラムです。
- 参加者が少ないため、1 人ずつの数値と図を P0xx のような記号で示します。
- お名前・連絡先・記録した日付と時刻は入れません。お使いのパソコンの種類（Windows / Mac）や作業の種類は、それを示すと誰の結果か分かるおそれがあるときは示しません。公表の前に、研究者が数値と図からあなたが分からないことを点検します。
- 研究者は、記号とあなたとの対応を知っています。点検しても、あなたを知る人が推し量る可能性を完全になくすことはできません。そのため、公表の前に、あなたの分の数値と図をお見せします。載せないよう求めていただければ、あなたの分は載せません。
