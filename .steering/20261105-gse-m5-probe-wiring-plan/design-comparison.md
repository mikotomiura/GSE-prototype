# 設計案の比較（/reimagine 1 回目・2026-11-05）

v1 はメインが書いた。v2 は v1 を読ませない別のエージェント（Opus）が要件と一次資料だけから書いた。食い違う主張はメインが一次で確かめた。

## v1 の要旨

O1 の変種として作る（`o1.mode` の隣に `s1.mode`・`meta` に `o1_variant`）。起点は「今のログファイルを開いた時刻」。今の `ProbeScheduler` に棄却の理由を返す `poll_outcome` を足して使い続け、層化（`probe_stratify.rs`）と調停（`probe_arbiter.rs`）と日の問い（`daily_check.rs`）を別々の純粋な関数に置く。同意の承認は配布フォルダの印。トレイの終了は日の問いの契機にしない。

## v2 の要旨

O1 の上に載る層として作る（EH3 と同じ作り。`s1.rs`・`meta` に `s1_mode`・EH3 との同時は立てない）。起点は `O1_LOG_OPENED_MS` と世代の数。無作為の枠は seed と起点だけで決まる候補の列（`RandomFrame`）に作り直し、`probe_frame` 行に seed と定数を残して記録から厳密に再現する。調停は 1 つの `Arbiter::tick`（無作為 → 層化 → 日の問いの順・後ろは前を読むだけ）。同意は本人が登録の画面で押した印。overlay の窓を段 1 で `show()` する。自分の窓へのフォーカスの遷移を除く。

## 主要な差異

| 観点 | v1 | v2 |
|---|---|---|
| モードの作り | O1 の変種（`o1.rs` の中に `O1Variant`） | O1 の上の層（`s1.rs`・EH3 の先例に揃う・EH3 との衝突を扱う） |
| 無作為の時刻の再現 | 今の `ProbeScheduler`（次の候補が `now + interval` でポーリングに依存・`probe_scheduler.rs:392-393`）。seed は trace にだけ残る | 候補の列を seed と起点に固定し、`probe_frame` に seed を書く。`gse-replay --probes` で厳密に照合できる |
| 調停の置き場 | 3 つのモジュール | 1 つの `Arbiter::tick`。順を固定し「後ろを外しても前の列が等しい」を検査 |
| 同意の承認 | 配布フォルダの印 `s1-consent.approved`（研究者が置く） | 本人が登録の画面で押した `~/.gse/s1_probe_consent`（ADR-043 D7 の「参加の条件」に近い）＋配布物の門で同意文書の承認の印 |
| 画面の窓 | 見落とし（O1 では overlay が `show()` されない・`lib.rs:3677`） | 段 1 で `show()` し、既存の退避に任せる |
| フォーカスの遷移 | 見落とし（カードを押すこと自体が `resumption` の引き金になりうる） | `eh3::focus_row_allowed` で自分の窓を除く |
| 一時停止の検査 | 「名前の列挙なので足す」と書いた（誤り。`recording.rs:15-23` は `KNOWN_LINE_TYPES` から導く） | 自動で入ると正しく書いた |
| `GSE_DISABLE_PROBES` | 触れていない | 段 1 では見ない（自動起動と挙動をそろえる・研究者に確かめる） |
| 日の問いの補助の契機 | 一時停止で即座に出す・トレイの終了は使わない | 一時停止は再開の直後に予約・トレイの終了は「答えて／答えずに終了」で最大 60 秒 |
| 層化の重なり | `resumption` を優先 | `low_operation_end` を優先 |
| 新しい行種 | `probe_suppressed`・`daily_check`・`probe_holdout` | `probe_frame`・`probe_suppressed`・`day_question`（問わない区間は `probe_frame` の値と抑制の理由で表す） |
| 変更規模 | 中 | 中〜大（`RandomFrame` の作り直し・overlay の表示・同意の画面・`s1.rs`） |
| テスト | 14 項目 | 名前つきで約 40 項目。記録からの厳密な照合を含む |
| リスク | 段 1 の画面が出ない・再現できない、を実装の途中で踏む | `RandomFrame` が今の `ProbeScheduler` と別物になり、Phase1 の数え方（同じ分布だが列が違う）との比べに注記が要る。変更の面が広い |

## 推奨案

v2 を土台にしたハイブリッド。理由:

- v1 は画面の窓・自分の窓へのフォーカスの遷移・一時停止の検査の 3 点で一次の事実を外していた。v2 はこれらを一次の行で押さえている。
- 無作為の枠を記録から厳密に再現できること（`probe_frame`）は、段 1 の主の申告（無作為の枠）の監査に効く（ADR-031 D2・判断 8 の「層化で時刻を動かさない」を記録で示せる）。
- O1 の上の層は EH3 の先例があり、`is_o1()` の分岐を 1 つも分け直さずに済む。

v1 から残すもの:
- 状態ファイルの IO を `analysis/` の外（`s1_day_state.rs`）に置く（v2 の変更対象表は `analysis/` に入れていたので、メインが design.md で直した）。
- 研究者に確かめる項目は v2 の 13 項目に、v1 の「判断 9 の理由の列の拡張（`card_open`・`superseded`）」が含まれているので、追加は無い。
