- Windows のポインタ: 観測スレッドのループが、`GetRawInputBuffer` で読む前に `PeekMessageW(..., 0, 0, PM_REMOVE)` で `WM_INPUT` を取り除いている（`src-tauri/src/input/observe_windows.rs` の `start`）。Microsoft のバッファ読みの手本は `WM_INPUT` を取り除かずに残す（*Using Raw Input*・`GetRawInputBuffer` の Remarks）。仮説で、Windows の実機では確かめていない。確かめと直しは G-GEAR（`.steering/_handoff/next-session-ggear-windows-pointer-raw-input.md`）。
- 本人以外の macOS の端末でポインタが記録されるかは、この Mac では確かめられない（本人の端末しか無い）。O1 に本人以外の macOS の人はいなかった。
- 観測 0 の本が多いこと（20261116 の R2・`feat` 行の書かれ方）は、このタスクでは確かめていない。

## 3 S1-E8 への響き

- 今の S1-E8 の一覧（A-1 判断 34）は基本の 5 つ（`ewma_x`・押下の数・BS の数・最長の間隔・フォーカスの遷移の有無）で、ポインタは記述。リズムを採れば 1 つ足す、としていた。
- 上の結果からの Claude の推奨: 一覧は基本の 5 つのまま確定し、リズムは足さない（検討の記録はこの節）。時間の感覚も足さない。ポインタは、Windows の記録が直るまで両 OS で同じ扱いにできないので、記述のまま。
