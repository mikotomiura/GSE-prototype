# requirement —— 段 1 の事前登録の改訂（ADR-047 Migration 3・ADR-048 Migration 3）

## 背景

- ADR-047（位置づけを「観測で見分けられる所と、保留すべき所」へ）と ADR-048（手跡を保留の裏側の柱に・日の終わりの問い）は、段 1 の事前登録 `docs/preregistration-stage1.md` に項目を足すことを別タスクに回した（ADR-047 Migration 3・ADR-048 Migration 3）。
- 引き継ぎ `.steering/_handoff/next-session-gse-after-adr-047-048.md` §2-2。尺度の文の素材は S-DQ（`docs/literature/20261105-daily-end-of-day-items.md`・枝 docs/gse-daily-item-scale-literature）。

## ゴール

`docs/preregistration-stage1.md` に、次の項目を「決めてあること・値（未定）・決め方・出典」の形で足す。値は R5（研究者本人の探索）の後で決めるので空欄のまま。凍結はしない。

- ADR-047 D1・D2: 見分けと保留の評価の量・許容する誤り・条件を見つけるデータと確かめるデータの分け方・適格の条件へ移す規則（契機の時点までの観測だけで評価し直す）・規則の凍結の時期。
- ADR-047 D3: 停滞の長さと型の層、件数の内訳と時間の内訳。
- ADR-047 D5: 本人を除く 2〜4 名の選び方（作業の様式の対照）。
- ADR-047 Consequences（codex-consult の残り）: 申告を求めない区間・回答率の層別。
- ADR-048 D3: 日の終わりの問い（契機・拾い直し・遅れた回答の印・欠測と回答率・回答の後の作業の感度分析・項目）。節 F の S1-F3。
- ADR-048 の決めずに残すもの 2・3: 同期の感覚と速さの区別の対照、前日の条件と順序の扱い。

## 受け入れ条件

- 上の各項目が節と番号を持ち、§4 の出典の対応表に行がある。
- 値は空欄（未定）で、決め方を書いている。新しく値を決めていない。
- ADR の言い方（「詰まる前に」と書かない・推定は契機を作らない・3 状態の名前を主張に使わない・「作業上の」）に従う。
- code-reviewer と /cross-review を通す。

## スコープ外

- 値を埋めること・凍結・attack-me（R7）。
- ADR の本文の変更（ADR-048 の出典の書き間違いは記録に残すだけ）。
- 同意文書（2-3）・コード。
