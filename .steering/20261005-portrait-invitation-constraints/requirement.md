# 肖像と招待の設計制約の台帳と決定 ＋ 情報回避・無視の罪悪感・促しへの反発の小さなサーヴェイ

## 背景

- 前のタスク `../20261005-motivation-reentry-survey/`（S-MR）で、研究者の気付きから核を磨き、具体案 v0 を `.idea/20261005-motivation-fatigue-reentry-surface.md` §8 に書いた。研究者の方針は「核を今後の GSE 研究で検証する」（同 decisions.md 判断 6）。
- 研究者が感じている制約と課題（2026-10-05・要旨）:
  1. タンジブルな要素として、作業をワクワクさせる面を作りたい。ただし邪魔にならないよう、1 台の PC で完結させたい。
  2. 停滞に近いときの身体回帰への招待と、ワクワクの面を、分けて考えるべきか。
  3. 招待や状態の表現が固定的なラベルであらかじめ決まっていると、自分の状態を突き付けられる感じになり、「見たくない」と避ける心理がありそう。
  4. 招待を無視したときの罪悪感など、受け入れられるための心理的な制約も考えたい。
  5. （追加）物体そのものの必要性も、あわせて議論したい。
- 既に決まっていること（ADR）: 本人に自分の量を返さない（ADR-025）・PC の招待面の要件 12 本（ADR-026）・応答を成功として戻さない（ADR-033）・招待の有無と時期を本人が統制する原則（ADR-035・Proposed）・応答のどの分岐にも正誤を付けない（選択の対称性）。
- 穴: 自分の状態の表示を避ける現象（情報回避）の一次は `references.md` に 0 本。招待・通知を無視したときの罪悪感の一次も repo に無い。

## grill で決めたこと（2026-10-05・研究者・AskUserQuestion 2 回・すべて推奨どおり）

| 論点 | 決定 |
|---|---|
| 招待と肖像の分け方 | **役割で分ける**: 肖像 ＝ ワクワク（評価されない驚き・状態を表さない・壁紙＋小面）／ 招待 ＝ 身体回帰への誘い（別の小さな要素・ADR-026 / 035） |
| タンジブル | **まず PC だけで作る**（EH1・EH2）。机上の物体は第 2 候補として残す。画面の質感は本物の触覚ではないと明記する |
| 範囲 | **台帳 ＋ 決定 ＋ 小さなサーヴェイ** |

## ゴール

1. **制約の台帳**: 肖像・招待・物体にかかる既存の制約（ADR・再査定・S-MR のカード・既存の文献カード）を 1 枚にまとめる。各行に出典（ADR の D 番号・`[Pn]`・ファイル:行）を付ける。
2. **決定**: 次を decisions.md に「決定 / 理由 / 却下案」で記録する（研究者に推奨と理由を添えて聞く）。
   - 状態のラベルの方針（肖像はラベルを持たない・招待は理由や状態を言うか）
   - 招待を無視したときの扱い（罪悪感を生まない出し方）
   - 物体の必要性（要るか・要るならどの条件で・何が PC では代えられないか）
   - 上の決定から出る、EH1 の設計の制約と EH3 で測るもの（回避・罪悪感・反発）
3. **小さなサーヴェイ**: `/literature-review` の 1 ラウンド（3 angle・情報回避／無視の罪悪感／促しへの反発）。カード・`references.md`・`_index.md`。
4. **`.idea/` への還元**（版管理外）。

## スコープ

### 含むもの
- 台帳・決定・サーヴェイ・`.idea/` の更新
- 用語が固まったら `docs/glossary.md` への追記（例: 「予期しない・評価を含まない驚き」）
- コミット・push・`/cross-review` 2 巡

### 含まないもの
- 実装（合成 trace・描画・壁紙の更新）＝ EH1 は別のタスク
- ADR の起票・`docs/research-positioning.md` と `docs/architecture/expression-channel.md` の改訂
- G1/O1 の収集・配布物の変更
- AI 疲労 DB の側の作業
- PR（計測の run 中なので push だけ）
