# 研究者の試視 —— 背景の層の自然世界とポインタ（10〜15 分）

起動と「開始する」は Claude が行います。見え方は口頭で伝えてください（results.md §5 に書きます）。

## 0. 起動の形（Claude が実行）

```bash
cd /Users/johnd/GSE-prototype-handmark-stage
export GSE_DATASET="$(mktemp -d)/gse-spike"
env -u GSE_HANDMARK_SPIKE_MEASURE -u GSE_HANDMARK_STAGE_SPIKE_SYNTH_POINTER -u GSE_HANDMARK_STAGE_SPIKE_POINTER_OFF \
  GSE_HANDMARK_SPIKE=1 GSE_HANDMARK_STAGE_SPIKE=1 GSE_DEBUG=1 VITE_GSE_DEBUG=1 npx tauri dev
```

- あなたのカーソル・クリック・ホイールは背景の描画にだけ使い、どこにも書きません（ADR-040）。計測の CSV もありません。
- セッション中は、本体がいつもどおり打鍵の時刻とキーの種類、O1 のポインタの 1 秒ビンを NDJSON に書きます。書き先は上の一時フォルダで、終わったら Claude が消します。
- 背景は壁紙の上・アイコンの下に、霧の帯・漂う粒・画面の下 3 割の草として出ます。
- トレイ（メニューバーの GSE）に「背景: カーソル」「背景: クリック」「背景: ホイール」の入れ切りと「背景を閉じる」があります。

## 1. 見てほしいこと

いつもの作業を打ちながら、ときどきデスクトップが見える状態にして、カーソルを動かす・デスクトップの空いた所をクリックする・ホイールを回すを試してください。

| # | 見るもの | 聞きたいこと |
|---|---|---|
| 1-1 | 草の近くでカーソルを動かす | 近くの草だけが動いた向きへなびくか。止めるとすぐ静まるか |
| 1-2 | 上の方でカーソルを動かす | 動かしている間だけ粒が寄り、止めるとほどけるか |
| 1-3 | デスクトップをクリック | その場に波紋が立って消えるか。窓の上でクリックしたときの、縁から見える波紋をどう感じるか |
| 1-4 | ホイールを回す | 粒が縦にずれて戻るか。どちらへ回すと上がるかに違和感はないか |
| 1-5 | 全体 | どの動きが自分のどの手の動きから来たか分かるか。入力を足すほど「自分の作業が一緒にいる」に寄るか、騒がしさに寄るか（トレイで切って比べる） |
| 1-6 | 実物の壁紙の上 | 見本（Version 5）と比べて、見え方・強さはどうか（強すぎ・弱すぎ） |
| 1-7 | 何もしない間 | 霧と粒の漂いが、カクつきとして気になるか（入力が無い間は 1 秒に約 10 回に絞っている） |
