## 背景

音・表現層トラック（`20260810-media-sound-modality-and-creative-tooling`）は
**表現層だけを見て全体を語っていた**。研究者から 2 つの指摘が入った:

1. 現行アーキ全体（入力層 → MhD 推論 → 表現層 → Physical Anchor）に対する
   **社会的インパクト・意義の整理ができていない**。AI 依存・不便益を最初に意義として掲げたが、
   **現状のアーキで何が言えて何が言えないか**が突き合わされていない。
2. **認知の核の確保候補**（常時オンラインの個人適応・作業内容ごとの学習/推論の振り分け）を
   **ちゃんと把握しているのか**。`.idea/` と `docs/` にあるはず。

→ 実際、`docs/architecture/personalization-and-online-learning.md`（104 KB・リポジトリ最大）と
`.idea/20260801-behavioral-context-online-latent-ml-design.md` は**一度も読まれていなかった**。

続けて 4 つの問いが出た:

3. **どうやって「認知を読ませる形」にして、推定 → オンライン学習 → メディア表現までつなげるか**
4. **現状、推論が読んでいる入力は具体的に何か**
5. **正規化の β もタスクごとに変えるべきではないか**
6. **まずは G1 で打鍵のみの有効性を測っている**（現状認識の確認）

## ゴール

1. インパクト／意義を**層ごとに・証拠の温度つきで**整理する（→ `impact-and-core-map.md` A 部）
2. 認知の核（MhD）の確保候補を**振り分け・癖の分類・反証ゲートまで**整理する（同 B 部）
3. ★ **入力層 → 推定 → オンライン学習 → メディア表現の接続設計**を出す（→ `design.md`）
4. **推論が実際に読んでいる入力を一次資料（コード）で確定する**（docs を根拠にしない）
5. β とタスクの関係について、**既存の決定（ADR-006）と実測の含意**を突き合わせる
