## §1 ★★★ リアルタイム性について — 前回の判断を一部訂正する

研究者の指摘: **「メディア表現はリアルタイムで変わっていくのがメディアアートの醍醐味では」**。

### 1.1 ★ α を退けた理由を精査すると、「リアルタイム」は理由に入っていない

D13 で案 α（常時ドローン）を退けた根拠を並べ直す:

| 退けた理由 | 実際に何を否定しているか |
|---|---|
| [P66]「難しい課題に有害」「系列再生に有害」 | ★ **作業中の聴覚曝露** |
| [P56] 意志で無視できない自動捕捉（金銭報酬でも消えず・ηp²=0.48） | ★ **聴覚固有の性質** |
| HIR を機械的に押し上げる | ★ **作業への割り込み** |
| 第 1 版の視覚単独と交絡する | ★ **実験デザインの都合** |

> ★★★ **どれも「リアルタイムであること」を否定していない。否定されているのは「作業中に音を鳴らすこと」である。**

### 1.2 ★★★ そして視覚には changing-state ペナルティが無い

文献カード §4 の非対称表（本編・追補 2 で確定済み）:

| | 聴覚 | 視覚（周辺） |
|---|---|---|
| 無視するコスト | ★ ほぼ不可能（自動捕捉・報酬でも消えない）[P56] | ほぼゼロ（視線を外す） |
| ★★ **状態に応じた変化のコスト** | ★★ **changing-state ペナルティ**＝系列的言語処理を壊す [P57] | ★★ **対応する現象が無い** |
| 実運用での終わり方 | チャネルごと停止される [P55]（不可逆） | 見られなくなる [V34]（可逆） |

> ★★★ **「リアルタイムに変わる」ことのコストは、視覚では文献上ゼロである。**
> **β（セッション後）は聴覚固有の制約への回答であって、視覚表現には適用されない。**

### 1.3 ★ 帰結 — 媒体を画面内（＝視覚）に決めたことで、リアルタイムは取り戻せる

D17 で媒体は **画面内（既存 `Overlay.tsx`）＝視覚**に決まっている。したがって:

> ★★★ **視覚表現は α（常時・リアルタイム）で作ってよい。β にする必要があるのはドローン（聴覚）だけである。**

★ **既決 7（de-risk pilot 第 1 版は視覚 1 モダリティ）と何も衝突しない**——
第 1 版はもともと視覚単独なのだから、**その視覚をリアルタイムにすることは既決の範囲内**である。
**音との交絡を避けるという既決 7 の理由は、視覚のリアルタイム化を禁じていない。**

**改訂後の分業**:

| 層 | 形 | 理由 |
|---|---|---|
| ★ **視覚（画面内）** | **α = 作業中・リアルタイム** | changing-state ペナルティが無い。**メディアアートとしての醍醐味はここで満たす** |
| **聴覚（ドローン）** | **β = セッション後** | ISE・自動捕捉・HIR は聴覚固有。第 2 版として単独条件で測る |
| **Physical Anchor** | 出口（不変） | D8: 表現層だけにすると information 系へ落ちる |

⚠️ **視覚リアルタイムの固有リスクは別にある（消えていない）**:
- ★★ [V34] TimeAware は**デスクトップ知識労働者向けの常時表示アンビエント自己追跡**の 8 週フィールド（N=24・ABA）で、
  **撤去 2 週で効果消失**した。第 2 版 §4.1 は媒体 A（常時反応する小型ランプ）を
  **「[V34] の直接の再実装であり対照条件としてのみ」**と判定していた。**常時表示は空白ではない。**
- **サリエンスの段階化（光が強くなる・濃くなる）に落ちると [V40] information 系（d=0.00・BF01=33.84）**。
- → ★ **差別化の軸は既に手元にある**: **D16（3 状態を肯定可能な語彙へ分散）** ＋
  **`reference_deviation`（自分の通常との並置）**。
  ★★ **[V34] が出していたのは「生産的時間の割合」という規範的な数値**である。
  **GSE は規範を持たない自己参照表現**なので、**枠の軸自体が存在しない**——ここが構造的な差分になる。

### 1.4 ★ そもそも α / β は二値ではない — 2 軸に分けると空きセルが見える

| | **リアルタイムに応答する** | 応答しない |
|---|---|---|
| **作業中に存在する** | ★ **α**（視覚なら可・聴覚は不可） | 定常 = 情報を運ばない（否定済み） |
| **作業中に存在しない** | ★★ **空きセル**（下記） | **β**（圧縮再生） |

★★ **空きセル =「作業していない時間にリアルタイムで応答する」**——
**休憩中・離席中（Physical Anchor の時間）に置く表現**である。
`.idea` §2 の **案 B（音を作業中から外し回復側に置く）**が既にこの位置を指しており、
[P60]（自然音はストレス・不快を下げる。CI が 0 を跨がない側）と [P2] Bratman（自然曝露が反芻を下げる）が
**同じ向きに働く**。★ **反芻リスク（第 2 版 §4.4 の最大リスク）を下げる側に効く可能性がある唯一の配置**。

### 1.5 ★ β 自体もリアルタイム化できる — 「圧縮再生」でなく「スクラブ」

β を「30〜60 秒に圧縮して聴く」と定義したが、**圧縮は β の必要条件ではない**。

| 形 | リアルタイム性 |
|---|---|
| 圧縮再生（現行案） | 無し |
| 等倍再生 | 無し（かつ長すぎる） |
| ★ **スクラブ可能にする** | ★★ **鑑賞者が時間軸を操作し、その操作に音がリアルタイムで応答する** |

★ **これは新しい実装を要さない**——`design.md`（音トラック）§2.7.1 の試作手順が
**既に「TouchDesigner の Table DAT で読み、タイムラインをスクラブしながら音を鳴らす」**である。
**試作の道具立てがそのまま鑑賞の形になる。**

> ★★ **区別しておくべきこと**: 「**リアルタイムに状態が変わる**」（α）と
> 「**リアルタイムに鑑賞者が変える**」（スクラブ）は別のインタラクティビティである。
> [P67] Eno の定義——*"must be able to accommodate many levels of listening attention
> without enforcing one in particular"*——は**前者を要求していない**。
> **後者だけでも「醍醐味」は成立しうる**（ただしこれは設計判断であり、文献の裏付けは無い）。

### 1.6 ⚠️ リアルタイム化しても絶対に動かしてはいけないもの

★★ **「リアルタイムに適応する表現」と「リアルタイムに調整する開発者」は別物である。**

| フェーズ | マッピングを動かしてよいか |
|---|---|
| 試作・デザイン探索 | ★★ **よい。これが TouchDesigner の本来の用途** |
| ★★ **pilot / 実験の実施中** | ★★ **絶対にだめ**（ADR-008 D4 / prequential [V64] / 適応的デザインの事前規定 [V65]） |
| 実験と実験の間の改訂 | よい。ただし **`EXPR_VERSION` を刻む** |

## §3 ★ 設計として進化させる案

| # | 案 | 中身 | 温度 |
|---|---|---|---|
| **B1** | ★★★ **視覚 = リアルタイム / 聴覚 = セッション後の分業** | §1.3 | ★ **文献の非対称に接地**（視覚に changing-state ペナルティが無い） |
| **B2** | ★★ **表現層に「今はもがきたい」を第一級で置く** | 表現層が「介入が近い」を示すだけなら **information 系**に落ちる。しかし**それに対して本人が「今はもがきたい」と答えられる**なら、**選択環境の変更＝structure 系**になる。★ **[V33] one sec の効果源が「10 秒の friction」ではなく「dismiss option の第一級提示」だった**のと同型 | ★★ **計器が既にある**——`dismiss_reason` に **`want_to_struggle`** が存在し、`not_stuck`（Need 過検出）と区別して **Opportunity 誤りの分離**に使われている |
| **B3** | ★★ **表現層を `reference_deviation` に接続する** | 「適応後の値」でなく「その人の通常からの逸脱」を写すことで、**個人適応が進んでも表現の意味が保たれる** | ★ [P48]「**自分の通常と並置された抽象**」と**同じものを別の語彙で言っている** |
| **B4** | ★ **系統 B（観測直結）だけで表現層の de-risk を先に回す** | `keys` 密度・沈黙長・BS 率は**推定を通らない**ので **GATE3 の可否と無関係** | ★ **MhD が Kill でも表現層が独立に立つ**（`design.md §4.2`） |
| **B5** | ★ **次の統制実験はブロック数を permutation の到達可能性から逆算する** | ★ **G1 が自ら「最も重要な弱点」と書いているのは検定の到達可能性**——C(8,4)=70 の離散性により **主判定は事実上 AUC ≈ 1.0 を要求**しており、**AUC 0.75–0.85 の「本物だが中程度」の効果は『分離できない』と報告される** | ⚠️ **G1 自体は凍結済みなので変更しない**。次の統制実験（G2 系）への教訓として持ち越す |
| **B6** | ★ **量子化（obs 26）は新軸で自然に消える** | 現行は 5×5 ビン＋BS penalty で情報を捨てているが、**Phase C は連続 `context` を直接受ける** | 新規の作業を要さない（軸の移行に含まれる） |
