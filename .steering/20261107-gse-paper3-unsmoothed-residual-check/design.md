# 設計（第 2 案・/reimagine で要件だけから作り直した案）

## 実装アプローチ

要件の芯は 2 つ。(A) 記号化の作りが依存を作る分を、平滑を外した列 u と窓の重ならない列 n で見分ける。(B) 当てはめたモデルが運べていない依存を、擬似残差の自己相関で測る。どちらも、論文の読者が公開の生データと公開の kit から作り直せることが前提になる（判断 13）。そこで次の 4 つを柱にする。

1. 列の定義を公開の kit に置く。u と n の規則は実験のコードではなく `papers/per-person-learning/kit/symbols/variants.py`（新しい）に書く。記号器 `symbolizer.py` は、tick の中で計算した平滑前の値を属性 `last_raw` に残す 2 行だけを足す（返す行は変えない）。`variants.py` は `symbolize` と同じ入口で、行ごとに (t, o, u, x_raw, y_raw) を返し、n の印を付ける。
2. 当てはめの数式は書き直さず、tau-extend の `hmm2.py`・`data.py` を写さずに読み込む（`sys.path` に tau-extend の `scripts/` を足す）。読み込んだファイルの SHA-256 を provenance に刻み、run.sh の頭で tau-extend の時点のコミットの値と照らす。新しく書くのは、列を選ぶ読み込み・範囲を絞った駆動（`fit.py`）・残差（`residual.py`）・集計（`report.py`）だけ。
3. 当てはめと残差を 2 段に分ける。`fit.py` は書き手ごとに、共通（w を除く）・本人（τ の 9 値）・r1 の母数を repo の外の npz に書く（人は開かない）。`residual.py` はその npz と評価の単位だけを読み、擬似残差の自己相関を出す。round 2 の査読で別の検査を求められても当てはめ直さずに済む。
4. 実行の順は n → o → u。n は短いので実データで配管を最初に通す。o は P-REPRO の門（tau-extend と一致）で、外れたら u に進まない。

### 列の規則（kit の `variants.py`）

- o: 記号器の symbol（今の出力）。
- u: `grid_symbol(x_raw, y_raw)`。その行の o が 25（連打の記号）なら u も 25。
- n: 系列（CoAuthor はセッション・CS1 は作業のまとまり）の最初の行の時刻を s とし、時刻が s + 30 秒 · j（j = 1, 2, …）にちょうど当たる行だけを採る（その秒に行が無ければその j は飛ばす）。採った行の 30 秒窓 [t − 30 秒, t) は互いに重ならない。記号は u。
- 書き残すこと: u・n でも、休止の秒の特徴は「最後の押下からの秒」と「直前の打鍵の文脈」に依り、窓をまたぐ記憶が残る。n は「平滑と窓の重なりを外した列」で、依存の出どころをすべて外した列ではない。

### 中間（Mac で作る）

- Mac で `variants.py` を全セッション・全課題に走らせ、feat 行ごとに u・x_raw・y_raw・n の印を足した中間を repo の外に書き、manifest で HP Z2 へ渡す。
- 門 P-U（Mac）: variants の (t, o) と、今の中間の feat 行の (t, obs) が全行で一致し、variants の平滑後の x・y が中間の ewma_x・ewma_y と bit まで一致する。出すのは行の数と外れた行の数だけ。

### 当てはめ（`fit.py`・HP Z2）

- 構造 hmm3・ar1〜ar3、τ の 9 値、行は τ 固定・τ 他人・2 段（他人）。相手は同じ構造の共通と r1。パネル CoAuthor P15（k = 1・5・15）・CS1 C5（k = 1・5）。
- 乱数の流れは tau-extend と同じ形にし、作らない k・折り目・外した構造の番では乱数だけを引いて捨てる。o の列は tau-extend と同じ値になる（P-REPRO）。u・n も同じ流れを使う（データが違うので値は違う）。

### 擬似残差（`residual.py`）

- 1 歩先の予測分布（`hmm2.pred_dist` と同じ前向き）を、25 を除いて正規化し、x の帯・y の帯の周辺に畳む。観測の帯 b で U = F(b − 1) + v · (F(b) − F(b − 1))、z = Φ⁻¹(U)。v は共通の乱数（同じ書き手・列・評価の時刻なら、どのモデルでも同じ）。観測が 25 の時刻は欠け。
- 量（書き手ごと）: 遅れ 1〜10 の自己相関（系列の中の組だけ・欠けを含む組は数えない）、z の平均と分散、25 の割合。副として、押下のある秒だけの組の遅れ 1（休止の秒が支配するという R1 の指摘への材料）。
- モデル: 同じ構造の共通（4 構造）・本人（τ 他人）・2 段（他人）で選ばれた (s, τ)・r1。
- 集計: 中央値・四分位（tau-extend と同じ `inverted_cdf`）。

### 読みの形（判断 5 を条件の D5 に書く）

- 主のセル P15 k = 5・P15 k = 15・C5 k = 5、全記号の中央値。量は C1 の G（hmm3 本人 − hmm3 共通）、C2a（hmm3 本人 − r1）、C2b（2 段 − r1）。
- u: o と同じ向きで |u| ≥ |o| / 2 は「残る」、同じ向きで |u| < |o| / 2 は「縮む」、逆向きは「逆」。n: 向きだけ。3 セルで揃ったときだけ、その語で書く。
- 残差: 各列・各セルで、遅れ 1 の自己相関の中央値を hmm3 の共通・2 段で選ばれた構造の共通・r1 で並べ、ar の |r_1| が hmm3 の |r_1| より小さいかを書く。
- 閾値と検定は置かない。
