# Coding form: column dictionary

Generated by make_coding_form.py from c_synthesis.py. Each coder fills in one copy of each file, named
`<file>_coder1.csv` and `<file>_coder2.csv`; the reconciled copy is `<file>_reconciled.csv`; `links.csv`
is shared. Cells are never left empty except where stated: a missing value has its own code and stands
alone in a cell. Multi-value cells separate values with `|`, each value once. The rules for choosing a
value are in the registration and the C2b codebook.

| Column | What is coded | Values accepted | Multi-value | May be empty |
|---|---|---|---|---|

| `boundary` | 1 if the item is a boundary item. | 0, 1, unresolved |  |  |
| `secondary_type` | C2b secondary type of a boundary item (empty otherwise). | AVO, FAT, FUT, IRR, MOT, OTH, unresolved |  | yes |
