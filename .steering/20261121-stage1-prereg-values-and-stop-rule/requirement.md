# 段 1 の事前登録の値と終了判定の script（stage1-prereg-values-and-stop-rule）

## 背景

- 3 名の段 1 の開始は早くて 12 月中旬。いちばん重いのは事前登録 `docs/preregistration-stage1.md` の凍結で、§2 の値の多くが空欄のまま（引き継ぎ `.steering/_handoff/next-session-gse-stage1-prereg-values-and-stop-rule.md`）。
- ADR-052 D4 の関門 4 は「事前登録の値が本人の記録で埋まった」こと。本人の後期（11-24〜12-08）のあいだに、後期に関わらない値を先に埋めると開始が前に出る。
- 終了判定（各人の最低の件数・期間に届いたか）はスプレッドシートで計算しない。特徴量が外に出るうえ、seed と版の規約から外れる。repo の script（`experiments/` 配下）で研究者の手元で回し、管理シートには件数と判定だけを載せる。
- 研究者の選択（2026-11-21）: 3 名の準備は「事前登録＋終了判定の script」から始める。

## ゴール

1. 未マージの事前登録の枝 2 本を main の版へ取り込む（判断 1〜3）。
2. §2 の値を「本人の記録で決める・設計で決める・後期の後でないと決められない」に分け、研究者に見せる。
3. 設計で決める値と、本人の記録の要約で決められる値を、研究者に 1 件ずつ聞いて埋める。
4. 終了判定の script を書き、陽性対照で縛り、本人の記録で回して要る日数の見積もりを研究者に示す（探索・ADR-043 D3）。

## スコープ

### 含むもの
- 事前登録の本文の取り込みと値の記入（凍結はしない）
- `experiments/<日付>-stage1-stop-rule/` の script・陽性対照・本人の記録での見積もり（件数・率・区間の幅・判定だけ）

### 含まないもの
- 事前登録の凍結と attack-me（凍結の前に別に行う）
- F（手跡の後期）の値のうち回 2 の後でないと決められないもの
- 管理シートの列の追加・自動送信・受領台帳（3 名の版のタスク）
- S-DQ の文献の取り込み（枝 `docs/gse-daily-item-scale-literature` に残す・判断 3）

## 受け入れ条件

- [ ] 事前登録に 2 本の枝の中身が入り、`scripts/check_citations.py` に違反が無い
- [ ] 値の分け方の表を研究者に見せた
- [ ] 研究者が選んだ値が §2 に入り、選んだ経緯が decisions.md にある
- [ ] 終了判定の script の陽性対照（件数が足りない合成の記録で「判定不能」、足りる記録で「届いた」）がテストで縛られ、変異で赤になる
- [ ] 本人の記録での見積もりの出力が件数・率・区間の幅・判定だけで、日付に結びつく数を含まない
- [ ] /cross-review（Codex には記録の本文と集計を送らない）

## 守ること

- 本人の記録の中身・個々の申告・日ごとの割付を出力しない。Codex に記録の本文と集計を送らない。
- gse-next（`~/Desktop/S1_実施用_macOS/`）を止めない。
- ビルドの後は push の前に `target` を消す（空き 8 GiB の下限）。push・PR は研究者に確かめる。
