### 1.3 揺れの world `h(c)`

- **区間の設定**: `g(0.5)` と同じ（STRUGGLE の `flight_median_ms` 219.08902300206645・`flight_sigma` 0.3、ほかは v4）。停滞の強さを対数の尺度で `δ = ln(219.089… / 150) = 0.5 × ln(320 / 150) ≈ 0.3788` と書く。
- **打鍵の間隔の揺れ**: FLOW と STRUGGLE の打鍵の間隔（バーストの中の 1 打鍵ずつの間隔）を、`lognormal(ln(m_kind) + z(τ), σ_kind)` で引く。`z(τ)` はセッションの時刻 τ（セッションの始まりからの ms）の速さの対数のずれで、
  - `z(τ) = u + d(⌊τ / 1000⌋)`
  - `u ~ N(0, (c δ)²)`: セッションごとの倍率（`exp(u)` 倍）。
  - `d(k)`: 1 秒ごとの定常な Ornstein–Uhlenbeck の列。`d(0) ~ N(0, (c δ)²)`、`d(k+1) = ρ d(k) + √(1 − ρ²) · c δ · ε_k`（`ρ = exp(−1 / tau_s)`・`tau_s` 300 s・`ε_k ~ N(0, 1)`）。定常な標準偏差は `c δ`、相関は 300 s で `e^{−1}`。
  - したがって `z` の全体の標準偏差は `√2 · c δ`（c = 0.5・1・2 で約 0.268・0.536・1.071）。STRUGGLE の分の `δ` に比べて、c = 0.5 で漂いと倍率がそれぞれ半分、c = 2 でそれぞれ 2 倍。
- **掛けないもの**: バーストの長さ（時間で終わる・v2 と同じ）・バーストの後の間（`gap`）・訂正の率・押下の長さ・区間の構造。バーストが時間で終わるので、`z` が大きい（遅い）ほど窓あたりの打鍵の数は減る。
- **乱数**: `u` と `d` は区間と打鍵の乱数とは別の流れ `derive_rng(seed, "speed", <組>, i)` から引く（`u` を先に、次に `d` を 1 秒ずつ）。`<組>` はセッションを作る単位（下の表）で、同じ単位の 2 つのセッションは同じ `z` を共有する。`c` が変わっても `ε` の列は同じで、`z` は c に比例する（段の間で揺れの形は同じ・大きさだけが違う）。ただし打鍵の数が変わるので、区間と打鍵の乱数の位置は段ごとにずれ、区間の構造は段ごとに違う列になる（中間の design §1.3 と同じ・段の間は対にならず、独立でもない）。
- **組ごとの扱い**（`gen_sessions.py` の組）:

| 組 | `z` の単位 | 時刻 τ の起点 |
|---|---|---|
| P | セッションごと（`"P", i`） | セッションの始まり |
| O（`Oa`・`Ob`）と J | 対ごと（`"O", i`）。共有の末尾は 1 回だけ作るので、a と b で同じ打鍵になる | 共有の末尾は `prefix_s` から |
| D_shuffled（`Dsh`・`Jsh`） | 対ごと（`"Dsh", i`）。区間を作った時刻の `z` が区間の打鍵に入り、並べ替えた b では区間とともに動く（b の `z` は時刻について滑らかでない） | a の並び |
| D_diffend | 対ごと（`"Dde", i`）。共有の前半と、a・b それぞれの後半が同じ `z` の列を使う | セッションの始まり |
| D_continuous・D_sleep | セッションごと | セッションの始まり（眠りの区間も時刻を進める） |
| D_noobs | 揺れを掛けない（手で置いた打鍵） | — |

- そのために `markov`・`gen_segment`・`gen_typing`・`flow`・`continuous` に、区間の起点の時刻（ms）と速さの関数（`None` なら今までと同じ）を渡す。速さの関数が `None` のときは、乱数の引き方も出力も今までとバイト単位で同じにする。
- **c = 0 の両端**: c = 0 では `z ≡ 0` で、出力は同じ seed の `--world graded --t 0.5` とバイト単位で一致する（`u` と `d` は別の流れなので、区間と打鍵の乱数に触れない）。自己検査で確かめる（§3.7 への追加）。
- **宣言**（推論）: 揺れは、窓の速さの要約（打鍵の数・短い間隔の中央値・連なりの長さ）と停滞の関係を薄める。ただし (1) A_speed は前の 4 窓と直前 L 秒の要約を持つので、漂いが遅い（300 s）ことを使って、セッションの中の相対的な遅れを読める。(2) STRUGGLE は σ も 0.25 → 0.3 と大きくなり、短い間隔の四分位範囲と中央値の比は揺れの倍率に依らない。この 2 つのため、揺れの幅を大きくしても A_speed が天井に残りうる。それも下見 0 の結果として受け入れる。

## 9. Claude が足した細部（研究者が変えてよい）

研究者が決めたのは判断 1（倍率 ＋ 漂い・停滞の強さ `g(0.5)`・幅の 3 段・段ごとの下見 0 と天井の規則）。次は Claude が足した細部で、固定の前に研究者が変えてよい。

1. 幅の単位を停滞の強さ `δ` に合わせ、倍率と漂いの標準偏差をどちらも `c δ` にしたこと。3 段を c = 0.5・1・2（倍ずつ）にしたこと。
2. 漂いを 1 秒ごとの定常な OU 過程にし、時定数を 300 s にしたこと（区間の長さ FLOW 180〜900 s・STRUGGLE 120〜600 s と同じ桁・L300 の範囲と同じ）。時定数がもっと短いと窓の中の揺れになり、もっと長いと倍率と見分けにくい。
3. 揺れを打鍵の間隔（バーストの中）だけに掛け、バーストの後の間・バーストの長さには掛けないこと。
4. 組 O・Dsh・Dde で `z` を対ごとに共有し、Dsh の b では区間とともに `z` が動く（時刻について滑らかでない）こと。D_noobs には掛けないこと。
5. `SEED` = 20261020（判断 1）。
