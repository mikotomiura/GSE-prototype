## 判断 1: world の形

- **判断日時**: 2026-10-14（研究者・AskUserQuestion・4 問とも推奨どおり）
- **背景**: A_speed には前の 4 窓の打鍵の数と短い間隔の中央値、直前 L 秒の 5 量が入っている（`baseline.py` の `window_speed`・`span_speed`）。セッションごとの倍率だけでは、セッションの中の相対的な遅れが前の窓との比べで拾われ、また天井に当たる見込み（推論）。
- **採用**:
  - 作り: セッションごとの速さの倍率 ＋ セッションの中で状態に依らずゆっくり揺れる速さの漂い。FLOW と STRUGGLE の打鍵の間隔の両方に掛ける。
  - 停滞の強さ: g(0.5) に固定（STRUGGLE の中央値 219.08902300206645 ms・σ 0.3）。
  - 揺れの幅: 3 段にして結果の前に固定する。段ごとに下見 0 を回し、L300 で hgb と lr の両方の AUC(A_speed) が 0.90 以上の段は `ceiling`（判定不能）として先へ進めない（中間の world の design §3.0 と同じ）。
  - /reimagine: 使わない。固定の前の `/cross-review` 2 巡で見る。
- **選択肢（採らなかったもの）**: 倍率だけ・漂いだけ／停滞の強さを v2 か g(0.25) に／幅を 1 つ・下見 0 で幅を選ぶ（判断 16 に反する）／/reimagine を使う。
- **Claude の既定（研究者が変えてよい・design §9）**: 入れ物 `experiments/20261014-rhythm-stage-speed-confound-world/`。`SEED` = 20261020（下見 0 と下見 1 は +1、スモークは +2）。`experiments/*/SEED` と origin の全ブランチの `experiments/*/{SEED,config.json}` に 20261019〜20261029 が無いことを 2026-10-14 に確かめた。漂いの式と 3 段の幅は design で決める。

## 判断 2: 固定の前の `/cross-review` 1 巡目（design）の結果と対応（2026-10-14）
