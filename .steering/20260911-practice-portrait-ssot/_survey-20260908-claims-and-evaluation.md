## §5.3 新規性候補の最小命題（★ 逐語）

> 現時点で「世界初」とは書かない。調査と実作を経た後も、主張候補は次の接続に限定する。

> **日常の知的作業が暗黙に共同制作するセッション固有の生成肖像が、普段は周縁に留まり、
> 必要時には同じ作品の内部から画面外への開口を作る。その先の身体を測定・達成判定・報酬化せず、
> 作品が自らの計測権限を終える。**

続けて明示: 「これは『要素の組合せが見つからなかった』だけでは研究貢献にならない。
次を形式化し、比較し、反証できるところまで進めて初めて理論候補になる。」

形式化が要る 6 項目:
1. 実践生成肖像の必要条件
2. 交差写像がデータ可視化と異なる条件
3. 内在的開口が通知と異なる条件
4. 計測終端が単なるセンサ不足と異なる条件
5. 媒体を変えても保存すべき意味構造
6. 作品として成立しなかったと判定する失敗条件

## §5.1 それ自体では新規性にしないもの（★ 全 8 項目・逐語）

1. データから絵を生成すること
2. 顔以外のデータで人物を肖像化すること
3. スマホの壁紙／ロック画面をアンビエント表示に使うこと
4. ユーザー状態に応じて媒体を変化させること
5. 抽象表現によって内省を促すこと
6. 身体信号をメディア作品へ変換すること
7. 周縁から必要時に注意を中心へ移すこと
8. 閉ループでメディアを適応させること

⚠️ 各項目に「なぜ新規性にならないか」の個別説明は付いていない（箇条書きのみ）。
§6 の先行事例が実例として機能していると読める。

## §5.2 GSE で厳密化できる貢献候補（A〜E）

| | 貢献 |
|---|---|
| **A. 肖像論** | 累積データから「その人らしさ」を固定する data portrait ではなく、**現在の実践関係だけを描き、セッションとともに消える過程的肖像**を定義する |
| **B. 造形方法** | 本文非保存の行動時系列を、単一値へ対応させず、**経路差を保ったまま逆算不能な形態へ変換する交差的・非可逆な造形文法**を定義する |
| **C. 介入形式** | 通知を作品へ添えるのでなく、**同一作品の位相変化が選択肢を開く内在的開口**を定義する。表現と介入は別モジュールのままだが、経験上は断絶した二画面にならない |
| **D. 身体論・倫理** | 身体回帰を測定精度の改善で閉じず、**センサのない身体を作品の積極的外部とする計測終端**を定義する。データ欠損を埋めるのでなく、システムの認識権限が終わる形式として扱う |
| **E. bioadaptive media** | 推定状態を望ましい状態へ制御する閉ループだけでなく、**ユーザーが作品へ影響し、作品もユーザーへ働きかけるが、正しい意味と行為をシステムが完結させない開いた循環**を示す |

## §9 評価と反証（8 軸）

> 分類精度だけではアート理論を検証できない。少なくとも次を分ける。

| 問い | 成立側の兆候 | 失敗側の兆候 |
|---|---|---|
| 肖像として成立したか | 「数値」より、自分の作業の時間や癖との関係を語る | 状態ウィジェット、壁紙、診断表示としか読まれない |
| 本人性があるか | 同じ状態でもセッション間の違いを感じる | 色違いの三状態表示にしか見えない |
| 権威を閉じていないか | 表現を仮説として受け取り、異なる解釈や否定ができる | 作品が自分の真の内面を知っていると感じる |
| 周縁に留まるか | 通常時は作業の注意を要求しない | 作品を頻繁に確認し、第二の作業になる |
| 開口になったか | 通知文なしでも画面外の選択肢を感じる | 警告、命令、装飾的変化としてのみ読まれる |
| 計測終端が伝わるか | 画面外で追跡されていない安心と余地がある | 行動を見られている、採点されると感じる |
| 報酬化していないか | 作品を良くするために行動を変えない | きれいな形、完成、連続記録を目的にする |
| 外部が保たれたか | 離席、継続、無視のいずれも可能 | 特定行動を「正解」と感じ、罪悪感が生じる |

**評価方法**: 形成的試視（qualitative interview）。正解を当てさせるだけでなく次を尋ねる（★ 逐語）:
- この形を自分のものだと感じる根拠は何か。
- 自分について何を断定されたと感じたか／感じなかったか。
- 変化を見て画面内と画面外のどちらへ注意が向いたか。
- 見逃したとき、失敗または未達だと感じたか。
- 形を良くするために作業を変えたくなったか。
- 何をシステムに知られていると想像したか。

⚠️ **反証条件は上表の「失敗側の兆候」列そのもの（8 項目）。**
⚠️ **定量指標・N 数・統計検定・比較群の明記は無い。** 実験の段取り（被験者数・セッション数・
対照条件・順序）も §9 内に記述なし。§11 手順 4「状態表示版と実践肖像版を並べ…形成的に比較する」が
唯一の対比構造で、A/B 比較の形はあるがプロトコルは**未確定**。

## §7 アート理論としての形

### §7.1 三者の作者性

| 作者性 | 作品へ与えるもの |
|---|---|
| **人間の実践** | 拍、修正、継続、間という因果的な揺らぎ |
| **推論・造形系** | 不完全な仮説、選択、圧縮、交差写像 |
| **媒体** | 画面サイズ、点灯機会、単色化、周縁性、外部との境界 |

> ユーザーだけが作者なのでも、アルゴリズムだけが作者なのでもない。作品は三者の交渉として生じる。
> その交渉の非対称性、特に**推論系が持つ権威を隠さないこと**が必要である。

### §7.2 内容・形式・媒体

| 層 | GSE における定義 |
|---|---|
| 内容 | 本人と現在の作業との関係が、生成・修正・間・再開を通じて変化した**時間構造** |
| 形式 | ground、結合、疎性、書換え痕、持続、開口からなる**生成的な構図** |
| 媒体 | 身体とともに移動しながら、普段は背景に留まる**スマートフォン面** |
| 外部 | 画面を離れた身体、環境、他者、紙、沈黙など、**GSE が所有しない領域** |

> 媒体としてのスマホは単なる小型ディスプレイではない。作業 PC から離れうる一方、
> 別の注意捕捉装置にもなる**両義的な物体**である。この両義性を隠さず、
> 「**開いた後は見続けるものがない**」という時間構成にする。

### §7.3 作品単位

```
作業 <-> 痕跡 -> 推論仮説 -> 生成肖像 -> 内在的開口
                                      |
                            計測終端   v
                                  身体・環境
                                      |
                                      v
                               次の作業として再接続
```

> レンダリングだけを切り出して「作品」と呼ばない。
> **計測が始まり、形になり、境界を開き、知ることを止めるまでが作品である。**

## §8 横展開できる貢献

> 横展開するのはキーボード特徴量や `stable/friction_rising/stuck` の三値ではなく、次の構成規則である

```
domain-local な行為痕跡 -> 時間的 primitive -> 交差的・非可逆な造形
  -> 媒体内の周縁的肖像 -> 必要時の内在的開口 -> センシングしない外部
```

| 領域 | 行為痕跡 | 開かれる外部 | 注意点 |
|---|---|---|---|
| Writing | 打鍵、修正、間、バースト | 紙、歩行、対話、何もしない時間 | 現在の第一実証。⚠️ 意味妥当性は未確証 |
| Coding | 編集、ビルド、テスト、往復 | 設計を描く、机を離れる、他者に相談する | ⚠️ イベント意味が Writing と異なり単純転移できない |
| 音楽練習 | 反復、間、テンポの揺れ | 楽器から手を離す、聴く、身体で拍を取る | 芸術行為そのものを採点しないことが重要 |
| 手仕事・制作 | 道具操作、工程の反復 | 素材へ触れる、距離を取って見る | 新たなセンシングの妥当性・プライバシーが要る |
| 学習 | 解答、書換え、停止 | 身体を動かす、別媒体で考える、他者に聞く | 速さや正解を能力肖像にしない |
| ケア／リハビリ | 日常行為のリズム | 本人の身体感覚、休息、支援者との対話 | ⚠️ **医療判断に見える表現は不可**。別の倫理・検証が必須 |

**§8.2 理論的な横展開**（逐語）:
1. **Human-data interaction**: 自分の量を返す以外に、データとの関係を作品化する方法
2. **Generative portraiture**: 顔や蓄積プロフィールでなく、短期の実践関係を描く肖像
3. **Ambient media**: 背景から注意中心へ移るだけでなく、**媒体外へ注意を手放す構造**
4. **Adaptive interfaces**: 正解状態へ適応するのでなく、**介入後に制御を閉じない設計**
5. **Critical data art**: 何を測るかだけでなく、**どこで測定を終えるか**を形式にする方法

> 横展開可能性は、Writing で成立した後に別ドメインで同じ primitive と作品条件が
> 保たれるかを比較して初めて主張できる。

## §2.1 / 2.3 / 2.4

- **§2.1 状態でなく経路を描く**: `p_stuck = 0.7` のような瞬間値は「切断面」にすぎず、
  本人らしさは加速・修正・まとまり・間・再開・揺り戻しの**配列**に宿る。
  例: 同じ `stuck` でも「A: 長い連続生成 → 少数の修正 → 急な停止」と
  「B: 短い生成と修正を反復 → 間が増える → 停止」は**肖像の形態が異なるべき**。
- **§2.3 推定を真実へ格上げしない**: GSE の肖像を「本人の内面の指標」ではなく
  **「機械が本文を読まずに立てた、本人と現在の作業との関係についての仮説を、
  本人が再解釈できる形にした暫定的な肖像」**と定義する。
  ⚠️ **autographic visualization そのものではなく「推論媒介的な指標」**と位置づける。
- **§2.4 作品にデータ以外の自由を残す**: 全画素がデータを担うと「高密度な計器」になる。
  autonomous ground の重要性 4 点: ①接続や観測がなくても作品が存在する ②変化しないことを
  空白や死として描かない ③データを担わない揺らぎが美的経験と状態符号を分離する
  ④OS や媒体が変わっても作品の存在様式を保てる

## §11 次に進める順序（★ 逐語）

1. 三語「実践生成肖像／内在的開口／計測終端」が既存概念の言い換えに留まるかを **scoping review** する。
2. 一つの実セッションを使わず、**合成系列**で「最終状態は同じ・経路だけ異なる」作品対を作る。
3. `ground/lattice/sparsity/aperture` を用いた「書き直される境界」の静止画または短い動画を作る。
4. **状態表示版と実践肖像版を並べ**、本人性・診断感・注意捕捉・画面外への方向を形成的に比較する。
5. 交差写像の再現性と非可逆性を定義し、どこまでを研究用リプレイ／層 B／層 A に置くか分ける。
6. **作品が成立しなかった条件も含めて記録し**、その後に限って理論・方法・実作の貢献を分離して書く。

## §12 暫定判断（★ 逐語）

> GSE の研究価値を上げうるのは、状態推定の精度に「アート」を加えることではない。

1. **作業の内容を読まず、その時間構造から実践の肖像を作ること。**
2. **介入を通知でなく作品の開口として経験させること。**
3. **その開口の先で、システムが身体を知ろうとすることを止めること。**

> この三点を、造形・相互作用・倫理の別々の工夫ではなく、**一つの作品構造**として成立させる。
> そこまで到達すれば、GSE は「認知状態を当てるアプリ」から、
> **計測が人間を閉じ込めず、自らの限界を形式として示すメディア**へ位置づけ直せる可能性がある。
