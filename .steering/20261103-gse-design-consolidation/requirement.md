# GSE の全体の設計の整理（MhD の内部の解剖・段 1 の配布までの道筋・プローブの配線の設計）

## 背景

2026-10-31〜11-03 に ADR-040〜043 が Accepted になったが、上流の文書（research-positioning §1・WBS B1〜B4）と実装（ADR-040 のコード・ADR-031 M5）が追いついていない。Proposed のまま残る ADR も多い。MhD（HMM_VERSION 0.5.0）は、配管の空回し 2 本（`experiments/20261103-mhd-pipeline-dryrun/`・`experiments/20261103-mhd-dryrun-v2/`）で `p_stuck` の予測の幅がごく狭い（CoAuthor の代理ラベルで logit の SD 0.059）こと、ROCKET 系が数百〜千件で過学習したことが見えた。

入口: `.steering/_handoff/next-session-gse-design-consolidation.md`（研究者の依頼「4. も含めて、もう少し全体の設計などの整理などを行いたい」「Mh-D 内部の解剖も含めて行おう」）。

## ゴール

議論で決めたことを SSOT の文書に落とす。順は研究者の選択（2026-11-03）で、解剖 → 地図 → 道筋 → M5 の設計。

1. MhD の内部の解剖: 特徴量・HMM・間引きと停止・出力の消費者・段の上げ方を一次で読み、空回しの結果と照らして、L0 の核として残す部分と直す・置き換える候補を分ける。
2. 全体の設計の地図（1 枚）: 層ごと（推定・契機・介入・アウトカム・ラベル・検証の段）に、決まったこと・実装の状態・未決・根拠の ADR。
3. 段 1 の配布までの依存の道筋: 何が何を待つか・Mac と G-GEAR のどちらでやるか。
4. プローブの配線（ADR-031 M5）の設計: 無作為の枠と層化の発火・6 択 UI・抑制・未回答・遅れの記録。ADR-040 の配線との順番。

## スコープ
