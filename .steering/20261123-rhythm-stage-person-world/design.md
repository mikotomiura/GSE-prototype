## 要旨（5 行）

1. 生成器に「人の層」を足し、人ごとの潜在値 z とセッションごとの揺れ ε を、ICC で混ぜた単位分散の量 x = √ICC·z + √(1−ICC)·ε として作る。z・ε は world と ICC と k に依らず同じ乱数で引き、段の間で列を対にする（セッションの区間の並び・ラベルも、全段で同じ乱数の流れから先に引く）。
2. 倍率の world（`m049`・`m068`）は burst の中の間隔の対数に σ_b z + σ_w ε を足す（f200 と同じ掛け方）。相対の型の world（`r049`・`r068`）は速さの揺れの周辺分布を倍率の world と同じにしたまま人と切り離し（人に結び付かない ε だけ）、3 つの次元（ばらつき・burst と休止の比・AR(1)）を共通の k で動かす。k=0 の相対の world は「速さが人に結び付かない world」とバイトで一致する。
3. (5) は人を単位にした 5 分割で、学習の人の組で対の分類器（|Δx| と平均）を当てはめ、検証の人の組の対で照合の AUC を出す。対照は 4 つ: 人の真の値を描く PC1-id、候補に人の信号を λ で混ぜる PCp、セッションごとの無関係な値を混ぜる PC0-id、生の打鍵の攻撃者 PC-raw（world の信号の有無の門）。生成器の真の潜在値で照らす「神託の AUC」を解析の値と照らし、計器の正しさを確かめる。
4. (6) は人ごとの読み手（その人の前の 3 本だけで当てはめ）と共通の読み手（ほかの人の組で当てはめ）を、同じ後の 3 本の人の中の AUC の平均で比べ、差の差を判定する。対照は、停滞を人ごとの向き（±）で描く PC1-pers・PCps と、全員同じ向きで描く PC0p（前の PC-stall そのもの。差の差が 0 になるべき対照）。
5. 判定の規則（0.03・3 値・判定不能の理由・陽性対照で検出器を確かめる）は前のものを写す。`without_smooth` の変種は判定の語を持たない記述とし（判断 10）、道の読みは親の判定と同じ攻撃者の上の上限の最大だけで 1 つに固定する（§3.3 (c)・判断 11）。段の順は m049 → m068 → r049 → r068、所要は約 8〜11 時間（推論）。

## いちばん自信の無い 3 点

1. **k の較正が「推定の揺れで決まる領域」に落ちること。** 判断 7 の規則（生の打鍵の攻撃者の照合の AUC を、同じ ICC の倍率の world にそろえる）で、倍率の world の攻撃者の上限は 1 次元の神託（解析で ICC 0.494 なら約 0.61、0.679 なら約 0.67・§3.4）に近い。相対の型の world は 3 次元で、真の値なら k に依らず 0.7〜0.8 に届く。したがって目標の AUC にそろう k は、3 時間のセッションでも型の推定の揺れが信号と同じ大きさになる小さい値になる見込みで、2 つの world は「人の中の揺れで頭打ちになる world」と「推定の揺れで頭打ちになる world」という違う形でそろう。判断 7 は変えず、神託の AUC と k の位置を記述として必ず並べ、読みの限りを §3.3 (e) に書いた。
2. **人ごとの読み手が 3 本（約 540 窓）で当てはまるか。** hgb は過学習しやすく、人の中の AUC は人ごとに揺れる。PCps が帯に入らず、多くの候補が `weak_person_pc` で判定不能になるおそれがある。lr を主に読む作りにはせず（前の規則を写す）、帯に入らないことを結果として書く。
3. **倍率の world の掛け方と、相対の 3 次元の尺度。** f200 と続けて読むため（判断 7）倍率を burst の中の間隔だけに掛けるので、速さが変わると打鍵の間隔と休止の比も変わる（相対のタイミングの一部が動く）。`D-all` はこの world でも純粋な「速さだけ」を見ていない。また 3 次元の尺度 h_j を 1 にそろえたのは、文献に根拠の無い置き方である（判断 7 は総量の k だけを較正する）。

### 1.2 生成器の人の層（`gen_sessions.py`・判断 2・3・7）

既存の world（v1〜v4・graded・confound・factor・drift）は変えず、写し元とバイトで一致させる。新しい world は `--world person-m` と `--world person-r` で、`--icc` と（r だけ）`--k` を取る。

**乱数の流れを分ける**（このタスクで足す・§9 の 2）: 新しい world では、セッション i について次の順で別々の流れから引く。

1. 区間の並び: `derive_rng(seed, "seq", i)` から状態と長さ（`markov` と同じ遷移と長さの分布）を先に全部引く。
2. 打鍵: 区間ごとに `derive_rng(seed, "keys", i, 区間の番号)` から引く。
3. 人の潜在値: `derive_rng(seed, "pz", p)` から z_p0, z_p1, z_p2, z_p3（4 つの標準正規）を、セッションの揺れ: `derive_rng(seed, "pe", p, s)` から ε_ps0〜ε_ps3 を引く。

こうすると、同じ seed の 4 段と k の格子のすべての点で、区間の並びとラベル（L300）が同じになり、z と ε も同じ数になる。打鍵の速さや型が違っても、区間の長さは打鍵から決まらない（v2 以降の「burst の長さは秒で引く」作りなので）。セッションの終わりを越えた区間を切る扱いは `markov` を写す。

**倍率の world `person-m`**:
- 人の中の速さの対数のずれ m_ps = σ_b z_p0 + σ_w ε_ps0（σ_b = 0.536、σ_w は ICC 0.494 で 0.543、0.679 で 0.369・判断 7）。
- 掛け方は f200 と同じ: burst の中の打鍵の間隔の対数の中央値に m_ps を足す（`gen_typing` の `mu + speed.z` の位置）。休止と burst の長さには掛けない。前の f200 の z = c δ u（SD 0.758）に当たる量が、m_ps（全体の SD 0.763 と 0.650）になる。
- 掛け方の帰結（固定の前に書く）: 速さが変わっても burst の長さ（秒）と休止は変わらないので、1 つの burst の打鍵の数と、間隔と休止の比が速さで変わる。`D-run` の窓の統計量は倍率に不変だが、`D-all` は休止を含むので不変でない（前の design §1.2 の宣言と同じ）。

**相対の型の world `person-r`**:
- 速さ: speed_ps = σ_t ε_ps0、σ_t = √(σ_b² + σ_w²)（ICC 0.494 で 0.763、0.679 で 0.650）。人に結び付かない（z_p0 を使わない）。速さの揺れの周辺分布は、同じ ICC の倍率の world と同じになる。これで、倍率の world と相対の world の差は「速さが人に結び付くか」と「相対の型があるか」の 2 つだけになり、相対の world の A_speed の照合の AUC は 0.5 に近いはずという、作りから来る陰性の確かめが 1 つ増える（§3.3 (d)）。
- 3 つの次元: x_psj = √ICC z_pj + √(1−ICC) ε_psj（j = 1, 2, 3・単位分散・人の間の分散の割合が ICC）。
  - 次元 1（間隔のばらつき）: burst の中の間隔の対数の SD を σ_f exp(k h_1 x_1) にする（σ_f は区間の種類ごとの元の値。中央値は動かさない: 対数正規の μ はそのまま）。
  - 次元 2（burst と休止の比）: burst の長さの上下（`burst_dur_min_s`・`burst_dur_max_s`）を exp(+k h_2 x_2 / 2) 倍、休止の中央値（`gap_median_ms`）と上限（`gap_cap_ms`）を exp(−k h_2 x_2 / 2) 倍にする（2 つの幾何平均を保つ）。
  - 次元 3（隣の間隔の相関）: burst の中の間隔の対数の残差を AR(1) にする: e_n = ρ e_{n−1} + √(1−ρ²) η_n、ρ = tanh(k h_3 x_3)。burst の始めで e を η から引き直す（burst を跨いで相関を持たせない）。周辺の分布（中央値と SD）は変わらない。
  - h_1 = h_2 = h_3 = 1（§9 の 4・自信の無い点 3）。
  - **上限**（判断 10・`/cross-review` 1 巡目）: 各次元の対数の倍率 `k h_j x_j` を [−1.5, 1.5] に切る（σ の倍率は 0.22〜4.5、ρ は ±0.905）。k の格子の上の方では、切らないと間隔の対数正規の指数が桁あふれし、生成が止まりうる。切られたセッションの割合（どれかの次元が切られたセッションの割合と、次元ごとの割合）を下見 1k と本番の記録に書く。x ~ N(0, 1) では、切られるセッションは k = 0.75 で約 13%、k = 1.0 で約 35% になる（推論）。本番の段でこの割合が 10% を超えたら、その段の型は「k h x」ではなく裾で切れた分布の world と宣言する（§3.3 (b)・`clipped.truncated_world`・判断 11）。k は 0 以上 1.0 以下に限る（格子の上端）。
- 全体の速さ（burst の中の間隔の中央値）は、次元 1・3 では動かない。次元 2 は休止の割合を変えるので、1 分あたりの打鍵の数と打鍵の有無の型が動く（相対の型がそのまま打鍵の有無に出る。基準 A がそれを持つ）。これは「burst と休止の型」を入れる以上避けられない帰結として書く。
- k = 0 では 3 次元とも元の値になり、`person-r` の列は「速さが人に結び付かない world」とバイトで一致する（自己検査 §3.7 の G3）。

### 1.5 (5) 個人の再識別（`person.py`・判断 8）

**セッションの要約**: L300 の表の行（窓）の、各特徴の平均と SD。
- 候補: `small` = 画の 20 量の平均（20 次元）、`full` = 20 量の平均と SD（40 次元）。変種は落とした量を除く。
- 基準: A = A の 11 量の平均と SD（22 次元）、A_speed = A ＋ 速さの量（`WS_NAMES` の 13 量）の平均と SD（48 次元）。どちらの特徴の組でも同じ基準を使う。
- 要約は窓の値だけから作り、真の潜在値・人の番号を読まない。

**対の特徴と攻撃者**:
- 対 (i, j)（i < j）の特徴は、学習の組の平均と SD で標準化したセッションの要約 v について、[|v_i − v_j|, (v_i + v_j)/2]。対称なので順序に依らない。
- 攻撃者は前と同じ 4 通り（`full`・`small` × `hgb`・`lr`）。ラベルは同じ人なら 1。
- 分割: 人を単位にした 5 分割（各 8 人・48 本）。分割の割り当ては `SEED` から決め、基準と候補で同じにする。学習は学習の 32 人の中の対（同じ人 480・違う人 17,856）、評価は検証の 8 人の中の対（同じ人 120・違う人 1,008）。**照合の AUC は、検証の組ごとに AUC を計り、5 つの平均にする**（組ごとに別の当てはめなので、得点を併せると組の間の尺度の違いが順位に入る・`/cross-review` 1 巡目・判断 10）。検証の組の間の対は作らない。対の数の偏り（違う人の対が同じ人の対の 8.4 倍）は AUC に影響しないので重みを付けない。ブートストラップと帰無も同じ量（組ごとの AUC の平均）で作る。
- 利得 = AUC(基準 ＋ 候補) − AUC(基準)（同じ攻撃者・同じ分割）。

**区間**（人を単位にしたブートストラップ・2000 回）: 当てはめた得点は固定し、人を復元抽出した重み m_p で対を重み付けする。同じ人の対の重みは m_p、違う人の対の重みは m_p m_q。同じ人を 2 回引いたとき、その写しどうしの対は作らない。AUC は重み付きで計算する（前の `auc_w` の重みを対に移したもの）。

**帰無**: 人の番号の並べ替え（20 回）。240 本を、1 人 6 本を保ったまま無作為に 40 の偽の人に分け直し、分割から当てはめまでを全部やり直す。基準と候補で同じ並べ替えを使う。null95 は前と同じく攻撃者の最大の 95% 点。

**対照**（画の名前。前の PC-stall と同じく、60 秒のブロックごとに U、N を引き、U < λ なら信号、そうでなければ N。入れる位置・止まり方・据え置きは前の PC-stall と同じ・`r` は 0.5 の定数）:

- `PC0-id-<候補>`: 信号 = Φ(ε'_s)（セッションごとに独立な値・人に結び付かない）。λ は PCp と同じ値。利得の上限が 0.03 未満で `baseline_below`。下限が 0.03 を超えたら、前の `red_detected_stop_path` と同じ扱い（人に結び付かない作りでも照合が上がる＝計器の道の汚れ）。

### 3.4 計器の確かめに使う解析の値（固定の前に書く）

- 1 次元の神託（m の段）: 同じ人の対の差は N(0, 2σ_w²)、違う人の対の差は N(0, 2σ_t²)。|差| の小さい方を同じ人と読む照合の AUC は P(|X| < |Y|) = (2/π) arctan(σ_t / σ_w) = (2/π) arctan(1/√(1 − ICC))。ICC 0.494 で約 0.607、0.679 で約 0.672（推論・計算は自己検査で数値で確かめる）。
- 3 次元の神託（r の段）: 距離の 2 乗の比は F(3, 3) に従い、AUC = P(F(3,3) < 1/(1 − ICC))。ICC 0.494 で約 0.7、0.679 で約 0.8（推論の概算・自己検査で数値で確かめる）。r の段の神託は k に依らない。
- これらは、真の値の距離という 1 つの得点の値であり、攻撃者の上限そのものではない（学習した攻撃者は、要約の揺れのために下回る）。

### 3.7 自己検査と変異

**生成器**:
- G0 既存の world: 写し元とバイトで一致する（前の計器と同じ検査を写す）。
- G1 対: 同じ seed で、4 つの world・2 つの ICC・k の格子の 3 点（最小・中・最大）について、すべてのセッションの L300 のラベルの列と区間の境目が一致する。z と ε の数が一致する。
- G2 ICC の混ぜ方: `manifest` の潜在値から、x の人の間の分散の割合を 4000 人 × 6 本の作り物の引き（生成なし・同じ関数）で求め、ICC との差が 0.02 以内。m の段で m_ps の全体の SD が σ_t と 0.01 以内。
- G3 k = 0: `person-r` を k = 0 で作った列が、「速さ = σ_t ε・型なし」の作りとバイトで一致する。
- G4 中央値を動かさない: 次元 1・3 を極端（k x = ±1）にした長い burst（作り物・10 万の間隔）で、間隔の対数の中央値の差が 0.01 以内、次元 3 の周辺の SD が σ_f と 2% 以内、lag 1 の相関が ρ と 0.01 以内。次元 2 で burst の長さと休止の中央値の幾何平均が保たれる。
- G5 速さを人に結び付けない: r の段で、速さの潜在値が z_p0 を読まない（作りの読みの記録）。
**読みの閉じ**:
- R1 候補・基準・PC-raw・距離の攻撃者は、`manifest` の真の潜在値と人の番号を読まない（`StageInput` と同じ形の閉じた入力で、要約の関数に人の番号を渡さない。人の番号を使うのは分割と対のラベルだけ）。PC1-id・PCp・PC1-pers・PCps は人の番号だけを読み、生成の潜在値を読まない（別の流れの z'・s_p を使う）。
**(5)**:

- P3 神託: 作り物の正規の潜在値（生成なし・4 万人）で、照合の AUC の計算が §3.4 の解析の値と 0.005 以内で一致する（1 次元と 3 次元）。
- P4 並べ替え: 偽の人が 6 本ずつで、元の人と独立に割り当てられる。
- P5 作り物の対照: 作り物の要約の表で、PC1-id の利得が 0.10 を超え、PC0-id が 0.03 未満。
**(6)**:
- Q1 人ごとの読み手の学習の行が、その人の slot 0〜2 だけ。共通の読み手の学習の行に検証の組の人が入らない。

- Q3 人の中の AUC の平均が、1 クラスの人を除き、除いた数を記録する。
**判定**:
