## 判断 10: PCr の λ の格子を 1.0 まで延ばす（固定の前・Claude）

- **判断日時**: 2026-10-15
- **背景**: 固定の前の試作（判断 9・seed 7770000・d100・P 40・ブートストラップ 50・hgb は天井で lr だけ）では、PC-stall の λ も PCr の λ も、24 候補すべてで格子の上の端 0.3 になった。λ = 0.3 での上乗せの点推定 / 下限の例:
  - `S-raw-hold-sub`: PCs +0.045 / +0.036・PCrl +0.039 / +0.030・PCrv +0.040 / +0.032
  - `S-smooth-hold-sec`: PCs +0.032 / +0.025・PCrl +0.026 / +0.017・PCrv +0.023 / +0.016
  - `S-rank-hold-sub`: PCs +0.025 / +0.018・PCrl +0.017 / +0.011・PCrv +0.037 / +0.029
  - λ = 1 の本番の流れ（同じ試作の自己検査）では、PCrl +0.106・PCrv +0.102。
- **選択肢**:
  - A: PC-stall と同じ格子のまま（0.3 まで）。PCr が帯に届かず、読みが `unclear`・`fails` に寄りうる。
  - B: PCr だけ格子を延ばす（0.4・0.5・0.6・0.8・1.0 を足して 17 点）。
  - C: 0.025 刻みで 1.0 まで（40 点）。
- **採用**: B
- **理由**: PCr は、`R2` を落とした後に `r` の側の手がかりを拾えるかを示す対照なので、落とさない列で帯の大きさに届かないと役に立たない。PCr は新しい対照で、PC-stall の格子に合わせる必要はない。λ = 1 で +0.10 に届くので、0.3 と 1.0 の間に帯がある見込み。C は所要が 3 倍で、帯を細かく当てる必要は無い。
- **トレードオフ**: L300r の所要が約 4 割増える（1 段あたり約 2.4 h → 約 3.3 h）。λ が大きいと、ブロックの多くが停滞の割合そのものになり、PCr が「止まりの経路」に近い強い手がかりになる。帯の上限 0.08 で大きさを抑えるので、読みの意味（0.03〜0.08 の型の漏れを拾える）は変わらない。
- **影響範囲**: `config.json` の `pc_r.pilot_grid`・`checks.py`（`pcr_grid`・`choose_all` の格子の引数・`pilot.json` の `rule_r` とその照合）・`selftest.py`。
- **見直しタイミング**: 本番の下見 1 で、PCr の λ が 1.0 に張り付いたとき。

## 判断 11: 変異の検査の結果（固定の前）

- **方法**: 使い捨ての写し（`experiments/zz-mut-<名前>/`・終わったら消した）に 1 つずつ変異を入れ、`selftest.py`（gse-replay を使わない分）か `selftest_split.py` を回した。変異の置換と回し方は scratchpad の `mutate.py`（コミットしない）。
- **結果**: 14 通りすべてを捕まえた（判断 10 の後に、L300r の family の取り違えを新しい行で回し直し、「延ばした格子を読まない」を足した）。
  - 生成器: `factor` が漂いも使う・`drift` が倍率も使う・2 つの shape の取り違え・`drift` で `u` を引かない。
  - 描画: PCr-level の手がかりを `a` に入れる・PCr-var の手がかりを水準に入れる・PCr のブロックに流れ 37 を使う・PCr の土台の λ を 0 にしない。

  - 並べる表: 走っていない段を「緑」に数える。
- **直したこと**: `pc_r.lam` を指紋から除かない変異は、最初は検査の名前ではなく、`--apply-pilot` の拒否（例外）で自己検査が終わる形で捕まった。そこで、`--apply-pilot` より前に、`pc_r.lam` が指紋を変えないことを名前つきで確かめる検査を足し、名前で落ちることを確かめた。

## 判断 12: 固定の前の `/cross-review` 1 巡目の結果と対応（2026-10-15）

- 範囲: `77e9cfb0..81c23d33`（計器の直しと design の草稿）。
  - Codex: `scripts/run-codex-review.sh` をパスで 2 回に分けた（A: 計器の本体 P1 1・P2 3、B: 自己検査と design P1 2・P2 2）。

  - 合成の NDJSON は差分に無く、渡していない。
- 採ったもの（一次で確かめてから直した）:
  1. **HIGH（code-reviewer）**: `Rall` の PCr は陰性の対照にならない。PCr の `a` は λ にも family にも依らないので、`r` の量をすべて落とすと PCr と土台の特徴が同じになり、`works` が原理的に出ない。直し: PCr の `Rall` を当てはめない（`pcr_drops` = none・R2）。「`a` は λ に依らない」を自己検査の等式で宣言として固定した。止まり方の漏れは土台の上限が拾う、と design §1.3 に書いた。判断 9 の「24 本すべて fails（見込みどおり）」を直した。
