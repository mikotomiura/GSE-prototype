# 要件: 打鍵の外の信号を持つ公開データの調べ

## 背景
- 公開データの俯瞰（`experiments/20261102-public-data-landscape/notes.md`・`.steering/20261102-gse-public-data-landscape/positioning.md` §2）では、KLiCKe と CoAuthor から見えるのは打鍵と休止の層まで。ポインタの動き・フォーカスの遷移・外からの受領・自己申告のラベル・IME は O1 にしか無い。
- 停滞の分解（ADR-041 D2）の手の様子の軸はポインタとフォーカスを含むが、O1 は研究者本人 1 人で、書き手をまたいで確かめる材料が無い。
- 俯瞰 L5: 約 11 分の単位では停滞が 0〜2 件。1 人あたりの記録が長いデータが要る。
- 入口: `.steering/_handoff/next-session-gse-public-data-signal-survey.md`（2026-11-02）。

## ゴール
打鍵と一緒に次の信号を持つ公開データの候補を一覧にし、各候補の利用の条件を一次で確かめる。
1. 打鍵とポインタの連続した動き
2. 打鍵とウィンドウ・アプリの切り替え
3. 打鍵と、詰まり・フラストレーション・作業の状態の自己申告
4. 1 人あたりの記録が長い、またはセッションが多い打鍵データ
5. （短く）日本語 IME の変換の過程の新しい候補

各候補で確かめること: 公開の場所と利用条件（ライセンス・同意の範囲・再配布）、人数と 1 人あたりの時間、時刻の精度、本文を使わずに使えるか、作業の種類（統制課題か自然な作業か）、AI の経路が作業にあるか。
