# Windows で O1（v0.1.40）がスリープをまたいで記録を続けるかを確かめる

## 背景

O1 の参加者はノート PC を閉じて使う。macOS は 2026-09-10 に成立しているが、Windows の記録は無い（引き継ぎ `.steering/_handoff/next-session-windows-sleep-test.md` §1）。

## ゴール

蓋を閉じられる Windows 機で v0.1.40 を寝かせて起こし、引き継ぎ §4 の 6 項目を実測で判定する。

## スコープ

### 含むもの
- 短い試験（5〜10 分のスリープ）・長い試験（6 時間以上・定期の再送）。後片付け。記録。

### 含まないもの
- 24 時間以上の試験（日ごとの区切り）・休止状態・蓋閉じ。
- （長い試験は当初は含めなかったが、研究者の判断で同じ日に行った）
- コードの変更。

## 受け入れ条件

- 6 項目それぞれに実測値と判定がある。判定しなかった項目を「問題なし」と書いていない。
- 試験で作ったもの（P998・自動起動の登録）を、研究者の了承を得て片付けた。
