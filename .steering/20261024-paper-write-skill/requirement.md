# 要件: 論文を書く Skill（paper-write）と、attack-me の編集者の役

## 背景

2026-10-24、研究者が別の論文の投稿で受けた編集者の判断を会話に貼った（本文は repo に入れない）。要旨: 方法と記録の価値は認めるが、このままでは査読に回さない。本文が長すぎる（目安 5,000〜7,000 語）・方法の細部と追加の分析と検証の手順は補足資料へ・論文の中心となる仕組みごとに「何を確かめるつもりで、実際に何を測り、何が分かり、なぜ大事か」で組む・評価の説明を簡単にする・登録／事後／取り置きの区別は保ちつつ繰り返しをまとめる・貢献の意義を、評価を実際に損ねた問題と、可能性にとどまる問題とに分けて示す。

今の道具には、書く段の指針が無い（文体の門は禁止語と言語だけを見る）。attack-me の査読者役は方法と再現性の基準で接地しているので、直すたびに但し書きと手順が本文に増えやすい（照合の論文の round 2 でも倫理の節が伸びた）。編集者が本文だけを読んで査読に回すかを決める段を模した役が無い。

## ゴール

1. `paper-write` Skill: 投稿先の適合の調べ → 主張と新規性の確定 → 本文と補足資料の分け方 → 中心の仕組みごとの組み立て → 但し書きの集約 → 分量の予算と測定 → 意義の議論、の手順を持つ。
2. attack-me に編集者の役（E）を足す。本文だけを読み、査読に回すかを判定する。直すときは「足す」より「移す・まとめる」を先に考え、round ごとに本文の語数の増減を記録する。

## 受け入れ条件

- `.claude/skills/paper-write/SKILL.md` がある。編集者の手紙の逐語を含まない（要旨だけ）。
- attack-me の SKILL.md に E の役（接地・依頼文のひな形・読む範囲〔本文だけ〕・判定）と、語数の記録がある。
- `paper-reviewer` の定義が E の役を含む。CLAUDE.md の研究トラックの表に paper-write がある。
- push だけで止める（PR は研究者に確かめてから）。
