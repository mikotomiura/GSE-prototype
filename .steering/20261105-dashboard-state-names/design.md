# 設計

## アプローチ

1. 回帰の検査を先に足し、直す前に赤（3 件）を見る（`/fix-bug` の回帰テスト先行）。
2. 文字列 3 か所を判断 2 の文に置き換える。
3. 検査が緑、`tsc` が緑、画面で文を見る。

## 変更対象

- `scripts/check_doc_lexicon.py`: 検査 5 を足す。`src/**/*.ts(x)` の `/* */` と `//`（`:` の直後は URL なので除く）を同じ行数の空白に置き換えてから、日本語（平仮名・片仮名・漢字）を含む行に `\b(Flow|Incubation|Stuck)\b|フロー|インキュベーション|スタック|推定状態` があれば違反。対象のファイルが 0 本なら空回りとして exit 1。
- `src/components/Dashboard.tsx` 492-493 行
- `src/App.tsx` 118 行
- `docs/functional-design.md` 249 行の注

## テスト戦略

- 陽性対照: 直す前に検査が 3 件を挙げて exit 1。
- 直した後に exit 0。コメント中の語（Dashboard.tsx 469・476 行）を拾わないこと、英語のラベルを拾わないことを、直す前の出力が 3 件ちょうどであることで確かめる。
- `npx tsc --noEmit`。
- 画面: `npm run dev` を Chrome で開き、Tauri の shim で O1 のモードにして注意書きの文を読む（memory「UI を変えたら画面を見るまで完了ではない」）。

## 根本原因と修正方針

- 原因: ADR-046 D1 より前の文が残っている。文の直しを止める仕組みが無かった（トレイにだけ Rust のテストがあり、フロントの文には無かった）。
- 方針: 文字列 3 か所を最小の変更で直し、同じ語の再混入を CI の既存の検査（Doc lexicon gate）で止める。
