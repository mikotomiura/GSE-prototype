## 判断 1〜4: 始める前に研究者が選んだこと（2026-11-09）

1. **ポインタの跡の置き場**: 戻っていく値（草の押し・粒のずれ）は Rust の固定刻み（16ms）の状態で計算する。打鍵の積分器（「今 − 0.5 秒」まで進める・PR 1 判断 7-3）とは別にし、ポインタには遅れを入れない。波紋の 6 枠は ADR-050 D4 のとおり窓の側に置き、年齢は時刻で決める（描画の回数に依らない）。
   - 採らなかった案: 波紋の枠も Rust に入れる（ADR-050 D4 の「枠は窓の側だけ」の読み替えか補訂が要る）／試作どおり窓の側で減らす（跡が描画の回数に依り、PR 4 の再生の道具が TSX の処理を写すことになる）。
   - ADR-051 D3 の判定がどの写像についてのものか: 打鍵の状態と、ポインタの戻っていく値（Rust の関数）の写像。波紋は窓の側なので、再生では押下の時刻と合成の位置から PR 4 が描き直す（波紋の式を Rust に写すかは PR 4 で決める）。
2. **再生の近似**: `pointer_bin` の 1 秒の量から、描画の種で決めた起点を、その秒の移動量のバケットの代表の距離だけ等速で動く合成の軌跡と、秒の中に等間隔に置いた押下を作り、ライブと同じ関数に入れる。位置は再現できない（ADR-051 D3 の限界）。`pointer_bin` の押下はどのボタンも数えるので、左だけのライブより押下が多めに出る（限界として記録する）。
   - 採らなかった案: 画面の中心に固定／位置を使わない量だけ（ライブと別の経路になる）。
3. **入力ごとの入れ切り**: トレイにカーソル・クリックの入れ切りを入れ、切った・戻した時刻を `handmark_day` に記録する（schema の変更・gse-dataset の同期）。
   - 採らなかった案: 入れるが記録しない／PR 3 では入れない。
4. **タスク名**: `handmark-pr3-pointer`（枝 `feature/handmark-pr3-pointer`・worktree `/Users/johnd/GSE-prototype-handmark-pr3`）。

## 判断 11: 区切りの点検（code-reviewer・security-checker）の指摘と直し（2026-11-09）

- security-checker: CRITICAL・HIGH・MEDIUM なし。ポインタの値が記録・tracing・ファイル・ネットワークへ出る経路は見つからなかった。LOW 5 件（検査の穴 4・入力の切りの持続 1）。

- 直したもの（実装役・b55a04d2〜161cabe9）:
  - HIGH（時計）: 送る側が壁時計・窓が単調な時計で、壁時計が戻ると窓が以後の跡と波紋を全部捨て、走行の終わりまで戻らない → ポインタのスレッドは `Instant` 起点の単調な ms。窓は世代が進むと基準を取り直し、遅れの判定が 5 回続いたら取り直す（macOS の `Instant` はスリープの間止まり、WKWebView の `performance.now()` の挙動は確かめていないので、ずれが一度に変わっても戻れるようにした）。Rust 側も時刻が戻ったら場を取り直す。
  - MEDIUM: 刻みを飛ばすと速さが 0 に戻り倒しが約 2Hz で脈打つ → 待ちを次の 16ms の境目に合わせ、カーソルが入っていて読みの無い刻みは速さを保つ（場には足さない）。17・16・33ms を繰り返す呼び出しで、倒しの最大は 16ms ちょうどの 0.73 倍（直す前は 0.65）。テストの下限は 0.7 とする（8 割にするには読みの無い刻みでも場に足す必要があり、合成の入力でない値を場に入れることになるので採らない）。

  - LOW: 駆動スレッドがパニックで抜けたら駆動役も捨てる（後のトレイの押下が門を開け直さない）・波紋にも世代を載せる・常に真の assert を直す・検査の穴 4 つ（走査に .js/.jsx/.mjs/index.html、イベント名を持つのは `handmark_stage.rs` だけ、`emit_trace`/`emit_ripple`/`screen_size_pt` を呼べるのは `lib.rs` と `handmark_stage.rs` だけ、逆向きの検査を識別子の単位にして `Point`・`Step` と 5 ファイルを足す、窓の列の作り手の語を足す）。
- 確かめ: fmt・clippy・`cargo test --workspace`（lib 1269 件）・emit_schema・tsc・node 17 件を自分で走らせ直して緑。変異: 窓の基準の取り直しを外す → node 1 件赤／読みの無い刻みで速さを保たない → 2 件赤／入力の切りが書けないときに印を書かない → 2 件赤。
