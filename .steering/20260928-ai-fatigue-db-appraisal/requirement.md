# AI 疲労 文献 DB の再評価（適格性 → 方法論 → 領域別 / 照合 → スクリーニング案）

## 背景

研究者が作成した AI 疲労サーベイ用の文献 DB
（`C:\Users\johnd\Downloads\AI_fatigue_database_with_AI_appraisal_2026-09-18.xlsx`・34 レコード・16 シート）には、
2026-09-18 に別の AI（ワークブックの記載では「GPT-6 Astra Pro」）が行った補助評価
（AI適格性評価 / AI方法論評価 / AI領域別評価 / AI照合事項）が入っている。スクリーニング欄は全件「未判定」。

研究者の依頼（2026-09-28・逐語）:
「AI適格性評価 → AI方法論評価 → AI領域別評価 / AI照合事項かつ, スクリーニングでの各判定などを客観的かつ,
これまでのGSE研究での内容やsurvey結果など多角的な視点での実施を行ってくれない？」

## ゴール

1. 同じ 4 段（適格性 → 方法論 → 領域別 / 照合）とスクリーニング判定を、**事前に固定した基準**で、
   **一次資料に当たり直して**独立に実施する（既存 AI 評価の追認ではなく、一次で確かめて一致・不一致を示す）。
2. GSE の既存調査（`docs/references.md` [P361]〜[P375]・生成的返権論 §6.3・理論ロードマップ §5.7・
   2026-09-19 の体系的レビュー）との照合を、**採否とは別欄**で付ける。
3. 結果を元ファイルを壊さずに新しい xlsx として返す。

## スコープ

### 含むもの
- 34 レコード全件の適格性判定（2 段の中心範囲・除外理由コード）
- 設計別の方法論評価（JBI チェックリスト項目に準拠した AI 予備判定・合計点なし）
- 中心候補の領域別評価（6 領域・4 段階）
- 既存 AI 照合事項 I01〜I15 の一次での再照合と、新規の照合事項
- スクリーニング案（TA 段・全文段・除外理由・全文確認・品質評価）
- 学術 API による再現可能な検索漏れ点検（ヒット件数つき）
- GSE 既存調査との照合・既存 AI 評価（GPT）との比較

### 含まないもの
- ⚠️ **元ワークブックの「スクリーニング」シートの判定者 1 / 判定者 2 / 最終判定欄への書き込み**
  （★ ワークブック自身が逐語で「判定者1・2は独立した人間の担当者を想定し、AIの予備整理を独立判定に数えません」と定める）
- ⚠️ 元の 16 シートの変更（★ 追加シートのみ。元ファイルは上書きしない）
- 「AI判定比較」シートへの人間判定の入力（★ 人間の独立判定後に研究者が行う）
- 正式な JBI / RoB 2 / COSMIN / GRADE の判定と称すること
- `docs/references.md` への登録（★ 本タスクは外部 DB の評価であり SSOT 本文で引かない。引くときに `citation-ssot` で登録する）
