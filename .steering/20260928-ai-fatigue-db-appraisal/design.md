## 1. 問い（元 DB の「項目定義・採択基準」シート r7〜r12 から操作化）

人間が AI を利用・監督・評価することに関連する疲労について、何が定義・測定・観察されているか（スコーピング型）。

- **P（対象）**: AI システムを利用・監督・評価する人間（年齢・職種・国を問わない）
- **C（概念）**: 疲労（認知・情動・身体・動機/行動面の消耗、exhaustion、weariness、burnout 様の枯渇を含む）を
  **定義・測定・質的に分析**しており、かつ **AI の利用・監督との関係の中で**扱っているもの
- **Context**: 教育・職場・消費・研究など問わない。AI の種類を問わない（生成 AI に限らない）
- 期間: オンライン公開が 2026-09-28 以前

## 2. 用途判定（既存 AI 評価と同じ語彙を使う）

`中心候補` / `背景保持` / `方法論保持` / `訂正連結` / `除外` / `保留`

★ `中心候補` を 2 段に分ける（★ 既存 AI 評価が AF019 / AF024 で「基準全体を揃えて再判定」と保留した点を、先に規則で閉じる）:

| 段 | 条件（すべて満たす） |
|---|---|
| **中心-A（AI 特異）** | 一次研究である ／ 疲労の構成概念が **AI に帰属させて**定義・測定されている（項目文・定義・質問文に AI が明示される、または AI 疲労としての自由記述・語りを分析する） |
| **中心-B（AI 文脈）** | 一次研究である ／ 疲労・消耗・バーンアウトを **測定または質的に分析**している ／ ただし構成概念は一般的（AI を項目に含まない）で、**AI の利用・AI 由来の要求を説明変数・文脈・標本定義として**関係づけている |

- 中心-A と中心-B は**別集計**にし、中心-B の結果を「AI 疲労」の証拠として中心-A と合算しない。
- 疲労を測っていない一次研究（認知負荷・不安・過信・批判的思考・利用量のみ）は `背景保持`（除外理由 E2 を付記）。
- 既存レビュー・尺度の原著・理論は `背景保持`（証拠集合の外・引用追跡と概念比較用）。
- 報告ガイドライン・方法論は `方法論保持`。訂正通知は `訂正連結`。

## 3. スクリーニング（元ワークブックの語彙に合わせる）

- **TA 段（題名・抄録）**: `含める` / `除外` / `保留`
  - 含める = P と C に当たる可能性がある一次研究（★ 迷ったら含める＝全文段へ回す）
- **全文段**: `含める` / `除外` / `保留`（★ 全文を読めなかったものは判定せず `保留`、全文確認欄は `入手不可`）
- **除外理由コード**（★ この表にない理由で除外しない）:

| コード | 内容 |
|---|---|
| E1 | AI が人の疲労を検出・予測する道具であるだけ（AI 利用者の疲労を扱わない） |
| E2 | 疲労（または同等の消耗状態）を定義・測定・質的分析していない（隣接概念のみ） |
| E3 | 疲労を測っているが AI の利用・監督と関係づけていない |
| E4 | 一次研究でない（レビュー・尺度原著・方法論・訂正通知）→ 証拠集合の外で別枠保持 |
| E5 | 重複出版・同一標本の二次報告 |
| E6 | 全文を入手できず全文段の判定不能（→ `保留`） |

- ★ 「スクリーニング（除外）」と「保持」は別物である: E2・E4 の件は証拠集合から外すが、DB からは削除しない。

## 4. 方法論評価（JBI チェックリストの項目文に準拠した AI 予備判定）

- 「品質評価」欄の値: 全文で JBI 項目を埋めた件 = `完了`（★ ただし「AI 予備」と明記）／抄録のみ = `進行中`／非該当（方法論・訂正） = `対象外`。

## 5. 領域別評価（中心候補のみ・既存 AI 評価と同じ 6 領域で比較可能にする）

領域: 選択・標本 / 測定・構成概念 / 時間順序・因果 / 交絡・文脈 / 解析・整合性 / 透明性・版管理

段階（★ 判定規則を先に固定）:

| 段階 | 規則 |
|---|---|
| `低懸念` | その領域について本文で具体的な手当てが確認でき、主張の強さと釣り合っている |
| `一部懸念` | 手当ての一部が欠ける、または主張がデザインを少し超える（例: 横断データに媒介の語を使うが因果は主張しない） |
| `高懸念` | 引用する主張を直接損なう問題が一次で確認できる（例: 報告値の内部不整合で解析単位が特定できない／横断データから因果・長期効果を断定／疲労の測定がタイトルの構成概念と一致しない） |
| `判定不能` | 全文未取得、または記載なし・未確認で判断材料がない |

- ⚠️ 「時間順序・因果」は **因果解釈に使う場合の懸念**を評価する（関連の記述として引用するなら別）。
- ⚠️ 質的研究の「交絡」は `NA`（非該当）とし、代わりに研究者の位置・反例の扱いを「交絡・文脈」に書く。
