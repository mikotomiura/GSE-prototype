## 3. 合否の基準と記述（固定する節）

### 3.1〜3.8

第 1 回 design §3.1〜§3.8 と同じ（基準の値 0.03・0.08・0.10・0.90、境界の扱い、判定の分岐、固定した読み方の文、world v4 の宣言、記述の量、自己検査、乱数のタグ）。§3.8 の `SEED` は 20261013、下見 1 は `SEED + 1`、スモークは `SEED + 2`（第 1 回 design §8 の最後の行と同じ考え方）。

### 3.7 への追加（自己検査）

`select_lambda` の検査を次に替える（手で作った値・格子は §3.9 の 12 点）。

- 点推定が単調に増え、下限が点推定 − 0.008 のとき、帯に入る λ のうち点推定が 0.055 に最も近いものを返す。
- 0.055 に最も近い λ が下限の条件（> 0.03）を満たさないとき、それを選ばず、満たすほかの λ を返す。
- 0.055 に最も近い λ が上の条件（≤ 0.08）を満たさないとき、それを選ばない（帯の外の λ は、点推定が近くても選ばない）。
- 境界: 下限の最大がちょうど 0.03 の λ は帯に入らない・点推定の最大がちょうど 0.08 の λ は入る。
- 等度回帰で値がまとまった帯の中の λ が複数あるとき、帯に入る λ の中で中央（偶数なら小さいほう）を返す。
- 帯に入る λ が無いとき、全格子で等度回帰の点推定が 0.055 に最も近いもの（同じ同点の規則）を返す。
- 下限が NaN の λ は帯に入らない。点推定が NaN の λ は除き（`excluded`）、すべて NaN なら格子の最大（0.30）を返す。

### 3.9 下見 1（λ の選び方・固定の後）

- `run.sh --pilot`: `SEED + 1`（20261014）・P 240・world v4・ブートストラップ 2000。PC1 と、PC-stall 24 本を λ の格子 `[0, 0.025, 0.050, …, 0.300]` で回す。ラベルは L300 だけ・帰無は回さない・候補 24 本は回さない（候補の値を本番の前に見ないため・第 1 回と同じ）。自己検査（§3.7）を下見の列で先に回す。
- 各 λ の値は、第 1 回 design §3.2 の比べ方で出す: 天井の分類器（AUC(A_speed) ≥ 0.90）を外した後の 4 通り（または 2 通り）の、点推定の最大 `g(λ)` と 95% 区間の下限の最大 `l(λ)`。
- **帯に入る λ**: `l(λ) > 0.03` かつ `g(λ) ≤ 0.08`（λ > 0 の格子だけ・境界は第 1 回 design §3.2 と同じ）。`l(λ)` が NaN の λ は入らない。
- **選び方**（候補ごと）:
  1. λ > 0 の格子の `g(λ)` に等度回帰（単調非減少・等しい重み・EH1 の `isotonic_blocks`）を当て、当てた値 `ĝ(λ)` を作る。`g(λ)` が NaN の λ は除く。
  2. 帯に入る λ があれば、その中で `|ĝ(λ) − 0.055|`（小数 6 桁に丸める）が最小の λ を選ぶ。最小の λ が複数あれば、その中央（偶数なら小さいほう）。
  3. 帯に入る λ が無ければ、λ > 0 の全格子で同じ規則で選ぶ。この λ では本番で PC-stall が働かないことがありうる。本番での働きは本番の値で判定し（第 1 回 design §3.9 と同じ）、届かなければ判定不能（`weak_stall_pc`）。どちらでも定義は変えない。
  4. `g(λ)` がすべて NaN なら 0.30（格子の最大）を使う。
- 選んだ λ を `config.json` の `pc_stall.lam` に書き、各候補の `g`・`l`・`ĝ`・帯に入った λ・選んだ規則を §8 に書く。λ = 0 の値（土台）は記述として残す。差し引かない（P 240 では小さい見込み・第 1 回の本番の土台の点推定の最大は +0.005 以下）。
- 0.055 は 0.03 と 0.08 の中央。下見と本番の列は違う（seed が違う）ので、本番の値は下見の値から両側にずれうる。中央を狙うのは、どちらにずれても帯に残る余地を同じにするため。
- 下見 1 が `fit_failed`（学習側が 1 クラスの fold）になった、または PC1 が働かない（下限の最大 ≤ 0.10）ときは、λ を選ばず研究者に戻す。
- 下見 1 で本番の所要を見積もり直す。第 1 回の本番は `--jobs 16` で判定と記述に 16676 s だった。
