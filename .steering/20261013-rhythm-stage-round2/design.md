### 3.7 への追加（自己検査）

`select_lambda` の検査を次に替える（手で作った値・格子は `config.json` の `pilot_grid` の 12 点）。

- 点推定が単調に増え、下限が点推定 − 0.008 のとき、帯に入る λ のうち点推定が 0.055 に最も近いものを返す。
- 0.055 に最も近い λ の下限がちょうど 0.03（帯の外）のとき、それを選ばず、帯に入るほかの λ を返す。下限が NaN の λ も同じ。
- 境界: 点推定の最大がちょうど 0.08 の λ は帯に入り、0.0801 の λ は入らない。
- 同点: 3 つの同点はその中央、等度回帰でまとまった 2 つはその小さいほう、格子の上でつながらない同点（まとまった塊の中の 1 つだけが下限で帯から落ちる）は残りの中央（偶数なら小さいほう）、0.055 の上と下に同じ距離の 2 つがあれば小さいほう。
- 帯に入る λ が無いとき、全格子で 0.055 に最も近いもの（同じ同点の規則）。すべての `ĝ` が 0.055 より下で平らな頂上があれば、その頂上の中央（格子の最大とは限らない）。
- 帯の判定は等度回帰の前の値で、近さは後の値で測る: 元の点推定がちょうど 0.08 で、等度回帰でまとまった値が 0.055 の λ は、帯に入り選ばれうる（許す・§3.9）。
- 点推定が NaN の λ は除く（`excluded`）。すべて NaN なら選ばない（下見 1 は止まる）。
- 結合: 下見の名前は候補ごとに 13 個で互いに違う（3 桁）。手で作った下見の値から 24 本の λ を選び（λ = 0 は選ばれない）、`--apply-pilot` が `config.json` の `pc_stall.lam` だけを書き換え、本番の検査（`lam_problems`）がそれを受け入れる。止まった下見（選択が揃っていても）・規則の無い第 1 回の形の `pilot.json`・別の seed・別の P・別の規則・値から計算し直した選択と違う選択からは書かず、`config.json` を変えない。λ = 0 は、0.055 ちょうどで入れれば勝つ値にしても選ばれない。帯は等度回帰の前の `g` で決まる（元の `g` が 0.085 で、まとめた値が 0.06 の λ は帯に入らない）。小数 6 桁で等しい距離は同点になる（丸めないと浮動小数の誤差で大きいほうが勝つ組で確かめる）。
- 下見 1 の止まり: PC1 の下限の最大が 0.11 なら続け、ちょうど 0.10・NaN・PC1 が無いときは止まる。当てはめの失敗・両方の分類器が天井でも止まる。

### 3.9 下見 1（λ の選び方・固定の後）

- `run.sh --pilot`: `SEED + 1`（20261014）・P 240・world v4・ブートストラップ 2000。PC1 と、PC-stall 24 本を λ の格子 `[0, 0.025, 0.050, …, 0.300]` で回す。ラベルは L300 だけ・帰無は回さない・候補 24 本は回さない（候補の値を本番の前に見ないため・第 1 回と同じ）。自己検査（§3.7）を下見の列で先に回す。
- 各 λ の値は、第 1 回 design §3.2 の比べ方で出す: 天井の分類器（AUC(A_speed) ≥ 0.90）を外した後の 4 通り（または 2 通り）の、点推定の最大 `g(λ)` と 95% 区間の下限の最大 `l(λ)`。
- **止まる条件**（λ を選ばず研究者に戻す）: 当てはめの失敗（学習側が 1 クラスの fold）・L300 で両方の分類器が天井・PC1 の下限の最大が NaN か 0.10 以下（有限で 0.10 を超えるときだけ続ける）・ある候補の `g(λ)` が λ > 0 の格子ですべて NaN。止まったときも `pilot.json` は残す（`stop` に理由）。
- **帯に入る λ**: `l(λ) > 0.03` かつ `g(λ) ≤ 0.08`（λ > 0 の格子だけ・境界は第 1 回 design §3.2 と同じ）。`l(λ)` が NaN の λ は入らない。
- **選び方**（候補ごと）:
  1. λ > 0 の格子の `g(λ)` に等度回帰（単調非減少・等しい重み・EH1 の `isotonic_blocks`）を当て、当てた値 `ĝ(λ)` を作る。`g(λ)` が NaN の λ は除く。
  2. 帯に入る λ があれば、その中で `|ĝ(λ) − 0.055|`（小数 6 桁に丸める）が最小の λ を選ぶ。**同点**は、その中で距離が等しい λ の集合で、λ の昇順に並べた添字の中央（偶数なら小さいほう）を選ぶ（格子の上でつながっていなくてもよい）。
  3. 帯に入る λ が無ければ、λ > 0 の全格子で同じ規則で選ぶ。この λ では本番で PC-stall が働かないことがありうる。本番での働きは本番の値で判定し（第 1 回 design §3.9 と同じ）、届かなければ判定不能（`weak_stall_pc`）。どちらでも定義は変えない。すべての `ĝ` が 0.055 より下なら、`ĝ` の最大の塊の中央になる（第 1 回の「すべて目標の下なら 1.0」に当たる規則は置かない）。帯の下（`l ≤ 0.03`）でも `ĝ` が 0.055 を超えることはあり、そのときは最大の塊にはならない。
  4. 帯は等度回帰の前の `g`・`l` で決め（本番の判定と同じ値）、近さは等度回帰の後の `ĝ` で測る（格子の揺れを均す）。`g` が単調でないとき、元の `g` が帯の端（0.08 ちょうどなど）にある λ が `ĝ` の近さで選ばれることがあるが、それは許す（帯に入っている）。
- 選んだ λ は、この入れ物から `$PYTHON scripts/checks.py --apply-pilot config.json results/pilot/pilot.json` で `config.json` の `pc_stall.lam` に書き、各候補の `g`・`l`・`ĝ`・帯に入った λ・選んだ規則を §8 に書く。λ = 0 の値（土台）は記述として残す。差し引かない（P 240 では小さい見込み・第 1 回の本番の土台の点推定の最大は +0.005 以下）。λ = 0 の上限の最大が 0.03 以上の候補は、本番で `stall_baseline` になる見込みとして §8 に書く（土台の条件 (3) は λ に依らない）。
- 0.055 は 0.03 と 0.08 の中央という目安である。帯の下側は点推定ではなく下限にかかるので、点推定で見た帯はおよそ (0.03 + 区間の下側の幅, 0.08] になり（第 1 回の本番で幅は 0.005〜0.009）、0.055 を狙うと下側の余地（約 0.017）は上側（0.025）より狭い。余地が対称になる保証は無い。研究者は 0.055 のままとした（判断 3）。下見が P 240 になれば、下見と本番のずれは主に seed の違いになる見込み（推論）。
