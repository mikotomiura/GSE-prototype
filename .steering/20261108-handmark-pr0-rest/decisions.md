# 重要な設計判断

## 判断 1: 持ち込みの形（研究者が 1 問ずつ選んだ・2026-11-08）

- **§1.4 と D2 の食い違い**: 枝の §1.4 は「状態（停滞・速さなど）を形から当てられない」を要件にし、反証の条件 3 は全体の速さの漏れを問う。ADR-048 D2 は速さ・リズム・止まりを許す行為の性質とし、要件を「許した情報を超えて系の判断を漏らさない」に変えた。ADR-051 D3 はポインタの量を加えた。→ **本文を D2 に合わせて書き直し**、節の頭に 2026-11-08 の注記で枝の版から変えた点を書く。理由: main で初めて入る節で、古い要件を本文に置くと読み手が古い契約を掴む。採らなかった案: 写して注記で読み替える。
- **文献**: [P485]〜[P554] の 70 本とカード 5 枚（S-TG・S-TN・S-TN2・S-CO・S-NW）と `_index.md` の 5 行を全部持ち込む。理由: 番号が連続し、各番号の出どころのカードが main にそろう。採らなかった案: §1.4 が引く 7 本（＋カード 1 枚）だけ。
- **枝の ADR-040**: 冒頭に「main で ADR-050 に振り直した」注を足す（枝へのコミット）。
- **/reimagine**: 当てない。
