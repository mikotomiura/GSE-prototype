# 研究者の手順書 —— 波紋の小面の試視

この Mac では Claude が画面を撮れないので、見え方は研究者に見てもらいます。10〜15 分の見込みです。結果は Claude に口頭で伝えてください（`results.md` §6 に書きます）。

## 0. 起動と後片づけ

ターミナルで、次をそのまま実行します（記録はすべて一時フォルダに入り、`~/Documents/GSE-sessions` には書きません）。

```bash
cd /Users/johnd/GSE-prototype-handmark-a
export GSE_DATASET="$(mktemp -d)/gse-spike"; echo "$GSE_DATASET"
GSE_HANDMARK_SPIKE=1 GSE_DEBUG=1 VITE_GSE_DEBUG=1 npx tauri dev
```

- 計測の環境変数（`GSE_HANDMARK_SPIKE_MEASURE`）は付けません。CSV は書かれません（前の試作の判断 4）。
- 本体の窓で「開始する」を押します。小面はセッション中だけ動きます。
- セッション中は、本体がいつもどおり打鍵の時刻とキーの種類を NDJSON に書きます（中身は書きません）。書き先は上の一時フォルダです。終わったら、トレイ（メニューバーの GSE）の「GSE を終了」で止め、次で消してください。

```bash
rm -rf "$GSE_DATASET"
```

- 小面は画面の右下の端の小さな灰色の点です。打つたびに、点から輪が 1 つ広がって消えます（250 ms）。続けて打つと、前の輪を打ち切って点から描き直します。トレイの「小面を閉じる」で消せます。
- 起動してから最初の数打は、輪が出ないか遅れることがあります（`results.md` §4 の起動直後の遅れ）。数打打ってから見てください。

## 1. 見てほしいこと

いつもの作業（文章でもコードでも）を 5 分ほど打ちながら、横目で見てください。

| # | 見るもの | 聞きたいこと |
|---|---|---|
| 1-1 | 打った瞬間に返ってくるか | 自分の打鍵に合わせて動いていると感じるか |
| 1-2 | 速く打っているとき | 一打ごとの輪の戻りが見分けられるか、それとも「ずっと動いている」に見えるか（測った範囲では、毎秒 4 打より速いと動きが途切れない・`results.md` §1） |
| 1-3 | 止まったとき | 止めるとすぐ点だけに戻るか |
| 1-4 | 邪魔さ | 視野の端で気になるか・作業の目が奪われるか |
| 1-5 | 状態として読めるか | 小面から「打っている / 止まっている」より多いこと（速さ・詰まり具合）が読めてしまうか |
| 1-6 | 色 | 灰のままでよいか（壁紙や窓の色によって見えにくくないか）。決めるのはこの後 |
