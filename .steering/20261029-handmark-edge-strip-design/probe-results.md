読めること:

1. **全画面の中では、どける操作で背景は出せない。** 外から全画面のアプリは隠れず、accessory の自分も前面に出られない（2 回）。全画面の間に背景を見せる面は、下の縁の帯だけになる。
2. **全画面でないときは、前面に出てから隠せば前面のアプリも隠れる見込み（推測・1 回ずつの揺らぎの可能性もある）。** run11 では前面のアプリも隠れた（`active_not_hidden=0`）が、待たずに隠した run12・run13 では前面のアプリが 1 つ残った。前面に出るのは非同期で、間に合うかどうかで分かれたと読む（推測）。前面になるのを待つ版は全画面の外ではまだ試していない。そのため「全画面の外なら `active=1` になる」という陽性対照がなく、待つ判定そのものが効くかは分かっていない。
3. **前面に出られないアプリが 1 つ残ることがある**（run11 の 1・run15 の 2 のうち前面でない 1）。研究者は VS Code と見た。原因は見ていない。
4. **戻すときの重なりの順番は、run12・run13 の 2 回（層 0 の窓 3 枚）で、窓の番号のうえで元どおりだった。** run11 には順番の検査がない（足す前）。run14・run15 の `same_order=1` は、全画面の中で隠す前後とも窓が 2 枚のまま変わらず、検査になっていない。run11 で Safari が見えなかったのは再現しなかった（原因は分からないまま）。`--restore-order` は元の前面のアプリを前面に戻す点で効いた（run13・1 回）。戻し方はアプリ単位（`activateAllWindows`）なので、アプリ A の窓・B の窓・A の窓のような交互の重なりは元どおりにならない（試していない）。
5. 帯の負荷は 1 コアの約 7〜11%（60 回/秒）で、前のタスクと同じ。

## 試し 4: regular のまま非アクティブの NSPanel（論点 1 の v2・run16）

条件: `--regular --panel`（GSE 本体と同じ regular・`NSPanel` の `[.borderless, .nonactivatingPanel]`・浮く層・前と同じ振る舞い）。テキストエディットを AXFullScreen で全画面にした約 25 秒の間を読んだ。隠す操作はしていない。

- 記録: 全画面の間（8〜33 秒）ずっと `onscreen=1`・`visible=1`。負荷は 1 コアの約 7〜11%。`front_of_layer0=1` も続いたが、浮く層の窓は層 0 より前に並ぶので、この値はほぼ必ず 1 になり、全画面の窓の上にある根拠にはならない（全画面の窓は層 0 の数え方に現れていない見込み）。根拠は `onscreen=1`（前のタスクの regular の NSWindow は全画面の Space で 0 だった）と研究者の目視。
- 研究者の目視: 「見えた」。
- 読めること: **regular のアプリでも、非アクティブの NSPanel なら他アプリの全画面の上に帯を出せた**（1 回）。前のタスクで regular の NSWindow が全画面の Space に入らなかったのと分かれたのは、窓の種類（NSPanel・nonactivating）。どちらが効いたか（NSPanel であること・nonactivating であること）は分けて測っていない。テキストエディット以外の全画面では見ていない。

## 試し 5: 全画面の外での陽性対照（cross-review B・run17）

条件: 全画面にしない。`--activate-first --abort-if-inactive --restore-order`（前面になるのを最大 1 秒待ち、出られなければ隠さずにやめる）。

- 記録: `activate_wait_ms=1007 active=0`・`hide aborted_inactive=1`。何も隠さなかった（見える 12・隠れ 1 のまま）。
- 読めること: **試作の「前面に出られたか」の判定は、全画面の外でも 0 だった。** 全画面を見分ける判定になっていない。試し 3（run14・run15）の `active=0` も、全画面のせいとは言えない。端末から起動された裏のプロセスは、他のアプリが前面のとき自分で前面を取れない見込み（macOS の前面の取り方の決まり・推測・一次資料は見ていない）。run11 で前面のアプリが隠れ、run12・run13 で残った違いも、待つかどうかではなかった可能性がある。
- 本物の GSE ではトレイのクリック（利用者の操作）がきっかけになるので、結果は違う見込み（未確認）。
