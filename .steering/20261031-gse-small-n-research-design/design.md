# 設計の案

## 案 A: 3〜5 名を事例として重ねる（2026-10-31・Claude 初案）

人数を標本として扱い群の平均を出す考えをやめ、1 人ひとりを独立した事例として扱う。同じ結果が事例をまたいで繰り返されるか（再現）で一般化を支える。

1 人あたりの流れ（WBS の Phase 1 → 2 を 1 人の中で回す）:

1. ベースライン期（Nudge なし・推定は本人に見せない）: プローブで Q1/Q2 を集め、L0 をその人の中で判定する。1 人あたり 20 件以上を確保できる期間を取る。
2. 介入期（Nudge あり）: ベースライン期と比べ、`receipt_free_resumption` 等の行動指標がその人の中で変わるか。
3. 人をまたぐ部分（多重ベースライン）: 介入期への切り替え時点を人ごとに無作為にずらす。無作為化検定は 1 人でも有効。
4. 介入期の中の無作為化（任意）: Nudge を出す時点ごとに出す・控えるを無作為に割り付ける（1 人の中の MRT）。
5. 事例ごとに面接・日誌で「GSE と暮らして何が起きたか」を記述する。

削る・延期: 群の平均としての Y、AB/BA、完全な MRT（X2）、Physical Anchor、作業種別どうしの比べ。

採択前: 研究者本人の記録で手順を一度通す（L0 の証拠にはしない・試運転）。審査に出す計画と同意文を仕上げる。

未接地（文献で確かめる）: 単一事例の設計の基準（効果の再現の回数など）、1 人の中の MRT の成立条件、HCI の少人数の現場展開研究の慣行、自伝的デザイン。

## Codex の第二意見（2026-10-31・codex-consult・入力は scratchpad の codex-consult-input.md）

1. 主要アウトカムの観測可能性（最優先）: 打鍵の再開だけでは自力の前進と転記・無関係な入力を区別できない。別端末の AI の答えは観測できない。→ 一次で確認: ADR-024 は受領を clipboard 経由の paste に限り「構造的に受領なしへ倒れる」と自認（:304）、分子は成果を求めない（:232）、起点は Stuck エピソード後の 180 秒以上の途絶明け（D1）。指摘は当たっている。
2. A と B は別の効果を測る（A: Nudge が届く運用への移行 / B: 履歴の下で 1 回足す効果）。主要な因果効果を 1 つに決め、観測窓と次の割付を重ねない。
3. 「数百時点 = 高検出力」ではない（同じ詰まりの反復・希少イベント・欠測・介入による適格時点の減少）。予備観測からシミュレーションで最小効果と区間幅を判定。単純な入れ替え検定は割付規則と整合させる。
4. 計測の検証は介入前でも汚れうる: 個人の調整と C-index の評価に同じラベルを使うと楽観化する。時間順に調整区間と評価区間を分ける（ADR-008 D4 と同じ向き）。同順位・未回答・プローブ自体の介入性。順位の性能は発火閾値付近の精度を保証しない。
5. 追加候補: 推定器のタイミングの価値を直接比べる（頻度を合わせた無作為時点 / 単純な休止ルール）。Nudge 自体の効果と推定器の付加価値を分けられる。
6. 再現は「全員有意」より条件の説明（本人を独立に示す・作業種別や AI 利用習慣の差を意図的に含める・失敗事例も並べる）。A の開始候補が少ないと検定が粗い → A を補助に下げる簡素化も。

## 案 B: 計測は自然作業で、介入効果は統制課題で（2026-10-31・Codex の 1・3・5 を受けて Claude が組み立て）

- 計測（主張 1）: 自然な作業の長い記録（O1 に近い形）で、1 人ごとに時間順に調整区間と評価区間を分けて L0 を判定する。介入なし。
- 介入効果（主張 2）: 答えの入手経路を統制できる課題のセッション（G1 の統制課題の基盤を流用する想定）で行う。AI の答えはアプリ内の経路からだけ入手できるようにし、受領を観測可能にする。課題は詰まりが起きやすいものを選び、希少イベントの問題を緩める。
- セッションの中で、Nudge の出し方を {推定器のタイミング / 頻度を合わせた無作為のタイミング / 出さない} に無作為に割り付ける。Nudge 自体の効果と推定器の付加価値（＝計測の主張の実用上の価値）を分けて言える。
- 1 人あたり多数のセッションを取り、個人ごとの判定を事例をまたいで並べる。
- 代償: 生態学的妥当性（自然作業での効果は言えない）。課題の設計と、アプリ内の答えの経路の実装が要る。統制課題で AI の答えの経路を作ることは、G1 の現行設計にない。

## 案 A と案 B の違い（要点）

| | 案 A | 案 B |
|---|---|---|
| 介入効果を測る場 | 自然作業 | 統制課題 |
| 受領の観測 | paste のみ（受領なしへ倒れる） | 経路を統制して観測可能 |
| イベントの頻度 | 少なくなりやすい | 課題で起こしやすい |
| 推定器の付加価値 | 分けられない | 無作為タイミングと比べて分けられる |
| 言える範囲 | 日常での効果 | 統制下での効果（日常は言えない） |
