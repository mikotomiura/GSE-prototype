# 設計

## 実装アプローチ

3 段で進める。**変換器 → 図 → デッキ**。前段が終わらないと後段が成立しない依存がある
（図を置けない変換器のままでは「図を積極的に使う」デッキが作れない）。

### 段 1: `scripts/md2pptx.py` の改修

引き継ぎが挙げた 5 つの穴＋レイアウト単一化を塞ぐ。

| # | 穴 | 直し方 |
|---|---|---|
| 1 | テンプレートを読めない | `--template <path>` を足し `Presentation(template)` にする |
| 2 | スライドサイズを無条件上書き | **テンプレート指定時は代入しない** |
| 3 | 見本スライドが残る | `_drop_all_slides()`（`drop_rel` と `sldIdLst.remove` を対で） |
| 4 | 図を置けない | `![alt](path)` を実装。`md2docx.py` の規約（相対解決 / repo 外拒否）を移植 |
| 5 | 表を行として流す | `shapes.add_table()` で **本物の `a:tbl`** にする |
| 6 | 全スライドが 1 レイアウト | スライドごとに `kind` を決め、`kind` ごとにレイアウトを選ぶ |

### 段 2: 新規図 5〜6 枚

既存 4 枚に倣い **SVG が正本 → PNG を書き出す**。⚠️ 書き出し手順は
`facts-claims.md` 末尾（LibreOffice `draw_png_Export`・**md5 一致で復元済み**）。

### 段 3: デッキの再構成

技術・アーキ・研究手段を主軸に据え直す。降ろしてはいけない節（主張の層構造 / 確証するのは L0 だけ /
較正前後の介入可否 / 未実装の明示）は残す。

## ⚠️★★★ 着手後に判明し、設計を変えた事実（2026-09-04 実測）

### (a) テンプレートは Google スライドの書き出しで、**装飾を各スライドが直接持つ**

引き継ぎは「レイアウトのプレースホルダ座標」を実測していたが、⚠️ **同梱スライドはその座標を使っていない**。

| | レイアウトの継承座標 | 同梱スライドが実際に使う座標 |
|---|---|---|
| TITLE | (1.40, 0.68) 7.64 x 0.45 | **(0.29, 0.18) 5.97 x 0.25 / 15pt** |
| BODY | (0.80, 2.50) 9.01 x 1.60 | (0.49〜0.80, 1.72〜2.55) 高さ 0.30〜1.82 |

さらに各スライドが持つもの:
- 全面 `#F4F4F4` の矩形（`custGeom`）
- **左端 0.16 x 5.62 inch の青いグラデーション画像**（`ppt/media/image6.png`・全 6 枚に存在）
- `p:sld` に `showMasterSp="0"`（マスタ図形を隠す）

→ ⚠️★★★ **レイアウトを継承するだけでは、テンプレートの見た目にならない。**

### (b) テンプレートに **`docProps/app.xml` が無い**

Google スライドの書き出しが出力しないため。⚠️ `python-pptx` はパート構成を引き継ぐので
**出力にも app.xml が無くなり**、`verify()` の必須パート検査に落ちる（実測で落ちた）。

### (c) `verify()` の検査 (7) に**偽陽性があった**

表紙レイアウトの `ctrTitle` / `subTitle` は master の `title` / `body` を継承するのが**正常**だが、
type 名で素朴に照合していたため違反として出た。
⚠️ **旧版で露見しなかったのは、全スライドが「タイトルとコンテンツ」1 種類だけを使い、
表紙レイアウトを 1 度も参照しなかったから**（★ 検査が空回りしていたのではなく、経路が無かった）。

## 判断

### D1: レイアウト種別の表現 —— 明示ディレクティブ ＋ 自動判定の併用

| 案 | 内容 | 判定 |
|---|---|---|
| A | `.pptx.md` に `<!-- layout: two -->` を書く | 明示的だが全スライドに書くのは冗長 |
| B | 図の有無で自動的に振り分ける | 楽だが表紙を作れない |
| **C（採用）** | **自動を既定にし、`<!-- layout: ... -->` で上書きできる** | 表紙だけ明示、あとは自動 |

自動規則: 図あり＋本文あり → `two` / 図のみ → `figure` / それ以外 → `content`。
`title` は**明示指定でしか選ばれない**（自動で表紙を作ると事故る）。

### D2: 版面はテンプレート継承ではなく**明示座標**にする

★ 理由は上記 (a)。継承すると本文枠が **9.01 x 1.60 inch（版面の 3 割弱）** のバナー型になり、
図も密度のある技術説明も入らない。
★ 座標は**スライド寸法に対する比**で持つので、寸法の違うテンプレートでも崩れない
（`Geometry` クラス）。

⚠️ ただし**テンプレートの「地」は引き継ぐ**（次項）。「基盤に採用する」を満たすのは
配色・フォント・背景・左端の帯であって、使えない本文枠ではない。

### D3: 「地」(chrome) の複製規則

同梱スライドのうち **図形数が最小のもの**（同数なら先頭）を見本とし、
**プレースホルダでなく・文字を持たない図形だけ**を全スライドの**最背面**へ複製する。
`--chrome-from N` で明示指定でき、`--no-chrome` で無効化できる。

★ `deck_temp1.pptx` では 2 枚目が選ばれ、複製されるのは
**背景矩形 ＋ 左端の帯**の 2 図形（＝狙いどおり。表紙の装飾やお断り書きは入らない）。
★ 画像を含む図形は `r:embed` を張り替える（`_ChromeSpec` が参照先パートを実体で保持）。

### D4: 欠けている `docProps/app.xml` は**出力側で補う**（検査は緩めない）

⚠️ 必須パート検査から外すと、テンプレート無しの経路で本当に欠落したときに気づけなくなる。
→ `_ensure_app_xml()` で content type と関係も対で足す。

### D5: 表は**本物の `a:tbl`** にする

引き継ぎは「図中心にするなら表を減らすのが先」と書いていたが、指定内容
（モデル比較・昇格ゲート・OS 制約）は**表が最も読みやすい形**である。
`python-pptx` の `add_table()` で足りるため、減らすのではなく作れるようにした。
★ テンプレートに `ppt/tableStyles.xml` が無いので、**セル塗りを自前で指定**する
（ヘッダ = テーマ dk2 `#158158`、本文行 = 白 / `#EAEAEA` の交互）。

### D6: 図の書式は PNG のみ

⚠️ `python-pptx` は SVG を画像として認識しない。★ repo の正本は SVG のままにし、
**スライドからは書き出した `.png` を指す**。`.svg` を渡したら明示的に失敗させる。

## 影響範囲

- `md2pptx.py` を使うのは設計スライド 1 本だけ（`docs/mitou_submission/README.md` の再生成節）。
  ⚠️ ただし CI (`frontend-check`) は `md2docx.py --selftest` を回しており、
  **`md2pptx.py --selftest` は CI に入っていない**（実測）。→ 入れるかは finish-task で判断。
- `figures/` に `.svg`/`.png` の対を足すと `md2docx.py --selftest` の**寸法一致検査が増える**。
- ⚠️ `.pptx.md` は `check_doc_lexicon.py` の検査対象。★ / ⚠️ を 1 文字も入れない。

## 既存パターンとの整合性

- 画像の解決規約（相対 / repo 外拒否 / 形式限定）は `md2docx.py` に合わせる。
- selftest の作法（**変異体を実際に作って落ちることを確かめる**）は `md2docx.py --selftest` に倣う。
- 出力の再現性（ZIP 日時固定・`FIXED_TS`）は既存のまま。
- 図は SVG が正本・PNG が書き出し（既存 4 枚と同じ手順・md5 で復元確認済み）。

## テスト戦略

- **単体 / 変異体**: `PYTHONUTF8=1 python scripts/md2pptx.py --selftest`
  （★ 解析 4 件・既定経路・テンプレート経路 9 件・変異体 10 件）
- **統合**: 実テンプレートで実デッキを生成し、`verify()` 7 点＋`measure()` を通す
- **語彙 / 引用**: `check_doc_lexicon.py` / `check_citations.py`
- **図**: `md2docx.py --selftest`（`.png`/`.svg` の寸法一致）
- ⚠️★★★ **目視**: LibreOffice で PDF 化 → PyMuPDF で各ページを PNG 化して実際に見る。
  ★ `--selftest` は ZIP と枚数と構造しか見ない。
- **事実照合**: 一次資料との突き合わせを**別エージェント**に投げる
  （★ 機械検査 3 本が全部緑のまま事実誤りが出た実績が 2 回ある）
