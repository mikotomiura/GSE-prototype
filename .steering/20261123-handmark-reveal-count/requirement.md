# 要件: 手跡の「ほかの窓をどける」とどけた回数（手跡の PR 6）

## 背景

- 3 名の段 1 に配る前の条件のうち、同意文書の条件 4 が残っている（`.steering/20261114-gse-stage1-n3-consent/consent-draft-s1.md` 末尾の表）。条件 4 は「どけた回数の記録が入った版で 3 名を始める（手跡の PR 6）。入らないなら本文の『ほかの窓をどけた回数』と項目 8 を直す」。
- 承認済みの同意文書は、すでに次の 2 文を約束している。
  - 「表示を見るために、ほかのアプリの窓をいったんどけることができます（もう一度操作すると戻ります）」（138 行）
  - 記録するもの「表示を始めた時刻、ほかの窓をどけた回数」（146 行）
- main には、どける操作も回数の記録も無い（2026-11-23 に origin/main 03cae459 で `tray.rs`・`handmark_*.rs` を grep して確かめた）。
- 決定の一次資料:
  - ADR-051（「入れる」に「背景を見る」を含む。どけた回数は本 ADR で扱い、入れる PR で schema と同意の文を改める）
  - `.steering/20261108-handmark-to-main-plan/decisions.md` 判断 6b（PR 6 の範囲）
  - window-boundary 判断 4・5（枝 `docs/tangibility-design` の a069dab1）
  - 同意のタスクの判断 3（記録する・同意に入れる）と判断 6（トレイの文言）
  - predist-fixes 判断 1・2・10（区間の削除で累計を引く仕組み・一時停止中は量を足さない）
- 3 名は両 OS で募り、Windows 版の手跡が通るまで始めない（ADR-052 D5）。

## ゴール

両 OS で、表示が出ている間だけトレイから「ほかの窓をどける」「窓を戻す」が使える。どけた回数が、日ごとの行（`handmark_day`）の累計として記録される。区間の削除と一時停止は、今ある量と同じ規則に従う。

## スコープ

### 含むもの
- 両 OS のどける・戻すの実装と、トレイの項目
- `handmark_day` の累計の項目・schema・区間の削除
- ADR-051 の補訂、同意文書の条件 4 の行への書き足し

### 含まないもの
- Mac の実機での確かめ（本人の段 1 の後期が終わる 12-09 以降。引き継ぎに書く）
- Windows の実機での確かめ（G-GEAR 側のセッションに任せる。引き継ぎに書く）
- 同意文書の文面の変更（今の文のまま約束を満たす）
- 3 名の版のリリースと配布、フォームの配備、台帳と管理シート（別のタスク）
- 本人の段 1 の配布フォルダ（`~/Desktop/S1_実施用_macOS/`・v0.1.42）への反映（前期と後期で計器を変えない）

## 受け入れ条件

- [ ] トレイの項目は、手跡の表示が出ている間（あり の日と後期の初日で、「やめる」を押していないとき）だけ出る。文言は「ほかの窓をどける」で、どけている間は「窓を戻す」になる。手跡・背景・状態の語を含まない（`handmark_tray_labels_are_plain` を広げる）。
- [ ] どけるときは、押した時に見えていた他のアプリだけを覚え、戻すときにはそれだけを戻す（macOS: hide/unhide・Windows: 最小化と元の重なり順での復元）。覚えた一覧は記録しない。
- [ ] 表示をやめた・日が変わった・入口の門が閉じた・アプリを終了するときは、どけた窓を自動で戻す。
- [ ] `handmark_day` に、どけた回数の累計の項目が 1 つ増える。数えるのは「どける」だけ。一時停止中は足さない。
- [ ] 区間の削除で、消した区間の回数が、前後の行の差の規則（predist-fixes 判断 1）でその日の後の行と状態ファイルから引かれる。テストと変異で縛る。
- [ ] schema（`schema_dto.rs`・`emit_schema`・`src-tauri/schema/current.json`）を作り直し、gse-dataset と照合する。
- [ ] 回数は本人に見せない（ダッシュボード・トレイ・帯のどこにも出さない）。
- [ ] 判定に関わる処理（いつ項目を出すか・いつ自動で戻すか・回数の足し方）は OS に依らない純関数にして `cargo test` で縛る。OS の呼び出しは OS ごとのファイルに閉じ、unsafe はラッパーに隔離する。
- [ ] ADR-051 に補訂を足す（どけた回数の記録の形と、Windows の作り）。
- [ ] 同意文書の条件 4 の行に、満たした版と根拠を書き足す。
