# 設計（議論のタスク）

実装と試作はしない。このファイルは議論の進め方だけを書く。決定は `decisions.md` が一次。

## 進め方

1. 引き継ぎ §3 の論点を、研究者に AskUserQuestion（推奨と理由を添える）で問う。
2. 論点 1・2 の前に調査 S-TG を 1 ラウンド回す（判断 5・11）。手順は `/literature-review`。
3. 決定は「決定 / 理由 / 却下案」で `decisions.md` に書く。
4. 結果を `.idea` §13 にまとめる（判断 7）。

## 守ること

- 合成の列だけを使う。キーストロークの内容・NDJSON を外部の LLM（Codex を含む）に送らない。
- `src-tauri/`・EH3 のファイルに触れない。
- `git add -A`・`git add <dir>` を使わない。
