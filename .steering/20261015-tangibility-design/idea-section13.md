## 13. 打鍵からの手応え（タンジブリティ）の設計（2026-10-15・タスク `tangibility-design`）

> 一次は `.steering/20261015-tangibility-design/`（ブランチ `docs/tangibility-design`）の `decisions.md` 判断 1〜17 と、調査 S-TG のカード `docs/literature/20261015-tangibility-agency-trace-replay.md`（[P485]–[P502]）。本節は要約で、一次ではない。EH0 の案で、ADR ではない。版管理の写しは同じタスクの `idea-section13.md`。

### 13.1 何を狙うか（判断 1・8）

- §1 の「タンジブルさ」を、**自分の作業（打鍵を含む）から形が生まれたと分かる手応え（作者性）**の意味で設計する。物体（判断 7）と本人が手を加えること（触る・残す・捨てる・名付ける）は保留にした（判断 6。起こす条件: 画面だけでは手応えが成り立たないと分かったとき・EH3 で判断 7 の条件 (a)(b)(c) が出たとき）。
- 狙うのは手応えと予期しない驚き（ワクワク）。**達成感は狙わない**（評価か量の蓄積から生まれやすく、§2 の制約とぶつかる）。

### 13.2 3 つの面と 3 つの案（判断 9〜16）

| 面 | 規則 | 載せる案 |
|---|---|---|
| 壁紙（再着手の面） | EH3 のまま（肖6・判断 5・U-4） | — |
| 画面端の小面 | 肖像の規則を引き継ぎ、**肖6 だけ外す**（推定を使わない・操作を記録しない・持ち越さない・すぐ閉じられる・取り込みから外す・数値や良し悪しを載せない） | **A 一打ずつ**: 打鍵のたびに 250 ms 以内に小さな変化が届き、すぐ止まる ／ **C 出会いの再生**: 本人がカーソルを乗せる・押したときだけ、その回の形が打った順に数秒で描き直される（きっかけは記録しない） |
| 背景のステージ | 壁紙と同じく時計で更新し、打鍵の最中は動かさない（肖6・判断 5 を当てる） | **D の形を滑らかに移し替える**（画の切り替えでなく数秒の移り変わり） |

- **D 手触りの写像**（全面に共通の材料）: 打ち方の**全体の速さを割り引いた相対のタイミング**（打鍵の間隔の比など）を形に写す。速さそのものは写さない（判断 14・仮説）。
- §12 のステージの提案のうち、リアルタイムの部分は小面の A に移り、ステージには滑らかさが残った（判断 15）。

### 13.3 調査 S-TG の要点（網は粗い・5 angle）

- 予測による主体感は 200〜250 ms 以内の応答に支えられる（[P485] [P486]）。遅れた結果に事後の推論の経路が残る可能性はあるが、数秒〜数分の遅れで測った実験は 0 件。→ A だけが予測の手応えを運べる。C と D は事後の推論と認識に頼る。
- 打鍵ごとの応答の代償を直接測った研究は 0 件。近い証拠は代償の側にある（動き続ける周辺表示は止まりと動きを繰り返す表示より妨げる [P267]・周辺の動きは最も邪魔 [P502]・自己へ向くフィードバックは成績を下げうる [P235]）。→ A は小面に限り、離散にした。
- 自分の運動は時間をおいても時間の構造から見分けられうる（[P489]・見分けられない動きもある [P490]）。ピアニストはテンポを除いても自分の演奏を見分けた（[P492]・抄録の要約・[P493] は逆向き）。人が自分の打鍵のリズムを見分けられるか、写した形で自分と分かるかは 0 件。→ D の材料を相対のタイミングにした根拠と、その不確かさ。
- 自分の過程の再生は気づきを生む（[P494]）が、痕跡を見せることが自意識を生んだ例があり、著者は本人が見え方を制御することを緩和に挙げる（[P495]）。→ C は本人が見に行ったときだけ。
- 消える作品を失う喪失の証拠はこの範囲で 0 件。作ったものへの愛着は完成に依存する（[P501]・抄録）。→ 決定 A を変える理由は得られなかった。

### 13.4 そのほかの決定

- 肖像と招待の分け方を機械で守る検査を入れる（判断 2・別タスク・小面にも同じ門を当てる）。
- EH3 の F-1 は、凍結の前に研究者が自分の壁紙で数日見比べて選ぶ（判断 3・基準は「予想しない形が返るか」「良し悪しに見えないか」）。

### 13.5 未決と次

- **次の段**: 相対のタイミングが停滞と速さを写さないかを、G-GEAR のステージの机上の検査の計器で合成の列から測る（判断 17）。[P492] [P493] の本文を読む。
- 未決: 本人が自分の打ち方と分かるか（人の段でしか測れない）／小面の大きさ・位置・A の変化の中身／ステージの移り変わりが打鍵の最中に重なったときの扱い／C のきっかけを記録しないことで ADR-033 を保てるかの実装の確認／小面を見た人には打鍵の有無が分かる（取り込みから外すので画面共有には映らない）。
