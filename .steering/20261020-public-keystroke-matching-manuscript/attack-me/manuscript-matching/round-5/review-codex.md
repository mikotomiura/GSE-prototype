1. **[severity: major] C2が「算出可能性」と「値の一致度」を混同**
   - **位置・引用:** `conclusion.tex`: “matching fell as the process measures were lost”; `abstract.tex`にも同表現。表4ではR7の全水準が`0/10/0`。
   - **問題:** 抑制率を上げても算出する指標数は減らず、変わるのは近似値とR0との相関です。また、非劣位点に限定した単調な交換関係は、その選択規則から生じる性質でもあり、独立した実証的発見としては弱い。「指標を保つにはこの損失が不可避」という含意までは支えません。
   - **解消条件:** 要約群を「評価した非劣位の形式では、照合率とR0との順位相関がともに低下」に統一。数値は維持し、反復する非劣位の説明を削減する。指標数・一致度・得点との関係を別の量として扱う。
   - **自信:** 高。

2. **[severity: major] A0との点推定の一致が、差の不存在に読める**
   - **位置・引用:** `abstract.tex`／`conclusion.tex`: “no more than the total length alone gave”; `generated/main-1000.tex`: R7(0.5)の利得`0.0 [0.0, 1.1]`。
   - **問題:** 最大値の候補にA0自身を含むため、利得は構造的に非負です。A0が選ばれたことは、他攻撃者との差が実質的にゼロであることの検証ではありません。区間も最大1.1ポイントの利得を含み、基準の2.2%に対して小さくありません。
   - **解消条件:** “A0 was the strongest attacker in the main analysis”という選択結果の記述に置換。同等性を新たに検定する必要はなく、本文の利得区間を参照すれば足ります。
   - **自信:** 高。

3. **[severity: major] 後の本文公開だけで保護が必ず失われる、という一般化**
   - **位置・引用:** `discussion.tex`: “processing protects a text only while no later release contains that text”; “the processing no longer keeps the two apart.”
   - **問題:** 本文が公開されることと、その本文を特定の処理済みログにリンクできることは別です。本文公開は補助情報を供給しますが、対応関係の確定を保証しません。これは、競合データとの照合を実施しないという既知の限界ではなく、処理全般についての新しい過剰主張です。
   - **解消条件:** 「後の公開は候補本文を利用可能にし、共通のログ等が残れば対応付けを可能にする」と条件化するか、断定部分を削除。
   - **自信:** 高。

4. **[severity: minor] 抑制の乱数に関する推定対象が不明瞭**
   - **位置・引用:** `protocol.tex`: “The random processing of R5, R6 and R7 is applied once per log”; “Intervals are percentile bootstrap intervals with writers as units”.
   - **問題:** 区間が、固定された今回の処理済み標本に条件付けたものか、処理を繰り返した場合の平均性能まで表すのか判別しにくい。書き手の再標本化は観測済みの処理結果の変動を含みますが、同じログを再処理した際の安定性は直接評価しません。
   - **解消条件:** 推定対象を一文で限定。追加検証をするなら、全解析の再実行より、C2を支える抑制水準だけ複数シードで感度を見る選択肢がある。
   - **自信:** 中〜高。

5. **[severity: minor] 4,992人の結果にλの適用範囲が曖昧**
   - **位置・引用:** `results.tex`: “with the registered $\lambda = 4$, A2 gained on R4(4) …, and on all 4,992 writers R4(4) reached 0.65\%”.
   - **問題:** 文法上、後半にもλ=4が掛かるように読めます。前半4.5%との大差が、標本変更によるものかλ変更によるものか本文だけでは確定できません。
   - **解消条件:** 文を分け、後半に攻撃者・λ・Nを明記。本文に必要ないなら全標本の感度結果を付録参照へまとめる。
   - **自信:** 高。

6. **[severity: minor] ENJA15の中心的測定が本文だけでは定義不足**
   - **位置・引用:** `attackers.tex`: “the standard number of keystrokes needed to type its reading with an input method”; `data.tex`: “one of eight categories”.
   - **問題:** 日本語の読みと入力打鍵数は一意ではありません。本文には読みの決定方法、入力方式、句読点を含むcommitの分類方法がなく、51.6%という中心結果の比較対象を理解し切れません。
   - **解消条件:** 使用する読み変換・打鍵数規則と、文字列を捨てる前後の分類手順だけ本文に短く残す。実装詳細は付録でよい。
   - **自信:** 中〜高。
