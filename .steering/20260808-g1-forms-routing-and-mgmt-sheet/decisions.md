# 判断と根拠 — G1-M/G1-S 導線・管理シート（2026-08-08）

## 判断 1 — ★★ 導線は「リンクを貼る」ではなく「3 つの関係を書く」

研究者の指摘は「**フォーム全体の位置づけの説明が足りない**」だった。
★ リンクだけ貼っても被験者は使い分けられない（(2) を登録の再送と誤解する / 毎回 (3) を出す）。

→ 受付メールに **(1) 登録・同意（済）/ (2) 作業直後の 1 問（3〜9 回目・計 7 回）/ (3) 終了後（1 回）**
を役割つきで書いた。★ **両分岐**（課題ページ用意済み / 未用意）で同じ節を出す
（分岐の中に入れると片方だけ緑になる = 2026-08-08 に実際に踏んだ型）。

### ★ 併せて直した「言い換えの断絶」

  → ★ 「フォームでは番号を『ブロック番号』と呼んでいます（3 回目＝ブロック 3）」を足した。
  ⚠️ `§2.6` の設問文とタイミングは**凍結**なので、フォーム側は 1 文字も触っていない。

### ⚠️ 見つけた矛盾（メール内で自己矛盾していた）

## 判断 2 — ★ フォームの回答 URL は 3 段に落とす（絶対に空を返さない）

`g1FormLink_(key, formId)`:
1. 短縮 `SHORTURL_<key>` → 2. `FORMURL_<key>` の `publishedUrl` → 3. ★ **フォーム ID から組み立て**

⚠️ ★ **空を返すと「リンクの無い案内」になり、今回直している不具合そのものに戻る。**
3 段目は `curl`（Cookie 無し＝匿名）で実測してから採用した:
`/forms/d/<id>/viewform` → 301 → 公開 URL → 200（G1-M / G1-S とも本物のタイトルを確認）。

⚠️★ **`shortenG1DistributionUrls()` はアプリと課題ページしか短縮しない。**
フォームは `shortenFormUrls()` 側（`SHORTURL_G1_MCHECK` / `SHORTURL_G1_SURVEY`）である。

### ⚠️★ 実配備で分かったこと: **その 2 つのプロパティが存在しなかった**

リンク集タブ D9/D10 には `x.gd/X2T95` / `x.gd/MgdXf` が**書いてあるのに**、
スクリプト プロパティには `SHORTURL_G1_MCHECK` / `_SURVEY` が**無かった**
（`SHORTURL_G1_APP` と `SHORTURL_G1_MATERIALS_P0xx` はある）。
→ ★ **シートのセルは「作られた時点の値」で、外界の現在値ではない。**
   `clearShortUrls()` を通ったか、短縮を手作業で作ったかのどちらかである。

→ ★ 新しい別名を作らず（`shortenFormUrls()` を叩かず）、**研究者のリンク集にある既存の別名**を
   スクリプト プロパティに入れた。⚠️ 新規発行すると**同じフォームに 2 つの短縮**ができ、
   「被験者が受け取ったのはどちら？」が追えなくなる。

## 判断 4 — ⚠️★★ ローカルの偽シートが「実物の制約」を知らなかった

初回の実配備で `setFrozenColumns(1)` が例外:
> 結合されたセルの一部だけを含む列を固定することはできません。

★ バナーを **A1 から**結合していたため、固定の境界（A|B）が結合を分断していた。
→ ★ **A1 は結合に含めず、B1 以降だけを結合**する形に変えた（固定と帯を両立）。
→ ★ 偽シート（`run_sheet_migration_test.cjs`）に**この制約を実装した**。
  ⚠️ 壊して赤を見て確認済み（A1 から結合に戻すと 2 件失敗する）。

★ 教訓: **偽物は「自分が知っている API」しか再現しない。** 実物で落ちたら、
まず偽物に制約を足してからコードを直す（次に同じ穴を踏まない）。

## 判断 5 — ⚠️ 実行時間: 200 行 × 列ごとの往復で **6 分制限に当たった**

初回の `migrateRunSheetToV14` は 360 秒で**タイムアウト**した。
★ 列ごとの `setColumnWidth` / `setHorizontalAlignment`（19 + 16 回）がそのまま往復回数になる。
→ ★ 行数を 200 → 100 に、範囲をまとめて往復を減らした（全体中央寄せ → URL/備考だけ左寄せ）。
再実行は **2 秒**で完了。⚠️ 途中の 95 秒は**毎時トリガー `refreshG1RunSheet` との競合**であって
コードの遅さではない（実行数ページで 2 本が同時に走っていた）。
