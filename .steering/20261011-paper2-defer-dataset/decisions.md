# 設計判断

## 判断 1（2026-10-11・研究者判断）— GSE の打鍵データセットの論文は、共同研究者が見つかるまで見送る

- **決定**: GSE で新しく集めて日本語 IME の打鍵の記録を出す論文（ADR-039 の Context の方針・D1）は、審査を受けられる大学の研究者を共同研究者に得られたときに実施する。それまでは見送る。次の候補は、新しい収集をしない論文（本文の分かっている公開の打鍵データセットに照合の攻撃と加工を当てる）。
- **理由**: 研究者の所属大学では倫理審査を通せず、審査に費用を出せない。Claude が 2026-10-11 に調べた範囲では、費用ゼロで審査を受ける道は共同研究者の所属先の委員会しか見つからなかった（有料の外部の委員会は 1 件 20 万円 [V242]、他大学の委員会への外部からの申請は手数料あり、学会の審査は医療系で会員が条件、英語圏でも所属の無い研究者は民間の委員会に自費が普通）。公開データの論文は、候補の調査なら誰の承認も待たずに始められる（解析に入るのは、データセットの利用条件と、二次利用に倫理の承認が要るかを確かめてから）。結果は見送った論文の関門（ADR-039 D6）の設計にも使える。
- **Claude が伝えた限界（研究者は聞いたうえで決めた）**: 公開データの論文では、データセットを出すという当初の主張はできない。主張できるのは、公開された打鍵の記録から本文がどれだけ照合されうるか、どの加工が効くか、まで。新規性は未確かめ（2026-10-09 のサーヴェイでは、当方の形式〔キーの種類だけの記録〕での照合を直接測った研究も、公開後の記録に加工をかけた評価も見つからなかったが、この問いに絞った調査ではない）。日本語の IME を通した公開データがあるかも未確認。
- **却下した案**: 有料の外部の委員会（費用）／所属大学での審査（研究者が不可と判断）／審査なしで収集を始める（ADR-039 D1・BRM の要件 [V237]）。
- **残すもの**: ADR-039 の D2〜D8（同意文 v2・関門の設計・G1 の扱い）は変えず、再開時の前提として残す。O1 の扱い（D2 の問い合わせ A〜C）はこの決定と独立。

なお `.steering/_handoff/README.md` では「2 本目の論文」が EMSE の [P321] の再解析の論文を指す。本タスクでは混同を避けて、新しい候補を「公開データでの照合の論文」と呼ぶ。
