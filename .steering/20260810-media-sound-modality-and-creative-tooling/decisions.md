# 設計判断の記録

## D1: サーヴェイは `docs/` に landing、具体案は `.idea/` に分ける

- **決定**: 文献の判定は `docs/literature/` ＋ `docs/references.md`（SSOT）へ。
  設計の選択肢は `.idea/` へ。`research-positioning.md §4`（差分の主張）には**書き加えない**。
- **理由**: gate 判定が依然 `de-risk 先行` であり、新規性として主張できる段階にない。
  第 2 版メモが §7 で同じ扱いをしているので踏襲する。
- **却下案**: 全部 `.idea/` に置く → 後で引用しようとすると無接地のまま残る（citation-ssot 違反）。

## D2: ★ 案の中心的推論を否決した（R-1）

- **決定**: `.idea` §3.7 の推論「聴覚は閉じられない → 無視のコストが上がる →
  [V40] structure 系（唯一未否定）に足がかかる」を **0-3 で否決**する。
- **理由**: **前提は真だが結論が誤り**。
  1. 前提（無視できない）は [P56] が支持（金銭報酬でも消えず、高関与でも ηp²=0.48・N=113/173）。
  2. しかし「止めるのに行動を要求する」は [P54] が **`demand action`＝最上位 notification level**
     として**逐語で定義したもの**であり、ambient display が使う 2 段（`change blind` / `make aware`）の
     **外側**にある。＝**定義上「表現層」ではない**。
  3. [V40] の structure 系が触るのは**選択環境（どの選択肢が楽か）**であって、
     **新しい作業（音を止める）を発生させることは選択環境の改善ではない**。
- **却下案**: 「音は無視できないので強い介入になる」を長所として採る
  → [P55] が示すとおり**チャネルごと殺される**（偽アラーム 72–99% の環境で音量を下げ・無視し・停止する）。
  [P46] の「硬い介入は放棄される」失敗様式に直撃し、`.idea` §3.3 と**逆向きの移動**になる。

## D3: 「音を足さない」を文献に支えられた判断へ格上げする（gate 判定は維持）

- **決定**: 前ラウンドの「音は de-risk pilot 第 1 版に入れない」を**維持**。
  ただし理由を「パラメータが増えて検出力が足りない」から
  **「状態に応じて変わる音は定義上 changing-state で、系列的言語処理を壊す」**（機序）へ差し替える。
- **理由**: [P57] の逐語——changing-state 音は系列再生を破壊し、**定常音はしばしば全く阻害しない**。
  GSE の Phase 1 対象は**論述執筆**＝[P18] Kellogg が接地した系列的言語処理そのもの。
- **却下案**: 反証（連続ソニフィケーションで主課題が落ちなかった [P59]）を根拠に音を入れる
  → **N=18 の null** かつ**主課題が単純な暗算**（ISE の弱いプローブ）で、論述執筆へ転移しない。
  ★ ただし**対称性のため references に登録した**（案に有利な最良の証拠として記録を残す）。

## D4: ★ 「感性が育つか」は主張しない・測らない・捨てない

- **決定**: RQ-D を探索仮説として `.idea/` に隔離。**de-risk pilot のアウトカムに入れない。**
- **理由**:
  - 最も近い実証（音楽訓練の遠転移）は設計品質統制で null（m=54・N=6,984 [P61]）だが、
    **被験者・介入・アウトカムが 3 つとも違う**ので**否定の根拠にもできない**（否決 R-2）＝**直接証拠ゼロ**。
  - 聴覚知覚学習は**訓練刺激に特異的**で、転移条件（刺激の変動性）と GSE の設計は**正反対**。
    育つとしたら「GSE の音への慣れ」であり、それは**慣化と同じ現象**である。
  - 測定器（AReA [V80]）は存在するが**特性尺度**で、`research-positioning §9`（n=3–10）では
    原理的に動かない。
- **却下案**: 「感性の涵養」を GSE の目的関数に足す
  → `research-positioning §7`（過大主張の自制）に抵触し、§4 の差分の主張を無接地に膨らませる。

## D3b: ★★ D3 を部分的に訂正する（2026-08-10 追記・ドローンは別カテゴリ）

- **訂正**: D3 で採った理由——「状態に応じて変わる音は**定義上** changing-state だから壊す」——は
  **誤りである**。ISE の条件は **acoustic change ではなく segmentation（分節）**であり、
  **連続的なランダム音高グライドは系列再生を阻害せず、同じグライドを規則的な無音で区切ると
  通常の changing-state 効果が出た** [P64]。
- **なぜ間違えたか**: [P57] の「changing-state 音は破壊的」という記述を、
  **「変化する音」全般に一般化した**。[P57] 自身は "changes acoustically **from one token to the next**"
  と書いており、**トークン（離散オブジェクト）への分節を前提にしていた**。読み落としである。
- **訂正後の判定**:
  - **警告・マーカー・サリエンスの階段としての音** → **不利側に確定（D3 のまま維持）**
  - ★ **連続的で分節しないドローン** → **判定不能に近い引き分け。否定されていない**
    （有利: [P64] 連続グライドは阻害せず・[P66] 器楽は記憶/言語課題で静寂と差なし /
     不利: [P66] 系列再生と「難しい課題」には有害・[P65] の予測子は合成定常音で外す）
- ★ **設計と文献が一致した点**: 分節を生むのは**オンセット・拍・音高のステップ・和声の切り替え**＝
  **アラームを「アラームらしく」している特徴そのもの**である。
  → 研究者が避けたい音と、ISE 文献が破壊的と特定した音は**同じ音響的特徴に帰着する**。
- **却下案**: 「ドローンなら安全」と書く
  → [P65] が **合成定常音でちょうど予測を外す**と自ら述べており、
    **計算でも文献でも安全性を主張できない**。**聴取＋行動測定が必須**。

## D3c: 第 1 版の構成は変えないが、音の位置づけを「捨てる」から「第 2 版で測る」へ変える

- **決定**: **de-risk pilot 第 1 版は視覚 1 モダリティのまま**（変更なし）。
  ただし音を**排除**するのではなく、**第 2 版で単独条件として測る対象**に位置づけ直す。
- **理由**: 第 1 版に足せない理由は「壊すから」ではなく
  **「視覚の効果と交絡し n=3–10 で切り分けられないから」**（前ラウンド追補 未着手 2）。
  判定が「不利側に確定」から「判定不能」へ変わったので、**排除の根拠が消えた**。
- **却下案**: 第 1 版にドローンを足す → 交絡で両方の結論が出せなくなる。

## D3d: ★★ 連続音には「ユーザーが止められること」を必須要件にする（追補 3）

- **決定**: ドローンを検討する場合、**オフスイッチ／音量制御を必須要件**とする。
- **理由**: 26 週のフィールド研究で、連続広帯域マスキングは心理指標も不快感も改善せず、
  ★★ **システムを利用者が制御できない場合は主観的 well-being がむしろ低下しうる** [P71]。
  ★ これは [P46]（強制的でない）・[V33]（dismiss option の第一級提示）と**同型**であり、
  GSE の既存 SSOT にそのまま乗る。
  ★★ **副次的な効能**: この 1 点を守れば連続音は [P55] の失敗様式
  （偽陽性に耐えかねてチャネルごと殺される）に落ちない——
  **止められるものは、止めるために犠牲を払う必要がない**からである。
- **却下案**: 「アンビエントだから常時鳴らしてよい」→ [P71] が直接の反証。

## D3e: ★ 「変調を足すと注意が上がる」は採らない（0-3 否決）

- **決定**: [P72]（Brain.fm / Communications Biology）の効果主張を **0-3 で否決**し、
  **数値も結論も引用しない**。借りるのは **「変調スペクトル」という測り方だけ**。
- **理由**（独立した 3 つ）:
  1. 利益が **ASRS 高得点者に限定**され、**三元交互作用 F(1,80)=4.03, p=0.048, ηp²=0.048**
     ＝subgroup かつ極めて弱い。**注意困難のない参加者には利益なし。**
  2. ★★ **統制音楽が別の市販曲**（同じ楽曲の無変調版ではない）＝**変調と楽曲内容が完全に交絡**。
  3. ★★ **COI**——著者が Brain.fm 社の従業員でストックオプション保有。
- ★ **対称性の記録**: 本追補は **連続音に不利な [P71] を 2-1 で残し、有利な [P72] を 0-3 で落とした**。
  基準（交絡・COI・subgroup・効果量）は同一である。

## D3f: 音環境の介入を主観指標だけで評価しない

- **決定**: ドローンを評価する場合、**TSRI / NASA-TLX 等の主観指標だけで go を出さない**。
  **客観指標（打鍵ベースの成績・介入発火回数・HIR）との三角測量を必須**にする。
- **理由**: ★★ **GSE の証拠基盤で「主観は動くが客観は動かない」形が 3 度出ている**——
  [V35]（客観生産性 null・主観のみ上昇）/ [P71]（26 週で心理指標も不快感も改善せず）/
  [P73]（ANC: 系列再生 null・知覚プライバシーのみ改善）。
  → **音環境の介入は「良くなった感じ」を作りやすい。**
- **却下案**: TSRI 単独で判断する → `.idea` §5 が既に禁じている（本決定はその聴覚版の強化）。

## D5: 試作ツールは「オフライン・replay 経由」から始める（OSC/WS を実装しない）

- **決定**: 第 1 歩で **GSE 本体に OSC / WebSocket 送出を足さない**。
  既存の `gse-replay --snapshot`（`FeatSnapshot` 1Hz・content-free）をファイルで渡す。
- **理由**:
  1. `data-privacy` の**外部送信境界を 1 本増やす**ことになる（第 2 版 §6 も同じ警告を書いている）。
     必要性が確認される前に境界を増やさない。
  2. 表現の比較に必要なのは**時系列の再生**だけで、ライブ性は要らない。
  3. ★ 実際に `FeatSnapshot` の中身（`p_stuck` / `ewma_x` / `ewma_y` ほか）を確認した結果、
     **既存 CLI で足りる**ことが分かった＝**GSE 本体の変更がゼロで済む**。
- **却下案**: 最初から TD へライブ送出 → 境界追加・`security-checker` 必須・
  被験者環境の要件が跳ね上がる。**試作の段階でその代償を払う理由がない。**

## D7: 音の生成は Python 側でやる（Audition を自動化しない）

- **決定**: 音の候補生成は Python（WAV 書き出し）で行い、**Adobe Audition は「聴いて判断する」工程に残す**。
- **理由**: ★ **実機を確認した結果、Audition 2026 にバッチ CLI が存在しない**
  （`Adobe Audition.exe` と crash reporter のみ）。Media Encoder も同様に CLI を確認できなかった。
  一方 §3 で演繹した音のパラメータ（単発・低 F0・緩やかなアタック・整数次倍音・繰り返さない）は
  **数式で書ける**ので Python で足りる。
- **却下案**: Audition の watch folder / スクリプトを当てにする → **実機で確認できていない**ため、
  `verify-before-claiming` に従い前提にしない。

## D8: ★★ 表現層を Physical Anchor から切り離さない（追補 4）

- **決定**: **Lv2 Wall を主軸から外すのは可**。しかし
  **表現層だけにして Physical Anchor を外すのは不可**とする。
- **理由（3 つの独立な経路が同じ結論へ）**:
  1. **[V40] の系統**——表現層が structure 系（唯一未否定）に留まれるのは
     **「出口を開く」から**であり、**出口には行き先が要る**。
     その行き先が Physical Anchor である。外すと情報の提示だけが残り、
     **information 系（d=0.00・BF01=33.84）へ落ちる**。
  2. **[P54] の語彙**——`change blind` / `make aware` だけの表示は
     **情報を提示するだけ**。「介入を出さずに済ませる」には
     **本人が代わりに何かをできる**必要がある。
  3. ★ **不便益 [P6]**——表現は**不便を課さない**（低侵襲・非強制がその定義）。
     不便を担うのは離席・歩行であり、**表現だけにすると GSE の核が抜ける**。
- **却下案**: 「表現は非強制だから単独でも自律性を損なわず優れる」
  → **非強制であることがまさに information 系へ落ちる理由**である。
- ⚠️ これは `.idea` 第 2 版 §3.3 の警告の**再導出**であり、新しい判断ではない。
  本タスクはそれに**構造的な理由**を与えた。

## D9: 連動は「記録版」でやる・自己効力感だけで成功と言わない（追補 4）

- **決定**: 表現 × 身体的回帰の連動は**記録版**で実装し（報酬版を採らない）、
  評価に **自己効力感 [P15] だけを使わない**。
- **理由**:
  - ★ 先行実装 [P76] は著者自身が **"physical rewards"** と呼ぶ**報酬版**であり、
    **社会的動態（議論・嫉妬・競争）を生んだ**。⚠️ かつ **走行活動が増えたとは報告していない**。
  - ★★ [P75] の **moral placebo effect**——**自己像の向上は真の選好を変えないまま
    行動に影響しうる**。記録版は「自分は停滞したら歩く人間だ」という自己像を作りうるが、
    **回復能力が上がったことを意味しない**。[P27] [P28] と同型の制約。
  - ★ GSE は**単独作業**が対象なので、[P75] が分離したい *pure self-signaling*
    （他者の視線チャネルが無い）の条件と一致する——**理論の適用条件を満たしている**。
- **却下案**: 「歩くと絵が綺麗になる」報酬版 → [P46] の reward/punishment 系・
  外的報酬が内発的動機を損なう古典的リスク・Vision（認知的自立）と正面衝突。
- ⚠️ **閉ループはランダム化のチャネルを開けたまま作る**（例 30% は応答させない）。
  H-X2 の 70/30 の拡張であり新しい方法論を要さない（[V58] / ADR-008 D4 / [V64]）。

## D10: ★★★ 歩行を MhD（推論層）の観測に入れない。合流点は表現層に置く（追補 5）

- **決定**: 「歩行を計測し、MhD（ML/HMM）の推論を経由してアートを変動させる」は**採らない**。
  代わりに **`p_stuck` と「歩いたかどうか」を別の入力として表現層で合流**させる。
- ★★ **まず前提を訂正する**: 「打鍵だけで足りている」は**崩れている**。
  `.idea/20260801-architecture-signal-and-online-learning.md` の実測——
  **§1.1 X 軸は主観摩擦を予測できていない**（P010 n=103 で全特徴量が偶然水準）、
  **§7.2 正規化を直しても GATE3 (0.65) に届かない見込み**、
  ★★ **§2-4「詰まりは打鍵の変化ではなく *打鍵しないこと* や *別行動への切替* として現れる可能性」**。
  → **「信号を打鍵の外へ広げる」方向自体は `.idea` が実データで既に支持している。
    提案は的外れではなく、既知の穴を突いている。**
- **それでも歩行だけは別である理由**:
  1. ★★★ **ランダム化が救済にならない**——`.idea` §5-c/§6 は閉ループを
     **H-X2 の nudge/defer ランダム化（70/30）**で因果識別に転化する解を持つが、
     **歩行は GSE 自身が促す行動**なので **defer アームで構造的に欠測**する。
     欠測が介入アームと完全に交絡するため**ランダム化しても観測が揃わない**。
     ★ 対して §3.A の候補（paste / IME 滞留 / 沈黙長 / アプリ切替）は**自発的に生じる**ので
     defer アームでも観測でき、ランダム化が機能する。
  2. ★★ **`self_directed_recovery` が自己言及的になる**——「回復した」と
     「歩いたから推定が下がった」が区別できない（ADR-009 D2）。
  3. **Phase 1 ではそもそも触れない**——`.idea` §7.3 の制約。
     ★ 守っているのは「核が貴重だから」ではなく、**Kill が Kill としてきれいに出るため**である。
  4. **実装の連鎖**——obs 空間 26 / emission `[f64; 78]` を変える → `HMM_VERSION` bump →
     ゴールデン再生成（`.idea` §5-b が「後付けが非常に高くつく」と警告している箇所）。
     ⚠️ そもそも**実機にセンサー実装が無い**。
- ★★★ **費用対効果（`.idea` §1.5）**: **新センサーを足す前に、収集済みで未使用の信号のほうが強い**——
  `paste_count`→Q1 = **0.571**（現行 5 特徴量すべてより上）、
  `keys`→Q2 = **0.615–0.676**（f4 を上回る）。**打鍵の外へ広げる最初の一手は歩行ではない。**
- **却下案**: 「歩行を obs に追加して HMM を再学習させる」→ 上記 1–4 のすべてに抵触。
- ★ **将来の生存形**（凍結解除後）: (i) `suppression` / 共変量として使う（推定を変えない）、
  (ii) **自発的な離脱だけを観測にし、介入誘発の離脱を競合イベントとして除外**する
  （ADR-009 が `externalized` を競合リスクとしたのと同じ手筋・[V61]）。
  ⚠️ ただし (ii) は**歩行センサーを必要とせず**、§3.A の沈黙長・アプリ切替でほぼ同じものが取れる。

## D11: ★★★ 歩行の「量」を測らない（報酬でなくても計測自体が害を生む）（追補 5）

- **決定**: 歩数・距離・MET 等の**量を算出して本人に向けない**。
  使ってよいのは **「歩いた / 歩かなかった」の二値のみ**。
- **理由**（[P77] Etkin 2016・**PDF 全文逐語**）:
  - ★★★ 逐語 **"Even in the absence of explicit external incentives, measurement itself
    can thus have similar effects."** → **「報酬ではない」は防御にならない。**
  - **opt-in でも害が出る**（実験 2: 歩数計を着けるか選べたが、着けた者は多く歩き楽しまなかった）。
  - **任意閲覧でも害が出る**（実験 3・6:「利用可能であるだけ」で楽しさが下がる）。

- **却下案**: 「opt-in にすれば良い」「見たい人だけ見れば良い」「ユーザーが望んでいる」
  → **3 つとも [P77] の実験内で潰れている**。
