### 層 0 の合成（`spec` §2 の逐語に接地）

```text
55–110 Hz 帯の持続音 ＋ 整数次倍音のみ（2f, 3f, 4f…）
非調和成分ゼロ / sharpness 低 / ★ 状態に応答させない
```

Web Audio での対応:

| 仕様 | 実装 | ★ 禁止事項をどう避けるか |
|---|---|---|
| 持続音 | `OscillatorNode` を**起動時に 1 度だけ作り、止めるまで stop しない** | ✗ **オンセット**——ノードを作り捨てすると毎回アタックが出る |
| 整数次倍音のみ | 基音 f に対し 2f, 3f, … を**別 Oscillator** で加算（または `PeriodicWave`） | ✗ **非調和成分**——比が整数でない成分を作らない |
| sharpness 低 | 倍音ゲインを 1/n / 1/n² / 低次のみ で減衰（S3-D2） | 高次の重みを落とす |
| 状態に応答しない | ★ **層 0 の合成パラメータは CSV を読まない** | Step 3 の趣旨そのもの |
| 音量変更 | マスター `GainNode` を `setTargetAtTime` で連続変更 | ✗ **音高のステップ**／段差 |
| 停止 | マスターゲインを**ランプで 0 へ落としてから** `suspend()` | ✗ **オンセット**（急に切ると切断クリックが出る） |

⚠️★★ **「停止」を `stop()` の即時呼び出しで実装しない。** 波形を途中で断ち切ると
**ステップ = 広帯域のクリック**が出る。これは `spec` §2 が禁じるオンセットそのものである。

### Step 3b — 「聴こえない程度に」何かに乗せる

`spec` §7 / 引き継ぎ §3b が許しているのは
**「基層が鳴り続けている上で、平滑化された値が“聴こえない程度に”何かに乗る」**ところまで。

- **乗せる先**: マスターゲインに **±0.5 dB 以内**の微小変調（★ **音色・音高には乗せない**）
- **駆動**: `sm.csv` の `t_rel_s` を再生時刻に合わせて読み、`AudioParam.setTargetAtTime` で連続追従
- ⚠️ **これは「マッピング」ではない**——**Step 4 で本格的にやる**。ここで確かめるのは
  **「1Hz の目標値 → レンダレートで連続追従」という形が音として破綻しないか**だけである。
- ★ **`segment` 境界（離席）で S3-D6 の 2 案を切り替えられるようにする**。

### ★ 機械検算（S3-D4）

`OfflineAudioContext` で **本番と同じグラフ**を N 秒レンダリング →
**エンベロープ（マスターゲインの時系列）** に Hann 窓 DFT を掛け、
**3.995 / 4.0 / 4.005 Hz の線**を報告する。⚠️ **窓なし DFT / 帯域 RMS は使わない**（S0-D8）。

### ★ 実装中に設計が変わった点（初稿からの差分・すべて実測が理由）

| # | 初稿 | 実際 | 理由 |
|---|---|---|---|
| 1 | `csv_to_js.py` で JS 化 | **ファイル選択（`FileReader`）** | S3-D9。CORS 回避に加え、**実データが repo に入る経路を作らない** |
| 2 | 実音声の **4 Hz の線**を測る | ★ **側帯波 f0±f を測る** | ⚠️ **4 Hz の線では変調を原理的に検出できなかった**（逆検査で −90 dB のまま PASS）。修正後は同じ注入で **−19.0 dB → FAIL** |
| 3 | 包絡の間引き 400 分の 1 | **40 分の 1（包絡 200 Hz）** | ⚠️ 20 Hz が間引きの零点に当たり **sinc 補正がゼロ除算で +31.7 dB** という値を出していた。★ 測れない周波数には**数字を出さず「測定不能」と書く**形にした |
| 4 | `await ctx.resume()` | **1.2 s で打ち切り＋画面にエラー** | ⚠️ 自動再生ブロック下で **play() が無言で固まる**（実測）。ボタンは押せるまま・エラーも出ない |
| 5 | （なし） | **`alert()` を全廃** | モーダルはページを止め、ブラウザ自動検証も固める |
| 6 | 反復周期 6200 s と記述 | ★ **10000 s（selftest が Fraction で計算）** | 手計算が誤っていた。**コメントを直すのではなく検査に計算させる**形へ |
| 7 | 倍音本数 / ゆらぎの切替で**鳴らし直す** | ★ **常に最大構成で組み、ゲインだけをランプする** | ⚠️ 鳴らし直しは**フェードアウト→フェードイン＝オンセット**であり、`spec` §2 の禁止事項を**自分の UI 操作で作りに行く**形だった。★ 未使用の倍音・LFO を**ゲイン 0** にしておけば、どの軸も連続ランプだけで移れる（実測: 未使用側がゲイン 0 のとき包絡 4 Hz は **−inf dB** のまま） |
