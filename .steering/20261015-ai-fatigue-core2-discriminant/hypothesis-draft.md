## 1. 主張を、競合する 2 つの説明に分ける

核 2: AI 疲労とデジタル疲労が両方高い人がいる。ただしそれは、画面越しの作業に共通する 1 つの疲労の 2 つの呼び名かもしれない。

| 説明 | 内容 | 支える側の手がかり（前のタスク） |
|---|---|---|
| A 共通の疲労 | AI 疲労・デジタル疲労・一般の疲労・燃え尽き（消耗）の項目の分散の大半を、1 つの一般因子が説明する | AI 疲労と画面疲労 r = .60・SNS 疲労 .63・一般・臨床の疲労 .52〜.63 [P362] [P485]。デジタル疲労と燃え尽きの HTMT = 0.83 [P491] |
| B 別の因子 | 相関はあるが、尺度ごとに固有の分散が意味のある大きさで残る | 他の疲労を足しても AI の利用の説明が ΔR² = .08 増える [P362] [P485]。ビデオ会議疲労と燃え尽き r = .51 [P492] |
| C 共変量で説明される共有分散（A・B と両立する） | 重なりの一部が、測った神経症傾向・否定的感情で説明される（検証の対象はこの関連に限る）。同じ方法で答えることによる分散 [P505] も重なりを生みうるが、§2 の手順では区別できないので、未検証の説明の候補として分けておく（方法の因子や標識の変数を置くかは §4 で未決）。これが共通の原因かどうか（因果の向き）は、同時点の質問紙からは区別できない。共通の原因という仮説は、別の設計（縦断など）が要る仮説として分けておく | 神経症傾向 .49・否定的感情 .47 [P362]（AI 疲労 DB の M2） |

どちらの結果も論文になる形にする（A なら「呼び名を分ける根拠が弱い」、B なら「AI 疲労は固有の分散を持つ」）。

## 2. 比べるモデル

| モデル | 構造 | A・B のどちらを表すか |
|---|---|---|
| M1 | 一因子（疲労の全項目が 1 つの因子に乗る） | A の最も強い形 |
| M2 | 尺度ごとの因子どうしが相関する | B |
| M3 | 二次因子（尺度ごとの因子の上に疲労の上位因子） | A と B の中間 |
| M4 | bifactor（一般因子＋尺度ごとの特定因子）[P504] | 一般因子の割合で A か B かを読む |
| M5 | bifactor-ESEM（交差負荷を許す）[P506] | M4 で交差負荷を 0 に固定したことによる歪みを避ける |
| 各モデル＋C | 神経症傾向（または否定的感情）を外の変数として入れ、統制の前後で因子の相関と一般因子の割合が変わるかを見る | C（共有分散の説明であり、因果の検定ではない） |

## 3. 判定の基準（候補）

| 基準 | 候補の値 | 根拠と確かさ |
|---|---|---|
| HTMT（尺度の対ごと） | 0.85 または 0.90 を超える対は弁別に疑いがある | [P503]（全文で照合: 0.85 を勧める著者と 0.90 を勧める著者がいると書く）。どちらを使うかは凍結の前に決める |
| bifactor の指標（ωh・ECV など） | 未記入 | [P504]。書誌は確かめたが、本文の推奨値は照合していない。凍結の前に本文で照合して入れる |
| 適合の比較（M1 対 M2 など） | 未記入 | 指標と差の基準を凍結の前に決める |
| 予測の上乗せ | AI 疲労が、他の疲労と燃え尽きと神経症傾向を統制しても、AI の回避（[P362] の行動の項目とは別に測る変数）を説明するか | [P362] の ΔR² の型を、独立の標本で確かめる形。結果の変数を測る尺度が決まっておらず、§5 の構成案にもそのブロックが無い。決まるまでこの分析は採用しない（採用するなら §5 にブロックを足し、項目数と時間を直す） |

判定の組み合わせ（案）:
- M1 が M2 と同程度に当てはまり、一般因子の割合が大きい → A を支持。
- M2 が明らかによく、HTMT が基準を下回り、特定因子の割合が残る → B を支持。
- C の統制で因子の相関や一般因子の割合が大きく下がる → 重なりの一部は、測った共変量で説明される共有分散である（共通の原因かどうかはこの設計では言えない）。

## 4. 測定不変性・標本・データの質

- 測定不変性: 性別・AI の利用の量・言語（2 言語で集める場合）で、形・負荷量・切片の順に確かめる [P508]（書誌のみ確認・本文未照合）。
- 標本の大きさ: 想定する負荷量と因子の相関（[P362]・[P491]・[P492] の値）を入れたシミュレーションで決める（方針）。SEM の標本の大きさの研究 [P507] は書誌のみ確認で、本文の数値は使っていない。無償の標本で脱落と除外が多いことを見込む。
- 不注意な回答の除外: 注意確認の項目・回答時間・同じ値の連続を、事前に決めた基準で除く [P509]（書誌のみ確認）。
- 共通方法分散: 尺度のブロックの順序をランダムにする。方法の因子や標識の変数を置くかは未決 [P505]（書誌のみ確認）。

## 6. 公開データで先に試せること（新しく集めずに）

Montag et al. 2022 の OSF のデータ [P502]（ZEF 15・MBI 16・Mini-IPIP の神経症傾向 4・N = 315 行）で、M1〜M5 と C（共有分散の説明）を「ビデオ会議疲労 対 燃え尽き」に当てられる（feasibility.md §4）。AI 疲労と一般の疲労は含まないので、核 2 の中心は確かめられない。使うなら、先に OSF のデータの再利用の条件を著者に確かめる（ライセンスの設定が無い）。この分析を独立の短い論文にするか、新しい収集の前の予備の分析にするかは研究者が決める。
