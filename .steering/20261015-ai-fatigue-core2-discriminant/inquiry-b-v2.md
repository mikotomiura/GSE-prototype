# 問い合わせ B（ZEN大学あて）の更新版 —— 3 つの研究をまとめて尋ねる

草案。送るのは研究者（外部への送信は取り消せない）。宛先・氏名は送る前に確かめる。打鍵の記録・NDJSON・参加者の情報は添付しない（`data-privacy` Skill）。

- 元の版: `.steering/20261007-research-use-and-release/inquiry-drafts.md` の B（O1 だけを書いている）。元の版は書き換えず、この版で置き換えるかは研究者が決める。
- 足したもの: (2) 公開データの二次利用（照合の論文・ADR-039 D1 の 2026-10-12 の注「データを取得する前に、研究を実施してよいかを研究者が所属機関の規程で確かめる」）と、(3) 匿名のオンライン質問紙（AI 疲労の核 2・まだ実施を決めていない）。問い 4（指針や規程の対象になるかを機関に判断してもらう）と問い 6（所属を書いて投稿してよいか）。
- 根拠: 日本心理学会の方針 2.1.1（委員会が無ければ所属機関の長の承認で代えることを認める場合がある [V241]・委員会等が審査は要らないと判断したら承認は必須でない [V325]）・2.1.3（公開データの二次利用は原則として承認を要しない [V325]）。誌ごとの扱いは `docs/ethics-review-routes.md`。
- 宛先: 公開資料に人を対象とする研究の審査の窓口は見つかっていない（ADR-039）。学生か教員かに応じて、指導教員・事務局・研究倫理教育責任者のどれに送るかを研究者が決める。

```
件名: 人を対象とする研究の倫理審査の取り扱いについてのお問い合わせ

【所属・氏名】です。
個人として行っている研究、または計画している研究について、学外の学術雑誌へ投稿する際に、
倫理審査の承認または免除（審査の対象外であること）の記載を求められるため、次の点をお尋ねします。
いずれも、診断や治療を目的とするものではありません。

研究の概要:
(1) パソコン作業の記録（実施中）
 ・ふだんのパソコン作業のあいだの操作を数週間記録し、作業の状態の推定に使えるかを調べる研究です。
 ・記録するのはキーを押した時刻と種類、日本語入力の変換にかかった時間、貼り付けの回数と文字数、
  画面の切り替えの時刻、マウスの動きの量などで、打った文字・画面の内容・アプリやウィンドウの名前は記録しません。
 ・対象は研究者が直接説明する 3〜5 名程度で、電子的な説明と同意を取っています。
(2) 公開データの二次利用（計画中）
 ・他の研究者がインターネット上で公開している、キー入力の時刻の記録のデータを使い、
  公開の際の加工が個人の識別をどこまで防ぐかを計算で調べる研究です。新しく人からデータを集めません。
(3) 匿名のオンライン質問紙（実施するかは未定）
 ・成人に、疲労・燃え尽き・性格についての既存の質問紙に匿名で答えてもらい、
  質問紙どうしの関係を統計で調べる研究です。氏名や連絡先は集めず、謝礼はありません。

お尋ねしたいこと:
1. 本学に、人を対象とする研究（医学系以外）の倫理審査を行う委員会や手続きはありますか。
   あれば、申請の方法と、【学生／教員】が申請できるかを教えてください。
2. 無い場合、「本学では人を対象とする研究の倫理審査を取り扱っていない」旨を、
   書面（メール可）でいただくことはできますか（投稿先への説明に使います）。
3. 委員会が無い場合に、所属機関の長などによる承認で代える仕組みはありますか。
   あれば、(1)〜(3) のそれぞれについて申請できるかを教えてください。
4. (1)〜(3) のそれぞれが、本学の規程や国の倫理指針（人を対象とする生命科学・医学系研究に関する倫理指針など）の
   対象になるかを、本学として判断していただくことはできますか（私自身では判断しないようにしています）。
5. 学外の倫理審査委員会で審査を受けることや、他大学の研究者と共同で、その大学の委員会の審査を受けることについて、
   本学として定めや制約はありますか。
6. 個人として行う研究の論文に、所属として本学の名前を書くことについて、定めや手続きはありますか。

お手数をおかけしますが、よろしくお願いいたします。
【氏名・連絡先】
```

注:
- 問い 3 の答えが「ある」でも、国際誌がそれを委員会の承認として受けるかは別に確かめる（`docs/ethics-review-routes.md` §4）。
- 問い 4 は、研究者自身が指針の対象外だと判断する文を外に出さないための問い（指針の対象には健康の保持増進も含まれる [V270]・米国の OHRP も研究者自身に免除を判断させないよう勧める [V313]）。2026-10-15 のレビューの指摘で、元の「健康や医療についての知識を得ることを目的とする研究ではありません」を「診断や治療を目的とするものではありません」に弱め、この問いを足した。
- (3) は実施を決めていないので、「計画の段階で尋ねている」ことが伝わる書き方にした。研究者が (3) を外したい場合は、(3) と問い 3 の「(1)〜(3)」を直す。
- 問い 6 は、所属で投稿するか独立の研究者として投稿するか（`docs/ethics-review-routes.md` 表 1 の 2 つの列）を決める材料。
