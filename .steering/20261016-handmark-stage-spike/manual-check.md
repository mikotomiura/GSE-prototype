# 研究者の手順書 —— 背景の層と右下の小面の試視（段 3）

この Mac では Claude が画面を撮れないので、見え方は研究者に見てもらいます。10〜15 分の見込みです。結果は Claude に口頭で伝えてください（`results.md` §7 に書きます）。

## 0. 起動と後片づけ

ターミナルで、次をそのまま実行します（記録はすべて一時フォルダに入り、`~/Documents/GSE-sessions` には書きません）。

```bash
cd /Users/johnd/GSE-prototype-handmark-stage
export GSE_DATASET="$(mktemp -d)/gse-spike"; echo "$GSE_DATASET"
env -u GSE_HANDMARK_SPIKE_MEASURE GSE_HANDMARK_SPIKE=1 GSE_HANDMARK_STAGE_SPIKE=1 GSE_HANDMARK_STAGE_SPIKE_PROTECT=1 GSE_DEBUG=1 VITE_GSE_DEBUG=1 npx tauri dev
```

- 計測の環境変数は `env -u` で外しているので、あなたの打鍵の時刻は CSV に書かれません。
- 背景と小面は、どちらも取り込みからの保護（共有の種別「なし」）を付けて出します（§2 の 5 で標準のスクリーンショットに写るかを見るため）。
- 本体の窓で「開始する」を押します。背景と小面はセッション中だけ動きます。
- セッション中は、本体がいつもどおり打鍵の時刻とキーの種類を NDJSON に書きます（中身は書きません）。書き先は上の一時フォルダです。終わったら、トレイ（メニューバーの GSE）の「GSE を終了」で止め、次で消してください。

```bash
rm -rf "$GSE_DATASET"
```

- 背景は、画面全体に薄い横の線が 9 本、壁紙の上・アイコンの下に出ます。打つと 1 秒ごとに少しずつうねりが大きくなって流れ、止めると 2 秒後からゆっくり平らに戻ります。トレイの「背景を閉じる」で消せます。
- 右下の小面は、墨の点（白い縁）から墨の輪（白い縁）が広がって消えます（候補台の乙・40 px）。トレイの「小面を閉じる」で消せます。

## 1. 見てほしいこと

いつもの作業を 5 分ほど打ちながら、ときどきデスクトップが見える状態にして見てください。

| # | 見るもの | 聞きたいこと |
|---|---|---|
| 1-1 | 右下の小面（乙） | いまの壁紙の上で見えるか。主張の強さはちょうどよいか（前の灰より見えるか・強すぎないか） |
| 1-2 | 背景の線 | 見えるか（薄すぎないか）。打つと動いて、止めると戻るのが分かるか |
| 1-3 | 背景と小面の組み合わせ | 2 つが一緒にあって、うるさくないか。どちらが自分の手のものに感じるか |
| 1-4 | 邪魔さ | 作業の目が奪われるか。デスクトップのアイコンが見にくくならないか |
| 1-5 | 状態として読めるか | 背景から「打っている / 止まっている」より多いこと（速さ・詰まり具合）が読めてしまうか |

## 2. 確かめてほしいこと（Claude が確かめられなかったもの）

| # | 操作 | 聞きたいこと |
|---|---|---|
| 2-1 | 任意: 壁紙を一時的に暗いものに替える（終わったら戻す） | 暗い壁紙でも小面と背景が見えるか |
| 2-2 | Mission Control（F3 か 3 本指で上へスワイプ）で右上の「＋」を押してデスクトップを 1 つ足し、Ctrl+→ で移る | 移った先のデスクトップにも背景の線があるか。見終わったら、Mission Control で足したデスクトップの × で消す |
| 2-3 | 何かのアプリを全画面にする（緑のボタン） | 全画面のあいだは背景が見えない（予想）。全画面を解いたら背景が動いているか |
| 2-4 | 外部のディスプレイをつないでいれば | もう 1 枚の画面に背景が出るか（出ない予想・主画面にだけ作る） |
| 2-5 | Cmd+Shift+3 で画面全体のスクリーンショットを撮る | 撮れた画像に、背景の線と右下の小面が写っているか（前の試作では、保護ありの小面は写った）。確かめたら画像は消してください |

## 3. 終わったら

トレイの「GSE を終了」→ `rm -rf "$GSE_DATASET"`。2-1 で替えた壁紙と、2-2 で足したデスクトップを戻してください。
