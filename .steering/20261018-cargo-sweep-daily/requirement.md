# requirement: cargo 定期掃除を「毎日・3 日・全ワークツリー」に強化する

## 背景
- 2026-10-18、gse-mac のデータボリュームの空きが **8.8Gi**（使用率 96%）まで落ちていた。
  週次・14 日の sweep（2026-08-31 導入）は動いていた（同日 03:00 に `done (local=1 runner=1)`）にもかかわらずである。
- 実測した溜まり方:
  - `dep-graph.bin`（incremental キャッシュ）が 499 個。メインクローンでは `gse_next_lib` 1 crate に 36 セッション（1 個 100〜200MB）
  - `libobjc2_*` などの依存成果物が、ワークツリー 5 本の target にそれぞれ重複していた
  - sweep の対象は**メインクローンとランナー workspace だけ**で、ワークツリーは対象外だった
- 手動掃除（incremental 全削除と `cargo sweep --time 3`）で 8.8Gi → 19Gi に回復した。

## ゴール
重複・陳腐化したビルド成果物が「溜まり続けない」状態にする。

## 受け入れ条件
- [x] 定期実行を週次から毎日へ
- [x] 既定の保持日数を 14 日から 3 日へ（`GSE_SWEEP_KEEP_DAYS` で上書き可のまま）
- [x] `git worktree list` の全ワークツリーを対象にする（ワークツリーの失敗は必須判定に含めない）
- [x] incremental の古いセッション（mtime > 保持日数）を消す
- [x] 実機で 1 回走らせて `rc=0`・全ワークツリーが `--- sweep:` に現れる
