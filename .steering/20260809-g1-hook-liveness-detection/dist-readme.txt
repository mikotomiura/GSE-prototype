GSE フック検証キット — 先に読んでください
==========================================

これは被験者向けの配布物ではありません。研究者/検証者が
「キーボードの記録が黙って止まっていないか」を確かめるための試験版です。

★ 参加者 ID の入力も、記録の提出も要りません。
★ このフォルダには g1.mode を入れていません（意図的です）。
  そのため 5 分での自動終了は起きません。手で終わるまで測り続けます。


■ 何を確かめるのか
-------------------
2026-08-09 に Windows 実機で「5 分間まったく打鍵の無いブロック」が
"正常" として記録・提出されました。アプリの「フックは生きている」判定が
"設置に成功した" しか意味していなかったためです。

そこで 1 秒ごとの生存監視を足しました。

  OS は入力を見ている（マウスやキーが動いている）
        かつ
  GSE のキーボードフックが 1 回も呼ばれていない   → 異常として数える

  30 秒たまる  … ログに警告を 1 回（画面は変わりません）
  120 秒たまる … トレイが「⚠ 計測できていません」／フックを 1 回だけ再設置


■ 手順
-------
1. gse-next.exe をダブルクリックして起動する
2. 「開始する」を押す
   ★ これを押さないと検証になりません（止まっている間は数えないため）

3. 【T-A】2 分間、キーボードを打ち続ける（10 秒以上手を止めない）
     期待: 何も起きない。トレイは「● 計測中」のまま

4. 【T-B】2 分間、キーボードに触れずマウスだけを動かす
     ★ 途中で 1 打でもしたらやり直してください
     期待: 約 30 秒でログに警告／約 120 秒でトレイが
           「⚠ 計測できていません」に変わる
     ★ 変わった瞬間にスクリーンショットを 1 枚撮ってください

5. 【T-C】T-B の直後に、キーを 20 回ちょうど押す（1 秒に 1 打）
     期待: トレイが「● 計測中」に戻り、打鍵が記録される

6. 終わったら、次の 2 つを研究者に送ってください
     %USERPROFILE%\Documents\GSE-sessions\gse-app.log
     %USERPROFILE%\Documents\GSE-sessions\gse_（日付）_（時刻）.ndjson
   ＋ 4. で撮ったスクリーンショット


■ うまくいかないとき
---------------------
・T-B で 2 分たっても何も変わらない
   → 検知そのものが効いていない可能性があります。そのまま報告してください
・T-C のあとトレイが「計測中」に戻らない
   → こちらも、直さずにそのまま報告してください

★ 「たぶん動いた」ではなく、上の 3 つ（T-A / T-B / T-C）それぞれについて
  何が起きたかを書いてください。起きなかったことも結果です。
