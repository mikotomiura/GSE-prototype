# design — O1 稼働コスト再測（round 2）

## アプローチ

### ★ 1 回目との差分（⚠️ 測り直すのは 2 つだけ）

| 指標 | 1 回目 | ★ 2 回目 |
|---|---|---|
| CPU / RSS / NDJSON | ★ 実測済み（880 サンプル・7.99 h） | ⚠️ **測り直さない**（★ 退避して残す） |
| エネルギー影響 | ⚠️ 列が無い | ★ `top -stats power` の 7・8 列目 |
| 起動時のコスト | ⚠️ 稼働 4h15m 後から測ったので原理的に不可 | ★ **サンプラを先に起こす** |

### ★ 順序（⚠️ ここが設計の本体）

1. ⚠️ **1 回目の結果を退避**（`results/with-gse` → `with-gse-20260904-steady`）。
   ★ `samples.tsv` は **git 未追跡**でディスクにしか無い。⚠️ 引き継ぎの `rm -rf` をそのまま
   実行すると 8 時間ぶんが消える。
2. ★ GSE 起動 → **孤児回収の観測**（§2）→ 1 分スモークで 8 列を確認 → 捨てる。
3. ★ GSE 停止 → サンプラ起動 → **基線 3 行（全列 0）** → GSE をバイナリ直叩きで起動。
4. ★ 8 時間後に `summarize.py`。

## 変更対象

- `experiments/.../scripts/summarize.py` —— ⚠️ **8 列目まで読んでいなかった**（★ 実測して確認）。
  - `energy` / `ref_energy` を読む（⚠️ 古い 6 列も落ちずに読めること）。
  - `energy_report()` —— ★ **閾値を置かず**、参照 (Finder) との比だけを出す。
    ⚠️ **参照が 0 の行では比を採らない**（★ Finder はアイドルで 0 を返す＝スモークで実測）。
  - `startup_report()` —— ★ 基線が無ければ「測れていない」と倒す。
  - ⚠️ `battery_drop_pt_per_8h` を**判定表から外す**（★ README が 2026-09-04 に取り下げ）。
    参考値としてのみ印字し、総合に効かせない。
  - ⚠️ **対照 (`without-gse`) の要求を外す**（★ README が廃止済み。残すと総合が永久に
    DataInsufficient で固定され、判定器として死ぬ）。
  - ★ 代わりに「**エネルギー影響 / 起動コストが未測定なら総合を PASS にしない**」門を置く
    （⚠️ 「6 指標中 5 つ実測」を「合格」と読ませない）。
  - ★ `sys.argv[1]` で run を選べるようにする（★ 退避した 1 回目も読めること）。
- `experiments/.../README.md` —— ★ 「やり方」を実際の順序に合わせる（⚠️ 対照の 2 行を削る）。

## テスト戦略（⚠️ 3 状態 ＋ 陰性対照）

| # | 状態 | ★ 期待 | 結果 |
|---|---|---|---|
| ① | **正常**（旧 6 列・1 回目の 880 行） | ★ 既知の値を再現（0.98 / 4.30 / 27.00 / 11.05）＋ エネルギー・起動は「測れていない」 | ★ 一致 |
| ② | **不在**（run ディレクトリが無い） | ★ 「まだ測っていない」・exit 1 | ★ 一致 |
| ③ | **壊れ**（energy 列が全行 0） | ★ 「測定器が壊れている疑い」 | ★ 出た |
| ④ | **壊れ**（列不足の行を 1 行足す） | ★ 「読めずに捨てた行: 1 行」 | ★ 出た |
| ⑤ | **陰性対照**（実測中の 8 列データ） | ⚠️ ③④ の警告が **出ない**・比と起動コストが出る | ★ 出ない／出た |

⚠️ ③④ は**陽性対照**（壊したら報告が出るか）、⑤ は**陰性対照**（壊していないのに出ないか）。
