## 背景

★ **Step 4 で数字が出た構造がそのまま本 Step の主題である**（S4-D14）。

| # | 実測 | 出所 |
|---|---|---|
| 1 | 瞬時 A/B（均衡設計・遷移 0 秒）で **5/8・ヒット 2/4・誤警報 1/4 ＝ 偶然水準** | S4 notes §3B |
| 2 | 条件は **+1.04 dB**。★ **即座に切り替えても信頼して聞き分けられない** | 同上 |
| 3 | 内訳を解くと **層 0 = 0.2483 / 層 2 最大 = 0.1565**（検算 `√(0.2483²+0.0783²) = 0.2603` が実測 A と一致） | 同上 |
| 4 | ★ **層 2 の振幅は設計どおり 2 倍に動いている。操作は効いている** | 同上 |
| 5 | ⚠️ **層 0 が層 2 より 4.0 dB 上にいる**ので、層 2 だけが 2 倍になっても全体は +1.04 dB にしかならない | 同上 |

→ ★ **量が足りない。速度の問題かどうかはまだ言えない。**

⚠️★★★ **そして「読めること」と「気にならないこと」が同じつまみの両端にある** ——
層 0 は [P48] の「自分の通常」の参照点であり、**並置が構造的に成立する土台そのもの**（spec §2）。
★ **下げるほど読めるが、音は動く。それはまさに B1（ずっと鳴っていて気にならない）が守っていたものである。**

## ゴール

> ★ **層 0 の音量つまみを足し、コントラストを変えながら盲検で「密度が読める閾値」を測る。**
> ★ **閾値が出たら、その倍率で 10 分聴いて「B1（気にならない）と両立するか」を問う。**

⚠️★★★ **これは α（常時鳴らす形）の可否そのものである**（S4-D14）。
**閾値を知らずに α を捨てるのも続けるのも根拠が無い。★ 判断材料を作ってから判断する。**

★ **判定するのは研究者の耳である。** エージェントは **候補を作って聴ける形にするところまで**。

## 受け入れ条件

| # | 条件 | どう確かめるか |
|---|---|---|
| **AC-1** | 層 0 の音量つまみが存在し、**層 0 だけ**が下がる（層 2 は変わらない） | ★ **実クリックで倍率を変え、層 0 単体 rms / 層 2 単体 rms を別々に実測**して、層 2 側が動かないことを示す |
| **AC-2** | つまみの切替が **段差にならない**（spec §2 ✗オンセット） | ★ 6.0 s ランプ（他の候補切替と同じ）。★ **切替中の rms 軌跡を実測**して段差が無いことを示す |
| **AC-3** | ★ **自己検算の陽性対照（`expr.gain` を使う逆検査）と衝突しない** | ★ **逆検査を走らせて FAIL することを実測**（＝計器が生きている）。★ つまみを変えても逆検査の結果が変わらない |
| **AC-4** | ★ 各倍率で **①比の実測をやり直せる**（層 0 を変えれば比は変わる） | ★ 倍率ごとに比を実測し、**予測表と実測を並べて記録**する（★ 予測を実測として書かない） |
| **AC-5** | ⚠️★★★ **測定の前提を検査する 4 点**（S4-D15）が新しい測定にも効く | 出題が均衡 / 対照に実際に差がある / 校正が端点で測る / ピークが飽和しない —— ★ **4 点とも壊して赤くなることを実測** |
| **AC-6** | ★ 静的検査が **層 0 コアの逐語複製の一致**を保つ（S4-D8） | ★ `buildGraph` 等を **編集しない**。編集が要るなら Step 3 側にも同じ変更を入れる |
| **AC-7** | ★ 研究者が閾値を測り、その倍率で 10 分聴いて B1 を判定できる状態になる | ★ **手順を notes に書き、実際に聴いてもらう** |
| **AC-8** | ★ 実データ・NDJSON がリポジトリにも外部 LLM にも出ない | ★ `run.sh check` の混入検査（`git check-ignore` 実測）/ `/cross-review` に diff のみ |
