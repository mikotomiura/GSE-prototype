## 4. ★ 実装の要点

### 4.1 つまみ本体

```js
// ★ 書き手はこの関数だけ（S5-D5）。★ buildGraph は触らない（S5-D4）
function applyLayer0Gain() {
  if (!playing || !graph) return;
  const now = ctx.currentTime, gl = CFG.envelope.glide_s;   // ★ 6.0 s = 他の候補切替と同じ
  const g = graph.expr.gain;
  g.cancelAndHoldAtTime(now);          // ★ 連打しても前の曲線に重ならない（H5 と同じ型）
  const from = g.value, to = layer0GainOpt().gain;
  // ★★ raised-cosine（端点の傾きが 0）。★ S4-D9 が「一次遅れより厳しい」として採った形と同じ
  const curve = new Float32Array(N);
  for (let i = 0; i < N; i++) {
    const w = 0.5 - 0.5 * Math.cos(Math.PI * (i / (N - 1)));
    curve[i] = from + (to - from) * w;
  }
  g.setValueCurveAtTime(curve, now, gl);
  l0RampUntil = performance.now() + gl * 1000 + 300;  // ★ §4.2
}
```

- ★★ **なぜ `linearRampToValueAtTime` ではなく raised-cosine か** ——
  ★ **線形ランプは始端・終端で導関数に角がある。** S4-D9 は同じ論点で
  「**raised-cosine は端点の傾きが 0 なので `spec` §2 の ✗オンセットに対してより厳しい**」として
  一次遅れから乗り換えている。★ **層 0 の音量は「層全体のレベル」なので、最も角が聞こえやすい量である。**
- ⚠️ **`exponentialRampToValueAtTime` は使えない** —— **0 に到達できない**ので `l0_off`（倍率 0）が作れない。
- ⚠️★ **所要 6.0 s の帯域は約 0.17 Hz** で、**禁止帯の下端 0.5 Hz より下ではあるが 1 桁も離れていない。**
  ★ `glide_s = 6.0` は**既に全候補の切替で使われている値**なので本 Step で新しい危険を持ち込んではいないが、
  ⚠️ **「安全である」とは書かない。** ★ **切替は測定の合間の操作であり、常時起きる変調ではない。**

### 4.2 ★★★ 校正がランプ途中を測らないようにする（S5-D6 の 5 点目 = BF-3 と同じ形）

⚠️ **つまみが 6.0 s ランプなので、切り替えた直後に①を押すと「途中の倍率」を端点として記録する。**

```text
つまみを操作 → l0RampUntil = performance.now() + glide_s*1000 + 余裕
①（比の実測）は l0RampUntil を過ぎるまで開始できない（★ 残り秒数を画面に出す）
```

★ **「待ってください」と書くだけにしない。★ 実際に押せなくする**（BF-3 は手順で塞ごうとして失敗した形）。

### 4.3 ★ 検算（OfflineAudioContext）へは倍率を渡さない（S5-D5）

★ **検算は常に倍率 1.0 で走る。** ⚠️ 渡すと「検算の基準」が UI 操作で動き、回帰の意味が消える。
★ **逆検査（4 Hz を `expr.gain` へ注入）が、つまみを変えても FAIL のままであることを実測する**（AC-3）。

### 4.4 ★ 層 0 単体 / 層 2 単体を分けて測れるようにする（AC-1）

既存の `renderRms({layer0, grainRate})` が**オフライン**で層別 rms を測る型を持っている。
★ **実時間側でも「層 2 を切る / 層 0 を 0 にする」で分離できる**ので、
★ **つまみを変えて層 2 単体 rms が動かないことを実測する**（＝つまみが層 0 だけに効いている証拠）。
