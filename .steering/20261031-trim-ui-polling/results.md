# 結果

## 条件
- 開発版（debug）・`probe/run-dev-o1.sh`（`GSE_O1_MODE=1`・識別子 `com.johnd.gse-next-trim-polling`・HOME と GSE_DATASET は一時フォルダ）。通常運用の確かめは `probe/run-dev-normal.sh`（同じで `GSE_O1_MODE` なし）。
- Mac は電池（49%・放電中）・低電力モードは CPU の内訳のタスクと同じ設定のまま。入力監視の許可が無く、打鍵のフックは動いていない（トレイは HookDown）。
- CPU は `probe/cpu-window.sh`（ps の累積 CPU 時間の 60 秒の差・1 コア = 100%）で、本体と WebKit の子 4 つ（`probe/procs.py`・期待数 4 で確かめた）の合計。
- 呼び出しの回数は一時的な計装 IPC-DIAG（30 秒ごとに `get_cognitive_state` の回数と、`get_intervention_decision` の回数を主窓・overlay に分けて出す）。計装はコミットの前に外した。
- 最小化は `probe/axclick.swift` の minimize（題名 gse-next の主窓だけ）。

## 1. 直す前の呼び出しの回数（30 秒あたり）
- 主窓が見える: `get_cognitive_state` 59・主窓の判定 59（500ms ごと）・overlay の判定 0〜8。overlay は画面外にあり、WebKit がタイマーを間引いている（最初の 30 秒の 8 回の後は 0 回）。
- 主窓を最小化: 主窓は 30 回（1 秒に 1 回）に落ちた。WebKit が隠れた窓のタイマーを間引く。

## 2. CPU（O1 の形・記録中・60 秒 × 2・合計 %）

| 状態 | 直す前 | 取得を全部止めた版（上限の確かめ） | 直した版 |
|---|---|---|---|
| 主窓が見える | 2.66 / 2.38 | 2.01 / 1.99 | 1.96 / 2.41 |
| 主窓を最小化 | 2.27 / 2.59 | | 2.00 / 1.55 |

- 取得を全部止めた版（統合ポーリングの effect を早期 return にした一時的な差し替え・計装の行が 1 つも出ないことで 0 回を確かめた）: 下がるのは約 0.5 ポイント。これが取得を削る効きの上限。CPU の内訳のタスクで「記録中の増分の大部分」と見立てたのは誤りだった（あちらは相関で、因果は確かめていなかった）。
- 取得が 0 でも、本体 0.85〜0.90%・WebContent 0.72〜0.80%・GPU 0.25〜0.40% が残る。
- 直した版の O1: 主窓の `get_cognitive_state` と判定の呼び出しは 0 回（計装の行で確かめた）。見える間は無打鍵の時間だけを取る（計装の対象外）。最小化の間の本体は 0.45 / 0.48%（直す前は 0.78 / 1.03%）。合計の差は 60 秒の窓の揺れ（同じ状態の 2 回で最大 0.9 ポイント）と同じ程度で、効きは小さい。
- 1 回目の直す前・見える状態の測りは、zsh が番号の並びを 1 つの引数で渡して失敗した（測り直した）。最初の上限の確かめは、Vite の差し替え（HMR）が窓に効かず呼び出しが続いていたので捨て、起動し直して測った。

## 3. 通常運用での確かめ（非 O1・第 1 週の既定で「開始する」）

| 状態 | `get_cognitive_state` | 主窓の判定 | overlay の判定 |
|---|---|---|---|
| 見える | 59 / 59 | 58 / 59 | 3 / 0 |
| 最小化 | 20（切り替えの途中）/ 0 | 42（途中）/ 30 | 0 / 0 |
| 戻した後の 30 秒 | 21 | 39 | 4 |

- 最小化で WKWebView の `visibilityState` は hidden になり、表示用の取得は止まった。判定の呼び出しは続いた（介入の判定の時計は止まらない）。
- 既存の振る舞いとして分かったこと: 最小化の間、主窓の判定は 1 秒に 1 回（30 秒で 30 回）に落ちる。直す前の版でも同じ（1 を参照）で、今回の変更によるものではない。介入の判定の時計が窓の見え方で速さを変えることになる。別タスクの候補（判定の時計を Rust へ移す案と関わる）。

## 4. 片付け
- 開発版は 4 回起動した（直す前・上限の確かめ・直した版の O1・直した版の通常運用）。毎回、自分が起動したプロセス（本体・tauri・npm・vite・esbuild・起動のスクリプト）だけを止め、一時フォルダを消した。ポート 1420 は空いている。O1 の収集アプリ（pid 99037）は動いたまま。
