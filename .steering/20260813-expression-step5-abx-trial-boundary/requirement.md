## 背景

2026-08-13、研究者が **層 0 = 0.5 で ② 盲検 8 回**を実施し、**5/8（ヒット 2/4・誤警報 1/4）** を記録した

→ ★ 一次資料（`player/step4.html` の `abxBlindNext` / `abxAnswer` / `buildAbxOrder`）を読み、
**穴は 3 件あり、うち 2 件は研究者の指摘より重い**ことが実測で確定した。

### 穴 1 — 区間の境目に印が無い（★ 研究者が指摘したもの）

```js
abxSet("A"); await sleep(4000);
abxSet(kind === "diff" ? "B" : "A");   // ★ same は入れ替えない = 何も起きない
await sleep(4000);
```

★ `same` のトライアルは **8 秒間まったくの無変化**で、区間の境目が音にも画面にも無い。
→ 課題が「**8 秒のどこかで跳びが鳴ったか**」の検出に化けており、★ **1 回目は開始時点すら分からない。**

### 穴 2 — ⚠️★★★ トライアル間で状態がリセットされない

`abxAnswer` は結果を積んで次へ行くだけで、**`diff` のトライアルは B のまま終わる。**
次のトライアル冒頭の `abxSet("A")` が跳びを作る。★ **実測**:

| 時点 | 粒子率 |
|---|---|
| `abxSet("B")` 後 | 400 |
| `abxSet("A")` の 150 ms 後 | **106** |
| 700 ms 後 | **100** |

⚠️★★★ **当ててほしい跳び（100↔400）と同じ大きさで、向きが逆なだけの跳びが、トライアル冒頭で鳴る。**

★★★ **研究者のデータに指紋が出ている**:

| # | 正解 | 回答 | 判定 | 直前 |
|---|---|---|---|---|
| 0 | diff | diff | ✓ | （1 回目） |
| **1** | same | **diff** | ✗ 誤警報 | ★ **diff** |
| 2 | same | same | ✓ | same |
| 3 | same | same | ✓ | same |
| 4 | same | same | ✓ | same |
| 5 | diff | diff | ✓ | same |
| **6** | diff | **same** | ✗ 見逃し | ★ **diff** |
| **7** | diff | **same** | ✗ 見逃し | ★ **diff** |

★ **直前が `diff` の 3 トライアルが、誤り 3 件と完全に一致する。**
⚠️ **事後に見つけたパターンなので、これ自体は検定として扱わない**（偶然の確率 1/56 ≒ 1.8%・n=8）。
★ **ただし機構はコードに実在し、跳びは実測した。** 偶然として片付ける形ではない。

### 穴 3 — ⚠️★★★ 出題順が毎回まったく同じ

`step4.config.json` の `layer2_rework.abx.blind.order_seed` は **固定定数 `20260813`**。
`buildAbxOrder` は純関数なので、★ **実測で 3 回とも同一**:

`diff, same, same, same, same, diff, diff, diff` ← ★ **研究者の記録の `truth` 列と完全一致**

⚠️★★★ **0.25 / 0.125 / 0 でも同じ順が出る。** 研究者は既に 1 回聴いており、残り 4〜5 回同じ順を聴く。
→ ★ **後の倍率ほど正答が上がる**ので、★ **閾値が実際より高い倍率側に見える**（＝「もっと下げなくても読める」という逆向きの誤り）。
⚠️ **これは本 Step の結論そのものを壊す。**
