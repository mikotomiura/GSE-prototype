# pause-auto-resume —「すぐ止める」を押すと約 1 秒後に再開が記録される件

## 背景

CPU の内訳を測るタスク（`.steering/20261030-gse-cpu-profile/`・枝 `chore/gse-cpu-profile`）で、開発版のダッシュボードの「すぐ止める」を研究者が実際のマウスで押すたびに、`recording_pause` の `paused:true` の約 1 秒後（0.8〜2.5 秒）に `paused:false` が書かれた（5 回とも・研究者は再開を押していない）。AX で押すと画面の文字だけが変わり、行は書かれなかった。一次は同タスクの `results.md` の 4・8。

O1 の配布版（v0.1.40）でも起きるなら、被験者が「すぐ止める」を押しても記録が続き、同意文書 §4 の約束が破れる。

## ゴール

- 再開の行がどこから送られているか（どの窓・どの操作か）を、計装した開発版で研究者が実マウスで押して確かめ、原因を特定する。
- 原因が GSE の欠陥なら直し、回帰テストを置く。
- O1 の配布版（v0.1.40 の zip から作ったアプリ・識別子を変える）で同じことが起きるかを Mac で確かめる。
- 直した後に、一時停止中の CPU を測る（CPU のタスクの results.md の 7 の手順）。

## スコープ

### 含むもの
- 開発版への一時的な計装（呼んだ窓・時刻・クリックの種類）と、研究者の実マウスでの再現
- O1 の収集アプリの NDJSON から `recording_pause` の行の時刻と向きだけを読む（研究者の許可済み・外に送らない）
- 原因の修正と回帰テスト、`lib.rs` の `set_recording_paused` のコメントと実装の食い違いの直し
- Mac での配布版の確認と、一時停止中の CPU の測り

### 含まないもの
- Windows での確かめ（別のタスク）
- 研究者の O1 の収集アプリを止める・押すこと
- NDJSON の生ログ・キーストロークの内容を外部の LLM に送ること
- G-GEAR の処理中に PR を出すこと（push まで。PR の前に研究者に聞く）

## 受け入れ条件

- [ ] 再開の行の送り手が、計装の記録（窓の名前・時刻）で特定されている
- [ ] 欠陥なら、直した開発版で研究者が実マウスで「すぐ止める」を 1 回押し、`paused:true` が 1 行あり、その後 2 分以上、再開の行もデータの行も書かれない
- [ ] 回帰テストが直す前に赤・直した後に緑（`cargo test` / 該当するなら tsc）
- [ ] 配布版（v0.1.40）で起きるか起きないかが、行で確かめられ results.md に書かれている
- [ ] 一時停止中の CPU（本体・記録のスレッド）が測られている
- [ ] code-reviewer と /cross-review を通している
