| O1 セッションファイル受け取り先 | ★ **`FOLDER_ID`**（受け口が `.age` を置く先） |

### ⚠️★ 研究が終わったらデプロイを**アーカイブ**する（2026-08-29 に Phase1 で実施）

★ 終わった研究の `/exec` を生かしたままにしない。⚠️ ウェブアプリの exec URL は
**capability URL** であり、認証が無く、URL を知っていれば誰でも叩ける。

手順: **デプロイ** → **デプロイを管理** → 対象の行 → **アーカイブ**
（⚠️ `/dev` で終わる**テスト用デプロイは別物**。★ アーカイブするのは `/exec` のほう）

⚠️★★ **「アーカイブした」を表示で信じない。** ★ 前後を**同じ方法で叩いて**比べる:

```bash
curl -s -o /dev/null -w "%{http_code}
" "<exec URL>"
# ★ 生きている: 200（doGet が応答する） / ★ 無効化済み: 404
```

★ Phase1 の実測（2026-08-29）: アーカイブ前 **200** → アーカイブ後 **404**
（`?pid=…&action=…` の capability の形でも 404）。
8. ⚠️★★★ **1 日ぶんの実サイズで通し確認する** → §4（★ ゲートが赤で保持している当のもの）。
