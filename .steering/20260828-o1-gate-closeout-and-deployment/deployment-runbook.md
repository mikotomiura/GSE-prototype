## §0 ★ Drive の ID をどこから取るか

⚠️★★★ **ID の値をこのファイルに書かない。**
★ `.gitignore` の規約（逐語:「このリポジトリは Actions の分数都合で **一時的に public にする運用がある**」
「⚠️ 一度入れると public にした瞬間に…」「★ git 履歴に残るため、後からローテートしても痕跡は消せない」）
に従い、⚠️ **`FOLDER_ID` は Apps Script のスクリプト プロパティに置く**。

→ ★ 値は研究者のローカルにある **`Form_O1/Drive関連情報.md`**（⚠️ `.gitignore` 済み）を見る。
★ ここでは**名前と用途の対応**だけを持つ:

| `Drive関連情報.md` の行 | ★ 用途（下で使う） |
|---|---|
| O1 メインフォルダ | ★ 親。⚠️ **ここを配布に使わない**（→ §2） |
| O1 セッションファイル受け取り先 | ★ **`FOLDER_ID`**（受け口が `.age` を置く先） |
| O1 フォーム集約先 | ★ フォーム 2 本の置き場 |

> ⚠️★★★ **受け取り先には「リンクを知っている全員」を絶対に付けない**（★ 不変条件）。
> ★ 付けた瞬間に、フォルダ ID が「誰でも他の被験者のセッションファイルを読める鍵」に変わる。
> ⚠️ ID そのものは資格情報ではないが、**共有設定 1 つで資格情報になる**。

> ⚠️★★ **配布フォルダ（`O1_APP_DOWNLOAD_URL`）に当たる ID は渡されていない。**
> ★ 研究者判断 2026-08-28:「**まだ無い（これから作る）**」→ §2 で作る。
> ⚠️ **受け取り先やメインフォルダを配布に転用しないこと** ——
> 配布フォルダは「リンクを知る全員が閲覧可」にするので、
> ★ **他の被験者のセッションファイルが見える**状態を作ってしまう。

## §1 B-1: 提出の受け口（GAS `doPost`）

★ 手順の正本は `Form_O1/GSE_O1_Submit.gs` のヘッダ 1〜8。⚠️ ここは ID を差し込んだ写しである。

   ⚠️★★★ `GSE_Gate1_submit` にも `GSE_Gate1` にも**貼らない**。
2. `GSE_O1_Submit.gs` の中身を貼る。
3. ⚙️ プロジェクトの設定 → **スクリプト プロパティ**に 2 つ入れる:

   | キー | 値 |
   |---|---|
   | `FOLDER_ID` | ★ `Drive関連情報.md` の「O1 セッションファイル受け取り先」 |
   | `SHARED_SECRET` | ⚠️ **G1 とは別の**ランダム 32 文字以上（★ 新規に生成する） |

   ⚠️★ **`SHARED_SECRET` は repo に書かない**（★ ゲートが `.gs` への直書きを検査している）。
4. ⚠️★★★ **`checkSubmitConfig()` を実行する**（★ 未設定と打ち間違いは**同じ症状**になる）。
5. デプロイ → **ウェブアプリ** / 実行するユーザー=**自分** / アクセス=**全員** → `/exec` を控える。
6. 配布フォルダに置く `g1-submit.json` を作る（⚠️ **ファイル名は `g1-` のまま**。中身で行き先が決まる）:

   ```json
   { "endpoint": "https://script.google.com/macros/s/……/exec", "secret": "……" }
   ```
7. ⚠️ `.gs` を直したら**必ず新しいバージョンでデプロイし直す**（★ 保存だけでは反映されない）。
8. ⚠️★★★ **1 日ぶんの実サイズで通し確認する** → §4（★ ゲートが赤で保持している当のもの）。
