# 設計（v2・/reimagine 1 回目・requirement.md だけから作り直した案）

> 入力は requirement.md と、研究者が選んだ判断 P〜5（decisions.md）だけである。v1 の PR の切り方は引き継いでいない。比べは design-comparison.md にある。

## 1. 出発点: 後期を始めるのに最低限なにが要るか

後期の 1 日を成り立たせるのに要るものは、次の 4 つである。

1. その日の割付が読める。
2. 「あり」の日に手跡が出る。
3. その日に何が出たかが記録に残る。
4. 記録に入力値が混ざっていない。

これ以外の部品は、どれも「後期を豊かにするもの」である。帯・カーソル・クリック・ホイール・「背景を見る」・漏れの道具・日の問いの項目がそれにあたる。

そこで v2 は、PR を部品の種類（文書／OS 非依存／macOS）で横に切らない。**後期を始められる最小の縦の切れ端を先に main に入れ、残りをそれに足していく**。

## 2. 決定性を最初の切れ端に入れる

- 判断 2 の漏れの確かめは、記録から見た目を描き直せることが前提である。描き直せるかどうかは、描画の作り（時刻の進め方・乱数・状態の持ち方）で決まる。描き直しの道具を後の PR に回すと、先に入れた描画が決定的でないと分かったとき、描画を作り直すことになる。
- このため、最初の縦の切れ端に「決定性の約束」を入れる。
  - 手跡の状態（風・粒・草の位置）は、純粋な関数 `state(t) = f(打鍵の時刻の列, pointer_bin の列, 種, t)` で決まる。固定の時間刻みで進める。
  - 窓の側（tsx）は、その状態を描くだけにする。描画の回数（30／10 回／秒・覆われたら止める）は、状態に影響しない。
  - 同じ入力から同じ状態が出ることを、`cargo test` の性質のテストで確かめる。
- 机上の道具（描き直しと予測器の比べ）は、この関数をそのまま呼ぶ。見た目から作る特徴を、画素ではなく状態から作る案も、道具の PR で比べる。状態は見た目を決めるので、状態から作る特徴は見た目の情報を落とさない。⚠️ 「状態から作れば十分」は推測で、道具の PR で画素から作る場合と一度比べる。

## 3. 入口を閉じておく（main の他の利用者を巻き込まない）

- 手跡のコードは、段 1 のモード（`s1.rs` の判定: 配布形は実行ファイルを包むフォルダの印 `s1.mode`、開発・検証は `GSE_S1_MODE=1`）で、かつ割付の表のファイルがあるときにだけ動く。表が無ければ何もしない（窓も作らず、tap も張らない）。
- これで、O1 の配布や本人の前期の記録には、手跡が main に入っても何も起きない。前期の途中で main のビルドに上げても、前期のままでいられる。
- 表が読めない・壊れている・SHA-256 が合わないときは、手跡を出さず、日ごとの行に「出せなかった理由」を書く（fail-closed）。

## 5. 試作から写すもの・写さないもの

- 写す: `handmark_wind.rs` の計算・`input/handmark_pointer.rs` の型（Debug・Serialize を持たない）・語の検査の考え方と陽性対照・描画の中身（tsx）・帯の NSPanel の作り（`overlay_panel` の再利用）。
- 書き直す: lib.rs と tray.rs への配線（main の招待の項目と `request_quit` に合わせる）。描画の時間の進め方（§2 の決定性のため）。
- 写さない: 小面・計測の環境変数と CSV・合成ポインタ・失敗の強制・確かめ用の tracing の行。
- rebase はしない。試作の枝は参照として残す。

## 7. テストの考え方（実装の PR へ渡す）

- 決定性: 同じ入力の列と種から、状態の列がバイト単位で同じになる。乱数の種を変えると変わる（陰性の対照）。
- 記録: 手跡が動いても、日ごとの行以外の行が 1 行も増えない。日ごとの行に入力値が無い（語の検査と型）。
- 門: 段 1 のモードでない・表が無い・SHA-256 が合わない、の 3 つで何も起きない（陰性）。正しい表なら出る（陽性）。
- 割付: 表どおりの日に「あり・なし」になる。日をまたいでも、切った状態が翌日に持ち越されない。
- 画面: UI を変えた PR は、画面を見るまで完了にしない。本人の gse-next が動いている間は AX で押さない。

## 8. 戻し方

- 文書は revert すれば戻る。コードは §3 の門があるので、表のファイルを消せば、手跡は動かなくなる（本体の戻しが要らない）。
