# 要件: ユーザー検証データ収集の方法論設計

## 背景
v0.3 較正スモーク (RH1) および Phase 4 βテスト効果検証 (RH3) に向け、開発者本人 (P000) 以外の
外部被験者からデータを収集・保存する方法論を設計する。本タスクは設計判断のみ (実装は別タスク)。

## ゴール
- 参加者 ID の割り当て方式を決める
- データ送付チャネル (主観/客観) の分離方針を決める
- 効果検証 (c) 自己効力感の測定尺度を確定する
- プライバシー制約 (data-privacy Skill) との整合を保証する
- 収集〜DB 保存のエンドツーエンド経路を設計する (進行中)

## 受け入れ条件
- 生 NDJSON / キーストローク内容を外部クラウド・GitHub 経路に出さない
- 実名↔P-ID 対応表をデータ本体と物理分離
- 心理尺度は検証済み日本語版を出典明記で使用

## 検証の2層 (前提整理)
1. v0.3 較正スモーク: RH1 (状態分離精度)。真値 = アプリ内ランダムプローブ `realtime_label`
2. Phase 4 βテスト効果検証: RH3。指標 (a) AI依存度 / (b) 自力解決率 / (c) 自己効力感
