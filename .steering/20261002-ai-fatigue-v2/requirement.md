## ゴール

1. **抄録段（213 件 ＋ 探索の記録）**: 無料の学術 API で抄録を取り、記入表 1 を作る。判定者 1 が記入した答えを検査してログに写す。抄録段で除外した件は記入表 2（AI の判定）で 2 回目を行う。
2. **全文段（抄録段で含める・保留の件）**: 無料の本文を確保し、34 件と同じ 2 段の問い（1 回目は事実と基準だけ・2 回目に AI の判定）で判定する。含める一次研究は品質評価を確定し、群の終わりに抽出を確かめる。Q1・Q2 に当たる件に印を付ける。
3. **34 件のメモの論点の見直し**: v1 §5 の 8 点の答えを、判定で含めた記録まで広げて確かめ直す。
4. **追加候補の表**（Downloads の `AI_fatigue_additional_candidates_judge1.xlsx`）を全件の判定で作り直す。
5. **提案のドキュメント v2**（Downloads の .docx・単独で読める完成版）: 追加候補の全件の結果・Q1・Q2 で変わる件・メモの論点の答え・構想（C）の材料を、含めた一次研究の集合で数え直したもの。
6. **Downloads の退避ファイルの整理**（一覧 → 確認 → 削除）。
7. **完了**: code-reviewer ＋ security-checker（並列）・/cross-review 2 巡・出荷。

- 213 件と探索の記録（46 件のうち判定者 1 が足したもの）の判定（抄録段・全文段・2 回目）・抽出・品質評価（含める一次研究）。

- 記入表 1・2 を作る道具・読む道具・検査。追加候補の表・提案のドキュメント v2 の道具と検査（前のタスクの道具を写して広げる）。

- 研究者・著者への送信・照会・フォーム・OSF など外部に出る操作（研究者に渡すのはユーザー）。
- C の外枠・原稿・attack-me（研究者の返事 Q10 しだい）。N-05 の英語の登録版。
- 研究者が決めること（判定者 2 の人選・最終判定・基準の読み方 Q1・Q2 の確定・著者への照会・登録型にするか・追加候補を DB に入れるか）。
