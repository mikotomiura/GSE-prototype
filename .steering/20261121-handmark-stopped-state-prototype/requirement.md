# 手跡の止まり（ADR-056）の試作

作業の場所: worktree `C:\GSE-wt\stopped-state`、枝 `feature/handmark-stopped-state-prototype`（origin/main `bd557a6b` から切った。研究者が 2026-11-21 に「main から」を選んだ）。
引き継ぎ: `.steering/_handoff/next-session-handmark-adr056-prototype.md`。

## 背景

- 今の手跡は、打鍵が止まると風が 10〜50 秒ほどで消え、その後は何も返さない。30 秒止まっても 10 分止まっても、見た目はほぼ同じになる（ADR-056 Context 1）。
- ADR-056（Accepted・2026-11-20）では、次の形を決めた。打鍵が止まると自分の跡が引き、場の自律の動きが見えてくる。止まりの長さは返さない。設計案 §4.4（`.steering/20261120-handmark-coexistence-design/design-proposal.md`）で、作るものに降ろしてある。
- 始める条件の回 1（本人の段 1・前期の漏れの検査）は 2026-11-21 に回した。主は「満たす」で、写像は直さなくてよい（`.steering/20261117-stage1-self-run1/decisions.md` 判断 4）。研究者は 2026-11-21 に「始める」を選んだ。

## ゴール

ADR-056 の止まりの試作を、研究者自身が試せる状態まで作る。

1. 見えの度合い v を作る。v は `is_idle` と短い移り変わりだけで決まり、止まりの長さを持たない。
2. 自律の動きの値を作る。日の種と絶対の格子の時刻から、有限の窓で平滑して作る。`grid_start` と周期の関数は使わない。
3. 境界の状態を作る。起動の直後・戻した直後・記録の一時停止の間・一時停止が明けた後は、どれも最初の打鍵まで止まりを返さない。
4. 見た目の形を 3 つ作る（流れる帯・粒の漂い・風の向きの揺らぎ）。形・窓・強さ・移り変わりの長さは研究者用の設定で切り替え、参加者の配布物では切っておく。
5. 設計案 §4.4 の確かめ方 1〜3 を回す: 単体テスト、経過が読めない 3 つ (i)〜(iii)、漏れの検査（ADR-051 D3）。

## スコープ

### 含むもの
- `analysis/handmark/` の状態（v・移り変わりの始まりの時刻）と、自律の動きの純関数
- 窓の側の描画（3 つの形・研究者用の切り替え）
- 単体テスト。再生の決定性（`replay` と `replay_live` の `to_bits` の一致）を含む
- 机上の道具での確かめ（経過が読めない 3 つ・漏れの検査）。今ある基層（`drift`）の扱いは、(iii) の結果を見てから研究者に確かめる

### 含まないもの
- 研究者自身の数日ずつの試しと、値の確定。段 1 の期間の外で行う次のタスクにする（研究者が 2026-11-21 に「試しの前で区切る」を選んだ）。ADR-056 の「決めずに残すもの」の 1 は、このタスクでは閉じない。
- 段 1 の後期の配布物に入れること。後期（11-24 から）は今の手跡のまま始める。研究者が 2026-11-21 に「入れない」を選んだ。ADR-056 D6 の記述の比べは後に回す。
- 参加者に出すこと。段 2 の扱い（ADR-056 D5）。日の終わりの問いの項目（PR 7）。
- 入力のある間も動く層 2 の B と、A・C。
- ADR の本文の書き換え。

## 受け入れ条件

- [ ] v は移り変わりの後に一定で、止まりの長さで変わらない（単体テスト）
- [ ] 自律の動きの値は、`grid_start` をずらしても同じ時刻で同じ値になる。窓より離れた 2 つの時刻は乱数の値を共有しない（単体テスト）
- [ ] 境界の 4 つの状態で v = 0 になる（単体テスト）
- [ ] マウスだけを使う間（打鍵なし）は、ポインタの跡と自律の動きが両方出る（単体テスト）
- [ ] 移り変わりの始まりは「`is_idle` が初めて真になった格子の刻み」で決まる。更新の間隔を変えても、立ち上がりの途中で `replay` と `replay_live` の `to_bits` が一致する（単体テスト）
- [ ] 日付と割付の切り替え・時計の補正のときも、再生で同じ見た目になる（単体テスト）
- [ ] 経過が読めない (i)〜(iii) と漏れの検査を、机上の道具で回した結果を decisions.md に書く（推測で書かない）

- [ ] 止まりの長さ・経過時間・残り時間・累計を、見た目でも数字でも返さない。推定の出力を手跡に入れない（レビューで確かめる）
