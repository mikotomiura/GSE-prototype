# 設計

## 実装アプローチ

論文 3 と同じ分け方（`data.split`: 評価 = 後ろの H 単位、学習 = その直前の k 単位）で、本人の記録を A（学習の k 単位）と B（評価の H 単位）に分ける。A と B それぞれで 1 状態の 26×26 遷移表を当て、本人の A が他の書き手の A より本人の B に近いかを数える（同定の形）。これを、全員の入れ替えで作った帰無と比べる。

- 予測の点数（論文 3）は「本人の表が共有の表より本人の B をよく当てるか」を問う。差の向きと大きさが本人の中で安定していても、共有の側との差が小さいと点数に出ない。
- 目は「本人の A が、他人の A より本人の B に近いか」を問う。比べる相手は他の書き手なので、共有の表の良し悪しが打ち消される。
- データの量は論文 3 と同じにする（A = k 単位・B = H 単位）。目が論文 3 の取りこぼした段を拾えば、それは仕組みではなく読み方の差になる。

### 共通の部品

- 記号: 論文 3 の 26 記号（S3）。合成は `synth.py` の生成のまま。
- 共有の表 `S_{-w}`: w を除く全員の評価でない単位の遷移の数（`ml.pool_units(exclude=w)` と同じ単位）に 0.5 を足した 1 状態の表。
- 本人の表: `p_w^A[j,·] = (N_w^A[j,·] + m · S_{-w}[j,·]) / (N_w^A[j,·].sum() + m)`。m は行あたりの事前の数で、候補すべてで同じ値に固定する（conditions で凍結。初案 m = 26）。B も同じ作り。
- 単位をまたぐ遷移は数えない（単位の頭の記号は遷移の起点にだけ使う）。

### 目の候補（3 案）

| 案 | 近さ s(w → v)（v の B に対する w の A） | 意味 |
|---|---|---|
| E1 交差尤度 | v の B の記号列の、w の A の表での 1 記号あたり対数尤度 | 照合の考え方。B は生の列のまま |
| E2 ずれの相関 | δ_w^A = log p_w^A − log S と δ_v^B の重み付き相関（重み = 共有の行の占有 × S のセル） | 共有からのずれの向きが揃うか |
| E3 行ごとの JS | − Σ_j π_j JS(p_w^A[j], p_v^B[j])（π_j = 共有の行の占有） | 行ごとの分布の近さ |

- 書き手 v ごとの AUC_v = v の B の列で、他の書き手 w ≠ v のうち s(w→v) < s(v→v) となる割合（同点は 0.5）。
- パネルの量 T = AUC_v の書き手の平均。
- 帰無: B の名札を書き手の間で無作為に並べ替えた T（2,000 回）。p = (1 + #{T_perm ≥ T}) / 2,001。p ≤ 0.05 でその複製は「拾えた」。

### 合成の複製

- 生成は `synth.build`（論文 3 の感度の合成）を読み込んで使い、写さない。λ は論文 3 の `results/calibration.json`（K = 3: 1e-3〜3e-2・K = 5: 1e-2）を SHA-256 を照らして読む。
- 新しい SEED（2026112201）。複製の種は `build` の rep_seed に通し番号を渡す。
- 筋: 用量（全員に g）・分布（17 人中 5 人に 3e-2・`lam_rule("dist")`）・構造（真の K = 5 の差なしと 1e-2）。
- 形とセル: CoAuthor k = 5（主）・15・1、CS1 k = 5・1。
- 複製の数（生成は CoAuthor 0.1 秒・CS1 0.8 秒/複製と実測）: 差なし 1,000、各段 500。

### 選びと止め（判断 4・5）

判断 11・12 で改めた形（一次は conditions.md D5）。

- 許す: CoAuthor k = 5 の差なし 1,000 複製で拾えた数が 64 以下（Bin(1000, 0.05) の上側 97.5% 点）であることを、第 1 と第 2 の帰無の両方で満たす。
- 止め: 許された案のどれも、第 2 の帰無の CoAuthor k = 5・g = 3e-2 の検出力が 0.8 に届かなければ、凍結せずに止める。
- 選ぶ: 第 1 の帰無の CoAuthor k = 5・g = 3e-3 の検出力が最大の案。差 0.03 未満は同率とし、1e-2 → 分布の筋 → E1 > E2 > E3 の順で決める。
- 第 2 の帰無の生成の母数（nfs の npz）は HP Z2 にだけあるので、第 2 の帰無の複製は HP Z2 で回す。
