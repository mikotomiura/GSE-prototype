## 判断 4: 一時停止中の測りを打ち切り、「すぐ止める」の件を別のタスクにする（2026-10-30・研究者の回答・推奨どおり）

- **選択肢**:
  - A: CPU の計測は 3 状態で閉じ、この件は別のタスクで最優先に調べる
  - B: このセッションで原因を追う
  - C: 一時停止は測らずに終える（件も引き継ぎに回す）
- **採用**: A
- **理由**: O1 の配布版でも起きるなら、同意文書 §4 の「すぐ止める」が破れる。CPU の計測とは別の不具合で、文脈を混ぜると両方が中途半端になる。
- **トレードオフ**: 一時停止中の CPU（空回りの修正が実機で効くかの確かめ）は取れていない。ロガーを実際に動かすテスト（空回りの修正のタスクの results.md の 2）の 0.00% だけが根拠のまま。
- **影響範囲**: 次の O1 の版の確認手順（results.md の 7）の 1 番目に、この件の解決を置いた。
- **見直しタイミング**: 次のタスクで原因が分かったとき。開発版だけの現象なら、一時停止中の CPU を測り直す。
