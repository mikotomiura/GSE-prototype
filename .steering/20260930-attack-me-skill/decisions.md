## 判断 1: 完了時レビュー（/cross-review 1 巡目）の指摘を PR の前に直す（2026-10-01・G-GEAR）

- **背景**: 研究者の指示（前のセッション）は「次のセッションのタスクが終わった後に、この枝の PR を出す」。次のタスク（IME 論文の M0）が Mac で終わり main に入った（PR #278）ので、main を取り込み（`211e51b1`）、完了時レビューを回した。範囲は `9f1d28dc..211e51b1` の 8 ファイル。
  - Claude: code-reviewer（HIGH 4・MEDIUM 10・LOW 5）∥ security-checker（HIGH 1・MEDIUM 2・LOW 2）
  - Codex: `scripts/run-codex-review.sh`、パス限定・1 回・30,667 トークン（P1 1・P2 4）
  - ⚠️ git-workflow ルール 6: HIGH が残ったまま merge しない → PR の前に直す。
- **裏取り**: 指摘はすべて SKILL.md（改訂前）の本文で位置と逐語を確かめた。偽陽性は下の表の 2 件だけ。
- **採用した直し方（要点）**:
  - **読める範囲**（3 系統が一致）: 旧 L61「書き出される範囲」と旧 L174「`*.internal.*` でないもの」が食い違い、ひな形の方が広かった（`sealed/`・`runs/`・`experiment/raw/` が入りうる）。→ メインが `context-A.md` に「読んでよいファイルの一覧」を絶対パスで作り、それだけを読ませる。入れないものを名指しした（生ログは合成入力のものも・封印物・未追跡・`*.jsonl` ほか）。
  - **注入**（security HIGH）: 構造で閉じる。査読者役・監査役を新しい `paper-reviewer`（道具は Read・Grep・Glob だけ・`model: opus`）で起動する。論文の取得と本文の抽出はメインが行い、`round-<N>/tmp/sources/` に置く（`tmp/` は root の `.gitignore` が無視する。repo の外にしないのは、査読者役の Read が作業ディレクトリの中で届くようにするため）。応答はメインが目で見てから保存する。ひな形に「信頼できない入力」の節を足した。
    - 選ばなかった案: 依頼文に規則を足すだけ。理由: general-purpose は Web・Bash・Write を持つので、文だけでは外へ送る経路が残る。
  - **改訂 round の入力**（2 系統が一致）: 旧 Step 4「前の round の指摘と対応を渡す」と、ひな形の「他の round の記録を読まない」が矛盾していた。→ メインが役ごとに `carryover-*.md` を書く（その役の分だけ・他の役の指摘は渡さない）。
  - **採否の 2 層**: 裏取りの判定（真 / 偽陽性 / 確かめられない）はメイン、対応の採否は研究者。旧 L36・L116・L127・L235 を揃えた。
  - **接地**（2 系統が一致）: 数えるのは「確認済み、かつメインが本文を開けた（読めた）」文献だけにした。さらに次を足した。
    - 抜け道: 候補を 8 本試して足りなければ、立場の角度を替えるか研究者に問う。
    - 査読者役は、逐語の基準を 2 本以上の文献から取れなければ、査読に入らずに返す。
    - 裏取りは査読者ごとに 1 件以上。捏造が 1 件でもあれば、その査読者の引用を全件確かめる。
  - **規程の照合**（Codex P2）: 2 回の WebFetch が一致しても、同じ要約の経路なので照合にならない。→ 原文（`curl -sL`・pypdf）で逐語を確かめたものだけを「照合済み」とする。未照合の要件に依る指摘は研究者に問う。
  - そのほか:
    - stage の表に、査読者役に渡す重み（評価表 a〜g）と判定の読み替えを足した。意図（観点 1）は監査役の担当と明記した。
    - 複数の stage に当たる対象物は重みの和集合をとる。round 2 以降は stage を変えない。
    - 置き場を `attack-me/<stage>-<略名>/round-<N>/` にした。
    - 失敗した役（429・ハング・空）の扱いを決めた。「指摘なし」とは書かない。
    - 締切 25 分の根拠を書いた。
    - Codex の 5 人目の扱いを決めた: 4 本の後に直列で回す。preview と研究者の OK を取る。context-B は貼らない。一致の数は別枠で数える。
    - 検索語の規則を足した。
    - allowed-tools を変えた: 素の Bash を外し、Agent と AskUserQuestion を足した。
    - チェックリストを「起動の前」と「返ってきた後」に分けた。
    - 決定の根拠に使う文献は `citation-ssot` の対象とした。
