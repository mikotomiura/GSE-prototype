# design — 文献接地 1 ラウンドの進め方

## アプローチ

`/literature-review` の Step 0〜9 に従う。⚠️ ただし本ラウンドは **通常のサーヴェイではなく
「既に本文で使っている主張の *一次確認と登録*」**である（★ 探索より **検算**が主）。

→ ★ したがって **Step 1（RQ 分解）は「主張ごと」に割る**。

### 下位問い（★ 証拠の種類が変わる境界で割る）

| # | 下位問い | ★ 証拠の型 | ⚠️ どこに効くか |
|---|---|---|---|
| **Q-a** | **長い沈黙の意味は一方向か** | 実証（相関・符号） | ★★★ **ADR-030 D2 / D3**（onset を「持続」で切る） |
| **Q-b** | **打鍵過程特徴の性能天井はどこか** | 実証（AUC・baseline 比較） | ★ D10 の投資順序・`Q`（abstention）の必要性 |
| **Q-c** | **ラボの性能は実地に持ち越せるか** | 実証（外的妥当性） | ★ `Context-3b (vi)` |
| **Q-d** | **反復エピソード / 競合リスクの標準的作法は何か** | 方法論（統計の原典） | ★ D2 の反復エピソード規則・ADR-029 D3 |
| **Q-e** | **Translog-II / ENJA15 は IME をどう記録するか** | 一次仕様（データ・論文） | ★ 起票 5・`research-positioning.md:752-755` の否決判定 |

⚠️★★★ **温度は下位問いごとに分ける。**★ 平均化すると gate 判定を誤る（`/literature-review` Step 4）。

## テスト戦略（★ 本ラウンドは機械検査が薄いので明示する）

1. `PYTHONUTF8=1 python scripts/check_citations.py`
   ⚠️★★★ **1 回で全件出ない** → ★ **「違反なし」まで是正→再実行を繰り返す**
   （★ 検出: 未登録参照 / 欠番 / tombstone の引用 / 相互リンク無しの同一 key）
2. ⚠️★★★ **`check_doc_lexicon.py` は ADR を検査していない**
   （★ 対象は `docs/mitou_submission/**` ＋ `glossary.md` ＋ `physical-anchor/SKILL.md` だけ）
   → ★ **緑を「検査された」と読まない。手 grep を併用する。**
3. ★ **重複 key の手動突合** —— ⚠️ 前ラウンドの教訓「**key 突合の対象に *持ち越しの一次取得* を含めること**」
4. ⚠️ コードは 1 行も触らないので `cargo` 系は不要（★ 触ったら `cd src-tauri`）

## ⚠️ 失敗モード（★ 前セッションの 2 型を持ち込まない）

1. ⚠️★★★ **一次資料の一部だけを見て「核心を閉じた」と称する**
   → ★ 本ラウンドでは **サーヴェイ 551 行を全文読んでから着手した**（★ 2026-09-13）
2. ⚠️★★★ **二次情報（`.idea` メモ）の数値をそのまま `references.md` に書く**
   → ★ **原文で見た数値だけを書く。**⚠️ 見ていないなら **`provisional` ＋ その旨を明記**
3. ⚠️★★★ **有利な主張を甘く通す** → ★ 対称フィルタ（3 票）を GSE に不利な主張にも同じくかける
