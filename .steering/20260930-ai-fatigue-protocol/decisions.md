### 分け方（§7.3）の読み方として決めたこと（45 組を読んで）

1. **介入・曝露が違えば「別の研究」**: 同じ医療機関・同じ著者でも、AI の道具（返信の下書きと記録支援など）や試験が違う組は、§7.3 の「対象が明らかに違う」に当たるとして別の研究にした（例: S04-18 と S04-19）。
2. **N の違いだけでは「明らかに違う」としない**: 脱落・部分標本で N は変わるので、国・対象・時期のうち 2 つが一致し、ほかに違いが無ければ同じ研究の群にした（例: S02-09 と S02-11、AF006・AF007・AF009）。
3. **著者が違うのにデータが一致する組**（S14-02 と S14-51・S14-52: N 303・男性 49.8%・同じ変数と分析・言い換えに近い抄録）は、§7.3 のどの区分の条件（同じ報告・同じ研究の群はどちらも著者の重なりを求める）にも当たらない。→ 行は消さず、**「同じ研究の群」に入れて一致点と「著者が違う」を書く**（G10）。★ 元の DB の方針（不整合の指摘は研究不正の認定ではない）に合わせ、事実だけを書く。
4. **確かめられない組**は 3 組（AF002・AF003 の抄録なし、S04-74 の抄録に標本の情報なし）で少ないので、判定者用ファイルの群の列に「要確認」（U1・U2）として出す（§7.3 の最後の行の「件数を見て決める」）。
5. 方法論の文献どうし（AF030・AF031・AF033）は標本の研究ではないので、著者が重なっても別の研究にした（同じ報告の版違いではない）。
