# 手跡の表現の議論（handmark-expression-design）

## 背景

手跡（タンジビリティの層）の案 A（小面）は試作で、14 px の灰色の丸が打鍵ごとに白く光るだけの仮の見た目になっている（`.steering/20261016-handmark-a-surface-spike/`）。研究者は 2026-10-16 に「右下で白いのが光るだけなのはどうか」「背景（壁紙のような場所）で、打鍵に応じてリアルタイムに変わる潜在的なメディア表現があれば最適ではないか」「壁紙の差し替えではなく、その場所でメディア表現ができないか」と述べ、手跡の理論の語より先にこの議論を選んだ。事実の一覧は `.steering/_handoff/next-session-handmark-expression-design.md` §2。

## ゴール

次の 4 点について、研究者の判断を `decisions.md` に記録する（順番は判断 1 で決めた 4→3→1→2）。

1. 介入（招待）を背景で表すか（打鍵に合わせて背景を変えるだけか、行き詰まりの推定で背景を変えるか）
2. 背景の層で動く表現: 何を動かすか、打鍵とどう結ぶか、邪魔にならないか、状態計として読まれないか。2026-10-12 の判断 1（EH3 の後に回す）を見直すか
3. 小面の見た目と中身（何を返すか・大きさ・位置・色・動きの長さ）を手跡の 2 条件に照らして
4. 案 C（出会いの再生）と案 D（手触りの写像）の形、EH3 の形の文法とのつなぎ

必要なら、合成の打鍵列だけで作った見本のページで動きを見比べる。

## スコープ

### 含むもの
- 議論と判断の記録（decisions.md）、論点の整理（design.md）
- 必要に応じて見本のページ（artifact・合成の打鍵列のみ）
- 決まったことを試作に回すための引き継ぎ

### 含まないもの
- コードの変更（`src-tauri/`・`src/`・EH3 のファイル・G-GEAR の `experiments/`）
- 背景の層の技術の実現可能性の断定（Mac のデスクトップの高さの窓・Windows の WorkerW・画面共有に写るか）。要るなら試作のタスクにする
- PR を出すこと（push で止める）
