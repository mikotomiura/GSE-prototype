## コンセプトの書き換え（★ サーヴェイ結果に従う）

### 降ろす表現

| 降ろすもの | 理由 |
|---|---|
| 「認知リソースを**一方向に消耗**させる」 | ★ ego depletion の限定資源モデル。事前登録の大規模再現が **d = 0.04 / 0.06**、バイアス補正で **b = 0.003**。⚠️ Vohs 2021 は**操作が効いていた**（努力感 d = 1.76）のに成績が動かなかった |
| 「生成 AI ワークは通常のスクリーンワークより**消耗が激しい**」 | ★ 因果的に最強の証拠（stepped-wedge RCT / 3 群 RCT）は**逆向き**。⚠️ 山 (b)（AI に置き換えられる不安）を山 (a)（道具の使用負荷）の証拠として使うのはカテゴリーエラー |
| 「特別な機材は一切不要——…点が GSE **最大の強み**である」 | ★ 断定が強すぎる。⚠️ 実際には**キーボード自体を作るわけではなく**、PC の常駐アプリである |
| 段階呼称 **Lv1〜Lv4** | ADR-018 D7 |
| 絵文字 **⚠️ / ★** | 研究者指示。★ 強調は**語**で行う |
| Physical Anchor の**完了条件**（時間＋往復） | ADR-018 D1 / D2 |

### 立てる表現

| 立てるもの | 一次根拠 |
|---|---|
| 「demanding な作業を続けたあとに変わるのは**処理能力ではなく、投資を続ける意思**である。人は決定閾値を下げて**関与から降りる**」 | Lin, Saunders, Friese, Evans & Inzlicht (2020) *Psychol. Sci.* 31(5) —— 事前登録 4 実験・N=686・拡散モデル。逐語 *"reduced response caution rather than inhibitory control … people disengage"* |
| 「生成 AI は仕事を重くするのではなく、**生成の努力を肩代わりして関与を下げ**、残りを**検証**へ移す」 | Burelli et al. (2026) arXiv:2606.20598（N=60・事前登録クロスオーバー・EEG θ/α 低下）＋ Lee et al. CHI 2025（*"shifts … toward information verification, response integration, and task stewardship"*） |
| 「GSE が守るのは**関与が起きる余地**である」 | ★ 上記 2 本から自然に接続する。⚠️ 「消耗を回復させる」とは書かない |
| **Physical Anchor = 身体的回帰への方向づけ**（完了条件なし） | ADR-018 |
| **計測なき身体回帰**を §3 の新規性として明示 | ADR-017 D10 / ADR-018。★ [P77] Etkin *"measurement itself can thus have similar effects"* |
| **3 クラス分類は後段のサブ応用研究** | ★ 「降ろした主張」ではなく「本研究の後に位置づく応用」として書く（研究者指示） |
| **未踏理由 = n=1 の限界と玄人の助言の必然性** | ★ 研究者の文言に沿って書き下ろす |
