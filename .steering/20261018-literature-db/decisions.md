## 判断 9（2026-10-18・メインの判断・2026-10-18 の手作りの版との違い）

`build.py` を 2026-10-18 の commit に固定して作り（README §6）、Drive の `GSE文献DB_v2_2026-10-18.csv` と列ごとに比べた。件数（906・要約 675・カードでの記述 576 件 1,571 行・番号の衝突 48）と、ID・番号の衝突・名前空間・著者と題・研究の筋・要約・特徴・要約の材料・カードでの記述・枝・key は一致した。違いは次のとおりで、どれも手作りの版の誤りを直す向きなので、新しい方に揃える。

- **接地の `<` `>`**: 手作りの版は `<https://…>` の山括弧を外すときに、本文の不等号まで消していた（「d=.43 > schedule」→「d=.43 schedule」・「p<0.001」→「p0.001」・30 件）。URL を囲む山括弧だけを外す。
- **年**: 手作りの版は出典の最初の 4 桁を年にしていたため、頁や論文番号を年にしていた（`e2013097118, 2021` → 2013・`27:1949–1963, 2023` → 1949 など 20 件）。注記（最初の「（」）より前の最後の年を採り、頁の範囲・論文番号・`arXiv:2010.…` を年にしない。年が書かれていない出典は空のまま（`CHI '10, pp.1851–1860` は手作りの版も空・`Journal of Educational Data Mining（arXiv:2010.04124…）` は 2010 → 空）。
- **カードの題の ★**: 手作りの版はカードの題（`_index.md` のトピックの列・60 字まで）に ★ を残していた。外す（記号を多用しない方針）。
- **カード外の引用元**: 手作りの版は 200 字ほどで切れていた（9 件）。切らない。
- **URL が「—」**: 手作りの版は「—」をそのまま URL にしていたものと、DOI から補ったものが混じっていた。「—」は空とみなし、DOI / arXiv から補う。
- **状態の `**`**: 外す（1 件）。
- **CSL**: 人名から Crossref の `affiliation`・`role` を落とす（手作りの版は文字列にして持っていた）。Crossref の型名（`journal-article` など）を CSL の型名に直す（手作りの版は 896 件が `@misc` になっていた。直すと `@article` 494・`@inproceedings` 138・`@inbook` 11）。キャッシュで取れなかった DOI の書誌に DOI を入れる。最小限で作る書誌の型は `document`（手作りの版は `article`）。
- **読んだ の FALSE**: シートの 読んだ はチェックボックスで、付けていない行は `get_values` で `FALSE` が返る（2026-10-18 に実物で確認）。それは書いた内容に数えない（数えると、消えた key のたびに中身の無い行で止まる）。

## 判断 11（2026-10-18・メイン・/cross-review 1 巡目への対応）

Claude（code-reviewer）と Codex の両方が回った（縮退なし）。指摘はメインが関数を直接呼んで再現してから採否を決めた。

採用して直したもの:
- **読んだ・メモが黙って消える入口（両者一致・HIGH）**: シートの見出しに `key`・読んだ・メモの列が無い／JSON に `values` が無い／表が空のとき、終了コード 2 で止める（前は空の 読んだ・メモ で CSV を作っていた・再現済み）。
- **rekey の重なり（両者一致・HIGH）**: 2 つの key が同じ key に入るとき、後の方で上書きしていた（再現済み）。終了コード 3 で止める。
- **空の key・同じ key の 2 行（Claude・HIGH）**: 空の key に書いた行は捨てていた。同じ key の行は後勝ちだった（再現済み）。内容が同じ 2 行は 1 つにまとめ、違えば止める。
- **FALSE の扱い（両者一致）**: チェックボックスの列（config の `checkbox_columns`・既定は 読んだ）だけに限る。メモの「false」は残す。
- **途中で止まった回の出力（Codex）**: 一時のフォルダに全部作ってから出力先へ移す。止まった回は出力先が前の回のまま。`--no-bib` の回は前の回の .bib を消す。シートの値は、ネットに出る前・何かを書く前に読んで確かめる。
- **温度（Claude）**: `3-0` などが日付（`2026-03-04`）の中に当たり、「確定した」「否決した」の動詞にも当たっていた（再現済み）。直すと、2026-10-18 の版で 12 行の温度が変わる（後ろの動詞が前の票を上書きしていた 8 行は票に、動詞だけの 4 行は空に）。件数は変わらない。
- **fetch の一過性の失敗（Claude）**: タイムアウト・429・名前解決の失敗をキャッシュに残さない（404・410 だけ「無い」と覚える）。2026-10-18 のキャッシュには一過性の失敗が残っていた（Semantic Scholar の 429 が 26 件・名前解決の失敗が 7 件）ので、抄録の無い記録で失敗が一過性だけのものは次の `--fetch` で取り直す。
- **ls-tree の日本語のパス（Claude）**: `-z` にした。いま日本語の名前の .md（mitou_submission の 5 本）に引用は無く、件数は変わらない。
- **7 列で接地に ` | ` がある行（両者一致・LOW）**: 重複の列の形（`—` か、番号で始まる短い印）で 8 列と見分ける。最初に入れた形（`→P430`・`=V9` だけ）は狭すぎて、実データの 8 列の行（4 枝で延べ 32 行・`[P270]`・`→ **[P116] が正**` など）を 7 列と読み、重複の列を接地に混ぜた（2026-10-18 の版で 8 件の接地）。2026-10-18 の版との比較で見つけて広げた。
- **ページ**: `<script>` に埋めるデータの `<` をすべて `\u003c` にする。ハイライトは元の文字列で探して断片ごとにエスケープする（`&amp;` や挿れた `<mark>` に当たっていた）。リンクは http(s) のときだけ。

採用しないもの・確かめたもの:
- **CSV の数式（Codex・要確認）**: 2026-10-18 のデータで `= + - @` で始まるセルは 0 個（最初に 3,923 個と数えたのは、空のセルを数えた私の検査の誤り）。値を書き換える対策は入れず、`manifest.json` の `formula_like_cells` に数え、1 個以上なら警告する。
- **arXiv の版つき key（要確認）**: 実データに版つきの arXiv の key は無い。
- **年が頁に当たる（LOW）**: 出典に年が無く頁だけがある形（`7(2), 1850–1855`）は、まだ頁を年と読みうる。実データで当たる行は見ていない。直さない。
- **要約の写しの検査の限界**: `merge_summaries.py` は英語の語で抄録との重なりを数えるので、抄録を日本語に訳して写したものは見つけられない。依頼文（自分の言葉で書く）と、数値の目視に頼る。

変異テスト: 直した 14 か所を 1 つずつ壊して、11 か所が赤。残った 3 か所のうち 2 つ（見出しの列の欠落・空の key）は、別の経路（ValueError・正本に無い key）で同じく何も書かずに止まる。温度の 1 つはテストが日付の後ろ側しか見ていなかったので、前の数字だけが手がかりになる例（`2026-12-1`）を足して赤を確かめた。
