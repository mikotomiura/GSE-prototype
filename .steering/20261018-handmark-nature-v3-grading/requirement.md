# 自然世界の見本（版 3）を改め、打鍵の影響の強さを伏せて見比べる

## 背景

`.steering/20261017-handmark-why-interesting/` の議論で、背景の表現は版 3（自然世界）を前提に進めることになった（判断 7）。S-NW（`docs/literature/20261018-handmark-nature-world.md`）を材料にした議論で、版 3 の写像を「入力の性質を自然の乱れに写す・基層の時間の進みは打鍵で変えない」に寄せること（判断 9 (2)）と、打鍵の影響の強さを数段に振って伏せて見た後に写像を開示すること（判断 9 (3)・判断 11 (2)）が決まった。いまの見本（`handmark-nature.html`）はそのどちらにもなっていない。

引き継ぎ: `.steering/_handoff/next-session-handmark-nature-v3-grading.md`。

## ゴール

見本のページ（版 3）を次のように改め、同じ URL へ出し直し、設計者本人が伏せた見比べを行える状態にする。

1. 打鍵の速さを風の平均の強さ、打鍵の不規則さを風の息（むら）に写す。基層（霧・草の小さな揺れ・粒の上下）は打鍵で変えない。
2. 基層を周期の無い漂い（ノイズ）にする。元の正弦波と切り替えて見比べられる。
3. 打鍵の影響の強さを 4 段（倍率 0 / 0.33 / 0.67 / 1）に振れる。
4. 伏せた見比べの欄: 4 段を符号で伏せ、乱数の順で見せ、`20261017-handmark-why-interesting/decisions.md` 判断 4 の 4 項目を 7 段で付ける。結果は文字列として表示し、送信も保存もしない。
5. 画面の中で動く量（動いた画素の割合・明るさの差の平均）を数えて表示する。

## スコープ

### 含むもの
- 見本のページ 1 枚（`.steering/20261017-handmark-why-interesting/handmark-nature.html`）の改修と出し直し
- 符号の割り当てと順の乱数での決定・記録・開示
- 設計者本人の評定の記録と開示（1 人・設計者本人の観察として）

### 含まないもの
- Tauri の背景の層（`HandmarkStage.tsx`）への移植
- 人の段の計画（2 回とも伏せる対照・群の割り付け・人数）。要件として判断 11 (2)・12 にある
- 線の版と自然世界の版の注意の比較そのもの（判断 10）。今回は動く量を数える準備だけ
- 理論の文書・用語表・ADR の書き換え

## 受け入れ条件

- [x] 強さ 0 で、打鍵しても画面が打鍵前と同じ動き方である（基層だけ）

- [x] 打鍵を止めても霧・草・粒が漂い続け、その進みは打鍵で変わらない
