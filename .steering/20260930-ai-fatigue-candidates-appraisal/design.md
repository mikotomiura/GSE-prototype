- 判定者用ファイルの『はじめに』は `judge_xlsx.intro_rows()` を直して作り直す。

## 値の語彙（評価プロトコル v1.0 §2・§3 ＋ 2026-09-30 の範囲の決定）

| 列 | 値 |
|---|---|
| 題名・抄録段 | `含める` / `除外` / `保留` |
| 全文段 | `含める` / `除外` / `保留`（本文を読んだものだけ）／ `保留` ＋ E6（OpenAlex に無料の版が無い）／ `未実施`（本文を読んでいない・研究者の決定で読まない。無料の版がある、または本文の入手が分からない）／ `—`（題名・抄録段で除外） |
| Claude案（現時点） | 全文段を判定したものはその値。未実施は題名・抄録段の値。E6 は `保留` |
| 除外理由 | `E1`〜`E6` と短い理由。題名・抄録段で除外なら必須 |
| 全文確認・抽出 | `完了`（前のタスクで本文を読んだ）／ `未完了`（無料の版あり）／ `入手不可`（OpenAlex に無料の版なし・判断 3 の用語の範囲）／ `入手不明`（DOI なし・OpenAlex に記録なし。★ 2026-09-30 のレビューで足した）／ `対象外`（題名・抄録段で除外） |
| 中心範囲の段 | `中心-A` / `中心-B` / `中心（A/B 未確定）` / `境界（保留）` / `背景（E2）` / `背景（E4）` / `除外（E1）` / `除外（E3）` |
| 用途判定（Claude） | 中心範囲の段から決まる: 中心-A・中心-B・中心（A/B 未確定）→ `中心候補`、境界 → `保留`、背景 → `背景保持`、除外 → `除外` |
| 原文確認レベル | `題名のみ` / `抄録` / `本文関連箇所確認` |

- ★ 中心-A と中心-B の分け方（9/29 の評価基準の規則を変えない）: 抄録で項目文・定義に AI が入ることを確かめられないものは `中心（A/B 未確定）`。★ ただし抄録が一般の尺度の名前（MBI・CBI・Mini-Z・BAT など）を書くもの、疲労を AI と無関係の課題で操作したもの、AI に触れない単一項目と本文で確かめたものは `中心-B`。AI 疲労としての語り・自由記述を分析すると抄録が書くものは `中心-A`。
- ★ 範囲の決定 (a)（AI の導入・利用の比較で疲労系の結果を測る研究）は、結果の向きとデザインを問わない。作業負荷・時間だけを測った比較（S-04 §3.1・§3.2・S12-10）は、抄録の評価項目に疲労・消耗・燃え尽きが無いと確かめたものは、題名・抄録段 `除外` ＋ E2・中心範囲の段 `背景（E2）`（作業負荷は E2 の「隣接概念」）。★ 抄録が燃え尽き・疲労を何らかの形で問う（副次の評価項目・知覚の質問）と書くものは `含める`・`中心-B`。抄録が評価項目を列挙しない・抄録が無いものは、迷ったら含める（`含める`・`中心（A/B 未確定）` ではなく、疲労の測定の有無が分からないので `境界（保留）`）。
- ★ AI が人の疲労を検知・予測するだけの研究（S-12 §3.2 など）は `除外（E1）`。AI が研究者の分析の道具で、参加者が AI を使っていないもの（S12-11・S12-12・S12-20）も E1 の見立て（プロトコル v1.0 の E1 の文言「AI 利用者の疲労を扱わない」）。
- ★ 同じ研究の別の記録（前刷りと雑誌の版）は、1 件ずつ行を持ち、`Claude照合事項` で結び、E5 の案は判定者に委ねる（題名・抄録段は各行の中身で決める）。
