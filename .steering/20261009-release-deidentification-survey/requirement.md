# 要求: 公開する打鍵の記録の照合・復元・再識別のサーヴェイ（issue #333）

## 背景

- issue #333 は、ADR-039（打鍵の記録の研究利用と公開）の技術側の論点をまとめた議論のメモである。
  公開の段（段 0 集計値 / 段 1 分析に使った表現 / 段 2 加工した打鍵イベント / 段 3 生の記録）と、
  加工・アクセス条件・公開前の関門（照合攻撃ほか）の案を挙げ、「現時点の推奨（未決）」を置いている。
- 2026-10-09 に研究者と話し、**決める前にサーヴェイを 1 ラウンド挟む**ことにした。理由:
  1. 公開は撤回できない（誤ったときの代償が非対称）。
  2. issue の要の主張に根拠が無い —— 「数十語で候補の文章をほぼ一意に特定できる」は issue 自身が「概算・要実測」。
     加工の効き目の根拠 [V239] は抄録だけ、[V240] は下位エージェントの報告だけ。
  3. repo に打鍵データの公開・再識別・開示制御のサーヴェイが無い（`docs/literature/_index.md` で 0 件）。
  4. 急ぐ理由が無い（2 本目の論文の収集は審査の後・ADR-039 D1）。期限は**審査の申請書と同意文 v2 を書く時点**。

## ゴール
