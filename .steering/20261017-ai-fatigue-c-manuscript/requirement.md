# AI 疲労の測定論の論文（C）—— 実現性の見積もりと原稿の外枠

## 背景

C の登録版（`.steering/20261017-ai-fatigue-c-outline/registration-en.md` 0.6）は凍結の手前まで来た。検証の集合は 2026-12-31 に締まるが、何件入るかの見積もりがまだ無い。論文の形（C を単独の論文にするか、narrative review と 1 本にするか）は、研究者が「見積もりを見てから決める」とした（2026-10-17）。

## ゴール

1. 検証の集合に入りそうな件数を、幅と前提つきで出す（`feasibility.md`）。
2. 論文の形を研究者に聞く。
3. 原稿の外枠（主張と根拠の対応表・節の構成・結果の入れ物の表）を書き、プレ査読にかける。

## スコープ

### 含むもの
- 見積もりの脚本（決定的・seed 固定）と、その出力を使った `feasibility.md`
- 原稿の外枠（結果と考察の本文は書かない）

### 含まないもの
- 登録版の変更（必要なら提案として書き、研究者が決める）
- 審査・コーディングそのもの

## 受け入れ条件

- [ ] 見積もりの各数字が、一次（追加候補の表・34 件の判定ファイル・登録版）までたどれる
- [ ] 前提を変えたときの幅が表になっている
- [ ] 見積もりを原稿・登録に書かない（結果の予想にあたるため）ことが守られている
- [ ] 論文の形を AskUserQuestion で聞いた
