# requirement — 本日のリマインド予定タブ

## 背景
Phase1 未提出者リマインド (`sendReminders`, 毎日 20:00) は送信判定を関数内にインラインで持ち、
結果は「リマインド運用」タブ(生ログ)に残るだけ。研究者が「本日 誰に送る予定か / 誰に既に
送ったか」を一目で俯瞰する場所が無い。

## ゴール
管理シートに「本日のリマインド予定」専用タブを新設し、以下を一覧表示する。
- ① 送信予定(今夜 20:00 に送る候補) … 日次 / 停滞チェックイン
- ② 本日 送信済み … 日次 / 停滞
- ③ 応答あり・抑制中(送信しない) … doGet 応答 / 停滞スロットル中
- ④ 対象外・送信不要 … 本日提出済み / 未オンボード / メール未登録 / 撤回除外

## 受け入れ条件
- 表示は既存ダッシュボード同様 **P-ID のみ**(実名・メールはロスタータブに閉じる)。
- 送信判定は `sendReminders` と **同一ロジックの単一真実源**(判定を共有関数へ切り出し、
  送信タブ双方が同じ関数を使う。二重化しない)。
- `sendReminders` の送信挙動は変えない(リファクタは等価)。
- タブは buildManagementSheet / refreshRosterStatus / sendReminders 実行後に自動再描画され、
  夜間送信後は「予定」→「送信済み」へ自動で切り替わる。
- 研究者が任意タイミングで最新化できる `refreshReminderPlan()` と、管理シートの
  カスタムメニュー「GSE 運用」を用意する(標準スクリプトのため installable onOpen トリガー)。
- Phase1=終了 / REMINDER_ENABLED=false / 下書きモード時は、実際には送らない旨をバナー表示。

## 非対象
- 送信の承認ゲート化(本タブは監視・プレビュー用であり送信を止めない)。
- 実名・メール本文の表示。
