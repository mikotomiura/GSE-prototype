# audit（意図の監査役・paper-reviewer・opus）—— round 1

最も重いのは 2-1 と 2-3。

## 1 意図にあって対象物に無いもの
- 1-1 「本文を保存しないことはプライバシーの保証ではない」が無い（ADR-054 D3・RP §2.2）。漏れの値は L17・L39 にあるが結論の一文が無い。
- 1-2 「人の申告は 0 件・人のデータは実質 n=1」の現状の一文が無い（前回の指摘の中心・review-response L12・L22）。L41 は計画だけ。
- 1-3 持ち帰り 1 の「尖り」が名指しされていない（§1 の見出しは「一言」）。
- 1-4 ADR-054 Consequences の「計測と方法の研究に見えるおそれ」に、派生の素材なのに答えていない（系は L20 の 3 文と §4 の否定だけ）。
- 1-5 RP §9.2 の主張しないことの一部（停滞の始まりで詰まりを検出・身体回帰が起きたこと〔測らない〕・手跡の動機づけ・共生・再開が速い＝良い）が落ちている。L20 で身体回帰の招待を書くので「身体回帰が起きたことは測らない」を外すと誤読の余地。

## 2 対象物にあって意図に無いもの
- 2-1 「読める所」の材料（L15 IME の変換の有無）が停滞の材料ではないのに、L20「読める所でだけ、系は停滞の中の本人に…招待を差し出す」と結んでいる。正本は「見分けられた所は…適格の条件に使う」（RP §1.2）・「契機の時点までに見える観測だけで評価し直したものに限って段 2 の適格の条件に移す」（§2.2）。適格の条件はまだ無く段 1 で作る、の限定が抜けている。「確かに言える」も強い（合成入力だけ・Windows の precision 0.76 が省かれた）。
- 2-2 L16「観測からは言えないこと」は観測一般の否定に読め、ADR-054 D3（推定器の 30 秒の上がりに限る）・L27 と衝突。0.49〜0.52 に KLiCKe の 0.512・0.518（検出できるがごく小さい）を括っている。
- 2-3 L49 が「探索していない手順」と「見つからなかった組み合わせ」を混ぜている（RP §8 は、3 つの検査の手順は先行の探索をしていない、見つからなかったのは別の組み合わせ、と分ける）。
- 2-4 L26「事前登録した帯の中で 3 つの公開データに当てた」: 正本で事前登録の帯の内と書かれるのは CS1 の holdout だけ。L37 とも食い違う。
- 2-5 定義の検査の結論から「調整」が落ちた（L18・L38）。影響は小さい。
- 2-6 漏れる所の行（L17）に「合成入力」「候補の集合が既知」の限定が無い。
- 2-7 L3 が「正本」と呼ぶ ADR-054 は Proposed（状態の注記）。

## 3 矛盾
- 3-1 意図どうし: 判断 5・ADR-054 D5 は派生の素材で系を前に出す想定、持ち帰り 3 と対象物の作りは系を従に置く。この素材で系をどこまで前に出すかが決まっていない。
- 3-2 L16 と L27（一般の否定と、推定器 1 つに限る否定）。
- 3-3 L26 と L37（帯が事前か見た後か）。
- 3-4 L15・L20 と L41（停滞について読める所は今の対象物に無い）。
- 3-5 L28「同時に、2 つのことが分かった」: ADR-054 Context 5 では R2・R3 は R1 の後に出た別の研究で、同時に出た結果ではない。経緯として不正確な可能性。

## 4 沿っていた所
一言（L9）は D1 と逐語で一致。持ち帰り 2 は L29〜31、持ち帰り 3 は L20 の末尾と L48。定義の検査をまだ当てていないことは L37。AI は判断 8 のとおり（L37 の CoAuthor 1 回）。
