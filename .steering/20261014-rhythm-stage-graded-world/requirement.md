# 背景のステージの机上の検査 —— 中間の world（打鍵の間隔の 3 段）

## 背景

第 1 回（`.steering/20261012-rhythm-stage-desk-check/`・SEED 20261009）と第 2 回（`.steering/20261013-rhythm-stage-round2/`・SEED 20261013）は、どちらも world v4 で回した。v4 では FLOW と STRUGGLE の打鍵の時刻は同じ作り方で、停滞は訂正の率と区間の構造にだけある。項目 1 は作りの上で緑に寄りうる。v4 の緑は「停滞が打鍵の時刻に出るときにステージがそれを写さない」ことを言わない（第 1 回 design §3.3 の v4 の宣言）。一方、v2（停滞が打鍵の間隔に出る世界）は基準のモデルの天井に当たる（L300 の AUC(A_speed) の小さいほう 0.997）。

項目 1 の判定（赤は 2 回とも 0）は、L300 が第 1 回で緑 14・判定不能 10、第 2 回で緑 24。L1800 は 2 回とも 24 本が判定不能だった。PC1 の手がかりは直前 60 s、PC-stall の手がかりは直前 300 s で、ラベルの範囲（1800 s）に合わない（`stage.py` の `PC1_SPAN_S`・`PC_SPAN_S`）。

研究者の判断（第 1 回の判断 16・21、第 2 回の判断 7）:
- 天井の値に合わせて世界を調整しない（判断 16）。中間の world は、強さを段にした系列を結果の前に固定する（判断 21）。
- 段の軸は打鍵の間隔で、v4（t = 0）と v2（t = 1）の間の 3 段（t = 0.25 / 0.5 / 0.75）を置く。下見 0 は段ごとに回し、L300 で両方の分類器が天井になった段は判定不能（`ceiling`）として報告し、先へ進めない。
- L1800 に、直前 1800 s の停滞の割合を使う専用の PC1 と PC-stall（候補ごと）を足す。L300・L60 の対照は変えない。

引き継ぎ: `.steering/_handoff/next-session-rhythm-stage-intermediate-world.md`。

## ゴール

1. 設計（`design.md`）を書く。第 2 回の design から変えるのは、world の段（補間の式と 3 段）・段ごとの下見 0 と天井の規則・L1800 の専用の対照・seed だけにする。固定の前の `/cross-review` に通し、どの結果（下見 0 を含む）よりも前にコミットして固定する。
2. 計器を `experiments/20261014-rhythm-stage-graded-world/` に写して直す。段ごとに、下見 0 → 下見 1 → スモーク → 本番を回し、notes を第 1 回・第 2 回と同じ型で書く（固定の後の段）。
3. notes を `/cross-review` に通す。

## スコープ

### 含むもの
- world の段: STRUGGLE の `flight_median_ms`（150 → 320）と `flight_sigma`（0.25 → 0.35）の補間・t = 0.25 / 0.5 / 0.75（第 2 回の判断 7）。
- 段ごとの下見 0（天井の測り）と、天井の段を先へ進めない規則。
- L1800 の専用の PC1 と PC-stall（直前 1800 s・λ は L1800 の下見 1 で選ぶ）。
- `SEED` = 20261016（下見 1 は +1・スモークは +2）。段どうしで同じ seed を使う。

### 含まないもの
- 段の位置を天井の値を見て動かすこと（判断 16）。
- L300・L60 の対照の範囲を変えること。
- 端から端までの赤の検査（変異を候補として最後の判定まで通す）。入れたくなったら研究者に戻す。
- 第 1 回・第 2 回の入れ物・判定・notes を変えること。
- `src-tauri/`・EH3 のファイル。
- 実在の人の打鍵。キーストロークの内容・NDJSON の生ログ（合成も）を外部の LLM（Codex を含む）に送ること。
