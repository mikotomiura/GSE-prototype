## 1. 研究質問

主要質問は、Semantic Stop と残存応答義務の終了を組み合わせた対象条件が、応答要求を残す対照より interaction / verification burden、応答義務、罪悪感、不利益予期を下げつつ、判断品質、支援到達可能性、誤採用、無検証依存を許容範囲内に保てるか、である。

「招待に従う」「再開する」「低い罪悪感」のいずれも単独の成功指標にしない。明示の受諾、保留、拒否、見逃し、無応答は正誤や遵守へ変換しない（★ 2026-09-19: 旧「受容」を分岐の意味では「明示の受諾」と呼ぶ —— §5 の注記）。

## 2. 条件

| コード | 条件 | 操作 | 役割 |
|---|---|---|---|
| `C0` | 無招待 | 同じ課題・観測窓だが招待を提示しない | 自然経過と測定反応の基準 |
| `C1` | 命令 + 完了確認 | 推奨行為を明示し、明示の受諾・拒否・完了確認の応答を要求 | GR-H4 の命令対照 |
| `C2` | Semantic Stop + residual duty | 意味推論と達成認定は停止するが、確認・説明・検証のいずれかを要求 | GR-H9 の負担転嫁対照 |
| `C3` | Semantic Stop + no duty + minimum support | 応答を要求せず、拒否・無視で不利益を生まず、必要時の支援経路を残す | EVAL-NCC 対象条件 |
| `C4` | negligent relinquishment | 応答は要求しないが、文脈支援・説明・是正へ戻る実効経路を意図的に欠く | 放置的返還の負の対照 |

> ⚠️ **2026-09-19（J-16）**: `C0`〜`C4` の比較は**研究用の別計器（replay prototype・実験用アプリ）の中でだけ**行う。★ GSE 本体・O1 には `C1`（命令＋完了確認）も `C4`（支援経路を欠く）も入れない。

`C4` は低リスクの模擬課題と短い観測窓に限定する。研究者への緊急連絡と安全上の救済は常に残し、課題後に説明する。実害のある支援剥奪は行わない。

ここでいう負の対照は、成功条件の弁別に使う**設計上の負の比較条件**である。未測定交絡を検出する formal negative-control exposure / outcome とは呼ばない。

## 3. 最小支援義務

`C3` が満たすべき minimum support は次の六項目である。

1. 支援経路が提示後も発見可能で、最大手順数と応答時間の基準を満たす。
2. 応答しない、拒否する、後から戻ることによる評価・報酬・アクセス上の不利益がない。
3. 支援要求、異議申立て、誤り訂正、必要時の人間へのエスカレーション経路がある。
4. システムが停止した対象と、継続する運用処理を利用者向け説明と実装監査の双方で区別できる。
5. 後から支援を求めても、先の無応答や画面外行為を遡及的に遵守・失敗・回復として認定しない。
6. 支援不能・不確実性・技術故障を、利用者の自己責任へ変換せず明示する。

一項目でも操作確認に失敗した機会は `C3 delivered` とみなさず、ITT には割付どおり残し、実装忠実度解析で別記する。

## 4. 解析集団

### 4.1 主要集団

`Invitation-assigned set (IAS)` を、条件へランダム割付された全機会と定義する。表示成功、気づき、クリック、回答、再開の有無を問わず含める。これは participant-level ITT ではなく、反復する opportunity-level ITT 相当であり、推定時には参加者内相関を扱う。

### 4.2 副次集団

| 集団 | 用途 | 禁止事項 |
|---|---|---|
| `Delivered set` | 表示・配信の忠実度確認 | 主要効果の母集団へ置換しない |
| `Aware set` | 終了後 probe で招待に気づいたと回答した機会 | 選択後サブグループのため因果効果と呼ばない |
| `Protocol-conformant set` | 最小支援義務や割付操作が実装どおりだった機会 | ITT を置換しない |
| `Completer set` | 全自己報告を完了した機会 | 主要解析にしない |

## 5. 分岐の定義

| 分岐 | 観測規則 |
|---|---|
| 明示の受諾（★ 旧: 受容） | W0 内に、招待が示す選択肢を明示的に選ぶ。画面外行為の達成や回復は推定しない。⚠️ **別計器でだけ記録する**（GSE 本体の表現チャネルには inbound が無い・ADR-017 D3） |
| 保留 | W0 内に `later` / 保留を明示選択する。後の行為で明示の受諾へ遡及変更しない（★ SSOT の受容（離席が起きたか）は別に記述として報告してよい） |
| 拒否 | W0 内に拒否・dismiss を明示選択する |
| 見逃し | W0 に操作がなく、後の中立 probe で「招待に気づかなかった」と回答した場合だけ付与 |
| 意図的無応答 | W0 に操作がなく、probe で「気づいたが反応しなかった」と回答した場合だけ付与 |
| 判別不能無応答 | 操作がなく、probe が `わからない`、未回答、または取得不能 |

> ⚠️ **2026-09-19（J-13）**: SSOT の「**受容**」は「提示に対して離席が起きたか」という**行動定義**である（ADR-018 D5）。本契約の明示選択と混同しないため、上の表の旧「受容」を「明示の受諾」と呼び分けた。★ 行動定義の受容も、明示の受諾も、**成功の指標にしない**（記述として報告する・ADR-033 D5）。

ログだけから見逃しと意図的無応答を推定しない。probe 自体が応答義務を作らないよう、ブロック終了時に全条件共通で一度だけ尋ね、無回答選択を認める。

`C0` は招待がないため、応答分岐を構造的 `not applicable` とする。C0 の作業転帰を C1-C4 と比較する際も、架空の無応答分岐を付与しない。

## 7. Estimand

### 7.1 主要 treatment-policy estimand

各主要評価量 `Y` について、

`tau_Y = E[Y(A=C3)] - E[Y(A=C2)]`

を IAS 上で推定する。配信失敗、見逃し、拒否、無応答を割付どおり含める。反復機会には参加者クラスタを用いる。

共同成功は次の階層 gate とする。

1. **Burden gate**: interaction burden、verification burden、応答義務のうち事前指定した主要量で `C3` が `C2` より優れる。
2. **Quality gate**: 判断品質と支援到達可能性が非劣性を満たす。
3. **Reliance gate**: 誤採用と無検証依存の増加が許容上限を超えない。
4. **Non-abandonment gate**: `C3` が `C4` より支援到達可能性または放置不安で優れ、minimum support の操作確認を満たす。

全 gate を通過した場合だけ `jointly acceptable` と呼ぶ。複数アウトカムを加重平均した単一スコアで失敗を相殺しない。

### 7.2 GR-H4 estimand

`C3` 対 `C1` の IAS 差として、応答義務、罪悪感、不利益予期を主要に、選択肢分布の集中、早期離脱を副次に推定する。分岐後の自己報告を分岐で条件付けず、全 IAS で取得する。

### 7.3 分岐別 estimand

分岐は割付後変数である。各分岐内の平均、分布、転帰は記述的 estimand とし、`C3` と `C2` の因果比較とは呼ばない。principal stratification は次の条件を満たす場合だけ感度分析として行う。

- 潜在分岐の定義と同定仮定を事前登録する。
- 単調性を当然視せず、仮定別の bounds を示す。
- 主要 ITT と結論が異なる場合は ITT を優先する。

## 8. 推定モデル

- 連続・順序尺度: participant random intercept を持つ mixed model または GEE。尺度分布が不適切なら ordinal model を用いる。
- 二値評価量: identity link の binomial model で risk difference を主要にし、収束しない場合は marginal standardization を用いる。
- 判断項目: participant と item の交差 random intercept を候補とする。
- 競合転帰: cause-specific hazard だけでなく cumulative incidence を報告する。
- 標準誤差: participant cluster を最低単位とし、opportunity 数を独立 N と数えない。
- 多重性: 共同 gate は intersection-union test として扱い、一つでも不通過なら全体支持にしない。探索的副次量は FDR または記述的 CI を用いる。

無作為化が成立していれば、主要モデルに事前共変量を必須調整しない。精度向上に用いる場合は、割付前に測る課題難度、ベースライン性能、AI 経験、NFC などに限定し、未調整推定も併記する。

## 9. 非劣性マージン

マージンは次の順で決める。

1. 各評価量の損失単位を定義する。例: 判断一件の誤り、支援へ到達できない参加者一人。
2. 対象利用者と課題専門家に、負担低減と交換できない最小悪化を blind vignette で判断してもらう。
3. EH3 pilot で尺度の信頼性、床・天井、対照分布だけを確認する。条件差の点推定を有利にする方向へ使わない。
4. 候補幅の感度表を作り、最終幅を EH4 割付前に一本へ固定する。
5. CI 全体が非劣性境界内に入ることを要求する。`p > .05` を非劣性の根拠にしない。

安全または高影響判断では、誤採用・支援到達可能性に緩い非劣性幅を置かず、優越性または実質ゼロ損失を要求する。本契約の初回評価は低リスク課題に限定する。

## 10. 欠測と観測不能

### 10.1 区分

- `TECH`: 配信・ログ・入力障害。
- `OBS`: 計器では区別不能。例: 見逃しと意図的無応答を probe なしに判別できない。
- `SEL`: 自己報告拒否・離脱など転帰に依存しうる無応答。
- `STR`: 条件上評価量が定義されない。
- `ADMIN`: ブロック終了等の管理打切り。

### 10.2 主要処理

- IAS から TECH を除外しない。treatment-policy estimand を主要とする。
- 自己報告の SEL は complete-case を主要にせず、事前共変量と観測済み行動を使う multiple imputation を候補とする。
- MNAR 感度分析として、欠測者の平均が観測者より `delta_missing` 高い・低い pattern-mixture を複数提示する。
- 二値 gate は worst/best-case bounds を示す。
- 見逃しと意図的無応答を無理に補完せず、判別不能無応答を独立カテゴリで残す。
- 産出の再開、再停止、外部化、離脱は互いの欠測ではなく競合転帰である（⚠️ 2026-09-19: 離脱のうち `left_observation` は競合と打ち切りの混合として両極で上下界を併記する・ADR-009 D2）。

## 11. 調整禁止

主要 ITT で次を共変量に入れない。

- 明示の受諾、保留、拒否、見逃し、無応答（★ SSOT の受容 —— 提示の後に離席が起きたか —— も同じく調整しない）
- 介入後の罪悪感、応答義務、不利益予期、放置不安
- 検証行動、支援利用、確信変更
- 産出の再開、再停止、外部化、離脱（`left_observation` と打ち切りに分解）
- 配信成功を除く操作後の実装忠実度

これらは媒介、分岐、競合転帰または post-treatment selection である。機序分析では因果媒介仮定を明記し、主要結論と分離する。

## 12. 支持・縮小・棄却

| 判定 | 条件 |
|---|---|
| 支持候補 | 共同 gate をすべて通過し、C3 と C4 の弁別、欠測感度、実装忠実度が整合 |
| 縮小 | burden gate は通るが効果が一部構成概念に限られる、分岐 probe が不十分、または外部化可能範囲が狭い |
| 棄却 | 品質・支援・reliance gate のいずれかが実質的に悪化、minimum support 不成立、または不利益が実際に発生 |
| 未解決 | CI が支持・棄却の双方にかかる、選択的欠測で結論が反転、操作確認不成立 |

## 13. EH と主張範囲

| 段階 | 本契約でできること | できないこと |
|---|---|---|
| `EH1` | 割付、停止、非再捕捉、支援経路の実装監査 | 利用者経験の推定 |
| `EH2` | 計器、分岐分類、probe、所要時間の本人試行 | 受容性・効果の一般化 |
| `EH3` | 項目理解、床天井、操作の読まれ方、欠測理由 | 効果量・非劣性の確証 |
| `EH4` | 事前固定した条件差と共同 gate | 自然環境での持続性 |
| `EH5` | 複数セッションの異質性、欠測、持続性 | 未観測集団への普遍化 |

AI 実装監査を `EH3`、本人パイロットを外部形成的評価として数えない。
