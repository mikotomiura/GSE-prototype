# GSE 理論の操作化・体系的差分レビュー

> Status: pre-SSOT review requirement. 本タスクの成果は `.idea` 段階の検討草案であり、Claude Code との批判的検討と人間による採否判断を経るまで、`docs/`、ADR、事前登録、実装仕様へ昇格させない。

## 背景

生成的返権論と GSE 理論体系には、権限・負担の二重台帳、Semantic Stop、第二作業化、判断品質、誤受容などの構成概念が導入されている。しかし、負担、第二作業化、判断品質、誤受容は、名称と予備的な反証条件までは定義されている一方、観測可能な指標、比較条件、許容幅、交絡要因が未確定である。

また、現在の新規性判断は迅速なスコーピング・レビューに基づく。Mixed-Initiative Computing、adjustable autonomy、interruptibility、calibrated trust、automation bias、ambiguity、reflective design、open work、non-use、data refusal、Digital Nature などとの重なりを、再現可能な検索・選定・抽出手順で検証する必要がある。

## ゴール

1. 負担、第二作業化、判断品質、誤受容を、概念定義、操作的定義、指標、反証条件まで落とす。
2. GSE の残余差分を体系的に検証できるレビュー・プロトコルと証拠表を作る。
3. GSE から導く CS 命題、芸術命題、規範命題を、先行概念との差分、適用範囲、代替説明、反証条件を伴う形で確定する。
4. 結果を生成的返権論、理論体系・ロードマップ、未踏研究計画へ整合的に反映する。
5. AI エージェントによる実装支援で確認できる範囲と、本人・外部参加者による検証が必要な範囲を分離した証拠階梯を作る。
6. 上位理論、統合理論、下位理論、評価・測定モデル、構成概念、作品形式、命題、実証予測の階層を固定し、同じ名称を複数の役割で使わない。

## スコープ

### 含むもの

- 四構成概念の概念定義、操作的定義、測定候補、除外規則、交絡要因
- 主観指標と行動指標を分けた測定モデル
- 誤受容、棄却、無検証依存、判断校正を含む判断品質の評価
- データベース、検索式、期間、言語、採否基準、重複除去、抽出項目を明示したレビュー・プロトコル
- CS 系、HCI 系、AI 信頼・検証系、芸術・メディア系、Digital Nature 系の差分表
- CS 命題、芸術命題、規範命題の必要条件、反例、境界条件、反証可能な予測
- 自律性、パターナリズム、共和主義的非支配、関係的自律、異議申立可能性、責任・負担配分との比較
- 権限・負担の二重台帳による先行研究の再コーディング
- 調査サブエージェントによる独立探索と、一次資料・DOI による照合
- Mh-D の測定妥当性と、表現・介入の受容性を分けたユーザー検証ロードマップ
- AI エージェント実装、本人パイロット、外部形成的評価、統制比較、フィールド評価の役割分担

### 含まないもの

- 参加者実験、本収集、効果量や非劣性マージンの最終推定
- AI 疲労の診断、打鍵特徴からの AI 疲労推定
- AI の道徳的・法的責任主体性の決着
- 単一作品だけに基づく「新しい芸術ジャンル」の成立宣言
- GSE 本体の介入ロジック、Mh-D、UI の実装変更
- 体系的レビュー完了前の「先行研究が存在しない」という主張

## 受け入れ条件

- [ ] 四構成概念について、定義、非該当例、観測指標、主要評価量、副次評価量、交絡、失敗条件が表になっている
- [ ] 負担低減と判断品質維持を別々に判定でき、誤受容とのトレードオフが明示されている
- [ ] 第二作業化が、単なる所要時間や主観的不快感と区別されている
- [ ] 検索式、採否基準、検索日、データベース、抽出表を第三者が再実行できる
- [ ] 類似概念ごとに「既知の要素」「GSE の結合差分」「残る衝突」「縮小条件」が整理されている
- [ ] CS 命題、芸術命題、規範命題が、それぞれ一つの中核命題と複数の反証・反例条件に縮約されている
- [ ] 規範命題が、父権的介入、放置的返還、負担転嫁、再捕捉を別々に判定できる
- [ ] 「非支配的協調」を共和主義的非支配と同一視せず、理論的依拠と差分が明示されている
- [ ] Digital Nature との接続が、融合一般ではなく計算・推論・認定の停止可能性として境界づけられている
- [ ] CS・芸術・規範の横断中核命題、Digital Nature 接続命題、理論内部の構成命題、実証予測が別系列で番号づけられている
- [ ] 実践生成肖像論／自己撤退する媒体論が下位理論、非認定的再開結合／Criterion-Direct Practice Dynamics が評価・測定モデルとして整理されている
- [ ] 既存三文書の用語、研究ゲート、論文計画が更新結果と一致している
- [ ] 未実証の因果、新規性、一般化、ジャンル成立を断定していない
- [ ] 「AI エージェントで実装できたこと」をユーザー受容・介入効果の証拠として扱っていない
- [ ] 本人による自己使用を、外部ユーザー検証ではなく実行可能性・計器監査の段階として位置づけている
- [ ] Mh-D の測定妥当性と、肖像・Semantic Stop・介入の受容性を別々の研究質問とゲートで検証できる
