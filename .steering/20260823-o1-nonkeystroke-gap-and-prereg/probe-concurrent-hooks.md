# 実機確認 — **2 プロセスが同時にフックと Raw Input を張れるか**（ADR-016 D9 前提 1）

- **日付**: 2026-08-23
- **問い**: ⚠️★★★ **O1（GSE 本体・常時）と ADR-012 の別計測器が *同じ時間に* 走ったとき、
  両方に同じイベントが届くか。片方が失敗したり取りこぼしたりしないか。**
- **なぜ要るか**: ★ 研究者判断 2 =「**完全に重ねる（同時稼働）**」の前提 1（ADR-016 D9）。
  ⚠️ `.steering/20260823-.../decisions.md` D-18 で「**どちらも未確認**」と記録していた。

## ★ 計器（⚠️ 使い捨て・repo 外）

- 置き場所: **scratchpad**（`.../scratchpad/hookprobe/`）。⚠️ **repo に置かない**（ADR-012 D7「使い捨ての測定器」の作法）。
- 中身: 1 プロセスが **`WH_KEYBOARD_LL`** ＋ **message-only window ＋ Raw Input
  (`RIDEV_INPUTSINK`・マウス `0x01/0x02` とキーボード `0x01/0x06`)** を張り、**数だけ**数える。
- ⚠️★★★ **内容は 1 バイトも読まない**: VK を読まない／`GetRawInputData` は **`RID_HEADER` のみ**
  （＝ デバイス種別だけ。**座標・移動量・VK を読まない**）。
- 出力は「登録の成否」と「件数」だけ。

## ✅ ラウンド 1 — **合成入力**（2026-08-23・25 秒 × 2 プロセス同時）

★ 注入した入力: **Shift 押下 30 回**（⚠️ 文字を発生させないキーを選んだ）＋ **1px マウス移動 60 回**。

| 指標 | プロセス **A** | プロセス **B** | ★ 期待値 |
|---|---|---|---|
| `WH_KEYBOARD_LL` の設置 | ✅ **OK** | ✅ **OK** | — |
| Raw Input `RIDEV_INPUTSINK` の登録 | ✅ **OK** | ✅ **OK** | — |
| `hook_calls`（LL フック呼び出し） | **60** | **60** | 30 down + 30 up = **60** ✅ |
| `keydowns` | **30** | **30** | **30** ✅ |
| `raw_mouse`（`WM_INPUT`・マウス） | **60** | **60** | **60** ✅ |
| `raw_kbd`（`WM_INPUT`・キーボード） | **60** | **60** | **60** ✅ |

→ ★★★ **2 プロセスの計数が完全に一致し、期待値とも一致した。**
★ **どちらのプロセスも失敗せず、取りこぼしも直列化による欠落も観測されなかった。**

## ⚠️ ラウンド 2 — **実入力**（同日・20 秒 × 2 プロセス同時）

| 指標 | A | B |
|---|---|---|
| 登録（フック / Raw Input） | ✅ **OK** | ✅ **OK** |
| `hook_calls` / `keydowns` / `raw_mouse` / `raw_kbd` | **0 / 0 / 0 / 0** | **0 / 0 / 0 / 0** |

⚠️★★★ **これは「失敗」ではなく `signal_absent` である**（★ ADR-013 D1 の語彙）——
**計器は設置できたが、その 20 秒に実入力が発生しなかった。**
⚠️ **「実入力では届かなかった」と読んではならない。**

★ 再実行: `bash .../scratchpad/hookprobe/rerun_real.sh`（★ 20 秒の窓が開く）。

## ★ 結論（★ どこまで言えるか）

| | ★ 言えること | ⚠️ 言えないこと |
|---|---|---|
