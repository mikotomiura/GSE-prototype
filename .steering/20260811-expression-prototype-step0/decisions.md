## ★★ S0-D7: 表現層の平滑化は **dt を見る**一次遅れにする（固定 alpha を使わない）

- **決定**: `alpha = 1 - exp(-dt/tau)`（`tau >= 60 s`）とし、**dt を毎サンプル見る**。
  固定 alpha の EWMA は使わない。**平滑化は 1Hz 側ではなくレンダレート側で回す。**
- ★★ **理由（実測に基づく・引き継ぎには書かれていなかった）**:
  **サンプル間隔は 1000 ms 固定ではない** —— `phase1_ime_heavy.ndjson` を replay すると
  **2691 ms のギャップが実在する**。固定 alpha だと**サンプルが飛んだとき実効時定数が変わる**。
  → 実測: dt を見る形なら 均一 1.0 s と 1.0/2.691 s 混在で到達点の差は **1.11e-16**。
- ★ **「レンダレート側で回す」理由**: 1Hz 側で平滑化しても**出力は 1 秒ごとの階段のまま**である。
  spec §1.2 が要求しているのは「1 秒ごとに値が変わる」形ではなく
  **「1 秒ごとに次の値へ滑らかに向かう」形**なので、**出力はフレーム/オーディオレートで刻む**。
- ★ **数値で固定した**（spec §1.3「この 1 点だけは耳で判断せず、数値で固定する」）:

  | 量 | 実測 | 基準 |
  |---|---|---|
  | 4 Hz の減衰 | ★ **-63.6 dB** | <= -60 dB |
  | 0.5 / 20 / 70 Hz の減衰 | -45.5 / -77.5 / -88.4 dB | <= -40 dB |
  | ★ 段差の低減 | ★ **403 倍（52.1 dB）** | >= 100 倍 |
  | 1 フレームあたり最大変化（60 fps） | 2.78e-04 | < 1e-3 |

  ⚠️ **0.5 Hz だけ基準を -40 dB にした理由を明記する**（後付けで緩めたのではない）——
  **0.5 Hz は入力側の Nyquist そのもの**である（推論ゲートが 1Hz・spec §1.2）。
  **入力が原理的に到達できない上限**なので、そこに -60 dB を要求する意味が薄い。
- **却下案**: 既存のヒステリシス（`engine.rs:113` の ~2.5 s）を流用する
  → spec §1.3 が明示的に「**2.5 秒時定数は禁止帯の低い端にあり不足**」と書いている。
- ⚠️ **`EXPR_VERSION = 0.1.0-step2` を刻んだ**（spec §5 要件 4 / `design.md` §4.4）。
  **pilot 実施中はこの版を動かさない。**

## ⚠️★★★ S0-D8: 変調スペクトルは **必ず窓を掛けて**測る（Step 6 への拘束）

- **決定**: 変調スペクトルの測定は **Hann 窓 ＋ コヒーレントゲイン補正**を既定とする。
  **窓なしの DFT を判定に使わない。** また **単一周波数の「帯域 RMS」を判定に使わない。**
- ★★★ **理由（実測で符号が逆になった）** —— 同じ信号の 4.0 Hz 成分:

  | 測り方 | 階段 | 平滑後 | 結論 |
  |---|---|---|---|
  | **窓なし** | 1.86e-17 | 4.46e-05 | ✗ **「平滑化すると増える」という誤結論** |
  | **Hann 窓** | 2.68e-06 | 1.79e-09 | ★ **-63.5 dB**（解析解 -63.6 dB と一致） |

  表現層の信号は低域に非常に強い成分を持つ（状態の波は 0.001-0.02 Hz）ので、
  **窓が無いと低域からの漏れが -80 dB 帯を埋め尽くす。**
  ⚠️ **一様に刻んだ帯域 RMS も誤る**——階段のエネルギーは極めて細い線に集中しているため、
  一様サンプリングは**線をほとんど跨いでしまい**、「平滑後のほうが +1.7 dB 高い」と出る。
- ★★ **付随して初稿の主張を 1 件訂正した**——私は
  「零次ホールドは 1 Hz の**整数倍に線スペクトルを持つ**（＝ちょうど 4 Hz に線が立つ）」と書いたが、
  **整数倍ちょうどは ZOH の sinc の零点**であり**エネルギーはほぼ無い**（側帯波の 1/190）。
  **エネルギーが乗るのは両脇 `k*1Hz ± f_signal`**（実測 3.995 / 4.005 Hz に 5.0e-04）。
  → ★ **selftest が初回実行でこの誤りを FAIL として検出した。**
    **主張と一緒に検査を置いていたから気づけた**（`verify-before-claiming` ルール 6 の実例）。
- **却下案**: numpy/scipy を入れて FFT を使う → **本 Step には要らない**（見たい周波数が数点なので
  O(N) の直接評価で足りる）。★ **依存追加は研究者の別判断**（引き継ぎ §4 が明記）なので勝手に足さない。
