# 設計（進め方）

議論のタスクなので、コードの設計ではなく進め方を書く。

1. 置き場所を「層（窓のレベル）」「OS が持つ面（メニューバー・Dock など）」「場面（デスクトップが見えるとき）」「他の窓との関係（縁・隙間）」の 4 つの軸で洗い出す。
2. 確かめ方を分ける: 資料で決まるもの（API の有無・要る権限）は Apple の文書と SDK のヘッダで。資料で決まらないもの（全画面の Space に出るか）は最小の試作で。
3. 最小の試作: Swift の単一ファイル。窓を作ってレベルと collectionBehavior を変え、別の窓を全画面にして、CGWindowListCopyWindowInfo で画面上にあるか（onscreen）・層の順を数値で読む。画面は撮らない。全画面にする窓も試作自身が作る（研究者のアプリには触らない）。
4. 地図は `placement-map.md`。各行に根拠（資料の URL・ヘッダの行、または実測の記録）を付ける。
